# 32天公安省考冲刺

> 2026年11月3日—12月4日，每天4小时，共128小时。目标：绵阳市县级公安机关，执法勤务（金融财会），职位43206010；行测、行政执法类申论、公安专业科目、心理素质测试。
> 本专题是2026-11-03确认后的当前执行计划，优先于站内旧版“工作日2小时、周末5—6小时”安排。专业科目按用户确认的公安专业科目准备。

## 使用方法

按下表打开当天页面：先做四科任务，再使用当日联网资料和练习，最后打卡。日期安排为内容学习顺序；漏学时按自身情况补学，补发资料不会增加每天4小时的学习预算。

常规日为行测100分钟、申论65分钟、公安65分钟、心理准备10分钟；模拟日重新分配但总计仍为240分钟。心理准备不设置人格评分或“标准答案”，以了解要求、真实作答和正常作息为主。

## 考务与资料边界

查到的[绵阳2027年度人民警察招录公告转载正文](https://www.fenbi.com/page/exam-information-detail/470065370654720)载明笔试为2026-12-05至06，心理测试12-06；具体科目时间地点以准考证和[官方报名专题](https://www.scpta.com.cn/front/Special/Info/44ad63b224814ead8b066b95b0aa6aff)为准。转载页面顶部与正文截止时间有差异，不能使用顶部摘要替代正文及系统提示。

公安法律知识须核对本次适用大纲、现行有效文本和题目时点。国考或外省大纲只能用作通用框架参考。题目优先链接可公开核验的原出处；自编题显著标注，不能冒充四川真题。
