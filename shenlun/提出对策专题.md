# 申论 · 提出对策专题

> 对策须回答解决什么、做什么、怎样做。例题均为实际考试公开整理版本，题源和原题要求见 [配套真题](../真题/申论/知识点配套真题.md)。

## 一、对策来源逐项查

| 来源 | 操作 | 真题应用 |
| --- | --- | --- |
| 明示建议 | 提取建议的对象、动作和适用条件 | [T07](../真题/申论/知识点配套真题.md#t07)中的信息标示、管护探索 |
| 成功做法 | 从案例提炼解决机制 | [T06](../真题/申论/知识点配套真题.md#t06)中的较好文化运营案例 |
| 失败教训 | 写出失败环节，推导如何避免 | [T06](../真题/申论/知识点配套真题.md#t06)中的重复建设与雷同服务 |
| 问题反推 | 反转缺口，并补充可执行方式 | [T07](../真题/申论/知识点配套真题.md#t07)中的破损脏污 |
| 原因治理 | 针对产生问题的机制，避免仅治表象 | [T08](../真题/申论/知识点配套真题.md#t08)中的人才与专业能力短板 |

“材料直接建议”与“仓库推导建议”要区分。推导可以合理延伸实施方法，不能伪造原资料没有的事实或资源。

## 二、一条措施怎样写

    针对的问题 → 主体和权限 → 动作与对象 → 实施方式 → 必要保障

同一主体可在段首统一交代，字数紧时不用机械写齐所有要素。加强宣传、加强管理只给了方向，应继续回答宣传什么、谁来管、如何执行。

**真题例题：** [T07座椅](../真题/申论/知识点配套真题.md#t07)。功能信息不足可推导设置醒目说明与使用指引；破损脏污可推导责任公示、巡查维修和清洁。建议具体，但不需要编造每周几次等硬指标。

## 三、问题与建议对应

| T07材料问题归类 | 仓库推导的建议方向 | 核对点 |
| --- | --- | --- |
| 供需适配不足 | 调查需求、补充数量与功能配置 | 服务谁、补在哪 |
| 材质结构与选址欠妥 | 优化材质、坐靠结构和位置，兼顾安全通行 | 不只说提升设计 |
| 破损脏污、反馈不清 | 明确管护主体，巡查清洁、及时维修、公示联系方式 | 建设与维护都考虑 |
| 功能信息不明显 | 设置功能说明和使用指引 | 不只说提高意识 |
| 多部门规范协调困难 | 协调标准与职责，形成协同机制 | 不由一个部门包办一切 |

## 四、身份与可行性

- 能直接实施的事项，明确动作。
- 需要其他部门权限或资源的事项，用协调、推动、提出建议等表达，并写清协作对象。
- 需要新政策的事项，不能以基层工作人员身份直接宣布制定全国法律。
- 没有材料依据的预算、名额、时限和处罚不自行补入。

**真题例题：** [T08脱贫攻坚队](../真题/申论/知识点配套真题.md#t08)。按队员专长与日志领域配置工作，区分专业帮扶和需要当地部门协调的事项。

## 五、真题精讲：四川公共座椅

**原题：** 2024四川县乡卷第2题，20分，资料2，400字以内。身份为市政部门工作人员，明确要求先梳理完问题再提建议。[题源与摘要](../真题/申论/知识点配套真题.md#t07)。

**作答步骤：** 逐个场景找问题→按属性归类→建立对应建议→检查市政身份与协同权限→先问题后建议成文。

**参考表达（仓库整理）：**

> 问题：座椅数量与功能配置未充分满足需求；部分材质、结构和选址影响舒适、安全及通行；设施破损脏污，管护主体与反馈渠道不清；智能功能说明不足；多部门标准协调困难。
>
> 建议：调查人群与场所需求，合理补充座椅及配套功能；改进材质、坐靠结构和位置，兼顾季节舒适与安全通行；明确管护责任，开展巡查维修保洁，公示联系方式；设置醒目功能说明；协调相关部门衔接标准与管理职责。

以上是整理示范，具体表现应在阅读完整资料后补足，不能只背这段概括。

**易错：** 问题建议交错写违反顺序；只增加座椅数量漏掉设计和维护；提出没有依据的强制罚款。

## 六、真题精讲：文化空间

**原题：** [2024国考地市级第4题·T06](../真题/申论/知识点配套真题.md#t06)，资料4，450字以内。

先找运营能力、布局、服务与文化功能问题，再读取正面案例提炼服务机制。数量扩张无法单独解决运营质量问题；不宜只写多投入、多建设。

## 七、自测与复盘

按原题完成T06、T07、T08，不改变设问。将每条建议标记为明示、借鉴或推导，再检查针对性、具体性、权限和原题格式顺序。

**复盘标签：** 问题漏点、措施无对应、空泛动词、措施越权、虚构指标、特殊要求遗漏。下一次重写最薄弱的一条措施，并返回资料核对。
