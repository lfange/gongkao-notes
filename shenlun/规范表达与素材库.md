# 申论 · 规范表达与素材库（口语→规范 / 主题案例 / 金句）

> 这份是**工具库**，不是阅读材料：小题用它把"土话"换成规范词，大作文用它补论据和金句。
> 用法：**每周固定 30 分钟过一遍 + 大作文动笔前按主题查案例**；素材贵精不贵多，每个主题**记住 2 个 + 一句金句**即可。
> 积累新的素材随手补进对应分区，并在 [笔记.md](笔记.md) 里打卡。

## 一、口语 → 规范表达对照表（小题提分利器）

| 材料口语 | 规范表达 |
| --- | --- |
| 搞好、弄好 | 推进、落实、抓好 |
| 让……发展起来 | 推动……发展、促进……壮大 |
| 钱不够 | 资金保障不足、投入有限 |
| 东西贵 | 价格水平偏高、消费成本较高 |
| 人不够用 | 人才（队伍）力量薄弱 |
| 没人管 | 监管缺位、管理主体缺失 |
| 各管各的、谁都管 | 多头管理、职责不清、条块分割 |
| 政策没落地 | 政策落实不到位、执行不力 |
| 老百姓不理解 | 群众认同度低、缺乏社会共识 |
| 大家一起管 | 多元共治、协同治理 |
| 先试试再说 | 试点先行、稳步推进 |
| 想出来的办法 | 创新举措、探索……机制 |
| 出了事再管 | 重事后处置、轻事前预防（被动应对） |
| 一阵风 | 缺乏长效机制、运动式治理 |
| 只顾眼前 | 重短期效益、轻长远发展 |
| 光说不干 | 重部署轻落实、执行力不足 |
| 帮一把 | 政策扶持、精准帮扶 |

> 用法提示：**方向别偷换**——材料"人手不够"写"人才队伍薄弱"没问题，写成"人才流失"就是无中生有。

## 二、高频动宾搭配（对策题直接套）

- **机制类**：健全……机制 / 完善……制度 / 建立……体系 / 构建……格局；
- **投入类**：加大……投入 / 强化……保障 / 拓宽……渠道（资金、人才、技术）；
- **监管类**：强化……监管 / 严格……执法 / 落实……责任 / 开展专项整治；
- **服务类**：优化……服务 / 简化……流程（放管服）/ 提升……效能；
- **宣传类**：加强……宣传 / 营造……氛围 / 引导……参与；
- **科技类**：推进……数字化 / 赋能…… / 依托大数据、智能化手段。

## 三、主题案例库（每主题 2—3 个，大作文论据）

### 1. 民生服务

- **"接诉即办"（北京）**：以 12345 热线为抓手，群众诉求"闻风而动、有一办一"，并升级"未诉先办"——用一根热线撬动超大城市治理。适用：精细治理、群众路线、服务型政府。
- **"口袋公园 / 一刻钟便民生活圈"**：利用边角空地、步行 15 分钟范围补齐便民设施——小空间承载大民生。适用：微改造、以人为本、精细化。

### 2. 基层治理

- **"枫桥经验"**：新时代"矛盾不上交、就地化解"，从依靠群众到发动群众、多元共治——基层治理的传家宝。适用：社会治理、化解矛盾、共建共治共享。
- **老旧小区改造"居民议事会"**：改造方案居民共商，加装电梯纠纷从三个月缩短到两周——全过程人民民主的微观样本。适用：协商民主、问需于民、共同缔造。

### 3. 创新发展

- **新质生产力**：以科技创新为主导（C919 大飞机、新能源产业、人工智能大模型）——从要素驱动转向创新驱动。适用：高质量发展、科技自立自强、产业升级。
- **深圳"先行示范"**：从"三天一层楼"到"基础研究 + 产业化"迭代——创新生态的重要性。适用：改革精神、创新环境、宽容失败。

### 4. 生态文明

- **塞罕坝**：三代人 55 年荒原造林百万亩，获联合国"地球卫士奖"——接续奋斗 + 绿水青山就是金山银山。适用：久久为功、生态优先、代际传承。
- **长江十年禁渔**：共抓大保护、不搞大开发，江豚重现——发展方式转型。适用：人与自然和谐共生、转型阵痛与长远眼光。

### 5. 文化传承

- **故宫文创 / 数字敦煌**：让文物"活起来"，传统 IP 现代表达——创造性转化、创新性发展。适用：文化自信、科技 + 文化、供给侧创新。
- **"村超""村晚"**：贵州乡村足球赛火爆出圈，群众办、群众乐——文化活力在民间、乡村振兴的软引擎。适用：群众文化、乡村振兴、基层活力。

> 使用规则：**一个案例只用 30 字讲完**（主体 + 做法 + 结果），紧跟一句分析——案例是论据不是故事。

## 四、金句库（按用途分类，各背 2 句）

### 开头 / 立论

- 治国有常，利民为本。（民生主题万能开头）
- 政之所兴在顺民心，政之所废在逆民心。（群众路线）
- 苟日新，日日新，又日新。（创新、改革）

### 论证 / 过渡

- 天下大事，必作于细。（精细化、小事小节）
- 图之于未萌，虑之于未有。（风险防范、未诉先办）
- 钉钉子往往不是一锤子就能钉好的，而是要一锤一锤接着敲。（久久为功、抓落实）
- 绿水青山就是金山银山。（生态文明）

### 结尾 / 升华

- 民生无小事，枝叶总关情。（民生收尾）
- 道阻且长，行则将至；行而不辍，未来可期。（奋斗、展望）
- 国之大者，在乎民也。（升华到人民立场）

> 金句使用戒律：**全文 2—3 句足矣**，堆砌反而降档；引用要**贴题**，别硬塞。

## 五、素材更新规则

1. 看到好案例 / 金句 → 按**主题分区**补进本文件对应表格（附一句"适用什么题"）；
2. 每条素材记**三元组**：主体（谁）+ 做法（干了什么）+ 结果（成效如何）；
3. 时效性素材（年度热词、当年政策）同步补到 [../xingce/常识判断/笔记.md](../xingce/常识判断/笔记.md) 的时政分区，两边不重复维护。

## 六、自测练习

1. 把下面三句材料口语改写成规范表达：①"村里年轻人都出去打工了"；②"相关部门互相推诿"；③"这个政策执行得虎头蛇尾"。
2. 用"塞罕坝"案例写一个 60 字以内的论据段（含一句分析）。
3. 检验金句储备：不看笔记，"民生"主题的开头句和结尾句你各能默写哪句？

### 答案附录

1. ① 人才外流严重、农村空心化（青年劳动力流失）；② 部门职责不清、推诿扯皮（缺乏协同机制）；③ 政策执行缺乏持续性、重开头轻长效（落实不到位、虎头蛇尾→"缺乏长效机制 / 执行不力"）。
2. 示例：三代塞罕坝人接力造林五十余载，终使百万亩荒原变林海（30 字案例）。正是因为一茬接着一茬干的定力，才成就了这份生态奇迹——抓落实，贵在坚持（分析句）。可见任何事业都非一锤定音，而在久久为功（回扣）。
3. 开头：治国有常，利民为本 / 民生无小事，枝叶总关情；结尾：民生无小事，枝叶总关情 / 国之大者，在乎民也。（两句互换亦可，关键是默写准确、用对场合）

## 错题归因模板

素材用错时记入 [错题本.md](../错题本.md)：

- **表达错**：口语没转换 / 方向偷换 → 回对照表重写；
- **案例错**：张冠李戴（主体、结果记串）→ 回案例库重记三元组；
- **金句错**：引错场合、默写不准 → 标注"适用主题"重新背。
