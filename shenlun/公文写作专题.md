# 申论 · 公文写作专题（应用文：格式 + 内容 + 语气）

> 公文题是**性价比最高**的题型：格式分是**白送的**（背一遍文种表就能拿），内容分是概括题的找点功夫。
> 一句话本质：**格式（文种决定）+ 内容（材料决定）+ 语气（对象决定）**。
> 专题结构：**本质 → 格式四要素 → 高频文种表 → 内容写法 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录）。
> 使用方法：看讲解 → 遮住参考答案自己写例题 → 对照 → 缺点记入 [错题本.md](../错题本.md)。

---

## 一、本质：格式分 + 内容分

- 公文题阅卷两把尺：**格式（约 2—4 分）**——标题、称谓、落款等要素齐不齐；**内容（大头）**——要点全不全、逻辑顺不顺；
- 所以做题顺序固定：**先审文种定格式 → 再审对象定语气 → 最后回材料找内容**。

## 二、审题三问（动笔前 30 秒）

1. **什么文种？** → 决定格式与结构（倡议书？讲话稿？提纲？）；
2. **给谁看 / 给谁听？** → 决定称谓和语气（群众用亲切语、领导用汇报语、内部用平实语）；
3. **写它干什么？** → 决定正文重心（倡议=动员号召，报告=摆情况提建议，通知=讲清事项要求）。

> 题干"不考虑格式"或"写提纲"→ 格式分免除，把全部字数投给内容要点；反之**文种格式一个不能少**。

## 三、格式四要素

| 要素 | 写法 | 说明 |
| --- | --- | --- |
| **标题** | 发文机关 + 事由 + 文种，如《关于开展 XX 活动的倡议书》；申论一般写"关于……的文种"即可 | 居中，不带书名号也常见（写上更稳） |
| **称谓** | 顶格写对象："各位居民朋友：""各位领导、各位同事：" | 对内汇报可写"尊敬的各位领导" |
| **正文** | 开头（背景 / 目的）→ 主体（分条写要点）→ 结尾（号召 / 要求 / 希望按文种定） | 主体占 70% 以上篇幅 |
| **落款** | 署名（题干给的身份 / 单位）+ 日期（"XX 年 X 月 X 日"或写考试日期） | 右下，两行 |

## 四、高频文种速查表

| 文种 | 格式要点 | 语气 / 结构特点 |
| --- | --- | --- |
| **倡议书** | 四要素全 | 面向群众，有感染力；结尾"让我们携手……"发出号召 |
| **公开信 / 回信** | 四要素全 | 回应关切：先表态感谢 → 逐条回应 → 承诺展望 |
| **讲话稿 / 发言稿** | 标题 + 称谓（可无落款） | 口语化、有互动感（"大家好""相信大家都能感受到"）；结尾"谢谢大家" |
| **调研报告 / 汇报材料** | 标题 + 正文（提纲可不称谓落款） | 汇报语；结构：基本情况 → 做法 / 成效 → 问题 → 建议 |
| **通知** | 四要素全 | 简洁正式：事项（干什么）→ 要求（怎么办）；少形容词 |
| **工作方案 / 实施方案** | 标题 + 正文 | 目标 → 任务 → 措施 → 保障，条目化 |
| **短评 / 新闻稿 / 编者按** | 标题 + 正文（**无称谓、无落款**） | 面向公众；新闻稿重事实（导语五要素），短评重观点（首段亮明看法） |
| **建议书 / 提案** | 四要素全 | 重心在建议条目：每条"建议 + 理由/做法" |

> 记不住时判断逻辑：**对外宣传类**（短评、新闻稿）无称谓落款；**上行下达类**（倡议、通知、建议、回信）四要素全；**口头发言类**（讲话稿）有称谓可免落款。

## 五、内容写法（正文三段式）

1. **开头**（2—3 行）：交代背景 / 目的 / 缘由——"为进一步……""根据……安排""近期，我社区出现了……现象"；
2. **主体**（重心）：把材料要点按文种逻辑组装——
   - 倡议书：倡议事项分条（每条 = 做什么 + 为什么要做）；
   - 调研报告：做法 / 成效 / 问题 / 建议分块；
   - 通知：事项 + 要求；
3. **结尾**（1—2 行）：按文种收口——倡议书号召、报告"以上报告，请审阅"、通知"特此通知"、讲话稿"谢谢大家"。

> **字数账**：300—500 字的公文题，格式要素约占 50—80 字（标题称谓落款），主体只能写 4—6 条——**要点宁精勿滥**。

## 六、易错点清单

1. **格式张冠李戴**：短评写了称谓落款、倡议书丢了落款——背文种表。
2. **文种定错语气**：通知写成抒情散文、讲话稿写成书面文件——**对象感**是命门。
3. **只抄材料不组装**：公文主体必须**按文种逻辑重排**（如调研报告"问题—建议"两块），不是材料顺序照搬。
4. **开头冗长**：背景写 100 字挤占主体——开头最多 3 行。
5. **落款日期瞎编**：写"XX 年 X 月 X 日"即可，别空着也别写错年份。
6. **忽略题干身份**：题干说"以社区工作者身份"，署名就不能写"XX 街道办事处"。
7. **"不考虑格式"还写格式**：白占字数挤掉要点——审题逐字看。

## 七、精讲例题

### 例题 1（倡议书）

**题**：假如你是 X 社区工作人员，请根据给定资料，写一份号召居民参与垃圾分类的倡议书。（25 分，450 字左右）

**材料**（节选）：

> X 社区垃圾分类试行半年：多数居民知道分类，但"嫌麻烦、怕分错"心理普遍，投放高峰期混投率仍超三成；社区仅有 4 名督导员，分身乏术；而参与"绿色账户"积分试点的 3 栋楼，居民凭积分兑换日用品，混投率不足 5%；小学生志愿者入户宣传后，家中老人分类准确率明显提升；厨余垃圾破袋投放时异味大，部分居民直接绕行。

**解题过程**：

1. 审题：文种=倡议书（四要素全）；身份=社区工作人员；对象=居民（亲切、动员）。
2. 内容组装：
   - 开头：背景（试行半年、成效与不足）+ 目的（号召参与）；
   - 主体：倡议事项（从材料做法提炼）——主动学习分类、破袋正确投放、参与积分激励、发动家庭邻里（孩子带动老人）、志愿督导；
   - 结尾：号召。

**参考答案**：

> **关于参与垃圾分类、共建绿色家园的倡议书**
>
> 各位居民朋友：
>
> 垃圾分类在我社区试行半年，大家的分类意识明显增强，但混投率仍偏高，分类习惯尚未养成。为共建绿色整洁的家园，我们向全体居民发出如下倡议：
>
> 一、**主动分类，准确投放**。请提前学习分类知识，不怕麻烦、不怕分错，逐步掌握要领；厨余垃圾请破袋投放，勿因异味绕行混投。
> 二、**参与积分，兑换实惠**。欢迎注册"绿色账户"，分类投放攒积分、兑换日用品，让环保有回报。
> 三、**小手拉大手，全家齐参与**。请支持社区小小志愿者入户宣传，让孩子带动长辈，全家养成分类习惯。
> 四、**邻里互助，争当督导**。欢迎加入志愿督导队伍，高峰时段在桶边指导，帮助街坊正确投放。
>
> 垃圾分一分，环境美十分。让我们从今天、从自家垃圾桶做起，共同守护美丽家园！
>
> X 社区居民委员会
> XX 年 X 月 X 日

**自评**：四要素齐全；主体 4 条全部来自材料做法；语气动员化（"请""欢迎""让我们"）；约 380 字。

### 例题 2（讲话稿）

**题**：假设你是县文化馆馆长，要在"乡村文化能人"培训班上作动员讲话，请拟写讲话稿的开头与结尾部分（不需写主体）。（15 分，200 字左右）

**解题思路**：讲话稿=标题 + 称谓（可无落款）；口语化、有互动；开头=问候 + 培训背景目的；结尾=提希望 + "谢谢大家"。

**参考答案**：

> **在全县乡村文化能人培训班开班式上的讲话（节选）**
>
> 各位学员、各位乡贤：
>
> 大家上午好！今天，我们全县的文艺骨干、非遗传承人、村文化礼堂管理员齐聚一堂，共同参加这期乡村文化能人培训班。乡村振兴，既要塑形，更要铸魂；大家就是咱们县乡村文化建设的"种子"。希望大家珍惜这次机会，学有所获、学有所用。
>
> （主体略）
>
> 最后，希望大家把学到的本领带回村里，带火一支队伍、带活一方文化。咱们文化馆永远是大家的后盾！预祝大家满载而归。
>
> 谢谢大家！

## 八、自测练习

1. 短评、倡议书、讲话稿三者的格式要素各是什么？
2. 讲话稿和通知在语气上有什么区别？各举一个典型用语。
3. 一道"写一份调研报告提纲（500 字，不考虑格式）"的题，500 字应该怎么分配？

### 答案附录

1. 短评：**仅标题 + 正文**（无称谓、无落款）；倡议书：**四要素全**（标题、称谓、正文、落款）；讲话稿：**标题 + 称谓**（落款可省，一般以"谢谢大家"收尾）。
2. 讲话稿**口语化、有对象感**："大家好""相信大家都能感受到""谢谢大家"；通知**书面正式、简洁祈使**："现将有关事项通知如下""请遵照执行""特此通知"。
3. "不考虑格式"→ 全部字数给内容。调研报告结构：**基本情况约 100 字 → 主要做法与成效约 150 字 → 存在问题约 100 字 → 对策建议约 150 字**。建议部分是重心，动词开头条目化。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **格式错**：文种要素记错 → 回文种表重背该文种；
- **语气错**：对象感丢失、文种与语体不匹配 → 重写结尾一段；
- **组装错**：材料顺序照搬、没按文种逻辑分块 → 重新列结构提纲；
- **要点漏**：主体条目少于 3 条 → 回材料重找（重点看案例做法与专家建议）。
