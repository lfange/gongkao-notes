# 申论知识图谱

> 配套练习均使用 [23道历年真题](../真题/申论/知识点配套真题.md)，年份、卷别、题号与来源逐题标示。
> 核心问题：题干要求完成什么任务，材料中的哪些信息与任务相关，如何加工成符合身份、文种和字数的答案。

## 一、总图

    申论
    ├─ 输入：题干 + 给定资料
    ├─ 处理
    │  ├─ 审题
    │  ├─ 阅读
    │  ├─ 提取
    │  ├─ 合并
    │  ├─ 分类
    │  ├─ 转换
    │  └─ 排序
    ├─ 输出
    │  ├─ 概括归纳
    │  ├─ 提出对策
    │  ├─ 综合分析
    │  ├─ 应用文
    │  └─ 大作文
    └─ 约束
       ├─ 材料范围
       ├─ 身份与对象
       ├─ 文种格式
       ├─ 字数
       └─ 作答要求

## 二、审题知识图谱

    题干
    ├─ 任务：概括 / 分析 / 对策 / 应用文 / 作文
    ├─ 对象：谁或什么事情
    ├─ 范围：某则材料 / 全部资料
    ├─ 身份：以谁的名义
    ├─ 受众：写给谁看
    ├─ 文种：提纲 / 通知 / 讲话稿 / 短评等
    ├─ 字数：决定要点数和展开度
    └─ 要求：全面 / 准确 / 有条理 / 观点明确

### 2.1 任务词关系

| 题干动词 | 核心任务 | 加工程度 |
| --- | --- | --- |
| 概括、归纳 | 找全材料中的同类信息 | 压缩、合并、分类 |
| 分析 | 揭示含义、原因、影响或逻辑关系 | 在材料依据上建立关系 |
| 谈理解 | 解释表层和深层含义 | 释义 + 分析 + 结论 |
| 谈看法、评价 | 对观点或现象作判断 | 态度 + 依据 + 结论 |
| 提出对策 | 解决指定问题 | 提取与推导可执行措施 |
| 总结经验、启示 | 提炼成功逻辑并迁移 | 从个性做法到一般方法 |

### 2.2 审题错误关系

    范围看错 → 找再多也是越界
    对象看错 → 要点主体错位
    任务看错 → 问原因却答问题
    身份看错 → 对策越权、语气不符
    文种看错 → 内容功能和格式不符
    字数忽视 → 要点过少或无法写完

## 三、材料信息图谱

    一段材料
    ├─ 现状 X：发生了什么、呈现何种特征
    ├─ 问题 W：哪里不好、未达到什么目标
    ├─ 原因 Y：为什么发生
    ├─ 影响 I：带来什么积极或消极结果
    ├─ 对策 D：谁采取了什么办法
    ├─ 观点 G：谁如何判断或解释
    └─ 案例 A：具体人物、地方、事件和数据

### 3.1 要点之间的因果链

    背景/现状
       ↓ 暴露
    问题
       ↓ 追问为什么
    原因
       ↓ 造成
    影响
       ↓ 倒推解决
    对策
       ↓ 实施后
    成效与新问题

### 3.2 显性与隐性要点

    显性要点
    ├─ 关联词：因为 / 导致 / 应当 / 有利于
    ├─ 观点句：专家、领导、群众评价
    └─ 政策句：目标、措施、要求

    隐性要点
    ├─ 数据变化 → 程度或趋势
    ├─ 正面案例 → 经验和做法
    ├─ 反面案例 → 问题、原因或教训
    ├─ 前后对比 → 变化和成效
    └─ 群众反应 → 需求、问题或评价

### 3.3 案例加工

    案例细节
       ↓ 去掉人名、地名和过程性枝节
    主体 + 做法 + 对象 + 效果
       ↓ 根据题目转换
    问题 / 原因 / 经验 / 论据

## 四、要点加工图谱

### 4.1 合并

    散点
    ├─ 同义 → 合并
    ├─ 同主体 → 可合并
    ├─ 同环节 → 可合并
    └─ 不同得分关键词 → 保留

**边界：** 合并是去重复，不是把多个独立得分点压成一句空泛大词。

### 4.2 分类

    分类标准
    ├─ 主体：政府 / 企业 / 社会 / 群众
    ├─ 环节：事前 / 事中 / 事后
    ├─ 层面：认识 / 制度 / 资源 / 技术
    ├─ 领域：经济 / 社会 / 文化 / 生态
    └─ 逻辑：问题 / 原因 / 影响 / 对策

**选择规则：** 优先使用材料自带结构；一种答案只保持一套主要分类标准。

### 4.3 转换

    问题
       └─ 反向转换 + 补主体和手段 → 对策

    他地做法
       └─ 去个性细节 + 转换适用主体 → 启示

    数据和案例
       └─ 压缩事实 + 说明证明什么 → 作文论据

    口语材料
       └─ 提炼核心词 + 保留具体表现 → 规范表达

### 4.4 排序

    并列信息 → 按重要性或材料顺序
    流程信息 → 事前—事中—事后
    因果信息 → 问题—原因—影响—对策
    对策信息 → 制度—资源—执行—监督
    综合分析 → 观点/释义—分析—结论

## 五、概括归纳图谱

    概括题
    ├─ 概括问题
    ├─ 概括原因
    ├─ 概括影响
    ├─ 概括做法
    ├─ 概括特点
    └─ 概括变化

    作答链
    题干任务
       ↓
    只找同类要点
       ↓
    同义合并、异点保留
       ↓
    核心词前置
       ↓
    分条书写

### 5.1 不同问法的关系

| 问法 | 答案节点 | 特别要求 |
| --- | --- | --- |
| 问题 | 负面表现 | 回答“哪里不好” |
| 原因 | 导致现象的因素 | 回答“为什么” |
| 影响 | 造成的结果 | 区分积极意义与危害 |
| 做法 | 已经采取的措施 | 不改写成建议语气 |
| 特点 | 区别于其他对象的属性 | 需要定性概括词 |
| 变化 | 前后状态对比 | 同一维度写“由 A 到 B” |

**答案最小单元：**

> 序号 + 核心概括词 + 材料中的具体表现。

> 详细方法和例题见 [概括题专题](概括题专题.md)。

## 六、提出对策图谱

    对策来源
    ├─ 材料直接建议
    ├─ 成功案例做法
    ├─ 失败案例教训
    ├─ 问题反向转换
    └─ 原因针对性解决

    一条完整对策
    ├─ 主体：谁来做
    ├─ 对象：针对谁或什么
    ├─ 手段：通过什么方式
    ├─ 内容：具体做什么
    ├─ 目标：解决什么问题
    └─ 保障：如何确保落实

### 6.1 问题—原因—对策

    表层问题
       ↓ 追到原因
    制度缺失？资源不足？执行不力？能力不足？
       ↓
    对症措施
       ↓
    制度建设 / 资源保障 / 责任落实 / 培训赋能

**可执行性检查：**

- 只写“提高认识” → 缺少方式；
- 只写“加强监管” → 缺少主体、对象和措施；
- 对策超出作答身份权限 → 越权；
- 每条对策不能对应材料问题 → 脱离材料。

> 完整推导和四川真题见 [提出对策专题](提出对策专题.md)。

## 七、综合分析图谱

    综合分析
    ├─ 词句理解
    │  └─ 释义 → 材料表现/原因/影响 → 结论
    ├─ 评价分析
    │  └─ 态度 → 理由与条件 → 对策/结论
    ├─ 比较分析
    │  └─ 统一维度 → 相同点/不同点 → 结论
    └─ 启示分析
       └─ 成功逻辑 → 主体转换 → 可借鉴做法

### 7.1 词句理解

    表层关键词
       ↓ 结合上下文解释
    句子直接含义
       ↓ 联系全文主旨
    深层指向
       ↓ 用材料要点展开
    问题 / 原因 / 影响 / 做法
       ↓
    总结或提出方向

### 7.2 评价分析

    评价对象
       ↓
    是否有合理性？
       ├─ 有 → 合理依据
       └─ 无或有限 → 问题与适用条件
       ↓
    明确、辩证的态度
       ↓
    改进方向

### 7.3 比较分析

    A 与 B
       ↓ 使用同一组维度
    主体 / 目标 / 方法 / 资源 / 效果 / 条件
       ↓
    相同点 + 不同点 + 总体结论

### 7.4 启示分析

    案例为什么成功
       ↓
    主体做了什么 + 解决什么问题
       ↓ 去掉个性细节
    可复制的一般方法
       ↓ 转为当前主体
    启示答案

> 四类题型例题见 [综合分析专题](综合分析专题.md)。

## 八、应用文图谱

    应用文
       ↓ 先判断沟通功能
    ├─ 宣传动员
    │  └─ 倡议书 / 宣传稿 / 讲解稿
    ├─ 汇报参谋
    │  └─ 汇报提纲 / 调研报告 / 情况汇报
    ├─ 组织执行
    │  └─ 通知 / 工作方案 / 指导意见
    └─ 评论解释
       └─ 短评 / 回应稿 / 编者按

### 8.1 身份—受众—语气

    写作者身份
       + 受文对象
       + 写作目的
       ↓
    决定称谓、权限、语气和内容重点

| 受众 | 语气 | 内容倾向 |
| --- | --- | --- |
| 上级领导 | 客观、精炼 | 情况、问题、原因、建议 |
| 下级单位 | 明确、可执行 | 任务、步骤、时间、责任 |
| 社会公众 | 通俗、真诚 | 意义、具体行动、号召 |
| 专业同行 | 准确、交流性 | 做法、成效、经验、反思 |

### 8.2 格式节点

    完整格式
    ├─ 标题
    ├─ 称谓
    ├─ 正文
    ├─ 发文机关/署名
    └─ 日期

**规则：** 是否需要完整格式以题干、文种和“提纲/要点”等要求为准；内容得分始终优先于机械拼格式。

> 文种格式和例题见 [公文写作专题](公文写作专题.md)。

## 九、大作文图谱

    命题
       ↓ 提取关键词与关系
    主题
       ↓ 结合材料主旨
    总论点
       ↓ 分解
    分论点 1 + 分论点 2 + 分论点 3
       ↓ 每段论证
    解释 + 论据 + 分析 + 回扣
       ↓
    结尾回应命题

### 9.1 立意关系

    题干关键词
       ∩ 材料反复出现的问题
       ∩ 命题人给出的价值方向
       =
    文章核心立意

### 9.2 分论点关系

    总论点
    ├─ 分论点之间并列：三个不同维度
    ├─ 分论点之间递进：认识 → 实践 → 保障
    └─ 分论点之间因果：意义 → 问题 → 路径

**要求：** 分论点同层级、互不重叠、共同穷尽总论点的主要内容。

### 9.3 论证关系

    分论点
       ↓ 为什么成立
    道理论证
       ↓ 有何事实支持
    案例或数据
       ↓ 案例证明了什么
    因果分析
       ↓
    回扣分论点

**常见断裂：** 案例与观点无关、只叙述不分析、分论点写对策而论据只讲意义、结尾突然引入新观点。

> 立意、结构和论证示例见 [大作文专题](大作文专题.md)。

## 十一、一材多题转换图

    同一段材料
    ├─ 问“问题” → 提取负面表现
    ├─ 问“原因” → 提取导致因素
    ├─ 问“经验” → 提取有效做法并上位概括
    ├─ 问“对策” → 做法借鉴 + 问题反推
    ├─ 问“理解” → 解释观点并串联问题、意义、做法
    ├─ 写应用文 → 按身份、受众和目的重组
    └─ 写作文 → 提炼价值关系，用案例作论据

这说明“材料要点”不是固定答案；题干任务决定提取、转换和组织方式。同套真题的任务转换见 [必备知识框架与例题](必备知识框架与例题.md#六同套真题的任务转换)。

## 十二、失分原因图谱

    失分
    ├─ 审题
    │  └─ 任务/对象/范围/身份/文种看错
    ├─ 找点
    │  └─ 漏掉观点、数据、案例中的暗点
    ├─ 加工
    │  └─ 合并过度、分类交叉、转换无依据
    ├─ 表达
    │  └─ 没有核心词、口语化、句子过长
    ├─ 结构
    │  └─ 要点顺序混乱、论证断裂
    └─ 书写
       └─ 超字、格式错、卷面难辨

## 十三、训练闭环图

    限时作答
       ↓
    对照参考要点
       ↓
    标注：找到且写清 / 找到未写清 / 完全遗漏
       ↓
    定位错因节点
       ↓
    重写答案
       ↓
    三天后遮住答案再做
