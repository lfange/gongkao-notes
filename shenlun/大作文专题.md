# 申论 · 大作文专题（议论文：立论 / 结构 / 论证 / 开头结尾）

> 大作文 40 分上下，是申论**单题分值之王**，但也是**套路最固定**的题型：
> **立意决定档次（一等/二等文），结构决定下限（不跑题就有基本分），卷面决定印象（同档次差 2—3 分）**。
> 专题结构：**本质 → 审题立意 → 结构模板 → 论证方法 → 开头结尾 → 易错点 → 范文提纲精讲 → 自测练习**（答案见文末附录）。
> 使用方法：看讲解 → 按自测题列提纲 → 对照 → 缺点记入 [错题本.md](../错题本.md)。

---

## 一、本质：一篇"命题方向 + 材料血肉"的议论文

- 大作文**不是自由写作**：总论点必须从**题干关键词 + 材料主旨**中来，脱离材料就是跑题（四类文，20 分以下）；
- 也不是照抄材料：**材料给方向，自己搭论证**——大段抄材料按抄袭降档；
- 阅卷现实：每篇 1—2 分钟扫完，**标题、开头、每段首句、结尾**是必扫点——这几处必须最精彩。

## 二、审题立意（决定档次的 5 分钟）

### 2.1 三步定总论点

1. **抓题干关键词**：抓"引言 / 观点句"里的核心词（如"改革要坚持'钉钉子'精神"→ 核心词：钉钉子精神=坚持、专注、接续发力）；
2. **回到材料验证**：通读全部材料（重点看首则、末则、政策表述段），看命题人围绕核心词**主张什么**——是讲意义、讲做法，还是讲辩证关系；
3. **合成总论点**：把核心词与材料主旨合成一句**判断句**——"唯有 X，才能 Y"。

### 2.2 立意自检三条

- **是否紧扣核心词**（题干"基层治理"，全文不能只谈"治理"丢了"基层"）；
- **是否与材料倾向一致**（材料讲务实，你不能写"仰望星空更重要"）；
- **是否能拆出 2—3 个分论点**（拆不动的立意趁早换）。

### 2.3 总分论点关系两种主流搭法

| 搭法 | 结构 | 适用 |
| --- | --- | --- |
| **意义型**（是什么→为什么） | 分论点 = 总论点的三重价值："X 是……的基石 / 动力 / 保障" | 材料偏讲道理、谈意义 |
| **对策型**（怎么做） | 分论点 = 实现总论点的三条路径："要 A / 要 B / 要 C" | 材料偏讲做法、给案例 |

## 三、结构模板（1000—1200 字）

```
标题（观点式 / 对仗式，含核心词）
开头 150 字：引入 + 亮总论点
分论点段一 280 字：段首句（分论点）+ 例证 + 分析 + 回扣
分论点段二 280 字：同上
分论点段三 280 字：同上
结尾 130 字：总结重申 + 升华展望
```

**标题写法**：
- 观点式：《以钉钉子精神抓改革落实》；
- 对仗式：《落一项改革 钉一颗钉子》《既要有为 也要无形》（引言类题好用）；
- 禁忌：文艺空标题《论坚持》、无观点标题《谈谈基层治理》。

**分论点段内结构**（背下来）：

1. **段首句**：分论点（判断句，20 字内）；
2. **阐释 1 句**：把分论点说白（"也就是说……"）；
3. **例证 1—2 个**：材料内案例 + 自己积累（详略搭配，一个详例 + 一个排比略例最佳）；
4. **分析 1—2 句**：例后必分析——因果分析（"正是因为……才……"）或假设分析（"倘若没有……何来……"），**光堆例子不分析是二类文通病**；
5. **回扣 1 句**：回扣分论点收束。

## 四、论证方法（让分析不空洞）

| 方法 | 句式 | 示例 |
| --- | --- | --- |
| **因果分析** | 之所以……是因为……；正是……才…… | 正是塞罕坝人三代接续，才有了荒原变林海的人间奇迹 |
| **假设分析** | 倘若……又怎能……；如果……何以…… | 倘若改革浅尝辄止、朝令夕改，何以积跬步至千里 |
| **对比分析** | 反观……；与之相对…… | 反观一些地方"新官不理旧账"，蓝图屡换、一事无成 |
| **主体分析** | 于国家……于社会……于个人…… | 于政府是公信，于企业是机遇，于百姓是实惠 |
| **条件分析** | 唯有……方能…… | 唯有把功夫下在平时，方能在关键时刻顶得上 |

## 五、开头结尾模板（各背 2 套）

### 开头

1. **概括引入式**：概括材料背景（1 句）→ 指出问题 / 趋势（1 句）→ 亮总论点（1 句）；
   > 从"半年完成"到"三年蹚出新路"，基层改革的实践反复证明：改革越到深处，越要靠落实。唯有发扬钉钉子精神，一锤接着一锤敲，才能把发展蓝图变成现实图景。
2. **引言式**：引政策 / 名言（1 句）→ 简释（1 句）→ 亮总论点；
   > "钉钉子往往不是一锤子就能钉好的，而是要一锤一锤接着敲。"习近平总书记的比喻，道出了干事创业的深刻方法：抓落实，贵在坚持、成于坚持。

### 结尾

1. **总结升华式**：重申总分论点（1—2 句）→ 升华到时代 / 人民（1 句）；
   > 一锤接着一锤敲，一张蓝图绘到底。当千千万万实干者都以钉钉子的韧劲履职尽责，改革的果实必将挂满枝头，复兴的脚步必将坚实有力。
2. **呼应开头式**：回应开头案例 / 引言 + 展望——首尾呼应，结构分稳拿。

## 六、易错点清单

1. **跑题**（最致命）：总论点与题干核心词无关联——动笔前**把总论点写在草稿纸上**再开写。
2. **立意平庸**：抄材料主题句当论点、只改两个字——立意要**从材料主旨往前走半步**（概括题"零引申"，大作文"半步引申"）。
3. **分论点之间不是并列关系**：三条一会儿讲意义一会儿讲对策，逻辑打架——**先定意义型或对策型，三条同型**。
4. **只举例不分析**：三个故事 + 三句口号——例后必加"因果 / 假设"分析。
5. **大段抄材料**：单处引用超 50 字即高危——材料案例要**转述压缩**（30 字内讲完）。
6. **开头绕远**：从盘古开天写到改革开放——开头 3 句话内必须见核心词。
7. **卷面硬伤**：涂黑团、连笔、段落失衡（一段 300 字一段 80 字）——写错划**一根线**，段落匀称（各分论点段字数相近）。
8. **字数不足**：少于 1000 字直接降档——按结构模板字数分配写，天然达标。

## 七、精讲例题（提纲示范）

**题**："给定资料"结尾写道："城市治理的精细功夫，藏在群众的日常琐碎里。"结合你对这句话的思考，自拟题目，写一篇议论文。（40 分，1000—1200 字）

**审题立意**：

1. 核心词：**精细治理 × 群众日常**——治理的"精细"要从群众身边小事做起；
2. 材料主旨（假定材料讲了：老旧小区改造征求民意、口袋公园一园一策、"接诉即办"办好群众身边事、反面案例"大拆大建忽略小需求"）：命题人主张——城市治理要着眼群众身边小事、在精细处见真章；
3. 总论点：**城市治理要在群众日常的"小处"下"绣花功夫"，于细微处见初心、见实效。**

**参考提纲**（意义型三分）：

> **标题**：于细微处见真章——在群众日常里绣出治理之花
>
> **开头**（概括式）：从"口袋公园"到"接诉即办"，治理成效正体现在群众身边的点滴小事。城市的面子在高楼，里子在胡同。唯有把功夫下在群众日常的琐碎细微处，治理才有温度、有实效。
>
> **分一**：在细微处用力，是践行治理为民的初心所在。（分析 + 例：老旧小区改造问需于民，电梯纠纷从三个月到两周）
> **分二**：在细微处用心，是提升治理效能的关键一招。（分析 + 例：一园一策差异化供给 vs 大拆大建浪费；接诉即办以"小切口"撬动"大治理"）
> **分三**：在细微处久久为功，是考验治理韧性的时代标尺。（分析 + 例：绣花功夫非一日之功，反面：重建设轻管护致"回潮"）
>
> **结尾**（总结升华式）：城市的美好，不在惊天动地的宏大叙事，而在千家万户的柴米油盐。以针脚般的细心、水滴般的恒心穿引治理之线，方能绣出百姓安居乐业的幸福图景。

**自评**：总分论点紧扣"细微 / 日常 / 精细"；三条分论点同型并列（初心—效能—韧性，递进式并列）；例子全部由材料转述 + 分析句黏合。

## 八、自测练习

1. 题干关键词是"数字技术赋能基层治理"，材料讲的多是反面案例（形式主义、重复填报）。总论点应该怎么立？
2. "意义型"和"对策型"分论点各写一个针对"人才振兴"的三分结构。
3. 拿任一套真题作文题（见 [../真题/](../真题/)），30 分钟内只写：标题 + 总论点 + 三个分论点段首句 + 开头结尾两段。写完对照本专题模板自查。

### 答案附录

1. 反面案例多 = 材料倾向是**警示**。总论点立对策方向：**数字技术赋能基层治理，重在务实高效，必须力戒形式主义、以群众需求为导向**（"既要……更要防止……"的辩证立意）。分论点可取：数据要整合共享（反对重复填报）、系统要贴合实务（反对为用而用）、考核要看实效（反对指尖留痕）。
2. 意义型：人才振兴是产业升级的引擎 / 是乡村发展的源泉 / 是区域竞争的根本。对策型：引才要精准对接需求 / 育才要用好本土资源 / 留才要优化服务生态（引—育—留，天然递进）。
3. 自查清单：① 标题含核心词且有观点；② 总论点写在开头末句；③ 三个分论点同型且各自是判断句；④ 每段首句后能接例证 + 分析句式；⑤ 开头 3 句内见核心词、结尾升华不空喊。

## 错题归因模板

写完（或批改后）按四类归因，记入 [错题本.md](../错题本.md)：

- **立意错**：偏题 / 跑题 → 重做审题三步，把题干核心词和总论点抄写对照；
- **结构错**：分论点不同型、段内缺分析 → 重列提纲 + 补分析句；
- **论证错**：例子堆砌、材料照抄 → 把一段例证改写成"例 + 因果分析 + 回扣"；
- **表达卷面错**：标题无观点、涂改 → 标题重拟三个择优，誊抄一遍练字。
