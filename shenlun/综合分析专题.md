# 申论 · 综合分析专题（词句理解 / 评价分析 / 比较分析 / 启示分析）

> 综合分析是概括题的**组合升级版**：不再是单一任务，而是**多种要点按逻辑结构组装**。
> 一句话本质：**亮观点 → 拆开分析 → 收尾**（总—分—总），"分"的部分仍然是找点抄点。
> 专题结构：**本质 → 四类题型 → 作答结构 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录）。
> 使用方法：看讲解 → 遮住参考答案自己写 → 对照 → 缺点记入 [错题本.md](../错题本.md)。

---

## 一、本质：观点 + 逻辑 + 要点

- 阅卷看三样：**观点是否准确**（解释对不对 / 评价公不公）、**结构是否完整**（总分总缺一扣一）、**要点是否全面**（分析角度漏不漏）；
- 综合分析的分通常 15—20 分，是拉开档次的题型——但它的"分"仍然是踩点，**披着作文外衣的概括题**。

## 二、四类题型与作答结构

### 2.1 词句理解（"谈谈对'……'的理解"）

| 结构 | 写什么 |
| --- | --- |
| **总** | 解释这句话的含义：拆词分别解释 + 合起来说（有上下文的联系上下文） |
| **分** | 围绕词句多角度找点：背景 / 原因 / 问题 / 影响 / 对策——材料有什么写什么 |
| **总** | 总结或提对策："因此，要……" |

> 关键：**拆词**。"指尖上的形式主义"= 拆成"指尖上"（依托手机、网络）+"形式主义"（重形式轻实效）→ 组合解释。

### 2.2 评价分析（"对……谈谈你的看法 / 怎么看"）

| 结构 | 写什么 |
| --- | --- |
| **总** | **亮明观点**：值得肯定 / 应当警惕 / 辩证看（既有合理性又有问题）——观点必须先给 |
| **分** | 摆依据：合理性在哪（意义 / 原因）、问题在哪（危害 / 缺陷）——按观点的方向组织 |
| **总** | 得出结论 / 提对策 |

> 关键：**观点来自材料倾向**——材料通篇讲成绩，就肯定为主；材料正反都有，就辩证。**不要用自己的好恶替代材料态度**。

### 2.3 比较分析（"比较 A 与 B 的异同"）

- 先**分别概括** A、B 各自的做法 / 特点（各自找点）；
- 再**归纳同与异**：同在哪一维度、异在哪一维度（主体 / 方式 / 目的 / 效果）；
- 结构：总（二者本质）→ 同（几条）→ 异（几条）→ 总（启示）。

### 2.4 启示分析（"……对我们有什么启示 / 借鉴"）

> **最容易失分的题型**，失分点在**主体转换**。

- 材料讲的是**别人的成功经验**，答案要转成**我们应该怎么做**：
  - 材料说"该市财政每年投入 5000 万" → 启示"**加大财政投入力度**"（不是抄 5000 万）；
  - 材料说"聘请高校团队规划" → 启示"**借助专业智力资源，科学规划**"；
- 经验直接转对策即可；**教训反着说**（材料"因监管缺位导致失败"→ 启示"强化监管"）；
- 结构：总起一句 + 分条（每条 = 动词开头的对策式表达）。

## 三、通用技巧

1. **首句必亮观点**：不要铺垫背景，第一句就回答问题本身；
2. **"分"的部分按材料顺序组织**：材料先讲原因后讲影响，你就先写原因后写影响——不颠倒、不遗漏；
3. **字数分配**：总 30—50 字，分 150—250 字（大头），总 30—50 字；
4. **对策收尾保底**：分析不完满时，结尾对策是"万能收口"。

## 四、易错点清单

1. **词句理解不拆词**：整句硬翻——拆成两半分别解释，分数立涨。
2. **评价分析不亮观点**：开头写一大段背景，阅卷找不到"看法"——**第一句必须表态**。
3. **观点与材料倾向相反**：材料通篇肯定，你大谈问题——先判断材料态度再下笔。
4. **启示题照抄经验细节**：数字、地名、当地特殊做法不能搬——**转成普适性对策动词**。
5. **只分析不收尾**：总—分—总少了最后的"总"，结构分必扣。
6. **辩证 = 各打五十大板**：辩证要有**主次**（总体值得肯定，但需注意……），不是五五开和稀泥。
7. **把比较题写成两段概括**：必须点明"同"与"异"的维度，不是 A 概括一遍 B 概括一遍就完。

## 五、精讲例题

### 例题 1（词句理解）

**题**：给定资料中提到"社区治理既要'有为的手'，也要'无形的手'"，谈谈你对这句话的理解。（20 分，250 字左右）

**材料**（节选）：

> L 社区党委牵头成立"红色物业"，党组织书记兼任物业总监，半年内投诉量降了六成——政府力量下沉，居民叫好。但社区书记也坦言："大事小情都找社区，我们十几个人快转不动了。"而在 M 社区，业委会自治管理，聘请职业经理人，物业费收缴率达 98%——市场机制和专业力量盘活了社区资源。南大学教授指出：社区治理不能政府包办，也不能一放了之，行政力量与市场、社会力量各展所长，才是长久之计。

**解题过程**：

1. 拆词："有为的手"= 政府 / 行政力量；"无形的手"= 市场（及社会）力量。
2. 组合释义：社区治理需要政府力量与市场社会力量协同发力。
3. 多角度找点：政府力量——L 社区红色物业成效好但包办不可持续（材料"十几个人快转不动了"）；市场力量——M 社区自治 + 职业经理人成效好；专家结论——不能包办、不能放任，各展所长。
4. 收尾对策：推动行政力量与市场社会力量协同共治。

**参考答案**：

> 这句话是说：社区治理既需要政府行政力量积极作为，也需要市场和社会力量参与，二者协同方能长效。
> "有为的手"指政府力量。L 社区党委牵头"红色物业"，力量下沉成效显著；但政府包办难以为继，社区负担过重。"无形的手"指市场和社会力量。M 社区通过业委会自治、聘请职业经理人，盘活了资源、提升了效能。
> 因此，社区治理不能政府包办，也不能一放了之，应推动行政机制与市场、社会机制各展所长、协同共治。

### 例题 2（启示分析）

**题**：根据给定资料，谈谈 G 市打造"口袋公园"的做法对推进城市微改造有何启示。（15 分，200 字左右）

**材料**（节选）：

> G 市利用桥下空间、街角空地建成 120 个口袋公园。选址前，规划部门逐点位发放问卷、开现场会听取周边居民意见；建设资金采取"财政出大头、企业认建认养"模式，多家本地企业冠名捐建；建成后由认养企业负责日常养护，并聘请周边居民担任"市民园长"参与监督；公园功能按"一园一策"设计，有的配健身器材，有的设儿童沙坑。

**解题过程**：

1. 逐条经验 → 转换为普适启示（注意去地名化）：

| 材料经验 | 启示（动词开头） |
| --- | --- |
| 逐点位问卷、现场会听意见 | 坚持问需于民，改造前充分征求居民意见 |
| 财政出大头、企业认建认养 | 创新多元投入机制，引导社会资本参与 |
| 认养企业养护 + 市民园长监督 | 建立共建共管长效机制，发动社会力量参与管护 |
| 一园一策、功能各异 | 因地制宜、差异化设计，避免"千园一面" |

**参考答案**：

> 一是坚持问需于民。改造前通过问卷、现场会等方式充分征求居民意见，让项目贴合需求。二是创新投入机制。构建"财政引导 + 社会资本参与"的多元投入模式，破解资金难题。三是建立长效管护机制。推行认建认养，发动企业、市民共同参与日常养护和监督。四是因地制宜、精准设计。坚持"一园一策"，按不同人群需求差异化配置功能，避免同质化。

## 六、自测练习

1. 词句理解题首句"总"应该写什么？如果这句话里有比喻（如"无形的手"），第一步做什么？
2. 评价分析题的观点从哪里来？亮观点应该放在第几句？
3. 材料说"某地因招聘门槛过高，基层岗位三年招不到人"——写启示题时这条应怎么转换？
4. 按例题 2 的材料，若改问"概括 G 市打造口袋公园的主要做法"，和"启示"答案的区别是什么？写一版做法版答案。

### 答案附录

1. 写**这句话的含义（解释）**。有比喻先**还原比喻**："无形的手"→ 市场机制 / 社会力量——还原后再组合释义。
2. 从**材料倾向**来（通篇成绩则肯定为主，正反兼备则辩证）；观点放**第一句**。
3. 教训反着说："合理设置招聘门槛，保障基层岗位人才供给"（或"降低不合理的准入条件，畅通基层引才渠道"）。
4. 做法版答案保留**主语和具体动作**（"该市规划部门逐点位发放问卷""采取'财政出大头、企业认建认养'模式"），启示版答案**去主体、动词化、普适化**（"问需于民""多元投入"）。核心区别：做法=他做了什么（可具体），启示=我们该怎么做（须普适）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **观点错**：解释偏差、评价与材料倾向相反、辩证没主次；
- **结构错**：没亮观点、没收尾、比较题没点同异维度；
- **转换错**：启示题照抄经验细节、数字地名没去掉、教训没反推；
- **要点漏**："分"的部分材料角度没找全 → 重标材料。
