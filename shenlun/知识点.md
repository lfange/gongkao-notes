# 申论 · 知识点精细化总纲

> 申论的知识点不是背固定答案，而是掌握“题干怎样限定任务、材料怎样提供信息、信息怎样加工成答案”。本文按“概念—分类—识别—关系—边界—例证—复盘”整理全部主干。  
> 关系总览见 [知识图谱](知识图谱.md)，题型导航见 [必备知识框架与例题](必备知识框架与例题.md)，题源与解析见 [配套真题](../真题/申论/知识点配套真题.md)。
> 各节按“操作—真题落地—易错复盘”补充。真题均标年份、卷别、题号；题干转述、材料摘要与仓库参考解析分开标注，完整练习须阅读题源。

## 一、总作答链

    题干
       ↓ 审清任务和边界
    带着问题阅读材料
       ↓ 提取相关信息
    问题 / 原因 / 影响 / 做法 / 观点 / 案例
       ↓ 加工
    合并 + 分类 + 转换 + 排序 + 规范表达
       ↓ 输出
    概括 / 对策 / 综合分析 / 应用文 / 大作文
       ↓ 检查
    任务、对象、范围、身份、文种、字数

### 1.1 三个层次

| 层次 | 核心问题 | 常见错误 |
| --- | --- | --- |
| 信息层 | 材料说了什么 | 漏点、找错对象、脱离材料 |
| 关系层 | 要点之间是什么关系 | 问题原因混写、分类交叉 |
| 表达层 | 如何按任务输出 | 核心词不前置、文种语气错、超字 |

**补充操作：** 操作时先查信息是否找对，再查行为之间能否合理归类，最后压缩表达。

**真题例题：** [2024国考地市级第1题·T01](../真题/申论/知识点配套真题.md#t01)。

**解析与复盘：** 已找到建椅子等事实却只写改善环境，属于表达与加工问题；没有读到传统习俗则属于信息遗漏。

## 二、审题：七个边界

### 2.1 任务

| 动词 | 要完成的核心动作 | 不能替代成 |
| --- | --- | --- |
| 概括、归纳 | 找全并压缩同类信息 | 任意分析或提建议 |
| 分析 | 解释含义、原因、影响或关系 | 只摘抄表面句 |
| 谈理解 | 释义并结合材料展开 | 只写一句同义替换 |
| 评价、谈看法 | 表明态度并说明依据 | 只有观点没有材料理由 |
| 提出对策 | 针对问题提出可执行措施 | 空泛口号 |
| 总结经验、启示 | 提炼有效做法的机制并迁移 | 照抄地名和个性细节 |
| 拟写、撰写 | 按文种功能组织材料 | 只套格式不完成沟通任务 |

**补充操作：** 任务先译为我要输出哪类信息；同是“谈谈”，后接怎样、为什么、理解会改变动作。

**真题例题：** [2024国考地市级第1题·T01](../真题/申论/知识点配套真题.md#t01)。

**解析与复盘：** 本题围绕已经采取的做法展开，不能因出现谈谈就套评价态度。

### 2.2 对象

**问题：** 题目让你概括谁、分析什么现象、解释哪句话、为哪个主体提建议？

**边界：** 同一段材料可能出现多个主体，甲的问题不能写成乙的问题；“做法”要保留行动主体。

**补充操作：** 写出“主体＋被问属性”，每一要点回查其所属对象。

**真题例题：** [2019国考地市级第1题·T02](../真题/申论/知识点配套真题.md#t02)。

**解析与复盘：** 讲述者不等于作答对象；个人感受可以反映变化，但不能替代家乡各维度变化。

### 2.3 范围

**类型：** 指定某则材料、某几则材料、全部给定资料。

**边界：** 范围外内容即使正确也可能无效；只给局部材料时不能强行套全文主题。

**补充操作：** 圈材料编号、起止时段、地点和限定群体；边读边标出越界信息。

**真题例题：** [2017国考地市级第2题·T09](../真题/申论/知识点配套真题.md#t09)。

**解析与复盘：** 第1、2题都用资料2，作文另有资料5引句。共同主题不意味着各题都可照搬全卷。

### 2.4 身份与权限

| 身份 | 合理动作 | 越权表现 |
| --- | --- | --- |
| 基层工作人员 | 调研、协调、宣传、反馈、落实 | 直接制定全国性法律政策 |
| 部门负责人 | 组织、部署、完善机制、监督 | 超越本部门职权包办其他主体事项 |
| 媒体评论者 | 分析评价、引导认知 | 直接下行政命令 |
| 群众代表 | 反映需求、提出建议 | 代替政府作正式决定 |

**补充操作：** 列可直接做、可协调、需建议上级三个权限层次，并与队员专长匹配。

**真题例题：** [2020国考副省级第3题·T08](../真题/申论/知识点配套真题.md#t08)。

**解析与复盘：** 帮扶队长宜组织专业支持、联系协调；不能直接决定当地全部人事和财政事项。

### 2.5 受众

受众决定语言、信息重点和说服方式：面向领导重情况与建议；面向公众重通俗解释和行动指引；面向下级重任务、步骤和责任。

**补充操作：** 受众写在草稿顶端，再选择称谓、关注利益和语气。

**真题例题：** [2017云南省考第3题·T13](../真题/申论/知识点配套真题.md#t13)。

**解析与复盘：** 倡议面向青年，要给能参与的行动及理由；不能把上级工作部署语言原样搬来。

### 2.6 文种

文种决定沟通功能，不只是标题、称谓和落款。通知重“告知并执行”，倡议重“说明意义并号召”，汇报重“情况—问题—建议”，短评重“观点—分析—结论”。

**补充操作：** 将文种转换为沟通目的，再核对本题要全文、部分正文还是提纲。

**真题例题：** [2020国考副省级第4题·T15](../真题/申论/知识点配套真题.md#t15)。

**解析与复盘：** 本题只写两部分；调研报告这个名称并不授权补写整篇报告。

### 2.7 字数与要求

- 字数决定要点展开度，不决定是否可以漏掉核心得分点；
- “全面”要求尽量覆盖不同信息类别；
- “准确”要求对象、关系和用词与材料一致；
- “有条理”要求分类或顺序清楚；
- “简明”要求删掉案例枝节、重复修饰和空话。

**补充操作：** 先将特殊要求单列，然后按要点数量决定每点展开度，给标点和必要格式留空间。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 400字与先问题后建议共同约束答案。压缩应先删枝节，保留所有核心问题和对应措施。

## 三、材料信息节点

### 3.1 七类信息

| 节点 | 回答的问题 | 识别信号 |
| --- | --- | --- |
| 现状 | 正在发生什么 | 当前、目前、呈现、数据显示 |
| 问题 | 哪里不好 | 缺乏、不足、困难、乱象、未能 |
| 原因 | 为什么发生 | 由于、源于、根源、制约、因为 |
| 影响 | 带来什么结果 | 导致、造成、有利于、提升、损害 |
| 对策 | 应如何解决 | 应当、需要、通过、建立、完善 |
| 观点 | 谁如何判断 | 认为、指出、强调、看来 |
| 案例 | 谁在何地做了什么 | 人物、地点、过程、数据、结果 |

**补充操作：** 给每段相关信息标W、Y、I、D、G等功能；一句可以有多种信息，但输出由任务筛选。

**真题例题：** [2024国考地市级第4题·T06](../真题/申论/知识点配套真题.md#t06)。

**解析与复盘：** 经营能力是原因类信息，运营不佳是问题；正面场馆案例提供可借鉴措施。

### 3.2 问题与原因

**问题**回答哪里未达到目标，**原因**回答什么使目标难以实现。定位时先写出题目所问的结果，再向前寻找解释因素。

**真题辨析：** 四川公共座椅题中，座椅损坏、脏污属于使用问题；多部门标准不一致、管护衔接困难属于需要分析的治理因素。不能由损坏擅自推出财政不足，材料没有说明的原因不要当成既定事实。

**补充操作：** 把句子拆成表现与解释；无明确因果时，先保留可确认的表现。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 写数量不足不能附会资金不足。复盘检查自己有没有把推测包装成材料事实。

### 3.3 原因与影响

因果位置随所问对象变化，要围绕对象截取链条。

    经营管理能力不足 → 文化空间运营乏力 → 文化服务难以持续发挥作用

这是从2024国考公共文化空间资料中整理的关系：问运营困境的原因，向前找能力等因素；问作用受到什么影响，向后找文化功能。材料只有相关现象而未明确因果时，不能把推测写成确定结论。

**补充操作：** 写出A导致B、B影响C，再围绕被问的B或C决定取哪段。

**真题例题：** [2024国考地市级第4题·T06](../真题/申论/知识点配套真题.md#t06)。

**解析与复盘：** 原因答案向前追，影响答案向后写；题干未问的链条不必全部塞入答案。

### 3.4 做法与成效

**做法**是采取的行动，**成效**是行动产生的变化。

2024国考乡村运营官材料中，共同建造大椅子是做法，村民逐渐认可团队是成效。问怎样当好运营官，应以行动为主；认可可以说明做法的作用，但不能代替行动。

**补充操作：** 用采取了什么、发生了什么变化两栏标注同一案例。

**真题例题：** [2024国考地市级第1题·T01](../真题/申论/知识点配套真题.md#t01)。

**解析与复盘：** 答案以行动为骨架，可简带目的成效；只有群众认可而没有具体做法，未完成原任务。

### 3.5 观点与事实

观点句常是命题人希望考生理解的上位判断；事实、数据和案例用于解释或证明观点。不能因为案例更具体就忽略观点，也不能只抄观点而漏掉支撑它的材料要点。

**补充操作：** 先提炼与会者见解，再将案例放到该见解下面，建立观点与依据的对应。

**真题例题：** [2016国考地市级第1题·T20](../真题/申论/知识点配套真题.md#t20)。

**解析与复盘：** 不能用苏东坡经历的长篇叙述代替政策见解，也不能把案例里的建议当作本题要求实施的措施。

## 四、找点方法

### 4.1 直接词定位

圈出因果词、转折词、对策词、评价词和总结词。转折后常出现问题或观点，段首段尾常出现概括句，但位置规律只是线索，不是绝对规则。

**补充操作：** 信号词用于定位，随后必须检查主语、所指对象及上下文。

**真题例题：** [2018国考地市级第2题·T03](../真题/申论/知识点配套真题.md#t03)。

**解析与复盘：** 转折前可能已经存在独立原因；不能只读转折后。逐段问这一信息是否解释压力。

### 4.2 同义改写识别

先判断多处描述是否在说同一属性，再决定合并。

四川公共座椅材料中，夏天烫、冬天冰可合成“材质未适应季节使用需求”；脏污、木条断裂、反馈渠道不清分别涉及保洁、质量维修、管护沟通，不能全压成“管理不好”。保留差异信息比追求字面工整更重要。

**补充操作：** 同一属性的不同表现可合并，不同环节的信息分别留关键词。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 合并前写出各细节对应的属性，避免以大词掩盖质量、管护与反馈的差异。

### 4.3 案例提炼

    案例细节
       ↓ 删除姓名、地点和过程枝节
    主体 + 做法 + 对象 + 效果
       ↓ 根据任务转换
    经验 / 问题 / 原因 / 论据

**补充操作：** 先提主体、动作、对象和作用，删过程枝节，再按经验环节组织。

**真题例题：** [2019国考地市级第2题·T14](../真题/申论/知识点配套真题.md#t14)。

**解析与复盘：** 案例不是无用信息，案例讲述顺序也不一定等于答案顺序。

### 4.4 数据提炼

数据不一定原样抄写，应先判断它证明什么：数量增加、比例失衡、差距扩大、效率提升还是群众需求强烈。只有题目要求或数据本身具有区分度时才保留关键数字。

**补充操作：** 每个数字旁写它说明的趋势，再判断原数是否不可替代。

**真题例题：** [2019国考地市级第1题·T02](../真题/申论/知识点配套真题.md#t02)。

**解析与复盘：** 变化题重方向和维度；概括数量变化可省枝节，涉及政策时限、关键比较值则应保留。

## 五、加工方法

### 5.1 合并

**合并对象：** 同义句、同一主体的同类动作、同一问题的不同表现。

**边界：** 不同主体、不同环节、不同得分关键词不要强行合并。

**补充操作：** 合并前检查对象和功能是否相同，合并后逐项核对信息是否仍在。

**真题例题：** [2017国考地市级第1题·T04](../真题/申论/知识点配套真题.md#t04)。

**解析与复盘：** 短答案能同时覆盖多项功能；少写条数本身并不等于漏点，丢掉属性才是。

### 5.2 分类

| 分类标准 | 适用材料 |
| --- | --- |
| 主体 | 政府、企业、社会组织、群众分别承担任务 |
| 环节 | 事前预防、事中执行、事后监督 |
| 层面 | 思想、制度、资源、技术、人才 |
| 领域 | 经济、社会、文化、生态 |
| 逻辑 | 问题、原因、影响、对策 |

**规则：** 优先采用材料已经形成的结构；同一层答案保持一套主要分类标准，避免第一条按主体、第二条按时间、第三条按领域导致交叉。

**补充操作：** 优先采用题干明确维度；每个维度只比较同一种属性。

**真题例题：** [2016河南省考第2题·T11](../真题/申论/知识点配套真题.md#t11)。

**解析与复盘：** 管理理念、价值取向和实施效果分栏，不把甲的效果拿去对比乙的理念。

### 5.3 转换

| 原材料 | 目标答案 | 转换方法 |
| --- | --- | --- |
| 问题 | 对策 | 反向解决 + 补主体、方式和保障 |
| 原因 | 对策 | 针对根源消除或缓解 |
| 成功案例 | 经验/启示 | 去掉个性细节，提炼可复制机制 |
| 失败案例 | 问题/教训 | 提炼失误和后果 |
| 口语描述 | 规范表达 | 提取上位词并保留具体表现 |
| 数据案例 | 作文论据 | 压缩事实 + 说明证明什么 |

**补充操作：** 确定转换前后的主体、时态与适用范围，再提炼可迁移机制。

**真题例题：** [2024国考地市级第3题·T16](../真题/申论/知识点配套真题.md#t16)。

**解析与复盘：** 县里已做变为全市拟做，语气和规模都变；原县预算或编制数不能自动成为市级指标。

### 5.4 排序

- 并列要点：按重要性、材料顺序或主体顺序；
- 流程要点：事前—事中—事后；
- 因果信息：问题—原因—影响—对策；
- 综合分析：释义/观点—分析—结论；
- 对策：制度—资源—执行—监督，或按问题出现顺序一一对应。

**补充操作：** 流程任务按先后，比较任务按维度，特殊要求优先于习惯模板。

**真题例题：** [2016国考地市级第2题·T21](../真题/申论/知识点配套真题.md#t21)。

**解析与复盘：** 原题同时要流程和要求，不能按重要性排序打乱办理链条。

### 5.5 规范表达

核心概括词 + 材料中的具体表现

在四川座椅题中，将使用者描述的冬冰夏烫加工为“材质选择不适用：季节变化影响舒适度”。规范词用于标明属性，具体表现用于保留材料依据；没有证据时，不增加偷工减料、采购腐败等判断。

**补充操作：** 核心词只概括可确认事实，后接能够显示该问题的具体表现。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 表达失分复盘先查证据强度，再查是否啰嗦；规范词不能替代材料细节。

## 六、概括归纳题

### 6.1 概念与分类

概括题要求提取指定类别的信息，并进行压缩、合并和分类。常见对象：问题、原因、影响、做法、特点、变化。

**补充操作：** 先将所问对象归到问题、原因、作用、做法、特点、变化等类别。

**真题例题：** [2017国考地市级第1题·T04](../真题/申论/知识点配套真题.md#t04)。

**解析与复盘：** 功能题按作用找点，不因题干使用阐述就展开长篇议论。

### 6.2 各问法边界

| 问法 | 应答节点 | 易错 |
| --- | --- | --- |
| 问题 | 负面表现、目标差距 | 把原因或危害当问题 |
| 原因 | 导致现象的因素 | 只重复问题 |
| 影响 | 已产生或可能产生的结果 | 把措施写进去 |
| 做法 | 已经采取的行动 | 改写成“应当”建议 |
| 特点 | 区别于其他对象的属性 | 只列事实无定性词 |
| 变化 | 同一维度的前后对比 | 前后比较维度不一致 |

**补充操作：** 变化必须同维度前后对照；特点要定性；做法要动作；原因要解释。

**真题例题：** [2019国考地市级第3题·T22](../真题/申论/知识点配套真题.md#t22)。

**解析与复盘：** 称呼改变是结果，原题要分析造成称呼改变的工作变化，不能只重复受欢迎。

### 6.3 作答步骤

    审题确定信息类别
       ↓
    逐段只找同类要点
       ↓
    同义合并、异点保留
       ↓
    核心词前置
       ↓
    分条书写并核对范围

**最小答案单元：** 序号 + 核心概括词 + 具体表现。

> 完整例题见 [概括题专题](概括题专题.md)。

**补充操作：** 先列全部候选点，分别标保留、合并、剔除，再压到原题字数。

**真题例题：** [2024国考地市级第1题·T01](../真题/申论/知识点配套真题.md#t01)。

**解析与复盘：** 先把材料写成答案再删字容易丢点；先有清单，压缩时才知道哪些关键词必须留下。

### 6.4 概括问题

问题以负面状态或目标缺口为核心，先写可确认表现，再概括属性。不能把改进建议当成已发生的问题。

**真题：** [T07四川公共座椅](../真题/申论/知识点配套真题.md#t07)。将破损、脏污与反馈对象不清分别保留后归类；本题还要求建议，不能完成问题部分便停笔。

### 6.5 概括原因

原因可以是资源约束、利益冲突、规则限制或执行因素；每条必须能够解释指定现象。

**真题：** [T03村支书压力](../真题/申论/知识点配套真题.md#t03)。围绕为什么处理困难找依据，不能只重复各村民希望分地。

### 6.6 概括影响与功能

功能回答能发挥什么作用，影响回答已经或可能带来什么变化。按任务选择积极或消极信息，不机械两面都写。

**真题：** [T04水系功能](../真题/申论/知识点配套真题.md#t04)。按照生态、安全、发展和公共生活等属性压缩，保留具体功能，避免只列上位分类。

### 6.7 概括做法与经验

做法保留实际行动；经验进一步提炼有效机制。两者都要有材料支撑，不能只有成果表述。

**真题：** [T01运营官](../真题/申论/知识点配套真题.md#t01)提炼已做的行动；[T14经验提纲](../真题/申论/知识点配套真题.md#t14)按可借鉴环节组织做法。

### 6.8 概括特点与亮点

特点要回答对象有何属性；亮点更强调值得说明的突出之处。核心词须有事实支撑，不能每条都写特色鲜明。

**真题：** [T05制博会备询](../真题/申论/知识点配套真题.md#t05)。区别首次设置、技术先进、可供体验等属性，把代表性事实放在定性词之后。

### 6.9 概括变化

同一对象、同一维度、前后状态是三个条件。未写明旧状态时，可以准确说明新状态，不补编过去。

**真题：** [T02家乡新变化](../真题/申论/知识点配套真题.md#t02)偏地区维度；[T22小吴变化](../真题/申论/知识点配套真题.md#t22)偏认识和工作方法，不能互换分类框架。

## 七、提出对策题

### 7.1 对策来源

1. 材料直接提出的建议；
2. 成功案例中的有效做法；
3. 失败案例的反面教训；
4. 问题反向转换；
5. 原因的针对性解决。

**补充操作：** 先查明示建议，再查正面做法，最后对缺失环节反推，记录每条来源。

**真题例题：** [2024国考地市级第4题·T06](../真题/申论/知识点配套真题.md#t06)。

**解析与复盘：** 既有问题也有成功案例的资料，不能忽略可借鉴办法而全靠自己想。

### 7.2 一条完整对策

    主体 + 对象 + 手段 + 内容 + 目标 + 必要保障

不是每条都要机械写满六项，但至少应做到“针对什么、做什么、怎样做”清楚。

**补充操作：** 最小可执行单元是动作＋作用对象＋必要方式；主体可以在段首统一交代。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 无需每条机械写六要素，但加强管护必须说明责任、巡检、维修等实施环节。

### 7.3 问题—原因—对策

| 四川公共座椅题中的问题 | 推导方向 | 可执行表达 |
| --- | --- | --- |
| 使用功能信息不明显 | 信息未有效触达使用者 | 设置醒目的功能说明和使用指引 |
| 破损脏污、反馈对象不清 | 明确管理和维护环节 | 公示管护主体及联系方式，巡查、清洁并及时维修 |
| 材质、靠背和位置影响使用 | 适配真实场景 | 调查不同人群需求，改进材质、结构和设置位置 |
| 多部门规范协调困难 | 协同明确标准 | 协调相关部门，衔接设置规范和管理职责 |

表内建议是依据真题材料的仓库推导，不是题本已有措施。不要把推导方向误写成材料已确认的事实。

**补充操作：** 制作问题与建议对应表，检查是否存在无对应问题的万能建议。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 本题作答先把问题集中，再集中写建议；草稿对应表不等于答卷一问一答。

### 7.4 边界

- 对策必须与材料问题对应，不能堆万能句；
- 对策不能超出题设身份权限；
- “提高认识、加强重视”若无具体方式，通常不可执行；
- 材料没有依据时，不宜擅自加入过度专业或成本巨大的措施。

> 完整推导与四川真题见 [提出对策专题](提出对策专题.md)。

**补充操作：** 检查职责、资源条件、适用对象和材料依据，措辞区分直接实施与协调推动。

**真题例题：** [2020国考副省级第3题·T08](../真题/申论/知识点配套真题.md#t08)。

**解析与复盘：** 具体不等于虚构：不凭空承诺金额、名额或完成日期。

## 八、综合分析题

### 8.1 词句理解

    解释关键词和字面义
       ↓
    结合上下文解释深层含义
       ↓
    用问题、原因、影响、做法展开
       ↓
    总结作者态度或实践方向

**边界：** 不能只做字典释义，也不能脱离材料进行哲理发挥。

**补充操作：** 拆关键词，找共同属性，以上下文解释，再用材料表现展开。

**真题例题：** [2017国考地市级第2题·T09](../真题/申论/知识点配套真题.md#t09)。

**解析与复盘：** 理解比喻不是罗列相似词；释义和事实必须互相支撑。

### 8.2 评价分析

    评价对象
       ↓
    明确态度：正确 / 错误 / 有合理性但有局限
       ↓
    材料依据：作用 + 问题 + 条件
       ↓
    结论或改进方向

**边界：** 辩证不等于各打五十大板；态度应由材料证据决定。

**补充操作：** 判断材料支持到何种程度，再写作用、限制和条件。

**真题例题：** [2015国考省部级第2题·T10](../真题/申论/知识点配套真题.md#t10)。

**解析与复盘：** 局部改善不能推出完全突破；辩证评价也不能自动各写一半。

### 8.3 比较分析

先建立统一维度，再比较A、B：主体、目标、对象、方式、资源、效果、适用条件。不同点要在同一维度上对照，不能一边写原因、另一边写结果。

**补充操作：** 先画维度×对象表，再逐行改写为同一句内的对照表达。

**真题例题：** [2016河南省考第2题·T11](../真题/申论/知识点配套真题.md#t11)。

**解析与复盘：** 只问不同不另写相同；没有要求优劣结论，也不强行判谁全面胜出。

### 8.4 启示分析

    案例为何成功
       ↓
    主体做了什么、解决了什么问题
       ↓ 去个性化
    可复制的一般机制
       ↓ 转换主体
    当前情境可采用的做法

**边界：** “参观学习、提高认识”通常不是案例成功的关键机制；要提炼制度、资源、技术、参与或监督方式。

> 四类题型见 [综合分析专题](综合分析专题.md)。

**补充操作：** 用具体做法解释成功机制，再转成所问主体可采用的原则和方法。

**真题例题：** [2020国考副省级第2题·T12](../真题/申论/知识点配套真题.md#t12)。

**解析与复盘：** 要迁移技术赋能的方法，不要求青年复制稻田、机器设备或全部产业。

## 九、应用文

### 9.1 先判沟通功能

| 功能 | 常见文种 | 内容骨架 |
| --- | --- | --- |
| 宣传动员 | 倡议书、宣传稿、讲话稿 | 背景意义—问题/做法—号召行动 |
| 汇报参谋 | 汇报提纲、调研报告 | 情况—问题原因—建议 |
| 组织执行 | 通知、工作方案、指导意见 | 目的—任务—步骤—责任要求 |
| 评论解释 | 短评、回应稿、编者按 | 观点—依据—分析—结论 |

**补充操作：** 写明谁向谁说明什么、希望改变什么认识或行为，再列内容。

**真题例题：** [2015国考地市级第4题·T17](../真题/申论/知识点配套真题.md#t17)。

**解析与复盘：** 时评为消除疑虑服务，应形成有依据的判断；只给青年列行动清单会偏离栏目功能。

### 9.2 格式

    标题
    称谓（需要时）
    正文
    发文主体/署名（需要时）
    日期（需要时）

**边界：** 是否写完整格式由题干、文种和“提纲、要点”等要求决定；不能为了格式挤掉核心内容。

**补充操作：** 逐项核对是否需要标题、称谓、署名和日期，服从明示要求。

**真题例题：** [2016国考地市级第1题·T20](../真题/申论/知识点配套真题.md#t20)。

**解析与复盘：** 本题不考虑格式；其他文种是否写落款要独立判断，不能套出统一四要素。

### 9.3 身份—受众—语气

- 对上级：客观、精炼，重情况、依据和建议；
- 对下级：明确、可执行，重任务、步骤、责任和时限；
- 对公众：通俗、真诚，解释利益关系和具体行动；
- 对同行：专业、准确，重经验、成效与适用条件。

> 文种示例见 [公文写作专题](公文写作专题.md)。

**补充操作：** 讲话以发言人视角组织经验，对同行既介绍具体动作，也说明可借鉴性。

**真题例题：** [2019国考地市级第2题·T14](../真题/申论/知识点配套真题.md#t14)。

**解析与复盘：** 提纲不是抒情散文，交流也不是行政下令。检查人称是否在第三人称与我们之间混乱切换。

## 十、大作文

### 10.1 立意

    题干关键词
       ∩ 材料反复出现的矛盾或价值
       ∩ 命题给出的方向
       = 总论点

**边界：** 立意不能只抓一句金句，也不能脱离全部材料自行选择熟悉话题。

**补充操作：** 题干关键词先确定主线，通读材料补足含义与关系，再形成可论证判断。

**真题例题：** [2017国考地市级第5题·T19](../真题/申论/知识点配套真题.md#t19)。

**解析与复盘：** 向水学习必须落到智慧与情操；只论城市水工程属于主题收窄。

### 10.2 分论点

| 关系 | 示例结构 | 要求 |
| --- | --- | --- |
| 并列 | 制度、技术、人才 | 同层级、不重叠 |
| 递进 | 认识—行动—保障 | 层层深入 |
| 因果 | 意义—问题—路径 | 逻辑完整 |

分论点应共同支撑总论点，不要求形式上恰好三个；数量取决于篇幅和论证需要。

**补充操作：** 检验每条分论点是否回答总论点的同一问题，是否重复或包含。

**真题例题：** [2018国考地市级第5题·T23](../真题/申论/知识点配套真题.md#t23)。

**解析与复盘：** 关系命题可以并列或递进，结构必须解释有与无如何关联，不能只各讲一段互不相干的话。

### 10.3 论证段

    分论点
       ↓ 解释为什么成立
    道理或机制
       ↓ 提供事实
    材料案例 / 公共知识 / 数据
       ↓ 说明案例证明什么
    因果分析
       ↓
    回扣分论点

**常见断裂：** 只讲故事不分析；案例与观点无关；分论点谈对策而论据只证明意义；段尾突然换话题。

**补充操作：** 给每个案例补一句它如何证明本段观点；案例只能支持其中一面时不夸大。

**真题例题：** [2017国考地市级第5题·T19](../真题/申论/知识点配套真题.md#t19)。

**解析与复盘：** 从自然现象跳到社会主张要交代迁移机制，不能只说水如此所以人必须如此。

### 10.4 开头与结尾

- 开头完成“引出主题—指出矛盾或意义—亮明总论点”；
- 结尾完成“回扣总论点—汇总方向—适度提升”，不新增未经论证的分论点；
- 名言和排比不是必需，准确、清楚优先。

> 完整结构和例题见 [大作文专题](大作文专题.md)。

**补充操作：** 开头交代命题关系并亮论点，结尾回应已论证内容；字数按本题限制安排。

**真题例题：** [2018国考地市级第5题·T23](../真题/申论/知识点配套真题.md#t23)。

**解析与复盘：** 本题是命题作文且约1000字；不能套另一卷1000—1200字，更不能另拟标题。

## 十一、规范表达

规范表达要保留原材料的主体、行为、程度和条件，不能把抽象程度当成准确程度。

| 真题事实转述 | 规范概括方向 | 依据 |
| --- | --- | --- |
| 和村民共同动手开展艺术建设 | 尊重村民主体、共同实践 | [T01](../真题/申论/知识点配套真题.md#t01) |
| 座椅坏了，不知道向谁反映 | 管护责任及反馈渠道不明确 | [T07](../真题/申论/知识点配套真题.md#t07) |
| 冬冰夏烫、坐靠不舒适 | 设计实用性与舒适性不足 | [T07](../真题/申论/知识点配套真题.md#t07) |
| 重大村务按规则决策、监督 | 规范程序、约束权力 | [T11](../真题/申论/知识点配套真题.md#t11) |
| 小吴和村民一起劳动并帮助解决困难 | 转变工作方式、密切联系群众 | [T22](../真题/申论/知识点配套真题.md#t22) |

**边界：** “反馈渠道不清”不等于完全没有主管部门；“逐渐认可”不等于所有人完全满意。保持证据强度。

**操作：** 先写事实短语，再写可覆盖它的概括词，最后检查是否夸大、偷换、删掉限定。素材运用见 [规范表达与素材库](规范表达与素材库.md)。

## 十二、一材多题转换

采用同套试卷的真实设问观察加工差异，不为材料另外编题：

| 2017国考地市级真实任务 | 材料范围 | 如何输出 |
| --- | --- | --- |
| 第1题概述水系功能 | 资料2 | 提取各类功能，压缩成并列要点，见[T04](../真题/申论/知识点配套真题.md#t04) |
| 第2题理解水系与指纹的比喻 | 同样是资料2 | 找共同属性，解释城市独特性，见[T09](../真题/申论/知识点配套真题.md#t09) |
| 第5题向水学习作文 | 资料5引句及给定资料 | 提炼智慧和情操的立意，联系实际论证，见[T19](../真题/申论/知识点配套真题.md#t19) |

前两题是真正的同一资料、不同设问；作文涉及不同资料范围，不能只拿资料2的功能清单充当全卷作文立意。

**复盘动作：** 对照前两题圈出各自需要的词，标出能够共享的事实和必须改变的组织方式。材料可复用，答案不能原样搬用。

所有作答练习回到原题，不另设模拟题：

**核对依据：** 每题卡片中的仓库参考要点用于定位遗漏；最终应逐条返回完整资料检查。分值是题目分值，不将参考答案条数换算成官方分数。

## 十四、复盘

### 14.1 三类漏点

| 类型 | 含义 | 修正 |
| --- | --- | --- |
| 找到且写清 | 已识别并规范表达 | 保持 |
| 找到但未写清 | 划到了却合并过度、表达含糊 | 重写“核心词+具体表现” |
| 完全遗漏 | 阅读时没有识别 | 补信号词和材料节点训练 |

**补充操作：** 遮住参考解析，按原资料逐段检查，再将要点分为三类并重写。

**真题例题：** [2024国考地市级第1题·T01](../真题/申论/知识点配套真题.md#t01)。

**解析与复盘：** 已划出却未写清时改表达；完全没找到时改阅读动作，两者不能都归结为不细心。

### 14.2 六类错因

- 审题错：任务、对象、范围、身份或文种看错；
- 找点错：观点、案例、数据中的隐性要点漏掉；
- 关系错：问题、原因、影响和对策混写；
- 加工错：合并过度、分类交叉、转换无依据；
- 表达错：无核心词、口语化、句子过长；
- 时间错：阅读、列提纲和誊写分配失衡。

> 套卷训练后使用 [复盘模板](../真题/套卷复盘模板.md)，三天后遮住答案重做一次。

**补充操作：** 把错因写成当时动作与下次动作，例如漏圈特殊顺序→审题先抄限定。

**真题例题：** [2024四川县乡卷第2题·T07](../真题/申论/知识点配套真题.md#t07)。

**解析与复盘：** 条理好却违反先问题后建议仍是审题错；不要只记录要点漏了几条。
