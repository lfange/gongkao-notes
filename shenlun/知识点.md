# 申论 · 知识点精细化总纲

> 申论的知识点不是背固定答案，而是掌握“题干怎样限定任务、材料怎样提供信息、信息怎样加工成答案”。本文按“概念—分类—识别—关系—边界—例证—复盘”整理全部主干。  
> 关系总览见 [知识图谱](知识图谱.md)，完整材料与例题见 [必备知识框架与例题](必备知识框架与例题.md)。

## 一、总作答链

    题干
       ↓ 审清任务和边界
    带着问题阅读材料
       ↓ 提取相关信息
    问题 / 原因 / 影响 / 做法 / 观点 / 案例
       ↓ 加工
    合并 + 分类 + 转换 + 排序 + 规范表达
       ↓ 输出
    概括 / 对策 / 综合分析 / 应用文 / 大作文
       ↓ 检查
    任务、对象、范围、身份、文种、字数

### 1.1 三个层次

| 层次 | 核心问题 | 常见错误 |
| --- | --- | --- |
| 信息层 | 材料说了什么 | 漏点、找错对象、脱离材料 |
| 关系层 | 要点之间是什么关系 | 问题原因混写、分类交叉 |
| 表达层 | 如何按任务输出 | 核心词不前置、文种语气错、超字 |

## 二、审题：七个边界

### 2.1 任务

| 动词 | 要完成的核心动作 | 不能替代成 |
| --- | --- | --- |
| 概括、归纳 | 找全并压缩同类信息 | 任意分析或提建议 |
| 分析 | 解释含义、原因、影响或关系 | 只摘抄表面句 |
| 谈理解 | 释义并结合材料展开 | 只写一句同义替换 |
| 评价、谈看法 | 表明态度并说明依据 | 只有观点没有材料理由 |
| 提出对策 | 针对问题提出可执行措施 | 空泛口号 |
| 总结经验、启示 | 提炼有效做法的机制并迁移 | 照抄地名和个性细节 |
| 拟写、撰写 | 按文种功能组织材料 | 只套格式不完成沟通任务 |

### 2.2 对象

**问题：** 题目让你概括谁、分析什么现象、解释哪句话、为哪个主体提建议？

**边界：** 同一段材料可能出现多个主体，甲的问题不能写成乙的问题；“做法”要保留行动主体。

### 2.3 范围

**类型：** 指定某则材料、某几则材料、全部给定资料。

**边界：** 范围外内容即使正确也可能无效；只给局部材料时不能强行套全文主题。

### 2.4 身份与权限

| 身份 | 合理动作 | 越权表现 |
| --- | --- | --- |
| 基层工作人员 | 调研、协调、宣传、反馈、落实 | 直接制定全国性法律政策 |
| 部门负责人 | 组织、部署、完善机制、监督 | 超越本部门职权包办其他主体事项 |
| 媒体评论者 | 分析评价、引导认知 | 直接下行政命令 |
| 群众代表 | 反映需求、提出建议 | 代替政府作正式决定 |

### 2.5 受众

受众决定语言、信息重点和说服方式：面向领导重情况与建议；面向公众重通俗解释和行动指引；面向下级重任务、步骤和责任。

### 2.6 文种

文种决定沟通功能，不只是标题、称谓和落款。通知重“告知并执行”，倡议重“说明意义并号召”，汇报重“情况—问题—建议”，短评重“观点—分析—结论”。

### 2.7 字数与要求

- 字数决定要点展开度，不决定是否可以漏掉核心得分点；
- “全面”要求尽量覆盖不同信息类别；
- “准确”要求对象、关系和用词与材料一致；
- “有条理”要求分类或顺序清楚；
- “简明”要求删掉案例枝节、重复修饰和空话。

## 三、材料信息节点

### 3.1 七类信息

| 节点 | 回答的问题 | 识别信号 |
| --- | --- | --- |
| 现状 | 正在发生什么 | 当前、目前、呈现、数据显示 |
| 问题 | 哪里不好 | 缺乏、不足、困难、乱象、未能 |
| 原因 | 为什么发生 | 由于、源于、根源、制约、因为 |
| 影响 | 带来什么结果 | 导致、造成、有利于、提升、损害 |
| 对策 | 应如何解决 | 应当、需要、通过、建立、完善 |
| 观点 | 谁如何判断 | 认为、指出、强调、看来 |
| 案例 | 谁在何地做了什么 | 人物、地点、过程、数据、结果 |

### 3.2 问题与原因

**问题：** 负面表现或目标差距，回答“哪里不好”。

**原因：** 导致问题的因素，回答“为什么不好”。

**边界例证：**

> “窗口排队时间长，因为部门数据不互通。”

- 问题：群众办事排队时间长；
- 原因：部门数据壁垒、协同不足。

不能把“排队时间长”同时机械抄进原因栏。

### 3.3 原因与影响

同一句话的位置取决于题目对象：

    数据不共享 → 重复提交材料 → 办事时间增加

- 相对“重复提交”，数据不共享是原因；
- 相对“办事时间增加”，重复提交既可视为中间问题，也可作为直接原因；
- 作答时要围绕题干对象截取因果链。

### 3.4 做法与成效

**做法：** 主体采取的行动。**成效：** 行动后产生的积极变化。

> “村里建立合作社统一销售，农产品价格提高、滞销减少。”

- 做法：成立合作社、统一销售；
- 成效：提高售价、缓解滞销。

问“经验”时通常以做法为主体，并可用成效说明有效性；只写结果不等于答了经验。

### 3.5 观点与事实

观点句常是命题人希望考生理解的上位判断；事实、数据和案例用于解释或证明观点。不能因为案例更具体就忽略观点，也不能只抄观点而漏掉支撑它的材料要点。

## 四、找点方法

### 4.1 直接词定位

圈出因果词、转折词、对策词、评价词和总结词。转折后常出现问题或观点，段首段尾常出现概括句，但位置规律只是线索，不是绝对规则。

### 4.2 同义改写识别

材料可能用不同说法重复一个点：

    “部门各自建设系统”
    “数据格式不统一”
    “群众反复填报”
       ↓ 可按题目加工为
    数据标准不统一、部门信息共享不足，造成重复填报

**边界：** 合并要保留不同得分关键词；不能为了句子短，把“标准不统一”和“共享不足”压成泛泛的“机制不完善”。

### 4.3 案例提炼

    案例细节
       ↓ 删除姓名、地点和过程枝节
    主体 + 做法 + 对象 + 效果
       ↓ 根据任务转换
    经验 / 问题 / 原因 / 论据

### 4.4 数据提炼

数据不一定原样抄写，应先判断它证明什么：数量增加、比例失衡、差距扩大、效率提升还是群众需求强烈。只有题目要求或数据本身具有区分度时才保留关键数字。

## 五、加工方法

### 5.1 合并

**合并对象：** 同义句、同一主体的同类动作、同一问题的不同表现。

**边界：** 不同主体、不同环节、不同得分关键词不要强行合并。

### 5.2 分类

| 分类标准 | 适用材料 |
| --- | --- |
| 主体 | 政府、企业、社会组织、群众分别承担任务 |
| 环节 | 事前预防、事中执行、事后监督 |
| 层面 | 思想、制度、资源、技术、人才 |
| 领域 | 经济、社会、文化、生态 |
| 逻辑 | 问题、原因、影响、对策 |

**规则：** 优先采用材料已经形成的结构；同一层答案保持一套主要分类标准，避免第一条按主体、第二条按时间、第三条按领域导致交叉。

### 5.3 转换

| 原材料 | 目标答案 | 转换方法 |
| --- | --- | --- |
| 问题 | 对策 | 反向解决 + 补主体、方式和保障 |
| 原因 | 对策 | 针对根源消除或缓解 |
| 成功案例 | 经验/启示 | 去掉个性细节，提炼可复制机制 |
| 失败案例 | 问题/教训 | 提炼失误和后果 |
| 口语描述 | 规范表达 | 提取上位词并保留具体表现 |
| 数据案例 | 作文论据 | 压缩事实 + 说明证明什么 |

### 5.4 排序

- 并列要点：按重要性、材料顺序或主体顺序；
- 流程要点：事前—事中—事后；
- 因果信息：问题—原因—影响—对策；
- 综合分析：释义/观点—分析—结论；
- 对策：制度—资源—执行—监督，或按问题出现顺序一一对应。

### 5.5 规范表达

    核心概括词 + 材料中的具体表现

例如“大家都不愿意管，出了事互相推”可写成“权责不清、协同不足：部门职责边界模糊，出现推诿扯皮”。只写“权责不清”可能过空，只抄口语又不够凝练。

## 六、概括归纳题

### 6.1 概念与分类

概括题要求提取指定类别的信息，并进行压缩、合并和分类。常见对象：问题、原因、影响、做法、特点、变化。

### 6.2 各问法边界

| 问法 | 应答节点 | 易错 |
| --- | --- | --- |
| 问题 | 负面表现、目标差距 | 把原因或危害当问题 |
| 原因 | 导致现象的因素 | 只重复问题 |
| 影响 | 已产生或可能产生的结果 | 把措施写进去 |
| 做法 | 已经采取的行动 | 改写成“应当”建议 |
| 特点 | 区别于其他对象的属性 | 只列事实无定性词 |
| 变化 | 同一维度的前后对比 | 前后比较维度不一致 |

### 6.3 作答步骤

    审题确定信息类别
       ↓
    逐段只找同类要点
       ↓
    同义合并、异点保留
       ↓
    核心词前置
       ↓
    分条书写并核对范围

**最小答案单元：** 序号 + 核心概括词 + 具体表现。

> 完整例题见 [概括题专题](概括题专题.md)。

## 七、提出对策题

### 7.1 对策来源

1. 材料直接提出的建议；
2. 成功案例中的有效做法；
3. 失败案例的反面教训；
4. 问题反向转换；
5. 原因的针对性解决。

### 7.2 一条完整对策

    主体 + 对象 + 手段 + 内容 + 目标 + 必要保障

不是每条都要机械写满六项，但至少应做到“针对什么、做什么、怎样做”清楚。

### 7.3 问题—原因—对策

| 问题/原因 | 空泛答案 | 可执行表达 |
| --- | --- | --- |
| 群众不了解政策 | 加强宣传 | 由社区通过入户讲解、线上平台和办事指南说明条件与流程 |
| 部门相互推诿 | 加强协作 | 明确职责清单，建立联席机制和转办反馈时限 |
| 项目重建轻管 | 加强管理 | 明确管护主体、经费来源和日常巡检责任 |
| 服务能力不足 | 加强培训 | 分岗培训业务流程，设置考核和现场指导 |

### 7.4 边界

- 对策必须与材料问题对应，不能堆万能句；
- 对策不能超出题设身份权限；
- “提高认识、加强重视”若无具体方式，通常不可执行；
- 材料没有依据时，不宜擅自加入过度专业或成本巨大的措施。

> 推导示例见 [必备知识框架与例题](必备知识框架与例题.md#52-提出对策)。

## 八、综合分析题

### 8.1 词句理解

    解释关键词和字面义
       ↓
    结合上下文解释深层含义
       ↓
    用问题、原因、影响、做法展开
       ↓
    总结作者态度或实践方向

**边界：** 不能只做字典释义，也不能脱离材料进行哲理发挥。

### 8.2 评价分析

    评价对象
       ↓
    明确态度：正确 / 错误 / 有合理性但有局限
       ↓
    材料依据：作用 + 问题 + 条件
       ↓
    结论或改进方向

**边界：** 辩证不等于各打五十大板；态度应由材料证据决定。

### 8.3 比较分析

先建立统一维度，再比较A、B：主体、目标、对象、方式、资源、效果、适用条件。不同点要在同一维度上对照，不能一边写原因、另一边写结果。

### 8.4 启示分析

    案例为何成功
       ↓
    主体做了什么、解决了什么问题
       ↓ 去个性化
    可复制的一般机制
       ↓ 转换主体
    当前情境可采用的做法

**边界：** “参观学习、提高认识”通常不是案例成功的关键机制；要提炼制度、资源、技术、参与或监督方式。

> 四类题型见 [综合分析专题](综合分析专题.md)。

## 九、应用文

### 9.1 先判沟通功能

| 功能 | 常见文种 | 内容骨架 |
| --- | --- | --- |
| 宣传动员 | 倡议书、宣传稿、讲话稿 | 背景意义—问题/做法—号召行动 |
| 汇报参谋 | 汇报提纲、调研报告 | 情况—问题原因—建议 |
| 组织执行 | 通知、工作方案、指导意见 | 目的—任务—步骤—责任要求 |
| 评论解释 | 短评、回应稿、编者按 | 观点—依据—分析—结论 |

### 9.2 格式

    标题
    称谓（需要时）
    正文
    发文主体/署名（需要时）
    日期（需要时）

**边界：** 是否写完整格式由题干、文种和“提纲、要点”等要求决定；不能为了格式挤掉核心内容。

### 9.3 身份—受众—语气

- 对上级：客观、精炼，重情况、依据和建议；
- 对下级：明确、可执行，重任务、步骤、责任和时限；
- 对公众：通俗、真诚，解释利益关系和具体行动；
- 对同行：专业、准确，重经验、成效与适用条件。

> 文种示例见 [公文写作专题](公文写作专题.md)。

## 十、大作文

### 10.1 立意

    题干关键词
       ∩ 材料反复出现的矛盾或价值
       ∩ 命题给出的方向
       = 总论点

**边界：** 立意不能只抓一句金句，也不能脱离全部材料自行选择熟悉话题。

### 10.2 分论点

| 关系 | 示例结构 | 要求 |
| --- | --- | --- |
| 并列 | 制度、技术、人才 | 同层级、不重叠 |
| 递进 | 认识—行动—保障 | 层层深入 |
| 因果 | 意义—问题—路径 | 逻辑完整 |

分论点应共同支撑总论点，不要求形式上恰好三个；数量取决于篇幅和论证需要。

### 10.3 论证段

    分论点
       ↓ 解释为什么成立
    道理或机制
       ↓ 提供事实
    材料案例 / 公共知识 / 数据
       ↓ 说明案例证明什么
    因果分析
       ↓
    回扣分论点

**常见断裂：** 只讲故事不分析；案例与观点无关；分论点谈对策而论据只证明意义；段尾突然换话题。

### 10.4 开头与结尾

- 开头完成“引出主题—指出矛盾或意义—亮明总论点”；
- 结尾完成“回扣总论点—汇总方向—适度提升”，不新增未经论证的分论点；
- 名言和排比不是必需，准确、清楚优先。

> 完整结构和例题见 [大作文专题](大作文专题.md)。

## 十一、规范表达

| 口语材料 | 规范概括 | 对策方向 |
| --- | --- | --- |
| 谁都说不归自己管 | 权责不清、协同不足 | 明确职责、建立协调机制 |
| 文件很多但没人落实 | 执行不力 | 细化标准、压实责任、监督问效 |
| 建好以后没人维护 | 重建轻管 | 明确管护主体和经费 |
| 各系统不能互通 | 信息壁垒 | 统一标准、共享数据、整合流程 |
| 各地照搬同一种项目 | 同质化、因地制宜不足 | 调研需求、突出特色 |
| 只看数量和排名 | 评价机制单一 | 增加质量、效果和满意度指标 |

**边界：** 规范表达不是把所有材料都换成抽象大词；核心词后仍需保留能够得分的具体表现。

> 更多词组见 [规范表达与素材库](规范表达与素材库.md)。

## 十二、一材多题转换

同一段“平台不互通、群众重复提交、某地统一标准后办理时间缩短”的材料：

| 任务 | 提取结果 |
| --- | --- |
| 概括问题 | 数据标准不一、信息共享不足，群众重复提交材料 |
| 分析原因 | 部门分散建设、缺少统一标准和协同机制 |
| 提出对策 | 统一数据标准，建设共享平台，明确部门协同责任 |
| 总结经验 | 以标准统一为基础打通数据，通过跨部门协同再造流程 |
| 写短评 | 说明数字化不能止于“系统上线”，关键是数据和流程真正协同 |
| 写作文 | 作为“技术赋能必须配套制度协同”的事实论据 |

这说明材料不是固定答案，题干决定从同一事实中提取什么、加工到何种程度。

## 十三、自测

1. “窗口排队长，因为部门数据不共享”中，问题和原因分别是什么？
2. 问“已采取的做法”时，能否把答案全部改写为“应当……”？
3. 为什么“加强宣传”通常不是完整对策？
4. 启示题为什么不能只抄案例中的地名、项目名？
5. 比较分析题为什么要先建立统一维度？
6. 应用文是否一律需要完整标题、称谓、署名和日期？
7. 作文案例之后为什么必须分析？
8. “核心概括词”后为什么还要保留具体表现？

### 答案要点

1. 问题是排队时间长；原因是数据不共享、部门协同不足。
2. 不能；问做法应保留已经发生的事实语气。
3. 缺少主体、对象、渠道、内容和执行方式。
4. 启示要求提炼可迁移机制，个性名称本身不能直接复制。
5. 只有同一维度才能形成有效对照，避免A写原因、B写结果。
6. 不一律，以题干、文种和“提纲/要点”等要求为准。
7. 案例本身不能自动证明分论点，分析要说明事实与观点的因果或机制联系。
8. 只写抽象词可能过空，具体表现用于说明材料依据和得分内容。

## 十四、复盘

### 14.1 三类漏点

| 类型 | 含义 | 修正 |
| --- | --- | --- |
| 找到且写清 | 已识别并规范表达 | 保持 |
| 找到但未写清 | 划到了却合并过度、表达含糊 | 重写“核心词+具体表现” |
| 完全遗漏 | 阅读时没有识别 | 补信号词和材料节点训练 |

### 14.2 六类错因

- 审题错：任务、对象、范围、身份或文种看错；
- 找点错：观点、案例、数据中的隐性要点漏掉；
- 关系错：问题、原因、影响和对策混写；
- 加工错：合并过度、分类交叉、转换无依据；
- 表达错：无核心词、口语化、句子过长；
- 时间错：阅读、列提纲和誊写分配失衡。
