# 申论 · 概括题专题（单一题：问题 / 原因 / 影响 / 对策）

> 概括题是申论的**地基**：分值 10—20 分，人人会写但**差距在要点数量**——按点给分，漏一条少一条的分。
> 核心就一句话：**题干问什么，材料找什么，找到什么抄什么（加工后）**。
> 专题结构：**本质 → 审题 → 找要点 → 加工 → 书写 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录）。
> 使用方法：看讲解 → 遮住参考答案自己写例题 → 对照采分点 → 缺点记入 [错题本.md](../错题本.md)。

---

## 一、本质：按点给分的"找点抄点"题

- 阅卷规则：**踩点给分**——答案与标准要点的关键词重合即得分，语言不必一致；
- 因此概括题的胜负手是**找全**（不漏点）+ **写准**（关键词写出来），不是文笔；
- 反推复习方向：练"标注材料"的手上功夫，而不是背范文。

## 二、审题：先看任务再读材料（30 秒）

审题五要素：

| 要素 | 看什么 | 审错的后果 |
| --- | --- | --- |
| **任务** | 概括"问题 / 原因 / 影响 / 对策"中的哪一种 | 问原因答对策，0 分起步 |
| **范围** | "根据材料 X"还是"结合给定资料" | 越界找点白费功夫 |
| **字数** | 150—300 字不等 | 超格即扣分 |
| **身份 / 对象** | 概括"该市""该企业""网友"的…… | 主体错位，找错段落 |
| **特殊要求** | "全面、准确、有条理""分类合理" | "分类合理"暗示要合并同类 |

> 高频任务词陷阱："概括**变化**"（答前后对比）、"概括**特点**"（答"小而精"式的定性词）、"概括**争议**"（正反两方观点都要）——遇到不认识的动词，先想它要的是哪类信息。

## 三、找要点：信号词定位法（核心功夫）

带着任务读材料，逐段划出**与任务对应的信号词**：

| 任务 | 信号词 |
| --- | --- |
| **问题** | 不足、缺乏、困难、薄弱、滞后、矛盾、突出、堪忧、尚未、依然存在、"但是""然而"之后 |
| **原因** | 由于、因为、源于、究其原因、根源在于、……使然、"这得益于"（正面原因） |
| **影响（危害）** | 导致、致使、制约、损害、阻碍、引发、加剧 |
| **影响（意义）** | 有利于、促进、推动、提升、增强了、为……奠定基础 |
| **对策** | 要、应该、需要、必须、建议、通过、加强、完善、健全、推动 + 领导讲话 / 政策文件 / 专家建议 |

三个补充找点口诀：

1. **观点即要点**：专家、领导、网友说的话常直接给要点（对策 / 原因）；
2. **案例藏要点**：案例本身不是要点，但**案例背后的做法 / 教训**是（"某地通过 X 解决了 Y"→ 对策 X、问题 Y）；
3. **转折后是重点**："但是 / 然而 / 与此同时"之后出要点的概率远高于之前。

## 四、加工：三步把散点变成答案

1. **合并同类项**——三个维度任选（选最自然的）：
   - 同**主体**合并：政府 / 企业 / 社会组织 / 群众；
   - 同**范围**合并：政治 / 经济 / 文化 / 社会 / 生态（五位一体）；
   - 同**义**合并：说得是同一件事的并成一条。
2. **提炼核心词前置**：每条写成"**核心词 + 具体展开**"，如"**监管缺位**。多头管理、职责不清，缺乏常态化检查";
   核心词尽量从材料原词提炼（材料说"重建设轻管护"，核心词就是"重建设轻管护"）。
3. **理顺条理**：并列关系直接罗列；发现问题→原因→对策有明显逻辑链的按链排。

## 五、书写：格式规范

- 分条标号：一、二、三（或 1. 2. 3.），条与条之间要点号清晰；
- 字数分配经验：**每条 30—40 字**，200 字答 5 条左右，300 字答 7—8 条；
- 用**短语和短句**，不用长段落——阅卷 10 秒一题，让每个关键词都看得见；
- 标点占格，不顶格写（申论格子纸标点单独占一格）。

## 六、易错点清单

1. **任务看错**：问"原因"答成"问题"（问题=现在怎么了，原因=为什么会这样——两回事）。
2. **要点照抄整句**：把材料一段 80 字原样抄上——占字数、关键词被淹没，**必须压缩成"核心词+展开"**。
3. **大段抄案例**：案例的细节（人名、数字经过）不是要点，**做法与教训**才是。
4. **合并过度**：把三个不同的点并成一条，阅卷只算一个点的分。
5. **"全面"理解错**：不是字写满，是**点找全**——宁可每条短一点，也要多覆盖一条。
6. **主观发挥**：材料没有的自己编——概括题**只从材料来**（对策题允许少量引申，概括题不允许）。
7. **丢"暗点"**：数据对比、案例反差里藏着的问题（"仅 5% 的受访者表示满意"→ 满意度低）。

## 七、精讲例题

### 例题 1（概括问题）

**题**：根据给定资料，概括 S 市老旧小区改造中存在的主要问题。（15 分，200 字以内）

**材料**：

> S 市老旧小区改造推进两年，成效初显，但居民抱怨不少。部分小区改造方案由设计院"闭门"绘制，未征求居民意见，建成后健身器材无人使用；资金主要依赖财政拨款，社会资本参与积极性低，三个小区因资金断档中途停工；改造后的小区缺乏物业接管，环境半年内"回潮"；各区改造标准不一，材料、工艺五花八门；施工周期长、噪音扰民，12345 热线相关投诉同比上升四成。

**解题过程**：

1. 审题：任务=问题；范围=本段；字数 200→5 条左右。
2. 找要点（逐句标注）：

| 材料句 | 提炼 |
| --- | --- |
| 方案"闭门"绘制，未征求居民意见 | ① 改造方案脱离居民需求 |
| 资金依赖财政，社会资本参与积极性低 | ② 资金渠道单一 |
| 因资金断档中途停工 | （并入②后果，不单列） |
| 缺乏物业接管，环境"回潮" | ③ 后期管护缺位 |
| 各区标准不一 | ④ 改造标准不统一 |
| 施工周期长、噪音扰民、投诉上升 | ⑤ 施工扰民、群众不满 |

**参考答案**：

> 一是方案脱离需求。改造方案未经征求居民意见，"闭门"设计，建成后设施闲置。二是资金渠道单一。过度依赖财政拨款，社会资本参与积极性低，部分小区因资金断档停工。三是后期管护缺位。改造后缺乏物业接管，环境短期"回潮"。四是改造标准不统一。各区材料、工艺五花八门。五是施工扰民。施工周期长、噪音扰民，相关投诉大幅上升。

**自评**：5 条 × 核心词前置，约 130 字——每条都能被阅卷 3 秒扫到关键词。

### 例题 2（概括原因）

**题**：根据给定资料，分析 T 县乡村旅游"叫好不叫座"的原因。（10 分，150 字以内）

**材料**：

> T 县山水秀美，游客却留不下来。县里的旅游项目以观景、采摘为主，与周边县市高度雷同；民宿多由村民自营，旺季价格翻倍、卫生条件参差；县城到各景点仅有班车，末班车下午四点收班；宣传仍靠旅行社口口相传，年轻游客在小红书搜索"T 县攻略"几乎无迹可寻。

**解题过程**：

1. 任务=原因（为什么留不下游客）——每个"毛病"都是一条原因。
2. 找点：项目雷同→①产品同质化；民宿乱象→②服务品质差；交通不便→③配套交通滞后；宣传缺位→④营销方式落后。

**参考答案**：

> 一是产品同质化。旅游项目以观光、采摘为主，与周边地区高度雷同，缺乏特色。二是服务品质差。民宿村民自营、缺乏规范，旺季乱涨价、卫生参差不齐。三是交通配套滞后。县城至景点仅班车通达，末班过早，游客出行不便。四是营销方式落后。缺乏新媒体宣传，在网络平台无存在感，难以触达年轻客群。

## 八、自测练习

1. 概括"问题"和概括"原因"的答案可以一样吗？为什么？
2. 材料写"某社区开展'居民议事会'，加装电梯的纠纷从平均三个月缩短到两周解决"——这句话里能提炼出什么要点（分别从问题、对策两个任务角度）？
3. 用例题 1 的材料，改问"概括 S 市老旧小区改造的对策建议"（假设你是市住建局工作人员），写出你的答案，再对照附录。

### 答案附录

1. **不能一样**。问题是"现状哪里不好"（改造方案脱离需求），原因是"为什么不好"（决策机制不民主、缺乏居民参与）。有时同一句话能同时出两点（"因资金断档停工"：问题=工程停工，原因=资金渠道单一），但任务不同，**答案的组织方向不同**——问什么答什么。
2. 对策角度：**发挥居民协商机制作用**（开展居民议事会，民主协商解决纠纷）；问题角度：**缺乏协商机制时矛盾化解慢**（对照"三个月"的旧况）。注意数字对比"三个月→两周"是效果，不是要点本身。
3. 参考答案（对策方向）：
> 一是健全居民参与机制。改造方案征求居民意见，推行"居民议事会"协商共治。二是拓宽资金渠道。引导社会资本参与，建立多元投入机制，防止工程断档。三是落实后期管护。引入专业物业，建立长效管护机制。四是统一改造标准。出台市级技术规范，明确材料工艺要求。五是规范施工管理。压缩工期、控制噪音，及时回应群众诉求。
> （对照：对策题允许在材料问题基础上**反推**——"资金渠道单一"→"拓宽资金渠道"，但动词要规范、不能凭空加材料没依据的措施。）

## 错题归因模板

做错（丢分）时按四类归因，记入 [错题本.md](../错题本.md)：

- **审题错**：任务、范围、身份看错 → 重抄审题五要素；
- **找点漏**：信号词没划到、案例暗点没挖出 → 把材料重新逐句标注一遍，标出"我当时漏了哪句"；
- **加工错**：该合并没合并 / 合并过度、核心词没前置 → 重写一遍答案；
- **书写错**：超字数、照抄整句、关键词被淹没 → 练压缩：80 字压成 30 字。
