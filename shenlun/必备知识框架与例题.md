# 申论必备知识框架与例题

> 本篇解决两个问题：一是把各题型放进同一套作答逻辑；二是用一组自编材料演示“同一个要点如何随任务变形”。
> 文中材料、题目和参考答案均为教学用自编内容，不是真题或唯一标准答案。
> 考前需要集中背诵材料信号词、规范概括词和问题—对策对应时，查看 [必背公式与规则总册](../必公.md#65-申论必须形成条件反射的材料信号)。

---

## 一、申论不是背模板，而是完成一次信息加工

申论的通用作答链是：

> **审题定任务 → 带着任务读材料 → 提取相关要点 → 合并分类与转换 → 按文种组织 → 按字数成文 → 核对**

各题型的差别，主要不在“有没有固定句式”，而在以下三处：

1. **提取什么：** 问题、原因、影响、做法、观点还是案例。
2. **加工到什么程度：** 只要归纳，还是需要推导对策、转换主体、表明观点。
3. **以什么形式输出：** 分条要点、总分总短文、应用文还是议论文。

## 二、审题：七个要素决定答案边界

| 要素 | 要问的问题 | 常见失分 |
| --- | --- | --- |
| 作答任务 | 概括、分析、提对策、写应用文还是议论文？ | 问原因却只抄问题 |
| 对象 | 分析谁、什么事、哪句话？ | 将另一主体的做法当答案 |
| 材料范围 | 指定某则还是全部给定资料？ | 越界找点或漏读 |
| 身份 | 以谁的名义作答？ | 越权提对策，称谓和语气错位 |
| 受文对象 | 写给领导、同事、企业还是市民？ | 宣传稿写成内部报告 |
| 文种与格式 | 是提纲、信、通知、讲话稿、短评还是报告？ | 格式不符，或为拼格式压缩内容 |
| 字数与要求 | “全面”“准确”“有条理”“观点明确”分别要求什么？ | 要点数与展开度失衡，超字或留白过多 |

### 题干动词的“翻译”

| 题干动词 | 实际任务 |
| --- | --- |
| 概括/归纳 | 找全已在材料中出现的同类要点 |
| 分析 | 不仅列现象，还要揭示含义、因果、利弊或逻辑关系 |
| 谈理解 | 解释表层含义和深层指向，再用材料证明并得出结论 |
| 谈看法/评价 | 先表明态度，再分析依据，最后得出对策或结论 |
| 提出对策 | 针对问题和原因，将材料做法、教训、建议转成可执行举措 |
| 总结经验/启示 | 先概括案例成功逻辑，再转换为当前主体可学习的做法 |

## 三、阅读材料：不是摘抄，而是给信息定功能

### 3.1 六类常见要点

读每一段时，在段旁用简写标注其功能：

- **现状（X）：** 对象当前呈现什么特征或变化。
- **问题（W）：** 不合理、未达到目标或引发不良结果的表现。
- **原因（Y）：** 造成问题或成效的主客观因素。
- **影响（I）：** 带来的积极意义或消极后果。
- **对策/做法（D）：** 明确建议、已采取措施、经验或反面教训。
- **观点/解释（G）：** 领导、专家、群众和政策文件对事情的判断。

这些标注不是为了把所有内容都抄入答案，而是为了快速回到与当前任务相关的段落。

### 3.2 三种暗要点

1. **数据暗示特征：** 满意度由 40% 升至 80%，可概括为“群众认可度显著提升”，不必穷举数字。
2. **案例暗含做法：** 某地将三个部门的窗口合并并共享数据，可提炼为“整合部门职能，推进数据共享”。
3. **反面教训可转对策：** “没有统一标准导致各自为政”可转为“制定统一标准，强化部门协同”。

### 3.3 材料原词与规范概括

答案既不能大段照抄，也不能脱离材料自行发明。稳妥的表达单元是：

> **概括词前置 + 材料中的具体信息**

例如：

- 材料：“路灯坏了连续三周无人维修，群众在多个部门之间反复打电话。”
- 答案：“**管护机制不健全。** 设施维修滞后，部门职责不清，群众反复联系仍难解决。”

## 四、加工要点：合并、分类、转换、排序

### 4.1 合并

同义、同主体或同环节的细节可合并，但要保留可能的得分关键词。

> “不会用平台”“不懂直播”“不熟悉品牌包装”  
> 可合并为：“**经营能力不足。** 缺少数字平台运营、直播营销和品牌包装能力。”

### 4.2 分类

优先选择材料自带的分类；材料没有明显结构时，可选用一种稳定标准：

- 按主体：政府、企业、社会组织、群众；
- 按环节：规划、建设、运营、监管、评估；
- 按层面：思想认识、制度机制、资源要素、技术能力；
- 按逻辑：现状、问题、原因、影响、对策。

不要为了形式整齐硬凑“五个方面”；分类必须服务于找全和读清。

### 4.3 转换

| 原材料 | 作答任务 | 转换方向 |
| --- | --- | --- |
| 问题 | 提对策 | 反向转换，再补充主体、手段、对象和目标 |
| 他地经验 | 谈启示 | 去掉地名和个性细节，转为本地可执行做法 |
| 专家观点 | 综合分析 | 提炼为态度、原因、影响或方向 |
| 事例和数据 | 大作文 | 事例压缩为论据，补充其证明的道理 |

### 4.4 排序

- 对策题：可按“完善认识—健全机制—补齐资源—强化执行—监督评估”排列；
- 流程型材料：按事前、事中、事后排列；
- 综合分析：一般按“表明观点/解释含义—展开分析—得出结论/提出对策”排列；
- 应用文：按文种功能和受众需求排列，不能机械套“背景—问题—对策”。

## 五、五类核心作答任务的框架

### 5.1 概括归纳

**目标：** 找全、归准、写清。

**基本形式：** 序号 + 概括词 + 具体展开。

**不要做：** 自行分析原因、增加材料没有的对策、把事例过程原样搬入答案。

详见 [概括题专题](概括题专题.md)。

### 5.2 提出对策

**找点来源：**

1. 材料中的明示建议；
2. 成功案例中的做法；
3. 失败案例中的教训；
4. 问题和原因的反向转换。

**可执行对策的六要素：** 主体、对象、手段、内容、目标、保障。字数紧时不必每条六项齐全，但至少要回答“谁用什么方法解决什么问题”。

### 5.3 综合分析

| 小类 | 首要任务 | 常用结构 |
| --- | --- | --- |
| 词句理解 | 解释词句的表层与深层含义 | 释义 → 表现/因果/影响 → 结论或对策 |
| 评价分析 | 对现象或观点作有依据的判断 | 态度 → 理由（利弊/条件）→ 对策/结论 |
| 比较分析 | 统一维度比相同与不同 | 总括 → 分维度对比 → 结论 |
| 启示分析 | 把案例的成功逻辑转为可借鉴做法 | 总括 → 做法分条（适度说明作用） |

详见 [综合分析专题](综合分析专题.md)。

### 5.4 应用文

应用文的本质是“**在特定身份下，对特定对象完成一个沟通任务**”。先定功能，再定格式。

| 功能 | 常见文种 | 内容重心 |
| --- | --- | --- |
| 宣传动员 | 倡议书、宣传稿、讲解稿 | 为什么做、怎么做、发出号召 |
| 汇报参谋 | 汇报提纲、调研报告、情况汇报 | 情况、问题、原因、建议，依任务取舍 |
| 组织执行 | 通知、工作方案、指导意见 | 任务、步骤、分工、时间、保障 |
| 评论解释 | 短评、回应稿、编者按 | 亮明观点，说清事理，引导认识 |

详见 [公文写作专题](公文写作专题.md)。

### 5.5 大作文

作文的核心不是背开头，而是保证三组关系正确：

1. **题干与总论点：** 总论点必须直接回答命题。
2. **总论点与分论点：** 分论点共同支撑总论点，层级一致，不重叠。
3. **分论点与论据：** 案例和道理必须证明本段观点，讲完例子要有因果分析。

一个稳定的论证段可以是：

> **分论点 → 解释关键词 → 事例/道理论据 → 分析论据如何证明观点 → 回扣主题**

详见 [大作文专题](大作文专题.md)。

## 六、一材多用：综合训练

### 6.1 自编材料

> H 县有一条废弃铁路，沿线串联着老车站、厂房和多个社区。以往，轨道两旁杂草丛生，垃圾堆积，部分建筑年久失修。居民希望改善环境，又担心大拆大建会丢掉城市记忆。
>
> 县里最初委托某企业统一开发。企业计划建设大面积商业街，却未充分调查沿线社区的人口结构和需求。方案公布后，居民质疑停车场、菜市场和儿童活动空间不足，一些小商户也担心租金上涨。项目因意见分歧搁置。
>
> 随后，H 县重新组织规划。工作人员通过入户访谈、线上问卷和儿童议事会收集意见，将信息整理为生活服务、休闲健身、文化保护三类需求。规划部门、街道、居民代表和设计团队共同勘察，决定保留轨道和老站房，利用边角地补建小型菜市场、口袋公园和儿童活动区，并将旧厂房以低租金提供给非遗工坊和社区创业者。
>
> 项目没有一次铺开，而是先改造 800 米示范段。县里引入第三方评估人流、噪声、商户收益和居民满意度，再据此调整后续方案。改造后，志愿者、社区商户和物业组建共管委员会，将摊位收益的一部分用于设施维护。一年后，该区域成为居民日常活动空间，也吸引了游客，但节假日占道经营、垃圾增多和停车拥堵等问题逐渐显现。
>
> 一位参与规划的学者说：“城市更新不是把老地方涂成一样的新颜色，而是让历史、当下生活与未来需求在同一片空间里继续对话。”

### 6.2 任务一：概括问题

**题目：** 根据材料，概括 H 县废弃铁路沿线改造前期面临的主要问题。（150 字以内）

**找点：** “前期”限定第 1—2 段；任务是问题，不写后续做法。

**参考答案：**

> 一是环境与设施破败。沿线杂草、垃圾堆积，建筑失修。二是保护与发展矛盾突出。居民既求环境改善，又忧城市记忆流失。三是前期决策缺少调研和参与。统一开发未充分掌握社区需求，导致方案与民生需求脱节。四是利益协调不足。小商户担心租金上涨，项目因分歧搁置。

**易错点：** 不应把“节假日拥堵”写入，因为那是改造一年后出现的新问题，超出“前期”时间边界。

### 6.3 任务二：总结经验

**题目：** 根据材料，总结 H 县更新废弃铁路沿线的主要经验。（200 字以内）

**加工逻辑：** 材料是具体做法，答案要适度上升为可复用经验，但仍保留 H 县的具体做法作证据。

**参考答案：**

> 一是坚持需求导向。多渠道听取不同群体意见，对需求分类整理。二是推进多元共治。组织部门、街道、居民和专业团队共同勘察决策。三是统筹保护与利用。保留历史风貌，补齐民生设施，引入文化与创业业态。四是坚持渐进式更新。先行试点，引入第三方多维评估，依效果优化方案。五是建立长效管护机制。组建共管队伍，将经营收益反哺设施维护。

### 6.4 任务三：提出对策

**题目：** 针对改造后出现的新问题，提出进一步优化运营管理的建议。（200 字以内）

**推导链：**

| 问题 | 原因补全 | 对策转换 |
| --- | --- | --- |
| 占道经营 | 摊位空间、时段与执法标准不清 | 划定区域与时段，发布经营清单，柔性劝导与依法管理结合 |
| 垃圾增多 | 节假日人流增大，保洁与设施不匹配 | 动态增设垃圾收集点，增加高峰保洁频次，落实商户门前责任 |
| 停车拥堵 | 高峰需求集中，公交衔接与引导不足 | 完善接驳公交和步行导视，发布车位信息，必要时预约限流 |

**参考答案：**

> 一是规范经营秩序。合理划定摊位区域和时段，明确经营清单与商户责任，将柔性劝导与依法管理结合。二是提升环卫能力。根据节假日人流增设收集设施、加密保洁，引导商户履行门前责任。三是优化交通组织。增设接驳公交和步行导视，及时发布车位与拥堵信息，高峰时预约分流。四是完善动态治理。畅通居民、商户反馈渠道，定期评估并调整管理措施。

**易错点：** 只写“加强管理、加大宣传、提高意识”没有回答怎么做，也未与三个问题对应。

### 6.5 任务四：词句理解

**题目：** 谈谈你对“让历史、当下生活与未来需求在同一片空间里继续对话”的理解。（250 字以内）

**结构：** 解释含义 → 材料依据 → 结论/方向。

**参考答案：**

> 这句话指出，城市更新不是抹去历史、追求外观一新，而是统筹历史保护、现实民生和长远发展，使空间持续承载生活与活力。对 H 县而言，保留轨道、站房是延续城市记忆；增设菜市场、公园和儿童空间是回应居民当下需求；引入新业态、先试点再评估、建立共管机制，是为未来发展与长效运营预留空间。因此，更新应坚持保护与利用并重、多元参与、渐进实施和动态优化。

### 6.6 任务五：应用文提纲

**题目：** H 县拟召开城市更新经验交流会。假如你是县住建部门工作人员，请根据材料，拟写一份交流发言提纲。（400 字以内）

**审题：** 身份是住建部门工作人员，受众是交流会与会者，目的是介绍经验，文种是发言提纲。重点应是做法与效果，不是细讲所有问题。

**参考提纲：**

> **让老铁路延续城市记忆与生活活力**
>
> 各位领导、各位同仁：
>
> H 县废弃铁路曾面临环境破败、设施失修、开发方案脱离民生需求等问题。为统筹保护与发展，我们主要做了以下工作：
>
> 一、深入调研，分类掌握需求。通过入户、问卷和儿童议事会倾听多元声音。  
> 二、协同规划，兼顾记忆与民生。多方共同勘察，保留铁路风貌，补建服务设施，引入适宜业态。  
> 三、小步试点，以评估优化决策。先改造示范段，综合评估人流、环境、经营与满意度，动态调整。  
> 四、多元共管，保障长效运营。社区、商户、物业和志愿者共同参与，以部分经营收益反哺维护。
>
> 目前，沿线已兼具居民日常活动和文旅吸引力。下一步，我们将针对节假日经营、环卫和交通问题继续优化管理。谢谢大家。

### 6.7 任务六：大作文提纲

**题目：** 结合对学者所说“对话”的思考，联系实际，自拟题目，写一篇议论文。

**立意检查：**

- “对话”不是普通沟通，而是历史保护、当下民生、未来发展三者的统筹；
- 文章不能只写“保护历史”，否则丢失后两个维度；
- 分论点可以按三者并列，也可以按“为什么统筹—如何统筹”展开。

**参考提纲：**

> **题目：在守正创新中让城市持续生长**
>
> **总论点：** 城市更新应尊重历史文脉、回应现实民生、面向未来发展，以多元共治和渐进式更新实现三者统一。
>
> **分论点一：** 守护历史记忆，才能保留城市的根脉与特色。反面论证“千城一面”，正面结合保留轨道、站房的做法。  
> **分论点二：** 回应真实生活，才能使更新成果可感、可用、可及。对比前期商业化方案与后期需求调研。  
> **分论点三：** 预留未来发展空间，才能使一次建设转化为持续治理。以试点评估、利益反哺和动态优化论证。
>
> **结尾：** 回扣“对话”，强调更新不是割裂新旧，而是让文脉、生活与发展形成可持续的联系。

**论证段示例：**

> 回应真实生活，城市更新才能获得持久生命力。城市的主人是人，空间价值不仅在于外观精美，更在于能否承载买菜、休闲、创业等日常活动。H 县最初追求大面积商业开发，却因忽视停车、菜市场和儿童空间等需求遇阻；重新开门问需之后，项目才真正融入社区生活。可见，从“为城市造景”转向“为群众营生活”，才能让更新成果不止于一时热闹，而成为可感可及的长久福祉。

## 七、作答核对清单

### 小题交卷前

- [ ] 任务、对象、范围、身份和文种是否全部对应？
- [ ] 每条是否有可识别的核心词？
- [ ] 并列要点是否层级一致、互不包含？
- [ ] 是否把事例细节压缩成了做法、问题或影响？
- [ ] 对策是否逐一回应问题，且具有可执行性？
- [ ] 有无超出材料依据的主观发挥？
- [ ] 字数是否留有少量安全空间？

### 作文交卷前

- [ ] 标题和首段是否直接回应命题？
- [ ] 总论点是否明确，分论点是否共同支撑它？
- [ ] 每个论据之后是否有分析，而不是事例堆砌？
- [ ] 材料是否经过概括和转换，而不是大段照抄？
- [ ] 是否出现空泛口号、绝对化表达或与主题无关的背诵素材？
- [ ] 结尾是否回扣主题，而非突然引入新观点？

## 八、复盘时只问五个问题

1. **审题错在哪？** 是任务、对象、范围、身份还是文种？
2. **哪个要点没找到？** 它隐藏在什么信号中？
3. **哪个要点找到了却没写清？** 是缺概括词，还是压缩过度？
4. **分类与顺序是否服务于阅读？** 是否重复、交叉或层级混乱？
5. **下次怎么做？** 将“认真一点”改成可执行动作，例如“审题时圈出时间范围”“每段旁标 W/Y/I/D”。
