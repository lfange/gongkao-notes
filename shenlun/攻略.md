# 申论攻略

> 申论 = 给定材料 + 作答任务。核心能力：**读懂材料 + 找全要点 + 规范表达**。答案 80% 在材料里。
> 国考 180 分钟、5 题（含 1000-1200 字大作文）；省考 150 分钟左右、因省而异。

---

## 一、四大题型

### 1. 单一题（概括题）
- **任务：** 概括问题 / 原因 / 影响 / 对策，通常 200-300 字。
- **方法：** 审题定方向 → 逐段找要点（划关键词）→ 合并同类项 → 分条书写。
- **要点：** 宁可多写相关点，按点给分；每条用「核心词 + 展开」。

### 2. 综合分析题
- **类型：** 词句理解、评价分析、比较分析、启示分析。
- **方法：** 总—分—总结构。亮明观点 → 多角度分析（问题/原因/影响/对策）→ 总结/对策。

### 3. 公文写作（应用文）
- **类型：** 倡议书、讲话稿、调研报告、通知、汇报提纲、短评等。
- **方法：** 格式（标题/称谓/正文/落款，看题目是否要求格式）+ 内容（从材料提炼，分条逻辑清晰）+ 语气符合文种。
- **要点：** 审清文种和身份对象，格式分不能丢。

### 4. 大作文（议论文）
- **要求：** 1000-1200 字，基于给定材料立论。
- **方法：**
  1. **论点来自材料**：从材料主旨提炼总论点，忌脱离材料空谈。
  2. 结构总分总：开头亮观点 → 3 段分论点（每段「分论点 + 论据 + 分析 + 对策」）→ 结尾升华。
  3. 论据：材料内案例 + 自身积累（时政、典故、数据）。
  4. 卷面：字迹工整、段落匀称、首行缩进。

## 二、答题四步法（通用）

1. **审题**：看清任务、范围（哪几则材料）、字数、身份、文种。
2. **找要点**：回归指定材料，逐段标注与任务相关的词句（动词、问题词、原因词、对策词）。
3. **加工**：合并同类、理顺逻辑（并列/递进/总分）、提炼核心词前置。
4. **书写**：分条标号（一、1.（1）），规范表达，控制字数。

## 三、日常积累

- **规范表达：** 人民日报评论员文章、半月谈 —— 学官方表述和"对仗式"标题。
- **热点案例：** 按主题（民生、治理、创新、生态、文化）各攒 2-3 个万能案例。
- **金句：** 政府工作报告、领导人讲话中的对仗句，大作文开头/结尾用。

## 四、练习节奏

| 阶段 | 申论任务 |
|---|---|
| 基础筑基 | 每周 1 篇小题（单一题/综合分析），学框架 |
| 专项突破 | 每周 1 小题 + 半月 1 篇大作文（先列提纲） |
| 国考复盘/省考巩固 | 每周 1 篇完整大作文 + 小题限时 |
| 省考冲刺 | 套卷限时（150/180 分钟），背热点素材 |

## 五、考场要点

- 小题先做、大作文留足 50-60 分钟。
- 字迹工整 = 隐形加分，写错划一根线即可，不要涂黑团。
- 严格按字数格子，超字扣分。
