# 申论攻略

> 申论 = 给定材料 + 作答任务。核心能力：**读懂材料 + 找全要点 + 规范表达**。主要依据指定材料，不把“80%”当官方评分规则。
> 2026年度国考大纲规定申论180分钟、按三种职位类别命题；并未保证所有类别固定5题或都含1000—1200字作文。四川按岗位类别选择对应卷，下一年度时限以公告为准，见 [四川省考备考](../计划/四川省考备考.md)。
> 第一次学习建议先看 [申论必备知识框架与例题](必备知识框架与例题.md)，用“审题—找点—加工—成文”串联各题型。

---

## 一、五类高频作答任务

### 1. 单一题（概括题）
- **任务：** 概括问题 / 原因 / 影响 / 做法 / 特点等，字数依题干要求。
- **方法：** 审题定方向 → 逐段找要点（划关键词）→ 合并同类项 → 分条书写。
- **要点：** 宁可多写相关点，按点给分；每条用「核心词 + 展开」。
- **专题精讲：** [概括题专题.md](概括题专题.md)（审题五要素、信号词定位法、加工三步）。

### 2. 提出对策题
- **任务：** 针对材料中的问题、原因或指定情境，提出可执行的解决办法。
- **方法：** 优先提取材料中的直接建议、成功做法和反面教训，再将问题、原因反向转换为对策。
- **表达：** 每条尽量写清“谁做 + 做什么 + 怎么做 + 达到什么目的”，避免只写“加强重视、加大宣传”。
- **框架与例题：** [申论必备知识框架与例题](必备知识框架与例题.md#52-提出对策)。

### 3. 综合分析题
- **类型：** 词句理解、评价分析、比较分析、启示分析。
- **方法：** 总—分—总结构。亮明观点 → 多角度分析（问题/原因/影响/对策）→ 总结/对策。
- **专题精讲：** [综合分析专题.md](综合分析专题.md)（四类题型结构、启示题主体转换）。

### 4. 公文写作（应用文）
- **类型：** 倡议书、讲话稿、调研报告、通知、汇报提纲、短评等。
- **方法：** 格式（标题/称谓/正文/落款，看题目是否要求格式）+ 内容（从材料提炼，分条逻辑清晰）+ 语气符合文种。
- **要点：** 审清文种和身份对象，格式分不能丢。
- **专题精讲：** [公文写作专题.md](公文写作专题.md)（高频文种速查表、内容三段式）。

### 5. 大作文（议论文）
- **要求：** 基于给定材料立论，字数和任务完全依题干；仅在目标类别试卷有议论文任务时按大作文训练。
- **方法：**
  1. **论点来自材料**：从材料主旨提炼总论点，忌脱离材料空谈。
  2. 结构总分总：开头亮观点 → 3 段分论点（每段「分论点 + 论据 + 分析 + 对策」）→ 结尾升华。
  3. 论据：材料内案例 + 自身积累（时政、典故、数据）。
  4. 卷面：字迹工整、段落匀称、首行缩进。
- **专题精讲：** [大作文专题.md](大作文专题.md)（立意三步、结构模板、论证句式、开头结尾模板）。

## 二、答题四步法（通用）

1. **审题**：看清任务、范围（哪几则材料）、字数、身份、文种。
2. **找要点**：回归指定材料，逐段标注与任务相关的词句（动词、问题词、原因词、对策词）。
3. **加工**：合并同类、理顺逻辑（并列/递进/总分）、提炼核心词前置。
4. **书写**：分条标号（一、1.（1）），规范表达，控制字数。

## 三、日常积累

- **规范表达：** 人民日报评论员文章、半月谈 —— 学官方表述和"对仗式"标题。
- **热点案例：** 按主题（民生、治理、创新、生态、文化）各攒 2-3 个万能案例。
- **金句：** 政府工作报告、领导人讲话中的对仗句，大作文开头/结尾用。
- **工具库：** [规范表达与素材库.md](规范表达与素材库.md)（口语→规范对照表、主题案例库、金句库，每周 30 分钟维护）。
- **各题型笔记索引：** [笔记.md](笔记.md)。

## 四、练习节奏

| 阶段 | 申论任务 |
|---|---|
| 基础筑基 | 每周 1 篇小题（单一题/综合分析），学框架 |
| 专项突破 | 每周 1 小题 + 半月 1 篇大作文（先列提纲） |
| 国考复盘/省考巩固 | 每周 1 篇完整大作文 + 小题限时 |
| 省考冲刺 | 套卷限时（150/180 分钟），背热点素材 |

## 五、考场要点

- 按该卷题型分配时间；有大作文时可预留50—60分钟作为初始训练预算，再按实测调整。
- 字迹工整 = 隐形加分，写错划一根线即可，不要涂黑团。
- 严格按字数格子，超字扣分。
