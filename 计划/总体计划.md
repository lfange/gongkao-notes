# 总体计划（国考 + 四川省考，公安优先、普通岗备选）

> 更新：2026-10-05 ｜ 当前基础：行测已完整学过一遍，申论有初步了解
> 学习时间：工作日每天2小时，周末每天5—6小时；先按每周20小时执行，不把可用时间全部排满。
> 目标：2027年度国考及四川省考。下一轮正式日期本次尚未查到可核验公告，不预填笔试日。
> 本页保存学习安排和通用核验事项，不保存个人出生年份、视力及具体定向合同等资料；计划不等于完成记录。

## 一、当前策略：行测转训练，申论补输出，公安先核资格

不再从头重看整套行测基础课。现在的主要任务是：行测限时作答与复盘、申论持续动笔，以及确认公安岗位资格后安排专业科目。行测“学过一遍”不等于已经达到考场速度，先用陌生卷建立基线。

- 国考与四川省考都是准备目标，公共科目继续并行训练。先核实录取类别是定向还是非定向，再核验报考身份；不能仅凭“在职研究生”认定定向，也不因类别未知就提前放弃国考。确认资格后按最近一场正式笔试优先倒排。
- 公安岗是第一志愿方向，但普通公务员岗位须同步筛选，不能等警察体检不合格后再考虑转岗。
- 公安候选岗位须同时通过年龄、学历身份、专业、证书时间、身体条件等核验。不是“有硕士”或“身高达到某个数值”就一定能报。
- 当前关键资格未确认，默认使用下面的“公共科目版”，暂不安排系统公安专业课。希望保留公安入门的，可短期使用“资格待确认版”；只有存在合适且需加试的公安岗位后，才切换“公安三科版”。
- 若只有不加试公安专业科目的合适警察岗位，采用公共科目版，同时保留必要体能训练。
- 2027年度日程、卷类、题量、时限，以新公告和职位表为准；不能默认四川省考都在春季。

资格核验及历史依据见 [四川省考备考](四川省考备考.md) 与 [招警攻略](../招警/攻略.md)。疑问由具体招录机关答复，笔记不能替代资格审查。

### 毕业年度、定向就业与报考身份：三个分开的判断

**先核实事实：** “在职”描述当前工作状态，“非全日制”是学习方式，“定向/非定向就业”是录取就业类别，不是同一个字段。[教育部2026年硕士招生规定](https://www.moe.gov.cn/srcsite/A15/moe_778/s3261/202509/t20250918_1413836.html)分别规定学习与就业方式，且非全日制原则上招收在职定向就业人员。这说明需要重点核查，但不能替代本人入学时的实际录取记录。

核查顺序：研究生报名/录取登记材料中的“报考类别、录取类别或就业方式” → 是否有定向就业合同 → 请学校研招办或研究生院确认。材料没有显示、本人不记得签约或档案未转入学校，都不能单独作为确定结论。仅向招录机关提供准确类别，不把合同或身份证明上传公开仓库。

**项目规则核验案例（政策资料，不是个人档案）：** [西南财经大学2025年MBA官方简章](https://gs.swufe.edu.cn/info/1050/24761.htm)的“六、报名程序—网上报名—注意事项”明确要求非全日制方向选择定向就业；[学校2025年硕士网上报名公告](https://yz.swufe.edu.cn/info/1101/12201.htm)亦有相同要求。这属于该校该年度项目的明确规定，不仅是全国政策的“原则上”。应区分“项目规定已核实”“个人录取记录待核对”“公务员资格待审查”三个层次，不能把最后两项也标成已确认。

1. **国考报名资格：** 已核验的 [2026年度国考指南](https://www.forestry.gov.cn/c/www/gsgg/645382.jhtml)限制当年毕业的定向、委培生。项目简章已明确定向的，先按存在该限制风险核查，并用个人录取记录补充确认；进一步结合下一轮新指南询问该限制如何适用，仅取得原本科学历或单位同意，不自动解决资格问题。若实际记录为非定向，也还须核验其他岗位条件。
2. **四川普通岗位：** 先核验非全日制在读、实际录取类别、可能涉及的合同及录用后全职履职要求，再判断能否使用已取得的本科及学位报考；不把其他地区允许非全日制报名的政策直接套用到目标岗位。
3. **四川公安年龄放宽：** 可以报考非应届普通岗位，不等于能按应届硕士享受警察年龄放宽。资格身份、学历专业、年龄放宽须分别确认，不能只核对其中一项。

本科和硕士专业均按证书/学籍原文匹配；带“中文方向”的教育类旧专业不能自行改成汉语言文学，工商管理专业学位也不自动等同公共管理、会计或金融。旧专业归类疑问可准备学校专业说明、课程成绩单，再由招录机关按适用目录确认。

若下一轮国考确实不能报，不中断公共科目学习：转向资格符合的四川普通岗位，并把毕业后下一年度国考作为待核验的后续选项，不承诺毕业后一定可报。不要为未确认的资格先辞职、退学或变更合同。

公告发布后，把最近一场正式笔试记为 T。若距 T 不足6周，压缩专项补课，提前进入整卷训练；若两场相近，优先最匹配且最近的考试。不要按假定日期强行完成所有课程。

国考与四川套卷按各自目标类别轮换，建议一周国考、一周四川；临近考试时，以最近一场为主。国考结束后先用1—2天复盘，再回到四川目标卷，不长时间停学。若有两场考试录用时间重叠，依公告如实报告有关录用情况。

## 五、各科怎么用这些时间

### 行测：限时做题 → 找错因 → 隔日二刷

- 资料分析、判断推理、言语理解先诊断再决定轻重，不因“听懂课”就跳过计时。
- 做错、蒙对、超时做对分别标记。复盘只补确实不会的考点，再做陌生同类题检验。
- 数量不完全放弃，先保住基础题；政治理论持续学习，常识按错题和高频框架补充。
- 每周只主攻1—2个弱项。模块正确率用同类别、相近难度陌生题比较，熟题二刷不混作进步证据。
- 看 [行测知识框架](../xingce/必备知识框架与例题.md) 查漏，不重复从头听整套课。

### 申论：每天动笔，不把读范文当作答

1. 审题：任务、身份、范围、字数、文种。
2. 独立作答：先写再看解析，不边抄边练。
3. 对照材料：标出漏点、重复点、层次与表达问题。
4. 选最差的一题隔日重答，并写一句“下次怎样避免”。

小题是前期主线，但目标卷有作文就同步练完整写作；应用文也按真实任务成文。参考答案不是官方评分标准，估分注明来源，优先追踪漏点和完成时间。入口：[申论知识框架](../shenlun/必备知识框架与例题.md)。

### 公安：资格匹配后再增加投入

- 初期：职业素养与公安基础 → 法理/宪法、人民警察法 → 治安与行政执法 → 刑法/刑诉与刑事执法 → 群众工作、信息与情境题；交叉穿插对应题目，不等法条全背完才做题。
- 每次40分钟可分为20分钟知识与适用条件、15分钟题目、5分钟错因与法条定位；周末做情境专题。
- 数字与期限必须连同对象、起算点、例外记忆，不背孤立数字。
- 以 [公安12专题](../招警/笔记.md) 为索引；截至考试时的法律版本按 [更新清单](法律与时政更新清单.md) 核验。
- 若最终可报职位不考专业科目，不保留这部分“为了保险”的固定刷题量。

## 六、体能：提前准备，但不挤掉申论

建议每周3次、每次约30分钟，非连续日安排，含热身和整理。先以轻松跑/走跑和基础力量建立习惯，状态允许后再逐步练往返跑与纵跳动作；不要一开始就天天全力测1000米。疼痛、胸闷或其他健康疑问应先咨询专业人员。

此时间另计，共约1.5小时；学习加训练约21.5小时/周。如果工作日“2小时”是学习与运动的总上限，将训练移到周末弹性时段或替换相应学习，不默认额外增加时间。身高、体重不能替代三项实际成绩，也不以减重作为备考目标。

适用项目、年龄组、免测及次数先读 [招警攻略的体测标准](../招警/攻略.md)。资格未确认时维持基础运动即可，不购买昂贵专项课程，不为赶报名仓促作医疗决定。体测时间与笔试不同，按实际通知持续准备。

## 七、两类岗位同时筛，但各考试按规则选职位

| 候选池 | 筛选顺序 | 不应自行推定的事项 |
| --- | --- | --- |
| A：人民警察 | 年龄路径 → 毕业身份/拿证时间 → 学历专业 → 视力等身体标准 → 工作地点与服务年限 → 科目与卷类 | 省级机关年龄规则不直接套到直属基层职位；非全日制双证不自动等于应届放宽资格 |
| B：普通公务员 | 学历身份与专业 → 年龄/经历/政治面貌 → 工作地点与服务年限 → 科目与卷类 → 历史竞争作参考 | 自考并非一概不能报；硕士在读不能直接当已取得研究生学历；专业相近不等于符合 |

同一场考试通常只能报1个职位，初审通过后的改报限制按公告执行；“普通岗备选”是报名前保留第二候选池，不是警察体检失败后自动改录普通岗。国考和四川省考分别选定符合条件的职位，不能同场同时报两个岗位。

## 八、每周复盘只看五项

1. 行测：目标类别、总分/正确率、各模块耗时、空题数。
2. 申论：独立完成题数、漏点、重答改善、整卷是否超时。
3. 公安：仅在需要时记录陌生题正确率、法律/程序错误与情境判断错误。
4. 体能：训练次数、身体反馈；熟悉规则后再记录受控测试结果。
5. 资格及公告：新增证据、未解决问题、下一步；MBA课程与论文有无被挤占。

目标不是把每天塞满，而是连续四周留下可比较的真实输出。用 [每周计划模板](每周计划模板.md) 排任务，在 [每日打卡](每日打卡.md) 记录完成情况，错题归入 [错题本](../错题本.md)。
