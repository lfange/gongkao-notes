## 二、层级关系图

    目标层：全面建设社会主义现代化国家
       ↓ 通过什么道路
    道路层：中国式现代化
       ↓ 从哪些领域推进
    总体布局：“五位一体”
       ↓ 以哪些战略协同保障
    战略布局：“四个全面”
       ↓ 发展领域遵循什么原则
    理念层：创新 / 协调 / 绿色 / 开放 / 共享
       ↓ 用什么立场观点方法认识问题
    方法层：人民至上 / 自信自立 / 守正创新 / 问题导向 / 系统观念 / 胸怀天下

**易混关系：**

- 总体布局 ⚠ 战略布局：前者是建设领域，后者是战略部署；
- 现代化特色 ⚠ 本质要求：特色回答“是什么样的现代化”，本质要求回答“必须达到什么要求”；
- 发展理念 ⚠ 方法论：理念用于指导发展，方法论用于认识和解决各类问题；
- 高质量发展 ⚠ 单纯高速增长：强调质的有效提升和量的合理增长相统一。

## 三、新发展理念情境图

| 节点 | 解决的核心问题 | 高频材料信号 | 易混节点 |
| --- | --- | --- | --- |
| 创新 | 发展动力 | 技术攻关、制度改革、数字赋能、新产业 | 使用新工具不一定以创新为主要目的 |
| 协调 | 发展不平衡 | 城乡融合、区域协同、产业衔接、补短板 | 公共服务也可能突出共享 |
| 绿色 | 人与自然和谐 | 节能、降碳、修复、循环利用 | 不能只看是否出现“生态”一词 |
| 开放 | 内外联动 | 外贸、外资、国际合作、规则对接 | 不等于放弃安全和自主发展 |
| 共享 | 社会公平正义 | 公共服务、社会保障、机会公平、惠民 | 平均分配不是共同富裕 |

    情境题
       ↓ 找措施的直接目标
    目标是技术或制度破题？ → 创新
    目标是弥合结构差距？   → 协调
    目标是改善生态关系？   → 绿色
    目标是促进内外联动？   → 开放
    目标是成果公平惠民？   → 共享

## 四、“六个必须坚持”应用图

| 节点 | 判断问题 | 情境信号 |
| --- | --- | --- |
| 人民至上 | 为了谁、依靠谁、成果由谁共享 | 问需于民、群众评价、民生福祉 |
| 自信自立 | 是否立足国情、依靠自身力量 | 自主探索、自立自强、不照搬 |
| 守正创新 | 是否守住根本方向并解决新问题 | 坚持原则、改革方法、推陈出新 |
| 问题导向 | 是否针对矛盾和短板 | 急难愁盼、堵点难点、精准施策 |
| 系统观念 | 是否统筹整体、局部、当前、长远 | 协同治理、全周期、综合施策 |
| 胸怀天下 | 是否兼顾人类共同发展 | 全球治理、共同挑战、文明互鉴 |

## 五、中国式现代化节点图

    中国式现代化
    ├─ 领导和性质
    │  └─ 中国共产党领导的社会主义现代化
    ├─ 五个中国特色
    │  ├─ 人口规模巨大
    │  ├─ 全体人民共同富裕
    │  ├─ 物质文明和精神文明相协调
    │  ├─ 人与自然和谐共生
    │  └─ 走和平发展道路
    ├─ 时间安排
    │  ├─ 2020—2035：基本实现社会主义现代化
    │  └─ 2035—本世纪中叶：建成社会主义现代化强国
    └─ 题目辨析
       ├─ 共同富裕 ≠ 同步同等富裕
       ├─ 协调发展 ≠ 只发展单一领域
       └─ 和平发展 ≠ 放弃维护国家利益

## 六、政策与时政节点图

    正式文件
       ├─ 发布主体
       ├─ 文件名称
       ├─ 发布日期
       ├─ 施行/规划期间
       ├─ 目标与具体措施
       ├─ 已完成成就
       └─ 原文链接 + 核验日期

**必须区分：**

- 党中央提出规划建议 → 全国人大批准规划纲要；
- 预期目标 → 尚未等于实际完成值；
- 提出/部署 → 不等于已经实施完成；
- 国家部署 → 地方落实举措，两者主体不能互换。
