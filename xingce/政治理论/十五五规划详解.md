## 一、先用一条逻辑理解“十五五”

**“十五五”是向2035年基本实现社会主义现代化迈进的关键五年，核心是以高质量发展为主题，把产业升级、科技创新、扩大内需、改善民生、绿色转型和安全保障统筹起来。**

它既回答“经济靠什么增长”，也回答“发展成果如何惠及群众”“资源环境能否承受”“发生风险时能否保持稳定”。不能把它缩减为GDP目标表，或若干热门产业的扶持目录。

下面是学习用逻辑图，属于本文归纳，不是官方章节分类：

```text
目标：为2035年基本实现社会主义现代化打好基础
  │
  ├─ 动力：科技创新 + 改革开放
  ├─ 供给：实体经济 + 现代化产业体系 + 数智化
  ├─ 需求：消费 + 有效投资 + 全国统一大市场
  ├─ 共享：就业收入 + 公共服务 + 城乡区域协调
  ├─ 底线：生态环境 + 粮食能源 + 公共安全
  └─ 落实：指标 → 任务 → 工程 → 政策资金 → 监测评估
```

**为什么强调“夯实基础、全面发力”？**“十四五”已经开局，“十六五”将衔接2035年目标，“十五五”需要在承前启后中突破关键瓶颈、补齐短板。它是关键时期，不能直接写成“2030年基本实现社会主义现代化”。

依据：[《纲要》第一篇](https://zwfw.gansu.gov.cn/zhangye/ztfw/qyrzyqzq/zczx/xw/art/2026/art_5a3f88ff6daa461ab2bf9a0d3eee6498.html)；阶段关系参见[国家发改委2026年3月7日吹风会实录](https://www.ndrc.gov.cn/fzggw/wld/zb/zyhd/202603/t20260309_1404067.html)。实录解读的是草案，指标采用正式《纲要》核对。

## 二、文件、会议、年份：先把主体分清

### 1. 三类文件的分工

| 文件 | 主体与作用 | 学习时抓什么 |
| --- | --- | --- |
| 《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》 | 党中央提出未来五年的指导方针、主要目标和战略部署 | 历史方位、指导思想、原则和战略方向 |

### 3. 规划为什么不能直接等同于具体待遇

规划明确发展方向和实施任务；补贴由谁领取、何时执行、如何申请，以及法律制度如何调整，还需要看配套文件。“探索延长义务教育年限”等部署不能直接解释成“全国义务教育年限已经统一延长”。

判断任何政策消息，依次问：**哪个文件 → 国家还是地方 → 目标还是已实施 → 有无适用条件 → 什么时间生效。**

## 三、指导思想与六项原则：考试常考对应关系

### 1. 指导思想中的关键词

以下为正式《纲要》第二章的对应表述，背诵时保留修饰关系：

| 位置 | 对应内容 |
| --- | --- |
| 工作总基调 | 坚持稳中求进 |
| 中心 | 以经济建设为中心 |
| 主题 | 以推动高质量发展为主题 |
| 根本动力 | 以改革创新为根本动力 |
| 根本目的 | 以满足人民日益增长的美好生活需要为根本目的 |
| 根本保障 | 以全面从严治党为根本保障 |

这张表只拆解便于辨析的部分，不替代完整指导思想。尤其不能把“主题”“根本动力”“根本目的”互换。

### 2. 必须遵循的六项原则

| 官方原则 | 通俗理解 | 自编情境中的识别线索 |
| --- | --- | --- |
| 坚持党的全面领导 | 为现代化建设提供根本保证，统筹方向和落实 | 党中央集中统一领导、重大决策部署落实 |
| 坚持人民至上 | 依靠人民、为了人民，兼顾公平与获得感 | 从群众急难愁盼确定公共服务重点 |
| 坚持高质量发展 | 同时关注质量、效率、结构和合理增长 | 因地制宜培育新动能，改造传统产业 |
| 坚持全面深化改革 | 破除制约发展的体制机制障碍 | 打通成果转化、要素流动、市场准入堵点 |
| 坚持有效市场和有为政府相结合 | 市场发挥资源配置的决定性作用，政府更好履职 | 公平竞争、规则建设、公共服务和市场监管 |
| 坚持统筹发展和安全 | 提升发展质量，同时提高抵御风险能力 | 粮食能源保障、产业链韧性、风险预防 |

**易混辨析：**这六项是“十五五”发展原则，不是党的创新理论世界观和方法论中的“六个必须坚持”。数量相同不代表内容相同。

依据：[正式《纲要》第二章，正文第5—7页](https://www.ndrc.gov.cn/fggz/fzzlgh/gjfzgh/202603/U020260317369114704096.pdf)。

## 四、七大主要目标：先背标题，再理解落点

《纲要》第三章列出七方面主要目标，并用指标和任务作进一步展开。

| 主要目标的正式表述 | 理解时关注的落点 |
| --- | --- |
| 高质量发展取得显著成效 | 增长保持合理区间，结构优化，内需作用增强，产业和城乡区域发展取得进展 |
| 科技自立自强水平大幅提高 | 提高创新体系效能，强化基础研究、原始创新和关键核心技术攻关 |
| 进一步全面深化改革取得新突破 | 完善市场经济体制、开放体制机制与国家治理 |
| 社会文明程度明显提升 | 丰富精神文化生活，提高文化创新创造活力与文化影响力 |
| 人民生活品质不断提高 | 就业、收入、教育、健康、养老托育和基本公共服务改善 |
| 美丽中国建设取得新的重大进展 | 实现碳达峰目标，推进绿色低碳转型和环境质量改善 |
| 国家安全屏障更加巩固 | 保障粮食能源，防范重点领域风险，提升公共安全与社会治理能力 |

学习口诀可归为“**发展、科技、改革、文明、民生、生态、安全**”，但作答以完整表述为准。

**七大目标与五类指标是什么关系？**前者概括希望取得的整体成效；后者是便于跟踪的主要量化指标。文化、改革等内容没有全部转化成专栏1中的独立数字，不等于没有任务或不重要。

依据：[正式《纲要》第三章，正文第7—10页](https://www.ndrc.gov.cn/fggz/fzzlgh/gjfzgh/202603/U020260317369114704096.pdf)。

### 2. 预期性与约束性怎么理解

专栏1中有**12项预期性指标、8项约束性指标**。约束性指标是教育1项、绿色低碳5项、安全保障2项。

- **预期性指标：**重在通过政策、制度、法治环境引导落实。不是随意定出的数字，也不能认为政府不用履职。
- **约束性指标：**需要强化责任分解和落实。不能进一步推断成每个地区、每家企业都机械执行相同数值。

《纲要》第六十二章将两类任务分别部署推进方式。因此，题目中“全部指标都由政府直接行政分配”“民生指标全部是预期性”均不准确。

### 3. 六个最容易误读的数字

1. **GDP没有固定五年增速。**不能把2026年度增长目标直接写成2026—2030年每年的目标，也不能把“合理区间”理解成不要增长。
2. **研发增长＞7%不是研发占GDP比重＞7%。**前者看投入的增长速度，后者看投入强度，分子分母不同。
3. **入托率提高6个百分点，不是提高到6%。**自编算例：若起点为10%，提高6个百分点后为16%；提高6%后则为10.6%。此起点仅为教学假设。
4. **碳排放强度五年降17%，不是每年降17%，也不是排放总量必然降17%。**自编算例：若GDP由100变120，强度由1降到0.83，则排放量为120×0.83＝99.6，较100下降0.4%。
5. **粮食产能不是某一年实收产量。**丰年产量高于可稳定达到的能力，并不自动证明产能目标已经完成。
6. **优良水体比例不要与其他水质统计指标直接拼接。**使用本表80%→85%的口径；未核清定义前，不拿“地表水达到或好于Ⅲ类水体比例”等其他数据直接作增减比较。

### 1. 现代化产业体系：传统产业也要发展新质生产力

《纲要》把实体经济作为着力点，强调智能化、绿色化、融合化，构建以先进制造业为骨干的现代化产业体系。

- **传统产业**重在更新技术、提高质量、改造流程和降低消耗，并非一律退出。
- **新兴产业**重在壮大规模、拓展应用、完善配套，例如新一代信息技术、新能源、新材料、机器人、生物医药等。
- **未来产业**重在前沿技术、路线探索、概念验证和风险分担。正式文本列举量子科技、生物制造、氢能和核聚变能、脑机接口、具身智能、第六代移动通信等方向。

**理解：**新质生产力不能简单等同于“新开一个高科技项目”。一家传统工厂通过技术创新显著提升生产效率和产品质量，同样可能体现发展新质生产力。地方需要结合人才、产业和资源条件，避免同质化上马项目。

### 2. 科技创新与产业创新：从成果走向应用

基础研究解决原理与源头问题，关键技术攻关突破具体瓶颈，概念验证、中试等环节帮助成果走向应用，企业把技术与产品、生产和市场需求连接起来。

**自编情境：**高校研制出一种新材料，但样品成本高、量产不稳定。单纯继续发表论文不足以解决转化问题，还需要中试条件、企业需求对接、工程人才、资金及相应评价激励。

一体推进教育科技人才发展，就是把人才培养、科学研究和实际需求贯通；不能只理解为三项经费相加，也不能因此忽视基础研究的长期性。

### 3. 数字中国：既有技术供给，也有应用和治理

第四篇按算力算法数据供给、数智技术赋能、发展生态展开，涉及人工智能与产业、公共服务、治理的结合。

理解时把握三层：**能不能用**（基础设施与技术）、**用得好不好**（场景与效益）、**用得是否规范**（安全、伦理、规则等）。

**申论识别：**材料若说基层反复填表、多个平台不能互通，问题可能是流程和数据治理不协同。对策不能只写“再建一个平台”，应围绕数据共享、职责衔接、流程优化和群众使用体验提出措施。

### 4. 内需：惠民生与促消费、投资于物与投资于人相结合

消费需要支付能力、稳定预期、优质供给和便利环境。就业、收入、教育医疗养老等安排，既直接改善生活，也有助于减少后顾之忧、增强消费意愿。这里的作用机制是本文解释，不代表效果必然即时出现。

- **投资于物：**交通、能源、设备、基础设施等物质条件。
- **投资于人：**教育培训、健康、人才发展等提高人的能力和发展机会的投入。
- **结合：**医院既要有设备，也要有医护人员、诊疗能力和可持续运行机制；学校既要有校舍，也要有教师和教学质量。

“扩大有效投资”要关注需求、收益、公共价值和运营条件，不能直接理解成建设规模越大越好。

### 5. 统一大市场、改革与开放：提高资源配置效率

全国统一大市场着重打通市场准入、要素流动、公平竞争等方面的堵点，使商品和要素在更大范围内顺畅配置。统一规则并不意味着所有地方只能发展同一种产业。

改革要增强各类经营主体活力、完善要素市场化配置和宏观经济治理；开放则包括自主开放、贸易投资合作和高质量共建“一带一路”等安排。

**辨析：**“国内大循环为主体”与高水平对外开放可以相互促进；科技自立自强也不等于拒绝国际合作。

### 6. 农业、乡村、城镇化与区域：围绕人的生活与发展组织空间

农业农村现代化既关注粮食生产能力和质量效益，也关注农民收入、乡村公共服务和人居环境。乡村振兴不能只写农业产值增长或村容整治。

新型城镇化强调以人为本，农业转移人口融入城市不仅涉及落户，还涉及就业、住房与基本公共服务。区域协调强调联动、分工和协作，不要求各地区发展模式完全一致。

**自编情境：**县城建了产业园却招工困难，附近村民缺少技能培训、交通和托育支持。解决问题应联动产业、就业、交通和公共服务，不能只追加厂房建设。

### 7. 人口发展与民生：从服务供给到服务质量

第十一篇集中讨论生育、教育、健康与养老；第十二篇讨论就业、收入分配、社会保障、房地产、基本公共服务及群体权益。两篇联系紧密，但主题不能混成一项。

指标变化也体现了具体需求：养老不仅看床位数量，还看护理能力；托育不仅看有没有设施，还关注儿童实际入托；医疗同时关注医师与护士供给。

共同富裕需要通过发展、就业、分配调节和公共服务逐步推进。居民收入与GDP增长同步是总体目标，不能解释成每个人的工资每年都按同一比例上涨。

### 8. 文化：现代化同时包含精神生活

文化建设涵盖价值引领、公共文化服务、文化遗产保护、文化产业和传播能力等。公共文化事业与市场化文化产业的功能有所不同，评价标准也不能完全相同。

**自编情境：**基层文化场馆开放时间与群众休息时间错位。分析应落到服务供需匹配、运营管理和公众参与，不能只以建筑面积评价成效。文旅融合也应兼顾保护传承和公共利益。

### 9. 绿色转型：碳达峰需要能源、产业与生活方式共同变化

《纲要》部署碳排放总量和强度双控制度，以及节能降碳、环境治理、生态保护等任务。能源替代、技术改造、运输调整和绿色生活相互配合。

**强度**是单位经济产出对应的排放，**总量**是全部排放规模，两者有关但不同。从能耗双控转向碳排放双控，不代表不再节能。非化石能源占能源消费总量的比重，也不是发电装机容量占比。

达峰是排放达到峰值后进入下降阶段，中和涉及排放与吸收的平衡，不能把2030年的碳达峰要求改写成2030年实现碳中和。

### 10. 发展与安全：风险治理融入日常发展

安全既涉及粮食、能源、产业链等经济基础，也涉及防灾减灾、生产安全、食品药品、网络安全和社会治理。

《纲要》第五十三章明确推动公共安全治理模式向**事前预防**转型。理解时对应风险识别、隐患排查、监测预警和应急准备，而不是发生事故后才处理。

安全治理需要与法治、服务和发展协调。不能由某一安全目标直接推出未经法律授权的处罚措施。

上述十组关系主要依据[正式《纲要》第二至第十四篇，正文第11—123页](https://www.ndrc.gov.cn/fggz/fzzlgh/gjfzgh/202603/U020260317369114704096.pdf)；“自编情境”“理解”“识别”均为学习解释。

## 七、109项重大工程：怎样把规划落到行动

### 1. 六个方面的分布

| 方向 | 项数 | 学习抓手 |
| --- | --- | --- |
| 引领新质生产力发展 | 28 | 技术攻关、产业能力、创新和应用 |
| 构建现代化基础设施体系 | 23 | 交通能源等基础支撑 |
| 促进城乡融合发展 | 9 | 城乡联动、农业农村与城市发展 |
| 保障和改善民生 | 25 | 教育、医疗、养老托育等需求 |
| 推动绿色低碳转型 | 18 | 节能降碳、生态保护与环境治理 |
| 重点领域安全保障 | 6 | 关键资源供给与风险防范 |
| **合计** | **109** | **28＋23＋9＋25＋18＋6＝109** |

来源：[国家发改委《透视109项重大工程①》](https://www.ndrc.gov.cn/wsdwhfz/202606/t20260601_1405598_ext.html)，2026-06-01。这里是工程分类，与前文“五类指标”“16方面战略任务”不是同一套分类。

### 2. “重大工程”不全是大型土建项目

工程中既有雅下水电、三峡水运新通道等基础设施，也有科技、教育、医疗和社会服务等系统性安排。一项工程还可能包含一批项目或行动。

因此，**109项不等于109个孤立工地，也不能推断全部工程都必须在2030年前建成投用**。正式《纲要》第六十二章区分单体项目、打捆项目，以及期间开展前期工作的项目，并规定符合条件后按程序推进。

### 3. 落实机制的完整链条

**规划目标 → 年度计划和任务分工 → 具体项目与政策 → 财政金融和要素保障 → 动态监测、中期评估、总结评估 → 监督与必要调整。**

评价落实情况时，既要看是否建成、投入多少，也要看服务是否可及、设施是否有效运行、风险是否降低。申论写“完善落实机制”，至少交代责任主体、资源保障和评价反馈，避免停留在口号。

依据：[正式《纲要》第六十二章，正文第133—135页](https://www.ndrc.gov.cn/fggz/fzzlgh/gjfzgh/202603/U020260317369114704096.pdf)。

## 八、申论怎么用：把政策转成分析关系

### 1. 五组可以迁移的分析框架

| 材料中的问题 | 可用的政策理解 | 对策应写到的具体层次 |
| --- | --- | --- |
| 有科研成果，缺稳定产品 | 科技创新与产业创新深度融合 | 需求对接、中试验证、人才协作、评价激励 |
| 有设施，使用率低 | 投资于物与投资于人相结合 | 调研需求、人员配置、运营维护、效果评估 |
| 地方保护，企业跨区办事难 | 全国统一大市场 | 清理不合理壁垒、规则衔接、信息共享、协同监管 |
| 老龄群体就医养老不便 | 人口高质量发展与公共服务 | 需求识别、服务网络、专业人员、可负担性和便利性 |
| 隐患长期积累，事故后突击治理 | 统筹发展和安全、事前预防 | 风险排查、监测预警、责任落实、应急训练 |

此表是答题加工方法，不是可脱离材料直接抄写的标准答案。小题优先依据给定资料；作文引用规划，应具体解释与论点的关系。

### 2. 两段自拟论证示例

**主题：投资于物与投资于人相结合。**

> 公共服务的改善，既需要设施投入，也需要服务能力的持续成长。新建卫生院只是起点，若缺少医护人员、诊疗能力和转诊衔接，设备便难以转化为群众的健康获得感。因此，应把设施配置与人才培养、运行保障共同谋划，并以群众能否方便获得有效服务检验投入成效。

**主题：因地制宜发展新质生产力。**

> 发展新质生产力，需要找准技术与本地产业的结合点。对拥有制造业基础的地区，改善关键工艺、推动设备更新和提高产品质量，可以成为产业升级的现实路径。应立足资源禀赋、技术积累和市场需求选择方向，通过企业、高校与科研机构协同破解瓶颈，避免脱离条件追逐同一赛道。

以上均为本文自拟，不是官方原文，也不是特定真题答案。可学习“提出观点—解释机制—给出路径—说明检验标准”的写法。

### 3. 三条使用边界

1. 目标写“到2030年达到、提高、降低”，不能写成已经取得的成绩。
2. 规划中的探索、推进、逐步完善，不能改成已经全国统一实施。
3. 具体案例需要另核实地点、主体、措施和结果，不能用宏观规划替代案例事实。

## 十、十五条易错辨析

| 错误或不严谨的说法 | 正确认识 |
| --- | --- |
| “十五五”是2025—2029年 | 2026—2030年 |
| 五年规划建议都由五中全会通过 | 本次是二十届四中全会 |
| 国务院直接批准国家“十五五”纲要 | 国务院编制并提出草案，全国人大审查批准 |
| 2030年基本实现社会主义现代化 | 对应目标节点是2035年 |
| 高质量发展是根本动力，改革创新是主题 | 主题与根本动力对调了 |
| “六项原则”就是“六个必须坚持” | 两组概念所属内容不同 |
| 七大目标、五类指标、六类工程可以逐一配对 | 分别是目标、指标和工程的不同分类 |
| 国家规划确定每年固定GDP增长率 | 合理区间、各年度视情提出 |
| 20项指标全部为约束性 | 12项预期性、8项约束性 |
| 11.7年指义务教育年限 | 指劳动年龄人口平均受教育年限 |
| 入托率到2030年达到6% | 指五年累计提高6个百分点 |
| 全社会研发投入占GDP要超过7% | 指研发经费投入年均增速＞7%，按不变价格计算 |
| 五年碳排放总量下降17% | 指单位GDP二氧化碳排放五年累计降低17% |
| 1.45万亿斤是每年实际粮食产量硬指标 | 指2030年粮食综合生产能力1.45万亿斤左右 |
| 规划支持的产业、项目都会成功 | 规划方向不消除市场需求、技术、经营和实施风险 |

## 十一、自编练习与解析

### 题目

**1．下列对应正确的是：**

A. 二十届五中全会——通过“十五五”《建议》  
B. 十四届全国人大四次会议——批准“十五五”《纲要》  
C. 国家发展改革委——批准国家“十五五”《纲要》  
D. 全国政协——批准国家“十五五”《纲要》

**2．“十五五”发展的主题和根本动力分别是：**

A. 高质量发展、改革创新  
B. 改革创新、高质量发展  
C. 扩大投资、技术引进  
D. 提高增速、扩大消费

**3．下列属于约束性指标的是：**

A. 人均预期寿命  
B. 常住人口城镇化率  
C. 劳动年龄人口平均受教育年限  
D. 养老机构护理型床位占比

**4．关于托育指标，下列正确的是：**

A. 入托率提高到6%  
B. 入托率相对基期增长6%  
C. 3岁以下婴幼儿入托率五年累计提高6个百分点  
D. 每千人口托位数增加6个

**5．某传统制造企业通过自主技术改造，提高产品精度和资源利用效率。这表明：**

A. 传统产业必须全部退出  
B. 只有未来产业才能发展新质生产力  
C. 传统产业改造升级也可以体现发展新质生产力  
D. 科技创新只需要追求论文数量

**6．判断：**“碳排放强度下降17%，必然意味着碳排放总量下降17%。”

**7．判断：**“所有20项主要指标的基期数值都来自2025年，都是该年当年值。”

**8．判断：**“每千人口拥有医护人员数包含医师和护士，所以正式《纲要》实际上有21项主要指标。”

**9．简答：**某地建了普惠托育点，但开放时间不适配家长工作、人员不足、使用率低。用“投资于物与投资于人相结合”提出三条改进思路。

**10．简答：**为什么不能只用工程投资金额判断规划落实成效？

### 答案与解析

1. **B。**《建议》由二十届四中全会通过；《纲要》由十四届全国人大四次会议批准。注意“编制”“讨论”“审查批准”的主体。
2. **A。**以推动高质量发展为主题，以改革创新为根本动力。
3. **C。**教育年限是民生福祉类别中唯一的约束性主要指标，其余三项为预期性。
4. **C。**同时考指标名称、时间范围和百分点，不能替换为托位数或“达到6%”。
5. **C。**应从创新、效率、质量等实际变化判断，不能只按产业新旧标签判断。
6. **错误。**排放总量＝经济总量×排放强度；强度下降后的总量变化还受经济总量影响。
7. **错误。**数字经济核心产业占比、森林覆盖率标注了2024年数据；碳强度降幅的基期栏是上一五年累计数；入托率提高未列基期值。
8. **错误。**医护人员数是第10项，内含两个子项，总数仍为20项。
9. **参考要点：**调查家长需求并调整服务时段；加强人员配备与专业培训；完善运行保障、质量管理和使用反馈。必须针对已给问题，不能只写扩大建筑面积。
10. **参考要点：**投入金额是资源投入，不能直接代表产出效果；还要看项目适配度、运营效率、服务质量与可及性、生态安全效果和持续运行能力，并结合规划指标及评估要求判断。

## 十二、考前速记卡与复习安排

### 一分钟速记

- **时期与定位：**2026—2030年；基本实现社会主义现代化夯实基础、全面发力的关键时期。
- **主体：**党中央全会通过《建议》；国务院编制草案；全国人大批准《纲要》。
- **关键词：**高质量发展是主题，改革创新是根本动力。
- **结构：**六项原则、七大目标、五类20项指标、18篇62章、16方面任务、六方面109项重大工程。
- **属性：**12项预期性、8项约束性；约束性为教育1＋绿色5＋安全2。
- **数值：**城镇化率71%；受教育11.7年；寿命80岁；入托率提高6个百分点；碳强度累计降17%；粮食产能1.45万亿斤左右；能源产能58亿吨标准煤。
- **三组区分：**规划目标与实际成效；年均增速与期末值、累计值；百分比与百分点。

### 三轮学习

1. **第一轮理解：**读一至七，能用自己的话解释产业、科技、需求、民生和安全之间的联系。
2. **第二轮辨析：**默写主体、主题动力、指标属性和核心数字，完成自测；错误记录到[错题本](../../错题本.md)。
3. **第三轮迁移：**选一段真实材料，用“问题—原因—措施—效果”分析，尝试八、九中的框架；考前复核年度文件和配套政策。
