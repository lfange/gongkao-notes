# 政治理论专题（框架 / 辨析 / 时政应用）

> 独立学习入口，不再只混放在常识判断。依据 [2026年度国考公共科目官方大纲](https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml) 建立通用框架；四川下一轮范围、题量以当地正式公告及大纲为准。
> 更新日期：2026-10-05。这里是入门框架，不是完整教材，也不是预测考点清单。

## 一、学什么、怎么学

| 层次 | 主要任务 | 学习产物 |
| --- | --- | --- |
| 理论框架 | 理解党的创新理论中的目标、布局、方法和发展理念 | 每个概念一张“含义—解决问题—易混点”卡 |
| 政策原文 | 核对重要会议、规划、政府工作报告的主体与时间 | 标发布日、文件名称、出处，不只背标题 |
| 情境应用 | 从具体举措判断理念、方法或政策方向 | 用材料证据说明为什么选，而不是见词即选 |
| 四川积累 | 国家部署与四川落实举措分开记 | “国家要求—四川举措—具体案例”对照，不把地方口号冒充全国表述 |

每天可用10分钟看一张概念卡、5分钟做2—3道辨析题，与常识共用时间预算。每周回查错题的原文出处。

## 二、先搭概念骨架

理论学习以 [党的二十大报告全文](https://www.12371.cn/2022/10/25/ARTI1666705047474465.shtml) 为基础；遇到新表述按最新正式文件核验。下表作关系索引，完整条目回原文学习。

| 概念 | 应记的关系 | 易混点 |
| --- | --- | --- |
| “五位一体” | 经济、政治、文化、社会、生态文明建设的总体布局 | 不是“四个全面”的战略布局 |
| “四个全面” | 建设现代化国家、深化改革、依法治国、从严治党四方面战略部署 | 不能沿用旧版本的“全面建成小康社会”替代当前首项 |
| 中国式现代化 | 党的领导与社会主义方向；人口、共同富裕、文明、生态、和平等中国特色 | 不等于复制西方路径；共同富裕不等于平均分配 |
| “六个必须坚持” | 理论创新所用的立场、观点和方法；可查 [官方学习文章](https://www.12371.cn/2023/04/25/ARTI1682378989117415.shtml) | 与现代化五大特征、九项本质要求不是一组清单 |
| 新发展阶段、理念、格局 | 分别回答所处方位、发展指导原则、经济循环组织方式 | 三个概念不能互换；国内循环为主体不等于闭关运行 |
| 两步走目标 | 2035年基本实现现代化；本世纪中叶建成现代化强国 | “基本实现”与“建成”及时间不对调 |

不要用数字口诀代替全义：读到“系统观念”要能识别统筹关联和整体作用，读到“问题导向”要能识别针对矛盾与短板。

## 三、新发展理念：从“解决什么问题”辨析

| 理念 | 主要关注的问题 | 自编情境关键词（非原文） |
| --- | --- | --- |
| 创新 | 发展动力 | 技术突破、制度或组织创新 |
| 协调 | 发展不平衡 | 城乡、区域、不同领域协同 |
| 绿色 | 人与自然关系 | 减污降碳、生态保护、资源节约 |
| 开放 | 发展内外联动 | 国际合作、对外贸易、制度型开放 |
| 共享 | 社会公平正义 | 公共服务、机会公平、成果惠及群众 |

一道题可能同时涉及多种理念，按题目所问的“主要体现”以及核心措施判断；出现“农村”不一定只考协调，也可能突出共享。

## 四、规划、法律与会议：三组分清

1. 党中央通过规划 **建议**，全国人大批准规划 **纲要**；发布主体不能互换，详见 [五年规划专题](../常识判断/五年规划专题.md)。
2. 年度经济增长 **预期目标** 不等于已经实现的统计增速；初步核算与最终核实也不是同一版本。
3. 法律的拟修改、审议、通过、公布、施行是不同节点；列入立法计划不等于新条文已生效。核验入口见 [法律与时政更新清单](../../计划/法律与时政更新清单.md)。

## 六、自编入门辨析（非真题）

1. 打破关键技术瓶颈、提高自主研发能力，主要对应哪一种发展理念？
   A. 创新　B. 开放　C. 共享　D. 协调
2. 推动城乡公共服务均等化，重点强调成果惠及群众，主要体现：
   A. 绿色　B. 共享　C. 开放　D. 单纯追求总量增长
3. “国内大循环为主体”意味着完全停止国际经济合作。对还是错？
4. “2035年基本实现现代化”与“本世纪中叶建成现代化强国”可互换年份。对还是错？
5. 某法律被列入年度立法工作计划，是否可直接按尚未通过的草案回答现行法题？

**答案：** 1—A；2—B（题干重点是惠及群众，不只是城乡协调）；3—错；4—错；5—不可以，须核对有效版本及题目指定时点。

## 七、错题归因

- 概念错：把目标、布局、方法、理念混为一组。
- 主体错：党内会议、全国人大、国务院等发布主体对调。
- 时间错：提出、通过、施行、规划期与实际统计期混淆。
- 应用错：只凭关键词，没抓到题干的主要问题与举措。
