# 数量关系 · 约数倍数专题（最小公倍数 vs 最大公约数全辨析）

> 一句话判别：**"至少 / 下次同时" → 最小公倍数（LCM）；"最多 / 最长 / 最大等分" → 最大公约数（GCD）**。
> 先破一个口误级误区：公倍数只有"最小"没有"最大"（公倍数可以无限大），它的配对概念是**最大公约数**。
> 每个专题结构：**本质 → 判别速查 → 快算方法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：一个"往后找重合"，一个"往小切单位"

- **最小公倍数（LCM）**：几个周期各自循环，**下一次同时发生**的时刻。它是所有周期的第一个公共重合点——所以"往后看"。
- **最大公约数（GCD）**：把若干个量**等分成相同的小份且不许有剩余**，能同时整除所有量的最大单位——所以"往小切"。

为什么方向恰好相反：

- 公倍数是"变大的数"——重合点必然不小于每一个周期，所以从公倍数里挑**最小**的（第一次重合）；
- 约数是"变小的单位"——等分出的单位必然不大于每一个量，所以从公约数里挑**最大**的（每段最长）。

## 二、判别速查表（信号词 → 用哪个）

| 信号词 | 用哪个 | 本质 |
| --- | --- | --- |
| 至少再过 X 天 / 下次同时 / 再次相遇 | **LCM** | 周期的第一次重合点 |
| 第 N 次重合再过几天 | **LCM**，答案 × (N−1) | 今天算第 1 次 |
| 设工程总量（让效率变整数） | **LCM** | 总量要同时被所有时间整除 |
| 余数相同的"至少多少个" | **LCM**（同余型） | 总数减余数后是公倍数 |
| 每段最长 / 每份最大 / 最多分成几份且不剩余 | **GCD** | 能同时整除所有量的最大单位 |
| 铺最大正方形砖 / 切最大正方体 | **GCD** | 同时量尽各边（三维取三个数的 GCD） |
| 最多扎几束 / 最多分给几人（不剩余） | **GCD** | 束数 / 人数要同时整除各种数量 |

## 三、快算：LCM 与 GCD 怎么 10 秒求出

- **互质**（无公共质因数）→ LCM = 两数之积，GCD = 1。例：4 和 9 → LCM 36。
- **大数是小数的倍数** → LCM = 大数，GCD = 小数。例：12 和 24 → LCM 24、GCD 12。工程问题最爱这个：12 和 24 的总量直接设 24，别算成 288。
- **一般情况用短除法**：GCD = 公共质因数之积；LCM = GCD × 各自剩余的商。例：24 和 36 → 公共 2×2×3 = 12，剩余 2 和 3 → LCM = 12×2×3 = 72。
- **验算恒等式**：**两数之积 = GCD × LCM**。24×36 = 864 = 12×72 ✓。求完顺手一乘即可自检。

## 四、题型逐个击破

### 题型 1：周期相遇（LCM 最典型）

> 甲每 3 天去一次图书馆，乙每 4 天去一次，丙每 5 天去一次。今天三人恰好同去，至少再过多少天再次同去？

重合日必然是 3、4、5 的公倍数，下一次即最小公倍数：LCM(3,4,5) = **60 天**。

- 变体 1：**"每隔 N 天" = "每 N+1 天"**（中间隔 N 天）——高频陷阱，见易错点 1。
- 变体 2：问"第 N 次重合"（今天算第 1 次）→ 再过 **(N−1)×LCM** 天。

### 题型 2：工程问题设特值（LCM）

> 甲 12 天完成，乙 18 天完成，合作几天完成？

总量设 LCM(12,18) = 36，效率立刻是整数 3 和 2，全程口算。逻辑：总量必须**同时被 12 和 18 整除**，除出来才全是整数——这正是"公倍数"的定义；取最小纯粹为了算得小。完整解法见 [工程问题专题.md](工程问题专题.md)。

### 题型 3：余数相同（同余型，LCM）

> 一筐苹果，每人分 5 个多 3 个，每人分 7 个也多 3 个，筐里至少多少个？

余数相同 → 总数减 3 后能同时被 5、7 整除 → LCM(5,7)+3 = 35+3 = **38 个**。口诀：**同余减余数，加回最小公倍数**。余数不同的复杂同余直接代入排除，不值得现场推。

### 题型 4：剪绳 / 裁段（GCD 最典型）

> 两根铁丝分别长 24 米和 36 米，剪成等长小段且不许有剩余，每段最长多少米？

每段长度必须**同时整除 24 和 36**，取最大：GCD(24,36) = **12 米**。

- 常见追问"共剪成几段" → (24+36)÷12 = 5 段。**GCD 只是单位，最后还要除一下**。

### 题型 5：铺砖 / 最大正方形（GCD）

> 长 72 米、宽 54 米的地面铺正方形砖（整块无切割），砖的边长最大是多少？

边长要同时量尽长和宽：GCD(72,54) = **18 米**。追问块数 → (72÷18)×(54÷18) = 4×3 = 12 块。三维变体（长方体切最大正方体）取长宽高三个数的 GCD。

### 题型 6：扎花束 / 分礼物（GCD）

> 红花 96 朵、白花 72 朵，扎成若干束相同的花束（每束红、白数量各自相同）且不许有剩余，最多扎几束？

束数必须同时整除 96 和 72：GCD(96,72) = **24 束**（每束红 96÷24 = 4 朵、白 72÷24 = 3 朵）。

## 五、易错点清单

1. **"每隔 N 天" ≠ "每 N 天"**——每隔 2 天去一次 = 每 3 天去一次（中间实际隔 2 天）。周期相遇题错误率 top1，读题先做 +1 换算。
2. **"至少"和"最多"看反**——至少 / 下次 / 同时 → LCM；最多 / 最长 / 最大等分 → GCD。别顺着"最多扎几束"去想公倍数。
3. **问"几段 / 几块 / 几束"忘了最后一步除法**——GCD 求的只是单位长度，还要用总量 ÷ 单位。
4. **工程特值只被一个时间整除**——总量必须同时被所有时间整除，是 LCM 而不是随便一个乘积（12 和 18 设 36，不是 216）。
5. **第 N 次重合直接乘 N**——今天算第 1 次，第 3 次重合是再过 2×LCM，不是 3×LCM。
6. **大数是小数的倍数还傻算**——12 和 24 的 LCM 就是 24、GCD 就是 12，直接读数。

## 六、精讲例题

**例 1（周期相遇 + 每隔陷阱）**
> 甲每隔 2 天去一次健身房，乙每 4 天去一次，今天两人同去，至少再过几天同去？

每隔 2 天 = 每 3 天。LCM(3,4) = **12 天**。不换算直接 LCM(2,4)=4 就掉坑了。

**例 2（工程特值，衔接工程专题）**
> 一项工程甲 12 天完成、乙 18 天完成，总量应设多少？

LCM(12,18) = **36**（短除：公共 2×3 = 6，剩余 2 和 3 → 6×2×3 = 36），效率 3、2，合作效率 5。

**例 3（剪段 GCD + 追问段数）**
> 两根铁丝 24 米、36 米，剪成等长小段不剩余，每段最长多少？共几段？

GCD(24,36) = **12 米**；(24+36)÷12 = **5 段**。

**例 4（花束 GCD）**
> 红花 96 朵、白花 72 朵扎相同花束不剩余，最多几束？每束几朵？

GCD(96,72) = **24 束**，每束红 4 朵、白 3 朵。验算：96×72 = 6912 = 24×288（LCM），恒等式成立 ✓。

**例 5（辨析题：长相像，方向反）**
> A：一箱苹果每人分 5 个多 3 个、每人分 7 个也多 3 个，至少多少个？
> B：48 支笔和 36 本本子全部分给若干小朋友，每人分得的笔数相同、本数也相同且不剩余，最多分给几人？

A 是同余型 LCM：35+3 = **38 个**；B 是等分型 GCD：GCD(48,36) = **12 人**（每人 4 支笔、3 本本子）。两题都出现"相同 / 不剩余"，判别只看问的是"**至少多少量**"（LCM）还是"**最多几份**"（GCD）。

**例 6（第 N 次重合）**
> 三人今天同去图书馆（第 1 次），之后每 60 天重合一次，第 5 次同去是再过几天？

(5−1)×60 = **240 天**。今天算第 1 次，所以乘 N−1 而不是 N。

## 七、自测练习

1. 甲每 6 天、乙每 8 天去一次公园，今天同去，至少再过几天再次同去？

2. 甲每隔 3 天、乙每隔 4 天去一次操场，今天同去，至少再过几天同去？

3. 一项工程甲 10 天完成、乙 15 天完成，用特值法总量应设多少？

4. 两根绳子长 45 米和 60 米，剪成等长小段且不剩余，每段最长多少米？

5. 长 84 米、宽 56 米的地面铺最大正方形砖，边长多少？需要几块？

6. 72 个苹果和 54 个梨装成相同的果篮（每篮苹果数相同、梨数相同）且不剩余，最多装几篮？

7.（进阶）一袋糖每 4 颗一份余 2 颗，每 6 颗一份也余 2 颗，这袋糖至少多少颗？

8.（进阶）公交 8 分钟发一班车，地铁 12 分钟发一班，早上 7:00 同时发车。下次同时发车是几点？第 3 次同时发车（含 7:00 这次）是几点？

### 答案附录

1. LCM(6,8) = **24 天**（短除：公共 2，剩余 3 和 4 → 2×3×4）。
2. 每隔 3 天 = 每 4 天，每隔 4 天 = 每 5 天 → LCM(4,5) = **20 天**（先 +1 换算，别直接算 3 和 4）。
3. LCM(10,15) = **30**，效率 3、2。
4. GCD(45,60) = **15 米**（45 = 3×15，60 = 4×15）。
5. GCD(84,56) = **28 米**；(84÷28)×(56÷28) = 3×2 = **6 块**。
6. GCD(72,54) = **18 篮**，每篮 4 个苹果、3 个梨。
7. 同余 → LCM(4,6)+2 = 12+2 = **14 颗**。
8. LCM(8,12) = 24 分钟 → 下次 **7:24**；第 3 次 = 7:00 + 2×24 分 = **7:48**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **方向错**：至少 / 下次用了 GCD，最多 / 最长用了 LCM——回看信号词速查表；
- **审题错**："每隔"当"每"、"第 N 次"忘了 −1、追问段数没做最后除法；
- **计算错**：LCM 直接两数相乘（应先除 GCD）、大数是倍数还傻算、验算恒等式（积 = GCD×LCM）没用上；
- **辨析错**：同余型和等分型混了——问"至少多少量"是 LCM，问"最多几份"是 GCD。
