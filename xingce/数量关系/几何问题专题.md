# 数量关系 · 几何问题专题（等积变形、相似比例、立体图形）

> 行测几何不考证明，只考两件事：**记牢公式**（周长、面积、体积）和**会做变换**（割补、等积、相似比例）。
> 最高频的三个思想：**等底等高面积相等、相似比平方=面积比、和定积最大**。
> 每个专题结构：**本质 → 公式族 → 方法三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：公式 + 变换

行测几何题的三种面貌：

1. **直接套公式**（送分）：给边长求面积/体积——公式必须条件反射；
2. **等积变形**（高频）：图形不规则或条件刁钻时，把图形**割、补、移**成规则图形，或用"同底等高"转移面积；
3. **比例与相似**（高频）：不给具体长度、只给比例，用相似关系传递。

两个核心定理：

- **等底等高面积相等**：三角形面积 = ½ × 底 × 高，底和高都没变，形状怎么歪都一样。推论：**中线平分三角形面积**（把一个三角形分成等底等高的两块）。
- **相似比与面积比**：两个图形相似，对应边比 = a:b 时，面积比 = a²:b²，体积比 = a³:b³。**平方、立方是最大考点**——边长比 2:3 的相似三角形，面积比是 4:9，不是 2:3。

## 二、公式族（核心速查表）

**平面图形**（周长 | 面积 各归一列）：

| 图形       | 周长          | 面积                                    |
| ---------- | ------------- | ---------------------------------------- |
| 长方形     | C = 2(a+b)    | S = ab                                   |
| 正方形     | C = 4a        | S = a²                                   |
| 三角形     | 三边之和      | S = ½ × 底 × 高                          |
| 梯形       | 四边之和      | S = (上底 + 下底) × 高 ÷ 2 = 中位线 × 高 |
| 圆         | C = 2πr = πd  | S = πr²                                  |
| 扇形（n°） | 弧长 = nπr/180 | S = nπr²/360                            |

**立体图形**（表面积 | 体积 各归一列）：

| 图形   | 表面积                    | 体积           |
| ------ | ------------------------- | -------------- |
| 长方体 | S = 2(ab+bc+ac)           | V = abc        |
| 圆柱   | S = 侧面积(2πrh) + 2πr²   | V = πr²h       |
| 圆锥   | S = 侧面积(πrl) + πr²     | V = ⅓πr²h      |
| 球     | S = 4πr²                  | V = (4/3)πr³   |

> 圆锥的 l 为母线长。

扇形的面积 = nπr²/360 = nπr/180 × r/2（即 **½ × 弧长 × 半径**）

**扇形秒杀视角——把 n/360 当"占比"，公式不用死记**：弧长、面积都是整圆的 n/360。例如 r=6、n=60°：60° 占 360° 的 1/6 → 弧长 = 2πr ÷ 6 = 12π/6 = **2π**；面积 = πr² ÷ 6 = 36π/6 = **6π**（= ½ × 弧长 × r = ½×2π×6 ✓）。**反求圆心角**：n = 弧长×180/(πr)，如弧长 4π、r=6 → n = 4π×180/(6π) = 120°。

常用结论速记：

- 直角三角形勾股：a² + b² = c²（3,4,5 / 5,12,13 / 6,8,10）。
- **斜边上的高 = 两直角边乘积 ÷ 斜边**（面积法：½ab = ½c·h）。
- 三角形内角和 180°；外角 = 两个不相邻内角之和。
- 30° 角所对直角边 = 斜边一半。
- 圆内接正方形：对角线 = 直径（边 a → 圆半径 = a/√2）；正方形内切圆：直径 = 边长。
- 等周长的长方形中，**越接近正方形面积越大**；等周长平面图形中**圆面积最大**（篱笆类最值）。

## 三、方法三步法（拿到题先走这三步）

1. **识别目标**：求长度、面积、体积，还是比例/最值？决定套公式还是做变换。
2. **找变换**：不规则图形 → 割补成规则图形；给比例没给长度 → 相似/设特值；求最值 → "和定积最大"（长+宽=定值，越均匀积越大）。
3. **核对单位与 π**：面积单位是平方（1 m² = 10000 cm²）；题目说"π 取 3.14"再代数值，否则答案可带 π。

## 四、题型逐个击破

### 题型 1：等积变形（中线、同底等高）

中点连线上最常见的三类：三角形中线平分面积；平行四边形对角线平分面积；同底（或等底）同高的三角形面积相等——顶点沿着与底平行的直线滑动，面积不变。

识别信号："中点""对角线""平行线上的动点"。

### 题型 2：相似与比例

两图形相似（对应角相等、对应边成比例）：边比 a:b → 面积比 a²:b²，体积比 a³:b³。地图比例尺、影长测高、放缩照片都是相似。

识别信号："按比例放大""边长之比为""比例尺"。

### 题型 3：立体图形

圆柱、圆锥、长方体、球的表面积与体积。**注意"无盖"**（水桶、水池：少一个底面/顶面）。

### 题型 4：勾股与面积法

直角三角形斜边上的高 = 两直角边乘积 ÷ 斜边——同一个面积用两种方式算（½ab = ½c·h）。这个"一式两算"思想是几何求高的万能钥匙。

### 题型 5：最值（篱笆 / 靠墙）

周长一定求最大面积：长 + 宽 = 定值 → **和定积最大**（两个量相等时乘积最大）。靠墙时只有三边用篱笆：设垂直墙的边为 x，则 S = x(总长 − 2x)，配方或用"和定积最大"求极值——与利润问题"售价每降 1 元多卖 5 件"同一把钥匙。

### 题型 6：圆与正方形（内切 / 外接）

- 圆内接正方形：**对角线 = 直径**，正方形面积 = 2r²，圆:方 = π:2；
- 正方形内切圆：**直径 = 边长**，圆面积 = πa²/4。

### 题型 7：方阵问题（数阵的几何）

n 排 n 列的方阵，核心是"**每边人数与每层人数**"的换算：

- **实心方阵总人数 = n²**（n 为最外层每边人数）；
- **最外层一圈人数 = 4n − 4**（四个角不重复数）；
- **相邻两层：每边少 2 人，每层少 8 人**（一圈四个边各缩 2）；
- 层数 = (最外层每边人数 + 1) ÷ 2；
- **空心方阵总人数 = (最外层每边人数 − 层数) × 层数 × 4**。

识别信号："方阵""排成方队""最外层""中空"。

## 五、易错点清单

1. **相似比直接当面积比**：边比 2:3，面积比 4:9；体积比 8:27。**平方、立方！**
2. **"无盖"忘减一个底**：水桶只有 1 个底，烟囱/通风管 0 个底。
3. **圆锥体积忘 ⅓**，球体积记成 4πr³。
4. **单位平方/立方**：1 m² = 10⁴ cm²，1 m³ = 10⁶ cm³。
5. **斜边上的高用面积法**，别硬造相似。
6. **靠墙最值把三条边当四条边**：靠墙那侧不用篱笆。
7. **π 处理**：题目要求近似才代 3.14，否则保留 π；选项带 π 的优先带 π 算。
8. **对角线与边的关系**：圆内接正方形用对角线（=2r），不是边长。
9. **方阵每层人数是 4n−4 不是 4n**（四角别数两遍）；相邻两层差 8，不是差 4；空心方阵别按实心 n² 算。
10. **扇形弧长分母 180、面积分母 360 别混**：弧长 = nπr/180，面积 = nπr²/360 = ½×弧长×r。混不住就用占比视角——**都是整圆的 n/360**。

## 六、精讲例题

### 例题 1（等积变形）

**题**：△ABC 的面积为 24，D 为 BC 的中点，E 为 AD 的中点，连接 B、E。△BDE 的面积是多少？

A. 4　B. 6　C. 8　D. 12

**解析**：

1. D 是 BC 中点 → AD 是中线 → S△ABD = S△ACD = 24 ÷ 2 = 12。
2. E 是 AD 中点 → BE 是 △ABD 的中线 → S△BDE = 12 ÷ 2 = **6，选 B**。
3. 思想：**中点连中点，面积一路减半**——每次都是"等底（DE=AE）同高（B 到 AD 的距离）"。

### 例题 2（相似比例）

**题**：两个相似三角形的对应边之比为 2:3，较小的三角形面积为 8，较大三角形的面积是多少？

A. 12　B. 18　C. 27　D. 16

**解析**：

1. 面积比 = 边比² = 4:9。
2. 大面积 = 8 × 9/4 = **18，选 B**。
3. 陷阱：A 是按 1.5 倍线性放大（8×1.5）；C 是按立方（8×27/8）。**见到"相似"，先平方再说话。**

### 例题 3（立体图形，无盖）

**题**：做一个无盖圆柱形水桶，底面半径 5 分米，高 12 分米。至少需要多少铁皮？（π 取 3.14）

A. 408.2　B. 455.3　C. 533.8　D. 489.8

**解析**：

1. 侧面积 = 2πrh = 2×3.14×5×12 = 376.8。
2. 无盖 → 只算 1 个底 = πr² = 78.5。
3. 合计 = 455.3 平方分米，**选 B**。
4. 陷阱：C 是有盖（两个底 533.8）；A 是忘算底。**"无盖"就是文字里的数字陷阱，圈出来。**

### 例题 4（面积法求高）

**题**：直角三角形两条直角边分别为 3 和 4，斜边上的高是多少？

A. 2　B. 2.4　C. 2.5　D. 1.2

**解析**：

1. 斜边 = 5（勾股）。
2. 面积一式两算：½×3×4 = ½×5×h → h = 12/5 = **2.4，选 B**。
3. 思想：同一个面积，底和高可以任意配对——这就是"面积法"。

### 例题 5（圆内接正方形）

**题**：一个正方形内接于圆，正方形的面积为 10。圆的面积是多少？

A. 5π　B. 10π　C. 2.5π　D. 20π

**解析**：

1. 内接正方形的**对角线 = 直径**：正方形面积 = 对角线²/2 = 10 → 对角线² = 20 → (2r)² = 20 → r² = 5。
2. 圆面积 = **5π，选 A**。
3. 陷阱：B 是把边长当直径（a=√10 → π·10/… 错口径）。**内接看对角线，内切看边长。**

### 例题 6（扇形：反求圆心角）

**题**：一个扇形半径为 6、弧长为 4π，它的圆心角是多少度？面积是多少？

A. 90°，12π　B. 120°，12π　C. 120°，24π　D. 60°，12π

**解析**：

1. 反求圆心角：n = 弧长×180/(πr) = 4π×180/(6π) = **120°**。
2. 面积 = ½ × 弧长 × 半径 = ½ × 4π × 6 = **12π → 选 B**。
3. 验证（占比视角）：120° 占整圆 1/3 → 周长 12π ÷ 3 = 4π ✓，面积 36π ÷ 3 = 12π ✓。
4. 陷阱：C 是面积按 nπr²/180 算（分母少除 2）；A、D 是圆心角口算粗错。**见"弧长"，条件反射：n/360 占比 + ½×弧长×r。**

### 例题 7（篱笆最值）

**题**：用 40 米篱笆靠一面足够长的墙围一个矩形菜园，怎样围面积最大？最大面积是多少？

A. 196 平方米　B. 200 平方米　C. 225 平方米　D. 250 平方米

**解析**：

1. 靠墙 → 只围三边：设垂直墙的两边各 x 米，平行墙的一边 = 40 − 2x。
2. S = x(40 − 2x) = 2·x·(20 − x)。因子 x 与 (20−x) 之和为 20（定值）→ 相等时积最大：x = 10。
3. 此时 S = 10 × 20 = **200 平方米，选 B**（另一边 = 40−20 = 20 米）。
4. 陷阱：C 是不靠墙的正方形直觉（225 = 15²，但 15×4 = 60 ≠ 40）；D = 20×25? 口径错。**"和定积最大"再次立功**（与利润专题售价题同一钥匙）。

### 例题 8（方阵：空心三层）

**题**：某方阵最外层每边站 12 人，共 3 层（中间空心）。这个方阵共有多少人？
A. 96　B. 104　C. 108　D. 144

**解析**：

1. 空心方阵公式：总人数 = (12 − 3) × 3 × 4 = **108，选 C**。
2. 逐层验证：外层 4×12−4 = 44，中层 4×10−4 = 36，内层 4×8−4 = 28，合计 44+36+28 = 108 ✓。
3. 陷阱：D 是实心方阵 12²；A 是每层按 4n−4 只算了两层半的粗算。**"空心"二字决定用 (最外层边数 − 层数)×层数×4，逐层验证最稳。**

## 七、自测练习

1. 从一张长 8 分米、宽 6 分米的长方形纸上剪去一个最大的正方形。剩余部分的周长是多少分米？

2. 两个相似三角形的边长比为 3:5，较小的面积为 18，较大的面积是多少？

3. 一个圆柱形水桶底面半径 3 分米、高 10 分米，容积是多少立方分米？（π 取 3.14）

4. 梯形上底 4、下底 10、高 6，它的面积是多少？中位线长是多少？

5. 一个圆锥底面半径 3、高 6，它的体积是多少？（π 取 3.14，结果保留一位小数）

6.（进阶）用 30 米篱笆靠墙围矩形菜园（只围三边），最大面积是多少平方米？

7. 一个实心方阵最外层每边 10 人，共多少人？最外层一圈多少人？

### 答案附录

1. 最大正方形边长 6 → 剩余为 6×2 的长方形 → 周长 = 2×(6+2) = **16 分米**。

2. 面积比 = 9:25 → 18 × 25/9 = **50**。

3. V = πr²h = 3.14×9×10 = **282.6 立方分米**。

4. S = (4+10)×6÷2 = **42**；中位线 = (4+10)÷2 = **7**（面积 = 中位线×高 = 7×6 = 42 ✓）。

5. V = ⅓πr²h = ⅓×3.14×9×6 = **56.5**（忘 ⅓ 会得 169.6）。

6. 设垂直墙的边 x，S = x(30−2x) = 2x(15−x)，和定 15 → x = 7.5 → S = **112.5 平方米**。

7. 总人数 = 10² = **100 人**；最外层 = 4×10−4 = **36 人**（不是 40）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **公式错**：圆锥忘 ⅓、无盖忘减底、单位没平方/立方；
- **变换错**：没看出等积变形、相似比没平方；
- **关系错**：内接/内切搞混（对角线 vs 边长）；
- **方法错**：最值题没联想到"和定积最大"、求高没想到面积法。
