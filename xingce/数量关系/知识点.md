### 1.1 五类错因

| 错因 | 表现 | 修正动作 |
| --- | --- | --- |
| 翻译错 | 把“多20%”写成“多20” | 先定义未知量和基准量 |
| 模型错 | 追及题使用速度和 | 写清距离在缩小还是扩大 |
| 条件漏 | 忘记整数、不同、至少等限制 | 列边界清单 |
| 分类错 | 情况重复或遗漏 | 每类互斥、合计完整 |
| 计算错 | 单位、括号、百分数混乱 | 结果回代题干 |

## 二、通用工具

### 2.1 代入排除

**信号：** 选项是具体数值，题干关系容易验证；直接求解反而复杂。

**方法：** 先用奇偶、整除、大小范围筛选，再从中间值或特殊值代入。

**边界：** 代入必须满足全部条件；代入一个等式成立不能忽略其他限制。

**例证：** 某数除以5余2，除以3余1，选项中先筛“余2”再检验“余1”。

### 2.2 方程与不定方程

**信号：** 未知量少、等量关系明确；题干含“共、相差、合计、恰好”。

    设未知量
       ↓
    将文字关系逐句变成等式
       ↓
    解方程
       ↓
    检查整数、正数和范围

**边界：** 不定方程有多个整数解时，要结合选项、整除、奇偶和上下界，不可只求出一组就停止。

### 2.3 特值法与比例份数

| 场景 | 常设特值 | 原因 |
| --- | --- | --- |
| 工程只给时间 | 时间的最小公倍数作为总量 | 各效率成为整数 |
| 利润只给百分比 | 成本或原价设100 | 百分数直接转数值 |
| 只给比例 | 各量设成对应份数 | 消去共同倍数 |
| 几何只给比例 | 边长设简单数 | 面积、体积关系清晰 |

**边界：** 特值法适用于只涉及比例、不依赖绝对量的关系；题干给定固定差值或固定费用时不能任意缩放。

### 2.4 整除、倍数、尾数

- 人数、件数、分组数通常是整数；
- “每若干个一组正好分完”提示公倍数；
- “最多装若干组、每组尽量大”常提示公约数；
- 只问个位且选项尾数不同，可用尾数法；除法和借位复杂时慎用。

## 三、速率模型

### 3.1 工程问题

**本质：** 工作总量 = 效率 × 时间。

| 类型 | 关系 | 边界 |
| --- | --- | --- |
| 合作 | 总效率 = 各效率之和 | 同时工作才相加 |
| 中途加入/离开 | 分段工作量相加 | 每段时间和人员不同 |
| 交替施工 | 完整周期工作量 + 剩余阶段 | 剩余不足一个周期时逐步算 |
| 水管 | 进水为正、排水为负 | 净效率须大于0才会装满 |
| 按劳分配 | 报酬与完成工作量成比例 | 时间相同仍要看效率 |

**例证：** 甲6天、乙3天完成同一工程，设总量6，效率分别1和2，合作效率3，需2天。

> [工程问题专题](工程问题专题.md)

### 3.2 行程问题

**本质：** 路程 = 速度 × 时间。

| 类型 | 核心关系 | 易错 |
| --- | --- | --- |
| 相遇 | 初始距离 = 速度和 × 时间 | 相向运动用速度和 |
| 追及 | 初始距离 = 速度差 × 时间 | 同向缩短距离用速度差 |
| 流水 | 顺水 = 船速+水速；逆水 = 船速−水速 | 船速指静水速度 |
| 火车过桥 | 路程 = 车长+桥长 | 过人只需车长 |
| 往返平均速度 | 总路程÷总时间 | 等距离不能直接算速度平均 |
| 环形 | 相遇看速度和，追及看速度差和圈长 | 同地、同向、异向要分清 |

**例证：** 甲60千米/时、乙40千米/时，相距200千米相向而行，2小时相遇。

> [行程问题专题](行程问题专题.md)

### 3.3 牛吃草

**本质：** 原有存量 + 时间内新增量 = 时间内总消耗量。

    原有量 Y
       + 生长速度 x × 时间 t
       = 消耗单位数 N × 单位消耗 × t

**信号：** 草场生长、检票口持续来人、水池持续进水、资源持续补充。

**方法：** 用两组“单位数—时间”先求新增速度，再求原有存量。

**边界：** 若资源在减少，新增速度可视为负；必须统一每个单位的消耗速度。

> [牛吃草专题](牛吃草专题.md)

### 3.4 溶液浓度

**本质：** 溶质质量 = 溶液质量 × 浓度。

| 操作 | 不变量 | 变化量 |
| --- | --- | --- |
| 加水 | 溶质不变 | 总量增加、浓度下降 |
| 蒸发水 | 溶质不变 | 总量减少、浓度上升 |
| 加溶质 | 原有溶液关系保留 | 溶质和总量都增加 |
| 两液混合 | 溶质质量相加 | 浓度为质量加权平均 |
| 倒出再加满 | 倒出部分与原液同浓度 | 溶质按固定比例递减 |

**边界：** 混合浓度权重是溶液质量，不是体积，除非题目允许密度相同或直接用体积关系。

> [溶液浓度专题](溶液浓度专题.md)

## 四、基础代数模型

### 4.1 和差倍比

| 模型 | 公式 |
| --- | --- |
| 和差 | 大数=(和+差)/2；小数=(和−差)/2 |
| 和倍 | 小数=和/(倍数+1) |
| 差倍 | 小数=差/(倍数−1) |
| 比例分配 | 每份=总量/总份数 |
| 盈亏 | 两种分配方案的总差建立等量关系 |

**基准边界：** “甲比乙多20%”以乙为基准，甲=1.2乙；“乙比甲少20%”不能直接反写为甲比乙多20%。

> [和差倍比专题](和差倍比专题.md)

### 4.2 年龄

**不变量：** 两人年龄差不变。

**变化：** 每过一年，每个人增加1岁；n个人年龄和增加n岁。

**信号：** 若干年前、若干年后、年龄倍数。

**边界：** 年龄倍数会变化；过去时间不能超过当事人年龄形成不合理负数。

**例证：** 父子相差30岁，5年后仍相差30岁。

### 4.3 日期与周期

- 星期问题：总天数除以7看余数；
- 平年365天，跨过完整平年同一日期星期后移1；闰年366天后移2；
- 闰年通常按“能被4整除但不能被100整除，或能被400整除”判断；
- “每隔n天一次”相邻两次相差n+1天，题目若表述“每n天一次”则相差n天。

**边界：** 跨2月29日时必须看起止日期是否真正覆盖该日，不能只看年份是不是闰年。

### 4.4 鸡兔同笼

**假设法：** 假设全是脚数较少的对象，多出的总脚数 ÷ 每个对象多出的脚数 = 脚数较多对象数量。

**例证：** 10个头、28只脚，假设全是鸡得20脚，多8脚，每兔多2脚，所以兔4只。

**边界：** 不只适用于鸡兔，凡“两类对象、两个总量、单位贡献不同”都可使用。

> 年龄、日期、鸡兔详见 [专题](年龄日期鸡兔同笼专题.md)。

### 4.5 数列与平均数

| 节点 | 关系 |
| --- | --- |
| 等差数列通项 | aₙ=a₁+(n−1)d |
| 等差数列和 | n(a₁+aₙ)/2 |
| 奇数项等差平均 | 中间项 |
| 平均数 | 总量/份数 |
| 加权平均 | 各值×权重之和/权重之和 |
| 移多补少 | 总量不变，观察各量相对平均值的差 |

**边界：** 平均数介于最小值与最大值之间；简单平均只适用于权重相同。

> [数列与平均数专题](数列与平均数专题.md)

## 五、利润与分段计费

### 5.1 利润关系

    利润 = 售价 − 成本
    利润率 = 利润 ÷ 成本
    售价 = 成本 ×（1+利润率）
    折后价 = 原价 × 折扣

**边界：** 利润率分母是成本，不是售价；打八折是原价的80%，不是降低80%。

**例证：** 成本100元，加价50%后打八折，售价=100×1.5×0.8=120元，利润率20%。

### 5.2 总利润与销量变化

    总利润 = 单件利润 × 销量

价格提高使单件利润增加，但销量可能下降，不能只比较单件利润。若销量是价格的一次函数，总利润常成为二次关系，可用配方法、对称轴或和定积最大。

### 5.3 分段计费

**方法：** 总费用 = 固定起步费用 + 各区间实际用量 × 对应单价。

**边界：** 只有超过分界点的部分按高档计费，不能把全部用量都乘高档单价。

> [利润问题专题](利润问题专题.md)

## 六、计数模型

### 6.1 容斥原理

    两集合：|A∪B|=|A|+|B|−|A∩B|
    三集合：单项和−两两交集和+三者交集

**信号：** 至少参加一项、都参加、只参加、两项兼有、都不参加。

**边界：** “两两交集”是否包含三者交集要按题干口径判断；重复扣加最易出错。

**连接：** 容斥与最值结合时，先构造交集尽可能小或大，再检查各集合容量。

> [容斥原理专题](容斥原理专题.md)

### 6.2 排列与组合

    选择任务
       ↓ 顺序不同算不算不同结果
    算 → 排列
    不算 → 组合

| 限制 | 方法 | 边界 |
| --- | --- | --- |
| 必须相邻 | 捆绑为一个整体 | 整体内部仍可能排列 |
| 不能相邻 | 先排其他对象再插空 | 空位数量要正确 |
| 相同物品分配 | 隔板 | 正整数与非负整数版本不同 |
| 至少一个 | 总数−一个也没有 | 补集更简单时使用 |
| 分类情况 | 分类相加 | 各类必须互斥 |
| 分步过程 | 分步相乘 | 各步共同完成同一结果 |

### 6.3 概率

    等可能概率 = 有利情况数 ÷ 全部情况数
    至少一次 = 1 − 一次也没有

**边界：** 乘法需要事件独立或条件概率正确；不放回抽取前后概率会变化。

> [排列组合与概率专题](排列组合与概率专题.md)

## 七、几何与间隔

### 7.1 平面几何

| 图形 | 周长/面积核心 |
| --- | --- |
| 长方形 | S=ab |
| 三角形 | S=底×高/2 |
| 梯形 | S=(上底+下底)×高/2 |
| 圆 | C=2πr，S=πr² |
| 扇形 | 面积=nπr²/360 |

**关系：** 边长比a:b ⇒ 面积比a²:b²。

**边界：** 周长相等不等于面积相等；同一周长下越接近规则、均衡形状，面积通常越大，具体仍看题设范围。

### 7.2 立体几何

| 图形 | 体积 |
| --- | --- |
| 长方体 | abc |
| 圆柱 | πr²h |
| 圆锥 | πr²h/3 |
| 球 | 4πr³/3 |

**关系：** 相似立体边长比a:b ⇒ 体积比a³:b³。

### 7.3 方阵

- 实心方阵总人数n²；
- 最外层人数4n−4；
- 相邻两层边长相差2，人数通常相差8；
- 空心方阵按外方阵减内方阵，先确认层数。

> [几何问题专题](几何问题专题.md)

### 7.4 植树与间隔

| 场景 | 棵数与间隔数 |
| --- | --- |
| 线段两端都植 | 棵数=间隔数+1 |
| 线段一端植 | 棵数=间隔数 |
| 线段两端都不植 | 棵数=间隔数−1 |
| 封闭一圈 | 棵数=间隔数 |

**同构题：** 锯木、楼梯、钟声、排队、路灯，本质都要判断“点”和“间隔”。

> [植树问题专题](植树问题专题.md)

## 八、最值与统筹

### 8.1 最不利构造

**信号：** “至少多少才能保证”。

    构造尚未达到目标的最坏情况
       ↓
    最坏情况数量 + 1

**边界：** 最不利原则求“保证值”，不是求最小可能值；分类容量不同要分别填满。

### 8.2 构造数列

**信号：** 若干整数、互不相同、和一定，求最大或最小。

**方法：** 要让某个量最大，就让其他受约束量尽量小；随后检查整数、正数、互异、上下界。

### 8.3 和定积最大

两个非负量和一定时，在允许范围内越接近，乘积越大；积一定时越接近，和越小。

**边界：** 有整数、最小值、比例等附加限制时，应在可行范围内取最接近，而不一定精确相等。

> [最值问题专题](最值问题专题.md)

### 8.4 统筹

| 模型 | 原则 | 边界 |
| --- | --- | --- |
| 工序安排 | 可并行则并行，找关键路径 | 有先后依赖的任务不能强行并行 |
| 排队等待 | 短任务优先通常减少总等待 | 有优先级或到达时间时需另算 |
| 烙饼 | 设备槽位尽量满载 | 末轮是否能满载决定下界能否达到 |
| 过桥 | 减少最慢者重复往返 | 返回者选择影响总时间 |
| 货物集中 | 加权中位位置 | 运价、距离规则变化时不能直接套 |

> [统筹问题专题](统筹问题专题.md)

## 九、模型组合

| 组合 | 识别 |
| --- | --- |
| 工程 × 比例 | 先由时间比转效率比，再求合作 |
| 行程 × 几何 | 圆形跑道、折线或最短路径 |
| 利润 × 最值 | 单件利润和销量共同变化 |
| 容斥 × 最值 | 求至少有多少人同时满足 |
| 排列组合 × 概率 | 先数样本空间，再求概率 |
| 浓度 × 加权平均 | 权重为溶液质量 |
| 约数倍数 × 周期 | 多事件再次同时发生 |

## 十、自测

1. 甲6天、乙3天完成同一工程，合作需几天？
2. 两车相向而行和同向追及分别用速度和还是速度差？
3. 成本100元，加价50%后打八折，利润率是多少？
4. 10个头、28只脚，兔有多少只？
5. 两集合人数分别30和25，总人数40，至少同时参加多少人？
6. 从5人中选2人是否考虑顺序？若选班长、副班长呢？
7. 封闭环形道路每隔10米植树，周长100米，需要多少棵？
8. “至少抽多少个才能保证同色”属于什么模型？

### 答案要点

1. 2天。
2. 相向相遇用速度和；同向追及用速度差。
3. 售价120元，利润率20%。
4. 4只。
5. 至少15人，30+25−40。
6. 选2人不分职务用组合；班长、副班长职务不同，用排列。
7. 10棵，封闭图形棵数等于间隔数。
8. 最不利构造或抽屉原理。
