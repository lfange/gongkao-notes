## 二、方法选择图

    看完题干
       ↓
    选项能直接代入？
       ├─ 能 → 代入排除
       └─ 不能
          ├─ 存在明确等量关系 → 方程
          ├─ 只给比例/效率/百分数 → 设份数或特值
          ├─ 数字有整除、余数特征 → 整除与倍数
          ├─ 只需判断个位 → 尾数法
          ├─ 情况互斥且不止一种 → 分类相加
          └─ 连续步骤共同完成 → 分步相乘

### 2.1 通用工具之间的关系

| 工具 | 触发信号 | 与其他工具的关系 |
| --- | --- | --- |
| 代入排除 | 选项是具体数值，关系易验证 | 可结合整除、奇偶先筛选 |
| 方程 | 未知量少，等量关系清楚 | 不定方程常结合整除和代入 |
| 特值 | 只给比例、效率、百分比 | 工程设公倍数，利润设成本 100 |
| 比例份数 | 比例多、绝对量少 | 本质是特值法 |
| 整除倍数 | 人数、件数、周期、分组 | 与约数倍数、不定方程联动 |
| 极端构造 | 至少、保证、最多、最少 | 与最值、容斥、抽屉原理联动 |

> 工具详解见 [速算技巧专题](速算技巧专题.md)。

## 三、速率模型图

### 3.1 工程

    工作总量 W = 效率 P × 时间 T
       ├─ 多人合作 → 效率相加
       ├─ 进水/漏水 → 正负效率相加
       ├─ 中途加入或离开 → 分段计算
       ├─ 交替施工 → 完整周期 + 剩余阶段
       └─ 按劳分配 → 报酬与完成量成比例

**连接节点：** 工程 × 最小公倍数设总量；工程 × 比例份数比较效率。

> [工程问题专题](工程问题专题.md)

### 3.2 行程

    路程 S = 速度 v × 时间 t
       ├─ 相遇 → 速度和
       ├─ 追及 → 速度差
       ├─ 流水 → 船速 ± 水速
       ├─ 环形 → 多走一圈形成追及
       ├─ 往返 → 总路程与相遇次数
       ├─ 火车过桥 → 车长 + 桥长
       └─ 平均速度 → 总路程 ÷ 总时间

**易混：** 等距离平均速度不是速度的算术平均；相同时间的平均速度才可直接按时间加权。

> [行程问题专题](行程问题专题.md)

### 3.3 牛吃草

    原有存量
       + 单位时间新增量
       - 单位时间消耗量
       = 剩余量

    牛吃草
    ├─ 草场生长
    ├─ 水池进出水
    ├─ 检票排队
    └─ 资源开采

**连接节点：** 牛吃草 = 工程效率模型 + 动态增长模型。

> [牛吃草专题](牛吃草专题.md)

### 3.4 浓度

    溶质质量 = 溶液质量 × 浓度
       ├─ 两液混合 → 加权平均 / 十字交叉
       ├─ 加水 → 溶质不变、总量增加
       ├─ 蒸发 → 溶质不变、总量减少
       └─ 倒出再加满 → 溶质按比例递减

**连接节点：** 浓度 × 资料分析平均数；十字交叉本质是加权平均。

> [溶液浓度专题](溶液浓度专题.md)

## 四、基础代数模型图

### 4.1 和差倍比

    总量关系
    ├─ 和一定
    ├─ 差一定
    ├─ 倍数关系
    ├─ 盈亏关系
    └─ 平均数关系

    大数 =（和 + 差）÷ 2
    小数 =（和 - 差）÷ 2

**连接节点：** 和差倍比是利润、年龄、浓度、平均数等题型的代数底座。

> [和差倍比专题](和差倍比专题.md)

### 4.2 年龄

    年龄问题
    ├─ 年龄差永远不变
    ├─ 年龄和按人数同步增加
    ├─ 倍数随时间变化
    └─ 过去/现在/未来用同一时间轴

### 4.3 日期与周期

    日期
    ├─ 一周 7 天 → 总天数求余
    ├─ 平年 365 天 → 星期后移 1
    ├─ 闰年 366 天 → 星期后移 2
    └─ 跨 2 月 29 日须判断闰年

### 4.4 鸡兔同笼

    总头数 + 总脚数
       ↓ 假设全部是鸡
    实际多出的脚数 ÷ 每只兔多出的脚数
       ↓
    兔的数量

> 三类小模型见 [年龄日期鸡兔同笼专题](年龄日期鸡兔同笼专题.md)。

### 4.5 数列与平均数

    数列
    ├─ 等差数列 → 首项 / 末项 / 公差 / 项数 / 和
    ├─ 周期数列 → 项数除以周期长度取余
    └─ 递推数列 → 相邻项关系

    平均数
    ├─ 总量 ÷ 份数
    ├─ 移多补少
    └─ 加权平均

> [数列与平均数专题](数列与平均数专题.md)

## 五、计数模型图

### 5.1 容斥

    至少满足一个
       = 各集合数量之和
       - 重复计算的两两交集
       + 被多减的三者交集

    容斥
    ├─ 两集合
    ├─ 三集合
    ├─ 只满足一个/两个
    └─ 交集最值

**连接节点：** 容斥 × 最值，常考“至少有多少人同时满足”。

> [容斥原理专题](容斥原理专题.md)

### 5.2 排列组合

    计数任务
       ↓
    是否区分顺序？
       ├─ 区分 → 排列
       └─ 不区分 → 组合
          ↓
    限制条件
       ├─ 必须相邻 → 捆绑
       ├─ 不能相邻 → 插空
       ├─ 相同物品分组 → 隔板
       └─ 至少/至多 → 正面分类或反面排除

### 5.3 概率

    等可能古典概率
       = 满足条件的情况数 ÷ 全部情况数

    至少一次
       = 1 - 一次也没有

**连接节点：** 概率以前置的排列组合计数为基础；“独立”是概率相乘的重要条件。

> [排列组合与概率专题](排列组合与概率专题.md)

## 六、空间与边界模型图

### 6.1 几何

    几何
    ├─ 周长
    ├─ 面积
    ├─ 表面积
    ├─ 体积
    ├─ 相似
    └─ 割补

    边长比 a:b
       ⇒ 面积比 a²:b²
       ⇒ 体积比 a³:b³

**连接节点：** 几何 × 和定积最大；几何 × 比例份数；几何 × 最短路径。

> [几何问题专题](几何问题专题.md)

### 6.2 植树与间隔

    线形、两端都植 → 棵数 = 间隔数 + 1
    线形、两端不植 → 棵数 = 间隔数 - 1
    一端植或封闭图形 → 棵数 = 间隔数

> [植树问题专题](植树问题专题.md)

### 6.3 最值

    问“至少多少才能保证”
       ↓
    构造尚未达到目标的最坏情形
       ↓
    最坏情形数量 + 1

    问“某量最大”
       ↓
    让其他受约束量尽量小
       ↓
    检查整数、互异、上下界

> [最值问题专题](最值问题专题.md)

## 七、统筹决策图

    统筹

    └─ 渡河 → 明确船、人和返回条件
