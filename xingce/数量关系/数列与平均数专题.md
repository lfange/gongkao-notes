# 数量关系 · 数列与平均数专题（等差数列、中间项、循环周期、移多补少）

> 等差数列在行测里几乎不考通项，考的是三个"秒杀结论"：**和 = 平均数 × 个数、平均数 = 中间项（奇数个）、连续数差 1**。
> 平均数考"移多补少"和"加权平均"两件事。周期题考"找规律 + 除法"。
> 每个专题结构：**本质 → 公式族 → 方法三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：对称性

等差数列 3, 5, 7, 9, 11 画在数轴上**完全对称**——首尾等距的两项和都相等：

> 3+11 = 5+9 = 2×7 = 14。

对称性推出全部结论：

- **平均数 = 中间项**（奇数个时，正中间那个数就是平均数；偶数个时取中间两项的平均）；
- **和 = 首尾之和 ÷ 2 × 项数**（首尾配对，每对一样大）；
- 连续自然数 1~n 的和 = n(n+1)/2（高斯配对）。

平均数的本质同理：

> 平均数是"移多补少"的平衡点——每人补到平均数，多的总量 = 少的总量。

一句话总结本质：

> **见到"等差/连续/均匀增长"先想中间项，见到"平均"先想平衡点，两者是一回事。**

## 二、公式族（核心速查表）

| 场景 | 公式 / 结论 |
| --- | --- |
| 通项 | aₙ = a₁ + (n−1)d |
| 前 n 项和 | Sₙ = (a₁+aₙ)×n÷2 |
| **奇数个等差** | **和 = 中间项 × 项数**（中间项 = 平均数） |
| 偶数个等差 | 和 = 中间两项之和 ÷ 2 × 项数 |
| 中间项定位 | 第 k 项 = 中间项 ± (离中间的距离)×d |
| 连续自然数 | 1+2+…+n = n(n+1)/2 |
| 奇数列 | 1+3+…+(2n−1) = n² |
| 平均数 | 总量 ÷ 个数；加权平均 = Σ(数值×权重)÷Σ权重 |
| 移多补少 | 多出总量 = 缺少总量 = (平均数−原值)×移动方向 |
| 十字交叉 | 两组混合，组内平均值差之反比 = 两组数量之比 |

## 三、方法三步法（拿到题先走这三步）

1. **识别**：等差/连续？→ 中间项；给平均数、给变化 → 移多补少；出现"周期/循环/每隔"→ 周期问题。
2. **找中间**：等差题先问自己"中间项（平均数）是多少、项数多少"——和 = 中间项×项数一步出。
3. **验证口径**：平均数题注意"对谁平均"（全体/部分）、"单位是什么"（人天、个/次）。

## 四、题型逐个击破

### 题型 1：奇数项等差求和（中间项法）

> 7 个连续奇数和为 217 → 中间项 = 217÷7 = 31（第 4 个），整个数列直接写出来。
> **除得尽就是等差的证据**——和÷项数 = 整数，马上想到中间项法。

### 题型 2：偶数项 / 首尾配对

> 偶数个没有正中间，用"中间两项的和 = 首尾和"。例：8 个连续数和 172 → 中间两项和 = 172÷4 = 43 → 两数为 21、22。

### 题型 3：反求项数 / 中间项

> "从 1 加到几和是 190？" → n(n+1)/2 = 190 → n(n+1) = 380 = 19×20 → n = 19。**n(n+1) 连乘结构，拆成相邻两数相乘**。

### 题型 4：平均数（移多补少）

> "5 人平均分 72，每人加 2 分后平均多少"——别重算总分，**每人同时加 2，平均数就加 2 → 74**。
> "调入一个人后平均分变化"——新平均 × 新人数 − 原平均 × 原人数 = 新来者的分数。

### 题型 5：加权平均（十字交叉）

> 男 30 人平均 80 分、女 20 人平均 85 分 → 总平均 = (30×80+20×85)÷50 = 82。
> 已知总平均反求人数比 → 十字交叉：男:女 = (85−82):(82−80) = 3:2。

### 题型 6：周期循环

> "1, 2, 3, 4, 2, 3, 4, 1, …（循环）第 100 项是什么 / 前 100 项和多少"：
> 1. 找出一个完整周期（长度 L、周期和 S）；
> 2. 100 ÷ L = 整周期数 …… 余 r；
> 3. 总和 = 整周期数×S + 前 r 项之和；第 100 项 = 余 r 对应的位置（余 0 是周期最后一项）。
> 星期/日期循环同理（详见 [年龄日期鸡兔同笼专题.md](年龄日期鸡兔同笼专题.md)）。

## 五、易错点清单

1. **等差题不用中间项硬算**——慢且易错；先除项数找中间。
2. **偶数个没有中间项**，"中间项×项数"不适用，要用"中间两项和÷2×项数"。
3. **移多补少方向反**：调走 x 人后平均上升，别把"调走的平均"当"留下的平均"。
4. **加权平均权重弄反**：离总平均**近**的那组**数量多**（十字交叉的差之反比）。
5. **周期余 0** 表示正好整周期，对应**最后一项**，不是第 0 项。
6. **"连续奇数/偶数"公差是 2**：中间项法照用，但别和"连续自然数"（公差 1）混。
7. **平均速度 ≠ 速度平均**：平均速度 = 总路程÷总时间（详见 [行程问题专题.md](行程问题专题.md)），这是"平均"最大的伪装陷阱。

## 六、精讲例题

### 例题 1（奇数项中间项）

**题**：7 个连续自然数的和是 126，这 7 个数中最小的数是多少？
A. 15　B. 16　C. 17　D. 18

**解析**：

1. 中间项（第 4 个）= 126÷7 = 18。
2. 最小 = 18 − 3 = **15，选 A**。
3. 陷阱：D 是把中间项当最小；等差数列 15,16,17,18,19,20,21 验和 = 126 ✓。

### 例题 2（偶数项配对）

**题**：8 个连续偶数之和为 200，其中最大的偶数是多少？
A. 28　B. 30　C. 32　D. 34

**解析**：

1. 8 项 → 中间两项（第 4、5 个）之和 = 200÷4 = 50 → 两数为 24、26。
2. 最大 = 26 + 3×2 = **32，选 C**。
3. 验算：20,22,24,26,28,30,32,34 → 和 216？——重算：中间两项 24、26，数列为 18,20,22,24,26,28,30,32，和 = (18+32)×8÷2 = 200 ✓，**最大 32 正确**。陷阱：B 是忘加公差 2 只加 4。

### 例题 3（移多补少）

**题**：某班 20 人平均体重 48 千克，小明（50 千克）转走后，平均体重变为多少？
A. 47.5　B. 47.9　C. 48　D. 46.5

**解析**：

1. 剩 19 人体重 = 48×20 − 50 = 910 千克。
2. 平均 = 910÷19 ≈ **47.9，选 B**。
3. 快捷判断：转走的比原平均**重**，剩下的人平均**变轻**（但只轻一点，因为只走 1 人）→ 排除 A、D 这种掉太多的选项。C 是"没变化"的直觉陷阱。

### 例题 4（加权平均 + 十字交叉）

**题**：某班男生平均分 82，女生平均分 88，全班平均分 85。男女生人数之比是多少？
A. 2:3　B. 3:2　C. 1:1　D. 4:3

**解析**：

1. 十字交叉：男生距总平均 85−82 = 3，女生距 88−85 = 3。
2. 男:女 = 3:3 = **1:1，选 C**。
3. 理解：总平均 85 恰是中点 → 人数相等才能拉平。**总平均偏向人多的那组**——看到平均在中点，直接答 1:1。

### 例题 5（周期循环）

**题**：数列 3, 1, 4, 1, 5, 9, 3, 1, 4, 1, 5, 9, …以 6 项为周期循环。前 20 项之和是多少？
A. 69　B. 71　C. 73　D. 75

**解析**：

1. 周期和 = 3+1+4+1+5+9 = 23。
2. 20 ÷ 6 = 3 个整周期（18 项）……余 2 → 前 2 项 = 3+1 = 4。
3. 总和 = 3×23+4 = **73，选 C**。
4. 陷阱：A 是 3×23 只算整周期忘加余项。**"整周期×周期和 + 余项"两步都不能少；余 0 时余项按 0 算、末项取周期最后一项。**

### 例题 6（等差 + 反求）

**题**：一堆钢管最上层 5 根，每层比上一层多 2 根，共 8 层。这堆钢管共多少根？
A. 88　B. 90　C. 96　D. 100

**解析**：

1. 首项 5，公差 2，8 层 → 末项 = 5 + (8−1)×2 = 19。
2. 和 = (5+19)×8÷2 = **96，选 C**。
3. 陷阱：A 的 88 是末项按 17 算（公差少乘一层，末项 = 5+(8−2)×2 的错法）。**层垛问题 = 等差数列求和，先求末项再首尾配对。**

## 七、自测练习

1. 9 个连续自然数的和是 207，最大的数是多少？
2. 5 个连续偶数之和为 90，求这 5 个数。
3. 从 1 加到 n 的和为 210，n 是多少？
4. 某次考试 6 人平均 75 分，加入 1 人后平均提高 1 分，加入的人考了多少分？
5. 数列 2, 0, 2, 4, 2, 0, 2, 4, …（周期 4）第 2026 项是多少？前 2026 项之和是多少？

### 答案附录

1. 中间项 = 207÷9 = 23 → 最大 = 23+4 = **27**。
2. 中间项 = 90÷5 = 18 → 五数为 **14, 16, 18, 20, 22**。
3. n(n+1)/2 = 210 → n(n+1) = 420 = 20×21 → **n = 20**。
4. 新总分 = 76×7 = 532，原总分 = 450 → 新来者 = **82 分**。
5. 2026÷4 = 506 余 2 → 第 2026 项是周期第 2 项 = **0**；周期和 = 8 → 总和 = 506×8+2 = **4050**（前 2 项 2+0 = 2）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **方法错**：等差题硬算不用中间项/配对；
- **口径错**：偶数项乱用中间项、加权权重方向反、对错对象求平均；
- **周期错**：余数对应位置错、余 0 没当成最后一项、只算整周期忘加余项；
- **变形错**：没认出"平均速度""层垛"背后是同一套数列模型。
