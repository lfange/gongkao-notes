# 数量关系 · 速算技巧专题（代入排除、特值、整除、比例份数）

> 数量关系 15 题里，真正需要"从头解出答案"的不到一半——其余靠**数字特性 + 选项反向操作**就能锁死。
> 核心心法一句话：**选择题的答案就写在选项里，先看选项，再决定要不要算。**
> 专题结构：**本质 → 技巧总览 → 判断三步法 → 技巧逐个讲透 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。各技巧在具体题型里的应用见对应专题（工程 / 行程 / 利润 / 溶液 / 和差倍比）。

---

## 一、本质：题干和选项都是已知条件

硬解的思路是"题干 → 方程 → 解 → 对选项"；速算的思路是**"选项 → 代回题干验证 / 用数字特性先杀掉几个"**。两者关系不是替代，是**过滤器**：

| 过滤器 | 杀掉什么 | 成本 |
| --- | --- | --- |
| 整除 / 倍数 / 奇偶 | 不满足数字特性的选项 | 5 秒 |
| 尾数 | 末位对不上的选项 | 5 秒 |
| 估算范围 | 数量级 / 大小明显不对的选项 | 10 秒 |
| 代入验证 | 逐个排到只剩一个 | 每项 15 秒 |

四个过滤器走完还剩两个选项，再动笔算——**此时计算量已经减半，且知道答案长什么样**。

## 二、技巧总览（六把刀速查表）

| 刀 | 识别信号 | 一句话要领 |
| --- | --- | --- |
| ① 代入排除 | 选项是具体数值；问"xx 是多少/几个" | 挑好算的先代，问"最大"从大往小代 |
| ② 整除特性 | 出现 3/4/5/8/9 等因子、"每""平均""倍数" | 答案必被某数整除，先排选项 |
| ③ 倍数特性 | "甲是乙的 3/5"这类分数关系 | 甲是 3 的倍数、乙是 5 的倍数、和是 8、差是 2 |
| ④ 尾数法 | 加、减、乘、平方求和 | 只算末一位，除法无效 |
| ⑤ 特值法 | 题干全是比例/分数/百分数，无具体值 | 设最小公倍数 / 设 100 / 设 1 |
| ⑥ 比例份数 | 给出 a:b = m:n | 按份设数，"差 1 份"对应实际差 |

> 十字交叉（溶液 / 平均分 / 混合增长率）见 [溶液浓度专题.md](溶液浓度专题.md) 与 [../资料分析/混合增长专题.md](../资料分析/混合增长专题.md)；除法类速算（截位直除等）见 [../资料分析/速算方法专题.md](../资料分析/速算方法专题.md)。

## 三、判断三步法（拿到题先走这三步）

1. **看选项**：是具体数值还是"约/无法确定"？四个数的尾数、整除特征、数量级有没有明显差异？——**读题前先扫一眼选项，这一眼决定用哪把刀**。
2. **看题干关键词**：分数/百分数/比例（→ 特值或份数）；"每 X 人一组""平均""是…的几倍"（→ 整除）；"共花多少元、买了两种东西"（→ 不定方程）；多位数加减乘（→ 尾数）。
3. **排完再算**：过滤器杀不完的，用剩下的 1~2 个选项反代验证；都不顺手才列方程。

## 四、技巧逐个讲透

### 刀 1：代入排除（第一刀，永远先想它）

**适用**：选项是具体数值，且代回验证比正面解快（多位数、余数、年龄、不定方程类）。

**代入顺序**：
- 问"最大/最多"→ 从最大的选项开始代（题目常问"最大是多少"，答案偏好大端）；
- 问"最小/至少"→ 从最小的开始；
- 选项数字有奇偶/整除差异 → 先代满足特性的；
- 没有明显偏好 → 代 B 或 C（中间值，一次代入往往能顺带判断方向）。

**纪律**：验证**必须完整**（题干每个条件都过一遍），杀掉一个立刻代下一个——代入排除的失败案例几乎都是"代了一个觉得差不多就选了"。

### 刀 2：整除特性（5 秒杀选项）

题干出现这些信号，答案必带对应因子：

| 信号 | 结论 |
| --- | --- |
| 每 4 人一组（恰好分完） | 总数是 4 的倍数 |
| 每 5 人一组多 3 人 | 总数 **减 3** 是 5 的倍数（"多 3"就先减 3） |
| 平均分成 6 组 | 总数是 6 的倍数 |
| 男生占 3/7 | 总数是 7 的倍数，男生是 3 的倍数 |
| 单价 8 元、共花整十数 | 件数与 8 的乘积 → 尾数必为 0/8/6/4/2 循环 |

**余数问题的通用转化**："除以 a 余 r" ⇔ "N − r 是 a 的倍数"。除以 4 余 1、除以 5 余 3 → N−1 是 4 的倍数**且** N−3 是 5 的倍数，在选项里找同时满足的。

### 刀 3：倍数特性（分数关系的身份证）

**"甲 = 3/5 × 乙"（甲:乙 = 3:5）一句话拆四条**：

- 甲是 **3** 的倍数；乙是 **5** 的倍数；
- 甲 + 乙是 **8** 的倍数；乙 − 甲是 **2** 的倍数。

四条里随便哪条能排选项就先用哪条。**这是"和差倍比"类题的秒杀开关**（详见 [和差倍比专题.md](和差倍比专题.md)）。

### 刀 4：尾数法

加减、乘法、平方都尾数守恒（除法不守恒！）：

- 平方尾数表：0²→0，1²→1，2²→**4**，3²→**9**，4²→**6**，5²→**5**，6²→6，7²→9，8²→4，9²→1（尾数关于 5 对称）；
- 例：2023² 尾数 9，2024² 尾数 6，2023²+2024² 尾数 9+6 = **15 → 5**；
- "1²+2²+…+10²"这类求和，只加十个尾数，答案末位立现。

### 刀 5：特值法（题干没有具体值，就自己造）

**适用信号**：题干只有分数、百分数、比例、倍数，从头到尾没有一个具体数量；或问的也是比例/百分数。

**设什么**（三选一，按顺序想）：

| 设法 | 场景 | 例 |
| --- | --- | --- |
| 设**最小公倍数** | 出现"甲 12 天完成、乙 18 天完成" | 总量设 36，效率变整数 |
| 设 **100** | 成本、定价、折扣类利润题 | 成本 100 元，加价 20% → 120 |
| 设 **1** | "任意""每一份"、纯倍率传递 | "总量为单位 1" |

特值法是 [工程问题专题.md](工程问题专题.md)、[利润问题专题.md](利润问题专题.md) 的主力，此处不展开，只立原则：**设完之后所有量都该是整数——出现分数说明设错了**。

### 刀 6：比例份数（把比当"份数"用）

a:b = 3:5 不是两个字母，是**两堆份数**。核心动作：

- **按份设数**：设甲 3k、乙 5k，k 是"一份"；
- **一份 = 实际量 ÷ 份数**："乙比甲多 40" → 2 份 = 40 → 1 份 = 20 → 甲 60、乙 100；
- **同量反比**：路程相同，速度比 4:5 ⇒ 时间比 **5:4**；总量相同，效率比 3:4 ⇒ 时间比 4:3（**谁快谁省份数**）。

行程比例应用见 [行程问题专题.md](行程问题专题.md)。

### 兜底：方程法 + 不定方程

以上全不顺手 → 老实设 x。**不定方程**（未知数多于方程）是整除/奇偶的主战场：

> 例：7x + 4y = 29（x、y 正整数）。两边 mod 4：7x ≡ 29 ≡ 1（mod 4）→ 3x ≡ 1 → **x ≡ 3（mod 4）**→ x = 3，代回 y = 2。

套路固定：**用系数的余数特性锁定一个未知数，再代回**。奇偶性同理：4x + 3y = 24 中 4x、24 均为偶 → 3y 偶 → y 偶。

## 五、易错点清单

1. **特值设出分数**（设 1 而非最小公倍数）——设完先检查是否全整数。
2. **代入不验完**：只对了一个条件就选，掉进"半对陷阱"。
3. **倍数特性记不全**：和 (m+n)、差 (n−m) 的倍数关系最容易漏。
4. **尾数法用在除法**——除法尾数不守恒。
5. **同量反比搞反**：速度比 4:5，时间比是 5:4，不是 4:5。
6. **"多 r 人"忘减 r**：每 5 人一组多 3 → N−3 是 5 的倍数，不是 N+3。
7. **代入顺序乱**：问"最大"却从小代起，多代两次白耗 30 秒。
8. 不定方程解完不代回原方程验算（mod 运算手滑很常见）。

## 六、精讲例题

### 例题 1（代入排除：多位数）

**题**：一个三位数，各位数字之和为 16，十位数字等于百位与个位之和，这个三位数是：
A. 169　B. 187　C. 754　D. 891

**解析**：

1. 先扫选项（数字和秒算）：A：1+6+9 = 16 ✓；B：1+8+7 = 16 ✓；C：7+5+4 = 16 ✓；D：8+9+1 = 18 ✗ —— 第一刀只杀掉 D。
2. 验第二个条件"十位 = 百位 + 个位"：A：6 ≠ 1+9 ✗；B：8 = 1+7 ✓ → **选 B**。
3. 深度：两个条件分两层过滤，第一层（数字和）口算 5 秒，第二层只剩 3 个候选——**代入排除的本质就是"用条件分层筛"**。

### 例题 2（整除特性：分组余数）

**题**：某班学生 30~50 人，每 5 人一组多 3 人，每 7 人一组也多 3 人。该班有多少人？
A. 33　B. 36　C. 38　D. 43

**解析**：

1. "每 5 人一组多 3" → N − 3 是 5 的倍数；"每 7 人一组多 3" → N − 3 是 7 的倍数 → **N − 3 是 35 的倍数**。
2. N ∈ [30, 50] → N − 3 ∈ [27, 47] → 只有 35 → N = **38，选 C**。
3. 验算：38 = 5×7+3 ✓ = 7×5+3 ✓。两种分法余数相同，差 3 再找公倍数，**10 秒内完事**。

### 例题 3（倍数特性：四条身份证）

**题**：甲、乙两个仓库共有货物 480 吨，甲仓库存货是乙仓库的 3/5。甲仓库存货多少吨？
A. 160　B. 180　C. 280　D. 300

**解析**：

1. 甲:乙 = 3:5 → 甲是 3 的倍数：A（160÷3 ✗）、C（280÷3 ✗）出局，剩 B、D。
2. 再验"乙是 5 的倍数"：B → 乙 = 300 ✓；D → 乙 = 180，180÷5 ✗ 出局 → **选 B**。
3. 深度：本题正面解（480×3/8）也就一步，但**倍数特性在题目数字更丑时优势巨大**——两条特性筛完，根本不用算。四条身份证（甲 3、乙 5、和 8、差 2）至少有一条能对上选项差异。

### 例题 4（尾数法：平方求和）

**题**：1² + 2² + 3² + … + 10² = ?
A. 375　B. 380　C. 385　D. 390

**解析**：

1. 尾数依次为 1, 4, 9, 6, 5, 6, 9, 4, 1, 0，尾数和 = 45 → 答案尾数 **5**。
2. 四个选项只有 C（385）尾数 5 → **选 C**。
3. 深度：平方尾数表（尾数 0~9 → 0,1,4,9,6,5,6,9,4,1）要形成条件反射；尾数法对"求和、求大数乘积"类题是零成本一刀。

### 例题 5（特值法：利润率）

**题**：某商品按成本价加价 20% 定价，销售不畅后按定价的 8 折出售。最终盈亏情况是：
A. 盈利 4%　B. 亏损 4%　C. 亏损 20%　D. 不盈不亏

**解析**：

1. 题干无任何具体值 → 设成本 **100 元**。
2. 定价 = 100×1.2 = 120；售价 = 120×0.8 = 96。
3. 利润率 = (96 − 100)/100 = **−4%，亏损 4%，选 B**。
4. 深度：**"加价 20% 再打 8 折"= ×1.2×0.8 = ×0.96，恒亏 4%**——系数连乘一眼出答案，设 100 的意义就是让百分数现出原形。

### 例题 6（特值法：工程）

**题**：一项工程，甲队单独做 12 天完成，乙队单独做 18 天完成。两队合作需几天完成？
A. 7　B. 7.2　C. 7.5　D. 8

**解析**：

1. 设总量 = 12 和 18 的最小公倍数 **36**。
2. 甲效率 3/天、乙效率 2/天 → 合作 5/天 → 36÷5 = **7.2 天，选 B**。
3. 深度：**"单独 a 天、b 天"必设总量为 lcm(a, b)**，效率全变整数；设 1 会得到 1/12 + 1/18 再通分，慢一倍还易错。（详见 [工程问题专题.md](工程问题专题.md)。）

### 例题 7（比例份数：行程同量反比）

**题**：快车与慢车行驶同一段路，速度比 4:5。慢车比快车多用 30 分钟。快车用了多久？
A. 1.5 小时　B. 2 小时　C. 2.5 小时　D. 3 小时

**解析**：

1. 路程相同 → 时间比 = 速度比的反比：慢:快 = **5:4**。
2. 慢车比快车多 1 份 → 1 份 = 30 分钟。
3. 快车 4 份 = 120 分钟 = **2 小时，选 B**。
4. 深度：全程没出现"速度是多少 km/h、路程是多少 km"——**同量反比 + 份数差**两步收工。同量反比写反（4:5）会得 1.5 小时，恰是 A。

### 例题 8（不定方程：整除锁定）

**题**：钢笔 7 元一支，笔记本 4 元一本。小明恰好花 29 元买了若干支钢笔和若干本笔记本（均至少 1 件），他买了：
A. 3 支钢笔、2 本笔记本
B. 2 支钢笔、4 本笔记本
C. 4 支钢笔、1 本笔记本
D. 1 支钢笔、5 本笔记本

**解析**：

1. 列式：7x + 4y = 29。两边 mod 4：7x ≡ 29 ≡ 1（mod 4）→ 3x ≡ 1 → **x ≡ 3（mod 4）**。
2. x ≥ 1 且 7x < 29 → x ≤ 4 → x = 3 → y = (29−21)/4 = 2 → **选 A**。
3. 交叉验证（代入排除同样到达）：A：21+8 = 29 ✓；B：14+16 = 30 ✗；C：28+4 = 32 ✗；D：7+20 = 27 ✗。
4. 深度：不定方程**用 mod 锁定一个变量**是通法；选项又小又少时直接逐项代和更快——两把刀都认识，考场上哪个顺手用哪个。

## 七、自测练习

1. 一个数除以 4 余 1，除以 5 余 3。这个数可能是：13、17、21、23 中的哪个？
2. 甲的钱是乙的 5/8，两人共有 260 元。甲有多少元？（用倍数特性先筛再算）
3. 1³ + 2³ + 3³ + 4³ + 5³ 的值的尾数是几？
4. 一项工程甲单独 10 天、乙单独 15 天完成。两队合作几天完成？
5. 师徒两人产量比 3:4，徒弟比师傅少加工 60 件。师傅加工多少件？
6. 5x + 3y = 44（x、y 为正整数）。x 最大是多少？

### 答案附录

1. **13**。条件一"N−1 是 4 的倍数"：12 ✓、16 ✓、20 ✓、22 ✗（23 出局）；条件二"N−3 是 5 的倍数"：10 ✓、14 ✗（17 出局）、18 ✗（21 出局）→ 只剩 **13**（13 = 4×3+1 = 5×2+3 ✓）。
2. 甲:乙 = 5:8 → 甲是 5 的倍数、总和 260 是 13 的倍数 → 甲 = 260×5/13 = **100 元**。
3. 尾数：1 + 8 + 7(27) + 4(64) + 5(125) → 1+8+7+4+5 = 25 → 尾数 **5**。
4. 设总量 30 → 甲 3、乙 2 → 合作 5/天 → **6 天**。
5. 差 1 份 = 60 → 1 份 = 60 → 师傅 4 份 = **240 件**。
6. y 尽量小：y = 3 → 44−9 = 35 → x = 7；y = 1 → 41 ÷ 5 ✗ → **x 最大 = 7**（5×7+3×3 = 44 ✓）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **选刀错**：能整除秒杀的题硬列了方程（慢），或该列方程的硬代（更慢）；
- **特性错**：倍数/整除特性记漏（和、差的倍数），余数忘减余数；
- **特值错**：设出分数、设 100 用在非百分数场景；
- **验证错**：代入没验完所有条件、不定方程 mod 运算手滑没代回验算。
