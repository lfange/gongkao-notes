# 数量关系 · 溶液浓度专题（混合、十字交叉、反复倒加、蒸发加水）

> 溶液问题的全部秘密就一个公式：**浓度 = 溶质 ÷ 溶液**。
> 不管怎么倒、怎么加、怎么混合，**死盯"溶质"这个量**——多数变化里溶质不变或按规则变化，抓住它题目就解完了。
> 每个专题结构：**本质 → 公式族 → 方法三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：盯溶质

一杯盐水 = 盐（溶质）+ 水（溶剂），合起来是盐水（溶液）。

> **浓度 = 溶质 ÷ 溶液 ×100%，溶液 = 溶质 + 溶剂。**

所有变化分三类，每类的"溶质动向"固定：

1. **混合**：溶质相加、溶液相加——混合浓度 = 溶质之和 ÷ 溶液之和；
2. **加水 / 蒸发**：溶质**不变**，溶液变——浓度被"稀释或浓缩"的方向改变；
3. **倒出一部分再补满**（倒掉盐水加水加满）：剩下的溶质按比例减少，加回的是纯水（溶质为 0）。

一句话总结本质：

> **问浓度，先找溶质和溶液分别怎么变；溶质守恒的（加水、蒸发）最好做，溶质变的（倒出、混合）就追踪它变了多少。**

## 二、公式族（核心速查表）

| 场景 | 公式 / 结论 |
| --- | --- |
| 基本定义 | 浓度 = 溶质÷溶液，溶液 = 溶质+溶剂 |
| 两种溶液混合 | 混合浓度 = (C₁m₁ + C₂m₂) ÷ (m₁+m₂)，**必介于 C₁、C₂ 之间** |
| 十字交叉 | 两溶液质量比 = 浓度差之反比（见下） |
| 加水稀释 | 溶质不变：加水后浓度 = 原溶质 ÷ 新溶液总量 |
| 蒸发浓缩 | 溶质不变：蒸发后浓度 = 原溶质 ÷ 剩余溶液 |
| 反复倒加 | 每倒出 a、加满水，浓度 ×(1 − a/V)（V 为总量） |

**十字交叉法**（混合题的快刀）：

浓度为 30% 的溶液和 20% 的溶液混合成 24% 的溶液，求质量比：

```
      30% ┐           ┌ 24% − 20% = 4   （20% 溶液的质量权重）
          ├ 24% ──────┤
      20% ┘           └ 30% − 24% = 6   （30% 溶液的质量权重）
```

> 谁离混合浓度"远"，谁占的分量小——**交叉作差，差大的那边质量小**，质量比 = 对面差之比。本例 30% 液 : 20% 液 = 4 : 6 = 2 : 3。

适用范围：**任何"加权平均"**——平均分、混合增长率、平均价格都行，不止溶液。

## 三、方法三步法（拿到题先走这三步）

1. **定类型**：混合？加水/蒸发？倒出补满？——类型决定溶质怎么处理。
2. **算溶质**：把变化前后"溶质是多少"分别写出来（这是唯一需要动脑的一步）。
3. **套公式**：浓度 = 溶质÷溶液；混合题先看"答案是否在两种浓度之间"，再用十字交叉或直接算。

> 检验神器：**混合浓度必须介于两原浓度之间**。算出 40% 和 10% 混出 55%，立刻推翻重算。

## 四、题型逐个击破

### 题型 1：简单混合

> 甲溶液 m₁ 克浓度 C₁，乙 m₂ 克浓度 C₂ → 混合浓度 = (C₁m₁+C₂m₂)÷(m₁+m₂)。两数加权平均，没有捷径但绝不出错。

### 题型 2：混合求比例（十字交叉主场）

> 已知两浓度和目标浓度，求质量比——十字交叉 10 秒出。注意**求出的是"两溶液的质量比"**，若问"加入多少克水"，把水看成浓度 0% 的溶液再交叉。

### 题型 3：加水 / 蒸发（溶质不变）

> "加水 50 克浓度从 20% 变 15%"——溶质始终 = 原 20%×原溶液。用"溶质不变"列方程前后两次：溶质 = 20%×原 = 15%×(原+50)。
> 快捷理解：溶质一定时，**浓度与溶液总量成反比**——浓度 20%→15% 缩为 3/4，总量扩为 4/3，加的 50 克对应 1/3 份 → 原溶液 150 克。

### 题型 4：倒出再加满（等量稀释）

> 每次倒出 a 克再加满水：溶液总量不变（还是 V），溶质剩原来的 (1 − a/V)。
> **倒两次浓度 = 原浓度 ×(1−a/V)²**——幂次 = 倒的次数，这是本专题最"像难题"的送分点。
> 例：200 克 30% 盐水，倒出 40 克加满水，再倒出 40 克加满水 → 30%×(1−40/200)² = 30%×0.8² = 19.2%。

### 题型 5：加溶质（加盐/加糖）

> 加糖 m 克：溶质 +m，溶液 +m（糖既算溶质也算溶液总量）。想"变浓多少"老老实实列两个浓度。

### 题型 6：多次混合 / 交换

> 甲倒给乙、乙再倒回甲同量……浓度不变型结论：**来回倒等量且总量各自不变时，甲失掉的溶质 = 乙倒回来的溶质**（终态浓度可列守恒方程）。考得少，遇到先列"溶质守恒"方程再说。

## 五、易错点清单

1. **溶液 ≠ 溶剂**：100 克 20% 盐水里水是 80 克——别拿水当溶液去除。
2. **混合浓度不在两浓度之间** → 一定算错，先自检。
3. **十字交叉得出的是质量比（份数比）**，不是"各加多少"；问加水量把水当 0% 浓度参与交叉。
4. **倒 a 克加满，浓度乘 (1−a/V) 而不是减 a/V**：减的是"溶质的比例"，不是浓度绝对值。
5. **倒两次忘平方**、倒三次忘立方——幂次 = 次数。
6. **加水题忘算"加进来的水也进分母"**：新溶液 = 原溶液 + 加水量。
7. **百分比和克数混算**：统一成"克"（30% × 200 克 = 60 克盐）再运算。
8. **"含盐率""浓度"换汤不换药**，酒精、糖水、药液全是同一套。

## 六、精讲例题

### 例题 1（简单混合）

**题**：300 克 20% 的盐水与 200 克 35% 的盐水混合，浓度是多少？
A. 25%　B. 26%　C. 27.5%　D. 30%

**解析**：

1. 溶质 = 300×20% + 200×35% = 60+70 = 130 克；溶液 = 500 克。
2. 浓度 = 130÷500 = **26%，选 B**。
3. 检验：26% 在 20%~35% 之间 ✓。陷阱：A 是 (20%+35%)÷2 的简单平均（只有质量相等才成立）；本题质量不等，加权平均偏向质量大的一侧（20%），所以 26% < 27.5%（中点），方向也对。

### 例题 2（十字交叉求比例）

**题**：用浓度 45% 和 15% 的酒精配出 100 克浓度 30% 的酒精，需 45% 的多少克？
A. 40　B. 50　C. 60　D. 70

**解析**：

1. 十字交叉：45% 与 15% 配 30% → 45%液 : 15%液 = (30−15) : (45−30) = 15:15 = **1:1**。
2. 100 克按 1:1 → 各 50 克，**选 B**。
3. 快速直觉：30% 恰是两浓度的中点 → 必然等质量混合。**看到目标浓度是中点，直接对半分。**

### 例题 3（加水稀释）

**题**：一瓶盐水 400 克，浓度 25%。加水多少克后浓度变为 20%？
A. 60　B. 80　C. 100　D. 120

**解析**：

1. 溶质不变 = 400×25% = 100 克。
2. 目标浓度 20% → 新溶液 = 100÷20% = 500 克。
3. 加水 = 500−400 = **100 克，选 C**。
4. 反比快捷：浓度 25%→20% 为 5:4，总量 4:5 → 原 400 对应"4 份"，加的是 1 份 = 100 ✓。

### 例题 4（反复倒加，平方陷阱）

**题**：容器内有 200 克浓度 40% 的盐水，倒出 50 克后加满水搅匀，再倒出 50 克再加满。最终浓度？
A. 22.5%　B. 25%　C. 27.5%　D. 30%

**解析**：

1. 每次倒出 50（占总量 1/4）→ 浓度每次 ×(1−1/4) = ×3/4。
2. 两次：40%×(3/4)² = 40%×9/16 = **22.5%，选 A**。
3. 陷阱：B 是只乘一次 3/4（30% 也常见于此）；D 是 40%−2×(40%×1/4) 的"减法"误解。**幂次 = 倒的次数，乘法不改减法。**

### 例题 5（加溶质）

**题**：300 克 10% 的糖水，加多少克糖后浓度变为 25%？
A. 45　B. 50　C. 55　D. 60

**解析**：

1. 设加 x 克：溶质 = 30+x，溶液 = 300+x。
2. (30+x)÷(300+x) = 25% → 30+x = 75+0.25x → 0.75x = 45 → x = **60，选 D**。
3. 陷阱：B 是 300×(25%−10%)，把"浓度差×原溶液"当加糖量——糖加进去分母也变大，**必须列方程**。

### 例题 6（倒加 + 混合综合）

**题**：1000 克 20% 的盐水，倒出 200 克后，再往剩余溶液中加入 50 克盐，浓度变为多少？
A. 25%　B. 26%　C. 27.5%　D. 30%

**解析**：

1. 倒出 200 克（1/5）：剩余 800 克、浓度仍 20%（倒出的和剩的浓度相同！）→ 溶质 = 160 克。
   > 倒出搅匀溶液，浓度不变，溶质按比例剩——这是很多同学卡住的一步。
2. 加 50 克盐：溶质 = 160+50 = 210，溶液 = 800+50 = 850。
3. 浓度 = 210÷850 ≈ **24.7%≈25%，选 A**。

## 七、自测练习

1. 500 克 12% 的盐水含盐多少克？
2. 把 25% 的盐水 300 克加水稀释成 15%，需加水多少克？
3. 浓度 60% 与 10% 的酒混合成 40% 的酒 500 克，两种酒各多少克？
4. 一杯 250 克 32% 的糖水，倒出 50 克加满水，再倒出 50 克加满水，浓度变为多少？
5. 甲容器 300 克盐水浓度 20%，乙容器 200 克盐水浓度 40%，混合后浓度是多少？

### 答案附录

1. 500×12% = **60 克**。
2. 溶质 = 75 克；新溶液 = 75÷15% = 500 克；加水 = 500−300 = **200 克**。
3. 十字交叉：60%液 : 10%液 = (40−10):(60−40) = 3:2 → 60% 的 **300 克**、10% 的 **200 克**。
4. 每次乘 (1−50/250) = 4/5：32%×(4/5)² = **20.48%**。
5. (300×20%+200×40%)÷500 = 140÷500 = **28%**（介于 20%~40% ✓，且偏向质量大的 20% 侧）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **对象错**：拿溶剂当溶液、把浓度差当溶质量；
- **模型错**：加水/蒸发没抓溶质不变，倒加没用乘 (1−a/V)，幂次漏乘；
- **方法错**：质量不等的混合用简单平均，该列方程的加溶质题硬凑；
- **检验漏**：没检查"混合浓度在两浓度之间"。
