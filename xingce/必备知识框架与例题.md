# 行测必备知识框架与例题

> 这不是题型细节的重复堆砌，而是一张“先学什么、后练什么、遇题如何调用”的总地图。
> 文中例题均为自编练习，用于说明方法，不标作真题。各模块题量、时限和具体表述以当年目标考试大纲与真题为准。
> 理解本篇后，可用 [必背公式与规则总册](../必公.md#六政治理论常识与申论必备知识点) 集中背诵公式、政治理论、常识和申论规范表达。

## 一、先建立行测的总逻辑

六个模块看似分散，其实都在考同一条能力链：

> **读准任务 → 提取有效信息 → 识别关系 → 调用规则 → 排除干扰 → 在时限内作答**

| 模块 | 题目表面 | 底层任务 | 一句话解题链 |
| --- | --- | --- | --- |
| 政治理论 | 理论、政策、时政 | 辨明概念层级和适用情境 | 定位概念组 → 抓主要矛盾 → 排除张冠李戴 |
| 常识判断 | 法律、经济、人文、科技、地理 | 在广博知识中核对规则与边界 | 定学科 → 抓限定词 → 用确定知识排除 |
| 言语理解 | 词语、句子、文段 | 判断语境与行文意图 | 看提问 → 找话题 → 辨结构 → 比对选项 |
| 判断推理 | 图形、定义、词项、论证 | 发现稳定关系并检验 | 定题型 → 列条件 → 找关系 → 代回验证 |
| 数量关系 | 文字应用题 | 把情境翻译成数学模型 | 找等量 → 选方法 → 算结果 → 验范围 |
| 资料分析 | 文字、表格、图形数据 | 在统计口径下快速比较和计算 | 找口径 → 判现期/基期 → 列式 → 估算验量级 |

### 所有模块通用的三个习惯

1. **先看问法。** “能够推出”与“不能推出”、“最能削弱”与“不能削弱”只差一个词，任务却相反。
2. **先判类，后调公式。** 看到“每”不一定是平均数，看到“因此”也不等于论点必在其后；先判断问题在考什么。
3. **让错题回到“错因”。** 错因至少分成：概念不清、题型误判、定位错误、计算失误、选项陷阱、时间取舍。只记正确答案无法阻止重复犯错。

## 二、政治理论：用“层级—问题—举措”组织概念

### 2.1 必备框架

遇到理论或政策概念，先把它放入正确的“抽屉”：

- **目标层：** 要实现什么，注意时间节点和“基本实现/建成”等程度词。
- **布局层：** 从哪些领域整体推进，不要把总体布局、战略布局、发展理念混成同一组。
- **方法层：** 怎样认识和解决问题，看题干是否突出系统、问题、实践、人民等角度。
- **理念层：** 举措主要解决动力、不平衡、人与自然、内外联动还是公平共享问题。
- **政策层：** 记清发布主体、文件名称、发布时间、适用范围，把“目标”与“已完成成就”分开。

详细概念辨析见 [政治理论专题](政治理论/专题.md)。

### 2.2 例题

**题目：** 某地将乡村学校、县城医院和城市优质资源联网，建立远程课堂、远程会诊和师资轮岗机制，着力缩小城乡公共服务差距。该举措最直接体现的发展理念是：

A. 创新　B. 协调　C. 绿色　D. 开放

**思路：** 题干虽然出现“联网”这一新手段，但目标是缩小城乡差距，主要解决发展不平衡问题。

**答案：** B。

**易错点：** 不能按单个工具词选答案；要问“这项举措主要在解决什么问题”。

## 三、常识判断：知识要成系统，选项要抓边界

### 3.1 五个学科的主干

| 分区 | 必备主干 | 常见辨析角度 |
| --- | --- | --- |
| 法律 | 法律位阶、权利义务、责任要件、程序与救济 | 主体、年龄、故意/过失、一般/例外、现行时点 |
| 经济 | 供求与价格、宏观指标、财政政策、货币政策 | 总量/增速、名义/实际、扩张/紧缩、直接/间接影响 |
| 人文 | 历史时序、作者作品、思想流派、制度沿革 | 人物与时代是否对应，作品与作者是否对应 |
| 科技 | 物理化学原理、生命健康、天文航天、信息技术 | 现象与原理是否对应，必要条件是否缺失 |
| 地理 | 经纬度、地形气候、河流资源、中国区域 | 空间位置、上下游、迎风/背风、季节和时间 |

**记忆单元：** 不只记一句结论，而要记成“**对象 + 规则 + 条件 + 例外 + 时点**”。涉及新法、新政策、统计数据和时政的内容，使用前须按 [法律与时政更新清单](../计划/法律与时政更新清单.md) 核验。

### 3.2 例题

**题目：** 下列生活现象与所涉及的物理原理对应正确的是：

A. 高压锅更快煮熟食物——气压越高，水的沸点越低  
B. 冬天玻璃窗内侧出现水珠——室内水蒸气遇冷液化  
C. 照镜子看到虚像——光的折射  
D. 湿衣服在通风处干得快——空气流动降低了水的沸点

**思路：** 逐项校验“现象—原理”关系。高压使沸点升高；平面镜成像主要是光的反射；通风加快表面空气更新，促进蒸发。

**答案：** B。

**易错点：** 觉得现象“熟悉”不等于原理表述正确，要检查方向词和因果链。

## 四、言语理解：从“句子感觉”转向“语境证据”

### 4.1 题型树

    言语理解
    ├─ 逻辑填空：语境关系 → 词义侧重 → 搭配色彩
    ├─ 片段阅读
    │  ├─ 主旨/意图：话题 → 结构 → 中心句 → 同义替换
    │  └─ 细节判断：定位 → 比对 → 排查偷换
    └─ 语句表达
       ├─ 语句排序：首句 → 捆绑 → 顺序 → 验证
       └─ 语句填空/下文推断：上承 → 下启 → 话题一致

### 4.2 四个核心知识点

1. **关联词定关系：** 转折看转折后，因果找结论，并列须全面概括，必要条件注意“只有……才……”。
2. **行文结构定重点：** 问题—对策通常重在对策；观点—例子通常重在观点；并列结构要概括全部分支。
3. **选项要与原文同等强度：** “可能”不能换成“必然”，“部分”不能换成“全部”，“条件之一”不能换成“唯一原因”。
4. **填空不只比词义：** 先用关联关系确定空格方向，再比对侧重、对象、语体、感情色彩和固定搭配。

详见 [言语理解核心总纲](言语理解/知识点.md)。

### 4.3 例题：主旨概括

**题目：**

> 数字化平台让基层事务留痕更便捷，但一些地方不断增加截图、打卡和重复报表，反而挤占了工作人员入户走访和解决问题的时间。技术能否真正减负，关键不在于应用数量，而在于是否围绕实际需求整合系统、简化流程。

这段文字意在说明：

A. 基层工作不应使用数字技术  
B. 数字化建设应以实际需求和流程优化为导向  
C. 截图打卡是基层负担的唯一来源  
D. 数字平台的数量越少越好

**思路：** “但”引出问题，末句“关键不在于……而在于……”给出中心对策。B 是同义替换；A、D 过度绝对，C 偷换为“唯一来源”。

**答案：** B。

### 4.4 例题：逻辑填空

**题目：** 历史文化街区保护不能只追求外观复古。倘若居民生活和原有业态被全部挤出，再精美的建筑也可能成为缺少日常烟火的布景。因此，城市更新应在保护风貌与延续生活之间寻求______。

A. 一刀切　B. 平衡点　C. 替代品　D. 分水岭

**思路：** “与……之间”且前文同时肯定保护和生活延续，需要表达兼顾两者。

**答案：** B。

## 五、判断推理：先把题目转成关系

### 5.1 四大分支的骨架

| 题型 | 第一步 | 核心关系 | 验证方式 |
| --- | --- | --- | --- |
| 图形推理 | 看元素是相似还是凌乱 | 位置、样式、数量、属性、立体 | 规律必须覆盖整组图，不只解释两幅 |
| 定义判断 | 圈定主体、条件、方式、目的或结果 | 选项与要件的包含关系 | 逐要件打勾，不凭生活印象 |
| 类比推理 | 先造句确定一级关系 | 语义、包含、并列、功能、工艺、语法 | 再比对顺序、必然性和二级属性 |
| 逻辑判断 | 区分形式推理和论证推理 | 条件关系或“论据—论点”关系 | 代入规则，或说明选项如何影响论证 |

### 5.2 形式逻辑最小公式包

- A → B：肯前必肯后；否后必否前。不能由 B 推 A，不能由非 A 推非 B。
- “只有 A，才 B”：B → A，A 是 B 的必要条件。
- “A 且 B”为真：A、B 都真；其矛盾是“非 A 或非 B”。
- “A 或 B”通常是相容选言：至少一个真；其矛盾是“非 A 且非 B”。
- 削弱、加强先找论点和论据；优先处理两者之间的关联，不要被只评论背景的选项带走。

详见 [判断推理核心总纲](判断推理/知识点.md)。

### 5.3 例题：翻译推理

**题目：** 只有通过信息安全审查，该系统才能上线。如果该系统上线，就必须完成全员培训。已知该系统未完成全员培训，可以推出：

A. 已通过安全审查　B. 未通过安全审查　C. 该系统未上线　D. 该系统永远不会上线

**思路：** 上线 → 通过审查；上线 → 完成培训。“未完成培训”是否后，可推“未上线”。但未上线不能倒推审查情况。

**答案：** C。

### 5.4 例题：削弱论证

**题目：** 某公司将会议时长从平均 60 分钟压缩到 30 分钟后，当月完成的项目数增加。管理者据此认为，压缩会议时长能提高项目效率。以下最能削弱的是：

A. 部分员工喜欢线上会议  
B. 当月公司同时上线了自动化项目管理工具  
C. 有的会议时长仍超过 30 分钟  
D. 项目数增加受到客户好评

**思路：** 论据是“压缩会议后，项目数增加”，论点是“压缩会议导致效率提高”。B 提供了同期发生的另一个原因，削弱因果归因。

**答案：** B。

**易错点：** C 只说措施执行不完全，不能说明措施没有效果；D 是结果的好处，不影响原因判断。

## 六、数量关系：不是“会公式”，而是“会选模型”

### 6.1 见到题干后的决策树

    题目能否直接代选项？
    ├─ 能 → 从特殊性强、中间值或易算选项开始
    └─ 不能
       ├─ 有明确等量关系 → 方程/不定方程
       ├─ 只给比例或效率 → 赋特值/比例份数
       ├─ 重复运动或协作 → 行程/工程模型
       ├─ 计数、分类或抽取 → 排列组合/概率
       ├─ 至少、至多、保证 → 极端构造/最不利原则
       └─ 比较方案或排程 → 统筹与分类讨论

### 6.2 必备模型总表

| 模型 | 核心关系 | 优先方法 |
| --- | --- | --- |
| 和差倍比 | 总量、差量、倍数关系 | 比例份数、方程、代入 |
| 工程 | 工作总量 = 效率 × 时间 | 总量赋公倍数，效率相加减 |
| 行程 | 路程 = 速度 × 时间 | 画线段，分清相遇/追及/流水 |
| 利润 | 利润 = 售价 - 成本；利润率 = 利润 ÷ 成本 | 成本赋 100，注意折扣基数 |
| 容斥 | 总数中扣除重复计数 | 两集合/三集合公式，画图 |
| 排列组合 | 有序用排列，无序用组合 | 分步相乘、分类相加，据限制捆绑/插空 |
| 概率 | 满足条件情况数 ÷ 总情况数 | 正难则反，先判断是否等可能 |
| 几何 | 长度、面积、体积与相似比 | 标注图形，优先用比例和割补 |
| 最值 | 要“保证”则先构造最坏情形 | 最不利数 + 1，或构造极值序列 |

各题型细节与专项入口见 [数量关系笔记](数量关系/笔记.md)。

### 6.3 例题：工程问题

**题目：** 甲单独完成一项工作需 12 天，乙单独完成需 18 天。两人合作 4 天后，剩余工作由甲单独完成，还需多少天？

**思路：** 将总量赋为 12 和 18 的最小公倍数 36。甲效率 3，乙效率 2，合作 4 天完成 20，剩余 16；甲单独做需 16 ÷ 3 = 5又1/3 天。

**答案：** 5又1/3 天。

**验算：** 甲在全过程工作 9又1/3 天，完成 28 份；乙工作 4 天，完成 8 份，合计 36 份。

### 6.4 例题：最不利原则

**题目：** 一只不透明袋子中有红、蓝、绿三种颜色的球，每种都不少于 4 个。至少取出多少个球，才能保证其中有 4 个同色球？

**思路：** “保证”要构造最坏情形。在还没有 4 个同色球时，每种最多取 3 个，共 9 个；再取 1 个必然使某色达到 4 个。

**答案：** 10 个。

## 七、资料分析：先辨口径，再谈速算

### 7.1 概念关系图

    现期量 A、基期量 B、增长量 Δ、增长率 r
    ├─ A = B × (1 + r)
    ├─ Δ = A - B
    ├─ B = A ÷ (1 + r)
    └─ Δ = A × r ÷ (1 + r)

    比重 = 部分 ÷ 整体
    平均数 = 总量 ÷ 份数
    倍数 = 前者 ÷ 后者

先问四句：

1. 时间是当期、同期、上期还是多年间？
2. 指标是总量、增量、增速、比重还是平均数？
3. 范围是全国、某地、某行业还是其中一部分？
4. 单位是元/万元/亿元、人/万人，还是百分点？

### 7.2 快速判断规则

- **两期比重：** 部分增长率大于整体增长率，比重上升；反之下降。
- **两期平均数：** 总量增长率大于份数增长率，平均数上升；反之下降。
- **混合增长率：** 整体增长率介于各部分增长率之间，且更接近基期量较大的部分。
- **年均增长：** 间隔年数是指数中的 n，不是材料中出现了几个年份。
- **倍数与增长率：** “是基期的 1.5 倍”意味着增长 50%，不是增长 150%。

完整公式、速算与综合题见 [资料分析核心总纲](资料分析/知识点.md)。

### 7.3 例题：基期量与增长量

**题目：** 某地 2025 年高新技术产业增加值为 540 亿元，同比增长 8%。问 2024 年约为多少亿元？2025 年约增加多少亿元？

**思路：**

- 基期量 = 540 ÷ 1.08 = 500 亿元；
- 增长量 = 540 - 500 = 40 亿元，或用 540 × 8% ÷ 1.08。

**答案：** 2024 年约 500 亿元；2025 年约增加 40 亿元。

**易错点：** 直接用 540 × 8% 得到的不是精确增长量，因为 8% 的基数是 2024 年的量。

### 7.4 例题：两期比重

**题目：** 某市工业增加值同比增长 6%，其中高技术制造业增加值同比增长 12%。与上年相比，高技术制造业增加值占工业增加值的比重如何变化？

**思路：** 部分增速 12% > 整体增速 6%，所以部分占整体的比重上升。题目未给现期比重，无法求出上升了几个百分点。

**答案：** 上升，但无法仅凭已知条件确定上升幅度。

## 八、一道题的完整复盘模板

刷题量只有转化为稳定的识别能力才有价值。每道错题用下列六格复盘：

| 字段 | 应记内容 |
| --- | --- |
| 题型 | 精确到二级题型，如“论证—他因削弱” |
| 触发信号 | 下次看到什么词或结构应想到它 |
| 正确规则 | 用一句话或一个式子写清 |
| 本次错因 | 概念/定位/计算/陷阱/时间取舍 |
| 错误动作 | 当时具体哪一步做错，不写“粗心” |
| 下次动作 | 可执行的改动，如“圈出问法中的不能” |

### 复盘示例

> **题型：** 资料分析—增长量。  
> **触发信号：** 已知现期量和同比增速，问增加额。  
> **正确规则：** 现期量 × r ÷ (1+r)。  
> **本次错因：** 概念错误。  
> **错误动作：** 把现期量直接乘增长率。  
> **下次动作：** 先在草稿写 A、B、r，再代入。

## 九、学习顺序与达标标准

### 第一轮：建框架

- 每个二级题型能说出“识别信号 + 核心规则 + 一个易错点”。
- 例题先不计时，强制写出思路。

### 第二轮：专项迁移

- 同一题型连续做一组，但每题都说明为什么属于该题型。
- 分开记录正确率和用时：先解决不会，再解决太慢。

### 第三轮：混合识别

- 混合刷题，训练从题干选择方法，避免专项练习中“题型已被标签”的假熟练。
- 达标不是某一次高分，而是连续多组在相近时限内稳定输出。

### 第四轮：套卷取舍

- 用至少 3 套同类卷测试作答顺序和模块截止点。
- 同时统计正确率、耗时、放弃题、猜题和涂卡用时，使用 [套卷复盘模板](../真题/套卷复盘模板.md) 调整策略。

> **最终标准：** 看到题能迅速识别关系，能说明每个选项错在哪里，并能在预设时间到点时果断进入下一题。
