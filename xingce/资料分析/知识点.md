# 资料分析 · 知识点深度解析

> 配套 [笔记.md](笔记.md)（个人笔记/错题归档）与 [../攻略.md](../攻略.md#一资料分析--最高优先级)。
> 资料分析的本质 = **找数（准）→ 列式（全）→ 速算（快）**。它是行测中唯一"学会就能满分"的模块：公式有限、套路固定、提分最快。
> 本文例题数据为教学模拟数据（参照真实统计口径编写），重在讲透方法。

## 一、总纲：做题三步法

| 步骤 | 用时 | 要点 |
|---|---|---|
| ① 读材料 | 30 秒 | 只看**结构**不看数：标题（时间+对象+单位）、段落主题词、图表的横纵轴 |
| ② 读题列式 | 20 秒 | 圈出**时间、对象、考点**三个词，判断考哪个公式，先列式后找数 |
| ③ 速算 | 40-60 秒 | 截位直除 / 特殊分数 / 首数法，**永远不要硬算到底** |

一篇材料 5 小题，合理用时 5-6 分钟；单题超过 1.5 分钟先蒙过。

**四大材料类型：**

- **文字型**：段落式。每段首句是主题句，用笔圈"时间+主体+单位"。
- **表格型**：先看表头（行标题、列标题、单位注释），再做题。注意"合计"行是整体还是部分。
- **柱状/折线图**：看横轴（年份）、纵轴（单位与刻度起点——纵轴不从 0 开始时视觉差异被放大）。
- **综合型（复合图表+文字）**：国考主流。资料通常在图表下方注释里藏单位换算。

## 二、核心统计术语（概念必须清零）

| 术语 | 含义 | 易错提醒 |
|---|---|---|
| 基期 / 现期 | 比较的"基准期" / "当前期"。如 2023 年比 2022 年增长，2022 是基期 | 谁是基期看**"比"字后面** |
| 增长量 | 现期 − 基期，**带单位的绝对量**（亿元、万人） | "增长最多"比的是量 |
| 增长率 | 增长量 ÷ 基期，**百分数** | "增长最快"比的是率；增长率可负可零 |
| 同比 / 环比 | 与**上年同期**比 / 与**上一统计周期**比（月环比、季环比） | 材料给"3 月环比"，别拿去和去年 3 月比 |
| 累计 / 当期 | 1 月至本月累计 / 仅本月 | 表格列名常写"1-X 月累计" |
| 比重 | 部分 ÷ 整体，百分数 | 整体是谁要看清（占全国？占全省？占总量？） |
| 平均数 | 总量 ÷ 份数（人均、单价、亩产） | 分母是"人数/面积/件数"等计数单位 |
| 倍数 | A 是 B 的几倍 = A÷B；A 比 B 多几倍 = (A−B)÷B | "多 2 倍" = "是 3 倍"，挖坑重灾区 |
| 翻番 | 翻 n 番 = ×2ⁿ（翻一番×2，翻两番×4） | 与"增长 2 倍"区分 |
| 指数 | 以基期为 100 的相对数。指数 > 100 即同比增长 | 指数减 100 ≠ 增长率（仅当指数定义为增速+100 时相等，看材料说明） |
| 进出口 | 出口 + 进口；**顺差** = 出口 − 进口；**逆差** = 进口 − 出口 | 顺差是差值（绝对量），不是比重 |
| 五年计划 | "十四五"指 2021-2025 年，**基期是 2020 年，n = 5** | 求年均增速时 n 取 5 不是 4（首尾相减法也常考） |

## 三、九大核心公式（列式体系）

> 记号统一：**r** = 增长率，**A** = 现期部分值，**B** = 现期整体值，**a** = 部分增长率，**b** = 整体增长率。

### 3.1 基本三式（一切的根）

| 公式 | 表达式 | 常用变形 |
|---|---|---|
| 增长率 | r = (现期 − 基期) / 基期 | r = 增长量 ÷ 基期 |
| 基期量 | 基期 = 现期 ÷ (1 + r) | 增长量为负时同样适用 |
| 现期量 | 现期 = 基期 × (1 + r) | 也用于"按此增速，明年将达到多少" |

### 3.2 增长量公式（高频）

$$增长量 = 现期 - 基期 = \frac{现期 × r}{1+r}$$

**深度理解**：为什么除以 (1+r)？因为材料给的是**现期值**，而 r 的分母是基期。`现期×r` 算的是"以现期为基数的假增长量"，必然偏大——这也是选项里最常见的陷阱数（见例 3）。

### 3.3 比重体系

| 考点 | 公式 |
|---|---|
| 现期比重 | 比重 = A / B |
| 基期比重 | $\frac{A}{B} × \frac{1+b}{1+a}$（现期比重再乘修正项） |
| **两期比重升降判断** | a > b → 比重上升；a < b → 下降；a = b → 不变（**只需比增速，不用算！**） |
| 比重差（升几个百分点） | $\frac{A}{B} × \frac{a-b}{1+a}$，结果带"百分点" |

**深度理解**：比重差的本质是"部分跑赢整体多少"。判断升降只看 a、b 大小——这是资料分析性价比最高的结论；具体数值才需要上公式。

### 3.4 平均数体系

| 考点 | 公式 |
|---|---|
| 现期平均数 | 总量 ÷ 份数 |
| 基期平均数 | $\frac{现期总量}{现期份数} × \frac{1+b_{份数}}{1+a_{总量}}$ |
| **平均数增长率** | $\frac{a_{总量} - b_{份数}}{1 + b_{份数}}$（a 是分子的增速，b 是分母的增速） |

**深度理解**：均价 = 金额/面积，金额是分子。分子涨得比分母快 → 均价上升。平均数增长率公式其实就是"总量的隔年/复合视角"——分母增速进入修正项。**分子增速在前，分母增速在后带 (1+b)**，别记反。

### 3.5 隔年（间隔）增长率

$$r_{隔} = r_1 + r_2 + r_1 × r_2$$

**深度理解**：2023 比 2021 的增速 = (1+r₂₃)(1+r₂₂) − 1。两个增速同号时交叉项为正、异号为负；当 r₁、r₂ 都小于 10% 时，交叉项 < 1 个百分点，若选项间距大可先忽略估算。反向考法（隔年基期）：基期 = 现期 ÷ (1 + r_隔)。

### 3.6 年均增长率

$$(1+r)^n = \frac{现期}{基期}，n = 年份数差$$

**深度理解**："十四五"年均增速 = (2025年/2020年)^(1/5) − 1。考场**不解方程**，用编数代入法：先估现期/基期的倍数（如 1.4 倍），再对照 1.07⁵≈1.40、1.1⁵≈1.61 等常用值，或直接把选项代进去验证。必背：**1.1² = 1.21，1.1³ = 1.331，1.2² = 1.44，1.1⁵ ≈ 1.61，1.2³ ≈ 1.73，2⁵ = 32**。

### 3.7 混合增长率（线段法/十字交叉）

整体由两部分构成时（进出口 = 出口 + 进口；城镇 + 乡村 = 全国）：

$$整体增速 r 满足：\frac{r - r_{小}}{r_{大} - r} = \frac{大部分现期}{小部分现期}$$

三条结论（先判断后精算）：
1. r 必然**介于两部分增速之间** → 选项不在区间内直接排除；
2. r **靠近现期值大的那部分**的增速；
3. 精确值用十字交叉或加权平均：r = (A₁r₁ + A₂r₂)/(A₁+A₂)。

### 3.8 拉动增长率与贡献率（次高频）

- 拉动增长率 = 部分增长量 ÷ **整体基期**（"拉动整体增长 x 个百分点"）
- 贡献率 = 部分增长量 ÷ 整体增长量（百分数）

### 3.9 增长量 / 增长率比较口诀

- **增长率比较**：直接比 r；材料只给现期和基期时，比"现期/基期"的商（不必算出 r）。
- **增长量比较（估算）**："大大则大"——现期大且增长率也大，增长量必大；"一大一小看乘积"——比较 现期×r（严格应比 现期×r/(1+r)，但 r/(1+r) 随 r 单调递增，乘积大的一般量大，量级接近时需精算验证）。

## 四、速算方法（深度讲解）

### 4.1 截位直除（第一主力）

**原理**：除法精度只由**分母前几位**决定。选项首位不同 → 分母截 2 位；首位相同次位不同 → 截 3 位。

- `41700 分之 2700` → 分母截位为 `42` → 27/42 ≈ 0.64 → 首位 6，选首位为 6 的选项。
- 截位方向：**估大选小、估大选大**——分子分母四舍五入的方向决定商偏大还是偏小，选项贴边时用。

### 4.2 特殊分数转化（第二主力）

增长率与分数互化，乘除法瞬间变简单：

| 分数 | 百分数 | 分数 | 百分数 |
|---|---|---|---|
| 1/2 | 50% | 1/9 | ≈11.1% |
| 1/3 | ≈33.3% | 1/10 | 10% |
| 1/4 | 25% | 1/11 | ≈9.1% |
| 1/5 | 20% | 1/12 | ≈8.3% |
| 1/6 | ≈16.7% | 1/13 | ≈7.7% |
| 1/7 | ≈14.3% | 1/14 | ≈7.1% |
| 1/8 | 12.5% | 1/15 | ≈6.7% |

**核心应用——增长量速算**：当 r ≈ 1/n 时，`现期×r/(1+r) = 现期/(n+1)`。
例：r = 8.3% ≈ 1/12 → 增长量 = 现期 ÷ 13。r = 16.7% ≈ 1/6 → 增长量 = 现期 ÷ 7。**背熟这张表等于白捡半分钟/题。**

### 4.3 首数法 / 尾数法

- **首数法**：选项首位数字互不相同时，除法只算出第一位即停。A/B 列竖式，商到第二位即可锁定。
- **尾数法**：多个数加减（合计校验、增量累加）时，只算末一位或末两位。仅适用于精确加减，不适用于除法。

### 4.4 比较大小三件套

- **同位比较法**：比 A/B 与 C/D，分子分母同向截位后直除首位。
- **差分法**：A/B 与 C/D（A>C 且 B>D）时，构造"差分数" (A−C)/(B−D)，它与谁接近就说明谁大——适用于"分数桥"类比较题。
- **看倍数**：比较"现期/基期"整体倍数而非增长率本身，避免逐个算 r。

### 4.5 量级与单位

%与‰、亿元与万元、吨与万吨——动笔前先把单位统一。口算增长率 0.8% 还是 8%，先看材料单位是 % 还是‰。

## 五、高频陷阱清单（丢分重灾区）

| 陷阱类型 | 典型表述 | 破解 |
|---|---|---|
| **时间陷阱** | "累计"vs"当月"；"同比"vs"环比"；题干问 2022 年材料给 2023 年 | 圈题干时间词，回去对表头 |
| **单位陷阱** | 材料"亿元"、选项"万亿元"；图表注释"单位：‰" | 读数前先看单位注释 |
| **范围陷阱** | "全国"vs"该省"；"规模以上"vs"全部"；"制造业"vs"工业" | 主题词逐字匹配 |
| **概念陷阱** | "增长最多（量）"vs"最快（率）"；"是几倍"vs"多几倍"；"超过/不足/接近/约" | 逐词抠字眼 |
| **基数陷阱** | 增长率为负时，"降幅收窄"≠回升；比较降幅要看绝对值 | 负增长先定方向 |
| **图表陷阱** | 纵轴截断（不从 0 起）；饼图占比之和含"其他"；双轴图左右刻度不同 | 看轴再读数 |

## 六、案例题精讲（10 题，含深度解析）

> 每题按"定位 → 列式 → 速算 → 排陷阱"四步走，这是考场思维的标准动作。

### 例 1 · 增长率（截位直除）

**材料**：2023 年，某省社会消费品零售总额 44533 亿元；2022 年为 41823 亿元。

**问**：2023 年该省社会消费品零售总额同比增长率约为多少？
A. 5.8%　B. 6.5%　C. 7.2%　D. 8.0%

**解析**：
1. 定位：同比 → 与 2022 年比；考点 = 增长率。
2. 列式：r = (44533 − 41823) / 41823 = 2710 / 41823。
3. 速算（截位直除）：选项首位 5/6/7/8 互不相同 → 分母截 2 位：27/42 ≈ 0.64 → 6.5%。**选 B**。
4. 陷阱：别拿 44523 当分母（现期÷基期搞反会得到 106.5% 附近的干扰感）。"比"字后面是基期。

---

### 例 2 · 基期量（除法首位）

**材料**：2023 年某市地区生产总值（GDP）8600 亿元，同比增长 7.5%。

**问**：2022 年该市 GDP 约为多少亿元？
A. 7890　B. 8000　C. 8210　D. 9245

**解析**：
1. 列式：基期 = 8600 / (1 + 7.5%) = 8600 / 1.075。
2. 速算：直除首位——86/10.75，商 7 开头 → 排除 C、D；精算 8600/1.075 = 8000（可用 1.075 × 8000 = 8600 验证）。**选 B**。
3. 深度：C 项 8210 = 8600 − 8600×7.5%×0.9 附近，是"现期 × r 当减法"的错误产物；D 项 9245 ≈ 8600×1.075，是"现期再乘 (1+r)"的方向性错误。**基期永远往小除，现期预测往大乘。**

---

### 例 3 · 增长量（特殊分数，含陷阱选项）

**材料**：2023 年某企业营业收入 52000 万元，同比增长 8.3%。

**问**：2023 年该企业营业收入比上年增加约多少万元？
A. 3800　B. 4000　C. 4316　D. 4727

**解析**：
1. 列式：增长量 = 52000 × 8.3% / (1 + 8.3%)。
2. 速算（特殊分数）：8.3% ≈ 1/12 → 增长量 = 52000 / (12+1) = 52000/13 = 4000。**选 B**。
3. 陷阱：C 项 4316 = 52000 × 8.3%，正是忘除 (1+r) 的结果——命题人专门为你准备的。见到"增加多少"而选项里恰有"现期×r"，多想一步除 (1+r)。

### 例 4 · 比重 + 两期比重判断

**材料**：2023 年某国粮食总产量 69541 万吨，同比增长 1.3%；其中秋粮产量 49595 万吨，同比增长 1.9%。

**问 1**：2023 年秋粮占粮食总产量的比重约为多少？
A. 65.4%　B. 68.9%　C. 71.4%　D. 74.8%

**解析**：比重 = 49595/69541，截位 496/695 → 直除首位 7，次位 496×7=3472 与 695×7=4865 比较……直接算：695 × 0.714 = 496.2 → **约 71.4%，选 C**。

**问 2**：与上年相比，2023 年秋粮占粮食总产量的比重变化情况是？
A. 上升，约 0.4 个百分点　B. 上升，约 1.9 个百分点　C. 下降，约 0.4 个百分点　D. 下降，约 1.9 个百分点

**解析**：
1. **先判断方向（不用算）**：部分增速 a=1.9% > 整体增速 b=1.3% → 比重**上升**，排除 C、D。
2. 再算幅度：比重差 = 71.4% × (1.9% − 1.3%)/(1+1.9%) ≈ 71.4% × 0.6% ≈ 0.43% → 约 0.4 个百分点。**选 A**。
3. 陷阱：B 项 1.9% 是"用部分增速冒充比重变化"。比重差永远远小于两个增速之差（还要乘上比重本身），数量级感要有。

### 例 5 · 平均数增长率（真实考法定式）

**材料**：2023 年某国商品房销售面积 11.2 亿平方米，同比下降 8.5%；销售金额 11.7 万亿元，同比下降 6.5%。

**问**：2023 年商品房平均销售价格同比：
A. 下降 2.2%　B. 下降 2.0%　C. 上升 2.0%　D. 上升 2.2%

**解析**：
1. 均价 = 金额/面积，金额是分子：a = −6.5%，b = −8.5%。
2. 列式：平均数增长率 = (a − b)/(1 + b) = (−6.5% + 8.5%)/(1 − 8.5%) = 2%/91.5% ≈ **+2.2%，选 D**。
3. 深度理解：金额降得比面积慢 → 分子相对变大 → 均价上升。**先定性（谁降得慢）再定量**，方向错了全错。1+b = 91.5% < 1，所以结果比 2% 略大——"除以小于 1 的数变大"这个直觉要练。

### 例 6 · 隔年增长率

**材料**：2023 年某省固定资产投资同比增长 6%，2022 年同比增长 4%。2023 年该省固定资产投资为 31080 亿元。

**问 1**：2023 年投资额比 2021 年增长约：
A. 10.0%　B. 10.24%　C. 10.5%　D. 11.2%

**解析**：r_隔 = 6% + 4% + 6%×4% = 10% + 0.24% = **10.24%，选 B**。若选项只有 10% 和 10.5%，交叉项 0.24% 决定靠哪边——**两个增速都小于 5% 时交叉项才可忽略**，这里 0.24% 恰好是 B、A 的分界。

**问 2**：2021 年该省固定资产投资约为多少亿元？
A. 28200　B. 29000　C. 29900　D. 30000

**解析**：基期 = 31080 / 1.1024 ≈ 28200（验证：28200 × 1.1024 ≈ 31088）。**选 A**。陷阱：直接 31080/1.06 = 29321（只除一年）落在 B、C 之间制造干扰。

### 例 7 · 年均增长率（编数代入）

**材料**："十四五"期间（2021—2025 年），某高新区营业收入从 2020 年的 200 亿元增长至 2025 年的 280.5 亿元。

**问**：该区间营业收入年均增长率约为：
A. 5.5%　B. 6%　C. 7%　D. 8%

**解析**：
1. 定位 n：基期 2020、现期 2025，**n = 5**（不是 4）。
2. 列式：(1+r)⁵ = 280.5/200 = 1.4025。
3. 编数代入：1.07⁵ ≈ 1.40 → r = 7%。**选 C**。
4. 深度：考场上从不解高次方程。先算倍数 1.4 倍，对照背过的 1.06⁵≈1.34、1.07⁵≈1.40、1.08⁵≈1.47 直接选。若忘了这些值，把选项代回去乘两次验证也比硬解快。

### 例 8 · 混合增长率（线段法）

**材料**：2023 年某省出口额 20000 亿元，同比增长 10%；进口额 15000 亿元，同比增长 4%。

**问**：2023 年该省进出口总额同比增长约：
A. 4.0%　B. 6.0%　C. 7.4%　D. 10.0%

**解析**：
1. **先定区间**：整体增速必在 4% ~ 10% 之间 → A、D 排除。
2. **再定偏向**：出口（20000）大于进口（15000）→ 整体增速偏向 10% 一侧 → B（6.0% 恰在中点）排除，预判选 C。
3. 精算验证：r = (20000×10% + 15000×4%) / 35000 = (2000+600)/35000 = 2600/35000 ≈ **7.4%，选 C**。
4. 深度：B 项 6% 是简单算术平均（(10+4)/2）的陷阱——**增速的权重是现期量，不是简单的 1:1**。

### 例 9 · 增长量比较（大大则大 / 一大一小看乘积）

**材料**：2023 年，甲省社会消费品零售总额 50000 亿元，同比增长 5%；乙省 30000 亿元，同比增长 8%。

**问**：2023 年社会消费品零售总额同比增加更多的是：
A. 甲省，多约 2380 亿元　B. 乙省，多约 2220 亿元　C. 甲省，多约 2500 亿元　D. 乙省，多约 2400 亿元

**解析**：
1. 定性：甲现期大但增速小，"一大一小"→ 比乘积：甲 50000×5% = 2500，乙 30000×8% = 2400 → 乘积甲大，预判甲增长量大。
2. 精算：甲 = 50000×5%/105% ≈ 2381 亿；乙 = 30000×8%/108% ≈ 2222 亿 → **甲多，选 A**。
3. 陷阱：C 项 2500 = 甲的"现期×r"（忘除 1+r）。**比较类题先定性排除两个选项，再精算定答案**，速度翻倍。

### 例 10 · 综合分析题（一题考多个陷阱）

**材料**：2023 年，某市规模以上工业增加值 4500 亿元，同比增长 6.0%。其中，上半年累计 2100 亿元，同比增长 5.6%；前三季度累计 3300 亿元，同比增长 5.8%。全年进出口总额 1800 亿美元，同比增长 3.0%，其中出口 1000 亿美元、同比增长 5.0%，进口 800 亿美元、同比增长 0.6%。

**问**：能够从上述资料中推出的是：
A. 2023 年下半年，该市规模以上工业增加值超过 2400 亿元
B. 2022 年该市进出口总额不足 1750 亿美元
C. 2023 年前三季度增加值占全年的比重超过 75%
D. 2023 年该市进口额同比增长量超过 5 亿美元

**逐项深度解析**：

- **A（时间陷阱·累计当期混算）**：下半年 = 全年 − 上半年 = 4500 − 2100 = **恰好 2400 亿元，"超过"不成立**。错。挖坑点：用"前三季度−上半年"算出 1200 再当"下半年"就中招了（1200 是三季度单季）。
- **B（基期量·加和口径）**：2022 年进出口 = 1800/1.03 ≈ 1747.6 亿美元 < 1750 ✓。也可分项验证：1000/1.05 + 800/1.006 ≈ 952.4 + 795.2 ≈ 1747.6。**正确**。
- **C（比重·精确读数）**：3300/4500 = 73.3% < 75%。错。"接近 75%"和"超过 75%"一字之差。
- **D（增长量·单位陷阱）**：进口增长量 = 800×0.6%/(1+0.6%) ≈ 4.77 亿美元 < 5。错。挖坑点：800×0.6% = 4.8，忘除 (1+r)；以及"亿美元/元/万美元"单位层级。

**答案：B。** 综合分析题策略：**优先验证计算量小的选项**（如 A、C 这种一步加减/一步比重的），把"验证成本"当排序依据，别按 A→D 顺序死磕。

## 七、考场策略

1. **顺序**：资料分析放在头脑清醒的中前段做（建议做完常识后立刻做），不要留到最后 15 分钟。
2. **节奏**：一篇材料 5 题 6 分钟。最后一道综合分析若卡壳，先做完全部资料再回头。
3. **取舍**：综合分析题验证 2 项仍无答案，先用已排除信息蒙剩余中计算量最小的。
4. **草稿**：列式写清楚"数字+单位"，速算只写截位后的数，避免回读材料。
5. **复盘**：每套真题做完，把错题按"找数错 / 列式错 / 速算错 / 陷阱错"四类归因，归到 [错题本.md](../../错题本.md)——资料分析错因 80% 是"陷阱错"而非"不会算"。

## 附：公式速查卡（考前 5 分钟过一遍）

| 考点 | 公式 | 速算抓手 |
|---|---|---|
| 基期 | 现期/(1+r) | 直除首位 |
| 增长量 | 现期×r/(1+r) | r≈1/n → 现期/(n+1) |
| 隔年增速 | r₁+r₂+r₁r₂ | 都<5%时交叉项可略 |
| 年均增速 | (1+r)ⁿ=现期/基期 | 编数代入，n=年份差 |
| 两期比重方向 | a>b 升，a<b 降 | 不用算 |
| 比重差 | A/B × (a−b)/(1+a) | 远小于 a−b |
| 平均数增速 | (a−b)/(1+b) | 分子增速在前 |
| 混合增速 | 介于两者、偏大量 | 十字交叉 |
| 增长量比较 | 现期×r/(1+r) | 大大则大，一大一小看乘积 |
