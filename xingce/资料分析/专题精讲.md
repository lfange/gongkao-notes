## 专题一：基期与现期

### 本质

一切增长比较的参照系。**"比"字后面的时期是基期**——"2023 年比 2022 年增长"，2022 是基期。资料分析的难点从来不是识别，而是**材料给现期、题目问基期**时的方向转换。

### 公式族

| 场景 | 公式 |
|---|---|
| 已知现期、增长率 | 基期 = 现期 ÷ (1+r) |
| r 为负（下降） | 基期 = 现期 ÷ (1−\|r\|)，**基期 > 现期** |
| 已知隔年增速 | 基期 = 现期 ÷ (1+r_隔) |
| 基期差 / 基期和 | 先各自求基期，再加减（单位先统一） |

### 问法识别

"上年为""2022 年为""上年同期约为""上年同期相比，……约为多少"。

### 易错点

1. **下降忘反向**：增长率为负时分母 (1+r) < 1，除完应变大。
2. **同比环比混问**：题目问"上月"用环比增速，问"上年同期"用同比增速，两者互不通用。
3. 选项常放"现期×(1+r)"（越乘越大）和"现期×(1−r)"（越乘越小）两个方向性错误答案。

### 精讲例题 1（下降型基期）

**材料**：2023 年某省原油产量 20800 万吨，同比下降 4.3%。
**问**：2022 年该省原油产量约为多少万吨？
A. 19800　B. 20800　C. 21700　D. 22700

**解析**：
1. 列式：20800 ÷ (1 − 4.3%) = 20800 ÷ 0.957。
2. 定方向：下降 -> 基期**大于**现期 20800 -> 排除 A、B。
3. 速算：20800/0.957 ≈ 21735 -> **选 C**。
4. 陷阱：A 项 19800 ≈ 20800×0.957，是"下降就乘"的方向性错误。

### 精讲例题 2（同比环比双基期）

**材料**：2023 年 3 月，某企业水泥产量 500 万吨，同比增长 25%，环比增长 10%。
**问**：2022 年 3 月与 2023 年 2 月的产量分别约为多少万吨？
A. 400、455　B. 455、400　C. 400、550　D. 425、455

**解析**：
1. 2022 年 3 月（上年同期 -> 用同比）：500 ÷ 1.25 = **400**。
2. 2023 年 2 月（上一月 -> 用环比）：500 ÷ 1.10 ≈ **455**。**选 A**。
3. 深度：一道题里藏着两个基期，靠的就是"同期对同比、相邻对环比"。C 项 550 = 500×1.10（乘反）；B 项是两问对调。

## 专题二：增长率

### 本质

变化的**相对快慢**，永远以基期为分母。它是资料分析出现频率最高的考点，且变形极多（同比/环比/隔年/年均/混合），识别变形比计算更重要。

### 公式族

| 变形 | 公式 / 要点 |
|---|---|
| 基本 | r = (现期 − 基期)/基期 = 增长量 ÷ 基期 |
| 隔年 | r₁ + r₂ + r₁r₂ |
| 年均 | (1+r)ⁿ = 现期/基期 |
| 混合 | 十字交叉，介于两部分增速之间 |
| 拉动增长率 | 部分增长量 ÷ **整体基期**，单位"百分点" |
| 变化幅度 | 取绝对值比较（+5% 与 −8% 比，幅度 8% 的大） |

### 问法识别

"增长率""增速""增幅""同比增长百分之几""增长快慢"。注意：**"增长最多"比的是增长量，"增长最快"才是增长率**。

### 易错点

1. "降幅收窄"只说明负得少了，仍是下降；由降转增才叫回升。
2. 增长率比较题不必算出每个 r，直接比"现期/基期"的商。
3. 下降年份算"变化幅度"要加绝对值。

### 精讲例题 1（直接计算）

**材料**：某市 2023 年财政收入 31300 亿元，2022 年为 28000 亿元。
**问**：同比增长率约为？
A. 9.4%　B. 10.9%　C. 11.8%　D. 12.7%

**解析**：r = 3300/28000，截位 33/280 = 0.118 -> **11.8%，选 C**。
陷阱：B 项 10.9% ≈ 3300/30300（误用现期为分母）；D 项 ≈ 3300/26000（瞎算区间）。

### 精讲例题 2（变化幅度）

**材料**：四个省份 GDP 增速分别为：甲 +5.2%、乙 −8.1%、丙 −6.9%、丁 +7.3%。
**问**：GDP 增速变化幅度最大的是？
A. 甲　B. 乙　C. 丙　D. 丁

**解析**：幅度取绝对值：甲 5.2、乙 8.1、丙 6.9、丁 7.3 -> **乙，选 B**。
深度：正负号只代表方向，"波动多大"看绝对值。若题目问"增长最快"，则只比正的（丁 7.3%），负增长不参与"增长"比较。

### 精讲例题 3（拉动增长）

**材料**：2023 年某省新能源汽车产业增加值比上年增加 240 亿元；2022 年全省 GDP 为 8000 亿元。
**问**：新能源汽车产业拉动全省经济增长多少个百分点？
A. 1.5　B. 2.0　C. 3.0　D. 5.0

**解析**：拉动 = 部分增长量 ÷ 整体**基期** = 240/8000 = **3 个百分点，选 C**。
深度：分母是"整体基期"不是"整体现期"也不是"整体增长量"（那是贡献率）。"拉动 x 个百分点"的 x 加在整体增速上才自洽：整体增长 6%，其中新能源汽车贡献 3 个点。

## 专题三：增长量

### 本质

变化的**绝对多少**，带单位（亿元、万吨、万人）。它和增长率是一对镜像：量答"多少"，率答"快慢"，审题先分清这一对。

### 公式族

| 场景 | 公式 / 速算 |
|---|---|
| 已知现期和 r | 增长量 = 现期×r/(1+r) |
| r ≈ 1/n | 增长量 = 现期 ÷ (n+1)（**核心速算**） |
| r 为负 | 减少量 = 现期×\|r\|/(1−\|r\|)，如 r=−1/8 -> 现期 ÷ 7 |
| 已知现期、基期 | 直接相减（尾数法校验） |
| 比较 | 大大则大；一大一小看乘积（现期×r） |

### 问法识别

"增加/减少多少亿元""增长量为""比上年多多少"。

### 易错点

1. **忘除 (1+r)**——资料分析第一陷阱，几乎每套卷都配一个"现期×r"的干扰选项。
2. 减少量也是"增长量"的一种（增长量为负），问"减少了多少"答案是正数。
3. 单位：材料"万元"、选项"亿元"是常客。

### 精讲例题 1（特殊分数）

**材料**：2023 年某港货物吞吐量 34000 万吨，同比增长 6.7%。
**问**：比上年增加约多少万吨？
A. 1910　B. 2125　C. 2270　D. 3400

**解析**：6.7% ≈ 1/15 -> 增长量 = 34000 ÷ 16 = **2125，选 B**。
陷阱：C 项 2270 ≈ 34000×6.7%（忘除 1.067）；A 项 ≈ 34000×5.6%（特殊分数记错一格，1/18 附近）。

### 精讲例题 2（下降量）

**材料**：2023 年某企业利润 25000 万元，同比下降 12.5%。
**问**：2023 年利润比上年减少约多少万元？
A. 2500　B. 3125　C. 3570　D. 5000

**解析**：12.5% = 1/8 -> 减少量 = 25000×(1/8) ÷ (7/8) = 25000 ÷ 7 ≈ **3570，选 C**。
陷阱：B 项 3125 = 25000×1/8（忘除 1−r）；D 项 5000 = 25000×(1/5)（分数记错）。**下降时除的是 (n−1)**：r=1/8 -> 分母 7。

## 专题四：比重

### 本质

部分占整体的百分比。比重题占资料分析题量的四分之一，且"两期比重"是区分度最高的考点——**判断升降不用算，算差值有定式**。

### 公式族

| 场景 | 公式 |
|---|---|
| 现期比重 | A/B |
| 基期比重 | A/B × (1+b)/(1+a) |
| 升降判断 | **a > b 升，a < b 降**（零计算） |
| 比重差 | A/B × (a−b)/(1+a)，单位"百分点" |

### 问法识别

"占……的比重""……所占比例""比重比上年提高/降低多少个百分点"。

### 易错点

1. **整体找错**："占全国的比重"整体是全国不是某省；"占服务业的比重"整体是服务业不是 GDP。
2. **百分点 ≠ 百分数**：比重差的结果说"个百分点"；选项若写"%"往往是把比重差和增长率混着挖坑。
3. 比重差永远**远小于** a−b（还要乘比重本身 ÷ (1+a)），量级感可以秒杀选项。

### 精讲例题 1（基期比重）

**材料**：2023 年某市高技术产业增加值 12400 亿元，同比增长 10%；全市工业增加值 45000 亿元，同比增长 5%。
**问**：2022 年高技术产业占全市工业的比重约为？
A. 24.1%　B. 26.3%　C. 27.6%　D. 29.2%

**解析**：
1. 列式：基期比重 = (12400/45000) × (1+5%)/(1+10%)。
2. 速算：现期比重 124/450 ≈ 27.6%（先算出，它是 C 项陷阱）；修正项 1.05/1.10 ≈ 0.955（部分快 -> 基期比重更小）。
3. 27.6% × 0.955 ≈ **26.3%，选 B**。
4. 深度：修正项方向有直觉——部分增速快说明"它的占比在涨"，去年占比必然更低。先定性再定量，方向错了全错。

### 精讲例题 2（比重差）

**材料**：接上题。
**问**：2023 年高技术产业占全市工业的比重比上年约：
A. 上升 1.3 个百分点　B. 上升 5 个百分点　C. 下降 1.3 个百分点　D. 下降 5 个百分点

**解析**：
1. 定方向：a=10% > b=5% -> **上升**，排除 C、D。
2. 算差值：27.6% × (10%−5%)/(1+10%) = 27.6% × 4.55% ≈ 1.25 -> 约 **1.3 个百分点，选 A**。
3. 陷阱：B 项 5 个百分点 = a−b（增速差冒充比重差）。比重差 ≈ 比重 × 增速差，必然比增速差小一个量级。

### 精讲例题 3（纯口诀判断）

**材料**：2023 年某省餐饮收入增速 18.5%，社会消费品零售总额增速 7.2%。
**问**：2023 年餐饮收入占社会消费品零售总额的比重比上年？（上升/下降/不变）

**解析**：部分（餐饮）增速 18.5% > 整体（社零）增速 7.2% -> **上升**。三秒出答案，这就是"性价比之王"考点。

## 专题五：平均数

### 本质

总量 ÷ 份数："人均""单价""亩产""户均""单耗"全是它。平均数的核心难点是**平均数增长率**，而它有一个被大多数教程讲复杂的统一理解。

### 深度理解：平均数增长率就是"商的增长率"

平均数 = 总量/份数，是个"商"。商的增长率：

$$\bar{r} = \frac{1+a}{1+b} - 1 = \frac{a-b}{1+b}$$

（a = 分子增速，b = 分母增速）。**记忆锚点：分子增速在前，分母增速带 (1+b) 躲在后面。** 为什么和比重差公式不同？因为比重差是"两个百分数相减"（结果：百分点），平均数增长率是"商本身变快了百分之几"（结果：%）。一个做减法、一个做除法，用途别混。

### 公式族

| 场景 | 公式 |
|---|---|
| 现期平均 | 总量 ÷ 份数 |
| 基期平均 | 现期平均 × (1+b_份数)/(1+a_总量) |
| 平均数增长率 | (a − b)/(1 + b) |
| 升降判断 | a > b 升，a < b 降（同两期比重） |

### 问法识别

"人均""平均""每 x ……""单价/亩产/户均"，以及"平均……比上年提高/下降百分之几"。

### 易错点

1. 分子分母增速对调——列式时先写清楚谁是分子。
2. 平均数增速结果带 %，比重差带百分点，选项混排是经典坑。
3. (1+b) 中 b 为负时分母小于 1，结果会比 a−b 大（除以小数变大）。

### 精讲例题 1（现期平均 + 单位换算）

**材料**：2023 年某国电影票房 549 亿元，观影 12.9 亿人次。
**问**：平均票价约为多少元？
A. 32.6　B. 38.4　C. 42.6　D. 48.9

**解析**：549 亿 ÷ 12.9 亿人次 = 42.6 元/人次 -> **选 C**。
陷阱：亿元÷亿人次，"亿"约掉直接算 549/12.9。A 项是没约单位硬算的产物；做除法前先统一单位量级。

### 精讲例题 2（基期平均 + 平均数增长率，双问）

**材料**：2023 年票房 549 亿元，同比下降 18%；观影 12.9 亿人次，同比下降 22%。

**问 1**：2022 年平均票价约为多少元？

**解析**：基期平均 = 42.6 × (1−22%)/(1−18%) = 42.6 × 0.78/0.82 = 42.6 × 0.951 ≈ **40.5 元**。（人次降得更快 -> 上年平均更低？错——**人次是分母**，分母降得快把均价"垫高"了，所以上年均价更低没错，但要靠公式不是靠感觉：分子降 18% 拉低均价，分母降 22% 抬高均价，抬的力量小，净效果 40.5 < 42.6。）

**问 2**：2023 年平均票价同比增长约？

**解析**：a = −18%（分子），b = −22%（分母）-> (a−b)/(1+b) = (−18%+22%)/(1−22%) = 4%/78% ≈ **+5.1%**。
验算：40.5 × 1.051 ≈ 42.6 ✓（基期 × (1+增速) = 现期，自洽）。
深度：分子降得比分母慢 -> 均价反而涨。先定性（谁降得慢谁占便宜）再定量。

## 专题六：倍数与翻番

### 本质

A 与 B 的相对大小。"是几倍"和"多几倍"相差 1，是文字游戏的重灾区；翻番是倍数的指数形式。

### 公式族

| 场景 | 公式 / 要点 |
|---|---|
| 是几倍 | A ÷ B |
| 多几倍 | (A − B) ÷ B = 是几倍 − 1 |
| 基期倍数 | (A/B) × (1+b_B)/(1+a_A) |
| 翻 n 番 | ×2ⁿ（翻一番×2、两番×4、三番×8） |

### 易错点

1. "是 3 倍" = "多 2 倍"，读题逐字抠。
2. "翻两番"是 ×4 不是 ×2——"番"按 2 的幂走。
3. 基期倍数修正项方向：A 增得快 -> 基期倍数更小。

### 精讲例题 1（是几倍 vs 多几倍）

**材料**：2023 年甲省出口 36000 亿元，乙省 12000 亿元。
**问**：甲省出口是乙省的多少倍？比乙省多多少倍？

**解析**：是 36000/12000 = **3 倍**；多 (36000−12000)/12000 = **2 倍**。两个问答案差 1，命题人最爱在选项里同时放 2 和 3。

### 精讲例题 2（基期倍数）

**材料**：接上题。甲省出口同比增长 20%，乙省增长 10%。
**问**：2022 年甲省出口是乙省的多少倍？
A. 2.5　B. 2.75　C. 3.0　D. 3.3

**解析**：基期倍数 = 3 × (1+10%)/(1+20%) = 3 × 1.10/1.20 = **2.75，选 B**。
深度：甲（分子）增得快 -> 基期倍数比现期小，先排除 C、D；再算修正项。结构与"基期比重"完全同源——**基期比重/基期倍数/基期平均是一套公式**：现期值 × (1+b)/(1+a)。

### 精讲例题 3（翻番）

**材料**：2023 年某高新区总收入 640 亿元，比 2018 年翻了两番。
**问**：2018 年总收入约为多少亿元？

**解析**：翻两番 = ×4 -> 2018 年 = 640 ÷ 4 = **160 亿元**。
陷阱：误当"翻两番 = ×2"会得 320；误当"增长两倍 = ×2"同样错——增长两倍才是 ×3，翻两番是 ×4。

## 专题七：隔年增长

### 本质

跨过中间年份的比较（2023 比 2021）。核心公式只有一条，难在**反向运用**和与基期量的组合。

### 公式族

| 场景 | 公式 |
|---|---|
| 隔年增速 | r₁ + r₂ + r₁r₂ |
| 隔年基期 | 现期 ÷ (1+r_隔) |
| 反求其中一年增速 | r₂ = (1+r_隔)/(1+r₁) − 1 |

### 易错点

1. 忽略交叉项 r₁r₂——两个增速都 ≥5% 时交叉项 ≥0.25%，可能正好决定选项。
2. 异号时交叉项为负（如 6% 和 −4%：6−4−0.24 = 1.76%）。

### 精讲例题 1（正向）

**材料**：2023 年某省社会消费品零售总额增长 6%，2022 年增长 4%。
**问**：2023 年总额比 2021 年增长约？
A. 10.0%　B. 10.24%　C. 10.5%　D. 11.2%

**解析**：6% + 4% + 6%×4% = **10.24%，选 B**。若选项只有 10% 和 10.5%，10.24% 更靠近 10%——先算交叉项再定夺，别拍脑袋。

### 精讲例题 2（反向求增速）

**材料**：2023 年某市财政收入比 2021 年增长 21%，其中 2023 年同比增长 10%。
**问**：2022 年同比增长约？
A. 9%　B. 10%　C. 11%　D. 11.5%

**解析**：r₂ = 1.21/1.10 − 1 = 1.10 − 1 = **10%，选 B**。
深度：多数人背得住正向公式，反向就卡壳。记原理不背变形——(1+r_隔) = (1+r₁)(1+r₂)，三个量知道俩求第三个，永远是解方程而不是背公式。

## 专题八：年均增长

### 本质

一段时期内的"平均变化速度"（年均增长率）或"平均变化量"（年均增长量）。考点一半在计算，一半在 **n 的确定**。

### 深度理解：n 怎么定

"2021-2025 年""'十四五'期间" -> 基期 2020、现期 2025、**n = 5**（年份差）。口诀：**大年减小年**。年均增长量 = (现期 − 基期)/n，同一个 n。分不清时想：2020 到 2021 只走了"一步"，2020 到 2025 走了五步。

### 计算策略（考场不解方程）

1. 先算总倍数 现期/基期（如 1.4 倍）。
2. 对照必背幂值：1.1⁵≈1.61、1.2⁵≈2.49、2⁵=32、1.1³≈1.33、1.2³≈1.73。
3. 选项代入验证收尾。

### 精讲例题

**材料**：某高新区营业收入 2018 年为 500 亿元，2023 年为 800 亿元。
**问 1**：2018-2023 年年均增长量约为多少亿元？

**解析**：n = 2023−2018 = 5 -> (800−500)/5 = **60 亿元/年**。

**问 2**：年均增长率约为？
A. 8%　B. 9.9%　C. 11%　D. 12%

**解析**：总倍数 1.6；1.1⁵ = 1.61 略大于 1.6 -> r 比 10% 略小 -> **约 9.9%，选 B**。
陷阱：A 项 8% 是"忘了开方直接算平均"（(1.6−1)/5=12%？不，12% 才是——D 项 12% = (80%总增幅)/5，即"把总增幅除以 5"的错误；C 项 11% 是幂值没背准的估算漂移）。**年均增速永远明显小于"总增速÷年数"**，因为复利是滚雪球。

## 专题九：混合增长

### 本质

整体增速是各部分增速的**加权平均**（权重 = 各部分现期量）。十字交叉/线段法只是加权平均的几何表达。

### 三步法

1. **定区间**：r 介于最快与最慢部分之间，且**靠近量大的部分**——先排除不在区间的选项。
2. **线段法定距离**：r 到两端的距离比 = 两部分**数量之反比**。
3. **需要精确值时**：加权平均 r = Σ(部分量×部分增速)/总量。

### 易错点

- 权重是**现期量**不是基期量（近似计算时用现期量即可，误差极小）。
- 简单算术平均 (r₁+r₂)/2 是最经典干扰项——只有两部分等重时才成立。
- 反向题（已知整体和一部分，求另一部分）本质是解加权平均方程。

### 精讲例题 1（正向）

**材料**：2023 年某省社会消费品零售总额 47000 亿元。其中商品零售 42000 亿元，同比增长 5.8%；餐饮收入 5000 亿元，同比增长 18.5%。
**问**：社零总额同比增长约？
A. 5.8%　B. 7.2%　C. 12.1%　D. 18.5%

**解析**：
1. 定区间：5.8% ~ 18.5%，排除两端选项 A、D。
2. 定偏向：商品零售占 42000/47000 ≈ 89%，整体增速紧贴 5.8% 一侧 -> C（12.1%，恰是简单平均 (5.8+18.5)/2 的陷阱）排除，预判 B。
3. 精算：(42000×5.8% + 5000×18.5%)/47000 = (2436+925)/47000 = 3361/47000 ≈ **7.2%，选 B**。

### 精讲例题 2（反向求部分增速）

**材料**：2023 年某市进出口总额 2000 亿美元，同比增长 7%。其中出口 1200 亿美元，同比增长 10%。
**问**：进口（800 亿美元）同比增长约？
A. 2.5%　B. 4.0%　C. 5.5%　D. 6.5%

**解析**：
1. 定方向：整体 7% 介于出口 10% 与进口增速之间且低于 10% -> 进口增速 < 7%，排除 D。
2. 线段法：出口比整体快 3 个点，出口量:进口量 = 1200:800 = 3:2 -> 整体到进口端的"距离"= 3 个点 × 3/2 = 4.5 -> 进口增速 ≈ 7% − 4.5% = 2.5%。
3. 验算：(1200×10% + 800×2.5%)/2000 = (120+20)/2000 = 7% ✓ **选 A**。

## 专题十：陷阱深挖与综合演练

前九个专题的坑都是"点"上的，综合分析题把多个坑埋进同一篇材料。先复习最致命的四个：

| 陷阱 | 一句话破解 |
|---|---|
| 累计 vs 当期 | "下半年 = 全年 − 上半年"，别用"前三季度 − 上半年"（那是 Q3 单季） |
| 同比 vs 环比 | 问谁用谁；材料没给的数据不能"推出来" |
| 单位换算 | 亿元/万元、%/‰、亿人次/万人次，动笔前统一 |
| "超过/不足/约" | 超过 = 严格大于；"约"允许小幅误差，但方向和量级必须对 |

### 综合演练题

**材料**：2023 年，某市接待游客 8600 万人次，同比增长 16.2%；实现旅游总收入 1580 亿元，同比增长 21.4%。其中，国内游客 8400 万人次（同比增长 16.5%），入境游客 200 万人次（同比增长 4.0%）。分季度看，一至四季度分别接待 1900、2100、2400、2200 万人次。

**问**：能够从上述资料中推出的是：
A. 2023 年入境游客占接待游客总量的比重超过 2.5%
B. 2023 年游客人均旅游收入超过 1800 元
C. 2022 年国内游客不足 7200 万人次
D. 2023 年四季度接待人次同比下降

**逐项解析**：

- **A（比重）**：200/8600 ≈ 2.33% < 2.5%，"超过"不成立。错。
- **B（平均数 + 单位换算）**：1580 亿元 ÷ 8600 万人次 = 1580×10⁸ ÷ (8600×10⁴) = 1837 元 > 1800。**正确**。（亿元/亿人次先约掉"亿"，再做 158/0.86 万元的换算——这步单位处理就是本题真正的考点。）
- **C（基期量 + 精度）**：8400/1.165 ≈ 7210 万人次 > 7200，"不足 7200"不成立。错。估算时除法做保守截位（分母取 1.16 得 7241、取 1.17 得 7179，区间横跨 7200）——**结论贴着阈值时必须精算两位**，这是 C 项的训练价值。
- **D（同比/环比 + 数据存在性）**：材料只有分季度数据，四季度**同比**数据不存在；能算出的只有环比下降（2200 vs 2400）。"推不出"就是错。错。

**答案：B。**

**做题顺序复盘**：A（一步除法）、C（一步除法）成本最低先做，B 要单位换算其次，D 靠读题可直接判。综合分析题**按验证成本排序，不按选项顺序**。
