# 资料分析 · 增长量专题（量的计算与比较："大大则大"）

> 增长量的全部难点浓缩成两件事：**算的时候别忘了除 (1+r)**，**比的时候别忘了"一大一小看乘积"**。
> "现期×r"是资料分析第一陷阱选项——几乎每套卷都为它留一个位置。
> 专题结构：**本质 → 公式族 → 判断三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。必背的分数表见 [常用数据速查表.md](常用数据速查表.md) 第一节。

---

## 一、本质：为什么要除 (1+r)

材料给的是**现期值**，而增长量 = 现期 − 基期 = 现期 − 现期/(1+r)：

$$增长量 = \frac{现期 × r}{1+r}$$

深度理解 `现期×r` 为什么偏大：r 的真实分母是基期（= 现期÷(1+r)），拿现期直接乘 r，相当于把基数放大了 (1+r) 倍。r 越大，"现期×r"比真实增长量偏得越多——**所以增速大的时候，忘除 (1+r) 错得越离谱，也越好用"差得多"识别**。

## 二、公式族（核心速查表）

| 场景 | 公式 / 速算 | 要点 |
| --- | --- | --- |
| 已知现期、r | 增长量 = 现期×r/(1+r) | 第一公式 |
| r ≈ 1/n（增长） | **增长量 = 现期 ÷ (n+1)** | 特殊分数法，主力 |
| r ≈ −1/n（下降） | **减少量 = 现期 ÷ (n−1)** | "升加降减" |
| 已知现期、基期 | 直接相减，尾数法校验 | 表格题常用 |
| 比较（大大） | 现期大且 r 大 → 增长量必大 | 零计算 |
| 比较（一大一小） | 比乘积 现期×r | 贴身时精算验证 |

**特殊分数法**（配合 [常用数据速查表](常用数据速查表.md) 背熟）：r = 14.3% ≈ 1/7 → 增长量 = 现期÷8；r = −12.5% = −1/8 → 减少量 = 现期÷7。口诀：**升加降减**（分数分母，升 +1、降 −1）。

## 三、判断三步法（拿到题先走这三步）

1. **问量还是问率？**"增加多少亿元/万吨"是量；"增长百分之几"是率。量率混排的选项必是坑。
2. **正增长还是下降？**下降用"减少量 = 现期÷(n−1)"，除数是 n−1 不是 n+1。
3. **算还是比？**单个主体 → 特殊分数法；多个主体 → 先"大大则大"排一轮，剩下的比乘积。

## 四、题型逐个击破

### 题型 1：特殊分数法（主力）

r 化成 1/n，除法一步到位：现期÷(n+1)。增速 5%~20% 区间的题目几乎全适用。识别训练：看到 16.7% 想 ÷7（增长），看到 −16.7% 想 ÷5（减少）。

### 题型 2：下降（减少量）

下降时"增长量为负"，问"减少了多少"答案取正数。除数变成 **n−1**：r = −16.7% ≈ −1/6 → 减少量 = 现期÷5。**忘掉"降减"用 n+1 是本题专属错误。**

### 题型 3：增长量比较

- **大大则大**：A 现期大、增速也大 → A 增长量必然大（因为 r/(1+r) 随 r 单调递增），直接出答案；
- **一大一小看乘积**：比 现期×r，乘积大的一般量大；
- **乘积贴身要精算**：乘积法丢掉的是 ÷(1+r) 这一步，r 差异大时修正力度不同，**乘积只差几个百分点时可能翻车**（见例题 3）。

### 题型 4：现期减基期（表格题）

表格直接给两列数，相减即可，多个数相加用**尾数法**校验（只算末位）。注意表格单位注释和"合计"行的口径。

### 题型 5：增长量与增长率概念辨析

"增长最多"（量）vs"增长最快"（率）在同一篇材料里轮流问。两者答案可以不同——量看绝对值，率看相对值，大基数主体常"量多率慢"。

### 题型 6：单位换算叠加

材料"万元"、问"亿元"：先按万元算出增长量，再 ÷10000。**单位换算放在最后一步做，中间过程保留万元口径**，避免反复换算出错。

## 五、易错点清单

1. **忘除 (1+r)**——第一陷阱，选项里那个"现期×r"就是为你准备的。
2. **下降用错除数**：减少量 = 现期÷(n−1)，用成 n+1 会偏小。
3. **乘积法贴身时硬选**：乘积几乎相等时必须精算，修正项 ÷(1+r) 会翻转结果。
4. **"增长最多"答成增速最大的**——量率不分。
5. **单位**：万元/亿元、万吨/亿吨，算完最后统一换算。
6. **减少量答负数**：问"减少了多少"要正数。
7. 特殊分数背错一格（1/7 = 14.3% 记成 1/8），除数差 2，结果差一大截。

## 六、精讲例题

### 例题 1（特殊分数法）

**材料**：2023 年某港口货物吞吐量 12740 万吨，同比增长 14.3%。
**问**：比上年增加约多少万吨？
A. 1450　B. 1593　C. 1820　D. 1274

**解析**：

1. 14.3% ≈ 1/7 → 增长量 = 12740 ÷ (7+1) = 12740÷8 = **1592.5 ≈ 1593，选 B**。
2. 陷阱：C = 12740×14.3% = 1820（忘除 1.143，第一陷阱）；D = 1274（把 14.3% 当 10%，量级感错）。
3. 验算方向：1593×8 = 12744 ≈ 现期 ✓（除法可乘法回验，2 秒）。

### 例题 2（减少量）

**材料**：2023 年某企业亏损面收窄，利润 16800 万元，同比下降 16.7%。
**问**：2023 年利润比上年减少约多少万元？
A. 3360　B. 2800　C. 4032　D. 20160

**解析**：

1. 16.7% ≈ 1/6 → 减少量 = 现期 ÷ (6−1) = 16800÷5 = **3360，选 A**。
2. 陷阱：B = 16800÷6（忘掉"降减"，除数该减一）；C = 基期×r = 20160×0.2 = 4032（先求基期再乘 r，绕远且易错）；D = 20160 是基期本身（答非所问）。
3. 自洽检验：基期 20160 − 现期 16800 = 3360 ✓。

### 例题 3（一大一小看乘积 + 贴身翻车）

**材料**：2023 年甲省科研项目经费 30000 亿元，同比增长 4.8%；乙省 13000 亿元，同比增长 11.1%。
**问**：增长量较大的是：
A. 甲省，约 1370 亿元
B. 乙省，约 1300 亿元
C. 甲省，约 1440 亿元
D. 乙省，约 1443 亿元

**解析**：

1. 甲现期大、乙率大 → 一大一小，比乘积：甲 30000×4.8% = 1440；乙 13000×11.1% = 1443 → 乘积乙**微大 3**——**贴身！必须精算**。
2. 精算（特殊分数）：4.8% ≈ 1/21 → 甲 = 30000÷22 ≈ 1364；11.1% ≈ 1/9 → 乙 = 13000÷10 = 1300 → **甲大，选 A**。
3. 陷阱：D 是"乘积乙大 → 直接选乙"的翻车现场；C 是甲的乘积（忘除 1+r）。**乘积法只用来排明显差距，差距在 5% 以内一律精算。**

### 例题 4（表格直接减 + 尾数法）

**材料**：某厂 2023 年 1—4 月产量：1 月 4380 吨、2 月 4565 吨、3 月 4721 吨、4 月 4908 吨。
**问**：环比增加最多的月份是？
A. 2 月　B. 3 月　C. 4 月　D. 一样多

**解析**：

1. 直接减：2 月 +185、3 月 +156、4 月 +187 → **4 月，选 C**。
2. 技巧：增量分别是 5−0、1−5、8−1 的尾数组合（5、6、7），本题数小直接减；数大时用尾数法只算末位快速定位再精算锁定。

### 例题 5（量率辨析，一题两问）

**材料**：2023 年四省能耗（现期/基期，万吨标准煤）：甲 23000/20000、乙 9000/8000、丙 12000/10000、丁 55000/50000。
**问 1**：能耗增加最多的是？

**解析**：增量——甲 3000、乙 1000、丙 2000、丁 5000 → **丁**。

**问 2**：能耗增长最快的是？

**解析**：增速——甲 15%、乙 12.5%、丙 20%、丁 10% → **丙**。丁增量最大恰恰因为基数大，增速反而垫底；丙增量只有 2000 却涨得最猛。**"最多"和"最快"在同一组数据里选出两个答案，这种对价结构命题人百用不厌。**

### 例题 6（单位换算叠加）

**材料**：2023 年某公司营业收入 352000 万元，同比增长 9.1%。
**问**：营业收入比上年增加约多少**亿元**？
A. 2.9　B. 3.2　C. 29.3　D. 29333

**解析**：

1. 9.1% ≈ 1/11 → 增长量 = 352000÷12 = 29333 **万元**。
2. 换算：29333 万元 = **2.9 亿元，选 A**。
3. 陷阱：D = 29333（忘换算单位，单位就是考点）；C = 352000×9.1% = 32032 万元 ≈ 3.2 亿（忘除 1+r 且换算了单位——错误得更"高明"）；B 同为干扰。**看到问句里加粗的单位先圈出来，最后一步再换算。**

## 七、自测练习

1. 2023 年某市财政收入 8400 亿元，同比增长 25%。约增加多少亿元？
2. 2023 年某厂出货量 12400 万件，同比下降 11.1%。约减少多少万件？
3. 甲省社零 52000 亿元（+5.6%），乙省 48000 亿元（+6.7%）。增加较多的是谁？多约多少？
4. 两市常住人口（现期/基期，万人）：戊 66000/60000、己 24000/20000。增加最多和增长最快的分别是谁？

### 答案附录

1. 25% = 1/4 → 8400÷5 = **1680 亿元**（陷阱：8400×25% = 2100 忘除 1.25）。
2. 11.1% ≈ 1/9 → 12400÷8 = **1550 万件**（降减：分母 9−1 = 8）。
3. 一大一看乘积：甲 52000×5.6% = 2912；乙 48000×6.7% = 3216 → 乙；精算（1/18 → ÷19，1/15 → ÷16）：甲 ≈2737、乙 = **3000** → **乙，多约 260 亿元**。
4. 增量：戊 6000、己 4000 → 最多**戊**；增速：戊 10%、己 20% → 最快**己**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：看错行、拿错年份的数、单位注释没看；
- **列式错**：忘除 (1+r)、下降用 n+1、量率不分；
- **速算错**：特殊分数记错、乘积贴身时没精算、换算单位时截位过度；
- **陷阱错**："现期×r"干扰项、万元/亿元最后忘换算、"减少"答了负数。
