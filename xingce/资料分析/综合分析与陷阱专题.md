# 资料分析 · 综合分析与陷阱专题（找数防坑 + "能够推出"型收尾题）

> 每篇材料的最后一题（综合分析）把前面所有坑埋进同一篇材料，四个选项各考一个。资料分析的错题 **80% 是"陷阱错"而不是"不会算"**——所以这个专题的价值不亚于任何公式专题。
> 做题铁律：**按验证成本排序，不按 A→B→C→D 顺序**。
> 专题结构：**本质 → 陷阱总表 → 判断三步法 → 陷阱逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。陷阱清单简表另见 [知识点.md](知识点.md) 第五节。

---

## 一、本质：综合分析题是"命题人的陷阱展览会"

题型特征：**"能够从上述资料中推出的是："** 四个选项各是一个独立判断，只有一个成立（或问"不能推出"）。

三个事实决定策略：

1. 每个选项的验证成本差异巨大——有的一步除法，有的要换算单位再算基期；
2. 错误选项的错误点 90% 落在固定几类陷阱上（见下表）；
3. **验证 2 个选项就能锁定答案**（2 错 → 剩余 2 选 1 且方向明确；2 对 → 回读提问方式看是否"不能推出"型）。

所以正确动作是：**先扫四个选项，挑计算量最小的验证，用排除法收敛**，而不是从 A 开始按顺序死磕。

## 二、陷阱总表（六大类，逐个配破解）

| 陷阱 | 典型表述 | 破解 |
| --- | --- | --- |
| 时间陷阱 | "累计"vs"当月"；同比 vs 环比；题问 2022 材料给 2023 | 圈题干时间词，回表头核对 |
| 单位陷阱 | 材料亿元、选项万亿元；‰ 与 %；亿人次与人次 | 动笔前统一单位，最后一步换算 |
| 范围陷阱 | 全国 vs 该省；规上 vs 全部；制造业 vs 工业 | 主题词逐字匹配 |
| 概念陷阱 | 最多（量）vs 最快（率）；是几倍 vs 多几倍；超过/不足/约/接近 | 逐词抠字眼 |
| 基数陷阱 | 降幅收窄 ≠ 回升；负增长比较忘取绝对值 | 先定方向再比较 |
| 图表陷阱 | 纵轴截断；饼图含"其他"；双轴图左右刻度不同 | 看轴再读数 |

## 三、判断三步法（做综合分析题的固定动作）

1. **扫选项贴标签**：每个选项旁标注考点（基期？比重？增量？单位换算？），同步标验证成本（低/中/高）。
2. **按成本逐个验证**：一步加减/一步比重的先做；要换算 + 基期的后做；纯"材料没给"类（如材料只有分季度数据、选项说"四季度同比"）**零计算直接判死**。
3. **结论贴阈值必精算**：算出的值和"超过 7200"这类阈值几乎相等时，放缩法夹逼出区间再下结论（见 [速算方法专题.md](速算方法专题.md) 刀 1）。

**关键词翻译表**（概念陷阱的字典）：

| 题干词 | 数学含义 |
| --- | --- |
| 超过 / 不足 | 严格大于 / 严格小于（**恰好等于算"不成立"**） |
| 约 / 大约 | 允许小幅误差，方向和量级必须对 |
| 接近 | 差距在 10% 以内（命题口径） |
| 相近 / 大致相当 | 差距可放宽到 20%~30% |
| 增长最多 / 最快 | 增长量 / 增长率 |

## 四、陷阱逐个击破

### 陷阱 1：时间陷阱（累计/当期换算）

"下半年 = 全年 − 上半年"，"四季度 = 全年 − 前三季度"，"三季度单季 = 前三季度 − 上半年"。**最高频错误**：把"前三季度 − 上半年"当"下半年"（那是三季度单季）。表格列名是"1—X 月累计"的，取当期值必须做减法。

### 陷阱 2：数据存在性

材料只给环比数据，选项说"同比下降"——**推不出就是错**，"材料没给"不等于"算一算就有"。反向也成立：材料给"全年增长 x%"，选项问"四季度增长多少"——推不出（混合增速反向不可拆）。

### 陷阱 3：单位换算

亿元 ÷ 亿人次：量级字先约掉；亿元 ÷ 万人次 = 万元/人（差 4 个量级）。**平均数类选项是单位陷阱的favorite藏身处**——算之前先把复合单位写出来。

### 陷阱 4：恰好卡阈值

选项说"超过 2400"，算出来恰好 2400——不成立。"接近 75%"算出 73.3%——接近但不"超过"。**"约"字选项给宽限期，"超过/不足"一个字都不让。**

### 陷阱 5：方向性结论

"降幅收窄"≠ 回升；"由降转增"≠ 超过历史峰值（见 [增长率专题.md](增长率专题.md) 例题 5）；"占比下降"≠ 数值下降（比重是相对数，部分可能量增比重降）。

### 陷阱 6：图表读数

- **纵轴截断**：柱子高 2 倍 ≠ 数值大 2 倍（纵轴可能从 80 开始）；
- **饼图"其他"**："前三大合计占比"要自己加，且"其他"可能比第三大还大；
- **双轴图**：左轴右轴刻度不同，两条线的交点位置没有比较意义。

## 五、易错点清单

1. **按 A→D 顺序死磕**，在第 2 个选项耗掉 2 分钟——先贴标签排序。
2. **恰好等于阈值时选了"成立"**——"超过"是严格大于。
3. **累计当期换算错**（三季度单季当下半年）。
4. **"推不出"当成"要算"**——数据不存在直接判错，这是零计算得分点。
5. **量级换算错位**：亿元/万人次，差 4 个量级不是 8 个。
6. **图表题不看轴**就开始比大小。
7. 全部选项验证完都是"错"——回头检查提问方式是不是"**不能**推出"型。

## 六、精讲例题

### 例题 1（完整综合分析：一篇材料四个坑）

**材料**：2023 年，某市规模以上工业增加值 4520 亿元，同比增长 5.4%。其中，一季度 1030 亿元，同比增长 4.8%；上半年累计 2180 亿元，同比增长 5.1%；前三季度累计 3400 亿元，同比增长 5.3%。分所有制看，民营企业增加值 2760 亿元，同比增长 7.8%；国有控股企业 1280 亿元，同比增长 2.1%；外商及港澳台投资企业 480 亿元，同比下降 3.5%。

**问**：能够从上述资料中推出的是：
A. 2023 年下半年，该市规上工业增加值超过 2340 亿元
B. 2022 年外商及港澳台投资企业增加值不足 500 亿元
C. 2023 年国有控股企业增加值占比超过 30%
D. 2023 年四个季度中，增加值最高的是四季度

**逐项解析**（按验证成本重排：A → C → B → D）：

- **A（时间陷阱 · 恰好卡阈值）**：下半年 = 全年 − 上半年 = 4520 − 2180 = **恰好 2340 亿元**。"超过"要求严格大于 → **不成立**。挖坑点：如果手一滑用"前三季度 − 上半年 = 1220"当下半年，会算出更小的数，照样错。
- **C（现期比重，一步除法）**：1280/4520 ≈ 28.3% < 30% → **不成立**。若问的是"民营企业"（2760/4520 = 61.1%）就是"超过 60%"成立——**同一篇材料的比重，换个主体结论就反转，主体词逐字核对**。
- **B（基期 + 下降方向）**：480 ÷ (1−3.5%) = 480/0.965 ≈ **497.4 亿元 < 500** → "不足 500" **成立 ✓**。下降基期变大也没用——从 480 往上修一点点，还是过不了 500。
- **D（累计拆分 + 数据存在性）**：四季度 = 4520 − 3400 = 1120；三季度单季 = 3400 − 2180 = 1220；二季度 = 2180 − 1030 = 1150。最高的是**三季度**（1220），四季度反而最低 → **不成立**。

**答案：B。**
复盘：A、C 各一步加减/除法，先做；B 一步基期除法；D 需要拆三个季度，放最后——其实 D 靠"数据存在性 + 拆分"的标签就能预判成本最高。全程不到 90 秒。

### 例题 2（图表型综合分析）

**材料**：2019—2023 年某港货物吞吐量（亿吨）：5.2、4.8、5.6、6.1、6.5。（2020 年受外部冲击下降）

**问**：能够从上述资料中推出的是：
A. 2020 年吞吐量同比下降超过 8%
B. 2021 年吞吐量未恢复到 2019 年水平
C. 2023 年吞吐量比 2021 年增长不足 10%
D. 2019—2023 年年均增速超过 6%

**逐项解析**：

- **A（降幅 + 卡阈值）**：(5.2−4.8)/5.2 = 0.4/5.2 ≈ **7.7% < 8%** → "超过 8%"不成立。7.7% 和 8% 贴身，用放缩法：0.4/5.2，上限 0.4/5 = 8%，但分母实际是 5.2 > 5 → 真实值 < 8% → 稳判不成立。
- **B（直接读数比较）**：5.6 > 5.2 → "未恢复"不成立。
- **C（增长率，一步除法）**：6.5/6.1 = 1.0656 → 增长 **6.6% < 10%** → **成立 ✓**。
- **D（年均增速，n 的确定）**：n = 2023−2019 = **4**；总倍数 6.5/5.2 = 1.25 → 1.25^(1/4) ≈ 1.057 → 年均约 5.7% < 6% → 不成立。（若 n 误取 5，会算出 4.6% 附近——反正也不成立，但 n 错了 A 类逻辑就废了。）

**答案：C。**
复盘：B 零成本先判；A 一步除法；C 一步除法；D 要开方、成本最高放最后。**验证成本排序在图表题上同样成立。**

### 例题 3（"不能推出"型 + 提问方式反转）

**材料**：2023 年某省接待游客 5.6 亿人次，同比增长 12.8%；旅游总收入 6200 亿元，同比增长 18.3%。其中上半年接待游客 2.4 亿人次，旅游收入 2500 亿元。

**问**：**不能**从上述资料中推出的是：
A. 2023 年人均旅游消费超过 1100 元
B. 2022 年接待游客不足 5 亿人次
C. 2023 年下半年旅游收入占全年比重超过 60%
D. 2023 年人均旅游消费同比上升

**逐项解析**：

- **A（平均数 + 单位）**：6200 亿元 ÷ 5.6 亿人次 = **1107 元 > 1100** → 能推出。
- **B（基期 + 卡阈值）**：5.6/1.128 ≈ **4.96 亿 < 5 亿** → 能推出。结论贴阈值（4.96 vs 5.00），放缩夹逼确认：上限取分母舍位 5.6/1.12 = 5.00，但真实分母 1.128 **大于** 1.12 → 真实值**严格小于** 5.00 → "不足 5 亿"稳成立。**贴阈值题做到这个程度才敢下笔。**
- **C（当期拆分 + 比重）**：下半年收入 = 6200 − 2500 = 3700 → 3700/6200 ≈ **59.7% < 60%** → "超过 60%"不成立 → **不能推出，选 C**。
- **D（平均数方向判断，零计算）**：收入增速 18.3% > 人次增速 12.8% → 人均上升 → 能推出。

**答案：C。**
复盘：**"不能推出"型题的正确项是"错误陈述"**——方向和"能够推出"型完全相反，读完提问方式先在题旁写个"✗"提醒自己。B 项的贴阈值夹逼是本题真正的训练价值。

## 七、自测练习

**材料**：2023 年某市新能源汽车销量 28.8 万辆，同比增长 36.0%；其中纯电动 21.6 万辆，同比增长 40.0%。全年汽车总销量 96 万辆，同比增长 8.0%。2023 年 12 月当月新能源汽车销量 3.6 万辆。

判断下列各项能否从材料中推出（能/不能 + 一步验证）：

1. 2022 年新能源汽车销量超过 21 万辆。
2. 2023 年新能源汽车占汽车总销量的比重约为三成。
3. 2023 年 12 月新能源汽车销量环比上升。
4. 2023 年纯电动车占新能源汽车的比重比上年上升。

### 答案附录

1. **能**。28.8/1.36 ≈ 21.18 > 21 → "超过 21"成立（贴阈值：21.18 和 21 差 0.2，建议放缩夹逼确认）。
2. **能**。28.8/96 = 30%，恰好三成。
3. **不能**。材料只给 12 月当月值，没有 11 月数据，环比**推不出**（数据存在性陷阱——零计算得分点）。
4. **能**。纯电动增速 40% > 新能源整体 36% → 部分快于整体 → 占比上升（两期比重判断，零计算）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：累计当期没换算、年份/主体拿错行；
- **列式错**：基期方向反、比重整体找错；
- **速算错**：贴阈值结论没夹逼、量级换算错位；
- **陷阱错**：恰好等于阈值选"超过"、"推不出"当"要算"、"不能推出"型方向看反、按 A→D 顺序死磕超时。
