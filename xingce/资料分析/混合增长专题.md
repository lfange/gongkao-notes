# 资料分析 · 混合增长专题（线段法与十字交叉）

> 整体 = 部分一 + 部分二时，**整体增速是两部分增速的加权平均，精确权重为各部分基期量**。
> 线段法三步：**定区间 → 比基期量定偏向 → 按选项精度计算**。现期量加权只能作估算。
> 专题结构：**本质 → 公式族 → 判断三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。
> 本文例题为教学模拟数据，默认各部分可加、统计口径和价格口径一致；实际 GDP 数据不能直接用现价金额加权不变价增速。

---

## 一、本质：增速的加权平均

出口 + 进口 = 进出口，城镇 + 乡村 = 全省……整体增速 r 不是 (r₁+r₂)/2，而是：

$$r = \frac{基期_1 × r_1 + 基期_2 × r_2}{基期_1 + 基期_2}$$

因为整体增长量 = 基期₁×r₁ + 基期₂×r₂，而增长率的分母是整体基期。若材料给现期 A₁、A₂，则：

$$r = \frac{A_1+A_2}{A_1/(1+r_1)+A_2/(1+r_2)}-1$$

**权重是基期量**：基期块头大的一方，整体增速就贴近它。两部分基期量均为正、增速不相同时：

1. **r 介于两部分增速之间**（不可能比两者都大或都小）；
2. **r 靠近基期量大的那部分**；
3. **r 到两端的距离比 = 两部分基期量之反比**（线段法的灵魂）。

第 3 条的推导不用背，想天平：整体增速是天平支点，两端坐着两部分的增速，**谁重支点往谁那边挪**——"距离 × 重量"两边平衡，所以距离与重量成反比。

## 二、公式族（核心速查表）

| 步骤 | 工具 | 用途 |
| --- | --- | --- |
| 定区间 | r_min < r < r_max（两基期均正、增速不同） | 同速时整体同速 |
| 定偏向 | 偏向基期量大的部分 | 现期量接近时须换算基期 |
| 已知基期 B₁、B₂ | r = (B₁r₁ + B₂r₂)/(B₁+B₂) | 精确加权平均 |
| 已知现期 A₁、A₂ | r = (A₁+A₂)÷[A₁/(1+r₁)+A₂/(1+r₂)]−1 | 精确还原基期 |
| 距离关系 | B_高/B_低 = (r−r_低)/(r_高−r) | 高、低指增速，不指数量 |
| 反求部分增速 | 部分二基期 = 整体基期−部分一基期；r₂ = 现期₂/基期₂−1 | 已知整体和另一部分 |

**简单算术平均 (r₁+r₂)/2**：两部分增速不同时，只有**基期等量**才成立；若两部分增速相同，则任意权重都等于该增速。

**现期加权的误差**：两部分现期权重为 w₁、w₂时，近似值 r̂ = w₁r₁+w₂r₂；精确误差为 r̂−r = w₁w₂(r₁−r₂)²/[1+w₁r₂+w₂r₁]（r₁、r₂ > −1）。现期加权会偏高，增速差越大越要警惕。是否可用取决于选项间距，不能保证误差总是很小。

## 三、判断三步法（拿到题先走这三步）

1. **确认是"部分加和"结构吗？**——进出口、城乡、男女、年龄组、上半年+下半年。若两部分有重叠或遗漏（如"制造业"与"重工业"），不适用。
2. **给全量了吗？**——只给两个部分增速：可定区间，不能定偏向；给了量，还要辨清现期还是基期。
3. **问正向还是反向？**——求整体走三步；求某部分或求比例，用线段距离关系。

## 四、题型逐个击破

### 题型 1：求整体增速（正向三步）

先区间后偏向。已知基期量，直接加权；已知现期量，先各除 (1+r) 再相加。选项宽、增速差小时，可用现期加权估算，但要标明近似；接近选项分界时回到精确式。

反例：两部分现期都是 100，增速分别为 100% 和 0%。基期为 50、100，整体增速 = 200/150−1 = **33.3%**，并非现期加权得到的 50%。

### 题型 2：反求部分增速

已知整体 r 和部分一的 r₁、现期量：先用区间关系定方向，再算整体基期与部分一基期，相减得到部分二基期，最后求 r₂。直接拿现期量作距离比例只是估算。

### 题型 3：三部分混合（先合并或用总量差）

整体由三部分构成，给整体增速和两部分数据：用**整体基期−已知两部分基期**求第三部分基期，再求第三部分增速。也可用增长量守恒，但每个增长量均应算作现期×r/(1+r)，最后除第三部分**基期**。

### 题型 4：由距离关系反求量的比例

已知三增速 → 距离比先求**基期量比**。若题目问现期占比，将各自基期份数乘 (1+rᵢ) 后再归一；不能把基期占比直接当现期占比。

### 题型 5：混合结论判断（逻辑题）

不加数字，考结论：

- 部分增速 > 整体增速 → 该部分占比在上升（就是两期比重判断的另一种说法）；
- 一部分高于整体 → **必有另一部分低于整体**；
- 两部分增速不同时，整体增速恰为两部分的**中点** → 两部分**基期量相等**；现期量比为 (1+r₁):(1+r₂)。

## 五、易错点清单

1. **简单算术平均当整体增速**——精确权重是基期量，不能默认 1:1。
2. **区间结论忘了用**——选项有区间外的（比两部分都大/都小），直接排，别急着算。
3. **拿现期量定精确偏向**——现期量相近、增速差大时，基期大小可能反转。
4. **距离比例写反**——"到大量端的距离短"，距离与重量成**反**比。
5. **部分结构有重叠**（"制造业"与"规上工业"不是加和关系）硬套混合。
6. 三部分题直接套两部分十字交叉——先合并成两部分或用基期差；增长量算成现期×r、增长率除以现期，也会错。

## 六、精讲例题

### 例题 1（正向三步）

**材料**：2023 年某省出口额 15000 亿元，同比增长 20%；进口额 10000 亿元，同比增长 10%。
**问**：进出口总额同比增长约？
A. 10.0%　B. 15.0%　C. 15.8%　D. 20.0%

**解析**：

1. **定区间**：10% < r < 20% → A、D 排除。
2. **定偏向**：出口基期 = 15000/1.20 = 12500；进口基期 = 10000/1.10 ≈ 9090.91 → 整体偏向 20%，高于 15%。
3. **精算**：25000÷(12500+9090.91)−1 ≈ **15.8%，选 C**。
4. 现期加权得到 16%，可粗估但不是精确答案；简单平均得到 15%，忽略了基期权重。

### 例题 2（反求部分增速）

**材料**：2023 年某省社会消费品零售总额 21000 亿元，同比增长 6%。其中城镇 15000 亿元，同比增长 5%；乡村 6000 亿元。
**问**：乡村消费品零售额同比增长约？
A. 7.0%　B. 7.5%　C. 8.6%　D. 9.5%

**解析**：

1. 定方向：整体 6% 在城镇 5% 与乡村增速之间且高于 5% → 乡村 > 6%。
2. 整体基期 = 21000/1.06 ≈ 19811.32；城镇基期 = 15000/1.05 ≈ 14285.71。
3. 乡村基期 = 19811.32−14285.71 ≈ 5525.61；乡村增速 = 6000/5525.61−1 ≈ **8.6%，选 C**。
4. 现期量比 5:2 的线段估算给出 8.5%，此题接近但只能作近似；不能用现期×增速作增长量验算。

### 例题 3（三部分：总量差法）

**材料**：2023 年某国 GDP 1260000 亿元，同比增长 5.2%。其中第一产业 55000 亿元（+4.2%）、第二产业 470000 亿元（+4.8%）。
**问**：第三产业同比增长约？
A. 4.8%　B. 5.2%　C. 5.5%　D. 6.5%

**解析**：

1. 第三产业现期 = 1260000 − 55000 − 470000 = 735000 亿元。
2. 第三产业基期 = 1260000/1.052−55000/1.042−470000/1.048 ≈ 696462.24 亿元。
3. 第三产业增速 = 735000/696462.24−1 ≈ **5.5%，选 C**。
4. 三部分题用基期差即可。区间自检：整体 5.2% 高于第一、第二产业增速，第三产业必须高于 5.2%；这个结论不依赖谁占比最大。

### 例题 4（混合结论判断）

**材料**：2023 年全国商品零售额同比增长 5.8%，社会消费品零售总额同比增长 7.2%。
**问**：下列判断正确的是：
A. 餐饮收入增速必然低于 7.2%
B. 餐饮收入增速可能也是 5.8%
C. 商品零售额占社零总额的比重比上年下降
D. 无法判断餐饮收入增速与 7.2% 的关系

**解析**：

- 社零 = 商品零售 + 餐饮。商品零售 5.8% < 整体 7.2% → **必有另一部分（餐饮）> 7.2%** → A 错、D 错、B 错（若餐饮也是 5.8%，整体最高 5.8%，到不了 7.2%）。
- **C 对**：商品零售增速跑输整体 → 占比下降（混合结论 = 两期比重判断）。**选 C**。
- 深度：这道题一个数字都没算——混合体系的三条免费结论（区间、偏向、占比方向）覆盖了所有"判断型"选项。

### 例题 5（距离反求占比）

**材料**：2023 年某市 GDP 同比增长 6.5%。其中 A 区增长 10%，其余区县合计增长 5%。
**问**：A 区 GDP 约占全市的：
A. 31%　B. 35%　C. 43%　D. 70%

**解析**：

1. 距离：整体到低端 6.5%−5% = 1.5 个点；到高端 10%−6.5% = 3.5 个点。
2. 基期量比：A 区:其余区县 = 1.5:3.5 = 3:7 → **基期占比 30%**。
3. 现期量比 = 3×1.10 : 7×1.05 = 3.3:7.35 → 现期占比 = 3.3/(3.3+7.35) ≈ **31%，选 A**。
4. 陷阱：3/7 是两部分之比，不是占整体比重；30% 是基期占比，题目问现期时还要转换。

### 例题 6（中点 ⇔ 基期等量）

**材料**：2023 年某省进出口总额同比增长 9%，其中出口增长 12%，进口增长 6%。
**问**：可推出：
A. 出口额大于进口额
B. 出口额小于进口额
C. 出口额等于进口额
D. 贸易逆差

**解析**：

1. 整体 9% 恰是 12% 与 6% 的中点 → **两部分基期量相等**。
2. 设基期各 100，现期出口 112、进口 106 → **出口额大于进口额，选 A**；C 的“等于”错误，D 的贸易逆差也不成立。
3. 中点对应的是基期等量；增速高的一部分现期量更大。

## 七、自测练习

1. 出口 8000 亿元（+15%），进口 6000 亿元（+5%）。进出口总额同比增速约为？
2. 全市工业增加值 10000 亿元（+8%），其中重工业 7000 亿元（+10%）。轻工业 3000 亿元的增速约为？
3. 全省 GDP 增长 7.2%，其中省会城市增长 12%，其余城市合计增长 6%。省会 GDP 约占全省几成？
4. 判断：某省商品房销售面积同比下降 8%，其中期房下降 12%。现房销售面积的同比变化可能是 +3% 吗？

### 答案附录

1. 14000÷(8000/1.15+6000/1.05)−1 ≈ **10.5%**；现期加权的 10.7% 只是粗估。
2. 轻工业基期 = 10000/1.08−7000/1.10 ≈ 2895.62；增速 = 3000/2895.62−1 ≈ **3.6%**。
3. 基期量比 1.2:4.8 = 1:4，基期占比 20%；现期占比 = 1.12/(1.12+4×1.06) ≈ **20.9%，约两成**。
4. **可能**。整体 −8%，期房 −12%（低于整体）→ 现房必须高于 −8%，+3% 满足区间（−8% < +3%，且现房量足够小即可加权出 −8%）。混合只保证"另一部分高于整体"，不规定正负。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：量的口径拿错（现期/基期混用）、"其余部分"的量漏了倒推；
- **列式错**：简单平均代替加权、距离比例写反、三部分硬套两部分公式；
- **速算错**：加权平均分母加错、截位过度；
- **陷阱错**：简单平均、现期加权当精算、把基期占比当现期占比、把中点当现期等量。
