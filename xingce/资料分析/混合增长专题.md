# 资料分析 · 混合增长专题（线段法与十字交叉）

> 整体 = 部分一 + 部分二时，**整体增速是两部分增速的加权平均**（权重 = 各部分现期量）——进出口、城乡、男女、上下游，全是这个结构。
> 线段法三步：**定区间 → 定偏向 → 要精确再交叉**。前两步零计算就能排掉一半选项。
> 专题结构：**本质 → 公式族 → 判断三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：增速的加权平均

出口 + 进口 = 进出口，城镇 + 乡村 = 全省……整体增速 r 不是 (r₁+r₂)/2，而是：

$$r = \frac{现期_1 × r_1 + 现期_2 × r_2}{现期_1 + 现期_2}$$

**权重是现期量**：谁块头大，整体增速就贴近谁。由此立刻得到三条免费结论：

1. **r 介于两部分增速之间**（不可能比两者都大或都小）；
2. **r 靠近现期量大的那部分**；
3. **r 到两端的距离比 = 两部分数量之反比**（线段法的灵魂）。

第 3 条的推导不用背，想天平：整体增速是天平支点，两端坐着两部分的增速，**谁重支点往谁那边挪**——"距离 × 重量"两边平衡，所以距离与重量成反比。

## 二、公式族（核心速查表）

| 步骤 | 工具 | 用途 |
| --- | --- | --- |
| 定区间 | r_min < r < r_max | 排除区间外选项 |
| 定偏向 | 偏向现期量大的部分 | 排除中点型干扰项 |
| 精确值 | r = (A₁r₁ + A₂r₂)/(A₁+A₂) | 加权平均 |
| 距离关系 | (r − r_小)/(r_大 − r) = 量大者/量小者 | 已知三增速求量的比例 |
| 反求部分增速 | 解加权方程 | 已知整体和另一部分 |

**最经典干扰项**：简单算术平均 (r₁+r₂)/2——只有两部分**等重**时才等于加权平均，命题人逢混合题必配。

## 三、判断三步法（拿到题先走这三步）

1. **确认是"部分加和"结构吗？**——进出口、城乡、男女、年龄组、上半年+下半年。若两部分有重叠或遗漏（如"制造业"与"重工业"），不适用。
2. **给全量了吗？**——只给增速：只能做区间和偏向判断；给了量：可精算。
3. **问正向还是反向？**——求整体走三步；求某部分或求比例，用线段距离关系。

## 四、题型逐个击破

### 题型 1：求整体增速（正向三步）

先区间后偏向，多数题不用精算；要精算时用加权平均。**估算时分母用现期总量**（近似用现期量加权，误差极小，考场上不必换成基期量）。

### 题型 2：反求部分增速

已知整体 r 和部分一的 r₁、量，求部分二 r₂：解加权方程。先用区间关系定方向（r₂ 必在 r 的另一侧），再算。

### 题型 3：三部分混合（先合并或用总量差）

GDP = 一产 + 二产 + 三产，给 GDP 增速和两个产业，求第三个：把"已知两产业"的增量加总，用**总增量相减**求第三产业增量，再除以其现期量。

### 题型 4：由距离关系反求量的比例

已知整体增速和两部分增速 → 距离比 = 量的反比 → 可求"某部分占比"。这是线段法的高阶用法，考"某省出口占进出口的比重约为"这类题。

### 题型 5：混合结论判断（逻辑题）

不加数字，考结论：

- 部分增速 > 整体增速 → 该部分占比在上升（就是两期比重判断的另一种说法）；
- 一部分高于整体 → **必有另一部分低于整体**；
- 整体增速恰为两部分的**中点** → 两部分现期量**相等**。

## 五、易错点清单

1. **简单算术平均当整体增速**——权重是现期量，不是 1:1。
2. **区间结论忘了用**——选项有区间外的（比两部分都大/都小），直接排，别急着算。
3. **偏向判断用基期量**——用现期量近似即可，别浪费时间先求基期。
4. **距离比例写反**——"到大量端的距离短"，距离与重量成**反**比。
5. **部分结构有重叠**（"制造业"与"规上工业"不是加和关系）硬套混合。
6. 三部分题直接套两部分十字交叉——先合并成"两部分"或改用增量差。

## 六、精讲例题

### 例题 1（正向三步）

**材料**：2023 年某省出口额 15000 亿元，同比增长 20%；进口额 10000 亿元，同比增长 10%。
**问**：进出口总额同比增长约？
A. 10%　B. 15%　C. 16%　D. 20%

**解析**：

1. **定区间**：10% < r < 20% → A、D 排除。
2. **定偏向**：出口 15000 > 进口 10000 → r 偏向 20% 一侧 → 比 15% 大 → B 排除，预判 C。
3. **精算**：(15000×20% + 10000×10%)/25000 = (3000+1000)/25000 = **16%，选 C**。
4. 陷阱：B = (20%+10%)/2，简单平均——**出口占 60% 的盘子，增速凭什么跟进口对半分**。

### 例题 2（反求部分增速）

**材料**：2023 年某省社会消费品零售总额 21000 亿元，同比增长 6%。其中城镇 15000 亿元，同比增长 5%；乡村 6000 亿元。
**问**：乡村消费品零售额同比增长约？
A. 7%　B. 7.5%　C. 8.5%　D. 9.5%

**解析**：

1. 定方向：整体 6% 在城镇 5% 与乡村增速之间且高于 5% → 乡村 > 6%。
2. 线段法：整体比城镇快 1 个点；城镇量:乡村量 = 15000:6000 = 5:2 → 乡村比整体快 1×5/2 = 2.5 个点 → 乡村 ≈ 6% + 2.5% = **8.5%，选 C**。
3. 验算（增量差）：总增量 = 21000×6% = 1260；城镇增量 = 15000×5% = 750；乡村增量 = 510 → 510/6000 = 8.5% ✓。
4. 陷阱：A = 7%（简单平均思路 (5%+x)/2 = 6% 解出）；B = 距离比写反（1×2/5 = 0.4 个点 → 6.4% 附近的漂移项）；D = 距离算对但把"快 2.5 个点"夸成"快 3.5 个点"。

### 例题 3（三部分：总量差法）

**材料**：2023 年某国 GDP 1260000 亿元，同比增长 5.2%。其中第一产业 55000 亿元（+4.2%）、第二产业 470000 亿元（+4.8%）。
**问**：第三产业同比增长约？
A. 4.8%　B. 5.2%　C. 5.5%　D. 6.5%

**解析**：

1. 第三产业现期 = 1260000 − 55000 − 470000 = 735000 亿元。
2. 增量差：总增量 = 1260000×5.2% = 65520；一产增量 = 55000×4.2% = 2310；二产增量 = 470000×4.8% = 22560 → 三产增量 = 65520 − 2310 − 22560 = 40650。
3. 三产增速 = 40650/735000 ≈ **5.5%，选 C**。
4. 深度：三部分别套十字交叉，**"增量总和守恒"是最稳的路**——所有混合问题底层都是增量守恒。区间自检：三产占比最大（58%）且整体 5.2% 高于一二产 → 三产必须 > 5.2% ✓。

### 例题 4（混合结论判断）

**材料**：2023 年全国商品零售额同比增长 5.8%，社会消费品零售总额同比增长 7.2%。
**问**：下列判断正确的是：
A. 餐饮收入增速必然低于 7.2%
B. 餐饮收入增速可能也是 5.8%
C. 商品零售额占社零总额的比重比上年下降
D. 无法判断餐饮收入增速与 7.2% 的关系

**解析**：

- 社零 = 商品零售 + 餐饮。商品零售 5.8% < 整体 7.2% → **必有另一部分（餐饮）> 7.2%** → A 错、D 错、B 错（若餐饮也是 5.8%，整体最高 5.8%，到不了 7.2%）。
- **C 对**：商品零售增速跑输整体 → 占比下降（混合结论 = 两期比重判断）。**选 C**。
- 深度：这道题一个数字都没算——混合体系的三条免费结论（区间、偏向、占比方向）覆盖了所有"判断型"选项。

### 例题 5（距离反求占比）

**材料**：2023 年某市 GDP 同比增长 6.5%。其中 A 区增长 10%，其余区县合计增长 5%。
**问**：A 区 GDP 约占全市的：
A. 30%　B. 35%　C. 43%　D. 70%

**解析**：

1. 距离：整体到低端 6.5%−5% = 1.5 个点；到高端 10%−6.5% = 3.5 个点。
2. 距离比 = 量的反比 → A 区量:其余量 = 1.5:3.5 = 3:7 → A 区占比 = 3/10 = **30%，选 A**。
3. 陷阱：C = 3/7（把距离比直接当占比，忘了"反比"和"归一"）；D = 7/10（两边拿反）。**验算：0.3×10% + 0.7×5% = 3% + 3.5% = 6.5% ✓。**

### 例题 6（中点 ⇔ 等量）

**材料**：2023 年某省进出口总额同比增长 9%，其中出口增长 12%，进口增长 6%。
**问**：可推出：
A. 出口额大于进口额
B. 出口额小于进口额
C. 出口额与进口额大致相当
D. 贸易逆差

**解析**：

1. 整体 9% 恰是 12% 与 6% 的**中点** → 距离相等 → 两部分现期量相等 → **选 C**。
2. 陷阱：A、B 方向瞎猜；D 无关（顺逆差看绝对值不是增速）。**"增速居中点"="两端等重"，这条推论偶尔单独成题。**

## 七、自测练习

1. 出口 8000 亿元（+15%），进口 6000 亿元（+5%）。进出口总额同比增速约为？
2. 全市工业增加值 10000 亿元（+8%），其中重工业 7000 亿元（+10%）。轻工业 3000 亿元的增速约为？
3. 全省 GDP 增长 7.2%，其中省会城市增长 12%，其余城市合计增长 6%。省会 GDP 约占全省几成？
4. 判断：某省商品房销售面积同比下降 8%，其中期房下降 12%。现房销售面积的同比变化可能是 +3% 吗？

### 答案附录

1. (1200+300)/14000 = 1500/14000 ≈ **10.7%**（先区间 5~15，再偏向 15 一侧，精算收尾）。
2. 增量差：总增量 800 − 重工业 700 = 100 → 100/3000 ≈ **3.3%**（区间自检：3.3% < 8% < 10% ✓）。
3. 距离：7.2−6 = 1.2；12−7.2 = 4.8 → 省会:其余 = 1.2:4.8 = 1:4 → 省会占 **两成**（验算 0.2×12+0.8×6 = 2.4+4.8 = 7.2 ✓）。
4. **可能**。整体 −8%，期房 −12%（低于整体）→ 现房必须高于 −8%，+3% 满足区间（−8% < +3%，且现房量足够小即可加权出 −8%）。混合只保证"另一部分高于整体"，不规定正负。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：量的口径拿错（现期/基期混用）、"其余部分"的量漏了倒推；
- **列式错**：简单平均代替加权、距离比例写反、三部分硬套两部分公式；
- **速算错**：加权平均分母加错、截位过度；
- **陷阱错**：(r₁+r₂)/2 干扰项、区间外选项没先排、"中点=等量"没看出来。
