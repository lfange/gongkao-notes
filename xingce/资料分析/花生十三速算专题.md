## 一、体系总览：花生十三的速算世界观

两句话：

1. **选项思维**——与 [速算方法专题](速算方法专题.md) 的"选项决定精度"同源：算到选项分开就停；
2. **份数思想**（他的独门）——增长率 r 本质是一个**比例**：r = 1/n 时，基期和增长量天然构成 **n : 1** 的整数比。与其做除法，不如**把现期切成几份分掉**。

## 二、份数思想：把百分号变成"几份"

推导一遍就再也不用背：

r = 增长量 ÷ 基期。若 r = 1/n，即**基期每 n 份，增长量就占 1 份**。于是：

$$基期 : 增长量 : 现期 = n : 1 : (n+1)$$

现期 = 基期 + 增长量，份数自然相加。**"415"这个名字**就来自 r = 25% = 1/4 的情形：基期 4 份、增长量 1 份、现期 5 份——**4 : 1 : 5**。

为什么这套思想比"背公式"强：

- 已有笔记里的"增长量 = 现期÷(n+1)"只是**取 1 份**这一个动作；份数思想是**切一次份，基期（n 份）、增长量（1 份）、现期（n+1 份）、倍数（(n+1)/n）四个量全部到手**；
- 反过来也能用：知道"增长量 : 现期"的比，直接读出 r；
- r 不是 1/n 而是普通分数（如 37.5% = 3/8）时照样切：基期 8 份、增长量 3 份、现期 11 份。

## 三、415 份数法详解

### 3.1 标准三步

1. **认分数**：r ≈ 1/n 吗？——靠背熟[特殊分数表](常用数据速查表.md)（14.3%↔1/7、16.7%↔1/6、12.5%↔1/8……）；
2. **切份**：现期 ÷ (n+1) = 每份的量；
3. **取份**：要增长量拿 1 份，要基期拿 n 份，要倍数用 (n+1)/n。

下降时：基期 : 减少量 : 现期 = n : 1 : (n−1)，即口诀"**升加降减**"。

### 3.2 四个应用方向（一套切份全出）

以"2023 年某省规上工业利润 5550 亿元，同比增长 25%"为例（r = 1/4 → 现期 5 份）：

| 问题 | 取法 | 答案 |
| --- | --- | --- |
| 增长量 | 1 份 | 5550÷5 = **1110 亿元** |
| 基期（2022 年） | 4 份 | 1110×4 = **4440 亿元** |
| 2023 年是 2022 年的几倍 | (n+1)/n = 5/4 | **1.25 倍** |
| 增长率（反求） | 份比 1 : 4 | **1/4 = 25%** |

第三行是最容易被忽视的红利：**"是上年几倍"根本不用算出两个量再相除**，份数比直接就是倍数。

### 3.3 反用：给"增长量 : 现期"读出 r

已知 2023 年增量 600 亿元、现期 4800 亿元：增长量 : 现期 = 600 : 4800 = 1 : 8 → 现期是 (n+1) 份 → n = 7 → **r = 1/7 ≈ 14.3%**。
（验算：基期 = 4800−600 = 4200，600÷4200 = 14.3% ✓）

### 3.4 下降版与普通分数版

- **下降**：现期 4500，同比下降 20%（= 1/5）→ 基期 : 减少量 : 现期 = 5 : 1 : **4** → 每份 = 4500÷4 = 1125 → 基期 **5625**、减少量 **1125**。注意**现期是最小的份数（n−1 份）**，别切反。
- **普通分数**：r = 37.5% = 3/8 → 基期 8 份、增长量 3 份、现期 11 份 → 增长量 = 现期×3/11。常用的几个：2/5 = 40%、3/8 = 37.5%、3/7 ≈ 42.9%、5/6 ≈ 83.3%。

### 3.5 修正：r 不恰好是 1/n 时（415 的灵魂补丁）

真题的 r 常是 14.7%、11.0% 这种"差一口气"的数。**先按邻近的 1/n 切份，再修正**：

- **方向**：r 实际比 1/n **大** → 真实增长量比份数法结果**大**、基期比份数法结果**小**；反之对称。（直觉：增速更快，"长出来的部分"占得更多。）
- **幅度**：修正量 ≈ 现期 × Δr ÷ (1+r)²，实战简记"**现期×Δr，打八折**"（r 在 10%~15% 时 1/(1+r)² ≈ 0.8，r 更大就打七五折）。

例：现期 8400，r = 14.7%（邻近 1/7 = 14.3%，Δr = +0.4 个百分点）：

- 份数法：8400÷8 = 1050；
- 修正：8400×0.4% ≈ 34，打八折 ≈ **+27** → 增长量 ≈ **1077**（精算 1076.5 ✓）。

**什么时候不用修正**：Δr ≤ 0.2 个百分点、且选项间距明显大于修正量（约为现期×0.2%×0.8）时，直接用份数法结果。

## 四、假设分配法详解（r 丑时的主力）

### 4.1 为什么需要它

r = 7.6%：不贴任何特殊分数（1/13 = 7.7% 勉强沾边，但 3772÷14 依然难截）；直除 3772/1.076 更难受。花生的解法：**不做除法，做"分配"**——把现期量按

$$基期 : 增长量 = 1 : r$$

的比例分掉。"分配"的好处：可以**先分一个整数大头，零头再补一轮**，全程只有好算的乘法和加减法，而且**基期和增长量一次同时到手**。

### 4.2 标准四步

以求基期 3772（r = 7.6%）为例：

1. **假设**：给基期分一个整数大头。挑"×r 好算"的数——3500×7.6% = 266 口算无压力；
2. **乘**：增长量 = 3500×7.6% = 266；
3. **比差**：假设现期 = 3500+266 = 3766，比真实现期 3772 **少了 d = 6**；
4. **再分配**：把差额 d 也按 1 : 0.076 分掉——基期拿 d/(1+r) = 6/1.076 ≈ 5.6，增长量拿剩下的 0.4。

结果：**基期 ≈ 3505.6**（精算 3505.6 ✓），增长量 ≈ 266.4。一次分配，两个量同时到手。

### 4.3 差额怎么分（唯一的记忆点）

差额 d 继续按 1 : r 拆，于是：

> **基期拿 d/(1+r) ≈ d×(1−r)，增长量拿 d×r/(1+r) ≈ d 的 r 折。**

d 通常很小（几十以内），随手近似即可：r ≈ 8% 时基期拿九成、增长量拿一成；r ≈ 17% 时基期拿 85%、增长量拿 15%。

### 4.4 猜差了也不怕：零头再分一轮

第一轮大头**不必猜准**。例：现期 8821，r = 6.3%：

- 第一轮拿整数 8000：增长量 = 8000×6.3% = 504，合计 8504，零头 **d = 317**；
- 第二轮分零头：基期再拿 317/1.063 ≈ 317×0.94 ≈ 298（用化除为乘近似即可，二级修正不需要准），增长量拿 19；
- 结果：基期 ≈ **8298**（精算 8298.2 ✓），增长量 ≈ 523。

这就是"**先分大头、再分零头**"：大头图快，零头图准。零头分完通常只剩个位数，可以再分第三轮，也可以直接停（误差已被选项间距淹没）。

### 4.5 何时用假设分配（三选一决策）

| r 的长相 | 首选 |
| --- | --- |
| 贴着 1/n（±0.2 个百分点内） | 415 份数法 |
| 不贴 1/n，但"×r 好算"（7.6%、6.4%、17.2%……） | **假设分配法** |
| r ≤ 5% 且只要基期 | 化除为乘（下节，更省事） |

经验：**r 在 5%~20% 的"丑数区间"且选项贴身时，假设分配几乎是唯一又快又准的刀**；选项松时直接截位直除更省事。

## 五、化除为乘：小增长率的免死金牌

### 5.1 公式与误差

$$\frac{A}{1+r} = A×(1-r+r^2-r^3+\cdots) ≈ A×(1-r) + A·r^2$$

即 **÷(1+r) ≈ ×(1−r)**，结果**偏小** A·r²。r ≤ 5% 时误差 < 0.25%×A——选项间距普遍在 1% 以上，够用：

| r | 误差量级（占 A） |
| --- | --- |
| 3% | 0.09% |
| 5% | 0.25% |
| 8% | 0.64%（基本不能用） |
| 11% | 1.2%（千万别用） |

例：89200/(1+4.3%) ≈ 89200×0.957 = 85364（精算 85522，差 158 ≈ 89200×4.3%² = 165 ✓）。

**二次修正（选项贴身时）**：把 A·r² 加回去 → 85364+165 = 85529（精算 85522 ✓），两步合起来就是准精算。

### 5.2 下降版

÷(1−r) ≈ ×(1+r)，同样偏小、同样补 A·r²。例：4500/0.9 ≈ 4500×1.1 = 4950，补 4500×1% = 45 → 4995（精算 5000 ✓）。

### 5.3 和 415 的关系

r ≤ 5% 时 1/n 的 n ≥ 20，切份不直观；化除为乘相当于"n 很大时的退化版份数法"。两者衔接：**r ≥ 5% 用 415/假设分配，r < 5% 用化除为乘**。

## 六、配套小工具

1. **逢乘化除**：×12.5% = ÷8、×25% = ÷4、×16.7% = ÷6……（特殊分数表倒着用）；
2. **乘法拆分**：453.7×6.4% = 453.7×6% + 453.7×0.4% = 27.2+1.8 ≈ 29——两个一位数乘法替一个两位数乘法；
3. **回乘验算**：算出基期后 ×(1+r) 验一下能否回到现期（3505.6×1.076 ≈ 3772 ✓）——2 秒自检，假设分配的数字全是近似拼出来的，尤其值得验；
4. **十几乘十几**：口诀"**前头 = 一个数加另一个的个位，后头 = 个位相乘（满十要并进去）**"。13×14 → 13+4 = 17、3×4 = 12 → 170+12 = **182**；15×16 → 21、30 → 210+30 = **240**；12×18 → 20、16 → **216**。原理一行看穿：(10+a)(10+b) = 10×(10+a+b) + ab——前头是 10+a+b，后头是 ab，**后头是加法不是拼数字**。资料分析的主战场是**隔年增长率的乘积项**：r₁ = 13%、r₂ = 15%，乘积项 = 13%×15% = (13×15)×万分之一 → 13×15 = 195 → 1.95%，隔年 r = 13%+15%+1.95% ≈ **30%**，全程无竖式。顺手把 11²~19² 背成明牌（121、144、169、196、225、256、289、324、361），化除为乘的二次修正 A·r² 和选项里的平方数直接读出；
5. **乘 11（两边一拉、中间相加）**：34×11 = 3(3+4)4 = 374；87×11 = 8(15)7，中间满十进位 → 957。和十几乘十几是一家人：11 = 10+1，本质"乘 10 加自身"。

## 七、总决策表（拿到式子走哪条路）

| 式子长相 | 刀 | 一句话 |
| --- | --- | --- |
| r ≈ 1/n | 415 份数法 | 切 n+1 份，按份取 |
| r 丑、要基期/增长量 | 假设分配法 | 先分大头再分零头 |
| r ≤ 5%、要基期 | 化除为乘 | ×(1−r)，贴身再补 r² |
| 只要 1~2 位精度 | 截位直除 | [速算方法专题](速算方法专题.md) |
| 两个分数比大小 | 首位 → 差分 | [速算方法专题](速算方法专题.md) |
| 部分加整体的增速 | 线段法 | [混合增长专题](混合增长专题.md) |
| 多个增长量比大小 | 大大则大 / 比乘积 | [增长量专题](增长量专题.md) |

顺序心法：**先看 r 的长相（特殊分数？丑数？小数？），再看选项精度**——r 决定用哪把刀，选项决定磨多快。

## 八、易错点清单

1. **415 忘修正**：r = 14.7% 按 1/7 切完直接选——差 0.4 个点，增长量差近 3%（8400 的题差 27），贴身选项就翻车。
2. **修正方向反**：r 比 1/n 大，增长量该上修却下修——记"**增速快，长得多**"。
3. **假设分配大头选太偏**：零头比大头还大，分三轮没收口——第一轮拿"现期×(1−r) 的整值"即可。
4. **化除为乘超射程**：r > 5% 还在用，误差吃掉整个选项间距（r = 11% 时误差 1.2%）。
5. **下降版切反**：下降是 n : 1 : (n−1)，现期是最小份数，别把现期当 n 份。
6. **问基期又做一次除法**：切完份基期就是 n 份直接乘，别再 ÷(1+r) 一遍。
7. **省略回乘验算**：假设分配全是近似拼装，不回乘等于裸奔。
8. **十几乘十几把"加"当"拼"**：个位积满十时必须并进前头（15×16 = 210+30 = 240），把 21 和 30 硬拼成 2130、或丢掉十位只留个位，都是同一个错——口诀念完整"**满十要并进去**"再落笔。

## 九、精讲例题

### 例题 1（415 全家桶：一次切份，三问全出）

**材料**：2023 年某省规上工业利润 5550 亿元，同比增长 25%。
**问**：① 增长量约为？② 2022 年约为？③ 2023 年是 2022 年的几倍？

**解析**：
1. 25% = 1/4 → 基期 : 增长量 : 现期 = 4 : 1 : 5 → 现期 5 份，每份 5550÷5 = 1110。
2. ① 增长量 = 1 份 = **1110 亿元**；② 基期 = 4 份 = **4440 亿元**；③ 倍数 = 5/4 = **1.25 倍**。
3. 陷阱：若选项里出现 1387.5，那是 5550×25%（现期×r，忘除 1+r）。切份法天然免疫——1 份永远小于"现期×r"对应的大小。
4. 深度：**切一次份，材料里的量全在份里取**——这是份数思想对"一问一除法"的降维打击。

### 例题 2（下降版 415）

**材料**：2023 年某市二手房成交 4500 万㎡，同比下降 20%。
**问**：2022 年成交面积约为多少万㎡？
A. 3600　B. 5400　C. 5625　D. 5850

**解析**：
1. 下降 20% = 1/5 → 基期 : 减少量 : 现期 = 5 : 1 : **4**（现期是 n−1 份）。
2. 每份 = 4500÷4 = 1125 → 基期 = 5 份 = **5625，选 C**。
3. 陷阱：A = 4500×0.8（"下降就乘"）；B = 4500×1.2（方向全反）。
4. 深度：切份前先念一遍"**升加降减**"——下降题的现期永远是最小的份数。

### 例题 3（415 + 修正）

**材料**：2023 年某省社会消费品零售总额 8400 亿元，同比增长 14.7%。
**问**：比上年增加约多少亿元？
A. 1050　B. 1077　C. 1235　D. 1023

**解析**：
1. 14.7% 邻近 1/7 = 14.3%（Δr = +0.4 个百分点）→ 先按份数法：8400÷8 = 1050。
2. 修正：r 实际更大 → 增长量**上修**：8400×0.4% ≈ 34，打八折 ≈ +27 → **1077，选 B**（精算 1076.5）。
3. 陷阱：A = 不修正的份数法结果；C = 8400×14.7% = 1235（现期×r）；D = 修正方向反了。
4. 深度：**四个选项各踩一个具体的坑**——这就是"背了表不修正"和"修正反方向"在真题里的样子。

### 例题 4（假设分配法）

**材料**：2023 年某企业研发投入 3772 万元，同比增长 7.6%。
**问**：2022 年研发投入约为多少万元？
A. 3395　B. 3486　C. 3506　D. 3560

**解析**：
1. r = 7.6%：不贴特殊分数，直除 3772/1.076 难截——**上假设分配**。
2. 假设基期 3500（3500×7.6% = 266 好算）→ 假设现期 = 3766 → 差 d = 6。
3. 基期补 d/(1+r) ≈ 5.6 → **基期 ≈ 3506，选 C**（精算 3505.6）。
4. 陷阱：B = 3772×0.924 = 3486（化除为乘超射程：r = 7.6% 时误差 0.58% ≈ 20 万元，正好掉坑）。
5. 深度：B 这个选项专门收割"化除为乘用顺手了、忘了看 r 大小"的人——**每把刀都有射程**。

### 例题 5（假设分配两轮：大头猜偏也不怕）

**材料**：2023 年某市财政收入 8821 亿元，同比增长 6.3%。
**问**：2022 年财政收入约为多少亿元？增长量呢？

**解析**：
1. 第一轮拿整数大头 8000：增长量 = 8000×6.3% = 504，合计 8504，零头 d = 317。
2. 第二轮分零头：基期再拿 317/1.063 ≈ 317×0.94 ≈ 298 → 基期 ≈ 8000+298 = **8298**（精算 8298.2）。
3. 增长量顺手也出来了：504+19 ≈ **523**。回乘验算：8298×1.063 ≈ 8821 ✓。
4. 深度：第一轮故意只拿整的 8000（不纠结猜准），因为**零头可以再分一轮**——"假设"两个字的意思就是允许你先糙后准。

### 例题 6（化除为乘 + 二次修正）

**材料**：2023 年全国粮食产量 69541 万吨，同比增长 1.3%。
**问**：2022 年粮食产量约为多少万吨？
A. 68400　B. 68650　C. 68900　D. 69200

**解析**：
1. r = 1.3% ≤ 5% → 化除为乘：69541×(1−1.3%) = 69541 − 904 ≈ 68637。
2. 选项贴身 → 补二次修正：+69541×1.3%² ≈ +12 → **68649 ≈ 68650，选 B**（精算 68648.6）。
3. 增长量 = 69541 − 68649 ≈ **892**（低增速捷径 69541×1.3% = 904 是它的上界）。
4. 深度：化除为乘的误差 12 万吨听着吓人，**二次修正一行加法就消除**——"×(1−r) 再补 A·r²"两步就是准精算。

### 例题 7（综合：假设分配打底，算基期比重）

**材料**：2023 年某省高技术制造业增加值 12760 亿元，同比增长 7.1%；规上工业增加值 152300 亿元，同比增长 4.3%。
**问**：2022 年高技术制造业占规上工业的比重约为？
A. 7.4%　B. 8.2%　C. 9.0%　D. 9.8%

**解析**：
1. 基期比重 = (12760/1.071) ÷ (152300/1.043)——两个基期都不贴特殊分数，**双假设分配**：
   - 12760/1.071：假设 12000 → 12000×7.1% = 852 → 12852，d = −92 → 基期 ≈ 12000 − 92×0.93 ≈ **11914**；
   - 152300/1.043：假设 146000 → 146000×4.3% = 6278 → 152278，d = 22 → 基期 ≈ 146000+21 ≈ **146021**。
2. 基期比重 = 11914/146021 → 截位 119/1460 → 商 0.082 → **8.2%，选 B**。
3. 验算：现期比重 12760/152300 ≈ 8.4% > 8.2%，且部分增速 7.1% > 整体 4.3% → 比重上升，方向 ✓。
4. 深度：**"两个丑 r 的基期 + 一个除法"**是基期比重题的标准形态——假设分配负责把两个基期算准，截位直除负责最后一步。三把刀接力，每把只干自己最擅长的活。

## 十、自测练习

1. 现期 6300，r = 25%：基期、增长量各是多少？现期是基期的几倍？
2. 现期 4242，r ≈ 16.7%：增长量约为多少？
3. 现期 5550，同比下降 20%：上年值与减少量各是多少？
4. 2023 年增长量 600 亿元、现期 4800 亿元：r 约为多少？
5. 用假设分配法：现期 4567，r = 8.2%，基期约为多少？
6. 用化除为乘（含二次修正）：现期 78400，r = 2.6%，基期约为多少？
7. 现期 24371，r = 11.0%：用份数法 + 修正求增长量。
8. 2023 年同比增长 13%，2022 年同比增长 15%：用十几乘十几求隔年增长率。

### 答案附录

1. 每份 1260 → 基期 **5040**、增长量 **1260**、倍数 5/4 = **1.25**。
2. 16.7% ≈ 1/6 → 现期 7 份 → 4242÷7 = **606**。
3. 下降 1/5 → 基期 : 减少量 : 现期 = 5 : 1 : 4 → 每份 1387.5 → 上年 **6937.5**、减少量 **1387.5**。
4. 增长量 : 现期 = 600 : 4800 = 1 : 8 → n+1 = 8 → r = 1/7 ≈ **14.3%**。
5. 假设 4200 → 4200×8.2% = 344.4 → 4544.4 → d = 22.6 → 基期 ≈ 4200+21 ≈ **4221**（精算 4220.9）。
6. 78400×0.974 = 76362；二次修正 +78400×2.6%² ≈ +53 → **≈76415**（精算 76413）。
7. 11.0% 邻近 1/9 = 11.1%（Δr = −0.1 个百分点）→ 份数法 24371÷10 = 2437；修正 24371×0.1%×0.8 ≈ −20 → **≈2417**（精算 2415，误差已小于 1）。
8. 13×15：13+5 = 18、3×5 = 15 → 180+15 = 195 → 乘积项 1.95% → 隔年 r = 13%+15%+1.95% = **29.95% ≈ 30%**（验算 1.13×1.15 = 1.2995 ✓）。
