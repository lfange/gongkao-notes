# 资料分析 · 隔年与年均增长专题（跨期增长的两种形态）

> 隔年和年均都是"跨过不止一年"的增长：隔年是**已知两段增速求总效果**，年均是**已知总效果求平均每段**——互为逆运算。
> 各自有一个专属坑：隔年坑在**交叉项 r₁r₂**，年均坑在 **n 的确定**。
> 专题结构：**本质 → 公式族 → 判断三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。幂值反查表见 [常用数据速查表.md](常用数据速查表.md) 第二节。

---

## 一、本质：乘法链的两头

2021 → 2022 → 2023，每一步乘一个 (1+r)：

$$(1+r_{隔}) = (1+r_1)(1+r_2) \quad\Rightarrow\quad r_{隔} = r_1 + r_2 + r_1 r_2$$

隔年展开后多出交叉项 r₁r₂——它就是"利息的利息"。年均则是把整条链"平均"：

$$(1+r)^n = \frac{现期}{基期}，\quad n = 年份差$$

两条公式的考点分布：隔年考**交叉项算不算、方向反不反**，年均考 **n 取几、怎么不解方程**。

## 二、公式族（核心速查表）

| 场景 | 公式 / 要点 | 专属坑 |
| --- | --- | --- |
| 隔年增速 | r₁ + r₂ + r₁r₂ | 交叉项 |
| 隔年增速（异号） | 如 6% 和 −4%：6−4−0.24 = 1.76% | 交叉项变负 |
| 隔年基期 | 现期 ÷ (1+r_隔) | 只除一年 |
| 反求其中一年 | r₂ = (1+r_隔)/(1+r₁) − 1 | 直接相减 |
| 年均增速 | (1+r)ⁿ = 现期/基期 | **n = 年份差** |
| 年均增长量 | (现期 − 基期) ÷ n | 同一个 n |

**交叉项要不要算？** 两个增速都 < 5% 时交叉项 < 0.25 个百分点，选项间距大可忽略；**任一个 ≥ 5% 时交叉项 ≥ 0.25 个百分点，常正好卡在两个选项之间，必算**（交叉项速查表见 [常用数据速查表](常用数据速查表.md) 第 3.4 节）。

## 三、判断三步法（拿到题先走这三步）

1. **跨了几年？**——比"上年"多跨一年的，进入本专题；只跨一年回 [增长率专题.md](增长率专题.md)。
2. **求总还是求平均？**——给两段增速求总效果 → 隔年；给首尾求平均 → 年均。
3. **n 等于几？**——年均题动笔前先定 n：**大年减小年**（2025 − 2020 = 5）。"十四五""十三五"这类区间，基期是**规划期前一年**。

## 四、题型逐个击破

### 题型 1：隔年增速（正向）

r₁ + r₂ + r₁r₂。两个增速同号交叉项为正，异号为负（一涨一跌时，交叉项在"抵消"你）。**先算 r₁+r₂ 再补交叉项**，两步各 5 秒。

### 题型 2：隔年增速（反向求其中一年）

已知隔年总增速和其中一年，求另一年：

> r₂ = (1+r_隔)/(1+r₁) − 1

别背变形，记原理：(1+r_隔) = (1+r₁)(1+r₂)，知道俩求第三个，**永远是解方程**。最经典的错误是直接相减（r_隔 − r₁），漏掉乘法结构。

### 题型 3：隔年基期

"2021 年约为多少"：先合成 r_隔 再除一次。命题人标配两个干扰项——**只除 r₁ 一次、只除 r₂ 一次**，各对应一个"偷懒答案"。

### 题型 4：年均增速（n 的确定 + 编数代入）

考场**不解高次方程**，三步：

1. 算总倍数（现期/基期），如 1.4 倍；
2. 对照背过的幂值：1.06⁵≈1.34、**1.07⁵≈1.40**、1.08⁵≈1.47、1.1⁵≈1.61、2^(1/5)≈1.15（完整表见 [常用数据速查表](常用数据速查表.md)）；
3. 落在两档之间就插值，或把选项代回去验证。

**n 的三大高危情形**：

| 表述 | 基期 | n |
| --- | --- | --- |
| "十四五"期间（2021—2025） | 2020 年 | **5** |
| 2018—2023 年 | 2018 年 | **5** |
| 2023 年比 2019 年增长…… | 2019 年 | **4** |

年均增长量 = (现期 − 基期)/n，**和年均增速共用同一个 n**。

### 题型 5：幂值反查（数字特征题）

总倍数恰是 1.21、1.44、1.4641 这类"熟面孔"时直接反查：1.21 = 1.1²（两年均 10%）、1.44 = 1.2²、1.4641 = 1.1⁴（四年均 10%）。看到 1.4641 要瞳孔地震——这是 1.1⁴ 的指纹。

## 五、易错点清单

1. **n 取成年数**而不是年份差："2021—2025 年"n = 5 不是 4/5（五年规划基期在前一年，n = 5；"2018—2023"n = 5，2023−2018）。
2. **交叉项该算没算**：选项间距 0.5 个百分点以内时，0.25 以上的交叉项决定答案。
3. **异号交叉项没变号**：6% 和 −4% 的交叉项是 −0.24%。
4. **反求直接相减**：r_隔 − r₁ 漏掉乘法结构。
5. **隔年基期只除一年**——两个"只除一年"干扰项各配一个选项。
6. **年均增速 ≈ 总增速 ÷ 年数**——复利滚雪球，真实年均永远**明显小于**总增幅÷年数。
7. 年均增长量的 n 与年均增速的 n 不一致（低级但常见）。

## 六、精讲例题

### 例题 1（隔年正向 + 交叉项卡选项）

**材料**：2023 年某省社会消费品零售总额同比增长 12%，2022 年同比增长 8%。
**问**：2023 年总额比 2021 年增长约？
A. 19.04%　B. 20%　C. 20.96%　D. 21.6%

**解析**：

1. r_隔 = 12% + 8% + 12%×8% = 20% + 0.96% = **20.96%，选 C**。
2. 陷阱：B = 20%（忘交叉项——两个增速都不小，0.96% 正好卡在 B、C 之间，必算）；A = 20% − 0.96%（交叉项变号，当成异号）；D 凑。
3. 深度：**1.12×1.08 = 1.2096**，两位数乘法 5 秒可验，交叉项不需要"背要不要算"——选项贴身就算。

### 例题 2（隔年反向求其中一年）

**材料**：2023 年某市财政收入比 2021 年增长 56%，其中 2023 年同比增长 20%。
**问**：2022 年同比增长约？
A. 28%　B. 30%　C. 32%　D. 36%

**解析**：

1. 列方程：(1+56%) = (1+20%)×(1+r₂) → 1+r₂ = 1.56/1.20 = 1.30 → r₂ = **30%，选 B**。
2. 陷阱：D = 56% − 20%（直接相减，漏乘法结构）；A、C 是除法截位漂移。**验算：1.2×1.3 = 1.56 ✓——回代一步，答案自洽。**

### 例题 3（隔年基期，异号）

**材料**：2023 年某省原煤产量 42400 万吨，同比增长 6%；2022 年同比下降 1%。
**问**：2021 年该省原煤产量约为多少万吨？
A. 39900　B. 40400　C. 40000　D. 40800

**解析**：

1. 隔年增速：6% + (−1%) + 6%×(−1%) = 5% − 0.06% = 4.94%（异号，交叉项为负）。
2. 基期 = 42400 ÷ 1.0494 ≈ **40400，选 B**。
3. 陷阱：C = 42400÷1.06 = 40000（只除 2023 一年——最顺手也最错的路径）；A = 42400÷1.0631 附近的粗除漂移；D 凑。**验算：40400×1.0494 ≈ 42396 ✓。**

### 例题 4（年均：n 的确定 + 反查）

**材料**："十三五"期间（2016—2020 年），某市人均可支配收入从 2015 年的 25000 元增长至 2020 年的 33500 元。
**问**：该时期年均增长率约为？
A. 5%　B. 6%　C. 6.8%　D. 8%

**解析**：

1. 定 n：基期 2015、现期 2020 → n = 5。
2. 总倍数 = 33500/25000 = 1.34。
3. 反查：1.06⁵ ≈ 1.34 → **6%，选 B**。
4. 陷阱：C = 34%÷5 = 6.8%（"总增幅÷年数"，年均增速永远小于它）；A、D 是幂值没背准的漂移。**n 若取 4（把基期误当 2016），开方得 7.6% 附近，落进 C、D 之间两头不靠——n 错全局错。**

### 例题 5（年均增长量 + 年均增速双问）

**材料**：某高新区营业收入 2019 年为 440 亿元，2025 年为 880 亿元。
**问 1**：2019—2025 年年均增长量约为多少亿元？

**解析**：n = 2025−2019 = **6** → (880−440)/6 ≈ **73.3 亿元/年**。

**问 2**：年均增长率约为？
A. 10%　B. 12.2%　C. 14%　D. 16.7%

**解析**：

1. 总倍数 = 2，n = 6 → 2^(1/6) ≈ 1.122 → **12.2%，选 B**。
2. 陷阱：D = 73.3/440 ≈ 16.7%（年均增长量 ÷ 基期——量率混算，D 项就是问 1 的答案加工成的干扰项）；A、C 是幂值漂移。
3. 深度：**年均增长量用"首尾平均"，年均增速用"开方"**，两者数值差很远（73.3 亿的"平均增量"对应的是 12.2% 的复利，不是 16.7%）。

### 例题 6（幂值指纹题）

**材料**：2023 年某省外贸进出口总额比 2019 年增长 46.41%。
**问**：这四年的年均增长率约为？
A. 9.5%　B. 10%　C. 11.6%　D. 12%

**解析**：

1. 总倍数 = 1.4641——**1.1⁴ = 1.4641**，指纹级数字。
2. n = 2023−2019 = 4 → 年均增速 = **10%，选 B**。
3. 陷阱：C = 46.41%÷4（总增幅÷年数）。**考场上见到 1.21、1.44、1.331、1.4641、1.61 这几个数，先想 1.1 的幂。**

## 七、自测练习

1. 2023 年某省固定资产投资同比增长 15%，2022 年增长 20%。2023 年比 2021 年增长约？
2. 2023 年某市社会消费品零售总额比 2021 年增长 21%，2023 年同比增长 10%。2022 年同比增长约？
3. "十四五"期间某高新区营收从 2020 年的 400 亿元增至 2025 年的 536 亿元。年均增长率约为？
4. 某市 GDP 2017 年为 12000 亿元，2024 年为 26000 亿元。2017—2024 年年均增长量约为多少亿元？

### 答案附录

1. 15% + 20% + 3% = **38%**（交叉项 15%×20% = 3%，两个增速都大，必算）。
2. 1.21/1.10 = 1.10 → **10%**（(1+r₂) = 1.21/1.10，别 21−10 直接减）。
3. n = 5；总倍数 536/400 = 1.34 → 1.06⁵ ≈ 1.34 → **约 6%**。
4. n = 7 → (26000−12000)/7 = **2000 亿元/年**（大年减小年：2024−2017 = 7）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：基期年份定位错（五年规划基期在前一年）、增速和年份配错对；
- **列式错**：忘交叉项、异号没变号、反求直接相减、n 取错；
- **速算错**：幂值没背准、总倍数截位过度；
- **陷阱错**："总增幅÷年数"冒充年均增速、隔年只除一年、年均量/率混算。
