# 资料分析 · 倍数与翻番专题（是几倍、多几倍、翻 n 番）

> "是几倍"和"多几倍"相差 1，"翻两番"是 ×4 不是 ×2——倍数题考的是**文字翻译**，计算反而不难。
> 基期倍数和基期比重是同一个公式，学会一次就会两次。
> 专题结构：**本质 → 公式族 → 判断三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。幂值备查见 [常用数据速查表.md](常用数据速查表.md) 第 2.3 节。

## 一、本质：倍数是"相对大小"的三种说法

同一个事实"A 是 B 的 3 倍"，考卷上有三种问法，三个答案各不相同：

| 问法 | 算式 | 答案 |
| --- | --- | --- |
| A **是** B 的几倍 | A ÷ B | 3 |
| A **比** B **多**几倍 | (A − B) ÷ B | 2 |
| A 比 B **增长**了百分之几 | (A − B) ÷ B | 200% |

"多 2 倍" = "是 3 倍" = "增长 200%"——**命题人最爱在选项里同时放 2 和 3**，读题逐字抠"是"还是"多"。

**翻番是倍数的指数形式**：翻 n 番 = ×2ⁿ。翻一番 ×2、翻两番 ×4、翻三番 ×8、翻四番 ×16。注意区分："增长 2 倍"是 ×3（变到 3 倍），"翻两番"是 ×4——两句话数字里都有"2"，结果差 1。

## 二、公式族（核心速查表）

| 场景 | 公式 | 易错点 |
| --- | --- | --- |
| 是几倍 | A ÷ B | "是"字直接除 |
| 多几倍 | (A − B) ÷ B = 是几倍 − 1 | **别忘了 −1** |
| 基期倍数 | (A/B) × (1+b_B)/(1+a_A) | A 增得快 → 基期倍数更小 |
| 翻 n 番 | 现期 = 基期 × 2ⁿ | 翻两番 ×4 |
| 反求翻番前的值 | 基期 = 现期 ÷ 2ⁿ | 除法别乘反 |
| "多 x 倍"反求 A | A = B × (x+1) | 忘 +1 必错 |

## 三、判断三步法（拿到题先走这三步）

1. **"是"还是"多"？**——是几倍直接除；多几倍记得结果 −1（或反求时 +1）。
2. **现期还是基期？**——"2022 年 A 是 B 的几倍"要乘修正项 (1+b)/(1+a)。
3. **"番"还是"倍"？**——番走 2 的幂（2、4、8、16），倍走加法（+1）。听到"翻两番"先默念 ×4。

## 四、题型逐个击破

### 题型 1：是几倍 / 多几倍（双问）

两个答案恒差 1。做这类题**先算"是几倍"**（一次除法），再按提问 −1，比列两个式子快。

### 题型 2：基期倍数

> 基期倍数 = 现期倍数 × (1+b_乙)/(1+a_甲)（甲 ÷ 乙，a 甲增速、b 乙增速）

结构与基期比重完全同源——**"现期值 × (1+分母侧增速)/(1+分子侧增速)"是一套公式**：基期比重、基期倍数、基期平均共用。修正方向直觉：**分子（被比者 A）增得快 → 基期倍数更小**。

### 题型 3：翻番正向

"比 2018 年翻了两番" → 现期 = 2018 年值 × 4。先在心里换算成 2ⁿ 再动笔，**别把"两番"当"两倍"**。

### 题型 4：翻番反求

"2023 年为 3200 亿元，比 2018 年翻了五番" → 2018 年 = 3200 ÷ 32 = 100 亿元。五番 = 2⁵ = 32，幂值要背（见 [常用数据速查表](常用数据速查表.md) 第 2.3 节）。

### 题型 5："多 x 倍"条件句

"甲比乙多 1.5 倍"翻译成数学语言：甲 = 乙 × 2.5。**"多 x 倍"里的 x 要 +1 才是倍率**，这是条件理解题的固定坑。

## 五、易错点清单

1. "是几倍"与"多几倍"差 1——两个数常同时出现在选项里。
2. "翻两番"当 ×2、"增长 2 倍"当 ×2——正确分别是 ×4、×3。
3. 基期倍数修正项方向乘反（(1+a)/(1+b) 记反）。
4. "多 x 倍"反求忘 +1。
5. 翻番反求时乘除反（×32 而不是 ÷32）。
6. 单位不统一就相除（亿元 ÷ 万元）。

## 六、精讲例题

### 例题 1（是几倍 / 多几倍双问）

**材料**：2023 年甲省研发经费投入 1425 亿元，乙省 475 亿元。
**问**：甲省投入是乙省的多少倍？比乙省多多少倍？

**解析**：先算"是几倍"：1425/475 = 3 倍；"多几倍"再 −1 = 2 倍。
陷阱：若做成选择题，选项必有 3 和 2 各一个——**先除再减，两问问的都是它**。

### 例题 2（基期倍数）

**材料**：接上题。甲省研发经费同比增长 25%，乙省增长 5%。
**问**：2022 年甲省投入是乙省的多少倍？
A. 2.40　B. 2.52　C. 2.86　D. 3.00

**解析**：

1. 定方向：甲（分子）增得快 → 基期倍数**小于**现期 3 倍 → C、D 排除。
2. 修正：3 × (1+5%)/(1+25%) = 3 × 1.05/1.25 = **2.52，选 B**。
3. 陷阱：D = 3（现期倍数，忘修正）；A = 3÷1.25 = 2.4（只修了甲一侧）；C = 3÷1.05 = 2.86（修错了对象）。**验算：1425/1.25 = 1140；475/1.05 ≈ 452.4；1140/452.4 = 2.52 ✓。**

### 例题 3（翻番正向）

**材料**：2015 年某新能源企业营收 60 亿元，到 2023 年恰好翻了四番。
**问**：2023 年营收约为多少亿元？
A. 120　B. 240　C. 480　D. 960

**解析**：翻四番 = ×2⁴ = ×16 → 60×16 = **960 亿元，选 D**。
陷阱：C = ×8（当成翻三番）；B = ×4（当成翻两番）；A = ×2（当成翻一番/两倍）。**"番"每多一翻数字翻一倍，读题先数清翻了几番。**

### 例题 4（翻番反求）

**材料**：2023 年某市数字经济规模 3200 亿元，比 2018 年翻了五番。
**问**：2018 年该市数字经济规模约为多少亿元？
A. 100　B. 160　C. 200　D. 640

**解析**：五番 = 2⁵ = 32 → 2018 年 = 3200÷32 = **100 亿元，选 A**。
陷阱：D = 3200÷5（"翻了五番"当"增长 5 倍"再除）；B、C 是幂值记错。**反求时是除法——"翻番前的数更小"，方向感先立住。**

### 例题 5（"多 x 倍"条件句）

**材料**：某报告指出，2023 年甲市跨境电商进出口额比乙市多 2.4 倍，乙市该值为 1300 亿元。
**问**：甲市跨境电商进出口额约为多少亿元？
A. 3120　B. 4420　C. 5460　D. 2600

**解析**：

1. 翻译："多 2.4 倍" = "是 3.4 倍" → 甲 = 1300 × 3.4 = **4420，选 B**。
2. 陷阱：A = 1300×2.4 = 3120（忘 +1，本题第一干扰项）；D = 1300×2 = 2600（"多 2.4 倍"粗略当 2 倍）。
3. 深度：**"多 x 倍"进式子前必 +1**，和"是几倍 → 多几倍要 −1"是同一条规则的来回。

### 例题 6（基期倍数反向变式）

**材料**：2023 年甲市地铁客运量是乙市的 4 倍。甲市同比增长 20%，乙市同比增长 25%。
**问**：2022 年甲市客运量是乙市的约多少倍？
A. 3.20　B. 3.84　C. 4.00　D. 4.17

**解析**：

1. 定方向：乙（分母）增得快 → 把倍数"垫高"了 → 基期倍数**大于**现期 4 倍 → A、B、C 排除。
2. 修正：4 × (1+25%)/(1+20%) = 4 × 1.25/1.20 ≈ **4.17，选 D**。
3. 陷阱：B = 4×1.20/1.25（修正方向反）；A、B、C、D 四个选项把"只修一侧""修反""不修"配齐了。**验算：设乙现期 1000、甲现期 4000 → 基期甲 = 3333、基期乙 = 800 → 3333/800 = 4.17 ✓。**

## 七、自测练习

1. 2023 年 A 市财政收入 9600 亿元，B 市 2400 亿元。A 市是 B 市的几倍？比 B 市多几倍？
2. 2023 年甲厂产量是乙厂的 2.5 倍，甲厂增长 5%，乙厂增长 10%。2022 年甲厂是乙厂的几倍？
3. 某县 2020 年一般公共预算收入 130 亿元，若到 2025 年恰好翻两番，2025 年约为多少亿元？
4. 某省港口货物吞吐量比上年多 0.6 倍，上年为 2500 万吨。今年约为多少万吨？

### 答案附录

1. 9600/2400 = **是 4 倍，多 3 倍**（先除再减）。
2. 2.5 × 1.10/1.05 = 2.5 × 1.0476 ≈ **2.62 倍**（乙增得快 → 基期倍数更大）。
3. 130 × 4 = **520 亿元**（翻两番 = ×2² = ×4）。
4. 2500 × 1.6 = **4000 万吨**（"多 0.6 倍"= 是 1.6 倍，+1 再乘）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：两个主体的数拿反、年份拿错；
- **列式错**：多几倍忘 −1 / 反求忘 +1、番当倍、修正项方向反；
- **速算错**：2 的幂记错（2⁵ 当 16）、截位过度；
- **陷阱错**：选项里"是几倍"和"多几倍"成对出现选错、"翻两番"选了 ×2 的选项。
