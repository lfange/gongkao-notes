# 资料分析 · 比重专题（现期、基期、两期比重与比重差）

> 比重题占资料分析题量的四分之一，其中"两期比重"是全模块性价比最高的考点：**判断升降零计算（比增速大小），算差值有定式（乘上比重再修正）**。
> 整体是谁、单位是"百分点"，这两件事先于一切计算。
> 专题结构：**本质 → 公式族 → 判断三步法 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。个人笔记见 [笔记.md](笔记.md) 的比重差条目。

---

## 一、本质：部分跑赢整体多少

> **比重 = 部分 ÷ 整体**（A/B，A 部分现期值，B 整体现期值，a、b 为对应增速）

比重的一切变形都围绕一个问题：**部分和整体，谁涨得快？**

- a > b → 部分份额在扩大 → 比重**上升**；
- a < b → 部分份额在缩小 → 比重**下降**。

"两期比重判断"只需要这一行字，**不用任何计算**。算"上升几个百分点"才需要公式，而那个结果永远**远小于 a−b**——比重差 ≈ 现期比重 × 增速差，中间还夹着 ÷(1+a) 的折扣。

## 二、公式族（核心速查表）

| 场景 | 公式 | 计算量 |
| --- | --- | --- |
| 现期比重 | A/B | 一次除法 |
| 基期比重 | A/B × (1+b)/(1+a) | 修正项 1+b 比 1+a |
| 两期比重升降 | **a > b 升，a < b 降** | **零计算** |
| 比重差 | A/B × (a−b)/(1+a)，单位**百分点** | 三步定式 |

**比重差三步定式**（能不算就不算）：

| 步骤 | 动作 | 耗时 |
| --- | --- | --- |
| ① 判方向 | a > b 升，a < b 降 | 3 秒，排一半选项 |
| ② 卡上限 | \|比重差\| < 现期比重 × \|a−b\| < \|a−b\| | 10 秒，多数题到此出答案 |
| ③ 修一点 | 现期比重 × 增速差 ÷ (1+a)；a < 10% 可不修 | 选项贴身才用 |

## 三、判断三步法（拿到题先走这三步）

1. **整体是谁？**——"占**全国**的比重"整体是全国；"占**服务业**的比重"整体是服务业；"占全省 GDP 的比重"整体是全省 GDP 不是全国。逐字读"占"字后面。
2. **问现期还是基期？**——"2023 年占比"用 A/B；"2022 年占比"用基期比重公式。
3. **问方向还是问幅度？**——"上升还是下降"零计算；"上升几个百分点"上三步定式。

## 四、题型逐个击破

### 题型 1：现期比重（含饼图"其他"）

部分÷整体，截位直除。饼图材料注意：**占比之和含"其他"项**，"前三大行业合计占比"要自己加。部分值没直接给时用"整体 − 其他部分"倒推。

### 题型 2：基期比重

> 基期比重 = 现期比重 × (1+b)/(1+a)（b 整体增速、a 部分增速）

修正方向有直觉：**部分涨得快（a 大），说明它的占比在涨，去年（基期）占比必然更低**。先定性再定量：算出修正项是让现期比重变小还是变大，方向错了全错。

### 题型 3：两期比重判断（性价比之王）

只比 a、b 大小，三秒出答案。**最高频的坑**：部分在增长、但增速跑输整体 → 比重仍下降（"增长 ≠ 占比上升"）。零增速、负增速的部分照样参与比较。

### 题型 4：比重差（升几个百分点）

三步定式走完。两条量级感：

- **比重差 < \|a−b\|**（部分增速为正时恒成立）——选项里那个等于 a−b 的是头号陷阱；
- 比重差 ≈ 现期比重 × 增速差——比重 30%、增速差 5 个点 → 差值也就 1.5 个点上下，再 ÷(1+a) 打个折。

### 题型 5：反求部分或整体

已知比重和整体求部分：部分 = 整体 × 比重；已知部分和比重求整体：整体 = 部分 ÷ 比重。常和基期公式叠一层（见例题 6）。

## 五、易错点清单

1. **整体找错**——"占全国的比重"用了全省增速当 b，全盘皆错。
2. **百分点 ≠ 百分数**：比重差说"个百分点"；选项把比重差和平均数增长率（%）混排。
3. **比重差永远远小于 a−b**——"增速差冒充比重差"是第一陷阱选项。
4. **a 很大（如 30%+）时 ÷(1+a) 折扣狠**，必须修。
5. **"增长但跑输整体"当上升**——4.9% < 5.0%，比重照样降。
6. 基期比重修正项方向乘反（(1+a)/(1+b) 记反）。
7. 饼图"其他"项、表格"合计"行的口径没对齐。

## 六、精讲例题

### 例题 1（现期比重 + 部分倒推）

**材料**：2023 年某省 GDP 52000 亿元，其中第一产业 2800 亿元、第二产业 21000 亿元。
**问 1**：第一产业占 GDP 的比重约为？
A. 3.8%　B. 5.4%　C. 7.2%　D. 9.4%

**解析**：2800/52000，截位 28/520 = 0.054 → **5.4%，选 B**。

**问 2**：第三产业占 GDP 的比重约为？

**解析**：第三产业 = 52000 − 2800 − 21000 = 28200 → 28200/52000 = 54.2%。**部分没直接给就用整体倒推，别在材料里干找。**

### 例题 2（基期比重）

**材料**：2023 年某市装备制造业增加值 7800 亿元，同比增长 14.3%；全市工业增加值 39000 亿元，同比增长 10%。
**问**：2022 年装备制造业占全市工业的比重约为？
A. 17.8%　B. 19.2%　C. 20.0%　D. 20.9%

**解析**：

1. 现期比重：7800/39000 = 20%。
2. 定方向：a = 14.3% > b = 10% → 占比在涨 → **基期比重 < 20%**，C、D 排除。
3. 修正：20% × 1.10/1.143 = 20% × 0.962 ≈ **19.2%，选 B**。
4. 陷阱：C = 现期比重（忘修正）；D = 20%×1.143/1.10（修正方向反）。

### 例题 3（比重差，三步定式完整走一遍）

**材料**：2023 年某国铁路客运量中高铁客运量 12100 万人次，同比增长 15%；铁路客运总量 44000 万人次，同比增长 10%。
**问**：2023 年高铁客运量占铁路客运总量的比重比上年约：
A. 上升 1.2 个百分点
B. 上升 5 个百分点
C. 下降 1.2 个百分点
D. 上升 1.4 个百分点

**解析**：

1. **判方向**：15% > 10% → 上升，C 排除。
2. **卡上限**：\|a−b\| = 5 个百分点 → B（上升 5 个百分点）必错——比重差永远小于增速差。
3. **修一点**：现期比重 = 12100/44000 = 27.5%；比重差 = 27.5% × 5% ÷ 1.15 ≈ 1.2 → **选 A**。
4. 陷阱：D = 27.5% × 5% = 1.375 ≈ 1.4（忘 ÷(1+a)）。a = 15% 时折扣明显，必须修。

### 例题 4（两期比重判断：增长但跑输）

**材料**：2023 年某省规上工业增加值同比增长 5.0%。分行业：电动汽车制造业 +30.8%、纺织业 +1.2%、化纤行业 −2.5%、钢铁行业 +4.9%。
**问**：与上年相比，2023 年占规上工业增加值比重上升的行业有几个？

**解析**：

- 电动汽车 +30.8% > 5.0% → **升**；
- 纺织 +1.2% < 5.0% → 降；
- 化纤 −2.5% < 5.0% → 降；
- 钢铁 +4.9% **< 5.0% → 降**！

**只有 1 个行业上升。** 钢铁是本题的题眼：明明在增长，只差 0.1 个百分点没跑赢整体，比重照样降。**"占比上升"的唯一标准是 a > b，与 a 本身正负、大小无关。**

### 例题 5（整体找错：占全国的比重）

**材料**：2023 年某省 GDP 96000 亿元，同比增长 6.0%；全国 GDP 1260582 亿元，同比增长 5.2%。
**问 1**：该省 GDP 占全国的比重约为？
A. 6.9%　B. 7.6%　C. 8.1%　D. 9.4%

**解析**：96000/1260582，截位 9.6/126 ≈ 0.076 → **7.6%，选 B**。

**问 2**：该比重与上年相比？

**解析**：a = 6.0%（省）> b = 5.2%（全国）→ **上升**，幅度 = 7.6% × 0.8% ÷ 1.06 ≈ 0.06 个百分点——**上升但不到 0.1 个百分点**。深度：全国增速 5.2% 是"整体"，别顺手拿全省工业增速或省内某产业增速当 b；占比题的 b 永远是"占"字后面那个主体的增速。

### 例题 6（反求部分 + 基期叠加）

**材料**：2023 年某市工业投资 2800 亿元，同比增长 12%；其中技术改造投资占 35%，技术改造投资同比增长 18%。
**问**：2022 年技术改造投资占工业投资的比重约为？
A. 30.7%　B. 33.2%　C. 35.0%　D. 36.8%

**解析**：

1. 现期技改 = 2800 × 35% = 980 亿元（不用算出来，直接用比重链条）。
2. 基期比重 = 35% × (1+12%)/(1+18%) = 35% × 1.12/1.18 = 35% × 0.949 ≈ **33.2%，选 B**。
3. 方向自检：技改增速 18% > 整体 12% → 占比在涨 → 基期更小 ✓。陷阱：C = 现期比重；D = 修正方向反。

## 七、自测练习

1. 2023 年某区文创产业营收 4200 亿元，全区总营收 60000 亿元。文创占比约为？
2. 2023 年某省新能源汽车销售额 4500 亿元（+20%），全省社零 30000 亿元（+8%）。2022 年新能源汽车占社零的比重约为？
3. 2023 年某产品出口额占出口总额的 40%，产品出口增长 24%，出口总额增长 10%。占比比上年上升约几个百分点？
4. 2023 年全市 GDP 增长 6.8%。甲企业增加值增长 6.9%、乙企业 6.8%、丙企业 −10%。三企业增加值占全市 GDP 比重分别上升、不变还是下降？

### 答案附录

1. 4200/60000 = **7%**（截位 42/600）。
2. 现期 15%，基期 = 15% × 1.08/1.20 = **13.5%**（a 大 → 基期更小）。
3. ① 24% > 10% 升；② 上限 14 个百分点；③ 40% × 14% ÷ 1.24 ≈ **4.5 个百分点**。
4. 甲 6.9% > 6.8% → **上升**；乙 6.8% = 6.8% → **不变**（a = b 比重不变，别忘这条）；丙 −10% < 6.8% → **下降**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：整体拿错（省当全国、行业当整体）、a 和 b 对调；
- **列式错**：基期比重修正项乘反、比重差忘 ÷(1+a)；
- **速算错**：比重截位过度、修正项除法算错方向；
- **陷阱错**：百分点/% 混排、增速差冒充比重差、"增长但跑输整体"当上升。
