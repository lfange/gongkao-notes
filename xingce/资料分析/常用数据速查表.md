### 1.1 三条核心规律

1. **半整数分母转整数分数**：分子、分母同时乘 2。例如 1/5.5＝2/11，1/6.5＝2/13。
2. **增长求增量，分母加 1**：增长率 r＝1/n 时，增长量＝现期 × r/(1+r)＝现期 ÷ (n+1)。
3. **下降求减量，分母减 1**：下降率大小 d＝1/n 时，减少量＝现期 × d/(1−d)＝现期 ÷ (n−1)，要求 0<d<1，即 n>1。

**n 不必是整数**，5.5、6.5 等同样适用。以上均以已知现期量为前提；基期量＝现期量−增长量，或现期量＋减少量。近似换算时，上述等号相应改为约等号。

推导：当 r＝1/n 时，r/(1+r)＝(1/n)/((n+1)/n)＝1/(n+1)；下降时同理得到 d/(1−d)＝1/(n−1)。

### 1.2 四个口算例子

- **求占比对应量**：660 的 18.18% ≈ 660×2/11＝120。
- **另一组半整数分母**：780 的 15.38% ≈ 780×2/13＝120。
- **求增长量**：现期 650，增长约18.18%，增长量≈650÷6.5＝100，基期约550。
- **求减少量**：现期 450，下降约18.18%，减少量≈450÷4.5＝100，基期约550。

### 1.3 近似边界与一般分数

**选项差距决定是否可以替换。**18.2% 可近似看成 2/11，15.4% 可近似看成 2/13；选项很接近或结论贴着阈值时，应保留原百分数计算。表中“翻倍”指精确分数翻倍，百分数各自四舍五入，可能出现末位差异。

对正数求占比对应量时，18.2% 略大于 2/11，因此结果比“除以11再乘2”略大；求增长情况下的基期量时，增长率在分母，近似替换成较小增长率会使基期估值偏大。

**不要把百分号前的数字直接当成 n。**0.74%≈1/136，可用现期÷137估算增长量；136%＝34/25，并不是1/136，不能用现期÷137。

一般化：增长率 r＝m/n 时，增长量＝现期×m/(n+m)；下降率大小 d＝m/n 且 0<m<n 时，减少量＝现期×m/(n−m)。例如现期236、增长136%，增长量＝236×34/59＝136。写成倒数形式也成立，此时 n＝25/34，并非136；选便于计算的分数形式即可。

**低增速区间（4%~5%，真题常见）**：

| 百分数 | 分数 | 增长量速算 |
|---|---|---|
| 4.8% | ≈1/21 | 现期 ÷ 22 |
| 4.5% | ≈1/22 | 现期 ÷ 23 |
| 4.3% | ≈1/23 | 现期 ÷ 24 |
| 4% | 1/25 | 现期 ÷ 26 |
| 3.7% | ≈1/27 | 现期 ÷ 28 |

> 捷径：r < 5% 时，增长量 ≈ 现期 × r 直接乘（误差 ≤ r 本身即 5% 以内，选项间距大时够用；间距小用上表的 1/n 法更准）。

**常用"非整分子"分数**（比重、平均数估算用）：

| 分数 | 百分数 | 分数 | 百分数 |
|---|---|---|---|
| 2/3 | ≈66.7% | 3/8 | 37.5% |
| 3/4 | 75% | 5/8 | 62.5% |
| 2/5 | 40% | 7/8 | 87.5% |
| 3/5 | 60% | 5/6 | ≈83.3% |

## 二、常用幂值表（年均增长率专用，必背）

### 2.1 (1+r)ⁿ 增长系数表

**核心场景**：n = 5（五年规划、"十四五""十三五"）；n = 2、3（隔年/近三年比较）。

| r \ n | 2 | 3 | 4 | **5** |
|---|---|---|---|---|
| 5% | 1.10 | 1.16 | 1.22 | **1.28** |
| 6% | 1.12 | 1.19 | 1.26 | **1.34** |
| 7% | 1.14 | 1.23 | 1.31 | **1.40** |
| 8% | 1.17 | 1.26 | 1.36 | **1.47** |
| 9% | 1.19 | 1.30 | 1.41 | **1.54** |
| **10%** | 1.21 | 1.33 | 1.46 | **1.61** |
| 12% | 1.25 | 1.40 | 1.57 | 1.76 |
| 15% | 1.32 | 1.52 | 1.75 | **2.01** |
| 20% | 1.44 | 1.73 | 2.07 | **2.49** |

10% 的延长记忆：1.1⁶ ≈ 1.77，1.1⁷ ≈ 1.95，1.1⁸ ≈ 2.14。

**用法**：算出总倍数（现期/基期），对着表"反查"年均增速。例：五年翻 1.4 倍 → 落在 1.07⁵ = 1.40 → 年均 7%。

### 2.2 总倍数 → 年均增速反查表（n = 5 / n = 10）

| 五年总倍数 | 年均增速 | | 十年总倍数 | 年均增速 |
|---|---|---|---|---|
| 1.2 倍 | ≈3.7% | | 1.2 倍 | ≈1.9% |
| 1.3 倍 | ≈5.4% | | 1.5 倍 | ≈4.1% |
| 1.4 倍 | ≈7.0% | | 2 倍 | ≈7.2% |
| 1.5 倍 | ≈8.4% | | 3 倍 | ≈11.6% |
| 1.6 倍 | ≈9.9% | | 4 倍 | ≈14.9% |
| 2 倍 | ≈14.9% | | | |

### 2.3 翻番与 2 的幂

| 翻 n 番 | ×2ⁿ | 2ⁿ 备查 |
|---|---|---|
| 翻一番 | ×2 | 2⁵=32，2⁶=64，2⁷=128，2⁸=256，2⁹=512，2¹⁰=1024 |
| 翻两番 | ×4 | **"增长 2 倍"= ×3；"翻两番" = ×4**，别混 |
| 翻三番 | ×8 | |

**开方速记（反求年均增速）**：√2 ≈ 1.414，2^(1/3) ≈ 1.26，2^(1/4) ≈ 1.19，**2^(1/5) ≈ 1.15**，2^(1/10) ≈ 1.07。
推论：**翻一番用 5 年 → 年均约 15%；翻一番用 10 年 → 年均约 7%**。

√2≈1.414　√3≈1.732　√5≈2.236　√6≈2.449　√7≈2.646　√8≈2.828　√10≈3.162　3^(1/3)≈1.44

### 3.4 隔年增速交叉项 r₁×r₂ 速查（百分点）

| r₁ \ r₂ | 4% | 5% | 6% | 10% | 15% | 20% |
|---|---|---|---|---|---|---|
| 5% | 0.20 | 0.25 | 0.30 | 0.50 | 0.75 | 1.00 |
| 10% | 0.40 | 0.50 | 0.60 | 1.00 | 1.50 | 2.00 |
| 20% | 0.80 | 1.00 | 1.20 | 2.00 | 3.00 | 4.00 |

> 两个增速的绝对值都 < 5% 时，交叉项绝对值 < 0.25 个百分点；是否可忽略要看选项间距。任一增速较大也不能单独确定交叉项大小，例如 10%×1% 仅为 0.1 个百分点。

## 四、单位与量级换算（动笔前先统一）

### 4.1 数量级

| 换算 | 关系 |
|---|---|
| 1 万 | 10⁴ |
| 1 亿 | 10⁸ = 10000 万 |
| 1 万亿 | 10¹² = 10000 亿 |
| 1 ‰ | 0.1% |

**高频坑**：材料"亿元"、选项"万亿元"；材料"万人"、选项"亿人"（÷10000）。口算前先标量级。

### 4.2 常用计量单位

| 换算 | 关系 |
|---|---|
| 1 吨 | 1000 千克（公斤）；1 万吨 → 亿吨需 ×10⁻⁴ |
| 1 公顷 | **15 亩**（亩产题必用） |
| 1 平方公里 | 100 公顷 = 1500 亩 |
| 1 千瓦时 | 1 度电（发电量题） |
| 1 亿美元 | ≈7 亿元（汇率随年份波动，做量级估算即可，精确值材料会给） |

### 4.3 复合单位速算（平均数题）

- 亿元 ÷ 万人 = **万元/人**（如 549 亿元 ÷ 12.9 亿人次 → "亿"约掉，549/12.9 ≈ 42.6 元/人次）
- 亿元 ÷ 亿人 = 元/人；亿元 ÷ 万人 = 万元/人（差 4 个量级，先约"亿"再算）
