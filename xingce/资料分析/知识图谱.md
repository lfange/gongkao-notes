## 三、增长体系图

    基期量 B
       ├─ 乘（1 + 增长率 r）→ 现期量 A
       └─ 与现期量之差 → 增长量 Δ

    A = B ×（1+r）
    B = A ÷（1+r）
    Δ = A - B
    Δ = A × r ÷（1+r）
    r = Δ ÷ B

### 3.1 概念关系

| 问法 | 比什么 | 易错点 |
| --- | --- | --- |
| 增长最快 | 增长率 | 不能比较增长量 |
| 增长最多 | 增长量 | 不能只看增速 |
| 是几倍 | 现期 ÷ 基期 | “多几倍”比“是几倍”少 1 |
| 增长百分之几 | 增长量 ÷ 基期 | 分母不是现期 |

> [增长率专题](增长率专题.md) · [基期量专题](基期量专题.md) · [增长量专题](增长量专题.md)

## 四、比重体系图

    部分 A
       ÷ 整体 B
    现期比重

    部分增速 a 与整体增速 b
       ├─ a > b ⇒ 比重上升
       ├─ a = b ⇒ 比重不变
       └─ a < b ⇒ 比重下降

    基期比重
       = 现期比重 ×（1+b）÷（1+a）

    两期比重差
       = 现期比重 ×（a-b）÷（1+a）

**易混：** 比重变化的单位是“百分点”；增长率变化通常表述为提高或下降百分之几。

> [比重专题](比重专题.md)

## 五、平均数体系图

    总量 A
       ÷ 份数 B
    平均数

    总量增速 a 与份数增速 b
       ├─ a > b ⇒ 平均数上升
       ├─ a = b ⇒ 平均数不变
       └─ a < b ⇒ 平均数下降

    平均数增长率
       =（a-b）÷（1+b）

**同构关系：**

    比重 = 部分 ÷ 整体
    平均数 = 总量 ÷ 份数
    倍数 = 前者 ÷ 后者

三者都属于“分子 ÷ 分母”，基期值都可用现期值乘“分母侧修正”再除“分子侧修正”。

## 六、多期增长图

### 6.1 隔年增长

    第一年增长率 r₁
       与第二年增长率 r₂ 复合
    隔年增长率 = r₁ + r₂ + r₁r₂

**关系：** 百分比连续变化要连乘，不能直接相加。

### 6.2 年均增长

    基期 ×（1+r）ⁿ = 现期

    n = 年份差

**易错：** 2019 年到 2024 年的间隔是 5 年，不是 6；五年规划的基期通常是规划开始前一年。

### 6.3 翻番

    翻 n 番 = 原来的 2ⁿ 倍
    增长 n 倍 = 原来的（n+1）倍

## 七、混合与贡献图

### 7.1 混合增长

    部分 1：基期量 B₁、增速 r₁
    部分 2：基期量 B₂、增速 r₂
       ↓ 基期量加权
    整体增速 =（B₁r₁ + B₂r₂）÷（B₁+B₂）

    整体增速
       ├─ 介于各部分增速之间
       └─ 更接近基期量较大的部分

> [混合增长专题](混合增长专题.md)

### 7.2 拉动与贡献

    部分增长量
       ÷ 整体基期量
    拉动增长率（百分点）

    部分增长量
       ÷ 整体增长量
    增长贡献率（%）

**易混：** 两者分子相同，分母不同，单位不同。

## 八、速算方法图

    列式后
       ↓ 先看选项差距
    差距大？
       ├─ 是 → 截位直除 / 首数法 / 特殊分数
       └─ 否 → 保留更多有效数字
          ↓
    是比较题？
       ├─ 分子同 → 比分母
       ├─ 分母同 → 比分子
       ├─ 数量级差异大 → 估数量级
       └─ 接近 → 交叉相乘或计算修正

### 8.1 方法节点

| 方法 | 适用场景 | 风险 |
| --- | --- | --- |
| 截位直除 | 除法、选项首位不同 | 截位过多改变大小关系 |
| 特殊分数 | 增速接近 1/n | 只适合近似，不作精确相等 |
| 首数法 | 选项首位差异明显 | 选项接近时不够 |
| 尾数法 | 加减乘且选项尾数不同 | 除法通常不适用 |
| 量级判断 | 单位或数量级差异 | 必须先统一单位 |

## 九、综合分析判错图

    一个选项
       ↓
    1. 找数口径一致？
       ↓
    2. 计算概念正确？
       ↓
    3. 大小方向正确？
       ↓
    4. 表述范围和强度与材料一致？

| 陷阱 | 表现 |
| --- | --- |
| 时间错位 | 当月与累计、同比与环比混淆 |
| 对象错位 | 全国数据代替某地区 |
| 单位错位 | 万元与亿元、% 与百分点混淆 |
| 概念错位 | 增长最快与增长最多混淆 |
| 精度陷阱 | 选项接近却过度估算 |
| 范围扩大 | 部分年份成立改写为所有年份 |
