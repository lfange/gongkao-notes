# 资料分析 · 速算方法专题（截位直除、特殊分数、差分法与尾数法）

> 资料分析的三步是"找数 → 列式 → 速算"，前两步靠细心，第三步靠**手上有几把固定的刀**。
> 核心心法只有一句：**选项决定精度**——选项首位不同，算到首位就停；选项贴身，才多算一位。
> 专题结构：**本质 → 方法总览 → 判断三步法 → 五把刀逐个讲透 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。必背数值表见 [常用数据速查表.md](常用数据速查表.md)。

---

## 一、本质：除法的精度由分母前几位决定

资料分析的选项是"约多少"，不是"精确值"。`2700/41700` 到底等于 0.0647 还是 0.0648 无所谓——**选项差距有多大，就保留多高的精度**。所有速算法都是这条原理的不同切法：

| 选项形态 | 需要的精度 | 用的刀 |
| --- | --- | --- |
| 四个选项首位各不相同 | 商 1 位 | 截位直除（分母截 2 位） |
| 首位相同、次位不同 | 商 2 位 | 截位直除（分母截 3 位） |
| r 接近 1/n | 不用除 | 特殊分数法 |
| 两个分数比大小 | 不用算出值 | 同位比较 / 差分法 |
| 一串数加减 | 末位 | 尾数法 |

**永远不要硬算到底**——把除法列完整、商出四位数的，不是在做资料分析，是在做算术作业。

## 二、方法总览（五把刀速查表）

| 刀 | 适用 | 一句话要领 |
| --- | --- | --- |
| ① 截位直除 | 一切除法 | 分母截 2 位/3 位，商到选项分开即停 |
| ② 特殊分数 | r ≈ 1/n 的乘除 | r 化 1/n，增长量 ÷(n+1) / ÷(n−1) |
| ③ 首数法 | 选项首位不同 | 商第一位即停 |
| ④ 尾数法 | 精确加减 | 只算末一位/末两位 |
| ⑤ 差分法 | 两个分数比大小 | 构造差分数，与"小分数"比 |

## 三、判断三步法（动笔前先走这三步）

1. **看选项**：首位同不同？差几个百分点？——**先看选项再决定算多细**，这是速算的第一动作。
2. **认数字**：r 是不是特殊分数（14.3%、16.7%、12.5%……）？数是不是凑好的幂？
3. **选刀**：除法 → ①/③；带 r → ②；比大小 → ⑤；加减 → ④。一道题常是两把刀接力。

## 四、五把刀逐个讲透

### 刀 1：截位直除（第一主力）

**原理**：商的精度主要由**分母前几位**决定，分子截不截影响更小。

- **分母截 2 位**（选项首位不同时）：`2700/41700` → 27/42 ≈ 0.64 → 首位 6，选首位为 6 的选项。
- **分母截 3 位**（首位同、次位不同时）：`24371/58264` → 2437/583 → 商 0.41x，再定次位。

**分子处理**：截位时分子分母**同向缩放**（分子舍去、分母舍去），误差方向一致；要控制误差方向时用"**放缩法**"：

> 想要**上限**：分子进位（变大）、分母舍位（变小）→ 商偏大；
> 想要**下限**：分子舍位、分母进位 → 商偏小。
> 结论贴着阈值（"超过 7200 吗"）时，把上下限各算一遍，阈值夹在中间才敢下结论。

### 刀 2：特殊分数转化（第二主力）

增长率与分数互化，乘除一步变简单。**核心应用是增长量**：

- r ≈ 1/n，增长 → 增长量 = 现期 ÷ (n+1)；
- r ≈ 1/n，下降 → 减少量 = 现期 ÷ (n−1)。

其他应用：r = 12.5% 时求基期 → 现期÷(1+1/8) = 现期×8/9；比重估算把 0.285 想成 ≈2/7。**整张互化表必须背熟**（[常用数据速查表](常用数据速查表.md) 第一节，每天 5 分钟口算）。

**低增速捷径**：r < 5% 时，增长量 ≈ 现期×r（误差 ≤ 5%×r，选项间距大时直接用）。

### 刀 3：首数法

选项**首位数字互不相同**时，除法商出第一位即停：`453.7/127.2`，商 3 开头 → 只看谁的首位是 3。要区分 3.5 和 3.6 时才商第二位（453.7/127.2 = 3.56…）。**做除法时被除数从高位比起**，首数法是"选项帮忙"的极致。

### 刀 4：尾数法

**只适用于精确加减**（合计校验、增量累加、基期相减），不适用于除法：

- `4231 + 5607 + 3849 + 2915 = ?` → 尾数 1+7+9+5 = 22 → 和的尾数是 2，四个选项里只有一个尾数 2；
- 量级不同先对齐：`3.52 + 0.8 + 12`（亿元混合小数）要按末位对齐再加尾数。

### 刀 5：差分法（分数比较的"裁判"）

比 A/B 与 C/D（A>C 且 B>D，"大分数"与"小分数"）：

1. 构造**差分数** = (A−C)/(B−D)（分子差 ÷ 分母差）；
2. 拿差分数和**小分数**（C/D）比：
   - 差分数 > 小分数 → **大分数大**；
   - 差分数 < 小分数 → 大分数反而小。

直觉：差分数是"多出来的那部分"的平均密度，密度高说明加上去更值。适用于"两者都挺接近、直除又不好截位"的比较题。

## 五、易错点清单

1. **截位过度**：选项差距小时还截 2 位，商漂到隔壁选项——**先看选项间距再定截几位**。
2. **放缩方向记反**：估上限要"分子进、分母舍"，别两把都朝一边。
3. **尾数法用在除法上**——除法没有尾数守恒。
4. **特殊分数背半生不熟**：记住 1/7 ≈ 14.3% 却忘了增长量该 ÷8。
5. **差分法比较对象拿错**：差分数永远和**小分数**比，别和大分数比。
6. **量级不检查**：截位后 0.64 与 6.4 之间差 10 倍，商出来先数位数再对选项。
7. 加减尾数法遇到"量级不齐"（亿元混万元）没先对齐。

## 六、精讲例题

### 例题 1（截位直除：先看选项定精度）

**材料**：2023 年某省规模以上工业企业实现利润 24371 亿元，2022 年为 21950 亿元。
**问**：同比增长率约为？
A. 8.4%　B. 11.0%　C. 14.7%　D. 18.2%

**解析**：

1. 增量 = 24371 − 21950 = 2421。
2. 看选项：首位 8/11/14/18——**首位不同，商 1 位即可**。
3. r = 2421/21950 → 分母截 2 位：24/22 → 商 1 开头，1x% → 排 A；要分 11 还是 14，次位再商一步：242/2195 → 1.10 开头 → **11.0%，选 B**。
4. 深度：全程没算出完整小数。**首位定区间，次位定答案，第三位永远不需要。**

### 例题 2（特殊分数 + 验算回乘）

**材料**：2023 年某市新开工项目投资额 4800 亿元，同比增长 12.5%。
**问**：比上年增加约多少亿元？
A. 533　B. 600　C. 686　D. 427

**解析**：

1. 12.5% = 1/8 → 增长量 = 4800÷9 ≈ **533，选 A**。
2. 陷阱：B = 4800×12.5% = 600（忘除 1.125）；C = 4800÷7（升降用反）；D = 4800×0.089 凑数。
3. **回乘验算**：533×9 = 4797 ≈ 4800 ✓——除法的结果乘回去 2 秒自检，特殊分数法尤其值得验（防背错格子）。

### 例题 3（放缩法：结论贴阈值）

**材料**：2023 年某省游客 8400 万人次，同比增长 17.2%。
**问**：2022 年游客人次数能否超过 7200 万？

**解析**：

1. 直除 8400/1.172 一步得 7167 左右，但结论贴着 7200——**用放缩法定死区间**：
2. 算**上限**：分子进、分母舍 → 8400/1.17 = 7179；算**下限**：分子舍、分母进 → 8300/1.18 = 7034 → 基期 ∈ (7034, 7179)。
3. 整个区间都 < 7200 → **不能超过，稳了**。单点直除 7167 也能选，但区间夹逼在考场上更抗手抖。
4. 深度：**"约多少"用截位，"能否超过"用放缩**——问法不同，刀法不同。

### 例题 4（尾数法：合计校验）

**材料**：某市 2023 年四个季度 GDP 分别为 8462、9135、9878、10527 亿元。
**问**：全年 GDP 约为多少亿元？
A. 37902　B. 38002　C. 38102　D. 38012

**解析**：

1. 尾数：2 + 5 + 8 + 7 = 22 → 和的尾数是 2 → A、B、C、D 尾数全是 2？（A 2 / B 2 / C 2 / D 2）——尾一位不够用，**升到尾两位**：62+35+78+27 = 202 → 末两位 02 → **38002，选 B**。
2. 深度：尾数法失败（尾位撞车）就自动升位，这是它的标准退化路径。当然，四个数相加本身就快，尾数法的价值在**七八个数连加**或**表格合计校验**。

### 例题 5（差分法：贴身比较）

**材料**：2023 年甲省人均 GDP 为 84000/1770（元/人），乙省为 88000/1840（元/人）。
**问**：哪省人均 GDP 高？

**解析**：

1. 直除都 ≈ 4.7x 万，贴身——上差分法。
2. 大分数 88000/1840，小分数 84000/1770；差分数 = (88000−84000)/(1840−1770) = 4000/70 ≈ 57.1。
3. 差分数 57.1 **大于**小分数（84000/1770 ≈ 47.5）→ **大分数大 → 乙省高**。
4. 深度：差分数 57 远离两个原分数，说明"多出来的部分"密度很高，大分数胜出毫无悬念。差分法的价值在**不用把两个四位除法算到底**。

### 例题 6（综合：定性 + 截位 + 量级感三连）

**材料**：2023 年某省高技术制造业增加值 12760 亿元，同比增长 7.1%；规上工业增加值 152300 亿元，同比增长 4.3%。
**问**：高技术制造业增加值占规上工业的比重比上年约：
A. 上升 0.2 个百分点　B. 上升 2.8 个百分点　C. 下降 0.2 个百分点　D. 上升 2.3 个百分点

**解析**：

1. **先定性（零计算）**：a = 7.1% > b = 4.3% → 上升，C 排除。
2. **卡上限**：\|a−b\| = 2.8 个百分点 → B（恰等于增速差）必错——比重差永远远小于增速差。
3. **截位算比重**：12760/152300 → 128/1523，商 0.084（8.4%）。
4. 比重差 = 8.4% × 2.8% ÷ 1.071 ≈ **0.2 个百分点，选 A**。
5. 陷阱：D = 8.4×2.8 ≈ 23.5，再挪一位小数冒充 2.3 个百分点——**% 乘 % 要挪两位小数**，量级错一位就是 D 这种"看起来最像答案"的选项。

> **量级感报警**：算出的值和全部选项差一个量级时，先怀疑自己（截位过度？单位没换算？% 与百分点混了？），两轮自查无误后果断跳过——刷题软件的野题会有"选项全错"的坏题，考场真题不会；识别坏题的标准动作就是量级感报警，别耗时间往错误选项上硬凑。

## 七、自测练习

1. `24371/58264` 的商首位是几？次位呢？
2. r = 12.5%，现期 3600。增长量约为多少？
3. `1732 + 2846 + 3917` 的和的尾数是几？和是多少？
4. 用差分法比较：`84/177` 与 `88/184`，哪个大？
5. 某省 2023 年社会消费品零售总额 89200 亿元，同比增长 6.8%。"2022 年超过 83000 亿元"这个说法能成立吗？（用放缩法）

### 答案附录

1. 24/58 → 0.4 开头；次位 244/583 → 0.41 → **约 0.42**（首位不同时其实商一位就够）。
2. 12.5% = 1/8 → 3600÷9 = **400**。
3. 尾数 2+6+7 = 15 → 尾数 5；精算 **8495**。
4. 大分数 88/184，小分数 84/177，差分数 = 4/7 ≈ 0.57 > 小分数 0.475 → **88/184 大**。
5. 上限：89200/1.067（分母舍位）→ 8360 附近精算 89200/1.067 ≈ 83599；下限：89200/1.069 ≈ 83443 → 区间 (83443, 83599) 整体 > 83000 → **成立**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **找数错**：截位前就拿错数（速算救不了找数错）；
- **列式错**：刀选对式子列错，白算；
- **速算错**：截位过度、放缩方向反、特殊分数背错、量级（0.64 vs 6.4）没数位数；
- **陷阱错**：贴阈值结论没做区间夹逼、坏题（选项全错）耗时间硬对齐。
