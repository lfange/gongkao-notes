# 行测知识图谱总览

> 用途：把分散专题连接成“知识节点—关系—题型—方法—易错点”网络。  
> 图谱中的箭头表示知识之间的方向关系；点击节点后的专题链接可进入讲解、例题和自测。

## 一、图谱读法

| 关系 | 含义 | 示例 |
| --- | --- | --- |
| A → B | A 是理解或解决 B 的前提 | 增长率 → 基期量 |
| A ⇄ B | 两者需要对照辨析 | 比重 ⇄ 平均数 |
| A ⇒ B | 由规则可推出结论 | 部分增速大于整体增速 ⇒ 比重上升 |
| A ⊂ B | A 属于 B 的下位知识 | 追及问题 ⊂ 行程问题 |
| A × B | 两个知识点组合出题 | 容斥 × 最值 |
| A ⚠ B | 两者容易混淆 | 增长量 ⚠ 增长率 |

## 四、跨模块共用节点

### 4.1 比例关系

    比例
    ├─ 资料分析 → 增长率 / 比重 / 平均数 / 倍数
    ├─ 数量关系 → 比例份数 / 浓度 / 行程速度比 / 工程效率比
    ├─ 判断推理 → 集合包含 / 类比中的种属关系
    └─ 言语理解 → 数量范围和程度强弱

**迁移规则：** 分子回答“谁”，分母回答“以谁为基准”；所有百分数题先写清基准量。

### 4.2 条件关系

    条件
    ├─ 判断推理 → 充分条件 / 必要条件 / 逆否命题
    ├─ 数量关系 → 等量条件 / 整除条件 / 边界条件
    ├─ 常识判断 → 一般规则 / 适用条件 / 法定例外
    └─ 言语理解 → 只有…才… / 只要…就…

**迁移规则：** 看到“只有、必须、除非、保证、至少”时，先判断它限定的是必要条件还是结果边界。

### 4.3 因果关系

    因果
    ├─ 言语理解 → 原因与结论、因果倒置、强加因果
    ├─ 判断推理 → 因果论证、他因削弱、因果倒置
    ├─ 常识判断 → 现象与科学原理、政策工具与影响
    └─ 申论 → 问题—原因—影响—对策链

**迁移规则：** 同时发生不等于因果；结论必须有机制、对照或排除他因支持。

### 4.4 范围与时点

    范围/时点
    ├─ 资料分析 → 全国/局部、累计/当期、同比/环比
    ├─ 言语理解 → 部分/全部、可能/必然、当前/长期
    ├─ 常识判断 → 法律施行时点、政策适用对象
    └─ 政治理论 → 目标年份、规划期、提出/通过/实施

**迁移规则：** 选项改变对象、时间、数量范围或语气强度，即使主题相同也可能错误。

## 五、从题目反查知识节点

| 题干信号 | 第一联想 | 下一步 |
| --- | --- | --- |
| 同比、比上年增长 | 增长体系 | 判现期/基期，再看问率还是量 |
| 占、其中、每、平均 | 比例体系 | 判断比重、倍数或平均数 |
| 只有、除非、必须 | 条件推理 | 翻译箭头，使用逆否规则 |
| 最能削弱、最能支持 | 论证推理 | 找论点、论据和逻辑缺口 |
| 至少、保证、最多 | 最值模型 | 构造最坏情形或边界 |
| 但是、然而、关键在于 | 转折或对策结构 | 优先定位转折后和结论句 |
| 主体、条件、方式、目的 | 定义判断 | 逐要件匹配 |
| 主要体现哪一理念 | 政治理论情境题 | 判断措施主要解决什么问题 |
| 现象与原理对应 | 科技常识 | 校验完整因果链而非只认关键词 |

## 六、学习路径图

    第一步：总览
       ↓ 说出每个模块的底层任务
    第二步：模块图谱
       ↓ 记住一级、二级节点和关键关系
    第三步：专题例题
       ↓ 验证关系如何变成题目
    第四步：混合刷题
       ↓ 训练从题干反查知识节点
    第五步：错题回挂
       ↓ 把错题挂回对应节点和错误关系
    第六步：套卷取舍
       ↓ 用正确率、耗时和放弃题调整顺序
