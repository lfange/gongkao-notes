# 攻略

> 行测 = 行政职业能力测验，核心是「准确 + 速度 + 取舍」。[2026年度国考官方大纲](https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml)列出政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析六个部分，时限120分钟。
> 本仓库以四川为目标，题量、题型和时限以该年度四川公告、大纲及目标类别试卷为准，不把历年国考130/135题直接套用到四川。资料、判断、言语优先练，政治理论和申论同步推进；模块分值不作未经官方确认的比例推断。
> 下列正确率与用时为训练建议，不是官方分数线或上岸保证。目标差异见 [四川省考备考](../计划/四川省考备考.md)。
> 第一次学习建议先看 [行测知识图谱总览](知识图谱总览.md)，再用 [行测必备知识框架与例题](必备知识框架与例题.md) 建立六模块共同的解题链，最后进入各专题。

## 一、资料分析 ⭐ 最高优先级

- **训练单位：** 按目标真题的材料组练习，题量以该套试卷为准。
- **核心考点：** 增长率、增长量、比重、平均数、倍数 —— 五大概念 + 对应公式。
- **专题笔记：** 基期量 / 增长率 / 增长量 / 比重 / 平均数 / 倍数翻番 / 隔年年均 / 混合增长 / 速算方法 / 综合分析陷阱（专题见 [资料分析/笔记.md](资料分析/笔记.md)；速算刀法 → [速算方法专题](资料分析/速算方法专题.md)，找数防坑 → [综合分析与陷阱专题](资料分析/综合分析与陷阱专题.md)）。
- **方法：**
  1. 先花 30 秒看材料结构（标题、时间、单位、图表轴），再读题。
  2. 列式优先套公式，避免硬算。
  3. 速算：截位直除、特殊分数转化（如 1/6≈16.7%）、首位估算法。
  4. 找数要准：注意"累计/当月""同比/环比""全国/某省"等陷阱词。
- **目标（专项期）：** 正确率先稳定到75%左右，再压缩用时；按材料组统计，不机械套用“20题”。

## 二、判断推理 ⭐

- **训练分区：** 图形推理、定义判断、类比推理、逻辑判断；各类题量按目标卷记录。
- **图形推理：** 看位置（平移/旋转）、样式（遍历/运算）、数量（点/线/面/素）、属性（对称/曲直）、空间重构（折叠）。先整体后局部，多总结规律触发词 → [图推规律大全](判断推理/图推规律大全.md)。
- **定义判断：** 抓主体、客体、条件、目的、结果，逐个选项匹配排除 → [专题](判断推理/定义判断专题.md)。
- **类比推理：** 语义（近义/反义）、逻辑（全异/交叉/包含/属性）、语法（主谓/偏正）；遇纠结做二级辨析（二级关系）→ [专题](判断推理/类比推理专题.md)。
- **逻辑判断：** 翻译推理（if-then 公式）、削弱加强（找论点论据）、日常结论（只依材料）、朴素逻辑（列表/假设）→ [专题](判断推理/逻辑判断专题.md)。
- **概念总纲：** 图推三步定位、定义要件体系、类比关系表、逻辑翻译与削弱力度排序 + 考前速查卡 → [判断推理/知识点.md](判断推理/知识点.md)（日常看专题例题，考前过总纲）。
- **目标：** 正确率先达到70%左右，同时记录四个子题型的用时与错因。

## 三、言语理解 ⭐

- **训练分区：** 逻辑填空、片段阅读、语句表达；不得假设所有试卷都为40题。
- **逻辑填空：** 词义辨析（实词、成语）+ 语境逻辑（转折、递进、并列、解释）。积累高频成语，结合语境排除 → [专题](言语理解/逻辑填空专题.md) + [易混成语辨析表](言语理解/易混成语辨析表.md)。
- **片段阅读：** 主旨概括、意图判断、细节判断、语句排序、语句填充。方法：找关联词（但是/因此/而且）定位主题句 → [专题](言语理解/片段阅读专题.md) + [语句排序与填充专题](言语理解/语句排序与填充专题.md)。
- **概念总纲：** 语境关联词体系、行文脉络、细节偷换、钩子理论 + 考前速查卡 → [言语理解/知识点.md](言语理解/知识点.md)（日常看专题例题，考前过总纲）。
- **目标：** 正确率先达到70%左右；填空与阅读分开统计，减少反复回读。

## 四、数量关系

- **定位：** 先学基础题，按诊断结果决定投入，不默认每套卷都是15题或一定最难。
- **高频题型：** 工程、行程、利润、容斥、排列组合/概率、几何、年龄、日期、鸡兔同笼。
- **核心技巧：** 代入排除、整除倍数特性、尾数法、特值法、比例份数——先看选项再动笔 → [速算技巧专题](数量关系/速算技巧专题.md)。
- **其他常考题型：** 和差倍比、溶液浓度、数列与平均数、牛吃草、最值、统筹（专题见 [数量关系/笔记.md](数量关系/笔记.md)）。
- **方法：**
  1. 数量模块开始时快速扫题，挑熟悉且短时间可解的题先做，不必开考就打乱顺序。
  2. 超过预设预算的难题暂跳；最后结合排除结果补答，不把“统一蒙一个选项”当提分方法。
  3. 基础阶段学公式和方法，不求全会。
- **目标：** 先稳定做对自己选中的基础题，再增加可做题型；具体题数按目标卷调整。

## 五、常识判断

- **范围：** 法律、经济、人文、科技、地理等；政治理论单列学习入口，不重复计入两个模块。专题见 [常识判断/笔记.md](常识判断/笔记.md)。公安岗法律内容可与 [招警专题](../招警/攻略.md) 配套。
- **方法：** 和政治理论合用每日15分钟积累预算；辨析主体、年份、条件，不能仅凭第一感觉。
- **目标：** 根据诊断卷逐步提高正确率，不以固定“对12题”衡量不同题量的卷子。

## 六、政治理论

- **入口：** [政治理论专题](政治理论/专题.md)，包含概念关系、易混表、自编练习与四川政策积累模板。
- **方法：** 原文建立概念卡 → 通过选项辨析适用问题 → 错题回查出处。不要只背关键词或把政策标题等同于全文理解。
- **节奏：** 与常识合计每天15分钟，每周做一组限时练习；新增政策记录发布日和核验日。

## 行测总体目标（省考前）

- 在目标卷的正式时限内完成作答和涂卡；同时看正确率、猜题数、空题数与模块耗时。正确率不是行测官方加权分数，也不能据此保证进面。
- **顺序试验：** 可先做政治/常识，再资料、判断、言语、数量；用至少3套同类别卷验证，保留最适合自己的顺序。
- **120分钟训练预算示例（非四川已公布安排）：** 政治+常识12分钟、资料25、判断28、言语28、数量17、机动与涂卡10，共120分钟。题量或时限不同须重排，不要叠加六模块后超时。
- **时间意识：** 为各模块设截止点，难题标记后跳过，最后补答。详见 [套卷复盘模板](../真题/套卷复盘模板.md)。
