# 言语理解 · 知识点深度解析（核心概念总纲）

> 配套 [笔记.md](笔记.md)（个人笔记/错题归档）与 [../攻略.md](../攻略.md#三言语理解--)。
> 言语理解的两大核心能力：**还原语境**（逻辑填空——空格从来不是独立的，线索一定留在上下文）与**找重点、防偷换**（片段阅读——一段话只有一个重心，一切答案来自文段本身）。
> 本文是四篇专题的概念汇总速查版：**日常学习看专题（含例题与自测），考前快过看本文**。

## 一、总纲：题型谱系与做题三步法

**题型谱系**（国考 40 题为基准，省考口径略有增减）：

| 题型 | 提问标志 | 核心方法 | 深入 |
|---|---|---|---|
| 逻辑填空 | "填入最恰当的词语是" | 语境四关系定方向 + 辨析四把刀精选 | [逻辑填空专题](逻辑填空专题.md) |
| 主旨概括 | "主旨是 / 概括最准确" | 关联词定位 + 行文脉络 | [片段阅读专题](片段阅读专题.md) |
| 意图判断 | "意在说明 / 想表达" | 主旨 + "半步"引申 | 同上 |
| 细节判断 | "正确 / 不正确 / 可以推出" | 逐项回原文，抓六大偷换 | 同上 |
| 词句理解 | "文中 X 指的是 / 意思是" | 答案在上下文（尤其前一句），不是词典义 | 同上 |
| 标题提炼 | "最适合做标题" | 主旨 + 全面、醒目、匹配文体 | 同上 |
| 语句排序 | "语序正确的是" | 首句排除 + 捆绑验证 | [语句排序与填充专题](语句排序与填充专题.md) |
| 语句填充 | "填入最恰当的一句是" | 两头接缝，防"半截管" | 同上 |
| （词汇积累） | — | 高频成语三坑：近义混淆 / 望文生义 / 谦敬错位 | [易混成语辨析表](易混成语辨析表.md) |

**做题三步法**（所有题型共用）：

| 步骤 | 动作 | 要点 |
|---|---|---|
| ① 先读提问 | 判断题型，带着任务读文段 | 读文段之前必须知道要找什么 |
| ② 读文段标信号 | 关联词（但是/因此/不仅…而且）、举例标志（例如/以…为例）、冒号破折号、首尾句、高频词 | 信号词决定重点在哪、空格往哪走 |
| ③ 按题型收尾 | 填空：预判方向再比对选项；阅读：锁定主题句同义改写或逐项核对 | **选"最贴合语境的"，不是"最好看的"** |

## 二、语境逻辑：关联词体系（填空与阅读共用的地基）

同一个关联词，在逻辑填空里定**空格方向**，在片段阅读里定**重点位置**——一张表两头用：

| 关系 | 信号词 | 逻辑填空：空格怎么填 | 片段阅读：重点在哪 |
|---|---|---|---|
| **转折** | 但、却、然而、其实、反而 | 与前文**相反或相对** | **转折之后**（最高频） |
| **递进** | 甚至、更、不仅…而且 | 同向且**程度更深**（要"够得着"） | 递进之后 |
| **因果** | 因此、所以、可见、由于 | 果是空格，因必留线索（互为呼应） | **结果之后**（结论是重点） |
| **并列** | 和、与、分号、既…又、结构对称 | 与并列项**近义或结构一致** | **并列加和**（答案须全面覆盖各项） |
| **解释** | 冒号、破折号、也就是说、举例 | 空格是解释内容的**概括** | 解释内容所支撑的观点 |
| **条件/对策** | 只有…才、应该、必须、关键是 | 条件与结果配套 | **对策本身**（"怎么办"是重点） |
| **让步** | 尽管/虽然…也、即使…也 | 承认事实后转折 | 让步之后 |

> 最容易漏的是**解释关系**：冒号、破折号后面整句话都在告诉你空格是什么，看到这两个符号先划出来。

**假设与让步的区分**（关联词填空高频坑）：**"如果…就"是假设（未发生）；"尽管/即使…也"是让步（已发生或承认其存在）**。后文是既成事实的，前句只能用让步。

## 三、词语辨析四把刀（两个词都"像对"时用）

| 刀 | 看什么 | 例 |
|---|---|---|
| **词义侧重** | 拆字看侧重 | 遏**制**（控制住）/ 遏**止**（使之停止） |
| **感情色彩** | 褒 / 贬 / 中性 | 文段夸的事不能填贬义词；反讽文段才故意用贬词 |
| **搭配对象** | 习惯搭配哪个宾语 | 改进方法/技术；改善关系/条件/生活 |
| **程度轻重** | 递进处程度要够，克制处不能太重 | 批评 < 批判 < 抨击 |

成语考点集中在三坑（详见 [易混成语辨析表](易混成语辨析表.md)）：

- **望文生义**："差强人意"是大体满意、"目无全牛"是技艺纯熟、"首当其冲"是最先受害；
- **对象错配**："汗牛充栋"只用于书、"八面玲珑"形容人、"络绎不绝"形容人行车马；
- **谦敬错位**："抛砖引玉"是谦辞、"鼎力相助"是敬辞，主体搞反直接排除。

**多空题纪律**：从**最有把握的那一空**入手排除，不死磕第一空——一空定方向、另一空定答案。

## 四、行文脉络：结构定位主题句

没有关联词时，靠结构找重心：

| 结构 | 标志 | 主题句位置 |
|---|---|---|
| 总—分 | 首句亮观点，后文举例论证 | **首句** |
| 分—总 | 前文铺陈，尾句收束（因此/可见/总之） | **尾句** |
| 分—总—分 | 首句提话题，中间论证，尾句点题 | 尾句（或首尾呼应合并） |
| 并列 | 一方面…另一方面 / 此外 / 同时 | 无单一重点，答案须**全面覆盖** |
| 问题—对策 | 问题 + 危害 + "关键是/应当/必须" | **对策句** |

> 铁律一：**举例部分（"例如""以…为例"）永远不是主旨**——例子支撑的观点才是。
> 铁律二：铺垫写得再精彩也是铺垫——**转折前的内容当主旨**是片段阅读第一大坑。

## 五、细节判断：六大偷换 + 数字口径

| 陷阱 | 特征 | 例子 |
|---|---|---|
| 偷换概念 | 换主语/换名词 | "人工智能产业"→"人工智能技术" |
| 偷换时态 | 已然变未然（或反之） | "已建成"→"将建成" |
| 偷换范围 | 部分变全部 | "部分城市"→"各大城市均" |
| 无中生有 | 原文完全没提 | 选项引入新比较、新结论 |
| 绝对化 | 或然变必然 | "可能"→"必将" |
| 强加因果 | 把先后当因果 | "A 之后出现 B"→"A 导致 B" |
| **数字口径** | "了"与"到"一字之差 | "下降**了**四成"（减少 40%）≠"下降**到**四成"（只剩 40%） |

> 做题顺序：先扫选项中的**绝对化词**（都、全部、必然、唯一）和**比较词**（更、最），这两类最容易被原文打脸。
> 深度规律：**正确项是原文的"温和改写"（部分、可能、尚可、有一定），错误项是"加码改写"**。

## 六、语句衔接：钩子与接缝

句子为什么"必须"在这个位置？因为别的句子**扔出了钩子**：

| 钩子 | 信号 | 规则 |
|---|---|---|
| 指代钩 | 它们、这、该 | 被指代对象必须在前句 |
| 关联钩 | 因此、但是、不仅 | 配对的另一半必须相邻 |
| 时间钩 | 此后、公元前 2 世纪、到了近代 | 时间线只能单向走 |
| 话题钩 | 重复出现的关键词 | 把同类句子拴在一起 |

**排序四招**（永远"选项先行"，不从零排）：

1. **定首句**：以下不能做首句，见即排除该选项——指代词开头无所指 / 关联词后半（因此、但是）/ 顺序词（此后、其次）；
2. **找捆绑**（最硬的依据）：指代捆绑、关联配对、重复词捆绑；
3. **定先后**：时间顺序、逻辑顺序（问题→分析→对策；现象→原因→结论）、空间顺序；
4. **定尾句**：结论（因此/可见）、对策呼吁、总结升华。

**语句填充三看**：

| 看什么 | 判断 |
|---|---|
| 看位置 | 段首**总起**、段中**承上启下（缺一不可）**、段尾**收束** |
| 看话题 | 必须同时衔接前后两个话题——只接一头的"半截管"是最强干扰项 |
| 看思路 | 论证方向（提问题还是给对策、并列还是递进）不能断 |

## 七、意图与标题的分寸

**意图判断"半步"原则**：

- 文段是"问题 + 危害"结构 → 意图是**呼吁解决**，正确答案常是对策项（"应当…/需要…"）；
- 引申只能**半步**、贴着文段揭示的病因走——文段说"睡前刷手机影响睡眠"，选"国家应立法禁止短视频"就是飞了十步；
- 引申项与主旨项同在且引申合理 → **优先合理引申项**；引申不合理 → 选主旨项；
- 警惕"万能呼吁"（"政府应高度重视"）——放哪道题都"对"的对策，通常正是坑。

**好标题三标准**：**全面**（覆盖主旨不片面）、**醒目**（有吸引力）、**匹配文体**（议论文标题是观点，说明文标题是对象，新闻标题是事件）。

## 八、高频陷阱清单（丢分重灾区）

| 陷阱 | 表现 | 破解 |
|---|---|---|
| **语感代入** | 读起来通顺 ≠ 正确，出题人专门写"顺口的坑" | 先读语境找呼应点，再回选项 |
| **呼应点太远没找到** | 只看空格前后一个词，线索其实在两三句外 | 解释关系在冒号后，转折对象可能隔着半句 |
| **背景知识补充文段** | 用自己的知识"帮"出题人写答案 | 文段没说的一律不知道 |
| **铺垫/例子当主旨** | 转折前、举例部分写得精彩被带跑 | 铁律：转折后、观点句才是重点 |
| **并列只选一半** | 文段谈 A 和 B，选项只谈 A | 并列文段答案必须全覆盖 |
| **加码改写** | 部分变全部、可能变必然、"了"变"到" | 正确项特征是温和改写 |
| **半截管** | 填充题选项只承接上文、不引出下文 | 段中空必须两头接缝 |
| **恋战与改答案** | 排序题超 1.5 分钟；凭"读不顺"推翻第一判断 | 第一判断基于完整通读，改动必须有原文依据 |

## 九、考场策略

1. **时间盘子**：40 题 35 分钟——逻辑填空单题 40 秒左右，片段阅读 50-60 秒，排序题**封顶 1.5 分钟**（公认的性价比洼地，超时按捆绑句最像的选项走）。
2. **顺序**：每题**先读提问再读文段**；逻辑填空先通读全段不看选项，预判空格方向后再比对。
3. **排除优先**：填空用语境先杀一半选项再辨析；细节题先扫绝对化词和比较词；排序题先做首句排除。
4. **取舍**：两轮排除后仍二选一，选**更贴合主旨/语境**（而非"更好看"）的那个，标记后继续——言语的正确率靠总量，不靠单题死磕。
5. **复盘**：错题按"关系错（语境方向反）/ 定位错（主题句找错）/ 核对错（偷换没识破）/ 辨析错（词义分不清，记入成语表）"归因，记入 [错题本.md](../../错题本.md)。

## 附：考前速查卡（5 分钟过一遍）

| 考点 | 一句话抓手 |
|---|---|
| 空格方向 | 转折**反**、递进**深**、并列**同**、解释**概括**、因果**呼应** |
| 重点位置 | 转折后、递进后、结论后、对策句；并列须加和；例子永远不是主旨 |
| 正确项长相 | 温和改写：部分 / 可能 / 尚可 / 有一定 |
| 错误项长相 | 加码改写：都 / 必 / 唯一 / 无中生有 / "了"变"到" |
| 假设 vs 让步 | 如果…就（未发生）；尽管/即使…也（已是事实） |
| 首句排除 | 指代词、关联后半、顺序词开头——见即杀 |
| 排序最硬依据 | 指代捆绑、关联配对、重复词捆绑 |
| 填充判据 | 两头接缝；只接一头的"半截管"必错 |
| 意图引申 | 只走半步、贴着病因；万能呼吁是坑 |
| 标题三标准 | 全面、醒目、匹配文体 |
