# 言语理解知识图谱

> 核心问题：作者围绕什么话题，按照什么结构，想表达什么；选项是否与原文对象、范围和强度一致。

## 二、语境关系图

    关联词
    ├─ 转折：虽然…但是 / 然而 / 实际上
    │  └─ 前后反向，重点常在转折后
    ├─ 递进：不仅…而且 / 甚至 / 更
    │  └─ 前后同向，后项程度更深
    ├─ 因果：因为…所以 / 因此 / 可见
    │  └─ 原因支撑结果，主旨常落在结论
    ├─ 并列：同时 / 既…又 / 分号
    │  └─ 多项同级，主旨须全面概括
    ├─ 解释：即 / 也就是说 / 冒号 / 破折号
    │  └─ 抽象与具体互相解释
    └─ 条件：只要…就 / 只有…才 / 除非
       └─ 区分充分条件和必要条件

**跨题型关系：**

- 关联词 → 决定逻辑填空的词义方向；
- 关联词 → 帮助片段阅读寻找重点句；
- 关联词 → 构成语句排序中的捆绑关系；
- 关联词使用不完整 → 可能提示语句填空位置。

## 三、逻辑填空图谱

    逻辑填空
       ↓ 第一步
    判语境方向
       ├─ 同义并列
       ├─ 反义转折
       ├─ 递进加重
       ├─ 因果对应
       └─ 解释对应
       ↓ 第二步
    比词义差异
       ├─ 范围大小
       ├─ 程度轻重
       ├─ 侧重点
       ├─ 适用对象
       └─ 感情色彩
       ↓ 第三步
    验证搭配和语体

### 3.1 词语辨析五刀

| 节点 | 问法 | 示例方向 |
| --- | --- | --- |
| 范围 | 谁包含谁，适用对象多大 | “事件”范围通常大于“案件” |
| 程度 | 哪个更强、更深或更紧迫 | 关注 < 重视 < 高度重视 |
| 侧重 | 动作、状态、结果还是过程 | 改善重结果，改进重过程与方法 |
| 色彩 | 褒义、贬义还是中性 | 果断与武断不能互换 |
| 搭配 | 与什么主语、宾语、语体组合 | “发挥作用”“履行职责” |

### 3.2 成语节点

    成语
    ├─ 字面义
    ├─ 比喻义
    ├─ 使用对象
    ├─ 感情色彩
    ├─ 语法功能
    └─ 固定使用条件

> 成语不能只背一句释义，易混组见 [易混成语辨析表](易混成语辨析表.md)，完整方法与例题见 [逻辑填空专题](逻辑填空专题.md)。

## 四、片段阅读图谱

### 4.1 行文结构

    文段结构
    ├─ 总—分：首句提出观点，后文解释
    ├─ 分—总：前文铺垫，尾句归纳
    ├─ 总—分—总：首尾共同限定中心
    ├─ 问题—对策：重点常在有效对策
    ├─ 提出观点—举例论证：例子服务观点
    ├─ 背景—转折—观点：转折后是作者态度
    └─ 并列：中心必须覆盖全部并列项

### 4.2 主旨与意图

    片段阅读
       ↓ 圈出高频话题词
    主题对象
       ↓ 判断句间关系
    行文结构
       ↓ 定位作者判断或对策
    中心意思
       ↓ 与选项比对
    同义替换

**选项筛查：**

- 主题对象一致，但只概括例子 → 片面；
- 主题对象一致，但强度升级 → 过度；
- 内容正确，但不是文段重点 → 偏离中心；
- 提出新概念或新关系 → 无中生有；
- 对策过度具体、材料无依据 → 过度引申。

### 4.3 主旨、意图、标题的关系

    主旨题 → 准确概括作者主要观点
    意图题 → 在主旨基础上判断作者希望读者认识或行动什么
    标题题 → 主旨 + 对象明确 + 简洁吸引 + 不夸大

**边界：** 意图不等于任意拔高，标题不等于只求生动。

### 4.4 细节判断六类偷换

    原文与选项比对
    ├─ 对象偷换
    ├─ 范围偷换：部分 ↔ 全部
    ├─ 时态偷换：可能/将要 ↔ 已经
    ├─ 程度偷换：可能 ↔ 必然
    ├─ 逻辑偷换：相关 ↔ 因果
    └─ 条件偷换：条件之一 ↔ 唯一条件

> 片段题型和例题见 [片段阅读专题](片段阅读专题.md)。

## 五、语句表达图谱

### 5.1 排序题

    排序
    ├─ 选首句
    │  ├─ 引入话题
    │  ├─ 下定义
    │  └─ 提出观点
    ├─ 找捆绑
    │  ├─ 指代词与指代对象
    │  ├─ 关联词成对
    │  ├─ 重复话题词
    │  └─ 时间或逻辑顺序
    ├─ 排局部顺序
    │  ├─ 提出问题 → 分析 → 解决
    │  ├─ 观点 → 解释 → 举例
    │  └─ 宏观 → 微观 / 过去 → 现在
    └─ 通读验证

**不能作首句的高频信号：** 无明确指代对象的“这/其/该”、单独出现的“因此/但是”、明显承接前文的“也/更/这种”。

### 5.2 填空题

    空格位置
    ├─ 段首 → 引领下文、概括话题
    ├─ 段中 → 承上启下、保持局部衔接
    └─ 段尾 → 总结全文、提出结论或对策

    候选句
       ↓ 检查
    话题一致 + 指代清楚 + 逻辑顺畅 + 语体统一

### 5.3 下文推断

    尾句提出新话题 → 下文解释新话题
    尾句提出问题   → 下文分析原因或给出解决办法
    尾句列出分类   → 下文通常先讲第一个分类
    尾句已经总结   → 下文可能转换到相关的新层面

> 排序、填空和下文推断见 [语句排序与填充专题](语句排序与填充专题.md)。

## 七、错题回挂图

| 错因 | 应回挂节点 | 修正动作 |
| --- | --- | --- |
| 两个词都认识仍选错 | 词义五刀 | 写出范围、程度、对象差异 |
| 找到主题却主旨错 | 行文结构 | 标出观点句与例子句 |
| 总在二选一错 | 选项偷换 | 逐词比对范围和强度 |
| 排序只凭语感 | 捆绑关系 | 写出指代、关联和时间钩子 |
| 意图题过度拔高 | 主旨—意图关系 | 先准确概括，再有限引申 |

> 更完整的概念解释见 [言语理解知识点总纲](知识点.md)。
