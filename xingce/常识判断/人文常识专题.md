# 常识判断 · 人文常识专题（历史脉络 / 文学谱系 / 传统文化）

> 人文常识范围大但**考法很窄**：考"**第一 / 之最**""**朝代与事件对应**""**作者与作品对应**""**习俗与节日对应**"。
> 复习策略是**织网**：一条朝代线、一张文学表、一组文化符号——网织好，零散知识点自动挂上去。

## 一、历史主线（先背"顺序 + 都城 + 大事"）

### 朝代顺序歌

> 夏商与西周，东周分两段；春秋和战国，一统秦两汉；
> 三分魏蜀吴，二晋前后延；南北朝并立，隋唐五代传；
> 宋元明清后，皇朝至此完。

### 历史文化名人速挂

- **诸子百家**：孔子（仁、儒家）、《老子》（道家，辩证法）、墨子（兼爱非攻）、韩非子（法家集大成）、孙武（《孙子兵法》"知己知彼"）；
- **司马迁**《史记》：第一部**纪传体**通史（"史家之绝唱，无韵之离骚"）；司马光《资治通鉴》：第一部**编年体**通史；
- **四大发明**：造纸（东汉蔡伦改进）、印刷（隋唐雕版、北宋毕昇活字）、火药（唐末用于军事）、指南针（战国司南 → 北宋用于航海）。

## 三、传统文化（考"对应"）

### 传统节日（按农历）

| 节日 | 时间 | 习俗符号 |
| --- | --- | --- |
| 春节 | 正月初一 | 贴春联、守岁、拜年 |
| 元宵节 | 正月十五 | 赏灯、吃元宵、猜灯谜 |
| 清明节 | 公历 4 月 5 日前后 | 扫墓、踏青（唯一按**阳历**定的传统大节，节气合一） |
| 端午节 | 五月初五 | 赛龙舟、吃粽子（纪念屈原） |
| 七夕 | 七月初七 | 牛郎织女、乞巧 |
| 中元节 | 七月十五 | 祭祖 |
| 中秋节 | 八月十五 | 赏月、吃月饼 |
| 重阳节 | 九月初九 | 登高、敬老、赏菊（老年节） |
| 腊八 | 腊月初八 | 腊八粥 |

### 二十四节气（歌谣 + 考点）

> 春雨惊春清谷天，夏满芒夏暑相连；秋处露秋寒霜降，冬雪雪冬小大寒。

- 节气反映**黄河流域**的气候农事，是**农历**的组成部分（指导农事的阳历成分）；
- "四立"（立春立夏立秋立冬）表季节开始；二分二至：春分秋分（昼夜平分）、夏至（白昼最长）冬至（白昼最短）；
- 2016 年列入联合国教科文组织**人类非物质文化遗产**。

### 文化符号速记

- **文房四宝**：笔墨纸砚；**梅兰竹菊**：四君子；**岁寒三友**：松竹梅；
- **花中四雅 / 四大名绣**：苏绣、湘绣、粤绣、蜀绣；
- **京剧**：国粹，生旦净丑四大行当，"唱念做打"；**昆曲**：百戏之祖（首个入选人类非遗的剧种，2001）；
- **书法**：王羲之"书圣"《兰亭序》（天下第一行书）；颜真卿（颜体，雄浑）、柳公权（柳体，"颜筋柳骨"）、怀素张旭（狂草）；
- **国画**：《清明上河图》张择端（北宋风俗画）；"画圣"吴道子；
- **中医**：《黄帝内经》（最早的医学典籍）、张仲景《伤寒杂病论》"医圣"、李时珍《本草纲目》、华佗（麻沸散、五禽戏）；
- **史书体裁**：编年体（《春秋》《资治通鉴》）、纪传体（《史记》）、纪事本末体；
- **科举**：院试（秀才）→ 乡试（举人，第一名称"解元"）→ 会试（贡士，"会元"）→ 殿试（进士，"状元"）；连中三元 = 三试皆第一。

## 四、易错点清单

1. **《史记》是纪传体**，《资治通鉴》是编年体——考"第一部编年体通史"别答《史记》。
2. **《狂人日记》是第一篇白话小说**（不是第一部长篇白话小说——《子夜》等另说，注意提问口径）。
3. **清明节按阳历**（节气），其余传统节日按农历。
4. **夏至白昼最长、冬至白昼最短**；"冬至吃饺子"是习俗不是节气含义。
5. **元曲 ≠ 元杂剧**；《天净沙·秋思》是**散曲**小令。
6. **四大名著作者**张冠李戴是高频送分坑（三国-罗贯中、水浒-施耐庵）。
7. **"医圣"是张仲景**（华佗不是圣，扁鹊是脉学之宗）。
8. **连中三元**的"三元"：解元、会元、状元。

## 六、自测练习

1. 我国第一部纪传体通史和第一部编年体通史分别是什么？
2. "但愿人长久，千里共婵娟"写的是哪个节日？作者是谁？
3. 岁寒三友和花中四君子分别是什么？
4. 活字印刷术的发明者是谁？生活在哪个朝代？
5. 下列哪个节日的日期按阳历确定？（A. 端午　B. 中秋　C. 清明　D. 重阳）

### 答案附录

1. 《**史记**》（司马迁，纪传体）；《**资治通鉴**》（司马光，编年体）。
2. **中秋**节；**苏轼**（《水调歌头·明月几时有》）。
3. 岁寒三友：**松、竹、梅**；四君子：**梅、兰、竹、菊**。
4. **毕昇**，**北宋**（平民发明家，胶泥活字）。
5. **C**（清明为节气，按太阳黄经定，公历 4 月 5 日前后；余者均按农历）。

## 错题归因模板

做错时按三类归因，记入 [错题本.md](../../错题本.md)：

- **对应错**：朝代—事件、作者—作品、节日—习俗挂错号；
- **概念错**："第一部 / 之最"的限定词没看清（纪传体 vs 编年体、白话 vs 文言）；
- **范围错**：节气属阳历成分、节日的农历日期等时间口径混淆。
