# 常识判断 · 地理常识专题（中国地理 / 世界地理 / 自然现象）

> 地理常识考三样：**"位置"—"之最"对位**（最长的河、最大的高原）、**分界线**（阶梯、秦岭—淮河、季风区）、**自然现象的成因**（四季、昼夜、时区）。
> 地理题是典型的"**记对得分、记混丢分**"——把分界线和"之最"织成网，比零散背一百个知识点有效。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../../错题本.md)。

## 一、中国地理（考"三级阶梯 + 之最"）

### 地势三级阶梯

| 阶梯 | 范围 | 平均海拔 | 记忆点 |
| --- | --- | --- | --- |
| 第一级 | 青藏高原 | 4000 米以上 | **世界屋脊**，阶梯界线：**昆仑山—祁连山—横断山脉** |
| 第二级 | 高原盆地 | 1000—2000 米 | 界线：**大兴安岭—太行山—巫山—雪峰山** |
| 第三级 | 平原丘陵 | 500 米以下 | 东部平原、东南丘陵 |

> 地势**西高东低**→ 大江大河多自西向东流（水能集中在阶梯交界处）。

### 中国"之最"速查

| 类别 | 之最 |
| --- | --- |
| 最大高原 | 青藏高原（也是世界最高） |
| 最大盆地 | **塔里木盆地**（内含中国最大沙漠——塔克拉玛干） |
| 最高盆地 | 柴达木盆地（"聚宝盆"） |
| 最大平原 | 东北平原 |
| 最大岛屿 | **台湾岛**（海南岛第二） |
| 最长的河 | **长江**（6300 公里，世界第三） |
| 第二长河 | 黄河（"地上河"在下游） |
| 最大的淡水湖 | **鄱阳湖**（江西）；洞庭湖第二 |
| 最大的咸水湖 | 青海湖 |
| 最长的内流河 | 塔里木河 |
| 唯一注入北冰洋的河 | 额尔齐斯河 |
| 最大的海峡 | 台湾海峡 |
| 陆地最低点 | 吐鲁番盆地艾丁湖 |

### 秦岭—淮河一线（地理分界线的"总开关"）

- 1 月 **0℃** 等温线；**800 毫米**年等降水量线；
- 亚热带与暖温带、湿润区与半湿润区、**南方与北方**分界；
- 温带落叶阔叶林与亚热带常绿阔叶林；旱地与水田；河流结冰与不结冰。

### 河流与省份

- 长江：发源青藏高原（唐古拉山）→ 流经 **11 个省级区**→ 注入东海；上游水能（三峡）、中游荆江"九曲回肠"、下游黄金水道；
- 黄河：发源巴颜喀拉山 → 注入**渤海**；"凌汛"出现在宁夏、内蒙古与山东段（由低纬流向高纬的河段）；
- 五大淡水湖（由大到小）：鄱阳湖、洞庭湖、太湖、洪泽湖、巢湖；
- **跨纬度最广**的省：海南；**邻国最多**的省：新疆（8 个）；**邻省最多**的省：内蒙古、陕西（各 8 个）。

## 二、世界地理（考"大洲大洋 + 海峡运河"）

| 考点 | 内容 |
| --- | --- |
| 七大洲（面积由大到小） | 亚非北南美，南极欧大洋 |
| 四大洋（由大到小） | 太平洋、大西洋、印度洋、北冰洋 |
| 最高的高原 | 巴西高原（**最大**）；最高是青藏高原 |
| 最长的山脉 | **安第斯山脉**（南美洲，"南美洲的脊梁"） |
| 最大的平原 | 亚马孙平原（热带雨林） |
| 最深的湖 | 贝加尔湖（世界上最深、淡水储量最大） |
| 最大的沙漠 | 撒哈拉（非洲） |
| 最大的半岛 | 阿拉伯半岛 |
| 世界最低点 | 死海（湖面约 -430 米） |

### 海峡与运河（航运咽喉）

| 名称 | 地位 |
| --- | --- |
| 马六甲海峡 | 连接印度洋与太平洋，"海上生命线"（日本称） |
| 霍尔木兹海峡 | 波斯湾石油出口唯一海运通道，"石油海峡" |
| 直布罗陀海峡 | 地中海唯一通大西洋的出口 |
| 苏伊士运河 | 亚欧海运捷径（地中海—红海），亚洲与非洲分界 |
| 巴拿马运河 | 连接太平洋与大西洋，南北美洲分界 |
| 白令海峡 | 亚洲与北美洲分界、俄美边界 |

> 大洲分界线：亚欧——乌拉尔山脉、乌拉尔河、里海、大高加索山脉、黑海、土耳其海峡；亚非——苏伊士运河；南北美——巴拿马运河。

## 三、自然现象与时区（考"成因"）

- **四季与五带**：地球**公转** + 地轴倾斜（黄赤交角）→ 太阳直射点在南北回归线间移动 → 四季更替与五带划分；
- **昼夜交替**：地球**自转**（周期约 24 小时）；昼夜长短变化随纬度和季节（夏至北半球昼最长）；
- **极昼极夜**：极圈以内（极光也在极圈附近——见科技专题）；
- **时区**：全球 24 个时区，每 15° 经度 1 小时；**北京在东八区**（UTC+8）；**越往东时间越早**（"东加西减"）；国际日期变更线大致沿 180° 经线，跨线**自西向东减一天**；
- 北京时间 = 东八区**区时**（120°E 地方时，不是北京 116°E 的地方时）；
- **气候类型速记**：热带——雨林（全年多雨）、草原（干湿两季）、沙漠（全年干旱）、季风（雨旱两季）；亚热带——季风（雨热同期，我国南方）、地中海（**夏干热冬温雨**，独一无二）；温带——季风、海洋性、大陆性；
- 我国气候：**季风气候显著**（东部的热带/亚热带/温带季风）+ **气候复杂多样**；
- 寒潮、台风（夏秋东南沿海）、梅雨（长江中下游 6 月）、沙尘暴（北方春季）——我国主要气象灾害。

## 四、易错点清单

1. **最大盆地是塔里木，最高盆地是柴达木**——"最"字对位。
2. **最大的淡水湖是鄱阳湖**（不是洞庭湖、不是青海湖——咸水湖）。
3. **巴西高原是最大高原，青藏高原是最高高原**——题干问"最大"还是"最高"要分开。
4. **黄河注入渤海，长江注入东海**——入海口对位。
5. **秦岭—淮河 = 800mm 降水线 = 1 月 0℃ 线**——别记成 400mm（那是半干旱区界线，大兴安岭—张家口—兰州—拉萨一线）。
6. **台湾岛是我国最大岛屿**（海南岛第二）。
7. 地球自转 → 昼夜交替；公转 + 黄赤交角 → 四季——**别把四季归因于自转**。
8. **北京时间是 120°E 的区时**，不是北京经度的地方时。
9. 亚欧分界线**不经过苏伊士运河**（那是亚非分界）。

## 五、速记卡（考前 5 分钟过一遍）

> 昆仑祁连横断一，太行巫山雪峰二；西高东低江河东，水能藏在阶梯换。
> 塔里木盆大沙漠，柴达木高聚宝盆；鄱阳淡水青海咸，长江东海黄河渤。
> 亚非北南美，南极欧大洋；安第斯最长，亚马孙平原广。
> 马六甲生命线，霍尔木兹石油咽；苏伊士分亚非，巴拿马分美洲。
> 自转昼夜公转季，回归线上太阳移；北京东八度经百二，东加西减换日期。

## 六、自测练习

1. 我国地势第一、二级阶梯的分界线是什么？
2. 我国最大的淡水湖、最大的咸水湖分别是什么？
3. 世界最大的高原和最高的高原分别是什么？
4. 亚洲与非洲的分界线、南美洲与北美洲的分界线分别是什么？
5. 四季更替和昼夜交替分别由什么引起？

### 答案附录

1. **昆仑山—祁连山—横断山脉**（第二、三级阶梯分界：大兴安岭—太行山—巫山—雪峰山）。
2. 淡水湖：**鄱阳湖**（江西）；咸水湖：**青海湖**。
3. 最大：**巴西高原**；最高：**青藏高原**（"世界屋脊"）。
4. 亚非分界：**苏伊士运河**；南北美分界：**巴拿马运河**。
5. 四季更替：地球**公转 + 地轴倾斜**（太阳直射点移动）；昼夜交替：地球**自转**。

## 错题归因模板

做错时按三类归因，记入 [错题本.md](../../错题本.md)：

- **对位错**："之最"张冠李戴（最大/最高、淡水/咸水、盆地/高原）；
- **分界错**：阶梯、秦岭—淮河、大洲分界线的线路记串；
- **成因错**：自然现象归因错（自转/公转、时区东加西减方向反）。
