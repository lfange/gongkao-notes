# 常识判断 · 法律常识专题（宪法 / 民法典 / 刑法 / 行政法 / 新法清单）

> 法律是常识判断的"稳定得分区"：考点高度集中在**宪法制度、民法典新变化、刑法年龄、行政行为四分类**。

## 一、宪法（考国家机构与公民权利）

### 补充说明：宪法、民法典、刑法分别管什么

| 法律 | 核心内容 | 生活或考试中的例子 |
| --- | --- | --- |
| 宪法 | 国家根本制度、公民基本权利和义务、国家机构及国家象征等，具有最高法律效力 | 全国人大有什么职权？公民有哪些基本权利？ |
| 民法典 | 平等主体之间的人身关系和财产关系 | 买卖、租房、借钱、结婚离婚、继承、侵权赔偿 |
| 刑法 | 什么行为构成犯罪、应承担什么刑事责任、适用什么刑罚 | 盗窃、诈骗、故意伤害何时构成犯罪，如何处罚 |

民法典七编可以对应记为：**总则是基础规则；物权管物的归属和利用；合同管交易约定；人格权保护姓名、肖像、名誉、隐私等；婚姻家庭管家庭关系；继承管遗产；侵权责任管侵害权益后的责任。**

同一行为可能同时涉及不同法律：故意打伤他人，医疗费等赔偿涉及民事责任；达到犯罪条件的，还可能承担刑事责任。

国家机构及法规制定机关的例子见[法理学与宪法专题的补充说明](../../招警/法理学与宪法专题.md#补充说明人大人大常委会和政府)。依据：[宪法第三章](https://www.cac.gov.cn/2018-03/22/c_1122572643.htm)、[民法典全文](https://www.spp.gov.cn/zdgz/202006/t20200602_463886.shtml)、[刑法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5212248/content.html)。

### 高频数字

| 考点 | 内容 |
| --- | --- |
| 现行宪法 | 1982 年制定，历经 1988、1993、1999、2004、**2018** 五次修正 |
| 国家主席、副主席 | 连续任职**不受**两届限制（2018 年修正） |
| 监察委员会 | 2018 年入宪，国家监察体制：监委**独立行使监察权**，与"一府两院"并列为"一府一委两院" |
| 全国人大常委会组成 | 委员长、副委员长、秘书长、委员；**连续任职不得超过两届**的是委员长、副委员长 |
| 修宪程序 | 全国人大常委会或 **1/5 以上**全国人大代表提议，全体代表 **2/3 以上**多数通过 |
| 法律案通过 | 一般法律：全体代表**过半数**；宪法：2/3 以上 |

### 国家机构权限速记

- **全国人大**：修改宪法、制定基本法律、选举国家领导人；
- **全国人大常委会**：解释宪法和法律、制定一般法律、闭会期间代行部分职权；
- **国务院**：中央人民政府，**最高行政机关**，制定行政法规；
- **监察委**：对所有行使公权力的公职人员监察全覆盖；
- **法院 / 检察院**：审判权 / 检察权（法律监督），**依法独立行使，不受行政机关干涉**。

### 公民权利高频点

- **平等权**（法律面前人人平等）是首要的基本权利；
- 劳动和受教育既是**权利又是义务**；
- **物质帮助权**：年老、疾病、丧失劳动能力时获得帮助；
- 人身自由：**非经检察院批准或法院决定，不受逮捕**（公安机关执行）。

## 二、民法典（2021 年 1 月 1 日施行，考"新变化"）

### 民法典七编

总则、物权、合同、人格权、婚姻家庭、继承、侵权责任（**人格权独立成编是世界首创**）。

### 必背新变化

| 考点 | 规则 |
| --- | --- |
| 民事行为能力 | **8 周岁**以下无行为能力；8 周岁以上未成年人为限制行为能力（可独立实施纯获利益或与其年龄智力相适应的行为） |
| 诉讼时效 | 一般 **3 年**（民法总则起由 2 年改 3 年），自知道或应当知道之日起算 |
| 离婚冷静期 | 协议离婚：申请后 **30 日**内可撤回；期满后 **30 日**内须亲自领证 |
| 遗产范围 | 由列举具体种类并设兜底项，改为**概括式**定义：自然人死亡时遗留的个人合法财产；依法或依其性质不得继承的除外，不能把所有网络资产一概认定为可继承 |
| 打印遗嘱 | 新增有效形式：**两个以上见证人**在场见证，遗嘱人和见证人在每一页签名注日期 |
| 居住权 | 新设用益物权：居住权**无偿**设立（另有约定除外），不得转让、继承 |
| 高空抛物 | 明确**禁止**从建筑物中抛掷物品；查不清责任人时，可能加害的建筑物使用人**补偿**（可追偿），物业未尽安保义务担责 |
| 见义勇为 | 因自愿实施紧急救助造成受助人损害的，救助人**不承担**民事责任（"好人条款"） |
| 保密义务 | 任何组织和个人不得以刺探、侵扰、泄露、公开等方式侵害他人**隐私权** |

### 补充说明：列举式、概括式和不能继承的财产

**列举式是“列清单”，概括式是“给判断标准”。**原《继承法》第三条列出收入、房屋、储蓄、生活用品、林木牲畜、文物图书等，最后还有“其他合法财产”的兜底项；《民法典》第一千一百二十二条不再逐项列财产种类，而是用“死亡时遗留的个人合法财产”统一判断。

例如，房屋、银行存款、股票等，只要属于死者留下的个人合法财产，且不存在不得继承的情形，就可以依法继承。这种写法便于适应新的财产形式。**不能理解为“旧法没列出来就不能继承”**，因为旧法也有兜底规定。

| 不能作为遗产继承的情形 | 例子与分界 |
| --- | --- |
| 不属于死者的财产 | 向朋友借来的汽车仍归朋友；不能因为车在死者家里就继承 |
| 共有财产中属于他人的份额 | 夫妻共有存款100万元，无其他约定时，先分出50万元归在世配偶，另外50万元才是遗产；配偶还可能参与继承这50万元 |
| 非法取得的财物 | 盗窃、诈骗所得赃款赃物，不属于个人合法财产，应依法追缴、退赔等 |
| 法律规定不得继承的权利 | 民法典规定的居住权不得继承，权利人死亡时消灭；但本人合法所有的房屋通常可以继承 |
| 因死亡而向家属支付的特定款项 | 死亡赔偿金、死亡抚恤金通常不属于死者遗产，按相应规则确定领取与分配 |
| 依法直接给付指定受益人的身故保险金 | 父亲指定女儿为身故受益人，且女儿依法享有受益权时，该笔保险金不按父亲的遗产分配；没有指定受益人等法定情形下，保险金也可能作为遗产 |

姓名权、肖像权等人格权本身也不能继承；近亲属依法保护死者人格权益，不等于继承这些权利。

依据：[原继承法第三条](https://www.sdcourt.gov.cn/whhcqfy/754240/754247/848240/index.html)、[民法典第1122、1153条](https://www.cac.gov.cn/2020-06/01/c_15925617772683195.htm)、[第369、370条](https://www.cac.gov.cn/2020-06/01/c_15925617772683191.htm)、[第992、994条](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)、[死亡赔偿金及抚恤金案例](https://nyzy.hncourt.gov.cn/public/detail.php?id=29606)、[保险法第四十二条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_4c715a53f3d4402c89f62ae77809f638.html)。

### 合同与担保常考

- **要约**：希望与他人订立合同的意思表示（内容具体确定 + 表明经受要约人承诺即受约束）；**要约邀请**：招标公告、拍卖公告、招股说明书、商业广告和宣传（商业广告内容符合要约条件的视为要约）；
- 保证方式没有约定或约定不明的，按**一般保证**承担（民法典改了原担保法"推定连带"的规则）；
- **抵押不转移占有，动产质押转移占有**；权利质押依登记等法定方式设立，不能一概理解为交付实物。

### 补充说明：要约与要约邀请

**要约：条件说清楚，并表明你同意就按此订合同。**例如，你对小王说：“我这辆自行车800元卖给你，明天下午交车，你同意就成交。”小王按原条件回复“同意”，就是承诺；承诺生效时，合同通常成立。

**要约邀请：先邀请别人来报价或提出交易条件。**例如：“有辆二手自行车出售，有意联系，价格面议。”小王回复“我出500元买”，才是小王提出要约，你还可以决定是否接受。

招标公告是邀请他人投标，投标通常才是要约；商业广告通常是要约邀请，但符合要约条件的构成要约。重点看**内容是否具体确定，以及是否表明接受即受约束**，不能只看名称。

### 补充说明：一般保证与连带责任保证

假设小王向你借10万元，小李与你依法成立保证合同，替小王担保：

| 保证方式 | 到期不还时如何承担责任 |
| --- | --- |
| 一般保证 | 通常须先就债务纠纷经过诉讼或仲裁，并依法执行小王的财产，仍不能清偿，才由小李承担保证责任；法律规定的例外除外 |
| 连带责任保证 | 可以要求小王履行债务，也可以在保证范围内直接要求小李承担保证责任 |

**没有约定保证方式或约定不明，按一般保证处理。**这不等于“没有成立保证合同也自动成为保证人”，也不是“催小王一次就可以找小李还钱”。“原担保法推定连带”是旧规则，新旧规则不能混用。

### 补充说明：抵押与动产质押

**占有，可以先理解为实际控制、保管财物。**你用汽车抵押借钱，车通常还由你开；你用手表作动产质押，要将手表交给债权人占有。这里讨论的是依法设立担保后的区别，不能理解为所有财产仅签合同就能设立担保物权。

财物作为担保，不等于所有权立即归债权人。到期不还时，债权人可依法就担保财产折价、拍卖、变卖所得价款优先受偿。股权等权利也可以质押，其设立方式另按法律规定。

依据：[民法典第472—473、483、686—688条](https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm)、[第394、425、429、440条及相关规定](https://www.court.gov.cn/zixun/xiangqing/233181.html)。

## 三、刑法（考年龄 + 正当防卫 + 常见罪名）

### 刑事责任年龄（2021 年 3 月 1 日刑法修正案（十一）后）

| 年龄 | 责任 |
| --- | --- |
| ≥16 | 对所有犯罪负责 |
| 14–16 | 仅对**八类重罪**负责：故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质 |
| **12–14** | 犯故意杀人、故意伤害罪，致人死亡或以特别残忍手段致人重伤造成严重残疾，情节恶劣，**经最高检核准追诉**的应负刑责（修正案十一新增） |
| <12 | 一律不负刑事责任 |

### 正当防卫（2020 年指导意见后为热点）

- 起因：存在**不法侵害**（真实、正在进行）；
- 时间：不法侵害**正在进行**（事前、事后都不算）；
- 对象：针对不法侵害人本人；
- **明显超过必要限度造成重大损害**才构成防卫过当（负刑责但应减轻或免除）；
- **特殊防卫**（无限防卫权）：对行凶、杀人、抢劫、强奸、绑架等严重危及人身安全的暴力犯罪，造成不法侵害人伤亡的，**不属于防卫过当**。

### 高频罪名分界

- **盗窃 vs 抢夺 vs 抢劫**：秘密窃取 / 乘人不备公然夺取 / 当场使用暴力或胁迫（抢劫最高可判死刑）；
- 贪污（国家工作人员+利用职务便利）vs 职务侵占（非国家工作人员）；
- 危险驾驶罪：**醉驾（血液酒精 ≥80mg/100ml）**、追逐竞驶等，是"行为犯"——不要求出事故。

## 四、行政法（考"行为分类"，与定义判断联动）

### 具体行政行为四分类

| 行为 | 性质 | 例子 |
| --- | --- | --- |
| **行政许可** | 事前**放行**（赋予资格） | 颁发营业执照、排污许可 |
| **行政确认** | 事后**盖章**（认定既有事实） | 交通事故责任认定、学位证书 |
| **行政处罚** | **制裁**（对违法） | 罚款、行政拘留、吊销许可证 |
| **行政强制** | **手段**（保障执行） | 查封、扣押、冻结（强制措施）；加处罚款、划拨（强制执行） |

### 复议与诉讼

- 复议**前置**的典型：纳税争议（先复议后诉讼）；多数行为可**自由选择**复议或诉讼；
- 起诉期限：直接起诉一般自知道或应当知道行政行为之日起 **6 个月**；经复议后不服的，一般自收到复议决定书之日起 **15 日**内起诉，法律另有规定除外；
- 行政诉讼**不适用调解**（赔偿、补偿及行使自由裁量权的案件除外）。

### 补充说明：前置与复议时间怎么理解

**前置就是下一步之前必须先走的程序。**复议前置案件要先申请行政复议，对复议结果不服再依法起诉，不能跳过复议直接起诉。

例如，6月1日小王收到当场罚款决定，6月10日提交复议申请，6月12日被受理，7月3日复议机关作出决定，7月6日小王收到决定书。**申请60日是给小王提交申请的期限；普通程序办案60日从受理起算，是给复议机关的期限；收到决定书后一般15日内起诉，是给小王去法院的期限。**“日内”是最迟期限，不用等满才能办。

完整的前置清单、例子、受理与补正期限、特殊期限及法条依据见[行政执法法律专题](../../招警/行政执法法律专题.md#补充说明复议前置的情形和例子)。

## 六、易错点清单

1. **宪法修正案年份记串**：五次修正 1988/1993/1999/2004/**2018**，监察委、取消主席任期限制是 2018。
2. **诉讼时效 3 年**（不是 2 年）；行政诉讼 6 个月、复议后 15 日。
3. **离婚冷静期只适用协议离婚**，诉讼离婚不适用。
4. **防卫过当的认定**："明显超过必要限度**且**造成重大损害"，两个条件缺一不可。
5. **许可 vs 确认**：营业执照是许可（事前放行），事故责任认定是确认（事后盖章）——定义判断与常识双重考点。
6. **8 周岁**（原 10 周岁）是无/限制行为能力分界。
7. **醉驾标准 80mg/100ml**，属于危险驾驶罪，不需要造成后果。

## 七、速记卡（考前 5 分钟过一遍）

> 宪法五修 18 最新，监委独立一委两院；修宪代表 2/3 过，法律过半主席限届无。
> 民法典 21 年行，人格独立世界先；时效三年冷静三十，打印遗嘱两人见。
> 刑责 12 到 14，杀人重残最高检核；醉驾八十行为犯，正当防卫看进行。

## 八、自测练习

1. 我国现行宪法经历了几次修正？最近一次是哪一年？
2. 未成年人几周岁以上、不满十八周岁，实施故意杀人等特定犯罪经最高人民检察院核准追诉的应负刑事责任？
3. 协议离婚的冷静期是多少天？
4. 交管部门出具交通事故责任认定书属于哪一类具体行政行为？
5. 我国第一部专门关于民营经济的基础性法律是什么？何时施行？

### 答案附录

1. **五次**（1988、1993、1999、2004、**2018**）。
2. **12 周岁**（已满 12 不满 14，故意杀人、故意伤害致人死亡或特别残忍手段致重伤严重残疾、情节恶劣，经**最高检核准追诉**）。
3. **30 日**（30 日内任一方可撤回申请；期满后 30 日内须双方亲自申请领证）。
4. **行政确认**（对已发生的法律事实进行甄别、认定、宣告；对比：颁发执照是行政许可）。
5. **民营经济促进法**，2025 年 5 月 20 日施行。

## 错题归因模板

做错时按三类归因，记入 [错题本.md](../../错题本.md)：

- **数字错**：年龄 / 期限 / 比例记错（回到对应表格重记）；
- **分界错**：许可 vs 确认、盗窃 vs 抢劫、防卫时间条件等分界线混淆；
- **时效错**：新法新变化没更新（记录"名称 + 施行时间 + 首创点"三元组）。
