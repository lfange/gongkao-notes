# 常识判断 · 科技常识专题（物理化学生物 / 天文航天 / 前沿科技）

> 科技常识考两类：**中小学科学课的"硬知识"**（光声电磁、遗传维生素、月相日食）和**中国航天/大工程的"成就清单"**。
> 硬知识考辨析（现象背后的原理），成就清单考对应（项目—时间—首创点）。**常识科技题爱考"现象的原理是什么"**。
> **本专题成就截至 2025 年，之后的发射与工程以时政积累为准。**
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../../错题本.md)。

## 一、物理（考"现象 → 原理"）

| 现象 | 原理 |
| --- | --- |
| 海市蜃楼 | 光的**折射** + 全反射（密度不均的大气） |
| 水中筷子"折断" | 光的**折射** |
| 镜中像、后视镜、潜望镜 | 光的**反射** |
| 天空蓝色、朝霞晚霞 | **散射**（瑞利散射，蓝光波长短易被散射） |
| 影子、日食月食 | 光沿**直线传播** |
| 冬天摸铁比摸木头冷 | 铁是热的**良导体**，导热快（不是铁温度低） |
| 烧开水"白气" | 水蒸气遇冷**液化**（不是蒸发） |
| 樟脑丸变小 | **升华**（固态直接变气态） |
| 下雪不冷化雪冷 | 融化**吸热**、凝固放热 |
- 声音不能在真空中传播；光可以——**电磁波不需要介质**；
- 音调由频率决定，响度由振幅决定，音色辨人；
- 串联分压、并联分流；家庭电路并联（各用电器独立工作）；
- 安全用电：**不接触低压带电体，不靠近高压带电体**；火线零线 220V。

## 二、化学

| 考点 | 内容 |
| --- | --- |
| 空气成分 | 氮气约 **78%**、氧气约 **21%**（体积分数） |
| 金属活动性顺序 | 钾钙钠镁铝、锌铁锡铅氢、铜汞银铂金（氢前能置换酸中氢） |
| 最轻气体 / 最多的元素 | 氢气 / 宇宙中氢、地壳中**氧** |
| 人体必需微量元素 | 铁、锌、碘、硒（缺碘—甲状腺肿、缺铁—贫血、缺维生素 A—夜盲、缺维生素 C—坏血病、缺维生素 D—佝偻病） |
| 常见灭火 | 隔绝氧气（CO₂ 灭火）、降温（水）、撤走可燃物 |
| 酸碱中和 | 胃酸过多服氢氧化铝（抗酸剂）；酸性土壤撒熟石灰 |
| 硬水软水 | 含较多钙镁离子；煮沸可降低硬度（水垢） |
| 一氧化碳 | 无色无味、**与血红蛋白结合**致中毒（不是缺氧那么简单） |

## 三、生物

- **细胞**是基本单位；**线粒体**——有氧呼吸主场所（动力车间），**叶绿体**——光合作用场所（植物特有）；
- **光合作用**吸 CO₂ 放 O₂（储存能量），**呼吸作用**吸 O₂ 放 CO₂（释放能量）——白天两者并存，光合 > 呼吸时净放氧；
- **遗传**：DNA（基因载体）→ 基因（有遗传效应的 DNA 片段）；DNA 双螺旋——沃森、克里克；
- **血型**：ABO 系统，输血以输同型血为原则；O 型曾称"万能供血者"（现代医学已严格限制）；
- 人体最大器官：**皮肤**；最大的消化腺：**肝脏**（分泌胆汁，不含消化酶但乳化脂肪）；
- 维生素：A—夜盲、B1—脚气病、C—坏血病、D—佝偻（促进钙吸收）；
- **过敏**是免疫功能过强；艾滋病（HIV）攻击**免疫系统**（T 淋巴细胞）。

## 四、天文（考"天体运行常识"）

- **太阳系八大行星**顺序：水金地火木土天海（离太阳由近及远）；**木星最大**；
- 月球**同步自转**（始终一面对地球）；月相：新月（初一）→ 上弦（初七八）→ 满月（十五十六）→ 下弦（廿二三）；
- **日食必在朔（初一）、月食必在望（十五）**；日食是月球挡太阳（月球在中间），月食是地球挡太阳（地球在中间）；
- 极光见于高纬度（太阳带电粒子流与磁场作用）；流星是大气摩擦燃烧（许愿的"流星"多为尘埃颗粒）；
- **二十四节气 / 干支纪年**属天文历法（见人文专题）。

## 五、中国航天与大工程（成就清单——考"时间 + 首创"）

| 工程 | 记忆点 |

| 概念 | 一句话理解 |

## 七、易错点清单

1. **海市蜃楼是折射**（不是反射）；天空蓝色是散射。
2. **白气是液化**，樟脑丸是升华——物态变化别混。
3. **声音真空中不传播，光可以**。
4. **地壳中最多的元素是氧**（不是硅、不是铁）。
5. **日食必在农历初一**、月食必在十五。
6. **缺维生素 D 患佝偻病**（不是缺钙那么直接——D 促进钙吸收）。
7. **肝脏是最大消化腺**，胆汁乳化脂肪但**不含消化酶**。
8. 航天成就"首次"对位：月背着陆（嫦娥四号）、月背采样返回（嫦娥六号）、电磁弹射航母（福建舰）。
9. **木星是最大行星**；离太阳最近的行星是水星。

## 八、速记卡（考前 5 分钟过一遍）

> 蜃楼折射天蓝散，白气液化丸升华；铁导热快像很冷，声音无媒光可传。
> 氮七八氧二一，地壳氧先铁后铝；A 夜盲 C 坏血 D 佝偻，碘防大脖子铁防贫。
> 日食在朔月食望，月背四号六号采；火星天问落祝融，北斗组网二零完。
> 天眼射电五百米，福建电磁弹射先；九章量子墨子号，可控聚变人造太阳。

## 九、自测练习

1. "海市蜃楼"和"天空呈蓝色"分别是什么光学原理？
2. 人体缺碘、缺铁、缺维生素 A 分别导致什么疾病？
3. 日食和月食分别发生在农历的哪一天？为什么？
4. 人类首次实现月球背面采样返回的是哪个探测器？
5. 我国首艘采用电磁弹射技术的航母叫什么？

### 答案附录

1. 海市蜃楼：光的**折射与全反射**（大气密度不均）；天空蓝色：光的**散射**（蓝光波长短，最易被空气分子散射）。
2. 缺碘：**地方性甲状腺肿（大脖子病）**；缺铁：**缺铁性贫血**；缺维生素 A：**夜盲症**。
3. 日食在**初一（朔）**、月食在**十五（望）**——日食是月球运行到日地之间挡住太阳，只有朔日月球才位于日地连线上；月食是地球运行到日月之间，只有望月夜地球阴影才能投到月球上。
4. **嫦娥六号**（2024 年；嫦娥四号是首次月背着陆，六号是首次月背采样返回）。
5. **福建舰**（平直通长飞行甲板 + 电磁弹射；山东舰是首艘国产航母，蒸汽弹射都不是——滑跃甲板）。

## 错题归因模板

做错时按三类归因，记入 [错题本.md](../../错题本.md)：

- **原理错**：现象与物理/化学原理对应错（折射/反射/散射、液化/升华）；
- **对应错**：航天工程"首次"对位错、元素含量排序错；
- **概念错**：前沿科技概念混淆（量子计算 ≠ 量子通信、区块链 ≠ 比特币）。
