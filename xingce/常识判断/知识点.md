# 常识判断 · 知识点精细化总纲

从主干继续下钻，进入 [逐点精讲](逐点精讲.md)：35个具体考点，覆盖法律条件与例外、经济传导、人文关系、科技机制和地理区位。每点配识别步骤、规则关系、例题解析及适用边界。

> 常识无法穷尽所有事实。本总纲覆盖当前目录的法律、经济、人文、科技、地理五条主干，并用“对象—规则—条件—例外—时点”组织知识。新法、年度政策、科技进展必须按 [更新清单](../../计划/法律与时政更新清单.md) 核验。  
> 各学科关系见 [知识图谱](知识图谱.md)，事实表和练习进入对应专题。

## 一、统一判断法

    一个选项
       ↓ 定学科
    法律 / 经济 / 人文 / 科技 / 地理
       ↓ 圈限定
    主体 + 对象 + 条件 + 时间 + 范围 + 程度
       ↓ 查规则
    一般规则 → 法定或科学例外
       ↓
    确定知识直接判断；不确定时用其余选项排除

### 1.1 六类常见偷换

| 偷换 | 例子 | 检查动作 |
| --- | --- | --- |
| 主体 | 全国人大职权写给国务院 | 先问谁有权作出 |
| 对象 | 民事主体关系写成行政管理关系 | 判断双方是否平等 |
| 条件 | 把“满足条件可以”改成“一律” | 圈出前提与例外 |
| 时间 | 新法施行前后规则混用 | 记录公布日和施行日 |
| 范围 | 局部地理特征扩大为全国 | 对照空间范围 |
| 因果 | 同时发生写成因果关系 | 补全原理链 |

## 二、法律常识

### 2.1 法律规范层级与制定主体

**核心关系：** 宪法具有最高法律效力；法律、行政法规、地方性法规和规章由不同主体依权限制定，下位规范不得与上位规范抵触。

**识别信号：** “制定、修改、解释、批准、备案、效力”。

**边界：** 名称相似不代表效力相同；“条例、办法”等名称须结合制定主体判断，不能只看标题。

**最小例证：** 某部门规章不得创设超越法律、行政法规授权范围的制度。

> 具体权限和时效规则见 [法律常识专题](法律常识专题.md)。

### 2.2 宪法与国家机构

| 节点 | 核心关系 | 易错边界 |
| --- | --- | --- |
| 人民代表大会制度 | 国家权力机关体系 | 人大不是行政机关 |
| 全国人大及其常委会 | 分别依法行使国家立法权等职权 | 二者职权不能完全互换 |
| 国务院 | 最高国家权力机关的执行机关、最高国家行政机关 | 不行使国家审判权或检察权 |
| 监察机关 | 依法行使监察权 | 与人民法院、检察院职能不同 |
| 人民法院 | 国家审判机关 | 负责审判，不负责批准逮捕 |
| 人民检察院 | 国家法律监督机关 | 依法行使检察权 |

**公民权利辨析：** 政治权利、人身自由、宗教信仰自由、社会经济文化权利等各有对象；权利行使不得损害国家、社会、集体利益和其他公民合法自由权利。

### 2.3 民事主体与行为能力

    自然人
    ├─ 民事权利能力：依法享有权利、承担义务的资格
    └─ 民事行为能力：能否独立实施有效民事法律行为
       ├─ 完全
       ├─ 限制
       └─ 无

**识别：** 年龄、认知能力、能否独立订立合同、法定代理人追认。

**边界：** 权利能力与行为能力不是一回事；有权利能力不等于能独立实施所有法律行为。

### 2.4 民事法律行为

**有效关系：** 行为人具有相应行为能力 + 意思表示真实 + 不违反法律、行政法规的强制性规定，不违背公序良俗。

| 状态 | 核心含义 | 题目检查 |
| --- | --- | --- |
| 有效 | 成立并产生预期法律效果 | 三项有效条件 |
| 无效 | 自始不发生预期法律效果 | 强制规定、公序良俗等 |
| 可撤销 | 当事人可依法请求撤销 | 重大误解、欺诈、胁迫等具体条件 |
| 效力待定 | 是否有效取决于追认等后续行为 | 主体权限或代理问题 |

**边界：** “合同成立”不等于“合同一定有效”；撤销前的状态也不能简单等同于当然无效。

### 2.5 合同、侵权与责任

    民事责任
    ├─ 违约责任：违反合同义务
    └─ 侵权责任：侵害他人民事权益

**辨析：** 同一行为可能同时涉及违约和侵权，题目要看双方是否存在合同关系、请求保护的权益以及具体责任规则。

**最小例证：** 运输合同中承运人违约造成货物损坏，既有合同履行问题，也可能涉及财产权益侵害；作答须按题目所问区分。

### 2.6 犯罪构成与刑事责任

    犯罪判断
       ↓
    主体 + 主观方面 + 客体 + 客观方面
       ↓ 排除
    正当防卫 / 紧急避险等违法阻却事由
       ↓
    是否承担刑事责任及承担方式

**年龄节点：** 已满十六周岁原则上对犯罪承担刑事责任；较低年龄段仅在法律规定的特定犯罪、结果、情节和程序条件下追责。精确罪名范围和程序条件必须查现行条文。

**边界：** 年龄条件、行为时年龄和审判时年龄不能混淆；“承担刑事责任”不等于一律适用同样刑罚。

### 2.7 故意、过失与意外事件

| 类型 | 对结果的认识和态度 | 判断抓手 |
| --- | --- | --- |
| 直接故意 | 明知会发生并希望发生 | 希望结果 |
| 间接故意 | 明知可能发生并放任发生 | 放任结果 |
| 过于自信的过失 | 已预见但轻信能够避免 | 预见 + 轻信 |
| 疏忽大意的过失 | 应当预见而未预见 | 应见未见 |
| 意外事件 | 不能预见或无法避免 | 缺少法律要求的可预见性 |

### 2.8 正当防卫与紧急避险

| 比较 | 正当防卫 | 紧急避险 |
| --- | --- | --- |
| 针对 | 正在进行的不法侵害 | 正在发生的危险 |
| 损害对象 | 不法侵害人 | 第三方较小合法权益也可能受损 |
| 核心条件 | 防卫时机、目的、对象、限度 | 不得已、保护利益大于损害利益、限度 |

**边界：** 事前防卫、事后报复不属于针对正在进行侵害的防卫；具体是否过当须结合侵害性质、手段、强度和现场条件。

### 2.9 行政行为与救济

| 行为 | 本质 | 高频边界 |
| --- | --- | --- |
| 行政许可 | 依法准予从事特定活动 | 与资格确认、备案区分 |
| 行政处罚 | 对行政违法行为实施制裁 | 与刑罚、行政强制区分 |
| 行政强制措施 | 暂时限制权利或控制财物 | 与最终处罚不同 |
| 行政强制执行 | 促使义务履行或达到同等状态 | 注意实施主体和程序 |
| 行政征收征用 | 基于公共利益依法取得财产或使用权 | 条件、程序、补偿不能漏 |

    不服行政行为
       ├─ 行政复议
       └─ 行政诉讼

**边界：** 复议和诉讼的受案范围、前置条件、期限会受现行法律影响，具体数字必须查最新规定。

## 三、经济常识

### 3.1 GDP及相关指标

**GDP：** 一定时期内一国（或地区）境内生产的最终产品和服务的市场价值。

| 易混 | 区别 |
| --- | --- |
| 境内 vs 国民 | GDP重生产地域，不直接按生产者国籍 |
| 最终产品 vs 中间产品 | 避免重复计算 |
| 名义 vs 实际 | 是否剔除价格变动影响 |
| 总量 vs 人均 | 经济规模不等于居民平均水平 |

### 3.2 CPI、PPI与通胀

    CPI → 居民消费端价格变化
    PPI → 工业生产者出厂价格变化
    通货膨胀 → 总体价格水平持续上涨、货币购买力下降

**边界：** 单个商品涨价不等于整体通胀；CPI下降不一定等于物价绝对下降，也可能只是涨幅回落。

### 3.3 供给与需求

在其他条件不变时：

| 变化 | 均衡价格 | 均衡数量 |
| --- | --- | --- |
| 需求增加 | 上升 | 上升 |
| 需求减少 | 下降 | 下降 |
| 供给增加 | 下降 | 上升 |
| 供给减少 | 上升 | 下降 |

**边界：** 上表要求“其他条件不变”。若供给、需求同时变化，价格和数量方向要结合两者幅度判断。

### 3.4 财政政策与货币政策

| 比较 | 财政政策 | 货币政策 |
| --- | --- | --- |
| 主要实施主体 | 政府财政部门等 | 中央银行 |
| 工具 | 税收、支出、国债、转移支付 | 利率、准备金、公开市场操作等 |
| 扩张方向 | 增支、减税等 | 增加流动性、降低融资成本等 |
| 紧缩方向 | 减支、增税等 | 减少流动性、提高融资约束等 |

**边界：** 具体政策效果会受预期、传导机制和经济环境影响，不能把工具方向机械等同于最终结果。

### 3.5 利率、汇率与金融

- 利率是资金价格；在其他条件相近时，利率变化会影响储蓄、投资和融资成本；
- 汇率表示两种货币兑换关系，必须先看采用哪一种标价法，不能见“数字上升”就断定本币升值；
- 股票代表所有权凭证，债券主要体现债权债务关系；基金通过集合资金进行投资，风险收益取决于资产和管理方式；
- 风险与收益通常相关，但高风险不保证高收益。

> 详细辨析见 [经济常识专题](经济常识专题.md)。

## 四、人文常识

### 4.1 历史时间线

    朝代
       ↓ 对应
    人物 + 事件 + 制度 + 科技文化成果
       ↓ 再判断
    先后顺序与因果关系

**学习单位：** 不孤立背人名，把“时代—身份—事件—影响”绑定。

**高频边界：**

- 同名制度在不同时代内容可能不同；
- 事件发生时间与史书记载或作品成书时间不一定相同；
- 发明、改进、传播和广泛使用不是同一时点。

### 4.2 文学关系链

    时代 → 文体 → 作者 → 作品 → 名句/人物 → 风格

| 易错 | 检查 |
| --- | --- |
| 作者作品错配 | 是否同一时代、同一文体 |
| 人物作品错配 | 人物出自哪部作品 |
| 文体错配 | 诗、词、曲、赋、小说的时代特征 |
| 别称错配 | 字、号、谥号、籍贯不可混用 |

### 4.3 传统文化

| 节点 | 关系 |
| --- | --- |
| 节气 | 太阳周年运动与农业时令，不等同传统节日 |
| 干支纪年 | 天干十、地支十二组合形成六十循环 |
| 年龄称谓 | 与人生阶段对应，注意男女和语境差异 |
| 古代礼仪 | 对象、场合、身份决定称谓和礼节 |
| 书画戏曲 | 流派、代表人物、作品和艺术特征绑定 |

> 时间线和作品表见 [人文常识专题](人文常识专题.md)。

## 五、科技常识

### 5.1 物理：现象—原理—条件

| 现象 | 原理 | 易错边界 |
| --- | --- | --- |
| 惯性 | 物体保持原运动状态的性质 | 惯性不是力 |
| 摩擦 | 接触面相对运动或趋势产生阻碍 | 摩擦并非总是有害 |
| 压强 | 单位面积所受压力 | 压力大不必然压强大 |
| 浮力 | 流体对物体向上的作用 | 漂浮时浮力与重力平衡，不等于排液体积相同 |
| 光反射/折射 | 光在界面传播方向变化 | 镜像与折射成像不能混用 |
| 物态变化 | 熔化、汽化吸热；凝固、液化放热 | “白气”通常是小液滴，不是水蒸气本身 |

### 5.2 化学：变化、性质与安全

- 物理变化通常没有生成新物质；化学变化有新物质生成；
- 燃烧通常需要可燃物、助燃条件和达到着火条件，灭火可分别切断条件；
- 酸碱性、pH和指示剂变化有对应关系，但生活物质不能仅凭名称判断；
- 金属活动性、氧化还原、腐蚀防护要看反应条件，不能只背现象。

### 5.3 生物与健康

    细胞 → 组织 → 器官 → 系统 → 个体
    DNA → 基因 → 遗传信息表达 → 性状
    病原体进入 → 免疫反应 → 形成保护或疾病过程

**边界：**

- 抗生素主要针对细菌感染，不能笼统用于所有病毒性疾病；
- 疫苗通过训练免疫系统形成针对性保护，不等于接种后绝对不会感染；
- 遗传因素影响性状，不代表环境不起作用。

### 5.4 天文与航天

| 关系 | 结论 |
| --- | --- |
| 地球自转 | 昼夜更替、地方时差异 |
| 地球公转 + 地轴倾斜 | 四季、昼夜长短变化 |
| 月球绕地球运动及相对位置 | 月相变化 |
| 日地月特定位置 | 日食、月食等现象 |

**边界：** 昼夜更替不是地球公转造成；四季也不能简单解释为地球离太阳远近变化。

### 5.5 信息技术

    数据 → 算法 → 算力 → 模型/系统 → 应用
                                      ↓
                              隐私、安全、偏差、伦理

**边界：** 算法输出依赖数据与目标，相关预测不等于因果解释；自动化程度提高不意味着可以取消责任主体和人工监督。

> 现象例题见 [科技常识专题](科技常识专题.md)。

## 六、地理常识

### 6.1 地球运动

| 运动 | 周期性结果 | 易错 |
| --- | --- | --- |
| 自转 | 昼夜更替、地方时、地转偏向等 | 不直接产生四季 |
| 公转 + 地轴倾斜 | 正午太阳高度、昼夜长短、四季变化 | 不是单由日地距离决定 |

### 6.2 气候形成

    纬度位置
       + 海陆位置
       + 大气环流
       + 地形
       + 洋流
       ↓
    气温和降水特征

**边界：** 单一因素通常不能完整解释气候；迎风坡与背风坡还要结合气流方向和水汽条件。

### 6.3 地形与河流

- 地势决定河流总体流向，但局部还受地形构造影响；
- 河流水能取决于落差和水量，落差大不等于一定适合开发；
- 河流上中下游在侵蚀、搬运、沉积和利用方式上有差异；
- 洪涝形成与降水、地形、水系、城市下垫面和工程管理共同相关。

### 6.4 中国地理

    地势西高东低、三级阶梯
       ├─ 影响多数大河总体向东流
       ├─ 阶梯交界处落差较大
       └─ 影响交通、人口和城市布局

    秦岭—淮河附近
       ├─ 南北方重要地理分界
       ├─ 气温、降水、水文、农业指标发生变化
       └─ 多条界线大致接近但不完全重合

### 6.5 农业、人口与交通

| 对象 | 主要影响因素 |
| --- | --- |
| 农业 | 光热、水分、地形、土壤、市场、技术 |
| 人口 | 自然条件、经济机会、公共服务、交通 |
| 城市 | 区位、产业、资源、交通、政策 |
| 交通线 | 地形、人口城市、经济联系、建设成本 |

> 分界线和世界地理见 [地理常识专题](地理常识专题.md)。

## 七、综合例题

### 例题1：法律主体

选项称“国务院行使国家审判权”。错误。国务院是最高国家行政机关，国家审判权由人民法院依法行使。错误类型是主体错配。

### 例题2：民事能力

“自然人具有民事权利能力，因此均可独立订立任何合同”错误。权利能力与行为能力不同，独立实施行为还要看相应行为能力和具体行为。

### 例题3：供求

某产品原材料成本下降使供给增加，在需求不变时，均衡价格倾向下降、均衡数量倾向上升。若同期需求也大增，则价格方向还需比较两种变化幅度。

### 例题4：科技因果

“冬天呼出的白气是气态水蒸气”错误。水蒸气不可见，白气是水蒸气遇冷液化形成的小液滴。

### 例题5：地理因素

“某地处于同一纬度，所以气候一定相同”错误。海陆位置、地形、大气环流和洋流等也会改变气候。

## 八、自测

1. 如何区分民事权利能力与民事行为能力？
2. 正当防卫和紧急避险的损害对象有何不同？
3. CPI涨幅回落是否等于价格总水平一定下降？
4. 为什么“样本中某商品涨价”不能直接推出通货膨胀？
5. 四季变化主要由地球什么运动关系产生？
6. 为什么同纬度地区气候仍可能明显不同？
7. “白气”属于气态水蒸气还是小液滴？
8. 判断某法律规则时为什么要记录施行日期？

### 答案要点

1. 前者是享有权利、承担义务的资格，后者是独立实施有效民事法律行为的能力。
2. 防卫针对不法侵害人；避险可能为保护更大利益而损害第三方较小合法权益。
3. 不等于；可能只是价格仍上涨但涨得更慢。
4. 通胀考查总体价格水平持续变化，单一商品不能代表总体。
5. 地球公转与地轴倾斜共同作用。
6. 海陆位置、环流、地形、洋流等因素不同。
7. 小液滴。
8. 公布、施行及修法时点决定某时段适用哪一规则。

## 九、错题归因

| 错因 | 典型表现 | 修正 |
| --- | --- | --- |
| 学科定位错 | 用民法规则判断行政行为 | 先判断主体关系是否平等 |
| 主体错 | 把机关职权互换 | 建“机关—性质—核心职权”卡 |
| 条件漏 | 记住一般规则，忘记例外 | 每条规则同步记适用条件 |
| 时效错 | 用旧法旧政策答新题 | 标来源和核验日期 |
| 对应错 | 作者作品、现象原理错配 | 用三点绑定法复习 |
| 因果错 | 只看到同时发生 | 补全中间机制和限制条件 |
