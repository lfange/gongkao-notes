# 全国人大与全国人大常委会

全国人民代表大会（全国人大）是我国最高国家权力机关。全国人民代表大会常务委员会（全国人大常委会）是全国人大的常设机关，由全国人大选举产生，对全国人大负责并报告工作。两者都行使国家立法权。做题时，先看主体，再看动词和条件。例如，同样涉及宪法，“提议修改”“通过修改”“解释”“监督实施”各有分工。

## 一、组成与运行

| 比较项 | 全国人大 | 全国人大常委会 |
| --- | --- | --- |
| 由谁组成 | 由省、自治区、直辖市、特别行政区和军队选出的代表组成，各少数民族都应当有适当名额的代表 | 由委员长、副委员长若干人、秘书长、委员若干人组成，组成人员中应当有适当名额的少数民族代表 |
| 任期 | 每届五年 | 每届任期同全国人大，行使职权到下届全国人大选出新的常委会为止。委员长、副委员长连续任职不得超过两届 |
| 会议由谁主持 | 常委会召集大会，会议期间由大会选举的主席团主持 | 委员长召集并主持常委会会议。委员长、副委员长、秘书长组成委员长会议，处理常委会的重要日常工作 |
| 如何运作 | 大会每年举行一次。常委会认为必要，或者有五分之一以上全国人大代表提议，可以临时召集大会 | 常委会持续履职。召集全国人大会议、解释法律等是其法定职权，只有部分职权以全国人大闭会为条件 |

常委会组成人员不得担任国家行政机关、监察机关、审判机关和检察机关的职务。题干如果把这项限制扩大到全体全国人大代表，就改变了适用对象。依据为《宪法》第五十七至六十一条、第六十五至六十九条。[宪法全文](https://www.cac.gov.cn/2018-03/22/c_1122572643.htm)

## 二、职权对照

| 事项 | 全国人大 | 全国人大常委会 |
| --- | --- | --- |
| 宪法 | 修改宪法，监督宪法实施 | 可以提议修改宪法，解释宪法，监督宪法实施 |
| 法律 | 制定和修改刑事、民事、国家机构的和其他基本法律 | 制定和修改应由全国人大制定的法律以外的其他法律，解释法律。大会闭会期间可对大会制定的法律作部分补充和修改，但不得与该法律的基本原则相抵触 |
| 计划与预算 | 审查和批准国民经济和社会发展计划、国家预算及其执行情况的报告 | 大会闭会期间，审查和批准计划、国家预算在执行中所必须作的部分调整方案 |
| 人事 | 选举国家主席、副主席、中央军委主席、国家监委主任、最高人民法院院长、最高人民检察院检察长等。根据国家主席提名决定国务院总理人选，并有权依法罢免有关人员 | 大会闭会期间，根据总理提名决定部长、委员会主任、审计长、秘书长的人选，根据中央军委主席提名决定中央军委其他组成人员的人选。依法任免国家监委副主任、委员等 |
| 监督与纠错 | 监督宪法实施，有权改变或者撤销常委会不适当的决定 | 监督国务院、中央军委、国家监委、最高法、最高检的工作。有权撤销国务院制定的同宪法、法律相抵触的行政法规、决定和命令 |
| 重大事项 | 批准省、自治区和直辖市的建置，决定特别行政区的设立及其制度，决定战争和和平的问题 | 决定特赦、全国总动员或者局部动员等。大会闭会期间，如遇国家遭受武装侵犯或者必须履行国际间共同防止侵略的条约的情况，决定战争状态的宣布 |

**表决门槛**尤其容易和提议门槛混淆。修宪可由全国人大常委会或者五分之一以上全国人大代表提议，须由全国人大全体代表的三分之二以上通过。全国人大通过法律和其他议案，由全体代表过半数通过。两处的分母都是全体代表。以上对照选取常考事项，完整列举见《宪法》第六十二至六十四条、第六十七条。[宪法全文](https://www.sara.gov.cn/static/content/xxgk/flfg/2018-03-22/1306305917016342528.html)

## 三、机关职权与代表个人权利

- **人民代表大会制度**是我国的根本政治制度。全国人大是这一制度下的国家机关。地方各级人大是地方国家权力机关，其中县级以上地方各级人大设立常委会。
- **人大代表**是国家权力机关的组成人员。代表可以审议议案和报告、参加表决、依照法定程序提出议案和质询案，也可以提出建议、批评和意见。代表负有联系群众、听取和反映群众意见和要求的职责，并受原选举单位监督。看到“某代表投赞成票”，对应的是代表的表决权。看到“大会通过法律”，对应的是国家机关行使立法权。
- **全国人大专门委员会**按领域研究、审议和拟订有关议案，全国人大闭会期间受常委会领导。例如，宪法和法律委员会参与审议法律草案，法律的通过仍须由有权机关表决。
- **国务院**是最高国家行政机关。以总理任命为例，国家主席提名、全国人大决定人选、国家主席依决定任命。题目只换一个动词，答案就会变化。
- **全国政协**是中国人民政治协商会议全国委员会的简称，履行政治协商、民主监督、参政议政职能。“两会”期间，政协委员可以通过提案建言，全国人大代表在大会上审议、表决议案。

代表的议案权、质询权及履职保障可回看《宪法》第七十二至七十七条，国家主席的任免、公布职权见第八十条，地方人大常委会的设置见第九十六条。[宪法全文](https://www.cac.gov.cn/2018-03/22/c_1122572643.htm)

## 四、用情境检验分工

1. **全国人大闭会期间，能否由常委会修改全国人大制定的某部基本法律？** 可以作部分补充和修改，且须保留该法的基本原则。判断时要同时核对时间、修改范围和原则限制。
2. **国务院提出下一年度国家预算草案，和预算执行中确需部分调整，分别由谁审查批准？** 年度国家预算由全国人大审查批准。大会闭会期间，执行中所必须作的部分调整方案由常委会审查批准。
3. **常委会提出修宪议案，全国人大到会代表中有三分之二赞成，能否据此认定通过？** 还需核对赞成票占全体代表的比例。假设全体代表共 3000 人，到会 2700 人，1800 票赞成虽达到到会人数的三分之二，仍低于修宪所需的 2000 票。
4. **某法律经全国人大常委会表决通过，由国家主席签署主席令公布。谁行使了立法权？** 该案中行使国家立法权的是全国人大常委会，国家主席根据常委会的决定公布法律。
