# 常识判断 · 经济常识专题（宏观指标 / 财政货币 / 概念辨析 / 热词）

> 经济常识考点两极分化：一半是**稳定的基础概念**（GDP、CPI、财政货币政策），一半是**当年的政策热词**（新质生产力、双循环）。
> 基础概念靠辨析表一次记牢，热词配合时政积累。**经济题爱考"数字指标是谁的、政策的方向是谁定的"**。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../../错题本.md)。

---

## 一、宏观指标（必考，辨析是核心）

| 指标 | 定义 | 考点提示 |
| --- | --- | --- |
| **GDP** | 一个国家（或地区）**境内**、一定时期内生产的**最终**产品和服务总值 | 关键词：境内、最终产品（中间产品不算） |
| **GNP / GNI** | 本国**国民**拥有的生产要素生产的总值 | GDP 按国土算，GNP 按国民算；外资在华企业产值计入 GDP 不计入 GNP |
| **CPI** | 居民消费**价格**指数 | 衡量通货膨胀的核心指标；CPI > 3% 通常视为通胀预警，负增长为通缩 |
| **PPI** | 工业**生产者**出厂价格指数 | 上游价格，PPI 持续上涨会向 CPI 传导 |
| **恩格尔系数** | 食品支出 ÷ 总消费支出 | **越低越富裕**（吃占总消费比例随富裕下降） |
| **基尼系数** | 收入分配差异程度 | 0—1 之间，**越大越不平等**；0.4 为警戒线 |
| **失业率** | 失业人口 ÷ 劳动力总数 | 我国城镇调查失业率；摩擦性 / 结构性 / 周期性失业是常考分类 |
| **赤字率** | 财政赤字 ÷ GDP | 国际通行 3% 为参考线（不是死规矩） |
| **汇率** | 两种货币的兑换比率 | **直接标价法**（本币兑外币，如 1 美元 = 7.1 元人民币）是我国的标价方式；人民币升值利好进口、出境游，不利出口 |

> 高频陷阱：**"GDP 是国民的"（×，是境内的）"恩格尔系数越高越富"（×，越低越富）"基尼系数越低效率越高"（×，衡量的是公平不是效率）**。

## 二、财政政策 vs 货币政策（方向题的命门）

| | 财政政策（政府花） | 货币政策（央行调） |
| --- | --- | --- |
| **执行者** | 政府 / 财政部 | **中国人民银行**（央行） |
| **工具** | 税收、国债、财政支出、补贴、转移支付 | 存款准备金率、再贴现率、**公开市场操作**、利率（LPR） |
| **扩张（刺激经济）** | 减税、增支出（增发国债） | 降准、降息、买进债券 |
| **紧缩（给经济降温）** | 增税、减支出 | 加准、加息、卖出债券 |

> 记忆抓手：**央行不能财政（不列赤字、不给财政透支），财政不能发货币**——谁出手就分清了是哪类政策。
> "降低存款准备金率"= 商业行可贷资金变多 = 扩张性货币政策。

## 三、基础概念辨析（高频"对照式"考法）

| 组 | 区别 |
| --- | --- |
| **通货膨胀 / 通货紧缩** | 物价持续上涨 / 下跌；通缩同样危险（消费萎缩、债务实际加重） |
| **拉动经济的三驾马车** | **消费、投资、出口**（净出口） |
| **机会成本** | 为得到某物而**放弃的其他选项中价值最高者**（不是所有放弃项之和） |
| **沉没成本** | 已发生、不因后续决策改变的支出——理性决策**不应**考虑 |
| **边际效用递减** | 消费量增加，每新增一单位带来的满足感递减 |
| **供需规律** | 供大于求价格下跌，供不应求价格上涨；"看不见的手"（亚当·斯密） |
| **外部性** | 经济活动对第三方的影响：污染是**负外部性**，教育有正外部性 |
| **公共物品** | **非竞争性 + 非排他性**（国防、路灯）；私人物品两者皆反 |
| **市场失灵** | 垄断、外部性、公共物品缺失、信息不对称——政府干预的理论依据 |
| **实体经济 / 虚拟经济** | 制造、服务等实体制 vs 金融、投机炒作 |
| **存量 / 流量** | 某时点的量（人口、资本存量）vs 一段时间的量（GDP、收入） |

## 四、金融常识

- **中央银行**（中国人民银行）：发行货币、制定执行货币政策、维护金融稳定——**不以营利为目的、不办理个人业务**；
- **商业银行**（工行等）：吸收存款、发放贷款，以营利为目的；
- **存款保险**：同一存款人在同一家银行 50 万元以内**全额偿付**；
- **LPR**（贷款市场报价利率）：贷款利率定价基准；
- **股票 vs 债券**：股票是所有权凭证（风险共担、收益不定），债券是债权凭证（还本付息优先于股票）；
- **市盈率** = 股价 ÷ 每股收益。

## 五、政策热词族谱（配合时政持续更新）

| 热词 | 一句话理解 |
| --- | --- |
| **新质生产力** | 由技术革命性突破催生的先进生产力质态——以科技创新为主导，摆脱传统增长路径（战略性新兴产业 + 未来产业） |
| **高质量发展** | 从"有没有"转向"好不好"，全要素生产率提升为核心 |
| **双循环** | 以国内大循环为主体、国内国际双循环相互促进 |
| **供给侧结构性改革** | 从生产端优化供给（去产能、去库存、去杠杆、降成本、补短板） |
| **共同富裕** | 不是同步富裕、不是平均主义；做大蛋糕 + 分好蛋糕 |
| **专精特新** | 专业化、精细化、特色化、新颖化的中小企业 |
| **碳达峰 / 碳中和** | 2030 前 CO₂ 排放达峰 / 2060 前实现"净零"（排放=吸收）——"双碳"目标 |
| **全国统一大市场** | 打破地方保护和市场分割，要素自由流动 |
| **宏观政策取向一致性** | 财政、货币、产业、监管等政策协同发力、不打架 |

> 热词考法：**"下列关于 XX 的说法正确的是"**——设错手法常为偷换主体（把"主导"换成"辅助"）、偷换时间（2035 变 2030）、偷换范围（"同步富裕"）。记热词要连"时间 + 主导力量 + 目标"一起记。

## 六、易错点清单

1. **GDP 是境内不是国民**（国民口径是 GNP/GNI）。
2. **恩格尔系数越低越富**，基尼系数越大越不平等——方向别反。
3. **降准 / 降息是货币政策**（央行）；减税 / 发债是财政政策（政府）。
4. **央行不吸收个人存款、不以营利为目的**。
5. **机会成本是放弃选项中的最高值**，不是全部加总。
6. **公共物品双重属性**（非竞争 + 非排他）只满足一半的是"准公共物品"（教育、医疗）。
7. **双碳时间**：2030 碳达峰、2060 碳中和——记反必错。
8. **汇率升值的利好方向**：人民币升值 → 进口便宜、出境游便宜、出口变贵——考"对我国出口企业的影响"答案是竞争力下降。

## 七、速记卡（考前 5 分钟过一遍）

> GDP 境内最终产，国民口径看 GNI；恩格尔低是富裕，基尼越大越不均。
> 央行降准又降息，货币扩张暖经济；财政减税多发债，投资消费拉起来。
> 三驾马车消投出，机会成本舍最高；公共物品两非性，存款保险五十万。
> 新质生产力看创新，双循环内为主；30 达峰 60 中和，供给侧改补短板。

## 八、自测练习

1. GDP 与 GNP 的核心区别是什么？
2. 下列哪项属于货币政策工具？（A. 增发国债　B. 提高存款准备金率　C. 减税　D. 增加转移支付）
3. 恩格尔系数不断下降说明什么？
4. 我国"双碳"目标分别是什么时间节点？
5. 机会成本的准确含义是什么？

### 答案附录

1. GDP 按**国土（境内）**口径（含外资在华产值），GNP 按**国民**口径（含本国国民海外产值，不含外资境内产值）。
2. **B**（存款准备金率是央行货币政策三大传统工具之一；A、C、D 都是财政政策工具）。
3. 食品支出占总消费的比重下降，说明**生活水平提高**（越富裕恩格尔系数越低）。
4. **2030 年前碳达峰，2060 年前碳中和**。
5. 做出某选择时，**放弃的诸选项中价值最高的那一个**的价值（不是所有放弃项之和）。

## 错题归因模板

做错时按三类归因，记入 [错题本.md](../../错题本.md)：

- **口径错**：GDP/GNP、恩格尔/基尼方向、存量/流量混淆；
- **主体错**：财政与货币政策的执行者、工具张冠李戴；
- **热词错**：新热词的时间、主导力量、目标三元组记错 → 补入热词族谱表。
