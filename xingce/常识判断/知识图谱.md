## 二、法律知识图谱

    法律规范体系
       ↓ 先判断效力与制定主体
    宪法
       ├─ 国家根本法
       ├─ 公民基本权利和义务
       └─ 国家机构
    部门法
       ├─ 民法 → 平等主体的人身与财产关系
       ├─ 刑法 → 犯罪、刑事责任与刑罚
       └─ 行政法 → 行政主体、行政行为与救济

### 2.1 民法节点

    自然人
    ├─ 权利能力 → 出生至死亡
    ├─ 行为能力
    │  ├─ 完全民事行为能力
    │  ├─ 限制民事行为能力
    │  └─ 无民事行为能力
    ├─ 民事法律行为
    │  ├─ 主体适格
    │  ├─ 意思表示真实
    │  └─ 不违反强制规定和公序良俗
    └─ 民事责任
       ├─ 违约责任
       └─ 侵权责任

### 2.2 刑法节点

    犯罪判断
       ↓
    主体 + 主观方面 + 客体 + 客观方面
       ↓ 再排查
    正当防卫 / 紧急避险等阻却事由
       ↓
    刑事责任与刑罚

**年龄节点：** 已满十六周岁原则上负刑事责任；十四至十六周岁适用法定严重犯罪范围；十二至十四周岁特殊追责还须满足严重结果、恶劣情节和核准追诉条件。

### 2.3 行政法节点

    行政行为
    ├─ 行政许可 → 准予从事特定活动
    ├─ 行政处罚 → 对违法行为实施制裁
    ├─ 行政强制 → 强制措施 / 强制执行
    └─ 行政征收征用 → 基于公共利益依法进行
       ↓ 不服
    行政复议 / 行政诉讼

> 法律内容易受修法影响，完整条文与更新节点见 [法律常识专题](法律常识专题.md)。

## 三、经济知识图谱

    宏观经济运行
    ├─ 产出 → GDP及其增速
    ├─ 价格 → CPI / PPI / 通胀 / 通缩
    ├─ 就业 → 就业与失业
    ├─ 国际收支 → 进出口 / 汇率
    └─ 宏观调控
       ├─ 财政政策
       │  └─ 税收 / 支出 / 国债 / 转移支付
       └─ 货币政策
          └─ 利率 / 准备金 / 公开市场操作

### 3.1 供求节点

    其他条件不变
    需求增加 ⇒ 均衡价格上升、均衡数量上升
    需求减少 ⇒ 均衡价格下降、均衡数量下降
    供给增加 ⇒ 均衡价格下降、均衡数量上升
    供给减少 ⇒ 均衡价格上升、均衡数量下降

### 3.2 政策方向节点

    总需求不足
       ├─ 扩张性财政 → 增支 / 减税
       └─ 扩张性货币 → 增加流动性 / 降低融资成本

    需求过热、通胀压力
       ├─ 紧缩性财政 → 减支 / 增税
       └─ 紧缩性货币 → 减少流动性 / 提高融资约束

> 基础概念和辨析题见 [经济常识专题](经济常识专题.md)。

## 四、人文知识图谱

    人文常识
    ├─ 时间线
    │  └─ 朝代 → 人物 → 事件 → 制度
    ├─ 文学线
    │  └─ 时代 → 文体 → 作者 → 作品
    └─ 文化线
       └─ 节日 / 节气 / 称谓 / 礼仪 / 艺术

**三点绑定法：**

    人物
       ├─ 所处时代
       ├─ 代表作品或事件
       └─ 历史地位

**高频陷阱：** 人物时代错置、作者作品错配、典故对象错配、农历和公历混用、相邻朝代事件对调。

> 完整时间线与对应表见 [人文常识专题](人文常识专题.md)。

## 五、科技知识图谱

    科学现象
       ↓ 对应
    原理
       ↓ 受到
    条件限制
       ↓ 产生
    结果与应用

| 学科 | 核心关系链 |
| --- | --- |
| 物理 | 力—运动；温度—物态变化；光—反射/折射；电—能量转换 |
| 化学 | 物质性质—反应条件—生成物；酸碱—pH—应用 |
| 生物 | 细胞—组织—器官—系统；DNA—基因—遗传；免疫—疫苗 |
| 天文 | 自转—昼夜；公转与地轴倾斜—四季；天体位置—观测现象 |
| 信息技术 | 数据—算法—算力—应用—安全与伦理 |

**选项检查：** 是否把物理变化写成化学变化、把必要条件写成唯一条件、把相关关系写成因果关系、把适用范围无限扩大。

> 原理与现象例题见 [科技常识专题](科技常识专题.md)。

## 六、地理知识图谱

    地理位置
       ↓ 影响
    地形 + 气候 + 水文 + 资源
       ↓ 共同塑造
    人口、农业、城市与交通布局

### 6.1 自然现象关系

    地球自转 → 昼夜更替 / 地方时差异
    地球公转 + 地轴倾斜 → 四季 / 昼夜长短变化
    地形抬升 → 迎风坡降水 / 背风坡雨影
    高差 + 水量 → 河流水能条件
    纬度 + 海陆位置 + 地形 → 气候特征

### 6.2 中国地理主线

    西高东低、三级阶梯
       ├─ 影响河流流向
       ├─ 阶梯交界处水能较丰富
       └─ 影响交通与人口分布

    秦岭—淮河
       ├─ 南北方重要分界
       ├─ 气候、水文、农业指标附近变化
       └─ 各条具体界线并非完全重合

> 完整分界线、河流和世界地理节点见 [地理常识专题](地理常识专题.md)。
