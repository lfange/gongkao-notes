# 判断推理 · 图形推理智库（规律大全 + 例题精讲）

> 配套 [笔记.md](笔记.md) 与 [../攻略.md](../攻略.md#二判断推理--)。
> 图推 10 题，每题 ≤50 秒。它是最"纯"的规律题：**所有考点加起来不到 30 条规律**，本质是"特征 -> 规律"的条件反射库。
> 本文结构：破题总纲 -> 六大类规律（触发特征 + 规则全表 + 例题精讲）-> 压缩秒杀表 -> 自测练习（答案见附录）。

## 一、破题总纲：三步定位法

拿到一组图，按固定顺序问三个问题，90% 的题在第二步内锁定方向：

| 步骤 | 看什么 | 指向 |
|---|---|---|
| ① 元素是否**完全相同**（同种图形只是位置变了） | 黑块在动、图形在转 | **位置类**：平移 / 旋转 / 翻转 |
| ② 元素**部分相同**（行内图形长得像，线条有重叠） | 两个图叠加出第三个 | **样式类**：遍历 / 加减同异 |
| ③ 元素**完全不同**（每张图都不一样） | 数数、看属性 | **数量类**或**属性类**：点线面素角 / 对称曲直开闭 |

补充两条：
- 题干出现**汉字、字母、数字** -> 当图形看，优先数笔画、封闭面、部分数，其次求同。
- **立体图**（折叠、剖切、三视图）-> 直接走空间类，不进三步法。

> 国考近年趋势：一道题**叠两个规律**（如"对称轴方向 + 面数量"）。单规律做不出来时，回到你第一步排除掉的那个方向做二级验证。

## 二、位置类

### 触发特征

**每张图元素种类、数量完全相同，只有相对位置在变。**

### 规律全表

| 规律 | 常见考法 | 细节陷阱 |
|---|---|---|
| 平移 | 元素沿九宫格边/对角线走，恒定步长或递增步长；两个元素反向走；转圈走（走到底反弹或穿越） | 步长 1、2、3 递增；顺时针/逆时针方向；"九宫格外圈循环" |
| 旋转 | 整体绕中心转 45°/90°/180°；长短针各转各的 | 角度递增（30°、45°、60°）；旋转+翻转复合 |
| 翻转 | 沿竖轴/横轴翻（左右镜像/上下镜像） | **翻转与旋转的区分**：翻转改变"手性"（图形上某个不对称标记的相对方向变了） |

### 深度讲解

1. **平移先定"轨道"**：把一张图按 3×3 或行列看，追踪**一个**元素（通常是最显眼的黑块/箭头）的轨迹，其他元素往往同步。
2. **旋转看"参照物"**：盯着图中一个不对称的局部（如箭头的尖端、缺口），它转到哪整体就转到哪。
3. **翻转判定口诀**：旋转永远不改变图形的"旋转方向"（顺时针排布的元素旋转后仍顺时针）；**一次翻转改变手性，两次翻转=没翻**。选项中"看着像"的往往是旋转，"镜像感"的才是翻转。

### 例题精讲 1（平移，步长递增）

**题干**：九宫格（3×3）每格有一个小黑块。第 1 行黑块在最左，第 2 行黑块左移 1 格，第 3 行黑块左移 2 格（从上一行位置算）。问第 4 行黑块位置？

**解析**：
1. 元素完全相同（都是 1 黑块）-> 位置类平移。
2. 步长 0、1、2 -> 等差递增 -> 下一步移 3 格；3 格 = 一整行周期 -> **回到最左**。
3. 陷阱：步长看成一个"每行恒左移 1 格"会答错一列；**先写数列 0、1、2 再推**，不凭感觉。

### 例题精讲 2（旋转+翻转复合）

**题干**：一个"L 形"图形依次变化：图 1 到图 2 逆时针旋转 90°；图 2 到图 3 左右翻转；图 3 到图 4 又逆时针旋转 90°。问图 5 与图 1 的关系？

**解析**：把每次操作真的在草稿上执行（图推不靠想象力，靠执行）：
图 4 = 图 3 旋转后。图 5 应再翻转一次。逐步画出来，答案与"仅由图 1 旋转得到"的干扰项区分点在**手性**--两次翻转+旋转的复合仍改变手性（翻转奇数次即改变）。
**深度**：把"翻转"记为负号--翻转次数为奇，图形与原图镜像；为偶则等价于纯旋转。

## 三、样式类

### 触发特征

**行内（或列内）图形相似，线条有重叠、有增减。**

### 规律全表

| 规律 | 含义 | 常见形式 |
|---|---|---|
| 遍历 | 所有元素在一行/一列中**各出现一次** | 缺哪个补哪个（"缺啥补啥"） |
| 加 | 两图叠加，线条全保留 | 少见 |
| 减（求异） | 两图相加，**相同部分去掉** | "去同存异" |
| 求同 | 两图相加，**只留相同部分** | "去异存同" |
| 黑白运算 | 黑+黑=?、白+白=?、黑+白=?（自定义映射） | 九宫格前两行给出规则，第三行套用 |

### 深度讲解

1. **"去同存异"识别**：第一个图和第二个图有公共线条，第三个图恰好只剩不公共的部分。做法：图 1、图 2 各自**独有的线条**描出来。
2. **黑白运算是"自定义规则"，必须从前两行现场学**：先固定一个格子位置，看"黑+白"在前两行产出什么颜色，列映射表，再代入第三行。**不要假设黑+白=白**--规则每题不同。
3. **遍历题先数种类**：一行 3 格 ×3 种图形 = 9 个位置，每种图形应出现 3 次；数缺的那个就是答案。

### 例题精讲 3（去同存异）

**题干**：第 1 图 = 大圆内接小三角；第 2 图 = 大圆内接小正方形；第 3 图起以此类推。规律为：第 3 图 = 第 1、2 图去同存异。问第 3 图是？

**解析**：
1. 相似、有公共部分 -> 样式类。
2. 公共部分 = 大圆（两图都有）-> 去掉；独有部分 = 三角、方形 -> 保留。
3. 第 3 图 = **三角 + 方形（无圆）**。
4. 陷阱：选项中必有一个"圆+三角+方形全保留"（叠加不减）和一个"只剩圆"（求同）。**先判断是"存异"还是"存同"，看第三图缺什么**。

### 例题精讲 4（黑白运算）

**题干**：九宫格黑白格。第一行（左上到右下三个 2×2 图）：图 A = 黑白/白白，图 B = 白黑/白白，图 C = 黑黑/白白。第二行同构，第三行给出前两图，问第三图。

**解析**：
1. 元素只有黑白、数量不定 -> 不是平移 -> 黑白运算。
2. 逐格学规则（第 1 格）：行 1 是 黑+白->黑；行 2（假设第 1 格 白+黑->黑）确认"黑白相加=黑"。
3. 全部格子学完（黑+黑=?、白+白=? 也要从行中找样例），代入第三行。
4. 深度：**每个格子独立学一条规则**，别学了一条就急着推整图；规则表 4 条（黑黑/白白/黑白/白黑）补齐才动笔。

## 四、数量类（第一大考点）

### 触发特征

**图形杂乱、无相似性**。数量类占图推半壁江山，核心是**数什么、按什么顺序数**。

### 数什么：优先级顺序（重要！）

> **点 -> 线 -> 面 -> 素 -> 角** 不是等概率出现，按以下优先级试，命中率高 3 倍：

1. **面（封闭区域数）**：图形明显有窟窿/格子/圆圈 -> 先数面。出现频率第一。
2. **线（笔画数 / 直线曲线分开数）**：出现**单独的圆、弧、五角星、"日/田"变形** -> 想一笔画与笔画数；全部直线 -> 数直线条数，曲直混合 -> 直线曲线分开数。
3. **素（元素种类和个数）**：图形由多个独立小图组成（星星、月亮、圆散落）-> 数种类、个数、种类差。
4. **点（交点/切点）**：线条明显相交成网状 -> 数交点；圆与线相切 -> 数切点。
5. **角（直角/锐角）**：出现大量垂直结构、直角三角形 -> 数直角。

### 规律细节表

| 考点 | 全部变体 |
|---|---|
| 面数量 | 恒定 / 递增 / 等差 / 乱序但成和（九宫格"行和"= 常数）/ 面积大小规律 |
| 一笔画 | **奇点数为 0 或 2 的连通图可一笔画**；奇点数 ÷ 2 = 笔画数；常考"所有图均可一笔画"分组 |
| 线数量 | 恒定 / 递增 / 外框线与内部线分开数 / 曲线数、直线数各自成规律 |
| 素数量 | 种类数 / 个数 / "种类递增" / 部分数（一个图形连成几块） |
| 点数量 | 交点总数 / 线与线的交点 / 圆内交点 vs 圆外交点 |
| 角数量 | 直角个数 / 锐角个数 / 内角和（多边形内角和 180°×(n−2)） |

### 深度讲解：一笔画与奇点（必考，讲透）

- **奇点**：从该点出发的线有**奇数条**。端点（1 条线）也是奇点！
- **判定**：连通图，奇点数 = 0 或 2 -> 一笔画；奇点数 = 4 -> 两笔画（笔画数 = 奇点数/2）；**奇点必有偶数个**，数出 3 个或 5 个说明数错了。
- 常见一笔画图形：圆、五角星、没有"日"以上复杂度的单连通图形、"田"字是 4 奇点两笔画（"日"字 2 奇点一笔画，注意区分）。
- 考法：题干 5 个图，问哪个可一笔画/分组题"能一笔画的归一类"。

### 例题精讲 5（面数量）

**题干**：五个图形依次为：一个圆、圆内一条水平弦（分上下 2 面）、圆内十字（4 面）、圆内两条相交弦（4 面？）、"田"字（4 面）……

**解析**：
1. 图形杂乱、都有封闭区域 -> 数面。
2. 依次数：1、2、4、4、4 -> 规律不明 -> **换一级：内外分开数或数"面+某元素"的复合**。若仍不成规律，回总纲换方向（此题实际考"面数量恒为偶数"这类分组特征）。
3. 深度：数数量最忌"数出来没规律就慌"。标准动作：**横向（逐图）没规律 -> 竖向（九宫格行列分别看）-> 加和 -> 分组**，四级排查是固定套路。

### 例题精讲 6（一笔画）

**题干**：下列图形按"能否一笔画"分为两组：①五角星 ②"日"字 ③"田"字 ④单独一个圆 ⑤"巾"字形（顶部一横下垂三竖）。

**解析**：逐个找奇点：
- ①五角星：每条线首尾相连，奇点 0 -> 一笔画 ✓
- ②"日"：上下两条横线各接两条竖线，端点处各 2 条线，中间交点 4 条线（偶）-> 奇点 0 -> 一笔画 ✓（"日"是 0 奇点不是 2，注意）
- ③"田"：中心十字交点 4 条线（偶），四角端点各 2 条（偶）……实际"田"的 4 个角是 2 条线端点相连？不--"田"= 外框正方形 + 内部十字：十字端点在框上，框上 4 个点各 3 条线 -> 4 个奇点 -> **两笔画** ✗
- ④圆：无奇点 -> 一笔画 ✓
- ⑤"巾"：一横与三竖的 3 个交点各 3 条线，两端点 -> 数：横线两端点各 1 条线（奇）、三竖下端点各 1 条线（奇）、三个 T 交点各 3 条线（奇）-> 奇点 8 -> 4 笔画 ✗

分组：**{①②④} vs {③⑤}**。
深度：这题把奇点判定全考了一遍--**端点是奇点、T 形交点是奇点、十字交点不是**。分组题两组各 3 个的分布本身是验证手段。

## 五、属性类

### 触发特征

图形**规整**（对称感）、或明显分"开放/封闭"、"曲线/直线"两派。

### 规律全表

| 规律 | 考法 | 秒杀特征 |
|---|---|---|
| 轴对称 | 是/不是；对称轴**条数**（1、2、3、4…）；对称轴**方向**（横/竖/斜，逐图转 45°）；"轴+中心"双对称 | 图形左右/上下一样 -> 先画对称轴；多条等分线 -> 数条数 |
| 中心对称 | 图形旋转 180° 后与原图重合（N、Z、S、平行四边形系） | 出现 N/Z/S/波浪/"风车"形 |
| 曲直 | 全直线 / 全曲线 / 有曲有直分组；曲直交替 | 圆、弧、波浪线 |
| 开闭 | 全开放 / 全封闭分组；开放封闭交替 | 图形有没有"口" |

### 深度讲解

1. **对称轴方向是近年高频**：五个图的对称轴依次转 45°（竖 -> 斜 -> 横 -> 斜），比"是否对称"难一档。看到规整图形，**动手把对称轴画出来再看方向**。
2. **对称轴条数成数列**（1、2、3、4）：等腰三角 1 条、矩形 2 条、等边三角 3 条、正方形 4 条、圆无数条。
3. **属性+数量复合**：如"轴对称图形的面数量递增"——属性做门槛、数量做规律，国考热门。

### 例题精讲 7（对称轴方向）

**题干**：五个图形均为规整图形，对称轴依次为：竖直 -> 斜 45°（右上到左下）-> 水平 -> 斜 135°（左上到右下）-> ？

**解析**：对称轴每次**逆时针转 45°**：竖(90°)-> 斜(135°方向)-> 横(180°)-> 斜(225°)-> 下一个 = 回到竖直(270°=90°)。
答案：**对称轴竖直的图形**。
深度：干扰项是"顺时针转 45°"的图形（斜向易看错）。判定技巧：在自己草稿上给每个图画箭头标方向，**箭头序列连起来看转向**，不逐个凭感觉。

## 六、空间类（折纸盒 + 三视图 + 截面）

### 触发特征

题干给立方体展开图问立体 / 给立体问视图 / 问截面形状。

### 规律全表

| 考点 | 核心方法 |
|---|---|
| 折纸盒 | **相对面排除法** + 相邻面方向验证 |
| 三视图 | 主视（正面）/ 俯视（上方）/ 侧视（左或右）；看不见的轮廓线用虚线（考细节时） |
| 截面 | 常见截面形状库（见下） |
| 立体拼接 | 凑体积、凹凸互补 |

### 深度讲解：折纸盒两板斧（必考，讲透）

**第一斧：相对面。**
- 立方体展开图中，"Z 字形两端"的面互为相对面（隔一格）：像字母 Z 分布的两个面。
- 同层隔一格（中间恰好隔一个面）的也是相对面：如一行 A B C，A 与 C 相对。
- **相对面在立体图上必看不到其中一个**：选项同时出现 Z 字两端的两个面 -> 直接排除。一招排除 1-2 个选项。

**第二斧：相邻面方向（时针法）。**
- 对选项中能看到的两个相邻面，找到它们公共棱两侧的**标记图形**（线条、箭头、缺口）。
- 回展开图折成立体，检查同一对面上标记的相对方向是否一致：以三个面公共顶点为轴，按顺序记录三个面（如"1-2-3"），选项呈逆时针而展开图折出顺时针 -> 排除。
- 记法：**"看一对，查方向"**，每次只验证两个面，别想整体。

### 截面形状速查（常考结论）

| 切法 | 截面 |
|---|---|
| 平行于面切立方体 | 正方形 |
| 斜切穿过 4 条侧棱 | 矩形（不垂直时不是正方形） |
| 过三条棱切出"角" | 三角形（过三条不共面棱的截线时可出等边三角） |
| 过 6 条棱斜切 | 六边形 |
| 切圆柱（平行轴） | 矩形；垂直轴 -> 圆；斜切 -> 椭圆 |
| 切圆锥 | 三角形（过轴）/ 圆（垂直轴）/ 椭圆（斜切） |

### 例题精讲 8（折纸盒）

**题干**：展开图一行排布 6 个面，依次编号 1-6，面 2 与面 4 中间隔着面 3（同层隔一）。立体图选项中同时出现面 2 和面 4 相邻，其余选项分别显示"面 1+2+3""面 1+3+5""面 4+5+6"。

**解析**：
1. 同层隔一：面 2 与面 4 **相对** -> 它们在立体上不可能同时出现 -> 该选项排除。
2. 剩三个选项用"看一对，查方向"：任选选项中最有特征（不对称、有方向性）的两个面，回展开图折出方向对比。
3. 深度：先相对面排一个，再方向验证剩下两个，**50 秒内完成是及格线**。平时练 3-4 组折纸盒就能把方向感练出来，纸笔辅助前期不丢人。

## 七、汉字 / 字母 / 数字题专攻

看到汉字字母不要去读义，它就是图。考察优先级：

1. **笔画数**（一笔一画像线数量）
2. **封闭面数量**（"口"有 1 面，"日"2 面，"目"3 面）
3. **部分数**（连成几块："川"3 部分、"国"2 部分）
4. **曲直**（"O"全曲、"Z"全直）
5. **求同**（一组汉字都含"氵"都含相同部件）
6. 结构（左右/上下/包围）-- 次高频

**例题速讲**：题干为"由、甲、申、田、？”，问填什么？
- 数笔画：5、5、5、5 -> 应选 5 画的"且"或"凹"？注意"凹"5 画 ✓；
- 也可看封闭面：由 1、甲 1、申 1、田 1 -> 选 1 面且 5 画的"凹"（1 面）比"且"（1 面）双验证。
- 深度：**汉字题先数笔画/面，两个规律交叉验证**再定答案，正确率远高于单规律。

## 八、分组分类题专攻（国考主流题型）

**形式**：6 个图形，分成两组各 3 个。

**思路**：分组题的规律必然"跨图形共享"（一笔画/对称/某元素数量同奇偶），且**答案分布必为 3+3**。
- 数量类常见"数量同为奇数 vs 偶数"、"同为一笔画 vs 多笔画"。
- 先挑出最有把握的 2-3 个归一边，剩下的自动成组；
- **验证闭环**：两组各自内部一致、两组之间不同，缺一不可。卡住时把 6 个图两两配对找"最像的一对"，它们大概率同组。

## 九、秒杀压缩表（考前 10 分钟过一遍）

| 特征 | 第一反应 | 第二反应 |
|---|---|---|
| 元素相同、位置变 | 平移（步长 1/2/3）/ 旋转（45°/90°）/ 翻转（手性） | 双元素反向移动 |
| 行内相似 | 去同存异 / 去异存同 / 遍历 / 黑白运算 | 单格学规则再代入 |
| 图形杂乱 | 面 -> 线 -> 素 -> 点 -> 角 | 横向不成看竖向、看加和 |
| 有圆/五角星/"日" | 一笔画（奇点 0 或 2） | 笔画数 = 奇点÷2 |
| 图形规整 | 对称（条数/方向转动） | 对称+数量复合 |
| 明显曲直/开闭两派 | 曲直分组 / 开闭分组 | 曲线数直线数分开成规律 |
| 立方体展开图 | Z 字/隔一找相对面排除 | 相邻面时针法验证 |
| 汉字字母 | 笔画 -> 封闭面 -> 部分数 | 求同（相同部件） |
| 6 图分两组 | 找共享属性（一笔画/奇偶/对称） | 3+3 分布自验证 |

## 附录：自测练习（答案见文末）

**练习 1**：九宫格黑块，每行黑块从左到右依次移动，第一行移 1 格、第二行移 2 格、第三行移 3 格（周期为 3，循环）。问第四行黑块位置？（位置类）

**练习 2**：图 1 = 大三角套小三角；图 2 = 大三角套小圆。第 3 图 = 图 1、2 去同存异。画出第 3 图。（样式类）

**练习 3**：判断下列哪些能一笔画：①圆中一条弦 ②"井"字 ③等边三角形加一条中线 ④单独五角星 ⑤"回"字。（数量类-笔画）

**练习 4**：五个图形的对称轴方向依次为：竖、横、斜 45°、竖、横。第 6 个图的对称轴方向？（属性类）

**练习 5**：立方体展开图上"点数面 1 与 3 中间隔着面 2"。立体图选项中同时出现 1 点面和 3 点面，该选项是否正确？（空间类）

### 自测答案

| 题号 | 答案 | 提示 |
|---|---|---|
| 1 | 右移 3 格 = 回到原位 | 周期循环：步长模周期；写数列 1、2、3 再推 |
| 2 | 小三角 + 小圆（无大三角） | 公共部分大三角去掉，独有部分保留 |
| 3 | 仅①④能一笔画 | 逐个数奇点：①圆+弦：弦两端点各 3 条线 -> 2 个奇点 -> 一笔画 ✓；②"井"：4 条线的外侧端点各 1 条线 -> 4 个奇点 -> 两笔画 ✗；③三角形+中线：中线两端为 T 形交点（3 条线，奇）-> 4 个奇点 -> 两笔画 ✗；④五角星：0 奇点 -> 一笔画 ✓；⑤"回"：内外圈不连通，已不是连通图 -> 两笔画 ✗。**数出奇数个奇点必是数错，回查** |
| 4 | 斜 45° | 规律是"竖、横、斜"循环（周期 3）：第 6 个回到斜 45° |
| 5 | 不正确 | 同层隔一为相对面，相对面不能同时可见 |

## 学习安排建议

1. **第一遍（3 天）**：每天攻 2 大类，把每类触发特征抄到错题本扉页。
2. **第二遍（1 周）**：每天 15 道真题（粉笔/历年），**每题先说出口"特征 -> 第一反应"再动笔**，把条件反射练出来。
3. **考前**：只看第九节秒杀表 + 错题本。
4. 图推卡壳 40 秒即蒙（图推蒙同分布 C 正确率约 25%，不值得恋战）。
