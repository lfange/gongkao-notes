# 判断推理 · 类比推理专题（关系体系、二级辨析、造句法）

> 类比推理的本质是**找同一把尺子**：题干两个词用某种关系连着，四个选项里只有一个用**同一种关系**连着。
> 题干越短越靠"关系体系"的熟练度——**先判断关系类型，再做二级辨析**，两步定答案。
> 专题结构：**本质 → 方法三步法 → 关系体系全表 → 二级辨析 → 题型逐个击破 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：横向找关系，纵向比优劣

类比推理永远在两个方向上比对：

- **横向**：题干 A:B 是什么关系？每个选项的 A':B' 是什么关系？——先保证**关系同类**；
- **纵向**：多个选项横向都对时，比较**哪个选项与题干的关系"最像"**——词性、感情色彩、必然性，这就是二级辨析。

一句话总结本质：

> **先横后纵：横向筛掉关系不同的，纵向挑出关系最像的。**

## 二、方法三步法（拿到题先走这三步）

1. **判断题干关系**：造一个"最小句子"（A 是 B 的一种 / A 是 B 的一部分 / A 用来 B……），确定关系类型。
2. **逐项套同一句子**：用**同一个句子**套四个选项——套不上的排除。
3. **多选项都套得上 → 二级辨析**：比较词性、顺序、必然性、感情色彩。

## 四、二级辨析（多个选项都对时比什么）

1. **词性 / 结构**：题干是名词:名词，选项必须名词:名词；题干双音节词组结构（动宾/偏正）要一致。
2. **顺序**：题干"种:属"，选项也得"种:属"——**"苹果:水果"不能配"水果:苹果"**。
3. **必然 / 或然**："地震:海啸"是或然因果（地震不一定引发海啸），能匹配"下雨:堵车"（或然），不能匹配"缺氧:死亡"这种更必然的。
4. **感情色彩**：题干两词一褒一贬，选项也要一褒一贬。
5. **具体 / 抽象**：题干"盐:咸"（具体物:属性），选项"药:苦"像、"忠诚:品德"（抽象）不像。
6. **物理变化 / 化学变化**：原料成品题的高频考点——"面粉:馒头"（物理）、"葡萄:红酒"（发酵，化学）。

## 五、题型逐个击破

### 题型 1：两词型（A:B）

> 造最小句子 → 套选项 → 二级辨析。最基础的形态。

### 题型 2：三词型（A:B:C）

> 关系链更长的比对，如"医生:医院:病人"（职业:场所:对象）。**先固定中间词的身份**，再往两边套。

### 题型 3：填空型（A 对于 （ ） 相当于 （ ） 对于 B）

> 选项代入后两边各自成对，**两边必须是同一种关系**。技巧：代入后分别造句，两句必须同构。
> 陷阱高发：代入后前半对、后半关系不同——**两边都要验**。

### 题型 4：分级分类 / 多选项择优

> 题干关系冷门（如"锅盖:锅"），需要纵向比对时，回到**关系体系表**找最贴切的层级。

## 六、易错点清单

1. **种属 vs 组成**（第一大坑）："轮胎:汽车"是组成，"轿车:汽车"是种属——**"的一种"能说通是种属**。
2. **顺序反了**："水果:苹果"配"汽车:轮胎"，关系对但方向反——**方向也是关系的一部分**。
3. **只验证一半**（填空型）：前半句通就选，后半句没验。
4. **忽略必然性**：或然因果配必然因果——留意"可能"与"一定"。
5. **物理化学不分**：原料成品题默认考变化性质。
6. **凭生活直觉不造句**：类比题的"顺口"经常是出题人埋的坑，**最小句子必须真的造出来**。
7. **忽略职业主体**："厨师:炒菜"配"医生:看病"都对，但若题干是"教师:授课"，选项"学生:听课"方向就反了（职业者:职业行为 vs 接受者:接受行为）。

## 七、精讲例题

### 例题 1（功能关系：主要 vs 次要）

**题**：白醋:消毒
A. 热水器:加热　B. 汽油:去渍　C. 白糖:调味　D. 冰箱:保鲜

**解析**：

1. 白醋的主要功能是调味，消毒是**次要功能**——关系是"物品:它的次要功能"。
2. A、C、D 都是主要功能（热水器就是加热的、白糖就是调味的、冰箱就是保鲜的）。
3. 汽油的主要功能是燃料，去渍是次要功能 ✓，**选 B**。
4. **二级辨析的核心一课：功能关系要分主次**。真题爱把"主要功能"选项全排满，只有一个是次要功能。

### 例题 2（原料成品：物理 vs 化学）

**题**：葡萄:红酒
A. 面粉:馒头　B. 大米:米酒　C. 黄豆:豆浆　D. 棉花:棉布

**解析**：

1. 葡萄**发酵**成红酒——化学变化。
2. 面粉蒸馒头、黄豆磨豆浆、棉花纺棉布都是**物理变化**。
3. 大米**发酵**酿米酒 ✓，**选 B**。
4. 原料成品题的暗线：**变没变"化学本质"**。

### 例题 3（三词型：固定中间词）

**题**：教师:学校:授课
A. 医生:医院:坐诊　B. 律师:法院:旁听　C. 演员:舞台:观看　D. 厨师:厨房:洗碗

**解析**：

1. 中间词是**职业场所**：教师在学校（工作场所）授课（职业行为）。
2. B：律师执业场所不只是法院，且"旁听"不是律师的职业行为（关系错位）；C："观看"是观众的行为，不是演员的；D："洗碗"是洗碗工的行为——厨师对厨房、授课对洗碗都不对位。
3. A：医生在医院坐诊——职业:场所:行为全同构，**选 A**。
4. 三词题技巧：**中间词定身份，两边同时验证**，一个词错位整项排除。

### 例题 4（填空型：两边同构）

**题**：（　）对于 医生 相当于 教案 对于（　）
A. 处方　教师　B. 药品　病人　C. 医院　学校　D. 护士　学生

**解析**：

1. 代入 A：**处方**对于医生——处方是医生履职的专属文书；教案对于**教师**——教案是教师履职的专属文书。两边同构 ✓，**选 A**。
2. B：药品对于医生（使用对象？），教案对于病人（教案与病人无关系）——后半断裂。
3. C：医院对于医生（场所），教案对于学校（教案是教师写的、学校不是教案的"场所"）——前半是"场所:人"，后半是"文书:机构"，不同构。
4. D：护士对于医生（同事并列），教案对于学生（学生用教案？）——后半不成立。
5. 填空型铁律：**两边造出来的句子必须一模一样**。

## 八、自测练习

1. 灯泡:灯丝:照明（A. 汽车:发动机:驾驶　B. 电脑:鼠标:游戏　C. 手表:表带:装饰　D. 钢笔:墨水:书写）
2. （　）对于 蜂蜜 相当于 绵羊 对于（　）（A. 蜜蜂 羊毛　B. 花朵 羊绒　C. 蜂巢 剪刀　D. 甜蜜 温暖）
3. 出席:缺席（A. 生:死　B. 白:黑　C. 上:下　D. 晨:昏）
4. 珍稀:物种（A. 优秀:成绩　B. 古老:文明　C. 快速:列车　D. 保密:文件）

### 答案附录

1. **A**（组成 + 功能：灯丝是灯泡的核心组成部件、灯泡的功能是照明；发动机是汽车的核心组成部件、汽车的功能是驾驶。B 鼠标是电脑的外接配件而非组成部件；C 表带是配件且"装饰"非手表主要功能（计时才是）；D 墨水是钢笔的**消耗品**，不是组成部件）。
2. **A**（蜜蜂对于蜂蜜——生产者:产物；绵羊对于羊毛——生产者:产物，两边同构 ✓。B 花朵对于蜂蜜是"原料:成品"（花朵供花蜜），与后半"绵羊:羊绒"（生产者:产物）不同构；C 蜂巢是场所/容器；D 是属性搭配）。**方向陷阱自查：本题若选项给"羊毛 绵羊"（前后颠倒），必须排除**。
3. **A**（出席与缺席是**矛盾关系**——非此即彼，不存在"既出席又缺席"或"既不出席又不缺席"的中间态。白:黑之间有灰、上:下之间有中、晨:昏之间有午，都是**反对关系**（存在中间态）。裁决口诀：**找没有中间态的那一对**）。
4. **B**（"珍稀的物种"——修饰:被修饰；"古老的文明"与之共享"存续物 + 时间维度"的语义场，且都是常见固定搭配。A/C/D 虽也是修饰关系，但"古老:文明"在二级辨析（语义场、搭配惯用度）上最贴）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../../错题本.md)：

- **关系错**：种属/组成、主要/次要功能、物理/化学没分清；
- **方向错**：题干 A:B，选项给了 B:A；
- **半边错**：填空型只验证了一边；
- **纵比错**：多个选项都对时没做二级辨析（词性/色彩/必然性）。
