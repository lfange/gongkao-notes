# 判断推理 · 逻辑判断专题（翻译推理、真假话、削弱加强、日常结论、朴素逻辑）

> 逻辑判断是行测里**最"讲理"**的题型：规则就那么几条，会了就稳定拿分。
> 三大块各有一把钥匙：翻译推理靠**翻译公式**，削弱加强靠**拆论证**，朴素逻辑靠**假设与列表**。
> 专题结构：**本质 → 方法三步法 → 翻译推理 → 真假话 → 削弱加强 → 日常结论 → 朴素逻辑 → 易错点 → 精讲例题 → 自测练习**（答案见文末附录，先遮住自己做）。
> 使用方法：看讲解 → 遮解析做例题 → 对答案 → 错题归因记入 [错题本.md](../../错题本.md)。

---

## 一、本质：形式规则 + 论证结构

逻辑判断分两类题：

- **形式逻辑**（翻译推理、真假话）：题干给条件，答案由条件**必然**推出——像做数学题，靠公式；
- **论证逻辑**（削弱、加强、假设、结论）：题干给一个论证（论据 → 论点），问你怎么攻击或支援它——靠拆结构。

一句话总结本质：

> **形式题"只认规则不认内容"，论证题"先找论点再找缺口"。**

## 二、方法三步法（拿到题先走这三步）

1. **看提问定题型**："可以推出 / 必然为真"→ 翻译推理；"只有一人为真"→ 真假话；"最能削弱 / 加强 / 假设"→ 论证类；"可以得出什么"→ 日常结论；"排序 / 匹配"→ 朴素逻辑。
2. **形式题：翻译**——把"如果…那么…"翻成箭头式，套公式。
3. **论证题：拆结构**——先问"论点是什么？论据是什么？从论据到论点跳了哪一步？"——削弱攻的就是那一步。

## 三、翻译推理（形式逻辑核心）

### 3.1 翻译规则（背熟）

| 题干说法 | 翻译 | 记法 |
| --- | --- | --- |
| 如果 P，那么 Q | P → Q | 前推后 |
| 只要 P，就 Q | P → Q | 前推后 |
| 只有 Q，才 P | P → Q | **后推前** |
| 除非 Q，否则不 P | P → Q | 后推前 |
| P 是 Q 的必要条件 | Q → P | 必要在后被推 |
| 所有 P 都是 Q | P → Q | 前推后 |
| 有的 P 是 Q | 存在同时属于P与Q的对象 | 可换位为“有的Q是P”，不能推成全称条件句 |

### 3.2 推理规则

- **逆否等价**：P→Q等价于¬Q→¬P；已知P→Q，肯定P可以推出Q，否定Q可以推出¬P。
- **肯后、否前不必然**：已知 P → Q，"Q 成立"推不出 P；"P 不成立"推不出 Q 不成立——这两条是干扰项的制造机。
- **传递（连锁）**：P → Q，Q → R ⇒ P → R。
- **且或德摩根**：¬(P∧Q) = ¬P∨¬Q；¬(P∨Q) = ¬P∧¬Q。
- **"且"要全真，"或"要一真**："P 或 Q"为假，当且仅当两者都假。

### 3.3 做题套路

翻译 → 写出所有箭头式 → 找连锁 / 找逆否 → 对照选项。选项中出现"可能 / 不一定"这类弱表述，往往是用"否前 / 肯后"造的**正确答案**（弱表述天然安全）。

## 四、真假话（矛盾法）

四步：**找矛盾 → 绕开矛盾 → 判断其余真假 → 回代矛盾**。

常用矛盾对：

| 原命题 | 矛盾命题 |
| --- | --- |
| 所有 S 都是 P | 有的 S 不是 P |
| 所有 S 都不是 P | 有的 S 是 P |
| P → Q（如果 P 那么 Q） | P 且 ¬Q（P 且非 Q） |
| 甲说："是我做的" vs 乙说："不是我做的"（单称） | 二者必一真一假 |

> 三句话只有一真：真话必在矛盾对中 → 其余全假；只有一假：假话必在矛盾对中 → 其余全真。

## 五、削弱加强（论证逻辑核心）

### 5.1 拆论证

任何论证 = **论据 + 论点 +（暗含的桥梁）**。先标出：

- **论点**：通常在"因此 / 由此推断 / 专家认为"之后，或首句；
- **论据**：调查、数据、实验；
- **桥梁**：论据到论点之间没说出口的假设——**削弱和加强都打这里**。

### 5.2 削弱方式：先判断攻击对象

    论据 A
       ↓ 依靠桥梁 H
    论点 B

    削弱
    ├─ 攻击论点 B：B 不成立或存在直接反例
    ├─ 拆桥 H：即使 A 为真，也推不出 B
    │  ├─ 直接论据与论点无关
    │  ├─ 部分不能推出整体
    │  └─ 样本对总体没有代表性
    ├─ 攻击论据 A
    │  ├─ 论据无效、不能使用
    │  └─ 论据虚假或存在关键错误
    └─ 攻击因果 A→B
       ├─ 因果倒置：其实是 B→A
       └─ 另有他因：C 也能导致 B

| 攻击方式 | 核心问法 | 典型表现 | 判断边界 |
| --- | --- | --- | --- |
| 否定论点 | 结论本身是否错误 | 出现与结论正面冲突的事实或反例 | 反例范围必须覆盖论点，个别反例未必能推翻概率性结论 |
| 拆桥 | 即使论据为真，能否推出论点 | 无关指标、部分推整体、样本无代表性、类比对象有关键差异 | 论据本身可以是真的，只是证明不了该结论 |
| 削弱论据 | 论据是否真实、有效、可使用 | 数据造假、重复统计、测量方法错误、实验条件不成立 | 若只说明论据与论点无关，更准确地归入“拆桥” |
| 因果倒置 | 是否把结果当成原因 | 不是 A 导致 B，而是 B 导致 A | 必须能说明反向作用，而不只是二者同时发生 |
| 另有他因 | 是否存在 C 足以解释 B | 同期政策、环境或人群差异造成结果 | 只证明“还有一个可能原因”时，通常不能直接否定 A→B |

#### 5.2.1 削弱论点：直接攻击结论

若论点是“该措施能降低事故率”，选项证明“采用该措施的地区事故率没有下降，且其他条件相同”，就直接否定了论点。直接削弱论点通常很有力，但仍要检查**对象、时间和范围是否一致**。

#### 5.2.2 拆桥：论据是真的，也证明不了论点

1. **直接论据与论点没有关系**：论据说“使用线上签到后到课率提高”，论点却说“线上签到提高了教学质量”。到课率不等于教学质量，二者缺少必要联系。
2. **部分推出整体**：论据只覆盖某地区、某年龄段或某一时间，论点却扩大为全国、所有人或长期结论。要问“这一部分凭什么代表整体”。
3. **论据没有代表性**：调查对象是自愿参与者、产品忠实用户、获奖者或单一群体，却推出总体结论，存在选择偏差。

> **样本少不必然等于没有代表性。** 小样本主要降低结论稳定性；只有进一步说明抽样偏斜、遗漏关键群体或样本结构与总体明显不同，才能形成更有力的“无代表性”削弱。

#### 5.2.3 削弱论据：论据无效或论据有错

- **论据无效**：测量工具不能测出目标指标、实验对照失效、数据口径前后不一致，使该证据不能作为可靠依据；
- **论据有错**：数据被重复计算、记录错误、样本资料造假，或者作为前提的事实根本不存在。

两者都在攻击“论据能否站住”。如果该论据是论证的唯一支柱，指出致命错误往往削弱很强；若还有多组独立证据支撑同一论点，击破其中一组未必足够。

#### 5.2.4 因果倒置与另有他因

- **因果倒置**：原论证是 A→B，选项证明更可能是 B→A。例如“经常运动的人更健康”，可能是“身体本来健康的人更容易坚持运动”。它直接改变因果方向，通常比仅提出一种可能原因更直接。
- **另有他因**：原论证是 A→B，选项提出 C→B。例如“物业涨价后满意度上升”，同期也更换了老旧电梯。它说明结果未必由 A 造成，但通常仍未排除 A 也发挥作用。

> “另有他因”一般只是在争夺解释力，若只说“也可能存在 C”，削弱常常不强；但若 C 能**充分、独立地解释结果**，或控制 C 后 A 与 B 的关系消失，就可能成为最强削弱。仍须与其他选项比较，不能见到“他因”就直接选或直接排。

### 5.3 削弱力度：不背死排序，比较实际破坏程度

比较两个选项时依次问：

1. **是否命中题干的核心论点和关键论据？** 攻击背景信息通常无关；
2. **是否让结论直接为假，或让唯一论据彻底失效？** 能使论证坍塌的通常更强；
3. **覆盖范围是否匹配？** “个别人”难推翻“多数人”，“某地”难推翻“所有地区”；
4. **措辞是确定事实还是仅有可能？** “实际由 C 导致”通常强于“可能存在 C”；
5. **附加条件是否可靠？** 样本偏差、控制变量和数据错误要有题干所需的具体信息。

在对象、范围和条件相当时，直接否定论点、击毁唯一论据和彻底拆桥通常都属于强削弱；因果倒置和能完整解释结果的强他因也可能很强。仅提出一种可能他因、个别反例或模糊质疑通常较弱。强削弱之间仍要比较它们对本题核心论证的覆盖程度。

### 5.4 加强方式：先判断支援位置

    论据 A
       ↓ 依靠桥梁 H
    论点 B

    加强
    ├─ 加强论点 B：补充直接支持结论的新事实
    ├─ 加强论据 A：证明数据、实验或事实真实可靠
    ├─ 搭桥 H：建立 A 与 B 的联系
    │  └─ 部分→整体时，证明样本能够代表总体
    ├─ 解释机制：说明为什么 A 会带来 B
    ├─ 补充举例：增加符合结论的实例
    └─ 排除干扰：排除他因、倒置或其他解释

#### 5.4.1 六类加强路径

| 加强方式 | 核心作用 | 常见表现 | 适用边界 |
| --- | --- | --- | --- |
| 加强论点 | 新事实直接支持结论 | 对照结果、后续验证、直接观测与结论一致 | 对象、时间、范围必须与论点匹配 |
| 加强论据 | 提高原证据的真实性、可靠性 | 数据来源权威、测量准确、实验重复成功 | 论据可靠不等于论据与论点一定有关 |
| 搭桥 | 建立论据到论点的关键联系 | A能够导致B、P都属于Q、样本代表总体 | 箭头方向、对象和范围必须接上 |
| 解释机制 | 说明原论据为何能支持结论 | 补充中间过程、作用原理 | 只解释论据为何出现但未连到论点，力度有限 |
| 补充举例 | 增加与结论一致的具体事实 | 新地区、新人群、新实验出现同样结果 | 一个例子通常难证明“所有”；但可直接证明“有的” |
| 排除干扰 | 减少其他解释 | 排除他因、排除倒置、控制变量 | 排除一个他因不等于排除全部他因 |

#### 5.4.2 加强论点、解释论据与举例

1. **加强论点**：论点是“该培训能提升办事效率”，选项给出“同等条件下，接受培训组平均办理时间显著短于未培训组”，直接支持结论。
2. **解释论据**：论据是“流程改造后重复提交减少”，选项说明“系统统一字段并自动调用已有材料”，补充了结果产生的机制，使“流程改造有效”更可信。
3. **补充举例**：论点是“这种治理办法具有一定推广价值”，选项指出另一个条件相近地区采用后也取得成效，形成新例证。

**举例强度边界：**

- 论点是“有的对象具有某性质”时，一个真实、相关的实例就可能直接证明；
- 论点是“所有对象都如此”时，一个正例只能增加支持，不能排除其他对象存在反例；
- 论点是“通常、总体上有效”时，应看例子数量、独立性、覆盖范围和是否具有代表性；
- 重复引用同一数据来源不等于增加了独立证据。

#### 5.4.3 搭桥：从论据概念推向论点概念

**识别信号**：“使上述论证成立 / 使论证有效 / 补充哪项前提”等提问，且论据与论点使用了不同概念。例如，论据谈“不愿动脑”，论点却谈“缺乏主动性、创造性”，就要检查两者之间缺少什么联系。

**考场三步法**：

1. **拆结构**：分别写出论据和论点，不被题干先说结论、后说原因的语序带偏；
2. **找缺口**：保留共同的对象，圈出论据与论点中不同的概念；
3. **补关系并回代**：让论据中的概念推出论点中的概念，再检查选项的方向、范围和对象是否足以完成推理。

常见的集合搭桥模型：

    论据：有的 S 是 P
    论点：有的 S 是 Q
    桥梁：所有 P 都是 Q，即 P → Q
    回代：题干中那些属于 P 的 S，也属于 Q

这里 S 是共同对象，P 是论据概念，Q 是论点概念。**搭桥方向看推理方向，不看句子先后：从 P 推向 Q。** 这一模型适用于“有的 S 是 P → 有的 S 是 Q”的集合论证；遇到因果、措施等模型，仍需检查其具体缺口。

#### 5.4.4 两个易错点：箭头反向、对象未接上

| 选项关系 | 能否完成上述模型的搭桥 | 原因 |
| --- | --- | --- |
| 所有 P 都是 Q（P → Q） | 能 | 覆盖题干中属于 P 的那些 S，可以推出它们也属于 Q |
| 所有 Q 都是 P（Q → P） | 不能保证 | 方向反了，已知 P 不能靠“肯后”推出 Q |
| 某些 P 是 Q | 不能保证 | 只能说明 P、Q 有交集，交集中的人未必属于 S |
| 某些 Q 是 P | 不能保证 | 可换位成“某些 P 是 Q”，但仍无法接上题干中的 S |

> **“某些”不必然是弱项，“所有”也不必然是正确项。** 如果选项明确说明“有的 S 同时是 P 和 Q”，就能支持“有的 S 是 Q”。本模型中的问题是“某些 P 是 Q”没有保证这些对象属于 S，而不只是措辞不够强。

#### 5.4.5 部分—整体：证明部分能够代表整体

原论证：

    样本中的多数对象具有特征 X
       ↓
    总体多数对象也具有特征 X

需要补的桥梁是“样本能够代表总体”。常见加强方式：

- 从完整总体名单中随机抽取，降低选择偏差；
- 分层抽样覆盖不同地区、年龄、职业等关键群体；
- 样本结构与总体结构在关键变量上接近；
- 调查渠道没有系统性遗漏某类对象；
- 样本量足以降低偶然波动，并且抽样方式本身合理；
- 回应者与未回应者不存在会系统改变结论的关键差异。

> **样本大不自动等于有代表性。** 一万个产品忠实用户仍可能不能代表全部消费者；随机、覆盖和结构匹配解决“代表谁”，样本量主要改善估计稳定性。

**最小例证：** 调查全市政务平台满意度，如果样本按各区实际用户数分层随机抽取，年龄和办理事项结构与全部用户接近，就加强了“样本满意度可以推及全体用户”的桥梁。

#### 5.4.6 必要条件：看提问方式，用否定代入

| 提问方式 | 主要任务 | 判断方法 |
| --- | --- | --- |
| “最能加强/支持” | 找实际增加可信度最多的选项 | 比较对核心论证的支持程度 |
| “不能加强的是” | 找无关项、削弱项或未提供支持的项 | 逐项说明如何影响论证 |
| “基于以下哪项假设” | 找论证默认成立且离不开的条件 | 否定代入 |
| “必须具备的前提是” | 找必要条件 | 否定后论证应无法成立 |
| “使上述论证成立/有效” | 常考补桥或足够条件 | 回代后检查能否从论据推出论点 |
| “除哪项外均能加强” | 反向选择唯一不加强项 | 先圈“除外” |

**否定代入四步：**

1. 准确否定选项；
2. 将否定后的选项放回原论证；
3. 观察论据是否仍可能按原有理由支持论点；
4. 否定后论证必然失去成立条件，才是必要前提。

**准确否定：** “所有 P 都是 Q”的否定是“有的 P 不是 Q”；“有的 P 是 Q”的否定是“所有 P 都不是 Q”；不能把“并非所有”误写成“所有都不”。

**题型边界：**

- **充分搭桥**：加入选项后，论据能够推出结论；
- **严格必要前提**：原论证离不开它，否定后原论证不能按原有理由成立；
- 能加强不等于必要，能使结论更可信的事实未必是论证必不可少的条件；
- 有些题目虽使用“前提”字样，实质考补桥和充分支持，应结合选项与命题口径作答，但概念复盘时仍要分清充分与必要。

### 5.5 加强力度：看核心缺口，不背固定排序

比较加强选项时依次问：

1. 是否支持题干真正的论点，而不是只赞同背景？
2. 是直接支持结论，还是只让某个次要细节更可信？
3. 是否补上唯一关键桥梁或必要条件？
4. 证据是否独立、可靠，范围是否覆盖论点？
5. 因果题中是否排除了关键他因或倒置？

直接验证核心结论、补上唯一桥梁、确认必要条件，通常都可能形成强加强；解释机制、增强论据、补充举例的力度取决于它们是否击中缺口。不存在对所有题都适用的固定排名。

### 5.6 高频论证模型

| 模型 | 特征 | 加强时优先检查 | 削弱时优先检查 |
| --- | --- | --- | --- |
| 因果论证 | "因为 A，所以 B" | 解释机制、排除他因与倒置、控制变量 | 因果倒置 / 另有他因 / 相关不等于因果 |
| 调查归纳 | “受访样本如此，所以总体如此” | 随机分层、覆盖关键群体、样本结构匹配总体 | 抽样偏差、遗漏群体、样本与总体结构不同 |
| 部分—整体 | “某地区/时段有效，所以整体都有效” | 证明部分具有代表性、总体内部差异小 | 范围扩大、部分权重过小、整体内部差异 |
| 类比论证 | "甲地有效，乙地也会有效" | 证明两地关键条件相同 | 指出甲乙的关键差异 |
| 实验论证 | “实验组变化，所以处理有效” | 随机分组、对照有效、变量受控、结果可重复 | 对照失效、变量未控制、测量错误 |
| 措施论证 | "实施某政策 → 达到某目标" | 措施可执行、作用机制成立、关键条件具备 | 政策无法执行 / 达不到目标 / 有更糟副作用 |

## 六、日常结论（"可以推出"）

- **范围匹配**：题干能支持多大范围，就选对应结论；弱表述不是天然正确，强表述也不是天然错误。
- **不无中生有**：原文未直接出现的结论可以通过有效推导得到，但不能靠常识擅自补充条件。
- **比较类判断**：检查是否能直接或间接推出比较关系，不能只因选项含“更/最”就排除。

## 七、朴素逻辑（匹配、排序）

- **列表法**：人物 × 属性画表，条件打 ✓✗，排除到唯一；
- **假设法**：从信息量最大（限制最多）的人/物入手假设，推出矛盾则反推；
- **代入排除**：选项完整给出匹配结果时，直接逐项代回条件验证；
- **突破口**：找**出现次数最多的元素**或**最具体的限制**（"张不选 A、不选 B、不选 C"直接锁定）。

## 八、易错点清单

1. **肯后 / 否前当推理用**：P → Q 不代表 Q → P——翻译推理第一大坑。
2. **"只有…才…"翻错方向**：后推前（P → Q 里的 P 是"才"后面的）。
3. **"或"当"且"处理**：一真即真。
4. **真假话没绕矛盾**：直接硬猜四人谁说真话——必须先找矛盾对。
5. **削弱题选成"无关反驳"**：攻击了背景信息而非论点——**先写论点再读选项**。
6. **削弱力度机械排序**：不同题目的缺口不同，比较选项对当前论证的实际影响，不背固定级别；“另有他因”也不天然最强。
7. **日常结论机械选弱项**：“可能”无依据也错，“一定”有充分依据也可正确。
8. **朴素逻辑从零硬排**：不从最大信息量元素入手，时间黑洞。
9. **搭桥方向反了**：需要 P → Q，却选择 Q → P；或只看到“某些 P 是 Q”，没检查这些对象是否属于题干的 S。
10. **加强与必要混为一谈**：能补强、能充分搭桥，不代表严格必需；否定“所有”时也不能误写成“所有都不”。

## 九、精讲例题

### 例题 1（翻译推理：否后推否前）

**题**：如果小王参加比赛，那么小李和小张也都参加。由此可以推出：
A. 小李参加比赛，则小王也参加
B. 小张不参加，则小王不参加
C. 小王不参加，则小李和小张都不参加
D. 小李和小张都参加，则小王也参加

**解析**：

1. 翻译：王 → (李∧张)。
2. A 肯后（李 → 王）不必然 ✗；C 否前不必然 ✗；D 肯后不必然 ✗。
3. B：张不参加 → ¬(李∧张) 成立 → 否后推否前 → ¬王 ✓，**选 B**。
4. 记住："李**和**张都参加"的否命题是"**至少一个**不参加"——否定一个就够。

### 例题 2（真假话：矛盾法四步）

**题**：教室玻璃碎了，老师问四人。甲："是乙打碎的。"乙："是丁打碎的。"丙："不是我打碎的。"丁："乙在说谎。"四人中只有一人说真话，玻璃是（ ）打碎的。
A. 甲　B. 乙　C. 丙　D. 丁

**解析**：

1. **找矛盾**：乙说"是丁"（丁碎），丁说"乙在说谎"（不是丁）——两人矛盾，**必有一真一假**。
2. **绕开**：唯一的真话在乙、丁之中 → 甲、丙都说假话。
3. **推其余**：甲假 → 不是乙；丙假 → **是丙**，**选 C**。
4. 回代验证：丙打碎 → 甲（是乙）假 ✓、乙（是丁）假 ✓、丙（不是我）假 ✓、丁（乙说谎）真 ✓——恰好一真。

### 例题 3（削弱：因果倒置）

**题**：某研究团队调查发现，经常喝咖啡的人患心脏病的比例低于不喝的人，于是推断喝咖啡有助于心脏健康。以下哪项如果为真，最能削弱上述推断？
A. 有些心脏病患者也每天喝咖啡
B. 咖啡在我国种植面积不大，部分咖啡豆依赖进口
C. 心脏健康状况较好的人，本来就更可能保持长期喝咖啡的习惯
D. 常喝茶的人患心脏病的比例同样低于不喝的人

**解析**：

1. 论点：喝咖啡 → 心脏健康（因果）；论据：喝咖啡的人患病率低（相关）。
2. C 指出**因果倒置**：不是喝咖啡导致健康，是健康导致喝咖啡——直插论证心脏，**选 C**。
3. A "有些"是弱反例；B 无关（种植面积与健康无关）；D 是类比项（喝茶也低），不削弱"喝咖啡"的因果，反而略微支持"饮品与健康"相关。
4. 调查类因果论证要优先检查**倒置、他因和样本代表性**，再比较哪个选项对当前论证破坏更彻底。

### 例题 4（前提假设：否定代入）

**题**：某市拟规定公共建筑夏季空调温度设置不低于 26℃，环保部门预计该项规定可使全市空调用电量下降约一成。该预测须依赖以下哪项假设？
A. 该规定能够得到较为严格的执行
B. 居民普遍支持节能环保理念
C. 26℃的室温足以满足人体舒适需求
D. 该市其他季节的用电量也将下降

**解析**：

1. **否定代入 A**：若规定执行不严（大家照开 24℃），用电量根本不会降——论证直接崩塌 → A 是必要前提，**选 A**。
2. 否定 B：居民不支持，只要公共建筑执行了，预测依然成立 → 非必要。
3. 否定 C：26℃不太舒适，但规定强设 26℃，用电照样降 → 非必要（舒适度影响的是体验，不是用电量预测）。
4. 否定 D：其他季节与"夏季空调用电"预测无关。
5. 前提假设题的**判定标准**：否掉它，论证就塌。

### 例题 5（日常结论：范围限定）

**题**：某博物馆实行夜间开放后，工作日夜场观众中约六成是首次到访的年轻人。据此可以推出：
A. 工作日夜场观众中，首次到访的年轻人占多数
B. 大多数年轻人更喜欢夜间参观博物馆
C. 该馆白天的观众以老年人为主
D. 年轻人参观博物馆一定是为了社交打卡

**解析**：

1. A：约六成超过一半，因此“工作日夜场观众中首访年轻人占多数”可直接推出，**选A**。这只是构成比例，不能推出年轻观众绝对人数“大量”，也不能推出夜场对全体年轻人的吸引力。
2. B 偷换范围：夜场年轻观众多 ≠ 大多数年轻人喜欢夜间参观（分母变了）。
3. C 无中生有：白天的观众构成完全没提。
4. D 绝对化 + 无中生有："一定""为了社交打卡"双重加码。

### 例题 6（朴素逻辑：突破口 + 排除）

**题**：小张、小王、小李三人中，一位是医生、一位是教师、一位是律师。已知：小李比律师年龄大；小张和教师不同岁；教师比小王年龄小。则小张、小王、小李的职业依次是：
A. 律师、医生、教师　B. 医生、律师、教师　C. 教师、医生、律师　D. 律师、教师、医生

**解析**：

1. **突破口**："小张和教师不同岁"→ 小张不是教师；"教师比小王年龄小"→ 小王不是教师 → **教师是李**。
2. "小李（教师）比律师年龄大" + "教师比小王年龄小" → 律师 < 李(教师) < 王 → 律师不是王 → **律师是张，医生是王**。
3. **选 A**（张律师、王医生、李教师）。
4. 技巧：年龄/名次的**不等式链**是朴素逻辑的隐形条件——把"不同岁"翻译成"不是"，把"比…大"串成链。

### 例题 7（搭桥：论据 → 论点，2020 深圳）

**题**：有的上位者缺乏主动性、创造性，因为他们不愿真正动脑筋想问题。

要使以上论证有效，必要的前提是：

A. 缺乏主动性、创造性的人很难上位

B. 某些不愿真正动脑筋想问题的人具有主动性、创造性

C. 某些缺乏主动性、创造性的人不愿真正动脑筋想问题

D. 不愿真正动脑筋想问题的人都缺乏主动性、创造性

**解析**：

1. **拆结构**：论据是“有的上位者不愿真正动脑筋想问题”；论点是“有的上位者缺乏主动性、创造性”。“因为”后面给的是论据，句首给的是论点。
2. **标概念**：S = 上位者，P = 不愿真正动脑筋想问题，Q = 缺乏主动性、创造性。题干从“有的 S 是 P”推到“有的 S 是 Q”。
3. **补桥梁**：需要将“不愿动脑”接到“缺乏主动性、创造性”，D 给出 P → Q，覆盖题干中的那些上位者。加入 D 后，论据能推出论点，**选 D**。

| 选项 | 判断 | 具体原因 |
| --- | --- | --- |
| A | 不搭桥 | 讨论缺乏主动性、创造性的人是否容易上位，没有建立“不愿动脑 → 缺乏主动性、创造性”的联系 |
| B | 不搭桥 | 说明某些不愿动脑者仍具有主动性、创造性，不能建立所需桥梁；这些人也未必是上位者 |
| C | 对象未接上 | 只说某些人同时具有 P、Q 两个特点，没有保证这些人是题干中的上位者 |
| D | 完成搭桥 | 所有不愿动脑者都属于缺乏主动性、创造性的人，题干中的那些上位者也在其覆盖范围内 |

**C 的最小反例**：小王是上位者，不愿动脑，但具有主动性、创造性；小李不是上位者，不愿动脑且缺乏主动性、创造性。假设只有这两个人，那么题干论据和 C 都为真，结论“有的上位者缺乏主动性、创造性”却为假。因此 C 不能保证推理有效。

**边界提醒**：本题按补充桥梁的思路选 D。严格说，D 是足以使推理成立的全称条件，但并非该存在性结论的严格必要条件：即使有某个不愿动脑者仍具主动性、创造性，也可能另外存在符合题干结论的上位者。不要据此记成“所有必要前提题都要选全称搭桥”，也不要说 B 必然推翻了本题的存在性结论。

**记忆句**：论据概念 → 论点概念；方向要顺，对象要接，范围要够。

### 例题 8（部分—整体：证明样本能够代表总体）

**题**：某市调查 1200 名政务服务平台用户，其中 78% 表示满意。研究者据此认为，该平台全体用户的总体满意度较高。以下哪项如果为真，最能加强上述结论？

A. 该平台今年新增了多项服务功能

B. 调查从完整用户名单中按各区实际用户占比随机分层抽取，样本的年龄和办理事项结构与全体用户基本一致

C. 受访者填写问卷的平均时间不足 5 分钟

D. 邻市同类平台的满意度也较高

**解析**：

1. **拆结构**：论据是“1200 名受访者中 78% 满意”，论点是“全体用户总体满意度较高”。
2. **找缺口**：论据只覆盖样本，论点扩大到总体，必须补上“这 1200 人能够代表全体用户”。
3. **B 完整搭桥**：从完整名单抽取，降低遗漏群体的风险；按各区实际占比分层随机抽样，降低选择偏差；年龄和事项结构匹配，说明关键构成接近总体。因此 **选 B**。
4. A 只说明平台可能做得更好，没有证明调查样本可外推；C 与代表性无关；D 换成邻市，研究对象未接上。
5. **边界**：1200 人看似很多，但样本量大主要提高稳定性。若只在一个高满意度服务点拦访，再大的样本也可能系统偏向满意用户。

### 例题 9（解释机制：说明论据为什么支持论点）

**题**：某园区在厂房屋顶使用新型隔热涂层后，夏季空调用电量比上年同期下降。园区据此认为，该涂层能够降低厂房夏季空调用电。以下哪项如果为真，最能加强上述结论？

A. 涂层颜色与园区建筑风格协调

B. 该涂层能显著降低屋顶吸收的太阳辐射热，使室内制冷负荷下降

C. 部分员工认为涂层施工速度较快

D. 邻近园区也计划翻新厂房屋顶

**解析**：

1. 原论证从“使用涂层后用电下降”推出“涂层导致用电下降”，存在因果缺口。
2. B 给出“减少屋顶吸热 → 降低室内制冷负荷 → 减少空调用电”的完整机制，把原因与结果接起来，**选 B**。
3. A、C 只评价外观和施工，不进入“隔热—制冷负荷—用电”的因果链；D 与本园区结果无关。
4. **边界**：解释机制能加强因果关系，但若题目另有“同期全面更换高能效空调”等强他因，仍需综合比较；机制存在不等于它一定解释了全部变化。

## 十、自测练习

1. 只要天气晴朗，工地就开工。今天工地没有开工。由此可以推出（A. 今天天气不晴朗　B. 今天天气晴朗　C. 明天工地开工　D. 天气晴朗工地也可能不开工）
2. 班上丢失了班费。甲："不是我拿的。"乙："是甲拿的。"丙："乙在说谎。"只有一人说真话，班费是（ ）拿的。（A. 甲　B. 乙　C. 丙　D. 无法确定）
3. 某小区物业费涨价后，业主满意度反而上升了。物业经理据此宣传"涨价提升了服务质量，业主因此更满意"。最能削弱的是（A. 该调查仅回收了少量问卷　B. 同期小区刚完成了老旧电梯更换，出行体验大幅改善　C. 部分老业主仍不满意　D. 周边小区物业费更低）
4. 某单位从甲、乙、丙三人中选派一人驻村。甲说："我没被选上。"乙说："我被选上了。"丙说："乙没被选上。"三人中只有一人说真话，被选上的是（A. 甲　B. 乙　C. 丙　D. 无法确定）
5. 某阅读软件调查了连续使用该软件100天以上的用户，92%的受访者认为自己的专注力提高。据此认为，该软件可以提高所有新注册用户的专注力。最能削弱的是（A. 受访者以大学生为主　B. 能连续使用100天的人本就更自律，大量中途停用者没有进入调查　C. 软件内有多种阅读材料　D. 调查采用匿名方式）
6. 某企业上线新广告后，报表显示产品销量增长20%，因此认为新广告提高了销量。最能削弱的是（A. 同期行业整体销量有所增长　B. 内部审计发现报表将同一平台订单重复计算，实际销量并未增长　C. 部分消费者不喜欢新广告　D. 竞争对手也投放了广告）
7. 某校根据一个毕业班参加模拟面试后签约率较高，认为模拟面试能提高该校全体毕业生的签约率。最能加强的是（A. 该班学生都来自同一专业　B. 该班由各专业随机抽取学生组成，入训前成绩和求职意向结构与全体毕业生相近　C. 模拟面试老师有多年工作经验　D. 部分学生认为课程有趣）
8. 某公司认为，上线可反复观看的操作培训视频后，新员工的操作错误率会下降。该预测必须基于的假设是（A. 至少有一部分原本可能出现操作错误的新员工会在独立操作前实际学习该视频的相关内容　B. 老员工也喜欢观看培训视频　C. 视频制作成本低于线下讲座　D. 其他公司的培训视频时长相近）

### 答案附录

1. **A**（翻译：晴 → 开工；今天没开工 = 否后 → 否后推否前 → 今天不晴。B 肯定前件没发生；C 无关；D 是对规则本身的质疑，不是从题干推出的结论）。
2. **A**（矛盾对：乙"是甲拿的"与甲"不是我拿的"——一真一假 → 唯一真话在甲乙之中 → **丙说假话**。丙假 = 乙说的**不是**谎话 = 乙说真话 → 甲说假话 → "不是我拿的"为假 → **甲拿的**。回代验证：甲假 ✓、乙真 ✓、丙"乙在说谎"为假 ✓——恰好一真，自洽。验唯一性：若乙拿，甲真、乙假、丙真（2 真）✗；若丙拿，甲真、乙假、丙真（2 真）✗。**选 A**。
3. **B**（另有他因——电梯更换与“出行体验、满意度”直接相关，是本题中对满意度上升最具体的替代解释；它仍不等于证明涨价完全无效，只是其他选项更弱。A 仅说问卷少，未说明抽样偏差或结论不稳定到何种程度；C 是“部分”弱反例；D 是无关比较）。
4. **A**（矛盾对：乙"我被选上"与丙"乙没被选上"——一真一假 → 唯一真话在乙丙之中 → **甲说假话** → "我没被选上"为假 → **甲被选上**。回代验证：甲假 ✓、乙"我被选上"假（选的是甲）✓、丙"乙没被选上"真 ✓——恰好一真，**选 A**。结构完全同第 2 题：矛盾对锁定真话位置，剩余的人说假话，假话一反推即答案）。
5. **B**（题干由“长期坚持使用者”这一部分推到“所有新用户”，B 指出选择偏差：进入样本的人本就更自律，而且遗漏大量停用者，样本不能代表总体，属于“部分—整体 + 无代表性”拆桥。A 只说群体构成，没有说明与总体的关键差异；C、D 不削弱）。
6. **B**（题干的核心论据是“销量增长20%”，B 证明数据重复计算、实际并未增长，直接击毁唯一论据。A 是另有他因，但只说明行业增长可能贡献了一部分，未排除广告作用；C 是弱反例；D 与本企业销量上升原因没有建立关系）。
7. **B**（题干从“一个毕业班”推向“全体毕业生”，缺口是该班能否代表总体。B 说明跨专业随机抽取且关键结构相近，补上代表性桥梁。A 反而提示专业单一；C 可能加强培训质量，但没有解决样本外推问题；D 是主观感受）。
8. **A**（否定代入：若所有原本可能出错的新员工在独立操作前都没有学习相关视频，视频就不能通过所述机制降低错误率，预测失去成立条件。B、C、D 即使为假，也不妨碍“培训视频可能减少新员工错误”的论证）。

## 错题归因模板

做错时按五类归因，记入 [错题本.md](../../错题本.md)：

- **翻译错**："只有…才"方向反了、肯后/否前误用、"或且"处理错；
- **结构错**：没先拆论点论据就读选项、没有比较选项的实际影响；
- **削弱对象错**：把“论据有错”与“论据为真但推不出结论”混为一谈，或见到弱他因就直接选择；
- **规则错**：真假话没找矛盾对、日常结论扩大范围或无中生有；
- **方法错**：朴素逻辑没找突破口，硬排耗时。
