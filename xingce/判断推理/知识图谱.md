# 判断推理知识图谱

> 核心问题：题目中的对象之间存在什么稳定关系，这一关系能否覆盖全部条件并排除干扰项。

## 一、总图

    判断推理
    ├─ 图形推理
    │  └─ 位置 / 样式 / 数量 / 属性 / 空间
    ├─ 定义判断
    │  └─ 主体 / 客体 / 条件 / 方式 / 目的 / 结果
    ├─ 类比推理
    │  └─ 语义 / 集合 / 对应 / 语法 / 二级关系
    └─ 逻辑判断
       ├─ 翻译推理
       ├─ 集合推理
       ├─ 真假话
       ├─ 朴素逻辑
       └─ 论证推理

## 二、图形推理图谱

    图形元素相似？
    ├─ 是
    │  ├─ 位置变化
    │  │  └─ 平移 / 旋转 / 翻转 / 遍历
    │  └─ 样式变化
    │     └─ 叠加 / 去同存异 / 求同求异 / 黑白运算
    └─ 否
       ├─ 数量规律
       │  └─ 点 / 线 / 角 / 面 / 素 / 部分数
       ├─ 属性规律
       │  └─ 对称 / 曲直 / 开闭 / 凹凸
       └─ 空间规律
          └─ 折叠 / 拆纸 / 三视图 / 截面

### 2.1 数量节点的触发条件

| 图形特征 | 优先数什么 |
| --- | --- |
| 交叉明显 | 交点、奇点、笔画数 |
| 封闭区域多 | 面数、区域形状 |
| 线条规则 | 直线、曲线、横竖线 |
| 小元素重复 | 元素种类、数量、部分数 |
| 多边形突出 | 边数、角数、平行线 |

### 2.2 一笔画关系

    图形连通
       ↓ 数奇点
    奇点数 = 0 或 2 ⇒ 可以一笔画
    奇点数 > 2     ⇒ 最少笔画数通常为奇点数 ÷ 2

**验证规则：** 一个规律必须解释整组图形；只能解释相邻两图的“巧合”不能作为答案。

> 完整规律库见 [图推规律大全](图推规律大全.md)。

## 三、定义判断图谱

    定义
    ├─ 被定义对象
    ├─ 主体
    ├─ 客体
    ├─ 前提条件
    ├─ 行为方式
    ├─ 目的
    └─ 结果
       ↓
    选项逐要件匹配

### 3.1 要件关系

- “并且、以及、同时” → 要件通常需要同时满足；
- “或者、包括” → 可能是并列选择或列举，不能擅自改成全部满足；
- 目的要件 ≠ 实际结果：为了某目的实施，不代表一定实现；
- 主体要件优先排除：主体不符时，无须继续纠缠细节；
- 题目要求“不属于”时，先圈出否定词再匹配。

### 3.2 例证抽象

    生活案例
       ↓ 去掉故事细节
    主体做了什么
       ↓ 在什么条件下
    为何做 / 造成什么结果
       ↓
    与定义要件逐项对应

> 完整例题见 [定义判断专题](定义判断专题.md)。

## 四、类比推理图谱

    两个词项
       ↓ 先造句
    一级关系
    ├─ 语义：近义 / 反义 / 象征
    ├─ 集合：全同 / 包含 / 交叉 / 全异
    ├─ 对应：功能 / 工具 / 材料 / 场所 / 因果
    ├─ 组成：整体与部分
    └─ 语法：主谓 / 动宾 / 偏正
       ↓ 选项仍相似时
    二级关系
    ├─ 顺序是否一致
    ├─ 关系是否必然
    ├─ 主体是否一致
    ├─ 功能是主要还是次要
    └─ 词性和感情色彩是否一致

**集合关系：**

    全同：A = B
    包含：A ⊂ B 或 B ⊂ A
    交叉：A 与 B 有交集但互不包含
    全异：A 与 B 没有交集

> 关系表和二级辨析见 [类比推理专题](类比推理专题.md)。

## 五、形式逻辑图谱

### 5.1 条件命题

    P → Q
    ├─ 肯定 P ⇒ Q
    ├─ 否定 Q ⇒ 否定 P
    ├─ 肯定 Q ⇏ P
    └─ 否定 P ⇏ 否定 Q

| 语言 | 翻译 |
| --- | --- |
| 如果 P，那么 Q | P → Q |
| 只要 P，就 Q | P → Q |
| 只有 Q，才 P | P → Q |
| P 的必要条件是 Q | P → Q |
| 除非 Q，否则不 P | P → Q |

### 5.2 联言与选言

    P 且 Q 为真 ⇒ P、Q 都真
    P 或 Q 为真 ⇒ 至少一个真
    非（P 且 Q）= 非 P 或非 Q
    非（P 或 Q）= 非 P 且非 Q

### 5.3 量词

    所有 P 都是 Q
       ↔ 矛盾：有的 P 不是 Q

    所有 P 都不是 Q
       ↔ 矛盾：有的 P 是 Q

    有的 P 是 Q
       ⇒ 有的 Q 是 P
       ⇏ 所有 P 都是 Q

> 翻译、真假话和集合推理见 [逻辑判断专题](逻辑判断专题.md)。

## 六、论证推理图谱

    论据
       ↓ 通过隐含假设或逻辑桥梁
    论点

    削弱
    ├─ 攻击论点
    │  └─ 直接否定 / 范围匹配的反例
    ├─ 拆桥
    │  ├─ 直接论据与论点无关
    │  ├─ 部分不能推出整体
    │  ├─ 样本对总体没有代表性
    │  └─ 类比对象存在关键差异
    ├─ 攻击论据
    │  ├─ 论据无效：测量、对照或口径不能使用
    │  └─ 论据有错：数据、事实或实验条件错误
    └─ 攻击因果
       ├─ 因果倒置：B→A
       └─ 另有他因：C→B

    加强
    ├─ 加强论点
    │  └─ 新事实直接验证结论，范围与对象匹配
    ├─ 加强论据
    │  └─ 数据准确 / 测量有效 / 实验可重复
    ├─ 搭桥：论据概念 → 论点概念
    │  └─ 部分→整体：证明样本能够代表总体
    ├─ 解释机制
    │  └─ 补全 A 如何作用于 B 的因果链
    ├─ 补充举例
    │  └─ 存在结论可用一例；总体结论须看数量与代表性
    └─ 排除干扰
       └─ 排除他因 / 倒置 / 混杂变量

### 6.1 高频论证模型

| 模型 | 逻辑缺口 | 加强方向 | 削弱方向 |
| --- | --- | --- | --- |
| 因果论证 | 同时发生是否真由该原因造成 | 解释机制、控制变量、排除他因与倒置 | 他因、因果倒置、相关不等于因果 |
| 对比实验 | 两组是否只有一个变量不同 | 随机分组、对照有效、变量受控、结果可重复 | 对照失效、变量未控制、测量错误 |
| 调查推论 | 样本能否代表总体 | 随机分层、覆盖完整、结构与总体匹配 | 选择偏差、遗漏群体、回应偏差 |
| 部分—整体 | 局部规律能否覆盖全部对象 | 部分具有代表性、总体内部差异小 | 范围扩大、权重不足、内部差异 |
| 类比论证 | 两对象关键属性是否相同 | 证明关键条件相同 | 本质差异、适用条件不同 |
| 措施有效 | 措施能否解决目标问题 | 能执行、机制成立、必要资源具备 | 无法执行、目标错位、副作用 |

### 6.2 削弱力度图

    比较选项
       ↓ 是否攻击核心论点或唯一支柱
    命中核心？
       ↓ 再看范围是否覆盖论点
    范围匹配？
       ↓ 再看事实是否确定、条件是否可靠
    能否让论证直接坍塌？

- 论据为真但推不出结论 → 拆桥；论据本身无效或错误 → 攻击论据；
- 样本少不必然无代表性，选择偏差、遗漏关键群体更关键；
- 因果倒置改变因果方向，通常较直接；
- 另有他因若只提供一种可能，往往仍允许原原因成立，常需比较是否有更强选项；若他因充分解释结果或控制后原关系消失，也可以很强；
- 不存在对所有题都有效的固定排序，最终看选项对当前论证的实际破坏程度。

### 6.3 加强与前提图

    先看问法
    ├─ 最能加强 / 支持
    │  └─ 比较谁最能填补核心缺口
    ├─ 基于哪项假设 / 必须具备的前提
    │  └─ 否定代入：否掉后论证必塌
    ├─ 使论证成立 / 有效
    │  └─ 常考补桥或足够条件，回代检查能否推出
    └─ 除哪项外均能加强
       └─ 找唯一无关、削弱或未提供支持的项

    部分样本 → 总体结论
       ↓ 需要“样本代表总体”
    随机抽样 + 合理分层 + 覆盖关键群体 + 结构匹配
       ↓
    加强“部分 → 整体”的桥梁

- 样本量大主要降低随机波动，不能修复选择偏差；
- 同一来源的重复证据未必独立，不能机械累加力度；
- 能加强不等于必要；足够搭桥也不自动等于严格必要条件；
- 加强力度看是否命中核心缺口、范围是否覆盖、事实是否确定，不背固定排序。

## 七、朴素逻辑图谱

    多对象 + 多条件
       ↓
    先找确定条件
       ├─ 唯一项
       ├─ 最大限制
       ├─ 相邻/不相邻
       └─ 先后/对应
       ↓
    选择工具
       ├─ 列表
       ├─ 连线
       ├─ 排序
       ├─ 假设
       └─ 代入排除
       ↓
    回代全部条件
