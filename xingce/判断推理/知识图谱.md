# 判断推理知识图谱

> 核心问题：题目中的对象之间存在什么稳定关系，这一关系能否覆盖全部条件并排除干扰项。

## 一、总图

    判断推理
    ├─ 图形推理
    │  └─ 位置 / 样式 / 数量 / 属性 / 空间
    ├─ 定义判断
    │  └─ 主体 / 客体 / 条件 / 方式 / 目的 / 结果
    ├─ 类比推理
    │  └─ 语义 / 集合 / 对应 / 语法 / 二级关系
    └─ 逻辑判断
       ├─ 翻译推理
       ├─ 集合推理
       ├─ 真假话
       ├─ 朴素逻辑
       └─ 论证推理

## 二、图形推理图谱

    图形元素相似？
    ├─ 是
    │  ├─ 位置变化
    │  │  └─ 平移 / 旋转 / 翻转 / 遍历
    │  └─ 样式变化
    │     └─ 叠加 / 去同存异 / 求同求异 / 黑白运算
    └─ 否
       ├─ 数量规律
       │  └─ 点 / 线 / 角 / 面 / 素 / 部分数
       ├─ 属性规律
       │  └─ 对称 / 曲直 / 开闭 / 凹凸
       └─ 空间规律
          └─ 折叠 / 拆纸 / 三视图 / 截面

### 2.1 数量节点的触发条件

| 图形特征 | 优先数什么 |
| --- | --- |
| 交叉明显 | 交点、奇点、笔画数 |
| 封闭区域多 | 面数、区域形状 |
| 线条规则 | 直线、曲线、横竖线 |
| 小元素重复 | 元素种类、数量、部分数 |
| 多边形突出 | 边数、角数、平行线 |

### 2.2 一笔画关系

    图形连通
       ↓ 数奇点
    奇点数 = 0 或 2 ⇒ 可以一笔画
    奇点数 > 2     ⇒ 最少笔画数通常为奇点数 ÷ 2

**验证规则：** 一个规律必须解释整组图形；只能解释相邻两图的“巧合”不能作为答案。

> 完整规律库见 [图推规律大全](图推规律大全.md)。

## 三、定义判断图谱

    定义
    ├─ 被定义对象
    ├─ 主体
    ├─ 客体
    ├─ 前提条件
    ├─ 行为方式
    ├─ 目的
    └─ 结果
       ↓
    选项逐要件匹配

### 3.1 要件关系

- “并且、以及、同时” → 要件通常需要同时满足；
- “或者、包括” → 可能是并列选择或列举，不能擅自改成全部满足；
- 目的要件 ≠ 实际结果：为了某目的实施，不代表一定实现；
- 主体要件优先排除：主体不符时，无须继续纠缠细节；
- 题目要求“不属于”时，先圈出否定词再匹配。

### 3.2 例证抽象

    生活案例
       ↓ 去掉故事细节
    主体做了什么
       ↓ 在什么条件下
    为何做 / 造成什么结果
       ↓
    与定义要件逐项对应

> 完整例题见 [定义判断专题](定义判断专题.md)。

## 四、类比推理图谱

    两个词项
       ↓ 先造句
    一级关系
    ├─ 语义：近义 / 反义 / 象征
    ├─ 集合：全同 / 包含 / 交叉 / 全异
    ├─ 对应：功能 / 工具 / 材料 / 场所 / 因果
    ├─ 组成：整体与部分
    └─ 语法：主谓 / 动宾 / 偏正
       ↓ 选项仍相似时
    二级关系
    ├─ 顺序是否一致
    ├─ 关系是否必然
    ├─ 主体是否一致
    ├─ 功能是主要还是次要
    └─ 词性和感情色彩是否一致

**集合关系：**

    全同：A = B
    包含：A ⊂ B 或 B ⊂ A
    交叉：A 与 B 有交集但互不包含
    全异：A 与 B 没有交集

> 关系表和二级辨析见 [类比推理专题](类比推理专题.md)。

## 五、形式逻辑图谱

### 5.1 条件命题

    P → Q
    ├─ 肯定 P ⇒ Q
    ├─ 否定 Q ⇒ 否定 P
    ├─ 肯定 Q ⇏ P
    └─ 否定 P ⇏ 否定 Q

| 语言 | 翻译 |
| --- | --- |
| 如果 P，那么 Q | P → Q |
| 只要 P，就 Q | P → Q |
| 只有 Q，才 P | P → Q |
| P 的必要条件是 Q | P → Q |
| 除非 Q，否则不 P | P → Q |

### 5.2 联言与选言

    P 且 Q 为真 ⇒ P、Q 都真
    P 或 Q 为真 ⇒ 至少一个真
    非（P 且 Q）= 非 P 或非 Q
    非（P 或 Q）= 非 P 且非 Q

### 5.3 量词

    所有 P 都是 Q
       ↔ 矛盾：有的 P 不是 Q

    所有 P 都不是 Q
       ↔ 矛盾：有的 P 是 Q

    有的 P 是 Q
       ⇒ 有的 Q 是 P
       ⇏ 所有 P 都是 Q

> 翻译、真假话和集合推理见 [逻辑判断专题](逻辑判断专题.md)。

## 六、论证推理图谱

    论据
       ↓ 通过隐含假设或逻辑桥梁
    论点

    削弱
    ├─ 否定论点
    ├─ 反驳论据
    ├─ 切断论据与论点
    ├─ 提供他因
    ├─ 因果倒置
    └─ 给出反例

    加强
    ├─ 补充新论据
    ├─ 建立论据与论点联系
    ├─ 排除其他原因
    ├─ 解释机制
    └─ 增加代表性或可靠性

### 6.1 高频论证模型

| 模型 | 逻辑缺口 | 优先检查 |
| --- | --- | --- |
| 因果论证 | 同时发生是否真由该原因造成 | 他因、反向因果、机制 |
| 对比实验 | 两组是否只有一个变量不同 | 样本、控制变量、随机性 |
| 调查推论 | 样本能否代表总体 | 样本量、抽样方式、回应偏差 |
| 类比论证 | 两对象关键属性是否相同 | 本质差异、适用条件 |
| 措施有效 | 措施能否解决目标问题 | 执行条件、副作用、替代方案 |

**强弱判断：** 相关性越直接、对核心缺口影响越大、条件越可信，通常力度越强；不存在对所有题都有效的固定选项排序。

## 七、朴素逻辑图谱

    多对象 + 多条件
       ↓
    先找确定条件
       ├─ 唯一项
       ├─ 最大限制
       ├─ 相邻/不相邻
       └─ 先后/对应
       ↓
    选择工具
       ├─ 列表
       ├─ 连线
       ├─ 排序
       ├─ 假设
       └─ 代入排除
       ↓
    回代全部条件

## 八、错题回挂图

| 错因 | 回挂节点 | 修正动作 |
| --- | --- | --- |
| 图推规律能解释两图不能解释全组 | 图形验证 | 用规律逐图验一遍 |
| 定义题凭生活常识选 | 定义要件 | 逐项标主体、条件、方式 |
| 类比二选一 | 二级关系 | 造完整句并比较必然性 |
| 翻译箭头写反 | 条件命题 | 圈“谁是必要条件” |
| 削弱题只看话题相关 | 论证结构 | 先写论点、论据、缺口 |
