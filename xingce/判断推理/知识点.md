## 一、总纲：题型谱系与做题三步法

| 题型 | 提问标志 | 核心方法 | 深入 |
|---|---|---|---|
| 图形推理 | 给图问"下一个 / 分组" | 三步定位法：先看元素相同度定大类 | [图推规律大全](图推规律大全.md) |
| 定义判断 | "属于 / 不属于该定义" | 圈要件 → 逐项排除（一处不合即杀） | [定义判断专题](定义判断专题.md) |
| 类比推理 | "A:B 相当于" | 先横后纵：横向找关系、纵向比优劣 | [类比推理专题](类比推理专题.md) |
| 逻辑判断 | "可以推出 / 削弱加强 / 排序匹配" | 形式题翻译套公式；论证题拆结构 | [逻辑判断专题](逻辑判断专题.md) |

**共用三步法**：① 看提问定题型（先读问法再读题干）→ ② 按题型走核心动作（图推看元素、定义圈要件、类比造句、逻辑翻译/拆论证）→ ③ 排除到唯一，纠结时回题干找"裁决句"。

> 四个题型的共性纪律：**题干为王，常识靠边**——定义判断不用自己的理解替换定义，类比不凭"顺口"不造句，逻辑"只认规则不认内容"。

## 二、图形推理：三步定位法（先定大类，再套规律）

| 步骤 | 元素特征 | 指向大类 |
|---|---|---|
| ① | 元素**完全相同**，只有位置在变 | **位置类**：平移（步长恒定/递增）/ 旋转（45°/90°/180°）/ 翻转（改变手性） |
| ② | 元素**部分相同**，行内相似、线条有重叠 | **样式类**：遍历（缺啥补啥）/ 去同存异 / 去异存同 / 黑白运算（现场学规则） |
| ③ | 元素**完全不同**，图形杂乱 | **数量类**（面→线→素→点→角）或**属性类**（对称/曲直/开闭） |

**必考概念——一笔画与奇点**：

- 奇点 = 从该点出发有**奇数条线**的点，**端点也是奇点**；
- 有线条的连通图奇点数0或2 → 一笔画；**最少笔画数 = max(1，奇点数÷2)**；不连通时各部分分别算后相加；
- 奇点必有偶数个——数出 3 个、5 个必是数错了（自查信号）。

**高频二级规律**：对称轴**方向**逐图转 45°、对称轴**条数**成数列、属性做门槛 + 数量做规律（国考爱叠两个规律）。

**空间类两板斧**：① **相对面排除**——"Z 字两端"或"同层隔一"的面互为相对面，立体图上不可能同时可见，见即排除；② **时针法**——对相邻面按公共顶点记录三个面的顺序，展开图与选项转向不一致即排除。

**汉字/字母/数字**：当图形看，优先级**笔画 → 封闭面 → 部分数 → 曲直 → 求同**，两条规律交叉验证再定答案。

**分组分类题**（6 图分两组）：规律必然"跨图形共享"（一笔画 / 奇偶 / 对称），**答案分布必为 3+3**——分布本身就是验证手段。

## 三、定义判断：要件体系（戴着镣铐对号入座）

**六类要件**（读定义边读边圈）：

| 要件 | 标志词 | 比对要点 |
|---|---|---|
| 主体 | "行政机关""企业""个人" | 行为人身份对不对 |
| 客体 | "对……""针对……" | 作用在谁身上 |
| 目的 | "为了……""以……为目的" | 动机是否吻合 |
| 方式 | "通过……""以……方式" | 手段是否吻合 |
| 条件 | "在……情况下""依法""经批准" | 前提是否满足 |
| 结果 | "造成……""使得……" | 后果是否吻合 |

**判断规则**：先区分必要条件、并列可选条件与说明性内容。被定义明确要求同时具备的要件**缺一不可**；选项违反任一必要条件即可排除。不能把未出现“或”的所有描述都机械视为必要条件；条件越多，越要逐项标注其逻辑角色。

**三条纪律**：

1. **先看提问再比对**——"属于"还是"**不属于**"（每年代价最高的丢分）；
2. **题干为王，常识靠边**——常识里的"职业倦怠"表现不在题干要件里就不选；
3. **多定义题只精读提问所指的那一个**，其余扫一眼防混淆即可。

**法律类高频分界**：**许可给"资格"（事前放行）、确认认"事实"（事后盖章）、处罚施"制裁"（对违法）**。

## 四、类比推理：关系体系 + 二级辨析

**做题两步**：先**横向**（A:B 是什么关系，造"最小句子"套所有选项）→ 再**纵向**（多个选项都对时，比谁与题干"最像"）。

**关系体系压缩表**：

| 大类 | 关系 | 最小句子 |
|---|---|---|
| 语义 | 近义 / 反义 / 象征 | A 与 B 意思相近（相反 / A 象征 B） |
| 集合 | **种属**（is-a）/ **组成**（part-of）/ 交叉 / 全异 | A 是 B 的一种 / A 是 B 的一部分 / 有的 A 是 B / A 与 B 同层并列 |
| 对应 | 功能 / 场所 / 因果 / 工具+动作 / 原料+成品 / 职业+工具 / 作者+作品 | A 的功能是 B；A 导致 B…… |
| 语法 | 主谓 / 动宾 / 偏正 | 司机:驾驶；履行:承诺；湛蓝:天空 |

**二级辨析六条**（多选项都对时比什么）：词性结构、**顺序**（方向也是关系的一部分）、**必然/或然**（地震不必然引发海啸；缺氧是否致死取决于程度与时长）、感情色彩、具体/抽象、**物理/化学变化**（冰变水属于物态变化；酿酒涉及化学变化；发酵制馒头包含多种变化，不能整体概括为纯物理变化）。

**两大高频裁决点**（从专题例题提级的概念）：

- **种属 vs 组成**：能用"A 是 B 的一种"说通是种属；"轮胎:汽车"是组成、"轿车:汽车"是种属；
- **矛盾 vs 反对**（全异的细分）：**找中间态**——"出席:缺席"无中间态是矛盾关系；"白:黑"之间有灰、"上:下"之间有中，是反对关系；
- 功能关系分**主次**：白醋:消毒是次要功能——真题爱把主要功能选项排满，只有一个是次要。

## 五、逻辑判断（形式题）：翻译 + 真假话

**翻译规则表**（背熟）：

| 题干说法 | 翻译 | 记法 |
|---|---|---|
| 如果 P，那么 Q / 只要 P，就 Q | P → Q | 前推后 |
| **只有 Q，才 P** / 除非 Q，否则不 P | P → Q | **后推前** |
| P 是 Q 的必要条件 | Q → P | 必要在后被推 |
| 所有 P 都是 Q | P → Q | 前推后 |
| 有的 P 是 Q | 存在同时属于P与Q的对象 | 可换位为“有的Q是P”；不能推成全称命题 |

**推理规则**：

- **逆否等价**：P → Q ⇔ ¬Q → ¬P；此外，已知P→Q，肯前可肯后，否后可否前；
- **肯后、否前不必然**；弱表述也须有题干依据，不能仅凭“可能/不一定”选答案；
- 传递连锁：P → Q，Q → R ⇒ P → R；
- 德摩根：¬(P∧Q) = ¬P∨¬Q；"李**和**张都参加"的否命题是"**至少一个**不参加"。

**真假话矛盾法四步**：找矛盾 → 绕开矛盾 → 判断其余真假 → 回代验证。

| 原命题 | 矛盾命题 |
|---|---|
| 所有 S 都是 P | 有的 S 不是 P |
| 所有 S 都不是 P | 有的 S 是 P |
| P → Q | P 且 ¬Q |
| "是我做的" vs "不是我做的" | 单称必一真一假 |

> 三句话只有一真：真话必在矛盾对中 → **其余全假**；只有一假：假话必在矛盾对中 → 其余全真。

## 六、逻辑判断（论证题）：拆论证 + 影响比较

**拆论证三问**：论点是什么（"因此/专家认为"之后或首句）？论据是什么（调查、数据、实验）？**论据到论点之间跳了哪一步**（暗含的桥梁）——削弱和加强都打这里。

**削弱按攻击对象分类**：

| 攻击对象 | 核心作用 | 高频形式 |
|---|---|---|
| 论点 | 证明结论本身不成立 | 直接反例、相反事实；范围须与论点匹配 |
| 论据—论点的桥梁 | 承认论据为真，但指出推不出论点 | 直接论据与结论无关、部分推整体、样本无代表性、类比对象有关键差异 |
| 论据 | 证明证据不能使用或事实有错 | 测量无效、口径错误、重复统计、数据造假、实验条件不成立 |
| 因果关系 | 动摇“A 导致 B” | 因果倒置 B→A；另有他因 C→B |

**三组边界**：

- 论据是真的但与结论无关 → **拆桥**；论据本身虚假、测量失效或统计有错 → **削弱论据**；
- 从部分样本推总体时，只有指出选择偏差、遗漏关键群体或样本结构明显不同，才能有力说明“不具代表性”；仅说“样本少”通常不够；
- 因果倒置直接改变因果方向；另有他因通常只说明原原因不是唯一解释，未必排除原原因也有作用。若他因能充分解释结果，或控制他因后原关系消失，也可能形成很强削弱。

**力度比较**：不存在固定排名。先看是否击中核心论点或唯一支柱，再看范围是否覆盖、表述是确定事实还是可能性、附加条件是否可靠。直接否定论点、击毁唯一论据和彻底拆桥通常都属于强削弱；模糊他因、个别反例和笼统质疑通常较弱，但仍以具体选项为准。

**加强按支援位置分类**：

| 加强位置 | 核心作用 | 高频形式与边界 |
|---|---|---|
| 加强论点 | 用新事实直接支持结论 | 后续验证、对照结果与结论一致；对象、时间和范围须匹配 |
| 加强论据 | 提高原证据的可靠性 | 数据来源权威、测量准确、实验可重复；论据可靠不等于已搭好桥梁 |
| 搭桥 | 补上“论据 → 论点”的隐含关系 | 从论据概念推向论点概念，方向要顺、对象要接、范围要够 |
| 解释机制 | 说明为什么 A 能导致 B | 给出完整作用链；只换一种说法重复题干不算解释 |
| 补充举例 | 再给一个与结论一致的实例 | 对存在性结论可能很强；对全称或总体结论，单个正例通常很弱 |
| 排除干扰 | 排除他因、倒置或关键混杂变量 | 因果论证中常见；要排除与结果真正相关的竞争解释 |

**部分—整体的加强**：题干由样本、局部或某一时段推向总体，需要证明“部分能够代表整体”。优先找随机抽样、合理分层、样本结构与总体相近、覆盖关键群体、无系统性遗漏或选择偏差。**样本量大只会提高估计稳定性，不自动保证代表性**；从同一来源重复取样也不等于多份独立证据。

**前提假设要先看问法**：“最能加强/支持”是在比较支持力度；“基于哪项假设”“必须具备的前提”是在找必要条件，可用否定代入；“使论证成立/有效”常考补桥或足够条件，应回代检验能否推出结论；“除哪项外均能加强”先圈出反向设问。否定某选项后，若原论证必然失去成立条件，该项才是必要前提。**能加强不等于必需，足以搭桥也不必然是严格必要条件。**

**搭桥方向与范围**：论据“有的 S 是 P”要推出论点“有的 S 是 Q”，可补“所有 P 都是 Q”（P → Q）。例如“有的上位者不愿动脑”要推出“有的上位者缺乏主动性、创造性”，桥梁是“不愿动脑 → 缺乏主动性、创造性”。反向的 Q → P 不能保证推出；“某些 P 是 Q”也不能保证这些对象属于 S。充分搭桥不自动等于严格必要条件，否定“所有 P 都是 Q”应是“有的 P 不是 Q”。完整方法与题目解析见 [逻辑判断专题 §5.4、例题 7](逻辑判断专题.md)。

**高频论证模型速查**：

| 模型 | 特征 | 加强时优先检查 | 削弱时优先检查 |
|---|---|---|---|
| 因果论证 | “因为 A，所以 B” | 作用机制、排除他因与倒置、控制变量 | 因果倒置 / 另有他因 / 相关不等于因果 |
| 调查归纳 | “样本如此，所以总体如此” | 随机分层、结构匹配、覆盖完整 | 选择偏差 / 遗漏群体 / 样本无代表性 |
| 部分—整体 | “局部成立，所以整体成立” | 部分具有代表性、总体内部差异小 | 范围扩大 / 内部差异 / 部分权重不足 |
| 类比论证 | “甲地有效，乙地也会有效” | 证明两地关键条件相同 | 指出甲乙的**关键差异** |
| 实验论证 | “实验组变化，所以处理有效” | 随机分组、有效对照、变量受控、结果可重复 | 对照失效 / 变量未控制 / 测量错误 |
| 措施论证 | “实施政策 → 达到目标” | 可执行、机制成立、关键条件具备 | 无法执行 / 达不到目标 / 有更糟副作用 |

**日常结论（“可以推出”）**：核对命题的范围、条件和证据。强表述需要足够强的依据，但不是必错；弱表述也可能无中生有。原文没有直接比较仍可能通过条件推得比较，关键是推导是否成立。

## 七、朴素逻辑：把自然语言约束变成表格

### 7.1 条件类型

| 条件 | 形式化动作 | 最小例证 |
| --- | --- | --- |
| 唯一对应 | 表格打✓，同行同列排除其他项 | 甲只能选C，则甲—C确定 |
| 否定对应 | 表格打✗ | 乙不去北京 |
| 先后顺序 | 写不等式链或序列 | 甲早于乙、乙早于丙 ⇒ 甲＜乙＜丙 |
| 相邻 | 捆绑成整体或列相邻位置 | 甲乙必须相邻 |
| 不相邻 | 排除相邻位置或用插空 | 甲乙至少隔一位 |
| 二选一 | 分支假设 | 甲或乙参加且只有一人参加 |
| 条件联动 | 翻译箭头并传递 | 甲去→乙去，乙不去→甲不去 |

### 7.2 工具选择

    条件少、选项给完整结果 → 代入排除
    多对象多属性一一对应 → 列表
    名次、年龄、时间先后 → 排序链
    “相邻/连续”条件多 → 捆绑与位置图
    出现二选一或条件链 → 假设分支

### 7.3 突破口

优先处理唯一项、限制最多项、能形成最长传递链的条件，以及同时出现在多条条件中的对象。突破口不是“第一句话”，而是能一次排除最多可能性的条件。

### 7.4 边界

- “A或B”若未说明排他，通常至少一个成立，不能自行理解成只能一个；
- 先后关系不等于紧邻关系；
- “甲不比乙早”通常表示甲与乙同时或更晚，是否允许同时要看题设；
- 代入选项时必须核对全部条件，不能满足一两条就作答。

### 7.5 最小例证

甲、乙、丙分别去北京、上海、成都，已知甲不去北京，乙不去上海，去成都的不是甲；若甲去上海，则乙只能去北京、丙去成都。列表法比逐句口算更稳定。

### 7.6 自测

1. “甲早于乙”能否推出甲与乙紧邻？
2. 选项给出完整人员排序时，优先采用什么方法？
3. 为什么“限制最多的对象”适合作突破口？

**答案：** 1. 不能；2. 代入排除；3. 一次可排除更多可能性并触发连锁条件。

## 八、高频陷阱清单（丢分重灾区）

| 陷阱 | 表现 | 破解 |
|---|---|---|
| **图推恋战** | 单规律做不出死磕 | 单规律不成，回第一步排除的方向做二级验证；40 秒不成即蒙 |
| **定义看错提问** | "不属于"没看见 | 读题第一动作永远是读问法 |
| **常识替换题干** | 定义/逻辑里用自己的经验答题 | 题干为王，常识靠边 |
| **种属组成混** | "轮胎:汽车"当选种属 | "A 是 B 的一种"说通才是种属 |
| **方向反了** | 类比题干 A:B、选项 B:A；"只有…才"翻译反 | 方向也是关系的一部分；"只有…才"后推前 |
| **肯后否前当推理** | P→Q 就以为 Q→P | 肯前、否后有效；肯后、否前不必然 |
| **削弱机械排位** | 见“倒置/否论据/他因”等标签就决定强弱 | 先定位关键论证，再比较实际影响；另有他因不天然最强 |
| **真假话硬猜** | 不找矛盾对逐人猜 | 矛盾法四步是固定套路 |
| **强弱表述机械优选** | 见“可能”就选、见“必然”就排 | 看题干能否支持该范围与强度 |
| **朴素逻辑从零硬排** | 不找突破口，时间黑洞 | 限制最多的元素先处理 |

---

## 九、考场策略

1. **时间盘子**：40 题 35 分钟——图推单题 ≤50 秒（不成即蒙）、定义判断 40-50 秒、类比 30-40 秒（最快，可抢时间）、逻辑判断 60-80 秒。
2. **顺序**：类比（快）→ 定义（稳）→ 逻辑（深）→ 图推（卡壳蒙），或按个人习惯，但**图推和朴素逻辑设硬性止损**。
3. **超时处理**：先跳过难题，最后依据排除结果补答。四选一完全随机猜测的理论命中率为25%，不代表实际能稳定拿到25%，也没有“弱表述天然更容易对”的保证。
4. **复盘**：错题按"选刀错（题型方法没用对）/ 规则错（翻译方向、矛盾对、力度排序）/ 常识错（用经验替换题干）/ 恋战错（超时硬磕）"归因，记入 [错题本.md](../../错题本.md)。

## 附：考前速查卡（5 分钟过一遍）

| 考点 | 一句话抓手 |
|---|---|
| 图推定大类 | 相同→位置；相似→样式；杂乱→数量（面线素点角）/属性 |
| 一笔画 | 奇点 0 或 2；笔画 = 奇点÷2；端点也是奇点；奇点必为偶数个 |
| 折纸盒 | Z 字两端/同层隔一 = 相对面，不能同时可见；相邻面查时针 |
| 汉字字母 | 笔画 → 封闭面 → 部分数 → 曲直 → 求同 |
| 分组题 | 规律跨图共享，答案必 3+3 |
| 定义要件 | 主体/客体/目的/方式/条件/结果，一处不合即排除 |
| 许可/确认/处罚 | 给资格（事前）/ 认事实（事后）/ 施制裁（对违法） |
| 类比两步 | 先横后纵：横向同关系，纵向比词性/顺序/必然性 |
| 种属 vs 组成 | "A 是 B 的一种"说通 = 种属 |
| 矛盾 vs 反对 | 找中间态：无 = 矛盾，有 = 反对 |
| 翻译 | 如果…那么前推后；只有…才后推前；逆否等价，肯前和否后有效 |
| 真假话 | 找矛盾 → 绕开 → 其余定真假 → 回代；一真则矛盾对外全假 |
| 削弱分类 | 否论点 / 拆桥（无关、部分整体、无代表性）/ 削弱论据（无效、有错）/ 倒置 / 他因 |
| 削弱力度 | 击中核心、覆盖范围、事实确定、条件可靠；不套固定排序，弱他因常须与更强项比较 |
| 加强分类 | 加强论点 / 加强论据 / 搭桥 / 解释机制 / 补充举例 / 排除干扰 |
| 部分整体加强 | 证明样本代表总体：随机、分层、覆盖完整、结构匹配；样本大不等于有代表性 |
| 前提假设 | 见“前提/假设/必须条件”用否定代入；否掉它论证必塌才是必要条件 |
| 日常结论 | 能从题干推出才选，强弱措辞不是答案规则 |
