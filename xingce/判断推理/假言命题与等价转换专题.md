# 假言命题与等价转换专题

> 从“怎么翻译”一直学到“怎么改写、怎么否定、怎么推理、怎么找反例”。重点不是只背逆否，而是分清等价、推论和矛盾，准确处理充分必要、除非句式、复合条件、充要条件及量词范围。
> 本专题细分28个知识点，并配6道综合精讲、12道自测及逐题解析。例题均为自编规则练习，不标作历年真题；判断推理主干编号仍见 [逐点精讲22—28](逐点精讲.md#四-形式逻辑)。

## 命题基础

### H01 命题与逻辑符号

**概念：** 命题是可判断真假的陈述。先把一整件事设为一个字母，不能一会儿让P代表“报名”，一会儿又代表“没有报名”。

| 符号 | 含义 | 例子 |
| --- | --- | --- |
| `P`、`Q` | 完整命题 | P为“小李报名”，Q为“小李缴费” |
| `¬P` | P的否定 | 小李没有报名 |
| `P ∧ Q` | P且Q | 报名并且缴费 |
| `P ∨ Q` | P或Q，至少一真 | 报名或者缴费，允许两者都真 |
| `P → Q` | 如果P，那么Q | 报名就缴费 |
| `P ↔ Q` | P当且仅当Q | 报名与缴费互为条件 |
| `A ≡ B` | 两个表达式逻辑等价 | 在所有真值组合下同真同假 |
| `A ⇒ B` | A成立时B必成立 | 已知A可推出B，不保证反推 |

**操作：** 定字母 → 保留否定词 → 给复合条件加括号 → 写完整式子。本文用括号明确范围，不让“且、或、箭头”的结合次序靠猜。

**例子：** “如果报名，就提交材料并缴费”是 `P → (Q ∧ R)`，不是 `(P → Q) ∧ R`；后一式无论是否报名都要求R成立，信息更强。

**易错：** “并非P或Q”可能存在语义范围歧义。题干若指“并非二者至少一个成立”，应写 `¬(P ∨ Q)`；若指“非P，或者Q”，则是 `¬P ∨ Q`。

### H02 假言命题的真值与唯一反例

**规则：** `P → Q`只排除“P真而Q假”。

| P | Q | P → Q | 是否违反条件 |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 否 |
| 真 | 假 | 假 | 是，唯一违例 |
| 假 | 真 | 真 | 否 |
| 假 | 假 | 真 | 否 |

**理解：** “报名者必须缴费”被“报名却没缴费”反驳；没报名的人是否缴费，都不违反这条规则。条件句不是说P一定发生，更不是说P、Q同时发生。

**例子：** 规则为“提交申请就参加面试”。小李没有提交申请，仍可能因另一渠道参加面试，也可能不参加；这两个情形都不违反该条件。

**边界：** 前件假时，本次真值计算把条件句判真，并不是凭“某人没有申请”就验证了现实中所有申请者都参加面试。个人情形、全称规则和经验因果要分开。

**错因：** 把假言句当事实句；把“没P”误认为整条 `P → Q`为假。

### H03 充分条件与必要条件

**概念：** 在 `P → Q`中，P是Q的充分条件，Q是P的必要条件。充分表示“有它足以推出”，必要表示“没有它就不成立”；两者都相对于指定的另一命题。

| 说法 | 翻译 | 自编例子 |
| --- | --- | --- |
| P是Q的充分条件 | `P → Q` | 是正方形 → 是长方形 |
| P是Q的必要条件 | `Q → P` | “偶数”是“4的倍数”的必要条件 |
| P是Q的充分必要条件 | `P ↔ Q` | 整数能被2整除，当且仅当它是偶数 |

**如何判断：** 把句子改成“要有谁，就必须有谁”。“P是Q的必要条件”意味着“要Q，必须P”，所以是Q推P。

**例子：** 设P为“该整数为4的倍数”，Q为“该整数为偶数”。P足以保证Q；但6是偶数，不是4的倍数，说明Q单独不能保证P。

**易错：** “充分条件”不一定是唯一途径，“必要条件”不一定足以达成目标。题干只给一个方向时，不能加上“且仅当”。

### H04 等价关系与单向推出及矛盾关系

**等价：** A与B在所有真值组合下都同真同假，可双向替换。例如 `P → Q ≡ ¬Q → ¬P`。

**推出：** 满足A的每种情形也满足B，但B可能比A弱。例如 `P ∧ Q ⇒ P`；只有P不保证Q，故不等价。

**矛盾：** A与 `¬A`总是一真一假。例如 `P → Q`与 `P ∧ ¬Q`矛盾，不是等价。

**检验方法：** 等价要找“原句与选项真假不一致”的情形；必然推出要找“题干全真但选项假”的情形；矛盾则要核对是否恰好是整句否定。

**例子：** “报名且缴费”可推出“报名或缴费”，但未报名、已缴费使后者真而前者假。因此二者不等价。

**易错：** 由一条条件推得的必要结果，不一定与原条件完整等价；只在某一种实际情形下同真，也不是逻辑等价。

## 关键词与句式翻译

### H05 如果和只要等充分条件句

**句式：** “如果P，那么Q”“只要P，就Q”“一旦P，就Q”，按题干明确的条件关系写 `P → Q`。前件P可以带否定或包含多个条件。

“P足以保证Q”“有P即可Q”“P是Q的充分条件”也采用同一方向。“P有助于Q”“P通常伴随Q”则没有保证，不能直接并入这组必然条件句。

**例子：** “只要没有补交材料，就不能进入复审。”设M为“补交材料”、R为“进入复审”，翻为 `¬M → ¬R`，逆否为 `R → M`。

**步骤：** 圈出完整“只要”范围 → 圈出完整“就”范围 → 各自翻译 → 前推后。不能先去掉否定词，再凭语感补回来。

**边界：** “凡是P都是Q”一般还含对同类对象的全称限定，简写箭头时必须保持同一对象；“可能P则可能Q”不能把“可能”删掉变成必然规则。

### H06 只有和必须等必要条件句

**句式：** “只有P，才Q”翻为 `Q → P`。“要Q，必须P”“P是Q必不可少的条件”同向翻译。

“Q仅当P成立时才成立”“Q离不开P”“P是Q的前提”在题干明确表示必要条件时，也都是 `Q → P`。措辞虽把P放在不同位置，判断方法仍是“要Q，不能缺P”。

**例子：** “只有完成备案，才能上线。”设B为备案、U为上线，得到 `U → B`，等价于 `¬B → ¬U`，不是 `B → U`。

**理解：** 上线的人／项目不能缺备案，但备案后可能仍需测试、审批等条件。本句没有保证备案足以上线，也没有断定已上线或已备案。

**易错：** “P才Q”与“P就Q”方向不同；“必须P”要找到它服务的目标Q，而不是看到P在句子前面就让P作箭头前件。

### H07 除非否则句的统一翻译

**通式：** “除非P，否则Q”先改成“如果不P，那么Q”：

`¬P → Q ≡ ¬Q → P ≡ P ∨ Q`。

| 完整句式 | 第一步翻译 | 等价改写 |
| --- | --- | --- |
| 除非P，否则Q | `¬P → Q` | `¬Q → P`；`P ∨ Q` |
| 除非P，否则不Q | `¬P → ¬Q` | `Q → P`；`P ∨ ¬Q` |
| 除非不P，否则Q | `P → Q` | `¬Q → ¬P` |
| 除非不P，否则不Q | `P → ¬Q` | `Q → ¬P` |

**例子一：** “除非获批，否则暂停。”记A为获批、S为暂停，翻 `¬A → S`。没获批须暂停；没有暂停可推出获批。获批之后是否暂停，本句没有规定。

**例子二：** “除非获批，否则不能发布。”记F为发布，翻 `¬A → ¬F`，逆否 `F → A`。发布必须获批，但获批不保证发布。

**操作：** 先对“除非”后面的完整命题取否定，再保留“否则”后面的完整命题；需要简化时才做双重否定和逆否。

**易错：** “除非P否则Q”和“除非P否则不Q”不能背成同一个箭头；这里的或是相容或，不自动是二选一。

### H08 除非才与没有就没有句式

**必要条件读法：** 题干明确用“除非P，才Q”表达“只有P，才Q”时，翻 `Q → P`，等价于 `¬P → ¬Q`。例如“除非获得批准，才可发布”表示发布以批准为必要条件。

**句式对比：**

| 表述 | 翻译 |
| --- | --- |
| 除非获批，否则暂停 | `¬获批 → 暂停` |
| 除非获批，否则不发布 | `¬获批 → ¬发布` |
| 只有获批，才发布 | `发布 → 获批` |
| 没有获批，就不能发布 | `¬获批 → ¬发布` |

第二、三、四句互相等价，第一句只有在“暂停”被题干明确规定为“未发布”的同义状态时，才能并入同一组；不能自行偷换词义。

**边界：** 单独出现“除非P”但后面的结果被省略，或“才”兼有时间含义时，应先恢复完整语义。“没有P，就没有Q”有条件联系；“没有P，也没有Q”是两个事实的联言 `¬P ∧ ¬Q`，不是条件句。

### H09 否定词的范围与双重否定

**规则：** `¬¬P ≡ P`；只在否定指向同一个完整命题时才能抵消。翻译时先区分“句中有一个否定命题”与“整句话被否定”。

| 句子 | 翻译 | 含义 |
| --- | --- | --- |
| 如果没报名，就没缴费 | `¬P → ¬Q` | 等价于 `Q → P` |
| 并非没有报名 | `¬¬P` | 报名了 |
| 并非如果报名就缴费 | `¬(P → Q)` | 报名了且没缴费 |
| 并非只有报名才缴费 | `¬(Q → P)` | 缴费了且没报名 |

**例子：** “并非没有审核就不能发布。”设A为审核、F为发布，完整式为 `¬(¬A → ¬F)`，化简 `¬A ∧ F`：未审核却发布。

**易错：** “不P就不Q”不等于“不是P就Q”；句首“并非”通常否定其后的完整命题，不能只否定最近的一个字母。

## 假言命题的等价转换

### H10 逆否等价的完整操作

**公式：** `P → Q ≡ ¬Q → ¬P`。同时做两件事：交换前后件；分别对完整前件、完整后件取否定。

**例子：** “只要上线，就完成审核且完成备案。”翻 `U → (A ∧ B)`；逆否为 `¬(A ∧ B) → ¬U`，再用德摩根得到 `(¬A ∨ ¬B) → ¬U`。

**为什么成立：** 原句只排除U真而A、B不全真的情形，逆否排除的也是同一情形，所以真假完全一致。

**操作：** 标出箭头两侧整体 → 对调 → 给每个整体加否定 → 用双重否定、德摩根化简 → 重新译成中文。

**易错：** 原后件是“审核且备案”，取否定必须是“未审核或未备案”，不能写“未审核且未备案”。

### H11 原命题与逆命题及否命题

| 名称 | 形式 | 与原命题的关系 |
| --- | --- | --- |
| 原命题 | `P → Q` | 基准 |
| 逆命题 | `Q → P` | 一般不等价 |
| 否命题 | `¬P → ¬Q` | 一般不等价 |
| 逆否命题 | `¬Q → ¬P` | 必然等价 |

**两组等价：** 原命题与逆否命题等价；逆命题与否命题等价，因为二者也互为逆否。

**例子：** 原命题为“4的倍数一定是偶数”。“不是偶数就不是4的倍数”与它等价；“是偶数就一定是4的倍数”和“不是4的倍数就不是偶数”均被整数6反驳。

**术语区分：** 此处“否命题”特指把前、后件分别否定而不换位的条件句；“原命题的否定”则是 `¬(P → Q) ≡ P ∧ ¬Q`，不是同一概念。

**易错：** 逆命题不等价，不代表它一定与原命题矛盾；二者可能同真，也可能一真一假。

### H12 假言命题转换为相容选言命题

**公式：** `P → Q ≡ ¬P ∨ Q`。口诀“否前或肯后”，指的是对整条条件句的等价改写，不是在否定P后推出Q。

**例子：** “如果小李报名，那么小李缴费”，等价于“小李未报名，或者已缴费”。后句允许未报名且缴费，也允许报名且缴费，只排除报名而没缴费。

**逆向转换：** `P ∨ Q ≡ ¬P → Q ≡ ¬Q → P`。注意从或变箭头时，要否定被放在箭头前面的那一项。

**易错：** `¬P ∨ Q`不能写成 `P ∨ ¬Q`，后者等价于逆命题 `Q → P`；也不能写成 `¬P ∧ Q`，那只保留一种情形。

### H13 同一个假言命题的等价表述族

以 `P → Q`为中心，以下表述可以互换：

| 表述 | 形式 |
| --- | --- |
| 如果P，那么Q；只要P，就Q | `P → Q` |
| 只有Q，才P；要P，必须Q | `P → Q` |
| 除非Q，否则不P | `¬Q → ¬P` |
| 没有Q，就没有P | `¬Q → ¬P` |
| 非Q则非P | `¬Q → ¬P` |
| 非P或Q | `¬P ∨ Q` |
| 不存在P真而Q假的情形 | `¬(P ∧ ¬Q)` |

**例子：** “提交申请就完成缴费”可以改写为“只有完成缴费才提交申请”“未缴费就未提交申请”“未提交申请或已缴费”。这些都没有保证已提交申请。

**操作：** 候选句全部翻成箭头或或式 → 统一消除双重否定 → 与原句及其逆否比较。不要仅比较词序是否接近。

**易错：** 前后对象、时间或程度变化会破坏等价。例如“缴费后提交”多出时间先后；“大多数提交者缴费”把全称规则降成比例判断。

### H14 前后件含否定时的转换

| 原式 | 逆否 | 变析取 | 直观含义 |
| --- | --- | --- | --- |
| `P → ¬Q` | `Q → ¬P` | `¬P ∨ ¬Q` | P、Q不能同时真 |
| `¬P → Q` | `¬Q → P` | `P ∨ Q` | P、Q至少一真 |
| `¬P → ¬Q` | `Q → P` | `P ∨ ¬Q` | Q成立必须P成立 |

**例子一：** “甲参加，则乙不参加”只禁止两人都参加，两人都不参加仍可；它不是“恰好一人参加”。

**例子二：** “甲不参加，则乙参加”只禁止两人都不参加，两人都参加仍可；它也是相容或。

**例子三：** “甲不参加，则乙不参加”等价于“乙参加，则甲参加”，不是“甲参加则乙参加”。

**易错：** 否定箭头前的 `¬P`要得到P，而不是再抄一次 `¬P`；箭头前后含否定与整条箭头被否定，要分别处理。

### H15 充要条件与双条件命题

**公式：**

`P ↔ Q ≡ (P → Q) ∧ (Q → P)`。

`P ↔ Q ≡ (P ∧ Q) ∨ (¬P ∧ ¬Q)`。

**含义：** P、Q真假相同，要么都真，要么都假。“当且仅当”“充分必要条件”明确给出两方向；一句“只有”不够，一句“只要”也不够。

**例子：** 同一规则同时规定“入选者都参加培训”与“参加培训者都入选”，才有“入选当且仅当参加培训”。已知未入选，可推出未参加培训；已知参加培训，可推出入选。

**整句否定：** `¬(P ↔ Q) ≡ (P ∧ ¬Q) ∨ (¬P ∧ Q)`，即恰有一个真。不能写成“都假”，因为都假反而使充要命题为真。

**易错：** 双条件也不保证P实际发生；若P、Q都假，双条件仍真。现实中互有关联或高度相关，不等于逻辑充要。

## 整句否定与且或转换

### H16 假言命题的否定是前真后假

**公式：** `¬(P → Q) ≡ P ∧ ¬Q`。否定的是整条规则时，必须指出规则被违反的那种情形。

**例子：** 对“如果小李参加培训，那么小李考核合格”作整句否定，得到“小李参加了培训，而且考核不合格”。不是“没参加就不合格”，也不是“参加就不合格”。

**推导：** 先变析取 `P → Q ≡ ¬P ∨ Q`，整句否定为 `¬(¬P ∨ Q)`，德摩根化简为 `P ∧ ¬Q`。

**辨析：** `P → ¬Q`只禁止P、Q同真；P假时它仍真。`P ∧ ¬Q`则要求P实际为真，不能用前者替代后者。

**易错：** 一个与条件句矛盾的事实，必须同时肯定前件、否定后件；单独“没有Q”不够，因为P也可能没有发生。

### H17 德摩根与双重否定

**公式：**

`¬(P ∧ Q) ≡ ¬P ∨ ¬Q`。

`¬(P ∨ Q) ≡ ¬P ∧ ¬Q`。

`¬¬P ≡ P`。

**操作：** 外层否定进入括号，里面每一项取否定，“且”换“或”，“或”换“且”。项本身含否定时，再消去双重否定。

**例子一：** “并非甲、乙都参加”是 `¬(P ∧ Q)`，表示至少一人不参加，允许两人都不参加，不能断定恰好一人没参加。

**例子二：** “并非甲或乙参加”若指对整个相容或的否定，是 `¬(P ∨ Q)`，两人都不参加。

**复合例子：** `¬(P ∧ ¬Q) ≡ ¬P ∨ Q`，与 `P → Q`等价。因此“不能出现报名却未缴费”，也是“报名则缴费”的表述。

**易错：** 不仅要换且或，还要逐项取否定；多层括号从外向内处理，不能只翻最外面的连接词。

### H18 相容或与排他或

**相容或：** `P ∨ Q`表示至少一个真，允许两个都真。它等价于 `¬P → Q`，也等价于 `¬Q → P`。

**排他或：** “P、Q恰好一真”可写为 `(P ∨ Q) ∧ ¬(P ∧ Q)`，也等价于 `(P ∧ ¬Q) ∨ (¬P ∧ Q)`。本专题“要么P，要么Q，但不能同时”明确采用此读法。

| P | Q | 至少一真 | 恰好一真 |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 假 |
| 真 | 假 | 真 | 真 |
| 假 | 真 | 真 | 真 |
| 假 | 假 | 假 | 假 |

**假言组合：** `¬P → Q`保证至少一真；`P → ¬Q`保证不同时真。两条同时成立，才能保证恰好一真。

**例子：** “甲或乙至少一人参加”加“甲参加”，不能推出乙不参加；如果再加“不能同时参加”，才可推出乙不参加。

**易错：** “不是两人都参加”只表示至多一人参加，允许零人参加；“不能都不参加”只表示至少一人参加，允许两人参加。

## 复合条件与嵌套命题

### H19 后件为且和前件为或的同时拆分

**规则一：** 后件为且，可拆成两条同时成立的条件。

`P → (Q ∧ R) ≡ (P → Q) ∧ (P → R)`。

**例子：** “上线就完成审核且备案”，等价于“上线就完成审核”与“上线就完成备案”两条规则都成立。缺任意一项，都能否定上线。

**规则二：** 前件为或，也可拆成两条同时成立的条件。

`(P ∨ Q) → R ≡ (P → R) ∧ (Q → R)`。

**例子：** “持学生证或教师证，都能入馆”，意味着学生证足以入馆，教师证也足以入馆，不要求同时持两证。

**为什么可拆：** 后且要求每个结果都满足；前或中的任一触发条件，都足以触发同一个结果。拆分后的两个条件句之间是“且”，不能改成“或”。

**易错：** `(P → Q) ∧ R`不是规则一的拆分结果，它额外无条件断定R为真。

### H20 前件为且和后件为或时不要过度推理

**前且：** `(P ∧ Q) → R`需要P、Q共同满足，不能只凭P或只凭Q推出R。

它的逆否为 `¬R → ¬(P ∧ Q)`，即 `¬R → (¬P ∨ ¬Q)`。R假时只能说P、Q至少一项假；若再知道P真，才能推出Q假。

**反例：** “审核且备案就上线”，审核真、备案假、上线假满足原条件，却反驳“审核就上线”。前件中的且不能删。

**后或：** `P → (Q ∨ R)`只保证P真时Q、R至少一真，不能确定哪一个真，也不排除两个都真。

它的逆否为 `¬(Q ∨ R) → ¬P`，即 `(¬Q ∧ ¬R) → ¬P`。必须Q、R都假，才能这样否定P。

**例子：** “甲参加，则乙或丙参加”。甲参加、乙不参加，能推出丙参加；只知道乙不参加，不能推出丙参加，因为甲可能没参加。

**错因：** 把“联合条件足够”偷换成“任一条件足够”；把“至少一个结果”偷换成“每个结果”或“指定结果”。

### H21 前且后或的高级等价与拆分边界

对同一组固定命题，经典命题逻辑还有以下等价：

`(P ∧ Q) → R ≡ (P → R) ∨ (Q → R)`。

`P → (Q ∨ R) ≡ (P → Q) ∨ (P → R)`。

**与H20不冲突：** 它们是“两条条件句的或”，不是“两条条件句同时为真”。由 `A ∨ B`不能指定A真，也不能指定B真，因此不能把这两式当成H19式的同时拆分。

**推导示范：** `(P ∧ Q) → R`变成 `¬P ∨ ¬Q ∨ R`；右侧两个条件句的或变成 `(¬P ∨ R) ∨ (¬Q ∨ R)`，去掉重复R后完全一致。

**反例：** P真、Q假、R假时，`(P ∧ Q) → R`为真；`P → R`为假、`Q → R`为真。或式成立，但两条规则不是同时成立。

**全称边界：** “所有入选者都去甲地或乙地”允许有的人去甲地、有的人去乙地，不能改成“所有入选者都去甲地，或者所有入选者都去乙地”。把每个人各自的或，移到“所有人”之外，会改变含义。只有固定单组命题的转换，才能直接使用上述公式。

**考场用法：** 等价选项出现“或连接两个条件句”时可检查；普通推出题仍按前且联合触发、后或否一肯另一处理，不强行指定分支。

### H22 嵌套条件句与括号范围

**可合并的嵌套：** `P → (Q → R) ≡ (P ∧ Q) → R`。它表示P成立时，Q足以触发R；最终要P、Q共同成立才能触发R。

**另一种括号：** `(P → Q) → R ≡ (P ∧ ¬Q) ∨ R`。这里整条“P则Q”的真假，充当外层箭头的前件，不能当作两条独立规则的链。

**区分反例：** P、Q、R都假时，`P → (Q → R)`为真；`(P → Q) → R`为假，因为内层 `P → Q`为真而R假。两个括号位置不等价。

**复合否定：**

`¬[P → (Q ∨ R)] ≡ P ∧ ¬Q ∧ ¬R`。

`¬[(P ∧ Q) → R] ≡ P ∧ Q ∧ ¬R`。

`¬[P → (Q ∧ R)] ≡ P ∧ (¬Q ∨ ¬R)`。

**操作：** 找最外层箭头 → 把箭头两边当完整命题 → 用“前真后假” → 再处理内部且或。内部还含箭头时，继续逐层转换。

**易错：** 题干并列给出 `P → Q`与 `Q → R`，不等于给出嵌套句 `(P → Q) → R`；两条前提应以且连接。

**如果那么否则的双分支：** 当句子明确按前件P是否成立区分分支时，“如果P，那么Q，否则R”包含 `P → Q`与 `¬P → R`两条规则，等价于 `(P ∧ Q) ∨ (¬P ∧ R)`。例如“下雨就带伞，否则带遮阳帽”，否则分支由“不下雨”触发，不是由“不带伞”触发；它也没有禁止同时带伞和帽。

**复合式化简所需的括号规律：**

| 规律 | 等价式 | 用途 |
| --- | --- | --- |
| 交换 | `P ∧ Q ≡ Q ∧ P`；`P ∨ Q ≡ Q ∨ P` | 同一连接词内可换顺序 |
| 结合 | `(P ∨ Q) ∨ R ≡ P ∨ (Q ∨ R)` | 同一连接词的多项可重分组，且同理 |
| 去重 | `P ∨ P ≡ P`；`P ∧ P ≡ P` | 重复同一命题不增加约束 |
| 且对或分配 | `P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R)` | 将共同前提带入各分支 |
| 或对且分配 | `P ∨ (Q ∧ R) ≡ (P ∨ Q) ∧ (P ∨ R)` | 不能只分配而漏掉连接词转换 |
| 吸收 | `P ∨ (P ∧ Q) ≡ P`；`P ∧ (P ∨ Q) ≡ P` | 一个分支被另一分支覆盖时化简 |

例如“甲参加，且乙或丙参加”，等价于“甲乙都参加，或者甲丙都参加”。两式都允许三人全参加；分配律不把相容或变成排他或。不同连接词不能随意交换括号，嵌套箭头更不能按一般加法的习惯改写。

## 推理规则与反例检验

### H23 肯前否后有效与肯后否前不确定

在已知 `P → Q`为真的前提下：

| 新增事实 | 能否必然推出 | 理由 |
| --- | --- | --- |
| P真 | Q真 | 否则会出现前真后假 |
| Q假 | P假 | 若P真，也会前真后假 |
| Q真 | 不能确定P | P真或假都可能 |
| P假 | 不能确定Q | Q真或假都可能 |

**反例：** P假、Q真同时反驳“肯后推肯前”和“否前推否后”，却完全满足原规则。

**限定：** 不确定不是“必然相反”。在没有其他条件时，肯后、否前不能给出确定结论；如果题干另外提供 `Q → P`等条件，则可以通过新增规则得到结果。

**例子：** 上线必须审核，已审核不能断定上线；未审核能断定未上线。若另外说审核必上线，才构成充要。

**易错：** 逆否是规则本身的等价，否后推否前是“规则＋事实”的应用，不是把一条条件句直接改成“P假”的事实句。

### H24 相容选言的否一肯另一

**有效推理：** `P ∨ Q`与 `¬P`同时为真，可以推出Q；与 `¬Q`同时为真，可以推出P。

**原因：** 原或式至少一真，一项已假，只能由另一项为真满足规则。

**例子：** “甲或乙至少一人值班；甲不值班”，必有乙值班。“甲值班”则不能否定乙，因为两人都值班也满足条件。

**条件或的使用：** `P → (Q ∨ R)`不等于Q或R已经为真，先要触发P；所以P真、Q假才可推出R，单独Q假不够。

**易错：** 相容或没有“肯一否另一”；恰好一真的排他或才可以使用该规则。

### H25 条件链与逆否链

**连锁：** 已知 `P → Q`且 `Q → R`，可以推出 `P → R`；P真时R真，R假时可沿逆否链推出Q假、P假。

**例子：** 发布必须审核，审核必须备案，得到 `发布 → 审核 → 备案`；没备案则没审核，也没发布。

**不是完整等价：** 两条原规则合在一起可推出 `P → R`，但不能仅凭 `P → R`恢复两条原规则。反例P假、Q真、R假：简化后的 `P → R`为真，`Q → R`却为假。

**不能乱串：** `P → Q`与 `R → Q`只共享后件，不能推出P与R之间的箭头；`P → Q`与 `P → R`只共享前件，不能推出Q与R之间的箭头。

**易错：** 中间命题必须是相同对象、同一时点、同一范围。甲审核过与乙审核过不是同一个Q，“有的项目备案”也不能直接接“所有备案项目上线”后断言某个指定项目上线。

### H26 分类推理与二难推理

**同结果的分支：** 已知 `P ∨ Q`、`P → R`、`Q → R`，可以推出R。P与Q无论哪一项真，都落到同一结果R。

**不同结果的分支：** 已知 `P ∨ Q`、`P → R`、`Q → S`，只能由这些条件保证 `R ∨ S`，不能指定R或S。

**例子：** 甲或乙至少一人参加；甲参加会带相机，乙参加也会带相机，可以断定有人带相机。若甲带相机、乙带录音笔，只能保证相机或录音笔至少有一种被带来。

**边界：** “甲或乙会参加”若只是可能性描述，并未保证至少一人实际参加，就不能无条件落出结果；P、Q两分支之外若还有未覆盖情况，也不能当穷尽分类。

**易错：** 不能把相容或当排他或，两个分支可能同时成立；不同后件只能合成或，不能合成且。

## 量词与题型边界

### H27 全称规则与存在命题

**全称假言：** “所有报名者都缴费”是对每个对象x都要求 `报名(x) → 缴费(x)`；在同一论域内，等价于“所有未缴费者都未报名”。

**全称规则的否定：** “并非所有报名者都缴费”表示“至少存在一名报名而未缴费的人”，不是“所有报名者都没缴费”。否定全称要转成存在，并保留违例对象。

| 原句 | 整句否定 |
| --- | --- |
| 所有P对象都属于Q | 有的P对象不属于Q |
| 所有P对象都不属于Q | 有的P对象属于Q |
| 有的P对象属于Q | 所有P对象都不属于Q |
| 有的P对象不属于Q | 所有P对象都属于Q |

**集合含义：** “所有P都是Q”给出P集合包含于Q集合，反向不必成立。它不单独保证P集合非空，不能仅凭它推出“有的P是Q”。若另外已知有P对象存在，才可推出该存在性结论。

**例子：** “有的报名者缴费”只说某些对象同时具备两个性质，不能简写成普遍规则 `报名 → 缴费`。两个“有的”也可能指不同对象，不能自行串成同一个人。

**换位的等价边界：** “所有P都不是Q”与“所有Q都不是P”等价，都是两集合没有交集；“有的P是Q”与“有的Q是P”等价，都是交集非空。但“有的P不是Q”一般不能换成“有的Q不是P”。例如有员工不是党员，仍可能所有党员都是员工，后一句就为假。

**易错：** 把“对每人分别成立的或”提到“所有人”外；把全称逆否的“未缴费者”换成“没有缴费行为发生”，改变了对象层级。

### H28 等价题与推出题及论证题的区别

| 问法 | 核心任务 | 核验方式 |
| --- | --- | --- |
| 与题干意思相同、等价表述 | 保留全部逻辑信息 | 原句与选项每种情形同真同假 |
| 必然推出、一定为真 | 条件与已知事实共同推结论 | 不存在题干全真但选项假的反例 |
| 不可能发生、违反规定 | 找条件排除的情形 | 检查是否前真后假，或违反其他规则 |
| 整句否定、矛盾命题 | 找原命题恰好为假的条件 | 对完整命题取否定 |
| 加强、削弱、补前提 | 分析论据与论点的联系 | 不能只做机械等价换词 |

**例子：** 调查发现培训者成绩更好，并据此说“培训导致成绩提高”。这不是已经给定的必真规则 `培训 → 提高`；不能用逆否声称“没提高必然没培训”，需要讨论对照、他因等证据。

**条件词边界：** “通常”“可能”“大多数”不能删成必然箭头；制度中的“可以申请”不自动等于“实际申请”，二者不是同一个命题。

**弱表述也要检验：** “可能P”至少要能与全部题干条件相容；“P不一定”通常是在说存在P不成立的允许情形。“看起来比较弱”不等于正确。

**复盘：** 标错的是翻译方向、否定范围、等价关系、事实触发、量词范围，还是把论证当成确定规则，再回到对应知识点重做。

## 等价转换速查卡

| 任务 | 规则 | 首先检查 |
| --- | --- | --- |
| 逆否 | `P → Q ≡ ¬Q → ¬P` | 换位与完整否定一起做 |
| 变析取 | `P → Q ≡ ¬P ∨ Q` | “否前或肯后”，不是且 |
| 否定假言 | `¬(P → Q) ≡ P ∧ ¬Q` | 肯前、否后同时发生 |
| 否定且 | `¬(P ∧ Q) ≡ ¬P ∨ ¬Q` | 至少一项假，不限定哪项 |
| 否定或 | `¬(P ∨ Q) ≡ ¬P ∧ ¬Q` | 两项都假 |
| 充要 | `P ↔ Q`为双向条件 | 只要与只有分别给一个方向 |
| 后且拆分 | `P → (Q ∧ R)` | 两个条件句同时成立 |
| 前或拆分 | `(P ∨ Q) → R` | 每个分支都能单独推出R |
| 前且、后或 | 不能拆成两条同时为真的规则 | 联合触发、结果分支 |
| 全称规则的否定 | 存在一个前真后假的对象 | 存在性、对象一致 |

## 综合精讲例题

### 例题一 同一句话的等价选项

**题目：** 规定“只有完成审核，项目才能发布”。下列哪句与之等价？

- A. 只要完成审核，项目就会发布。
- B. 项目未发布，就一定未完成审核。
- C. 项目已完成审核且已发布。
- D. 项目未发布，或者已完成审核。

**解析：** 记A为审核、F为发布。题干 `F → A`，变析取为 `¬F ∨ A`，选D。A为逆命题 `A → F`；B为否命题 `¬F → ¬A`；C是更强的事实联言，不是条件规则。

**反例回查：** 完成审核但尚未发布，使题干、D为真，A、B、C为假。允许情形不能被等价选项额外删去。

**对应知识点：** H06、H11—H13。

### 例题二 除非翻译与条件链

**题目：** 除非通过审核，否则不能上线；没有完成备案，就不能通过审核。已知某项目没有完成备案，能必然推出什么？

**翻译：** A为通过审核、U为上线、B为备案。第一句 `¬A → ¬U`，即 `U → A`；第二句 `¬B → ¬A`，即 `A → B`。

**推理：** 条件链为 `U → A → B`。已知 `¬B`，逐级得到 `¬A`、`¬U`，所以项目未通过审核且未上线。

**不能多推：** 如果改成已备案，仅凭这些条件不能推出已审核或已上线；备案是必要条件，不是充分条件。

**对应知识点：** H07、H14、H23、H25。

### 例题三 复合必要条件与否后推否前

**题目：** 只有完成复核且完成备案，项目才可发布；除非负责人签字，否则不得备案。已知负责人没有签字，判断发布和复核各能否确定。

**翻译：** F为可发布、R为复核、B为备案、S为签字：`F → (R ∧ B)`；`¬S → ¬B`，等价于 `B → S`。

**推理：** 未签字推出未备案；原第一句可拆出 `F → B`，故未备案推出不可发布。结论是不可发布。

**不能确定复核：** R真或假都能与未备案、不可发布相容。不能把不可发布再逆向推出“未复核且未备案”。

**对应知识点：** H10、H19、H20、H23。

### 例题四 条件句的矛盾与真假话

**题目：** P为“小李报名”，Q为“小李缴费”。甲说“如果P，那么Q”；乙说“P而且非Q”；丙说“非P”。三句话恰好一真，能确定P或Q的真假吗？

**解析：** 甲说 `P → Q`，乙说 `P ∧ ¬Q`，互为矛盾，必一真一假。因为三句总共一真，丙必假，所以P真。

P真后，甲的话真假取决于Q，乙的话与之相反。Q真时甲真，Q假时乙真，都满足恰好一真。因此只能确定报名，不能确定是否缴费。

**易错：** 找到矛盾对并不等于知道矛盾对中具体谁真；第三句被定假后，得到的是事实P，不自动得到Q。

**对应知识点：** H04、H16、H23。

### 例题五 整句否定与否命题辨析

**题目：** 对“只要小李参加培训，小李就考核合格”作整句否定，并判断它是否等价于“小李不参加培训就不合格”。

**解析：** T为参加培训、G为合格。整句否定 `¬(T → G) ≡ T ∧ ¬G`，即参加培训而没合格；“不培训就不合格”是 `¬T → ¬G`，属于否命题，不是整句否定。

**反例：** 小李没培训也没合格时，否命题为真，但整句否定为假，因为缺少参加培训这个事实。两式不等价。

**量词拓展：** 如果原句变成“所有参加培训的学员都合格”，其否定是“有的学员参加培训而没合格”，未指定该人就是小李。

**对应知识点：** H09、H11、H16、H27。

### 例题六 后或与不能推出的最小反例

**题目：** 如果甲参加活动，乙或丙至少一人参加；乙不参加。能否推出丙参加？若再知丙不参加，又能推出什么？

**第一问：** A为甲参加、B为乙参加、C为丙参加，题干 `A → (B ∨ C)`且 `¬B`。不能推出C。反例 `¬A ∧ ¬B ∧ ¬C`满足原条件且否定C。

**第二问：** 再加 `¬C`，有 `¬B ∧ ¬C`，即后件整体为假，逆否得 `¬A`：甲不参加。

**若改为已知甲参加：** A真触发后件，得到 `B ∨ C`，再结合 `¬B`才可推出C。

**对应知识点：** H20、H23、H24。

## 自测练习

先遮住下一节。第1—7题写完整翻译或等价式，不只写关键词；第8—12题说明能否推出及理由。P、Q、R均为固定命题，“或”采用相容或。

1. “只有P，才Q”翻成什么？写出它的逆否。
2. “除非P，否则Q”翻成什么？写出其等价或式。
3. “除非P，否则不Q”是否等价于“只要P，就Q”？
4. “只有不P，才Q”翻成什么？它是否等价于“P则不Q”？
5. `¬P → ¬Q`与哪个肯定形式的条件句等价？
6. 对 `P → (Q ∧ R)`作整句否定。
7. 对 `(P ∨ Q) → R`作整句否定。
8. 已知 `(P ∧ Q) → R`、P真、R假，能推出什么？
9. 已知 `P → (Q ∨ R)`、Q假，能否断定R真？给出反例或推理。
10. 已知 `P ↔ Q`、P假，能否断定Q假？
11. “所有报名者都缴费”的否定是什么？原句是否保证有报名者存在？
12. 原句为 `P → Q`。以下哪些与其等价：A. `¬Q → ¬P`；B. `Q → P`；C. `¬P ∨ Q`；D. `¬P → ¬Q`；E. `¬(P ∧ ¬Q)`？

## 自测答案与解析

1. `Q → P`；逆否 `¬P → ¬Q`。“只有”前的P是必要条件，不是充分条件。
2. `¬P → Q`；等价 `P ∨ Q`。没有限定“恰好一个真”。
3. 原句 `¬P → ¬Q ≡ Q → P`，不等价于 `P → Q`。P真、Q假使原句真而候选句假。
4. `Q → ¬P`，逆否 `P → ¬Q`，所以等价。两者均只禁止P、Q同真，不保证至少一真。
5. 等价 `Q → P`；不是 `P → Q`。先换位，再分别消去双重否定。
6. `P ∧ ¬(Q ∧ R)`，即 `P ∧ (¬Q ∨ ¬R)`。前件必须发生，后件至少一项不满足。
7. `(P ∨ Q) ∧ ¬R`。P、Q至少一真，R假；不要求P、Q都真。
8. Q假。若Q真，P、Q同时真会推出R真，与已知R假冲突；也可先用逆否得到 `¬P ∨ ¬Q`，再由P真得到Q假。
9. 不能。P假、Q假、R假满足条件，R仍是假；若另有P真，才可推出R真。
10. 可以。双条件包含 `Q → P`，结合P假得Q假；两者同假不违反双条件。
11. 否定为“有的报名者没缴费”。原全称规则不单独保证报名者存在，所有人都没报名也满足它。
12. A、C、E等价；B、D互为逆否，但一般不与原句等价。P假、Q真使原句真而B、D假。

## 错因定位与复盘步骤

| 错因 | 常见表现 | 纠正动作 |
| --- | --- | --- |
| 方向错 | 只有被写成前推后 | 改写成“要谁必须谁” |
| 除非错 | 不管否则是否含否定都用同一口诀 | 一律先写“非除非项 → 否则项” |
| 否定范围错 | 只否一个词，或漏括号 | 先确定最外层命题 |
| 逆否不完整 | 只换位或只取非 | 对调后对两个完整命题分别否定 |
| 且或错 | 后或拆成两个结果、前且删一项 | 分清共同满足与可选分支 |
| 术语错 | 否命题被当成整句否定 | 四命题表与“前真后假”分别记 |
| 事实错 | 从规则直接断定前件已经发生 | 找题干实际给出的触发事实 |
| 等价错 | 把一个推论当完整同义句 | 同时检查反向能否成立 |
| 量词错 | 全称变存在，或两个“有的”串人 | 保留论域、对象与量词 |
| 题型错 | 因果调查被当成必真箭头 | 先看问法与证据性质 |

完整做题顺序：定对象和时点 → 设字母 → 保留否定词并加括号 → 写箭头 → 按问法做等价、否定或推理 → 用真值／反例回查。答案、条件与对象一起核对，不能只认熟悉口诀。
