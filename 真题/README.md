# 真题

> 真题收集索引与练习记录。当前有2篇申论单题页及23道知识点配套真题卡片，**尚未收齐行测或申论完整套卷**。卡片采用任务转述与材料摘要，完整资料须打开来源阅读。
> 按对应年度、批次、类别的正式时限练习，不把国考120/180分钟直接套到所有四川卷。

## 建议收集

- 四川近5年，优先目标职位类别；同年多批次分别存放。
- 国考2022—2026年度作为通用能力补充，按省级/市地/行政执法等类别匹配；旧卷模块结构可能不同。
- 需加试公安专业科目者另收相应真题，不默认所有四川公安岗位都需加试。
- 做完的套卷认真复盘，错题归入 [../错题本.md](../错题本.md)

“待收集”只表示本仓库尚未存放完整卷，不表示外部没有题源。官方大纲中的示例不是历年考试原卷，机构回忆版或模拟题也不能标为“官方真题”。

建议命名：`四川-年度-批次-类别-科目-版本.pdf`。入库同时记录原始链接、整理机构、缺页情况、答案性质和核验日；答案有争议的题标记“待核验”，不制造统一官方答案。
