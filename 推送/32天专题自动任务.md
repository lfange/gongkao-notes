将下面整段作为Codex任务内容，允许联网检索和在本仓库生成、提交、推送学习资料：

```text
在E:\public执行四川公安省考32天每日学习资料任务。用户已授权按计划联网搜索、生成资料并发布到lfange/gongkao-notes（GitHub Pages）；只发布本任务产生的内容，不发送微信、邮件等消息。计划为2026-11-03至2026-12-04，每天4小时，岗位为绵阳市县级公安机关执法勤务（金融财会）43206010，专业科目为公安专业科目。

1. 读取AGENTS.md（如有）、专题/32天公安省考冲刺/README.md、plan.json及当天页面。不得使用站内旧版每周20小时计划覆盖本专题。
2. 用北京时间确定今天。运行 python 推送/study_publish.py pending，联网获取远端已发布记录。检查11月3日至min(今天,12月4日)全部日期，按时间顺序处理尚未发布的页面。未联网核验远端时不得宣称没有遗漏。12月4日以后仍补齐遗漏，全部完成后不再生成新日期内容；若有定时任务管理工具，暂停此任务。
3. 每个日期先读plan.json对应四科任务和时间。保留其总学习预算240分钟、任务、站内链接和用户打卡；不得把过去页面上的用户笔记覆盖。若本地已有完整资料且尚未推送，先检查并发布，避免重复生成。
4. 必须实际联网搜索并阅读与该日期主题对应的资料。优先四川人事考试网、公安机关、国家法律法规数据库、中国人大网、中国政府网等权威页面；现行法律和考试规则必须核验适用版本、发布日和生效日。找不到本次四川大纲时明确待核实，不以国考或外省大纲冒充。过去日期补发以实际检索日核验，注明“补发”及实际检索日期；不伪装为历史当天已搜索。涉及政策时间点时区分当时规定与检索时规定。
5. 在当日页面“今日联网资料”部分写入可直接学习的精讲：行测对应方法与例题，申论对应审题与要点加工，公安对应知识结构、条件与程序；至少3个不同的已实际阅读来源链接，写入“来源与核验”区。标注来源支持的具体内容、适用地区/年份、实际检索日期；来源不可读时换可核验来源或明确资料未完成，不编造链接。不要只有链接清单。
6. 配套练习覆盖计划题量：可链接具体公开练习及题号，并提供精选自编例题；自编题明确标注，不冒充真题。若原题不可公开获取，提供原创练习替代并说明，不能写“已经收齐真题”。申论提供原创材料与题目、字数要求、参考要点和评分提示；公安提供答案理由与依据；心理准备仅使用官方说明、真实作答、作息和流程，不出人格“标准答案”或医学诊断。所有材料阅读、做题、订正均包含在当天240分钟内。套卷以合法公开可访问的整卷为优先，拿不到时明确未获取并提供等时限训练，不冒称整卷。
7. 页面必须包含“## 今日四科任务”“## 今日联网资料”“## 配套练习”“## 参考答案与解析”“## 来源与核验”和“实际检索日期：YYYY-MM-DD”。练习与答案分区，便于先做后看。保留打卡；只有资料完成且核验通过才添加 <!-- study-materials:该页YYYY-MM-DD --> 标记。
8. 对该日期运行 python 推送/study_publish.py validate YYYY-MM-DD，然后 python 推送/study_publish.py publish YYYY-MM-DD。脚本只提交这个日期页面，普通推送master；不强推、不重置、不自动变基、不暂存他人改动。遇Git冲突、暂存区有他人内容、网络/权限或来源核验失败就保留现状并报告，不写成功标记或跳过遗漏日期。每完成一天即推送并核对远端，再处理下一天。执行限时将到时报告剩余日期，下一次从远端记录继续。
9. 完成后报告本次实际发布的日期、网站链接和剩余日期；仅本地保存不能称已发布，Git已推送但Pages尚未更新时说明部署待生效。没有遗漏且没有新内容时保持安静，不每天发无变化状态。
```

## 脚本命令

```powershell
# 展示待发布日期（默认先fetch核对远端）
python 推送/study_publish.py pending

# 检查资料格式，不能替代来源真实性检查
python 推送/study_publish.py validate 2026-11-03

# 只提交及推送这个日期的学习页，再检查远端内容
python 推送/study_publish.py publish 2026-11-03
```

重建计划与占位页可运行`python 推送/study_plan.py`，已存在的逐日页面不会被覆盖。发布结果以远端日期页面及资料完成标记为准；模板存在不代表当日联网资料已完成。访问令牌、登录凭据与本地日志均不得写入公开笔记。
