# 备考 · 总索引

> 起始 2026-07-14 ｜ 每日 < 3h ｜ 零基础
> 目标：**2027年度四川省考** ｜ 可选练兵：**2027年度国考**（考试日期均待官方公告确认）
> 2026-10-05 校订：四川往年并非固定春季考试，先读 [四川省考备考](计划/四川省考备考.md)，不要按“明年3—4月”默认倒排。

## 快速开始

1. 读 [四川省考备考](计划/四川省考备考.md) 和 [总体计划](计划/总体计划.md) —— 核对岗位、试卷类别和倒排安排
2. 读 [行测攻略](xingce/攻略.md) 和 [申论攻略](shenlun/攻略.md) 建立科目认知，再用 [行测必备知识框架与例题](xingce/必备知识框架与例题.md)、[申论必备知识框架与例题](shenlun/必备知识框架与例题.md) 串联知识点
3. 按 [计划/每周计划模板.md](计划/每周计划模板.md) 排当周计划，每天在 [计划/每日打卡.md](计划/每日打卡.md) 记录
4. 完成一套诊断卷，使用 [套卷复盘模板](真题/套卷复盘模板.md) 找出薄弱项，再选定一套基础资料
5. 错题记到 [错题本.md](错题本.md)；法律、政策和考试规则参照 [更新清单](计划/法律与时政更新清单.md)

## 三句话原则

- **以四川岗位为目标，国考按需练兵。** 不把国考卷型和日期直接当四川安排。
- **抓大放小。** 资料分析、判断推理、言语理解重点练，政治理论与申论同步学。
- **每天动手，宁少勿断。** 连续性大于单次时长。
