# 公考备考 · 总索引

> 起始 2026-07-14 ｜ 每日 < 3h ｜ 零基础
> 终极目标：**2027 省考**（约 2027 年 3-4 月） ｜ 实战演习：**2026 国考**（约 2026 年 11 月底）

## 快速开始

1. 读 [计划/总体计划.md](计划/总体计划.md) —— 了解四个阶段的全周期安排
2. 读 [行测攻略](xingce/攻略.md) 和 [申论攻略](shenlun/攻略.md) —— 建立科目认知
3. 按 [计划/每周计划模板.md](计划/每周计划模板.md) 排当周计划，每天在 [计划/每日打卡.md](计划/每日打卡.md) 记录
4. 选一套基础网课/教材（见 [资源推荐.md](资源推荐.md)），**本周就开工**
5. 错题记到 [错题本.md](错题本.md)

## 网页版（可选）

## 三句话原则

- **以省考为目标，国考练兵。** 国考能上考场就是赢。
- **抓大放小。** 资料分析、判断推理、言语理解三大模块先吃透。
- **每天动手，宁少勿断。** 连续性大于单次时长。
