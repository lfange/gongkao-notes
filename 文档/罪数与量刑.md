# 数罪并罚、择一重罪处罚和从重处罚

[返回文档目录](文档/README.md)

做题先圈出法条规定的处理方式，再问两个问题：要定几个罪？每个罪的刑罚怎样确定？

| 处理方式 | 何时适用 | 判决怎样处理 |
| --- | --- | --- |
| 数罪并罚 | 一人犯数个应独立评价的罪，或者分则明确要求并罚 | 各罪分别定罪量刑，再决定执行刑罚。例如两罪分别判有期徒刑3年、5年，依第69条在5年至8年之间决定执行刑期，两个端点均包括在内。 |
| 择一重罪处罚 | 同一行为同时触犯数个罪名，构成想象竞合时通常择重；分则另有明确择重规定时依其规定 | 比较具体案情下各罪适用的法定刑，按处罚较重的罪定罪量刑。 |
| 从重处罚 | 某一罪已经确定，行为人又具备法定从重情节 | 依第62条，在该罪适用的法定刑幅度内判得较重。法定最高刑仍是上限。 |

## 六个常考例子

| 题干 | 结论与理由 |
| --- | --- |
| 甲盗窃财物数额较大，数日后因另一纠纷故意伤害他人致轻伤。两案在判决前一并查明。 | **数罪并罚。** 两次行为分别成立盗窃罪、故意伤害罪，各自量刑后决定执行刑罚（第69、234、264条）。 |
| 投保人为骗保故意杀害被保险人，并骗得数额较大的保险金。 | **数罪并罚。** 杀人和骗保虽然服务于同一目的，第198条第2款仍明确要求对这种同时构成其他犯罪的情形并罚。 |
| 甲在道路上醉酒驾驶，违反交通运输管理法规，致一人死亡并负事故全部责任。 | **择一重罪。** 同一驾驶行为同时构成危险驾驶罪和交通肇事罪。本例按交通肇事罪处罚（第133条、第133条之一）。 |
| 甲以危险方法破坏正在使用的交通工具，同一行为同时符合破坏交通工具罪和故意毁坏财物罪，且前罪适用的法定刑更重。 | **择一重罪。** 本例按破坏交通工具罪处罚。判断时要看是否足以造成交通工具倾覆、毁坏的危险，单有财产损失还不能直接推出前罪（第116、275条）。 |
| 成年人教唆17周岁的人盗窃，后者实施盗窃并达到入罪标准。 | **对教唆者从重处罚。** 先按其在盗窃共同犯罪中的作用确定责任，再适用教唆未成年人犯罪的从重规定（第29条）。 |
| 成年人因故意犯罪被判有期徒刑，执行完毕后第3年又故意犯罪，后罪应判有期徒刑以上刑罚。 | **对后罪从重处罚。** 题设符合一般累犯条件（第65条）。若把题干改为在前刑执行期间又犯新罪，则依第71条，将前罪未执行的刑罚与后罪所判刑罚按第69条并罚。 |

第62条和第69条可以先后适用。例如行为人因两罪受审，其中一罪具有法定从重情节，法院先对该罪从重量刑，再将两罪所判的刑罚并罚。

法条依据见[《中华人民共和国刑法》全文](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250311_1958931.html)。
