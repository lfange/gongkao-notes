# 笔记网站 · 部署指南

把这套笔记变成一个可以在浏览器里直接看的网站（Docsify 方案，零构建）：

- **Markdown 就是网站本身**：服务器上放的就是 `.md` 原文件，改完笔记跑一下部署脚本（或重新上传）刷新即生效
- **无外部依赖**：所有 JS/CSS/字体已下载到 `网站/assets/`，服务器和访问者都不需要访问国外 CDN
- 支持**中文全文搜索**（侧边栏顶部搜索框）和 **LaTeX 数学公式**渲染（资料分析的公式直接显示成排版效果）

---

## 一、本地先预览

部署前先在本机看一眼效果。仓库根目录执行：

```powershell
python -m http.server 8000
```

浏览器打开 <http://localhost:8000>，能看到侧边栏目录、搜索框、公式渲染即为正常。

> 直接双击打开 index.html 是不行的（浏览器禁止本地 AJAX），必须通过上面的 HTTP 服务访问。

---

## 二、部署到服务器（三选一）

服务器上只需要一个「能托管静态文件」的东西。假设笔记放在服务器 `/var/www/gongkao`。

### 方式 A：nginx（推荐，正式使用）

```bash
sudo apt install nginx          # Debian/Ubuntu；CentOS 用 yum install nginx
```

新建 `/etc/nginx/conf.d/gongkao.conf`：

```nginx
server {
    listen 80;
    server_name _;                       # 有域名就填域名
    charset utf-8;
    root /var/www/gongkao;
    index index.html;

    # 双保险：即使 推送/ 目录被误传上来，也拒绝访问
    location /推送/ { deny all; }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 方式 B：Docker（一行命令，不动系统配置）

```bash
mkdir -p /var/www/gongkao
docker run -d --name gongkao-docs -p 8080:80 \
  -v /var/www/gongkao:/usr/share/nginx/html:ro --restart always nginx
```

浏览器访问 `http://服务器IP:8080/`。

### 方式 C：纯 Python（服务器已有 Python3，零安装）

创建 `/etc/systemd/system/gongkao-docs.service`：

```ini
[Unit]
Description=gongkao notes site
After=network.target

[Service]
WorkingDirectory=/var/www/gongkao
ExecStart=/usr/bin/python3 -m http.server 8080
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now gongkao-docs
```

浏览器访问 `http://服务器IP:8080/`。（个人使用足够；公网多人访问建议用 A/B。）

## 三、把笔记传上去

### Windows 本机（推荐用脚本）

编辑 [部署.ps1](部署.ps1) 顶部的两个变量（服务器地址、目标路径），然后在**仓库根目录**执行：

```powershell
powershell -ExecutionPolicy Bypass -File 网站\部署.ps1
```

脚本会把白名单内容（网站文件 + 全部笔记）打包上传并解压，带安全自检（发现 `config.json`、`.log`、密钥类文件会拒绝上传）。

### 任意 Linux/macOS（等价 rsync 命令）

```bash
rsync -avz ./ user@server:/var/www/gongkao/ \
  --exclude '推送' --exclude '.git' --exclude '.claude' --exclude '网站'
```

> 注意两种方式都**排除了 `推送/` 目录**，原因见下节。

## 四、⚠️ 安全须知

1. **`推送/` 目录绝不能放进网站目录。**
   里面的 `config.json` 含 LLM API Key 和推送密钥（虽然被 git 忽略，但文件在服务器上真实存在），一旦被公网访问到等于密钥泄露。部署脚本的白名单机制和 nginx 配置里的 `deny all` 都是为了防这一点。
2. **公开访问 = 任何人有链接都能看**。以后往 `真题/` 里放东西时想一想版权问题；想加密码，nginx 一行配置即可：
   ```bash
   sudo apt install apache2-utils
   sudo htpasswd -c /etc/nginx/.htpasswd 你的用户名
   # nginx 配置的 location / 里加两行：
   #   auth_basic "notes";
   #   auth_basic_user_file /etc/nginx/.htpasswd;
   ```
3. **新增顶层目录或文件时**，记得同步加进 `部署.ps1` 的 `$items` 白名单（脚本会提示哪些没被包含）。

## 五、日常更新流程

1. 平时改笔记、加笔记（正常写 Markdown 即可，相对链接照常用）
2. 新增了笔记文件 → 在根目录 [`_sidebar.md`](../_sidebar.md) 里加一行链接（照抄现有格式）
3. 重新跑一遍部署（`部署.ps1` 或 rsync）
4. 浏览器刷新即可看到

> 部署会覆盖同名文件，但**不会删除**服务器上已不存在的旧笔记；想彻底重置就在服务器上清空目录再传。

## 六、附：零服务器选项（GitHub Pages）

如果暂时不想租服务器：把仓库推到 GitHub（**先确认 `推送/config.json` 未被提交**），Settings → Pages → 选 main 分支即可免费获得 `https://用户名.github.io/仓库名/` 的网站，`.nojekyll` 文件已备好。缺点是访问速度受网络影响。
