# 刑法专题（总则硬核 + 公安常考罪名）⭐

> 刑法考点集中在**总则的几条硬线**（责任年龄、正当防卫、停止形态、共同犯罪）+ **公安日常接触的罪名**（袭警、妨害公务、两抢一盗、黄赌毒、危险驾驶）。
> 考法：单选考数字与分界，情境题给一个案件事实问"构成何罪 / 如何处理"。与常识模块互链：[常识·法律常识专题](../xingce/常识判断/法律常识专题.md)。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

## 一、总则硬线（速查表）

### 刑事责任年龄

| 年龄 | 责任 |
| --- | --- |
| ≥16 | 对一切犯罪负责 |
| 14–16 | 仅对**八类行为**负责：故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质 |
| **12–14** | 故意杀人、故意伤害致人死亡或以特别残忍手段致人重伤造成严重残疾、情节恶劣，**经最高人民检察院核准追诉**的负刑责（刑法修正案（十一）） |
| <12 | 不负刑事责任（可专门矫治教育） |

### 正当防卫（情境题高频）

- 条件：**起因**（现实不法侵害）+ **时间**（正在进行）+ **对象**（侵害人本人）+ **意图**（防卫）；
- 防卫过当：**明显超过必要限度且造成重大损害**，两个条件缺一不可（应负刑责，但应当减轻或免除处罚）；
- **特殊防卫**：对**行凶、杀人、抢劫、强奸、绑架**及其他严重危及人身安全的暴力犯罪进行防卫，造成不法侵害人伤亡的，**不属于防卫过当**。

### 犯罪停止形态

| 形态 | 关键点 |
| --- | --- |
| 犯罪预备 | 准备工具、制造条件（**可以从轻减轻免除**） |
| 犯罪未遂 | **已着手**、意志以外原因未得逞（可以从轻或减轻） |
| 犯罪中止 | **自动**放弃或自动有效防止结果发生（**没有造成损害的应当免除处罚**，造成损害的应当减轻） |

> 题眼：未遂 vs 中止的区分就看**"能不能继续、愿不愿意继续"**——自动放弃 = 中止，被迫停止 = 未遂。

### 共同犯罪与自首立功

- 共同犯罪：二人以上**共同故意**犯罪（共同过失不构成）；主犯按其所参与的全部犯罪处罚，从犯（起次要或辅助作用）应当从轻、减轻或免除处罚；**教唆犯**按其在共同犯罪中的作用处罚，教唆不满 18 周岁的人犯罪的**从重**。
- 自首：**自动投案 + 如实供述**自己的罪行（可以从轻或减轻；犯罪较轻的可以免除）；
- 立功：揭发他人犯罪查证属实、提供重要线索侦破其他案件等（可以从轻、减轻或免除）。
- 认罪认罚从宽：刑诉法与刑法衔接的制度（情境题中"到案后如实供述 = 坦白，可以从轻"）。

## 二、公安常考罪名（情境判断库）⭐

### 袭警罪与妨害公务（最贴身的罪名）⭐

- **袭警罪**（刑法修正案（十一）增设）：**暴力袭击**正在依法执行职务的人民警察的，处三年以下有期徒刑、拘役或管制；使用枪支、管制刀具，或者以驾驶机动车撞击等手段严重危及其人身安全的，处三年以上七年以下。
- **妨害公务罪**：以**暴力、威胁**方法阻碍国家机关工作人员依法执行职务的（含阻碍人大代表依法执行代表职务、红十字会工作人员依法履行职责，以及故意阻碍**国家安全机关、公安机关**依法执行国家安全工作任务**未使用暴力威胁方法**造成严重后果的）。
- 分界：骂警察（辱骂，未暴力）一般不构成袭警罪，视情节构成侮辱或治安违法；**推搡、拳打脚踢等暴力**袭警 → 袭警罪。

### 侵犯人身权利

| 罪名 | 情境题眼 |
| --- | --- |
| 故意伤害罪 | 轻伤以上是刑事立案门槛；轻微伤 → 治安处罚 |
| 故意杀人 / 过失致人死亡 | 故意 vs 过失的主观分界 |
| 非法拘禁罪 | 剥夺他人人身自由（为索债非法扣押他人也构成） |
| 侮辱罪、诽谤罪 | **告诉才处理**的自诉案件（严重危害社会秩序和国家利益的除外） |
| 刑讯逼供罪 | 司法工作人员对犯罪嫌疑人、被告人使用肉刑或变相肉刑（主体特定） |
| 组织出卖人体器官罪 / 强奸罪等 | 出现在多选题的"重罪"选项中 |

### 侵犯财产（一条难度阶梯背下来）⭐

| 罪名 | 行为方式 | 要点 |
| --- | --- | --- |
| 盗窃罪 | **秘密窃取**（平和转移占有） | 数额较大（一般 1 千至 3 千以上）或多次盗窃、入户盗窃、携带凶器盗窃、扒窃 |
| 抢夺罪 | **乘人不备、公然夺取** | 对物暴力；夺取财物致人伤害可转化为抢劫认定 |
| **抢劫罪** | **当场使用暴力、胁迫或其他方法**强取财物 | **最高可判死刑**；携带凶器抢夺以抢劫论 |
| 敲诈勒索罪 | **威胁、要挟**（非当场强制）迫使交付财物 | 恐吓基础 + 被害人基于恐惧处分 |
| 诈骗罪 | **虚构事实、隐瞒真相**使被害人**自愿处分**财物 | 与盗窃的根本区别：谁处分财物 |

### 危害公共安全与交通

- **危险驾驶罪**（行为犯，不要求后果）：**追逐竞驶情节恶劣**；**醉驾（血液酒精 ≥80mg/100ml）**；从事校车业务或旅客运输严重超员、超速；违规运输危险化学品危及公共安全。
- 交通肇事罪：过失犯罪，要求**重大事故**后果（致人重伤、死亡或使公私财产遭受重大损失）。
- **帮助信息网络犯罪活动罪**（帮信罪）：明知他人利用信息网络实施犯罪，为其提供互联网接入、服务器托管、支付结算等帮助，情节严重——"两卡"案件（出租出售银行卡、电话卡）的口袋罪名，情境题高频。

### 黄赌毒（治安与刑事的分界）⭐

| 行为 | 治安违法 | 刑事犯罪 |
| --- | --- | --- |
| 卖淫嫖娼 | 是（拘留 + 罚款） | **组织、强迫、引诱、容留、介绍卖淫**才是罪 |
| 赌博 | 娱乐性赌博 | **以营利为目的聚众赌博、以赌博为业、开设赌场** |
| 吸毒 | 是（不构成犯罪） | **非法持有毒品达到数量标准**、走私贩卖运输制造毒品是罪 |
| 毒品犯罪 | —— | 走私、贩卖、运输、制造毒品**无论数量多少都追究刑责**（数量仅影响量刑） |

## 三、精讲情境例题（2 例）

**例 1.** 民警在查处酒驾时，驾驶人张某突然倒车企图逃离，将阻拦的辅警撞倒（构成轻伤）后弃车逃跑。张某的行为应认定为？
A. 妨害公务罪 B. 袭警罪 C. 危险驾驶罪与袭警罪 D. 交通肇事罪

**解析：** 醉驾（设血液酒精超标）本身构成危险驾驶罪；暴力袭击正在依法执行职务的警察（含与警察共同执行职务的辅警，视具体情况），驾车撞击属于"以驾驶机动车撞击等手段"袭击依法执行职务的人民警察——按袭警罪加重档处理；妨害公务罪与袭警罪是法条竞合，**优先适用袭警罪**（特别条款）。选 C（题干含醉驾事实时）。**陷阱：** 单选 D 交通肇事罪要求重大事故且系过失，本案是故意撞击。

**例 2.** 下列情形构成正当防卫的是？
A. 甲被乙殴打后，当晚纠集他人将乙打伤
B. 丙发现正在入户盗窃的丁，将其扑倒致丁轻伤
C. 戊抓住已停止侵害并求饶的己，将其打成重伤
D. 庚听闻仇人扬言"明天收拾你"，当晚先下手将其打伤

**解析：** B 对——**正在进行**的盗窃（财产性违法侵害可特殊防卫的情形有限，但对正在进行的盗窃可正当防卫，扑倒致轻伤未过当）。A 错（事后报复）；C 错（侵害已结束 + 明显过当）；D 错（侵害尚未开始，事前防卫不是正当防卫）。**陷阱：** 时间条件"正在进行"是正当防卫题的题眼，事前事后都不算。

## 四、易错点清单

1. 袭警罪要求**暴力袭击**，辱骂不算（那是治安 / 侮辱问题）；妨害公务是暴力威胁方法。
2. **抢劫最高可判死刑**，盗窃、抢夺都没有死刑（多选"可判死刑的罪名"常混入盗窃）。
3. 危险驾驶罪是**行为犯**——醉驾不出事故也构罪；交通肇事罪是**结果犯 + 过失**。
4. 吸毒**不构成犯罪**（治安处罚）；持有毒品达到数量标准才入刑；**贩卖毒品不论数量多少**都追责。
5. 自首"可以"从宽（不是应当）；中止"应当"减免——"可以 / 应当"档位常被偷换。
6. 12–14 周岁只限故意杀人、故意伤害两罪且须**最高检核准追诉**。
7. 帮信罪主观是"明知 + 提供帮助"，与诈骗共犯（通谋）区分。

## 五、速记卡（考前 5 分钟过一遍）

> 十六全责十四八，十二到十四最高检；正当防卫看进行，特殊防卫五罪名。
> 未遂欲罢不能停，中止自动当减免；主犯全案从犯宽，教唆未成年从重判。
> 盗窃秘密抢夺暴，抢劫当场暴力高；醉驾八十行为犯，袭警暴力辱骂非。
> 组织卖淫开设赌，持有毒品有数量；走私贩卖制毒品，不论多少皆追责。

## 六、自测练习

1. 袭警罪与妨害公务罪的区别是什么？
2. 盗窃、抢夺、抢劫三罪的行为方式如何区分？哪个可判死刑？
3. 醉驾构成什么罪？需要造成后果吗？
4. 哪些涉毒行为是犯罪？哪些只是治安违法？
5. 犯罪未遂与犯罪中止如何区分？处罚上有何不同？

### 答案附录

1. 袭警罪：**暴力袭击正在依法执行职务的人民警察**（特别条款）；妨害公务罪：以**暴力、威胁**方法阻碍国家机关工作人员依法执行职务（一般条款）；暴力袭警优先认定袭警罪。
2. 秘密窃取 / 乘人不备公然夺取 / 当场使用暴力或胁迫强行劫取；**抢劫罪**最高可判死刑（携带凶器抢夺以抢劫论）。
3. 危险驾驶罪（血液酒精 ≥80mg/100ml）；**不需要**造成后果（行为犯）。
4. 犯罪：走私贩卖运输制造毒品（不论数量）、非法持有毒品达数量标准、容留他人吸毒等；治安违法：吸食、注射毒品（不构成犯罪）。
5. 未遂 = 已着手因**意志以外原因**未得逞（可以从轻减轻）；中止 = **自动**放弃或自动有效防止结果（没有损害应当免除处罚，造成损害应当减轻处罚）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **分界错**：此罪与彼罪（盗窃 / 抢夺 / 抢劫、袭警 / 妨害公务、未遂 / 中止）；
- **数字错**：责任年龄、醉驾标准、十二至十四核准程序；
- **档位错**："可以 / 应当"从宽、死刑罪名范围；
- **情境错**：漏看题干关键词（"当场""正在""自动""明知"），回到情境题专项重做。
