# 刑事执法能力专题（受案立案 / 侦查措施 / 强制措施的操作）⭐

> 刑诉法知识在执法场景中的应用：题干给一个案件办理场景，考**立案不立案、用哪种侦查措施、上哪种强制措施、程序有没有错**。
> 与 [刑事诉讼法专题](刑事诉讼法专题.md) 配套：那边背数字，这边练操作。
> 使用方法：过流程 → 记"立案与否 / 措施选择"的判断标准 → 错点记入 [错题本.md](../错题本.md)。

---

## 一、受案与立案（第一道分岔口）⭐

### 流程

接受（报案、控告、举报、扭送、自首一律**先接受**）→ 受案审查（有无犯罪事实、是否归自己管辖、是否需要追究刑责）→ **立案**（开展侦查）或**不予立案**（通知控告人，不服可申请**复议**）。

### 立案与否的判断（情境题核心）

| 情形 | 处理 |
| --- | --- |
| 有犯罪事实 + 需追究刑责 + 属管辖 | **立案侦查** |
| 没有犯罪事实 / 情节显著轻微危害不大 | 不予立案（属治安违法的按治安案件办） |
| 已过追诉时效、特赦、嫌疑人死亡等法定不追诉情形 | 撤销案件 / 不予立案 |
| 不属于自己管辖 | **先接受再移送**主管机关，通知报案人 |

> 高频陷阱：把"不构成犯罪"直接退回不管——错！**能转治安案件的转治安案件**（如殴打致轻微伤），一推了之是不作为。

## 二、侦查措施的操作门槛（选用哪种？）

| 措施 | 什么情况用 | 关键程序 |
| --- | --- | --- |
| **讯问犯罪嫌疑人** | 对到案（被拘传 / 取保 / 居住 / 拘留 / 逮捕）的嫌疑人 | **侦查人员 2 人**；送看守所后**在看守所内**进行；第一次讯问应当问明是否委托辩护人 / 告知权利 |
| **询问证人 / 被害人** | 收集言词证据 | 可以到其所在单位、住处或通知其到公安机关；**不得使用羁押、拘传等方式对待证人**；询问未成年人法定代理人到场 |
| **勘验检查** | 犯罪现场、人身 | 持有证件；检查妇女身体由**女工作人员或医师**进行；必要时指派 / 聘请有专门知识的人 |
| **搜查** | 收集犯罪证据、查获犯罪人 | **搜查证**；执行拘留逮捕遇**紧急情况**可无证搜查；应当有被搜查人或其家属、邻居等见证人在场 |
| **查封扣押** | 与案件有关的财物、文件、邮件、电报 | **与案件无关的不得扣押**；开列清单一式两份；经查明无关的 **3 日内**解除、退还 |
| **查询冻结** | 存款、汇款、债券等 | 不得重复冻结；与案件无关的不得冻结 |
| **技术侦查** | 危害国家安全、恐怖活动、黑社会性质组织、重大毒品等案件 | 立案后 + **严格批准手续** + 期限 3 个月（可延） |
| **通缉** | 应当逮捕而在逃的犯罪嫌疑人 | **县级以上公安机关**发布通缉令；越辖区报上级 |
| **辨认** | 组织证人对嫌疑人 / 物品辨认 | 辨认前不得让辨认人见到辨认对象；多名辨认人应个别进行；混杂辨认（类似物品混杂） |

## 三、强制措施的选用阶梯（从轻到重）⭐

```
拘传（未羁押、需要到案）→ 取保候审（社会危险性小 / 特殊人群）→ 监视居住（符合逮捕条件但有特殊情形）→ 拘留（现行犯 / 重大嫌疑，情况紧急）→ 逮捕（证据 + 刑期 + 社会危险性三条件齐备）
```

### 情境判断三步法

1. **人在不在案？** 不在案 → 先拘传或传唤到案；符合拘留情形的先行拘留；
2. **社会危险性大不大？** 可能毁灭证据、串供、逃跑、再犯 → 拘留 / 逮捕方向；危险性小 + 特殊人群（患病、孕产哺）→ 取保 / 监视居住；
3. **程序跟上了吗？** 24 小时讯问、24 小时通知家属、看守所内讯问、2 人讯问——每个强制措施落地后跟一套程序动作。

### 数字总表（回背）

| 措施 | 时限 |
| --- | --- |
| 拘传 | 12 小时（重大复杂需拘留逮捕的 24 小时） |
| 取保候审 | 最长 12 个月（不得中断案件侦查） |
| 监视居住 | 最长 6 个月 |
| 拘留 → 提请批捕 | 3 日 → +1-4 日 → 流窜 / 多次 / 结伙 30 日 |
| 检察院批捕决定 | 7 日 |
| 侦查羁押 | 2 个月（+1+2+2 阶梯） |
| 扣押物品无关解除 | 3 日内 |

## 四、证据意识（执法规范化的考法）

- 证据 8 种；**孤证不能定案**（只有被告人供述没有其他证据的，不能认定有罪）；
- **非法证据排除**：刑讯逼供、威胁、引诱、欺骗等方法收集的言词证据应当排除；**实物证据**收集程序违法、可能严重影响司法公正且不能补正 / 合理解释的排除；
- **全程同步录音录像**：可能判处无期、死刑的案件或其他重大犯罪案件，讯问应当录音录像（侦查办案规范要求逐步扩大范围）；
- 电子数据（聊天记录、转账记录、监控视频）的提取要制作笔录、固定原始载体。

## 五、精讲情境例题（2 例）

**例 1.** 某派出所对一起盗窃案被害人报案材料审查后认为达不到刑事立案标准，遂口头告知"不归我们管"。下列评价正确的是？
A. 正确，立案前可以自由决定是否受理
B. 错误：对报案应当先接受；不予立案的应制作不予立案通知书送达控告人，不服的可申请复议；涉嫌治安违法的应按治安案件办理
C. 错误，派出所必须立案
D. 正确，口头告知即可

**解析：** B 对——"**先接受**"是硬规则，"不归我们管"的说法本身就违法；不予立案须书面通知 + 复议救济；够不上刑事的转治安案件。A、D 错；C 错（立案有法定条件，不是凡报必立）。**陷阱：** 题干把"不立案"（可能对）和"不受理"（必错）混在一起——分开评价。

**例 2.** 张某涉嫌诈骗被羁押于看守所。律师王某持三证要求会见，侦查人员以"案件尚在侦查、需要保密"为由拒绝。关于本案还发现：讯问由 1 名侦查人员和 1 名协警进行。下列说法正确的是？
A. 诈骗案侦查期间律师会见须经许可
B. 王某凭三证会见，看守所应至迟 48 小时内安排；讯问程序违法
C. 讯问只要同步录音录像即合法
D. 会见时侦查机关应当派员在场并记录谈话内容

**解析：** B 对。A 错——许可案件仅限**危害国家安全、恐怖活动**；C 错（2 名**侦查人员**是底线，协警不算）；D 错（会见不被监听）。**陷阱：** "需要保密"不是拒绝会见的法定理由。

## 六、易错点清单

1. **先接受、再审查、后分流**：报案材料不能拒收；不构成犯罪的转治安案件。
2. 需许可会见的只有**危害国家安全、恐怖活动**两类；会见**不被监听**。
3. 讯问 **2 名侦查人员**、送押后在**看守所内**；协警 / 辅警不能独立成为讯问主体。
4. 无证搜查仅限"执行拘留、逮捕 + 紧急情况"。
5. 扣押与案件无关财物违法；查明无关 **3 日内**解除退还。
6. 强制措施从轻到重有**阶梯**，能取保的不上拘留（比例原则）；孕产哺优先取保 / 监视居住。
7. 证人不能"拘传到案"——询问证人没有强制到案的手段。

## 七、速记卡（考前 5 分钟过一遍）

> 报案先收不能推，不立书面告复议；够不上刑转治安，一推了之即违法。
> 讯问两人在所内，危恐会见要许可；搜查持证急例外，无关财物三日退。
> 拘传十二取保年，监视半年拘三天；流窜多次结伙卅，批捕七日羁押二。
> 孤证不能定人罪，刑讯言词必排除；录音录像重大案，电子取证要固定。

## 八、自测练习

1. 公安机关对报案材料的处理流程是什么？
2. 讯问犯罪嫌疑人的程序要求有哪些？
3. 无证搜查的适用条件是什么？
4. 强制措施的选用阶梯是什么？取保候审适用于哪些情形？
5. 非法证据排除规则的内容是什么？

### 答案附录

1. 一律**先接受**并登记 → 受案审查（犯罪事实、管辖、追责必要）→ 立案侦查 / 不予立案（书面通知控告人，可申请复议）；构成治安违法的转治安案件，不属管辖的移送主管机关。
2. 由**侦查人员 2 人**进行；犯罪嫌疑人被送看守所羁押后，讯问应当在**看守所内**进行；第一次讯问后或采取强制措施之日起可委托辩护律师；可能判处无期、死刑等的案件讯问应当录音录像。
3. 在**执行拘留、逮捕**时，遇可能随身携带凶器、隐藏爆炸剧毒物品、企图毁弃转移犯罪证据等**紧急情况**。
4. 拘传 → 取保候审 → 监视居住 → 拘留 → 逮捕。取保适用于：可能判处管制拘役；可能判徒刑以上但无社会危险性；患严重疾病、怀孕哺乳婴儿的妇女；羁押期限届满案件未办结。
5. 采用**刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述**等言词证据应当排除；收集物证、书证不符合法定程序、可能严重影响司法公正且不能补正或合理解释的，也应排除。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **流程错**：受理 → 立案 → 侦查的分流节点判断错；
- **门槛错**：某种侦查措施 / 强制措施的启动条件记混（尤其搜查证、技侦、会见许可）；
- **数字错**：时限阶梯（回总表重背）；
- **情境错**：题干身份细节（孕妇 / 未成年人 / 危恐案件）漏看，错选措施档位。
