# 人民警察法与警械武器专题 ⭐（人民警察法 / 警衔 / 纪律 / 使用警械和武器条例）

> 本专题是"警察自身的权利义务说明书"，其中**《人民警察使用警械和武器条例》是情境题的第一大考点**——什么时候能开枪、什么时候绝对不能开枪，年年必考。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

## 一、人民警察法核心条文（权利义务面）

### 任务与义务

- 任务：维护国家安全，维护社会治安秩序，保护公民的人身安全、人身自由和合法财产，保护公共财产，预防、制止和惩治违法犯罪活动。
- 关键义务（情境题高频）⭐：
  1. **遇到公民人身、财产安全受到侵犯或者处于其他危难情形，应当立即救助**——"不作为"违法；
  2. 对公民提出解决纠纷的要求，**应当给予帮助**；
  3. 对公民的报警案件，**应当及时查处**；
  4. 秉公执法、办事公道；礼貌待人、文明执勤；尊重人民群众的风俗习惯。

### 盘问检查（与行政执法能力专题联动）⭐

- 为维护社会治安秩序，对有**违法犯罪嫌疑的人员**，经**出示相应证件**，可以当场盘问、检查；
- 经盘问、检查，对符合条件（被指控有犯罪行为 / 有现场作案嫌疑 / 携带物品可能是赃物等）的，可以**带至公安机关继续盘问**；
- 继续盘问（留置）时间：**自带至公安机关之时起不超过 24 小时**，特殊情况经县级以上公安机关批准可**延长至 48 小时**。

### 禁止行为（多选题直接考）

人民警察不得有下列行为：散布有损国家声誉的言论；泄漏国家秘密、警务工作秘密；**弄虚作假，徇私舞弊**；刑讯逼供或者体罚、虐待人犯；**非法剥夺、限制他人人身自由**，非法搜查他人的身体、物品、住所或者场所；敲诈勒索或者索取、收受贿赂；**殴打他人或者唆使他人打人**；违法实施处罚或者收取费用；接受当事人及其代理人的请客送礼；**从事营利性的经营活动或者受雇于任何个人或者组织**；玩忽职守，不履行法定义务；其他违法乱纪行为。

## 二、警衔与队伍管理（与公安基础知识专题联动）

- 警衔：**五等十三级**（详见 [公安基础知识专题](公安基础知识专题.md)）；
- 不得录用：曾因犯罪受过**刑事处罚**的、被**开除公职**的；
- 不得辞退：因公致残、患病或负伤在医疗期内、怀孕产假哺乳期内；
- 奖励：集体 / 个人——嘉奖、三等功、二等功、一等功、荣誉称号；
- 《公安机关人民警察纪律条令》：处分六种（警告、记过、记大过、降级、撤职、开除）。

## 三、使用警械和武器条例 ⭐⭐（情境题第一大考点）

### 先分清两类警械

| 类别 | 种类 | 使用条件 |
| --- | --- | --- |
| **驱逐性、制服性警械** | 警棍、催泪弹、高压水枪、特种防暴枪 | 结伙斗殴、殴打他人、寻衅滋事、侮辱妇女等**违法犯罪人员**，**警告无效**且经警告可能造成更严重危害后果的；用于**制止违法犯罪行为** |
| **约束性警械** | 手铐、脚镣、警绳等 | 对**抓获的违法犯罪行为人**或重大嫌疑分子，为防止其**脱逃、行凶、自杀、自伤或其他危险行为**（约束，不是惩罚） |

### 使用武器的条件（开枪的合法性框架）⭐

- 前提：判明是**暴力犯罪行为**的**紧急情况**，经**警告无效**的，可以使用武器（来不及警告或者警告后可能导致更严重危害后果的，**可以直接使用**）；
- 可以开枪的典型情形（概括）：放火、决水、爆炸等严重危害公共安全的；劫持航空器、船舰、火车、机动车或驾驶车船故意危害公共安全的；**抢夺、抢劫枪支弹药、爆炸、剧毒等危险物品**，严重危害公共安全的；使用枪支、爆炸、剧毒等危险物品实施犯罪或以暴力抗拒人民警察履行职责的；**破坏军事、通讯、交通、能源、防险等重要设施**足以危害公共安全的；实施凶杀、劫持人质等严重危及人身安全的；国家规定的警卫、守卫、警戒对象和目标受到暴力袭击、破坏或有受到袭击、破坏的紧迫危险的；**聚众械斗、暴乱等严重破坏社会治安秩序**，用非暴力方式不能制止的；等等。
- 开枪后处理：犯罪分子**停止实施犯罪、服从命令**，或**失去继续实施犯罪能力**的，应当立即停止使用武器；使用武器造成犯罪分子或者无辜人员伤亡的，应当**及时抢救受伤人员**、保护现场，并**立即向所属机关书面报告**。

### 不得使用武器的两种情形 ⭐⭐（考得最狠）

| 情形 | 例外 |
| --- | --- |
| 发现实施犯罪的人是**怀孕妇女、儿童** | 使用枪支等实施暴力犯罪的**除外** |
| 犯罪分子处于**群众聚集的场所或者存放易燃、易爆、剧毒、放射性等危险物品的场所** | 不使用武器予以制止，将发生**更为严重危害后果**的除外 |

### 使用警械的限制

- 以**制止违法犯罪行为为限度**；违法犯罪行为得到制止后应当立即停止使用；
- 不得对**已经停止、失去继续实施能力**的对象继续使用（继续打 = 违法，情境题最常设的"事后追击"陷阱）。

## 四、精讲情境例题（2 例）

**例 1.** 民警在商场内追捕持刀劫持人质的犯罪嫌疑人，下列做法正确的是？
A. 对着人群方向鸣枪警告，迫使嫌疑人就范
B. 判明情况紧急，可以不先行警告直接使用武器
C. 嫌疑人弃刀投降后，为防其逃跑朝腿部开一枪
D. 使用武器后口头向所领导汇报即可

**解析：** B 对——劫持人质属严重危及人身安全的暴力犯罪，来不及警告或警告可能导致更严重后果的可直接使用。A 错（人群聚集场所盲目开枪）；C 错（已服从命令，应立即停止使用武器）；D 错（须**书面**报告 + 保护现场 + 抢救伤员）。**陷阱：** "警告"不是绝对前置程序，"停止使用"才是硬线。

**例 2.** 民警甲将拒不配合的涉嫌盗窃人员乙控制后，为"教训"其不老实，给乙加戴手铐并长时间约束在椅子上。甲的行为？
A. 合法，使用约束性警械是法定职权
B. 违法，约束性警械只能用于防止脱逃、行凶、自杀、自伤等危险行为，不能作为惩罚
C. 合法，只要不造成伤害
D. 违法，因为手铐只能对已判刑人员使用

**解析：** B 对——约束性警械的用途是**控制危险**，不是**惩罚不老实**；A、C 错；D 错在"判决"（办案全程都可依法使用）。**陷阱：** 警械的每一类都有法定用途，超出用途（惩罚、逼供）即违法。

## 五、易错点清单

1. 不得使用武器的情形有**例外条款**：孕 / 童**自己使用枪支等暴力犯罪**、聚集场所**不制止会发生更严重后果**的，仍可使用——单选"一律不得"必错。
2. "来不及警告可直接使用"与"必须先警告"的区分：**警告为原则、直接使用为例外**（例外条件：来不及警告或警告后可能导致更严重危害后果）。
3. 使用武器后：**抢救伤员 + 保护现场 + 书面报告**（不是口头报告）。
4. 驱逐性警械（警棍、催泪弹）用于**制止违法行为**；约束性警械（手铐、警绳）用于**防止危险行为**——用途混设必错。
5. 继续盘问 24/48 小时（自带至公安机关时起算），与传唤 8/24 小时（治安案件）**不是一个制度**——两大"24"分属不同法。
6. 人民警察义务是"**应当立即救助**"危难公民——情境中"非警务活动不处理"的辩解不成立（同时"非警务活动"本身应移交主管机关）。

## 六、速记卡（考前 5 分钟过一遍）

> 盘查亮证先当场，继续盘问廿四双；危难救助是义务，报警案件及时办。
> 驱逐制服警告先，约束防逃不惩戒；开枪判明暴力急，警告无效直击要。
> 孕童聚集两禁区，例外条款莫忘记；停止服命即停手，书面报告护现场。

## 七、自测练习

1. 警械分哪两类？各自的使用目的是什么？
2. 使用武器的一般程序（含警告）是什么？什么情况下可以直接使用武器？
3. 不得使用武器的两种情形及其例外是什么？
4. 人民警察遇到公民人身安全受到侵犯时应当怎么做？依据是什么？
5. 继续盘问的时限及批准规则是什么？

### 答案附录

1. **驱逐性、制服性警械**（警棍、催泪弹、高压水枪、特种防暴枪——制止违法犯罪行为）与**约束性警械**（手铐、脚镣、警绳——防止脱逃、行凶、自杀、自伤等危险行为）。
2. 判明是暴力犯罪行为的紧急情况，经**警告无效**可以使用武器；**来不及警告，或者警告后可能导致更严重危害后果的**，可以直接使用。使用后立即停止的情形：犯罪分子停止犯罪、服从命令，或失去继续犯罪能力；事后保护现场并书面报告，伤亡的抢救伤员。
3. ①发现实施犯罪的人是**怀孕妇女、儿童**（但其使用枪支等实施暴力犯罪的除外）；②犯罪分子处于**群众聚集场所或存放易燃易爆、剧毒、放射性危险物品的场所**（不使用武器将发生更为严重危害后果的除外）。
4. **应当立即救助**（《人民警察法》规定的人民警察义务）。
5. 自带至公安机关之时起不超过 **24 小时**；特殊情况经**县级以上公安机关批准**可延长至 **48 小时**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **类别错**：驱逐性 / 约束性警械混用；
- **条件错**：武器使用的"警告原则 + 例外"、"两个禁区 + 例外"记不全；
- **程序错**：书面报告、停止使用、抢救伤员等事后动作漏项；
- **制度串**：继续盘问 24/48 与传唤 8/24、刑事拘留 24 小时讯问通知相混淆（各属不同法，分别回表）。
