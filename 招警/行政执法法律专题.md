# 行政执法法律专题（行政处罚 / 行政强制 / 复议 / 诉讼 / 赔偿）

> 民告官的"程序全家桶"：公安机关作出具体行政行为后，当事人怎么救济、公安机关怎么应诉。核心考**行为分类 + 时限 + 听证范围**。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。与常识模块互链：[常识·法律常识专题](../xingce/常识判断/法律常识专题.md)（行政行为四分类）。

---

## 一、行政行为分类（地基，先会分再谈程序）

| 行为 | 性质 | 公安例子 |
| --- | --- | --- |
| **行政许可** | 事前**放行** | 颁发枪支运输许可证、集会游行示威许可 |
| **行政确认** | 事后**盖章**认定既有事实 | 交通事故责任认定 |
| **行政处罚** | **制裁**（对违法） | 治安罚款、行政拘留、吊销许可证 |
| **行政强制措施** | 临时**控制**（保障程序） | 对涉案物品**扣押**、对醉酒人员**约束至酒醒**（保护性约束） |
| **行政强制执行** | 实现**履行义务** | 加处罚款、划拨存款、申请法院强制执行 |

> 题眼：**扣押是"措施"（临时控制），加处罚款是"执行"（督促履行）**——同属"行政强制"但一分为二。

## 二、行政处罚法（2021 年修订版要点）

### 处罚种类与设定

- 种类：警告、通报批评；罚款、没收违法所得 / 非法财物；暂扣 / 吊销许可证件、降低资质等级；**限制开展生产经营活动、责令停产停业、责令关闭、限制从业**；行政拘留；法律、行政法规规定的其他。
- **设定权限**：限制人身自由的处罚**只能由法律设定**；行政法规可设定除限制人身自由以外的处罚；地方性法规不得设定限制人身自由、吊销营业执照的处罚。
- **一事不再罚**：对当事人的**同一个违法行为**，不得给予**两次以上罚款**的行政处罚（同一违法行违反多个法条应择一重处）。

### 程序硬点 ⭐

| 规则 | 内容 |
| --- | --- |
| **告知与陈述申辩** | 作出处罚决定前依法告知拟处罚内容、事实、理由、依据及权利；未依法告知或拒绝听取陈述申辩的，**不得作出行政处罚决定**；当事人明确放弃陈述或申辩权利的除外（2021年法第62条，不沿用旧法“不能成立”措辞） |
| **听证范围** | 较大数额罚款；没收较大数额违法所得；降低资质等级、吊销许可证件；责令停产停业、责令关闭、限制从业；**其他较重的行政处罚**（治安案件新法：吊销许可证件、**4000 元以上罚款**、责令停业整顿，及可能执行行政拘留的未成年人案件——见治安专题） |
| **简易程序（当场处罚）** | 违法事实确凿、有法定依据，对个人处 **200 元以下**或警告的（**治安案件新法：警告或 500 元以下罚款**） |
| **普通程序办案期限** | 一般自立案之日起90日内作出处罚决定；法律、法规、规章另有规定的从其规定（第60条），治安案件另查特别规则 |
| **追责时效** | 一般违法行为2年内未被发现的不再处罚；涉及公民生命健康安全、金融安全且有危害后果的延长至5年；法律另有规定除外（第36条），治安案件不能直接套用一般时效 |
| **首违不罚** | 初次违法且危害后果轻微并及时改正的，可以不予处罚；当事人有证据足以证明没有主观过错的不予处罚，法律、行政法规另有规定的从其规定（第33条） |

> 以上程序与例外的核验出处：[2021年修订行政处罚法官方全文](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_76d37c09bd594d67b80ec2aa6fababcc.html)。

## 三、行政强制法

- 行政强制措施由**法律设定为原则**；查封、扣押由**法律、法规**设定；
- 实施程序：须出示执法身份证件，**当场告知理由、依据及权利**，听取陈述申辩，制作现场笔录；
- **查封、扣押的期限不得超过 30 日**；情况复杂的经批准可延长，**延长期限不得超过 30 日**（法律另有规定除外）；
- 冻结存款、汇款的期限同样 **30 日（+30 日）**；
- **查封、扣押限于涉案的场所、设施或财物，不得查封、扣押与违法行为无关的财物**；**不得重复查封**；
- 行政强制执行：**加处罚款或滞纳金的数额不得超出金钱给付义务的数额（本金）**；行政机关不得在**夜间或者法定节假日**实施强制执行（情况紧急除外），不得采取**停止供水、供电**等方式迫使居民履行。

## 四、行政复议（2024.1.1 施行新法）⭐

| 考点 | 新法规则 |
| --- | --- |
| 申请期限 | 知道或应当知道行政行为之日起一般 **60 日**内，法律规定超过60日的除外 |
| 复议机关 | 地方政府工作部门等案件以**本级地方人民政府集中管辖**为原则；税务等案件向上一级主管部门申请，省级政府、国务院部门等另有法定管辖规则 |
| 复议前置（扩大） | 当场处罚；侵犯已经依法取得的自然资源所有权、使用权的决定；未履行法定职责；申请政府信息公开被决定不予公开；法律、行政法规规定的其他情形 |
| 审理期限 | **普通程序**：受理之日起一般60日内，复杂案件经批准最多延长30日；**简易程序**：受理之日起30日内 |
| 复议决定 | 维持（原行为合法）、变更、撤销、确认违法、责令履行 |

> 记忆锚点：**申请一般60日；普通程序60日，复杂最多加30日；简易程序30日。**地方行政复议集中管辖不等于所有案件都向政府申请。

### 补充说明：复议前置的情形和例子

**前置就是下一步之前必须先走的程序。**复议前置意味着先申请行政复议，对复议决定不服再依法起诉，不能跳过复议直接起诉。

| 法定情形 | 通俗例子 | 做题分界 |
| --- | --- | --- |
| 对当场作出的行政处罚决定不服 | 交警适用简易程序，当场向小王作出罚款决定，小王认为罚错了 | 强调“当场作出决定”，不等于当场缴款，也不是所有处罚都前置 |
| 对侵犯已依法取得的自然资源所有权、使用权的决定不服 | 小王已有合法林地使用权，行政机关作出决定将该权利确认给他人 | 强调“已经依法取得”，不是所有涉及土地、森林的争议都前置 |
| 认为行政机关未履行法定职责 | 小王依法申请行政许可，行政机关超过法定期限仍不受理、不答复 | 先提出履职申请，再结合相关法定期限判断是否不履职 |
| 申请政府信息公开，行政机关不予公开 | 申请公开文件，机关以涉及国家秘密等理由决定不予公开 | 不能把所有信息公开争议都笼统归入“不予公开” |
| 法律、行政法规规定的其他情形 | 税务机关认为应缴税5万元，小王认为只需缴3万元，形成纳税争议 | 纳税争议与对税务处罚不服不是同一概念；当场处罚等另查前置规定 |

**纳税争议的特别条件**：先按纳税决定缴纳或解缴税款及滞纳金，或者提供相应担保，再申请行政复议；对复议决定不服再依法起诉。

**纠错提醒**：不能把“对工伤认定结论不服”一律列为复议前置。《工伤保险条例》第五十五条规定可以申请复议，也可以起诉；如果争议实际是行政机关未履行法定职责等，仍须另查复议前置规则。

依据：[行政复议法第23条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_70518816df484be18f6b38fa295750bb.html)、[税收征收管理法第88条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_1dbea81872cb4fda9ab3ccc45c627531.html)、[工伤保险条例第55条](https://xzfg.moj.gov.cn/front/law/detail?LawID=610)。

### 补充说明：行政复议各个时间节点

**知道行政行为 → 申请复议 → 审查受理 → 作出复议决定 → 不服再依法起诉。**每个期限对应不同的办事人和起算节点，不要把两个60日混在一起。

| 节点 | 期限 | 从什么时候计算、由谁办事 |
| --- | --- | --- |
| 申请行政复议 | 一般60日内 | 从知道或应当知道行政行为之日起，由申请人提交申请；法律规定超过60日的除外 |
| 审查是否受理 | 5个工作日内 | 从复议机关收到申请之日起审查；期限届满未作出不予受理决定的，依法视为受理 |
| 通知补正材料 | 5个工作日内 | 申请材料不齐全或表述不清、无法判断是否符合条件的，机关从收到申请起书面通知 |
| 提交补正材料 | 10个工作日内 | 从申请人收到补正通知之日起；有正当理由可延长合理期限 |
| 普通程序作出决定 | 一般60日内，复杂案件经批准最多延长30日 | 从受理申请之日起；法律规定少于60日的除外 |
| 简易程序作出决定 | 30日内 | 从受理申请之日起 |
| 不服复议决定而起诉 | 一般15日内 | 从收到复议决定书之日起 |
| 复议机关逾期不作决定而起诉 | 一般15日内 | 从复议期限届满之日起 |
| 前置案件不予受理、驳回申请后起诉 | 一般15日内 | 从收到相关决定书之日起 |

以上为常见规则，法律另有规定的从其规定。行政复议法中“3日、5日、7日、10日”按工作日计算；表中60日、30日、起诉15日通常按自然日计算。起算当日通常不计入，末日为法定休假日时依法顺延；中止、附带审查等法定不计入办案期限的情形另按规定处理。

特殊申请期限：未告知复议权利、复议机关和申请期限的，从知道或应当知道这些事项之日起计算，但自知道或应当知道行政行为内容之日起最长不超过1年。另有最长保护期限：从行政行为作出之日起，不动产申请超过20年、其他申请超过5年的不予受理。**5年、20年不等于可以任意拖延申请，正常仍须遵守60日等申请期限。**

### 补充说明：用同一张罚单看懂三个期限

以下为假设例子，采用普通程序，不考虑延期、中止等特殊情形：

1. **6月1日**，交警当场向小王作出罚款决定，小王认为罚错了。从知道该行为这个节点计算，一般应在60日内申请复议；他可以马上申请，不必等满60日。
2. **6月10日**，小王提交复议申请；假设复议机关**6月12日受理**。普通程序一般从受理这个节点计算60日办案期限。这是给机关办案的时间，不是要求小王再等60日才能提交材料。
3. 假设机关**7月3日作出决定**，维持罚款；小王**7月6日收到决定书**，仍不服，一般应在收到后的15日内依法起诉。他7月7日就可以起诉，不必等到最后一天。

| 期限 | 谁要办事 | 办什么 |
| --- | --- | --- |
| 申请60日 | 小王 | 提交行政复议申请 |
| 普通程序办案60日 | 复议机关 | 审理并作出决定 |
| 收到决定书后起诉15日 | 小王 | 向法院提起行政诉讼 |

**“多少日内”是最迟期限，不是必须等待的时长。**就像“3天内交作业”，今天交也可以。记忆：**申请60，审查5；普通60加30，简易30；不服起诉15。**

依据：[行政复议法第20—21、30—31、34、39、62、88条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_70518816df484be18f6b38fa295750bb.html)、[行政诉讼法第45条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_ba3b20d736d14aeeb1ace665f0f51a21.html)。

## 五、行政诉讼

| 考点 | 规则 |
| --- | --- |
| 起诉期限 | 直接起诉：知道或应当知道行政行为之日起 **6 个月**；经复议后不服：收到复议决定 **15 日**内 |
| 受案范围 | 具体行政行为（处罚、强制、许可、不履行法定职责等）；**抽象行政行为、内部人事处分、刑事侦查行为不可诉** |
| 管辖 | 基层法院管辖一审为原则；**县级以上地方政府为被告的案件由中级法院管辖** |
| 被告 | 经复议维持的，**原机关与复议机关是共同被告**（复议改变的，复议机关是被告） |
| 调解 | 行政诉讼**不适用调解**（行政赔偿、补偿及行使自由裁量权案件除外） |
| 举证责任 | **被告（行政机关）对行政行为的合法性负举证责任**（民告官、官举证） |

## 六、国家赔偿

- **行政赔偿范围**：违法拘留、违法采取限制人身自由的强制措施；非法拘禁或以其他方法剥夺公民人身自由；违法使用武器警械造成公民身体伤害或死亡；违法罚款、吊销许可证、查封扣押冻结财产等。
- **不予赔偿**：因公民、法人**自己的行为**致使损害发生的；行政机关工作人员**与行使职权无关**的个人行为。
- 赔偿标准（人身自由）：每日赔偿金按**国家上年度职工日平均工资**计算。
- 程序：赔偿请求人可**先向赔偿义务机关提出**，也可在申请复议 / 提起诉讼时一并提出（时效 **2 年**）。

## 七、精讲情境例题（2 例）

**例 1.** 县公安局以张某殴打他人为由决定罚款 5000 元。作出决定前，民警未告知张某享有听证权利。该处罚决定？
A. 程序违法，张某有权要求听证
B. 合法，罚款一律不属于听证范围
C. 合法，只有拘留才有听证
D. 程序轻微违法，不影响决定效力

**解析：** A 对——较大数额罚款属于法定听证范围，**应当告知**听证权利，未告知的构成程序违法（可导致决定被撤销）。B、C 错在范围；D 是"程序瑕疵不影响效力"的误用——**应听证未听证是重大程序违法**。**陷阱：** 听证是"**应当告知**、当事人**要求**才组织"，考题爱把"必须组织听证"设为错误项。

**例 2.** 李某对某区公安分局的行政拘留决定不服，下列救济说法正确的是？
A. 只能先申请行政复议
B. 可以自由选择申请复议或直接提起行政诉讼
C. 直接起诉的期限为收到处罚决定之日起 15 日
D. 复议维持后起诉的，只能以区政府为被告

**解析：** B 对——行政拘留不属于复议前置事项，可自选救济途径。C 错（直接起诉 6 个月，15 日是复议后再起诉的期限）；D 错（复议维持的，原机关与复议机关是**共同被告**）。**陷阱：** "复议前置"清单要记准，别把所有公安行为都当前置。

## 八、易错点清单

1. **扣押 = 强制措施，加处罚款 = 强制执行**；查封扣押 30+30 日。
2. 处罚时效一般 **2 年**（涉生命健康 / 金融安全且有危害后果 5 年），**治安案件 6 个月**——特别法优先。
3. 听证范围会背清单：**较大数额罚款、吊销许可证件、责令停产停业 / 关闭、限制从业等较重处罚**（"警告、通报批评、小额罚款"不在内）。
4. 复议 **60 日**申请、60 日审理；诉讼直接 **6 个月**、复议后 **15 日**——四个数字两两配对。
5. **官举证**：行政诉讼中被告对合法性负举证责任。
6. 行政诉讼不适用调解（例外：赔偿、补偿、自由裁量案件）。
7. 每日赔偿金按**上年度职工日平均工资**；赔偿时效 **2 年**。

## 九、速记卡（考前 5 分钟过一遍）

> 许可放行确认盖，处罚制裁强制保；扣押措施加罚执，一次不再二罚款。
> 听证较重处罚先，九十日内要裁完；时效两年特殊五，治安六月特别先。
> 复议申请六十日，普通六十简三十；诉讼直诉六月整，复议之后十五日。
> 官家举证民告官，赔偿日均工资算；夜间假节不执行，停水断电逼民完。

### 答案附录

1. 较大数额罚款；没收较大数额违法所得；降低资质等级、吊销许可证件；责令停产停业、责令关闭、限制从业；法律、法规、规章规定的其他较重的行政处罚。
2. 不得超过 **30 日**；情况复杂的经批准可延长，延长期限不超过 **30 日**。
3. 申请一般 **60 日**内；普通程序受理后60日内（复杂案件经批准最多延长30日），简易程序30日内。复议前置：当场处罚、侵犯已依法取得的自然资源所有权或使用权的决定、未履行法定职责、申请政府信息公开被决定不予公开，以及法律、行政法规规定的其他情形（如纳税争议）；不能将工伤认定争议一律列为前置。
4. **被告（行政机关）**对行政行为合法性负举证责任；直接起诉 **6 个月**，经复议后不服的 **15 日**内起诉。
5. 因公民、法人**自己的行为**致使损害发生的；行政机关工作人员**与职权无关的个人行为**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **分类错**：许可 / 确认 / 处罚 / 强制（措施 / 执行）定性错；
- **数字错**：60 / 15 / 6 个月、30+30 日、2 年 / 5 年 / 6 个月；
- **范围错**：听证清单、复议前置清单、赔偿范围记漏项；
- **规则错**：举证责任倒置、共同被告、不适用调解等"官民规则"记反。
