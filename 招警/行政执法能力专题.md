# 行政执法能力专题（接处警 / 盘查 / 办案程序 / 调解 / 应急处突）⭐

> 基本能力板块的"日常执勤手册"：警察每天做的事——接警、到现场、盘查、办治安案件、调解纠纷。考法几乎全是**情境题**：给你一个现场，问下一步做什么 / 哪步做错了。
> 使用方法：过流程 → 记"程序顺序 + 人员配置"硬规则 → 到 [情境题专项专题](情境题专项专题.md) 练综合案例 → 错点记入 [错题本.md](../错题本.md)。

## 一、接处警（一切勤务的起点）⭐

### 110 接处警基本流程

接受报警（问清**时间、地点、事由、人数、伤亡**）→ 分类处置（紧急警情立即派警，"有警必接、有难必帮"）→ 民警到场先期处置 → 反馈与回告。

### 到场先期处置的通用顺序（情境题万能框架）

1. **控制现场**：制止正在进行的违法犯罪，隔离冲突双方；
2. **救护优先**：有人受伤先组织救治（人身安全 > 案件办理）；
3. **保护现场**：划定区域、固定证据、寻找证人；
4. **稳控疏导**：疏散围观群众，防止事态扩大；
5. **查验证件、初步询问**，判断案件性质（治安 / 刑事 / 民事纠纷 / 非警务活动）；
6. **分流处理**：属刑事案件的立案侦查；属治安案件的办理；民事纠纷引导调解或诉讼；非警务活动移交主管部门（同时做好解释）。

> 记忆：**止—救—护—疏—查—分**。任何"先查证件再救人""先带走双方再管伤员"的选项都是错的。

### 常见警情处置要点

| 警情 | 处置要点 |
| --- | --- |
| 家庭暴力 | 及时出警、制止暴力、协助就医鉴定；**告诫书**制度（情节较轻不予治安处罚的，可出具告诫书）；告知申请人身安全保护令的途径 |
| 纠纷类（邻里、债务） | 稳控情绪，能调解的现场调解；涉嫌违法的依法处理，"民转刑"苗头要上报 |
| 聚众滋事 | 控制带头人员、疏散人群、固定证据，防止升级 |
| 群众求助（走失、危难） | 立即救助，不属于职责范围的说明并转交 |
| 醉酒人员 | 对本人有危险或对他人人身财产有威胁的，可**约束至酒醒**（保护性约束措施，使用约束室 / 约束带并注意安全监控，不能与办案区混用） |

## 二、盘查（人民警察法第 9 条的操作化）⭐

| 环节 | 规则 |
| --- | --- |
| 条件 | 对有**违法犯罪嫌疑**的人员（着装、神态、携带物等综合判断） |
| 人数 | 执行盘查的民警**不得少于 2 人** |
| 当场盘问、检查 | **出示证件**（着装执勤时可不出示？——着装并佩戴警号可表明身份，但被要求时应当出示）；检查物品须被检查人见证 / 配合 |
| 检查妇女身体 | **由女性工作人员进行** |
| 继续盘问 | 符合法定情形（被指控犯罪、有现场作案嫌疑、携带物品可能是赃物等）→ 带至公安机关，**24 小时内**，特殊经县级批准 **48 小时** |
| 身份不明 | 对拒不提供真实身份的，可按身份不明的程序处理；发现系在逃人员的立即控制 |

> 情境题坑点：盘查要"**有嫌疑依据**"——随便拦人检查是滥用职权；但对"行为可疑"（躲闪、携带可疑物品）可以盘查。

## 三、治安案件办理程序（全流程串一遍）

```
受案（报案材料登记）→ 受案审查（是否属于管辖、是否构成案件）
→ 调查取证（传唤、询问、检查、扣押、鉴定）
→ 告知（拟处罚事实、理由、依据 + 陈述申辩权；较重处罚告知听证权）
→ 决定（负责人审查决定；重大案件集体讨论）
→ 送达、执行（拘留送所、罚款缴银行；复议诉讼期间可申请暂缓执行拘留）
→ 结案归档
```

- **受案必须先收**：对报案、控告、举报和违法行为人的陈述，都应当立即接受（不是"先审查再决定收不收"）；
- **证据保全**：对与案件有关的物品可以扣押，开具清单；**与案件无关的不得扣押**；
- **快速办理**：对事实清楚、违法嫌疑人自愿认错认罚且有证据支持的案件，可以简化取证 / 告知程序，缩短办案时间（简易程序的扩展，期限以办案规定为准）；
- 具体时限、调解、听证、暂缓执行等数字见 [治安管理处罚法专题](治安管理处罚法专题.md)。

## 四、治安调解（情境判断三问）

1. **是不是民间纠纷引起的？**（不是 → 不能调解）
2. **是不是打架斗殴 / 损毁财物等行为且情节较轻？**（重伤害 → 刑事，轻伤 → 刑事自诉衔接，均不适用治安调解）
3. **调解结果如何？**（协议履行 → 不予处罚；不履行 → 依法处罚 + 告知民事诉讼）

> 不能 / 不宜调解的情形：雇凶伤害他人的；涉及黑恶势力的；寻衅滋事 / 聚众斗殴的；多次实施违反治安管理行为的；当事人明确不愿调解的；其他不宜调解的情形（多选题考点，按办案规定掌握）。

## 五、应急处突（突发事件先期处置）

- 突发事件分级：特别重大（Ⅰ）、重大（Ⅱ）、较大（Ⅲ）、一般（Ⅳ）；
- 民警先期处置职责：**先期控制**（封锁现场、设置警戒）、**抢救疏散**（人员优先）、**报告预警**（第一时间报告上级与指挥部）、**维护秩序**（防止趁乱作案、舆情发酵）；
- 处置原则：**以人为本、生命至上**；依法处置、防止激化；统一指挥、快速反应；
- 群体性事件处置：坚持"**三个慎用**"（慎用警力、慎用武器警械、慎用强制措施），教育疏导为主、隔离控制核心违法人员。

## 六、精讲情境例题（2 例）

**例 1.** 民警接警赶到斗殴现场，发现甲倒地流血、乙欲离开、围观群众聚集。下列处置顺序最恰当的是？
A. 先将乙强制传唤到案 → 再处理甲
B. 制止违法行为并控制乙 → 组织救助甲 → 疏散群众、保护现场 → 询问取证
C. 先疏散群众 → 再控制乙 → 最后救甲
D. 等待救护车和增援到场后再处置

**解析：** B 对——**止—救—护—疏—查**的顺序。A 错（人身救助优先于办案，且甲的伤情本身是证据）；C 错（疏散先于控制会放跑违法行为人，救助更不能等）；D 错（消极等待 = 不作为）。**陷阱：** "控制嫌疑人"与"救人"谁先——**正在进行的危险先止，已发生的伤害先救**。

**例 2.** 深夜，民警巡逻发现李某推一辆无牌电动车，神色慌张，言语矛盾。下列做法正确的是？
A. 李某未实施犯罪，不得盘查
B. 经表明身份当场盘问、检查；因李某不能说明车辆合法来源且有作案嫌疑，带至公安机关继续盘问
C. 直接对李某使用手铐带走
D. 扣押电动车后放李某离开

**解析：** B 对——有违法犯罪嫌疑（携带物可能是赃物）即可当场盘问检查，符合继续盘问情形的带至公安机关（24/48 小时内盘问）。A 错（"嫌疑"即可盘查，不要求已实施犯罪）；C 错（手铐是约束性警械，仅用于防止脱逃 / 行凶 / 自伤等危险，不是盘查标配）；D 错（人车分离不利查明来源，继续盘问的对象正是人）。**陷阱：** 盘查权与警械使用条件是两套门槛，别混。

## 七、易错点清单

1. 先期处置顺序：**制止 → 救助 → 保护现场 → 疏导 → 调查**，救人永远在办案前。
2. 盘查民警**至少 2 人**；检查妇女身体由**女性工作人员**进行。
3. 继续盘问 **24/48 小时**是人民警察法的留置盘问，不是刑诉法的传唤 / 拘传——三套制度三种时限。
4. 报案"**先受理再审查**"：拒绝接收报案材料是程序违法。
5. 家庭暴力"告诫书"适用：情节较轻、依法不予处罚的情形——不是所有家暴都告诫了事（构成治安违法 / 犯罪的依法处理）。
6. 群体性事件"**三个慎用**"：慎用警力、警械武器、强制措施（多选常拆开考）。
7. 醉酒约束是**保护性约束措施**（行政强制措施），目的是防止危险，不是惩罚。

## 八、速记卡（考前 5 分钟过一遍）

> 接警六字止救护，疏散查证再分流；盘查两人亮证件，妇女检身女警办。
> 继续盘问廿四时，县级批准四十八；受案先收后审查，告知听证莫忘它。
> 民间纠纷轻情节，可以调解不必须；群体事件三慎用，生命至上记心中。

## 九、自测练习

1. 民警到场先期处置的通用顺序是什么？
2. 继续盘问的适用条件、时限和批准规则是什么？
3. 治安调解的适用范围是什么？哪些情形不适用调解？
4. 家庭暴力警情的处置要点有哪些？
5. 群体性事件处置的"三个慎用"是什么？

### 答案附录

1. 制止违法犯罪 → 组织救助伤者 → 保护现场 → 疏散疏导 → 初步调查、判断性质 → 分流处理（止救—护—疏—查—分）。
2. 适用条件：被指控有犯罪行为 / 有现场作案嫌疑 / 携带的物品可能是赃物等；自带至公安机关起 **24 小时**内，特殊情况经**县级以上公安机关批准**可延长至 **48 小时**。
3. 适用：因**民间纠纷**引起的**打架斗殴或损毁他人财物**等**情节较轻**的。不适用：雇凶伤害、涉黑恶、寻衅滋事 / 聚众斗殴、多次违反治安管理、当事人明确不愿调解等。
4. 及时出警制止暴力；协助就医、伤情鉴定；情节较轻不予治安处罚的出具**家庭暴力告诫书**；告知可向法院申请**人身安全保护令**；构成违法 / 犯罪的依法处理。
5. **慎用警力、慎用武器警械、慎用强制措施**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **顺序错**：先期处置各环节先后颠倒（救人与办案的优先级）；
- **门槛错**：盘查 / 继续盘问 / 使用警械各自的启动条件记混；
- **数字错**：24/48、2 人、期限类；
- **处置错**：选了"合法但不是最优"的选项（情境题要选**合法 + 程序对 + 效果最优**的交集）。
