# 情境题专项专题（题型拆解 / 做题四步法 / 陷阱库）⭐

> 情境题是公安专业科目**最大的拉分板块**（约三成题量）：给一段执法情境材料，其下挂 3-5 道单选 / 多选。考的不是背诵，是**"假如你是这个民警，下一步怎么办"**。
> 本专题是方法论：先把各法律专题（[治安](治安管理处罚法专题.md) / [刑诉](刑事诉讼法专题.md) / [警械武器](人民警察法与警械武器专题.md) / [行政执法能力](行政执法能力专题.md)）学完再来，效果最佳。
> 使用方法：学方法 → 逐个精讲例题练"四步法" → 错点按陷阱类型归类进 [错题本.md](../错题本.md)。

---

## 一、题型拆解：情境题长什么样

**题干样例：**"某日 22 时许，民警甲、乙巡逻至某 KTV 门口时，发现多人聚集争吵，一名男子（后查明为张某）手持酒瓶抵在另一男子颈部……"

**下设小题类型：**

| 类型 | 问法 | 答题要点 |
| --- | --- | --- |
| **定性题** | 张某的行为构成何罪 / 属于何种违法？ | 用刑法 / 治安法分界（伤情、手段、数额） |
| **措施题** | 民警此时可以 / 应当采取什么措施？ | 警械使用条件、强制措施阶梯、处置顺序 |
| **程序题** | 后续办案程序正确的是？ | 时限、告知、文书、人数等硬规则 |
| **群众工作题** | 面对围观群众 / 家属，恰当的做法是？ | 态度 + 方法 + 保密 + 舆情 |
| **组合题（多选）** | 本案处置中正确的做法有哪些？ | 逐项判对错，宁缺毋滥 |

## 二、做题四步法 ⭐（核心方法）

**第一步：定位板块。** 扫一眼情境要素判断主战场：打打杀杀 → 治安 / 刑事定性；办案流程 → 程序时限；用枪用铐 → 警械武器；群众围观 → 群众工作。

**第二步：找"硬规则"。** 情境题 90% 的答案锚点是一条硬规则（时限 / 条件 / 禁止情形）。先想"法律怎么规定"，再看选项。

**第三步：代入角色排序。** 你就是现场民警，按**止—救—护—疏—查—分**的顺序和"比例原则"（能用轻的不用重的）选出最优项。

**第四步：多选题逐项"三问"。** ①合法吗（有无法律依据）？②程序对吗（时限、人数、告知）？③是最优吗（有没有更合理选项）？三项全过才选——**多选漏选得部分分、错选不得分的规则下，拿不准的项宁可不选**（按当年考试说明执行）。

## 三、陷阱库（八大经典陷阱，做错就对号入座）⭐

| 陷阱 | 长什么样 | 反制口诀 |
| --- | --- | --- |
| **合理不合法** | "为尽快破案，先搜查再补搜查证" | 目的正当 ≠ 程序合法 |
| **顺序颠倒** | 先抓人再救人；先处罚后告知 | 人身安全永远第一 |
| **档位用错** | "必须"调解、"一律"不得开枪 | 警惕"必须 / 一律 / 只能"，找例外条款 |
| **过度处置** | 对口角双方直接上拘留、铐人 | 比例原则：能轻则轻 |
| **处置不足** | 发现家暴只"批评教育"了事 | 构成违法的必须依法处理 + 告诫书 |
| **身份错配** | 辅警独立讯问、单独执法 | 执法主体资格是硬杠杠 |
| **信息泄露** | 把案情发朋友圈、向同学透露查询信息 | 保密是底线，泄露即违纪违法 |
| **对象错配** | 对孕妇使用约束性警械"防止逃跑"（无危险行为时） | 每种手段都有适用对象条件 |

## 四、精讲例题（完整情境 2 组，用四步法走一遍）

### 例组 1（治安 + 程序）

**情境：** 21 时许，某烧烤摊，李某酒后因琐事将摊主王某打成**轻微伤**（经鉴定），围观者报警。民警 10 分钟后到场，李某仍在辱骂推搡。

**（1）本案定性？**
- 四步法：定位（治安/刑事分界）→ 硬规则：**轻微伤 = 治安案件（殴打他人）**；轻伤以上才入刑。
- 答案：违反治安管理的殴打他人行为，公安行政处罚案件。

**（2）到场后的处置顺序？**
- 止（制止辱骂推搡、控制李某）→ 救（查看王某伤情、协助就医）→ 护（调取监控、寻找证人）→ 疏（疏散围观）→ 查（传唤李某到案询问）。
- 陷阱提示："先行调解再处理"看似和谐，但李某**正在现场继续滋事**，先控制后谈调解。

**（3）若决定对李某行政拘留 10 日并处罚款，程序上须做什么？**
- 告知拟处罚内容、事实理由依据 + **陈述申辩权**；拟处**四千元以上罚款**或吊销许可证件的告知**听证权**；处罚决定书**当场交付 / 送达**（不能当场宣告的 2 日内送达）；告知复议诉讼权利；拘留送所执行。
- 陷阱提示："口头宣布拘留带走"必错——处罚须**决定书**。

**（4）李某申请行政复议并申请暂缓执行拘留，怎么办？**
- 硬规则：复议期间可申请暂缓执行；公安机关认为**不致发生社会危险**的，由其或近亲属**提供担保人**或**按每日 200 元交纳保证金** → 暂缓。

### 例组 2（刑事 + 警械武器 + 程序）

**情境：** 民警甲、乙设卡盘查，一辆黑色轿车突然冲卡，将辅警撞倒（轻伤）后逃逸，两小时后在一小区内发现该车，驾驶人赵某（无证、涉嫌酒驾）弃车逃跑被群众协助堵住。

**（1）冲卡撞伤辅警的行为定性？**
- 暴力袭击正在依法执行职务的人民警察（含共同执行职务的警务人员），驾车撞击——**袭警罪**（加重档：以驾驶机动车撞击等手段严重危及人身安全），另有危险驾驶罪（醉驾成立时）数罪问题按案情处理。

**（2）设卡盘查时能否直接开枪射击轮胎逼停？**
- 硬规则：使用武器须"判明暴力犯罪 + 紧急情况 + 警告（或来不及警告）"；本案冲卡时撞人，属暴力犯罪紧急情形，但**须评估周边环境**（人群、危险物品场所禁区）——情境题标准答案是"判明情况、依法可以使用武器"或"视危险程度决定"，选项"一律不得开枪""必须击毙"都是错的。

**（3）赵某被控制后民警应做什么？**
- 带至公安机关（继续盘问 / 传唤）；呼气酒精检测，涉嫌醉驾的抽血送检；无证驾驶依法处理；拒绝配合的强制检测（按办案规定）。
- 程序陷阱：血液检测须由**医护人员**按规范抽取，民警不能自采。

**（4）本案证据收集要点（多选）？**
- 卡口监控、执法记录仪视频（民警现场记录）；辅警伤情鉴定；证人（在场群众）证言；车辆痕迹勘验。逐项"三问"全过 → 全选。

## 五、自测练习

1. 情境题做题四步法是什么？
2. "合理不合法"陷阱的典型样子？如何反制？
3. 多选题的"三项全过"指哪三问？
4. 到场先期处置的六字顺序是什么？
5. 遇到"必须""一律""只能"字眼的选项，第一反应是什么？

### 答案附录

1. 定位板块 → 找硬规则 → 代入角色排序 → 多选逐项三问。
2. 目的正当但程序违法（如"先搜查后补证"）；反制：程序合法性独立审查，目的正当不豁免程序。
3. ①合法吗（有无法律依据）②程序对吗（时限 / 人数 / 告知）③是最优吗（比例原则）。
4. **止—救—护—疏—查—分**（制止 → 救助 → 保护现场 → 疏散 → 调查 → 分流）。
5. 提高警惕，回忆例外条款（如"孕童不得开枪"有"持枪暴力犯罪除外"）——绝对化表述大概率是错的。

## 错题归因模板

做错时按陷阱类型归因，记入 [错题本.md](../错题本.md)：

- **定性错**：案件性质（治安 / 刑事）判断错 → 回刑法、治安专题的分界线；
- **程序错**：时限、告知、文书、主体资格 → 回对应法律专题的速查表；
- **处置错**：顺序颠倒或档位失衡（过度 / 不足）→ 回"比例原则 + 六字顺序"；
- **审题错**：漏看伤情等级、年龄、孕产等身份细节 → 把题干关键词圈出来的习惯练起来。
