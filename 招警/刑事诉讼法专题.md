# 刑事诉讼法专题（管辖 / 强制措施 / 侦查 / 期限）⭐

> 刑诉法是专业科目的"程序骨架"：**五种强制措施的适用条件与时限、侦查措施怎么用、办案期限多长**——几乎全部考"程序对不对"。
> 考法：单选多选考数字（时限）与条件（何时取保、何时拘留），情境题给执法场景挑程序错误。
> 修法动态（截至 2026 年 9 月）：第四次修改已列入全国人大常委会 2026 年度立法工作计划，**预计年内初次审议，尚未通过**——本专题以 2018 年修正的现行法为准。修法热点：律师辩护全覆盖（延伸至侦查阶段）、认罪认罚从宽完善、值班律师制度；新法通过后须及时更新本专题。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

## 一、基本制度

- **未经人民法院依法判决，对任何人都不得确定有罪**（法院专属定罪权）。
- 职能分工：**公安机关负责侦查、拘留、执行逮捕、预审**；人民检察院负责批准逮捕、提起公诉、诉讼监督；人民法院负责审判。
- 管辖分工（刑事案件由谁办）⭐：

| 机关 | 管辖 |
| --- | --- |
| **公安机关** | 绝大部分刑事案件的侦查 |
| **监察委员会** | 职务违法和职务犯罪（贪污贿赂、渎职等） |
| **人民检察院** | ①诉讼监督中发现的**司法工作人员利用职权实施的侵犯公民权利、损害司法公正的犯罪**（如刑讯逼供、徇私枉法）②公安机关管辖的国家机关工作人员利用职权实施的重大犯罪案件，经**省级以上检察院决定**可由检察院立案侦查 |
| **人民法院（自诉）** | ①**告诉才处理**的案件（侮辱、诽谤，暴力干涉婚姻自由，虐待，侵占）②被害人有证据证明的轻微刑事案件 |

- 地域管辖：刑事案件**由犯罪地的人民法院管辖**；被告人居住地更适宜的，可以由被告人居住地管辖。

## 二、五种强制措施（适用条件 + 时限，全卷最重表格 ⭐⭐）

| 措施 | 适用对象 / 条件 | 关键时限 |
| --- | --- | --- |
| **拘传** | 未被羁押的犯罪嫌疑人、被告人 | 持续不得超过 **12 小时**；案情特别重大、复杂需要拘留逮捕的不得超过 **24 小时**；不得连续拘传变相拘禁 |
| **取保候审** | ①可能判处**管制、拘役**②可能判处徒刑以上但采取取保不致发生社会危险性③患严重疾病、生活不能自理，**怀孕或正在哺乳自己婴儿的妇女**④羁押期限届满案件尚未办结 | 最长 **12 个月**；执行机关为公安机关（提出保证人或交纳保证金，**不得同时**用） |
| **监视居住** | 符合逮捕条件但有特殊情形（患病、怀孕哺乳、系生活不能自理的人的唯一扶养人、羁押届满等）；住处执行为原则，**指定居所**为例外（无固定住处；涉嫌危害国家安全、恐怖活动犯罪，住处执行有碍侦查经上一级公安机关批准） | 最长 **6 个月** |
| **刑事拘留** | **现行犯或重大嫌疑分子**，且具有：正在实行犯罪 / 被害人指认 / 身边查出犯罪证据 / 犯罪后企图自杀、逃跑 / 可能毁灭伪造证据或串供 / 不讲真实姓名、住址，身份不明 / 有流窜、多次、结伙作案重大嫌疑 | 公安机关提请批捕：拘留后 **3 日**内，可延长 **1-4 日**；**流窜、多次、结伙**作案的可延长至 **30 日**；检察院 **7 日**内决定是否批准逮捕 |
| **逮捕** | 有证据证明有犯罪事实，可能判处**徒刑以上**刑罚，采取取保不足以防止社会危险性 | 由检察院批准或法院决定，**公安机关执行**；逮捕后 **24 小时内**讯问、通知家属（无法通知除外） |

> 记忆链：**3 → +1~4 → 30（三种人）→ 检察院 7 日**，极限情形下公安机关关押 37 天（俗称"黄金 37 天"）。

### 拘留 / 逮捕后的两个 24 小时

1. **24 小时内讯问**：发现不应当拘留 / 逮捕的必须立即释放；
2. **24 小时内通知家属**（除无法通知或涉嫌危害国家安全、恐怖活动犯罪通知可能有碍侦查的情形——后者有碍侦查情形消失后应立即通知）。

## 三、侦查措施（情境题挑错用）⭐

| 措施 | 程序要点 |
| --- | --- |
| **讯问** | 讯问犯罪嫌疑人须由**侦查人员 2 人**进行；犯罪嫌疑人送看守所羁押后，讯问应当在**看守所内**进行；侦查阶段可委托律师为辩护人（自被侦查机关第一次讯问或采取强制措施之日起） |
| **辩护律师会见** | 凭"三证"（律师执业证、律所证明、委托书或法律援助公函）要求会见在押犯罪嫌疑人，看守所应当及时安排，**至迟 48 小时**；**危害国家安全、恐怖活动犯罪**案件侦查期间会见须经侦查机关**许可** |
| **勘验、检查** | 侦查人员执行；**检查妇女身体应当由女工作人员或医师进行** |
| **搜查** | 须出示**搜查证**；执行拘留、逮捕时遇**紧急情况**（可能随身携带凶器、隐藏爆炸剧毒物品、毁弃转移犯罪证据等）可以**无证搜查** |
| **查封、扣押** | 与案件**无关的财物、文件不得查封扣押**；应当会同在场见证人和持有人查点清楚，开列清单 |
| **技术侦查** | 立案后，对**危害国家安全、恐怖活动、黑社会性质组织、重大毒品犯罪**等案件，经过**严格批准手续**；批准期限 **3 个月**（可延长，每次不超过 3 个月） |
| **通缉** | 对应当逮捕而在逃的犯罪嫌疑人，**县级以上公安机关**可以发布**通缉令**（超出自己管辖区域的，报请上级发布） |

## 四、侦查羁押期限与办案节点

- 逮捕后的侦查羁押期限：**2 个月**；案情复杂、期限届满不能终结的，经检察院批准**延长 1 个月**（四类重大复杂案件可再延长，可能判处 10 年以上再延长——阶梯为 2+1+2+2）；
- **立案程序**：接受控告、举报、报案后**应当先接受**（不属于管辖的移送主管机关）→ 审查认为有犯罪事实需要追究刑责的**立案**；认为不立案的，将不立案原因通知控告人，控告人不服可以**申请复议**；
- 证据种类 8 种：物证，书证，证人证言，被害人陈述，犯罪嫌疑人、被告人供述和辩解，鉴定意见，勘验、检查、辨认、侦查实验等笔录，视听资料、电子数据；
- **非法证据排除**：采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述等应当予以排除（重证据、不轻信口供政策的程序化）。

## 五、精讲情境例题（2 例）

**例 1.** 某县公安局对涉嫌盗窃的李某执行刑事拘留。下列做法正确的是？
A. 拘留后第 5 日，因案情复杂报本局局长批准延长提请批捕时间
B. 拘留后立即将李某送看守所羁押，24 小时内讯问并通知家属
C. 讯问由一名侦查人员进行，另一名辅警协助记录
D. 李某系流窜作案，提请批捕时间延长至拘留后 60 日

**解析：** B 对（两个 24 小时）。A 错——延长 1-4 日经**县级以上公安机关负责人**批准，但"第 5 日"已超出 3+4=7 日的普通上限；C 错——讯问须**侦查人员 2 人**；D 错——流窜 / 多次 / 结伙作案上限是 **30 日**，不是 60 日。**陷阱：** 30 日是"3 日基础上的延长上限"，不是再加 30。

**例 2.** 关于辩护律师会见在押犯罪嫌疑人，下列说法正确的是？
A. 一律须经侦查机关许可
B. 凭三证要求会见，看守所至迟 48 小时内安排；危害国家安全犯罪案件侦查期间须经许可
C. 侦查阶段律师不得会见
D. 会见时侦查机关应当派员在场听取

**解析：** B 对。A、C 均错（一般案件无需许可，侦查阶段自第一次讯问后即可委托辩护律师）；D 错——辩护律师会见**不被监听**。**陷阱：** "三类许可案件"只剩**危害国家安全、恐怖活动**两类（2018 年修法调整），且"不被监听"是硬规则。

## 六、易错点清单

1. **取保 12 个月、监视居住 6 个月**；拘传 12/24 小时——三个"月 / 小时"别串。
2. 提请批捕链条 **3 日 → +1-4 → 流窜多次结伙 30 日 → 检察院 7 日**；"37 天"是极限合成。
3. 逮捕由**检察院批准 / 法院决定、公安机关执行**——公安机关自己"批准逮捕"必错。
4. 讯问在看守所内进行（送押后）；**会见不被监听**；许可案件仅限危害国家安全、恐怖活动。
5. 无证搜查只能发生在**执行拘留、逮捕时遇紧急情况**——日常搜查必须有搜查证。
6. 通缉令**县级以上公安机关**发布；越辖区报上级。
7. 12-14 周岁刑责须经**最高检核准追诉**（与刑法专题联动）。

## 七、速记卡（考前 5 分钟过一遍）

> 拘传十二二四时，取保一年居半载；拘留三日加四天，流窜多次结伙卅。
> 批捕七日检决定，公安执行别记反；捕后两个二十四，讯问通知不能缓。
> 搜查要证有例外，拘留逮捕紧急险；技侦三月可再延，通缉县级可越权。
> 危恐案件会许可，看守所内四十八；羁押二月延一月，阶梯二加二再加。

## 八、自测练习

1. 五种刑事强制措施分别是什么？取保候审、监视居住的最长期限各是多少？
2. 公安机关拘留后提请批准逮捕的期限规则是什么？
3. 哪两类案件侦查期间辩护律师会见须经侦查机关许可？
4. 什么情况下可以无证搜查？
5. 检察院直接立案侦查的案件范围是什么？

### 答案附录

1. 拘传、取保候审、监视居住、刑事拘留、逮捕；取保候审最长 **12 个月**，监视居住最长 **6 个月**。
2. 拘留后 **3 日**内提请批准逮捕；情况特殊可延长 **1-4 日**；流窜作案、多次作案、结伙作案的重大嫌疑分子，可延长至 **30 日**；检察院 **7 日**内作出决定。
3. **危害国家安全犯罪、恐怖活动犯罪**案件（在侦查期间）。
4. 在**执行拘留、逮捕**过程中遇紧急情况（如可能随身携带凶器、隐藏爆炸剧毒物品、企图毁弃转移犯罪证据等）。
5. ①司法工作人员利用职权实施的侵犯公民权利、损害司法公正的犯罪（刑讯逼供、徇私枉法等 14 类）；②对公安机关管辖的国家机关工作人员利用职权实施的重大犯罪案件，经省级以上检察院决定。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **数字错**：强制措施期限、提请批捕链条、羁押期限（回表重记）；
- **主体错**：谁批准逮捕、谁发布通缉令、谁自侦；
- **程序错**：讯问地点、会见规则、搜查证件要求；
- **情境错**：题干条件（流窜 / 多次 / 结伙；危安 / 恐怖）漏看导致时限档位选错。
