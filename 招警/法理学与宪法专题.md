# 法理学与宪法专题（法学基础理论 + 宪法相关考点）

> 法律基础知识的"地基篇"：考法学的**概念、渊源、关系、责任**四件事 + 宪法里与执法相关的高频点。
> 考法：单选多选考概念辨析（判例是不是法源、什么算法律关系），分数不多但**性价比高**——全是死知识。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。与常识模块互链：[常识·法律常识专题](../xingce/常识判断/法律常识专题.md)。

## 一、法的概念与特征

- 法的定义：由国家**制定或认可**、以国家强制力保证实施的**行为规范**的总和。
- 四大特征：①**规范性**（规定权利义务）；②**国家意志性**（制定或认可）；③**国家强制性**（军队、警察、法庭、监狱为后盾）；④**普遍性**（在其管辖范围内普遍适用）。
- 常考辨析：道德、宗教戒律、单位规章**不是法**——缺"国家意志 + 国家强制"。

## 二、法的渊源（公安考试爱考"判例算不算"）

| 渊源 | 制定机关 | 要点 |
| --- | --- | --- |
| **宪法** | 全国人大 | 最高法律效力 |
| **法律** | 全国人大（基本法律）及其常委会（一般法律） | 保留事项：犯罪与刑罚、限制人身自由的强制措施和处罚**只能制定法律** |
| **行政法规** | 国务院 | 低于法律 |
| **地方性法规** | 省级、设区的市级人大及常委会 | 本行政区域内适用 |
| **部门规章 / 政府规章** | 国务院各部委 / 省级和设区的市政府 | 与地方性法规冲突时由国务院提出意见 |
| **国际条约** | —— | 我国缔结或参加，声明保留条款除外 |

> **我国不把判例（案例）作为法的渊源**——成文法国家。选项出现"最高人民法院的判决可以反复适用，是法律渊源"必错（最高法发布的是**司法解释**，属于对法律的适用解释）。

### 法律效力层级口诀

宪法 > 法律 > 行政法规 > 地方性法规、规章。**上位法优于下位法、特别法优于一般法、新法优于旧法**。

### 补充说明：正式渊源是什么意思

**法的正式渊源，就是具有国家认可的法定效力的法律规范表现形式。**这里的“渊源”是在问法以什么形式存在，不是在追问法律最早起源于哪里；“法”取广义，包括宪法、法律、法规、规章等。

例如，《民法典》属于正式渊源，法学教授个人提出的观点不属于正式渊源。法的渊源清单不等于“所有带规定、办法、条例字样的文件”，应结合制定机关、权限和法定程序判断。

### 补充说明：行政法规、地方性法规、规章

**先看谁制定，再看适用范围和效力。**规章分为部门规章与地方政府规章；不是所有地方人大、政府或政府部门都有立法权。

| 类型 | 制定机关 | 例子及主要内容 |
| --- | --- | --- |
| 行政法规 | 国务院 | 《快递暂行条例》，规定快递经营、服务、安全和监督管理等事项 |
| 地方性法规 | 有立法权的地方人大及其常委会 | 北京市人大常委会制定《北京市生活垃圾管理条例》，规范本市垃圾分类、投放和处理等 |
| 部门规章 | 国务院有关部门等 | 交通运输部制定《快递市场管理办法》，细化全国快递市场管理规则 |
| 地方政府规章 | 有规章制定权的地方政府 | 北京市政府制定《北京市实施〈居住证暂行条例〉办法》，规范本市居住证办理和使用等 |

行政法规通常在全国适用；地方性法规、地方政府规章在相应行政区域适用；部门规章在本部门权限范围内适用，可以涉及全国相关领域。

效力分界：**行政法规高于地方性法规、规章；地方性法规高于本级和下级地方政府规章。**地方性法规与部门规章不能简单判断谁一定更高，冲突时依法定程序处理。“条例”既可能是行政法规，也可能是地方性法规，不能只看名字。

依据：[立法法第72、80—81、91、93、99—106条](https://www.bjrd.gov.cn/xwzx/qgrd/202303/t20230314_2935590.html)。例子原文：[快递暂行条例](https://xzfg.moj.gov.cn/front/law/detail?LawID=1768)、[北京市生活垃圾管理条例](https://www.beijing.gov.cn/zhengce/dfxfg/202009/t20200929_2102701.html)、[快递市场管理办法](https://xxgk.mot.gov.cn/2020/jigou/fgs/202401/t20240104_3980683.html)、[北京市居住证实施办法](https://www.beijing.gov.cn/gongkai/zfxxgk/zc/gz/202112/t20211220_2564946.html)。

## 三、法律关系（概念题 + 情境题双考）

- **三要素：主体、客体、内容（权利义务）**。
- 主体：自然人（公民）、法人、国家；**人民警察执法时是行政法律关系中的行政主体一方**。
- 客体：物、行为（如治安处罚中的"违法行为"）、人身利益、智力成果。
- 法律事实 = 引起法律关系产生、变更、消灭的客观情况，分**事件**（与人的意志无关，如死亡、自然灾害）与**行为**（人的有意识活动，如报警、打人、签合同）。

## 四、法律责任

| 责任类型 | 触发原因 | 典型承担方式 |
| --- | --- | --- |
| 民事责任 | 违约、侵权 | 赔偿损失、恢复原状、赔礼道歉 |
| **行政责任** | 违反治安管理等行政违法 | 警告、罚款、**行政拘留**、吊销许可证 |
| **刑事责任** | 犯罪 | 有期徒刑等刑罚（主刑 + 附加刑） |

> 关键分界（情境题常考）："拘留"二字两种身份：**行政拘留 = 行政责任**（治安案件），**刑事拘留 / 拘役 = 刑事**（刑事案件）。同一行为可能**只担其一**（治安处罚与刑罚一般不并用，涉嫌犯罪的按刑事办，已给予治安处罚的折抵）。

## 五、法治理念（习近平法治思想）

- **习近平法治思想**在 2020 年 11 月中央全面依法治国工作会议上确立为全面依法治国的指导思想。
- 抓总表述：坚持党对全面依法治国的领导；坚持以人民为中心；坚持**依法治国、依法执政、依法行政共同推进**，法治国家、法治政府、法治社会一体建设。
- 对公安执法的直接要求：**严格规范公正文明执法**（情境题判断执法行为时，"选择性执法""钓鱼执法""逐利执法"均违背）。

## 六、宪法高频点（执法相关）

| 考点 | 内容 |
| --- | --- |
| 公民在法律面前一律平等 | 平等权是首要的基本权利 |
| 人身自由 | **非经检察院批准或决定、法院决定，不受逮捕**（公安机关执行） |
| 人格尊严 | 禁止侮辱、诽谤和诬告陷害（执法中辱骂嫌疑人违宪违法） |
| 住宅安全 | 禁止非法搜查（搜查须依刑诉法出示搜查证） |
| 通信自由 | 只有**公安机关或检察机关**依法律规定的程序为**国家安全或追查刑事犯罪**需要，才可检查通信 |
| 依法治国 | 1999 年修宪入宪；国家工作人员**宪法宣誓**制度 |
| 国家机构 | "一府一委两院"；国务院领导全国公安工作（公安部是其组成部门） |

> 常识模块的宪法细节（修宪年份、人大职权、监委）见 [法律常识专题](../xingce/常识判断/法律常识专题.md)，两边重叠部分以那边表格为准。

### 补充说明：人大、人大常委会和政府

| 机构 | 性质 | 主要职责及例子 |
| --- | --- | --- |
| 人大，即人民代表大会 | 国家权力机关，由人大代表组成 | 依法决定重大事项、审查批准预算、选举或决定有关领导人员；有立法权的人大还制定法律或地方性法规。例如市人大选举市长、审查批准市级预算 |
| 人大常委会 | 本级人大的常设机关，由本级人大选举产生 | 经常性开展监督，依法决定重大事项、任免有关人员；有立法权的常委会还制定法律或地方性法规。例如听取、审议市政府环境治理专项工作报告 |
| 政府，即人民政府 | 国家行政机关 | 执行法律法规和有关决议，组织教育、医疗、交通、财政、市场监管等行政管理工作。例如组织污水处理设施建设、落实污染治理措施 |

人大代表大会通常每年至少举行一次会议，国家和地方事务需要持续处理，所以设常设机关依法开展经常性工作。**全国人大和县级以上地方人大设常委会，乡镇人大不设常委会。**常委会对本级人大负责并报告工作，并有自己的法定职权。

政府由本级人大产生，受其监督，对其负责并报告工作；在人大闭会期间，依法对本级人大常委会负责并报告工作。地方政府还对上一级政府负责。**国务院就是中央人民政府，是最高国家行政机关。**

### 补充说明：“由人大产生”是不是从人大代表里挑人

**由人大选举，不等于必须从人大代表中选举。**市长、县长候选人不必是本级人大代表。以县长为例：县人大会议主席团或十名以上县人大代表书面联名依法提名候选人，再由县人大代表投票，获得全体代表过半数选票才能当选。

| 职位 | 产生方式 |
| --- | --- |
| 市长、副市长，县长、副县长 | 本级人大选举 |
| 市、县政府局长等部门负责人 | 市长、县长提名，本级人大常委会依法决定任命 |
| 普通公务员 | 一般通过公务员招录等法定途径进入，不由人大逐一选举 |

“政府由人大产生”讲的是依法组成政府的制度关系，不是把一部分人大代表直接调到政府。联系法的形式记忆：**北京市人大或其常委会依法制定地方性法规，北京市政府依法制定地方政府规章。**

依据：[宪法第三章](https://www.cac.gov.cn/2018-03/22/c_1122572643.htm)、[地方组织法第26、29、50条](https://www.12371.cn/2022/03/12/ARTI1647046378091154.shtml)。

## 七、易错点清单

1. **判例不是我国法的渊源**；司法解释也不是"渊源"本身（是对法律的解释）。
2. **限制人身自由的处罚与强制措施只能由法律设定**——选项写"某省地方性法规设定行政拘留"必错。
3. 法律事实分**事件 / 行为**：地震、死亡是事件；报警、打人是行为。
4. **行政拘留 ≠ 刑事拘留**：前者是处罚（治安案件），后者是强制措施（刑事案件）——整份试卷反复考的分界。
5. 通信检查主体：**公安机关、检察机关**（法院无权），且只能为**国家安全 / 追查刑事犯罪**两项目的。

## 八、速记卡（考前 5 分钟过一遍）

> 制定认可加强制，规范普遍国家意；宪法法律行法规，判例从来非渊源。
> 上位优先特别法，新旧相争新法先；主体客体加内容，事件行为生关系。
> 限身自由唯法律，通信检查两家权；行政拘留治安案，刑事强制办刑案。

## 九、自测练习

1. 我国法的正式渊源包括哪些？"判例"是不是？
2. 法律关系的三要素是什么？
3. 限制人身自由的强制措施和处罚只能由什么规范性文件设定？
4. 宪法规定哪些机关可以依程序检查公民通信？目的限于什么？
5. 行政拘留与刑事拘留的本质区别是什么？

### 答案附录

1. 宪法、法律、行政法规、地方性法规、自治条例和单行条例、规章、国际条约；**判例不是**（我国是成文法国家）。
2. **主体、客体、内容（权利义务）**。
3. **法律**（全国人大及其常委会制定）。
4. **公安机关或者检察机关**；目的限于**国家安全或者追查刑事犯罪**的需要，且须依法律规定的程序。
5. 行政拘留是**行政处罚**（针对违反治安管理的行政违法，由公安机关裁决）；刑事拘留是**刑事强制措施**（针对现行犯或重大嫌疑分子，为侦查犯罪服务，不具惩罚性）。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **概念混**：法与道德 / 规章、渊源与解释、事件与行为；
- **主体错**：谁有权检查通信、谁有权逮捕（宪法条文的机关记错）；
- **层级错**：效力位阶与设定权限（拘留只能法律设定）；
- **情境错**：没分清案件性质导致拘留性质判断错（回到"治安 / 刑事"分界线）。
