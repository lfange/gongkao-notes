# 职业素养专题（政治素质 / 职业道德 / 纪律禁令）

> 职业素养是三大板块中最薄的一块，但**分数最稳**——考的是"记没记过"，不考理解。
> 考法：单选多选直接考原文表述（总要求、价值观、禁令内容），情境题考"哪个行为违反了纪律 / 哪个选项体现政治素质"。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

---

## 一、政治素质

### 核心表述（必背原文级别）

| 考点 | 内容 |
| --- | --- |
| 公安工作的根本原则 | **坚持党对公安工作的绝对领导**（"公安姓党"） |
| 人民警察队伍总要求 | **对党忠诚、服务人民、执法公正、纪律严明**（2017 年 5 月 19 日习近平总书记在全国公安系统英雄模范立功集体表彰大会上提出） |
| 人民警察核心价值观 | **忠诚、为民、公正、廉洁** |
| 政治建警 | 把**政治建设**摆在首位，锻造忠诚干净担当的公安铁军 |
| 中国人民警察节 | 每年 **1 月 10 日**（2021 年起，"110"的谐音日子） |

### 情境题怎么考政治素质

- 选项中出现**违背党的领导、损害警民关系、执法不公**的表述必错；
- "敏感案事件第一时间请示报告""重大舆情依法及时公开回应"是对的；
- 政治判断：对涉及**国家安全、社会稳定**的苗头信息要**见微知著、早报告早处置**（不能压案不报、也不能擅自定性）。

## 二、职业道德与纪律

### 《公安机关人民警察职业道德规范》十条（顺序记：先忠诚、再执法、后作风）

| 条目 | 内涵关键词 |
| --- | --- |
| **忠诚可靠** | 听党指挥、政治坚定（第一条，统领） |
| **秉公执法** | 不徇私情、不办人情案 |
| **英勇善战** | 关键时刻冲得上去 |
| **热诚服务** | 群众观点（对应"人民公安为人民"） |
| **文明理性** | 规范用语、克制情绪（情境题最爱：面对辱骂不还口、不激化矛盾） |
| **严守纪律** | 令行禁止 |
| **爱岗敬业** | 精通业务 |
| **甘于奉献** | 节假日备勤、牺牲精神 |
| **清正廉洁** | 不吃拿卡要（情境高频：当事人塞烟塞红包必须当场拒绝） |
| **团结协作** | 警组配合 |

### 公安部"五条禁令"（2003 年，逐字记）

1. 严禁**违反枪支管理使用规定**，违者予以纪律处分；造成严重后果的，予以辞退或开除；
2. 严禁**携带枪支饮酒**，违者予以辞退；
3. 严禁**工作时间饮酒**，违者予以纪律处分；造成严重后果的，予以辞退或开除；
4. 严禁**酒后驾驶机动车**，违者予以辞退；
5. 严禁**参与赌博**，违者予以纪律处分；情节严重的，予以辞退或开除。

> 记忆锚点：**枪、酒（三条：携枪饮 / 工作饮 / 酒驾）、赌**。"辞退"还是"处分"看后果——**携枪饮酒、酒驾最狠，直接辞退**。

### 纪律条令与保密

- 《公安机关人民警察纪律条令》（2010 年施行）：对人民警察违纪行为给予处分——**警告、记过、记大过、降级、撤职、开除**（与公务员处分种类一致）。
- 保密纪律：警务工作秘密（侦查措施、警力部署、个人信息）**不得泄露**；微信朋友圈晒案件现场、嫌疑人照片 = 违纪（情境题常设此坑）。
- **严禁刑讯逼供、严禁不履行法定职责**（"不作为"也是违纪违法，见人民警察法义务条款）。

## 三、易错点清单

1. **总要求 16 字 ≠ 核心价值观 8 字**：总要求"对党忠诚、服务人民、执法公正、纪律严明"（对外表述）；核心价值观"忠诚、为民、公正、廉洁"（更短）。题干问哪个就对哪个，混设选项必错。
2. **警察节是 1 月 10 日**，不是 1 月 1 日（数字陷阱）。
3. **五条禁令的处分档次**：携枪饮酒 / 酒驾 → **辞退**；其余 → 视后果递进。多选题常把"一律开除"设为错误项。
4. 职业道德"十条"与"八项纪律"之类数字陷阱：规范就是**十条**。
5. 情境题中"接受当事人一条烟、一顿便饭"——即使"不影响执法"也**违纪**（清正廉洁是绝对条款）。

## 四、速记卡（考前 5 分钟过一遍）

> 绝对领导公安姓党，十六字要求记周详；忠诚为民公与廉，四词核心价值观。
> 职业道德十条目，忠秉英热文，严爱甘清团；五条禁令枪酒赌，携枪饮酒辞退狠。
> 一月十日警察节，处分六种记心间；警务秘密不外传，朋友圈里不晒案。

## 五、自测练习

1. 人民警察队伍的总要求（十六字）是什么？
2. 人民警察核心价值观是哪四个词？
3. 公安部"五条禁令"包括哪些内容？哪两种行为一经查实直接予以辞退？
4. 《公安机关人民警察职业道德规范》共有几条？第一条是什么？
5. 中国人民警察节是每年的哪一天？

### 答案附录

1. **对党忠诚、服务人民、执法公正、纪律严明**。
2. **忠诚、为民、公正、廉洁**。
3. 严禁违反枪支管理使用规定、严禁携带枪支饮酒、严禁工作时间饮酒、严禁酒后驾驶机动车、严禁参与赌博；**携带枪支饮酒、酒后驾驶机动车**直接予以辞退。
4. **十条**；第一条是**忠诚可靠**。
5. **1 月 10 日**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **表述混**：总要求与核心价值观、道德规范与禁令的表述互相串（回到原文表重记）；
- **数字错**：禁令条数、辞退档次、警察节日期；
- **程度错**："一律开除"还是"辞退""视情节"——处分档次记错；
- **情境错**：没识别出题干行为违反了哪条纪律（对号入座：吃请→廉洁，晒案→保密，压案→不作为）。
