# 公安基础知识专题（性质 / 宗旨 / 方针政策 / 历史 / 执法监督）

> 公安基础知识是"公安自己家的常识"：考公安机关**性质、宗旨、根本原则、基本方针、基本政策 + 历史节点 + 执法监督制度**。
> 考法：单选多选考原文（谁提出、哪一年、什么制度），情境题考"某行为体现/违背了哪个政策"。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

---

## 一、公安机关的性质与宗旨

| 考点 | 内容 |
| --- | --- |
| 性质（三层） | ① 人民民主专政的**重要工具**；② 具有武装性质的**治安行政力量和刑事司法力量**（双重属性）；③ 国家的**治安行政机关** |
| 宗旨 | **全心全意为人民服务**（"人民公安为人民"） |
| 根本原则 | **党对公安工作的绝对领导**（一条统帅） |
| 根本路线（基本方针） | **党委领导下的专门机关与广大群众相结合**（"专群结合"） |
| 社会治安综合治理 | 党委领导、政府负责、社会协同、公众参与、法治保障 |

> 易错：双重属性是"**治安行政 + 刑事司法**"，选项偷换成"司法机关"（错，公安机关是行政机关，不是司法机关——司法机关指法院、检察院）。

## 二、公安工作的基本政策（情境题高频）

| 政策 | 一句话理解 |
| --- | --- |
| **严肃与谨慎相结合** | 该打击的坚决打击（严肃），不枉不纵、办成铁案（谨慎） |
| **宽严相济** | 区别对待：该宽则宽、当严则严（与刑事政策一致） |
| **重证据、重调查研究、不轻信口供、严禁刑讯逼供** | 证据裁判；只有被告人供述没有其他证据的不能定罪 |
| **教育与处罚相结合** | 治安管理处罚的原则之一：处罚是手段，教育是目的 |

## 三、公安历史大事记（单选爱考年份）

| 年份 | 事件 |
| --- | --- |
| **1927** | 中央特科在上海成立（周恩来领导，党的最早保卫组织） |
| **1931** | 中华苏维埃共和国**国家政治保卫局**成立（人民公安的前身，最早的人民政权公安保卫机关） |
| 1938 | 延安成立警察队（"延安警察"，人民公安机关的雏形之一） |
| **1949.11.1** | **中华人民共和国公安部**正式成立（首任部长**罗瑞卿**） |
| 2020 | 授旗仪式：中国人民警察警旗授旗（8 月 26 日） |
| 2021 | 首个中国人民警察节（1 月 10 日） |

## 四、公安队伍建设制度

### 警衔制度（人民警察警衔条例，1992 年）

- **五等十三级**：总警监、副总警监（一等）；**警监**（一、二、三级）；**警督**（一、二、三级）；**警司**（一、二、三级）；**警员**（一、二级）。
- 记忆：**监、督、司、员**各一至三级，顶上加"总警监、副总警监"两级。
- 警衔高的命令警衔低的；警衔相同按职务。

### 录用与辞退（人民警察法）

- 录用：**公开考试、严格考核、择优录取**（进人必考）；曾因犯罪受过刑事处罚的、被开除公职的**不得录用**。
- 辞退：不符合录用条件、不履行职责、旷工或无正当理由逾假不归等，予以辞退；但**因公致残、患病治疗期间、怀孕产假哺乳期**不得辞退。

## 五、公安执法监督（内外各记三条）

| 类型 | 制度 | 要点 |
| --- | --- | --- |
| **内部监督** | **督察制度**（《公安机关督察条例》） | 县级以上公安机关设督察机构，对**本级和下级**公安机关及其人民警察执法执勤进行现场督察；可对违法行使职权行为**当场处置、责令停止** |
| | 法制部门监督 | 案件审核、执法质量考评 |
| | 行政复议 | 上级公安机关/政府复议下级具体行政行为（详见 [行政执法法律专题](行政执法法律专题.md)） |
| **外部监督** | 检察监督 | 逮捕批准、立案监督、侦查活动监督 |
| | 监察监督 | 监委对公职人员监察全覆盖（民警也是监察对象） |
| | 社会监督 | 110 投诉、信访、舆论监督；聘请警风警纪监督员 |

> 易错：督察机构监督的是"**本级 + 下级**"，不是"上级"（上级督察机构监督本级和下级）；督察"当场纠正"针对的是**正在发生的**违法行使职权行为。

## 六、情境题中的公安基础考点

- "社区民警发动网格员、治安积极分子巡逻"体现 → **专门机关与广大群众相结合（专群结合）**；
- "办案民警对零口供案件靠证据定案"体现 → **重证据、不轻信口供**；
- "对未成年嫌疑人依法从宽、附条件处理"体现 → **宽严相济**（教育与挽救相结合）；
- "群众投诉办案民警吃拿卡要"→ 属**外部的社会监督**，接受投诉的渠道还包括督察（内部）——多选题两者都选。

## 七、易错点清单

1. 公安机关是**行政机关**（不是司法机关）；行使刑事司法职能（侦查）≠ 变成司法机关。
2. 基本方针 = "**党委领导下**的专门机关与广大群众相结合"——丢掉"党委领导下"就是错项。
3. 历史年份三连：**1927 中央特科、1931 政治保卫局、1949.11.1 公安部（罗瑞卿）**——选项常把特科与政治保卫局的年份对调。
4. 警衔"五等十三级"；警监以上是**职务等级**较高的领导警官——选项写"四等十一级"即错。
5. 督察≠监察：**督察是公安机关内部机构**，监察是监委对公职人员的外部监督——题干混用必设陷阱。

## 八、速记卡（考前 5 分钟过一遍）

> 专政工具双属性，治安行政刑事司法；宗旨为民党绝对，专群结合党委领导。
> 严肃谨慎宽严济，重证轻供禁逼供；特科二七保卫局三一，四九一一公安部。
> 警衔五等十三级，监督司员各三级；督察本级管下级，监外察内要分清。

## 九、自测练习

1. 公安机关的双重属性指什么？
2. 公安工作的根本原则和基本方针分别是什么？
3. 我国最早的人民政权公安保卫机关是什么？成立于哪一年？
4. 人民警察警衔分为几等几级？
5. 公安机关督察机构的监督范围是什么？

### 答案附录

1. 具有**武装性质的治安行政力量和刑事司法力量**。
2. 根本原则：**党对公安工作的绝对领导**；基本方针：**党委领导下的专门机关与广大群众相结合**。
3. **国家政治保卫局**（中华苏维埃共和国，1931 年；其前身为 1927 年的中央特科——特科是党的保卫组织）。
4. **五等十三级**（总警监、副总警监；一至三级警监、警督、警司；一至二级警员）。
5. 对**本级和下级**公安机关及其人民警察的执法执勤活动进行监督。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **表述混**：原则 / 方针 / 政策的表述互串；
- **数字错**：历史年份、警衔等级数；
- **性质错**：把公安机关当司法机关、把督察当监察；
- **情境错**：没把题干行为对应到"专群结合 / 宽严相济 / 重证据"等政策关键词。
