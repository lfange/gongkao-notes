# 群众工作与情报信息专题（公安工作的两个看家本领）

> 基本能力板块中最"软"也最好拿分的部分：群众工作方法 + 情报信息工作。考法：单选多选考**工作方法的名称与内涵**，情境题考"面对群众 / 情报该怎么做"——选**态度积极、程序合法、方式稳妥**的选项。
> 使用方法：过考点 → 记关键词 → 错点记入 [错题本.md](../错题本.md)。

## 一、群众工作能力（四项基本功）

### 大纲四能力：宣传教育、沟通协调、组织动员、服务群众

| 能力 | 内涵 | 情境对应 |
| --- | --- | --- |
| **宣传教育** | 普法宣传、防范宣传（反诈、禁毒、防盗抢） | 社区开展反诈宣传；到学校上法治课 |
| **沟通协调** | 与群众有效沟通，化解矛盾、争取理解 | 面对情绪激动的群众先安抚再释法；用群众听得懂的语言 |
| **组织动员** | 发动群防群治力量（治安积极分子、志愿者、网格员） | 组建义务巡逻队；"朝阳群众"式群防群治 |
| **服务群众** | 想群众所想，便民利民 | 户籍窗口"最多跑一次"；对老弱病残上门办证 |

### 核心原则（情境题的"标准答案气质"）

- **一切为了群众、一切依靠群众**（群众路线——与公安基础知识"专群结合"方针联动）；
- **新时代"枫桥经验"**：坚持和贯彻党的群众路线，**依靠群众就地化解矛盾**，"小事不出村、大事不出镇、矛盾不上交"（高频考点）；
- **互联网时代的群众工作**：网上问政、警民微信群、微警务——线上线下结合（选项"群众工作只需线下入户"必错）；
- **社区警务**：社区民警沉入社区，走访群众、掌握社情民意、排查矛盾隐患（"百万警进千万家"式走访）。

### 沟通的情境规范

- 对情绪激动的群众：**先安抚情绪、后解决问题**；不激化、不对骂；
- 对诉求不合理的：耐心释法说理，指明合法救济途径（复议、诉讼、信访），不能简单"打发"；
- 对媒体采访：按新闻宣传归口管理，个人不得擅自发布案件信息（与保密纪律联动）。

## 二、情报信息工作能力

### 三环节：收集 → 分析研判 → 预警利用

| 环节 | 要点 |
| --- | --- |
| **收集** | 渠道：社区走访、案件办理、技防系统、群众举报、部门共享；要求：**及时、准确、全面**；对线索来源依法保护（举报人保护制度） |
| **分析研判** | 对零散信息比对、串并、评估真实性；分级分类；**情指行一体化**（情报—指挥—行动闭环，现代警务运行机制关键词） |
| **预警利用** | 将研判成果转化为预警提示、巡防部署、专项打击；"**预测预警预防**"是目标 |

### 情境规范

- **个人信息保护**：收集、使用公民个人信息必须有法律依据、限于履职必需，严禁倒卖、泄露（题干中"把查询到的开房记录发给同学"= 违法甚至犯罪——侵犯公民个人信息）；
- **大数据赋能**：数据汇聚、模型预警是方向，但滥用数据、超目的使用违背正当性底线；
- 突发事件舆情：**早发现、早报告、早研判**，按权限归口发布，不信谣不传谣（与应急处突联动）。

## 三、两个能力怎么结合（情境题综合考法）

典型情境：社区民警发现辖区某小区电信诈骗警情一周内 3 起。

标准处置链：**汇总研判**（串并分析）→ **上报预警**（所里 / 情指中心）→ **宣传防范**（进小区反诈宣传、推预警短信）→ **组织动员**（发动物业、网格员留意重点人群）→ **跟进打击**（配合反诈中心止付、侦查）。

> 每一步都对应用户工作 / 情报的一个能力——情境题的选项往往就是这些环节，选**闭环完整、先后合理**的。

## 四、精讲情境例题（2 例）

**例 1.** 社区民警小王走访时，居民反映小区门口烧烤摊深夜喧哗扰民，曾多次发生口角。下列做法最恰当的是？
A. 告知这不归警察管，建议找城管
B. 记录情况，联合社区、城管等现场查看调解，宣传法律法规，并提示双方申请仲裁
C. 直接对烧烤摊主治安处罚
D. 将双方带到派出所训诫了事

**解析：** B 对——群众诉求先受理（沟通协调），联合多部门综合施策（组织协调），矛盾就地化解（枫桥经验），同时告知合法救济途径。A 错（"不归我管"式推诿，即使主业在城管也应协同并解释）；C 错（未先行教育疏导，简单处罚激化矛盾）；D 错（训诫不是万能手段，未解决根源）。**陷阱：** 情境题"最恰当"= 合法 + 解决问题 + 群众工作方法，不是"最有力度"。

**例 2.** 民警小李在办案中查到某明星的行程信息，其大学同学请求"发来看看"。小李的正确做法是？
A. 同学又不是外人，发一下无妨
B. 依法依规使用信息，拒绝请求；违规提供公民个人信息可能构成犯罪
C. 发"打码版"就可以
D. 收点辛苦费再发

**解析：** B 对——公安机关掌握的公民个人信息**只能用于履职**，违规向他人提供公民个人信息，情节严重可构成**侵犯公民个人信息罪**；A、C、D 均错（D 还涉嫌受贿）。**陷阱：** 情报信息题的底线是"来源合法、使用合规、绝对保密"。

## 五、易错点清单

1. 群众工作四能力名称：**宣传教育、沟通协调、组织动员、服务群众**——选项偷换"打击、管控"等管理色彩词必错（新时代总基调是"服务"）。
2. **枫桥经验**关键词："依靠群众**就地化解矛盾**"——不是"矛盾上交"、不是"运动式打击"。
3. 情报三环节：收集 → 研判 → 预警利用；**"情指行一体化"**是机制关键词。
4. 查询公民个人信息只能**履职必需**；对外提供（哪怕"打码"）都可能违法甚至犯罪。
5. 对群众诉求："**先受理、再分流、善告知**"——"不归警察管"的话不能说（应说明并转交 / 联动）。
6. 举报人 / 线索来源**依法保密**——情境中透露举报人身份的选项必错。

## 六、速记卡（考前 5 分钟过一遍）

> 宣教沟通与动员，服务群众四本领；枫桥经验就地解，矛盾不上交是魂。
> 走访社情连万家，网上网下齐发力；情报收集研判用，预测预警预防行。
> 情指行来一体化，个人信息履职用；线索来源要保密，举报人员必保护。

## 七、自测练习

1. 群众工作能力的四项基本功是什么？
2. 新时代"枫桥经验"的核心内涵是什么？
3. 情报信息工作的三个环节是什么？
4. 公安民警使用公民个人信息的边界是什么？
5. 对不属于公安机关职责的群众诉求，应当如何处理？

### 答案附录

1. **宣传教育、沟通协调、组织动员、服务群众**。
2. 贯彻党的群众路线，**依靠群众就地化解矛盾**，实现"小事不出村、大事不出镇、矛盾不上交"。
3. **收集 → 分析研判 → 预警利用**（目标是预测、预警、预防）。
4. 只能**出于履职需要、有法律依据**地收集和使用，严禁超范围查询、对外提供、泄露买卖（情节严重可构成侵犯公民个人信息罪）。
5. **不能推诿**：说明情况，告知主管机关，属于紧急危险的先行处置；能联动的联动相关部门协同解决。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **名称错**：四能力、三环节、枫桥经验等固定表述记偏；
- **基调错**：选了"管控型"而非"服务型"思路（新时代公安工作总基调）；
- **底线错**：个人信息、举报人保密等红线失守；
- **情境错**：没选"最恰当"的综合处置链（受理—分流—联动—反馈），漏了反馈 / 联动环节。
