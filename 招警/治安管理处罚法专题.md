# 治安管理处罚法专题 ⭐（公安专业科目分值第一的法）

> 治安案件是公安日常工作的主战场，本部法是专业科目**分值最高**的一部：处罚种类、不执行拘留的四种人、各类时限、调解、听证，年年必考。
> **新法提醒：** 《治安管理处罚法》2025 年修订，**2026 年 1 月 1 日起施行**——程序主线延续旧法，本专题按主线整理，"新法变化"单列；**处罚幅度等数字细节考前对照官方原文核一遍**。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

---

## 一、总则要点

- **处罚原则：** 以事实为依据，与违法行为的性质、情节及社会危害程度相当（**过罚相当**）；公开、公正；**尊重和保障人权，保护公民人格尊严**；**教育与处罚相结合**。
- **管辖：** 治安案件由**违法行为地**公安机关管辖；由**行为人居住地**管辖更为适宜的，可以由居住地公安机关管辖。
- **报案受理：** 任何单位和个人都有权报案、举报；公安机关对报案、控告、举报都**应当及时受理并登记**，不属于自己管辖的及时移送。

## 二、处罚种类与适用规则（速查表）

### 处罚种类

| 主处罚 | 附加（对外国人） |
| --- | --- |
| 警告、罚款、行政拘留、吊销公安机关发放的许可证 | **限期出境、驱逐出境**（可以独立适用，也可以附加适用） |

### 减轻处罚或不予处罚（五种情形）

情节特别轻微；**主动消除或者减轻违法后果，并取得被侵害人谅解**；出于他人**胁迫或者诱骗**；**主动投案**，向公安机关如实陈述自己的违法行为的；有立功表现的。

### 依法不予处罚（两类人 + 时效）

- **不满 14 周岁**的：不予处罚，责令监护人严加管教；
- **精神病人在不能辨认或者不能控制自己行为时**违法的：不予处罚，责令监护人严加看管和治疗（间歇性精神病人在精神正常时违法的**应当**处罚）。

### 从重处罚（四种情形）

有较严重后果的；**教唆、胁迫、诱骗他人**违反治安管理的；对**报案人、控告人、举报人、证人打击报复**的；**6 个月内曾受过治安管理处罚**的。

### 不执行行政拘留的四种人 ⭐⭐（全卷最高频考点之一）

| 对象 | 关键词 |
| --- | --- |
| 已满 **14 不满 16** 周岁 | 一律不执行 |
| 已满 **16 不满 18** 周岁，**初次**违反 | "初次"是题眼 |
| **70 周岁以上** | 年龄 |
| **怀孕或者哺乳自己不满 1 周岁**婴儿 | 哺乳"自己不满1周岁"的婴儿 |

> 拘留**裁决可以照做，只是不执行**——"不执行"≠"不处罚"（多选题陷阱）。

### 合并执行与时效

- 两种以上违法行为合并执行行政拘留的，**最长不超过 20 日**；
- 追责时效：**6 个月**内没有被公安机关发现的不再处罚（行为有连续或继续状态的，从行为**终了之日**起算）。

## 三、办案程序（时限速查表 ⭐）

| 环节 | 规则 |
| --- | --- |
| **传唤** | 需要传唤的，经**办案部门负责人批准**，使用传唤证；对**现场发现**的可**口头传唤**（询问笔录中注明） |
| **询问查证** | 不得超过 **8 小时**；案情复杂、依法**可能适用行政拘留**的，不得超过 **24 小时**；不得以连续传唤变相拘禁 |
| 询问未成年人 | 询问**不满 16 周岁**的违反治安管理行为人，应当**通知其父母或者其他监护人到场** |
| **办案期限** | 受理之日起 **30 日**内办结；案情重大、复杂的，经**上一级公安机关批准**，可以延长 **30 日** |
| **当场处罚（简易程序）** | 违法事实清楚、证据确凿，处**警告或 200 元以下罚款**的，可以当场作出处罚决定（24 小时内备案） |
| **听证** | 作出**吊销许可证**以及**较大数额罚款**等处罚决定前，告知听证权利（新法变化见下） |
| 罚款缴纳 | 罚缴分离，到指定银行；被处 **50 元以下罚款且无异议**等情形可当场收缴 |
| **暂缓执行拘留** | 被处罚人**申请行政复议、提起行政诉讼**期间，可申请暂缓执行；公安机关认为不致发生社会危险的，由其或近亲属**提供担保人**，或**按每日 200 元标准交纳保证金**，决定暂缓执行 |

### 治安调解 ⭐

- 适用范围：**因民间纠纷**引起的**打架斗殴或者损毁他人财物**等违反治安管理行为，**情节较轻**的，公安机关**可以调解处理**。
- 结果：调解达成协议并履行的，**不予处罚**；调解不成或达成协议不履行的，依法处罚，并告知当事人可就民事争议**向法院提起民事诉讼**。
- 情境判断：调解不是必经程序（"可以"不是"应当"）；调解一般一次，必要时可增加一次（次数以新法及办案规定为准）。

### 检查

- 对与违法行为有关的**场所、物品、人身**可以检查；检查人员**不得少于 2 人**，并出示工作证件和检查证明文件；
- **确有必要立即检查**的，人民警察经出示工作证件，可以**当场检查**（检查公民住所仍须有检查证明文件）；
- **检查妇女的身体，应当由女性工作人员进行**（情境题高频）。

## 四、新法变化（2026.1.1 施行，考前对照原文核）

> 以下为本次修订被广泛报道的要点，**具体条文表述以官方文本为准**：

1. **未成年人违法行为记录封存**：对违反治安管理的未成年人依法封存违法记录（犯罪记录封存制度在治安领域的延伸）；
2. **"屡教不改"可执行拘留**：对已满 14 不满 16 周岁**情节严重、影响恶劣**，以及已满 16 不满 18 周岁**一年内二次以上**违反治安管理的，依法可以执行行政拘留（对"四种人不执行"的重大例外）；
3. **听证范围扩大**：拟作出行政拘留等较重处罚的，保障当事人要求听证的权利（旧法听证限于吊销许可证、较大数额罚款）；
4. 对无人机"黑飞"等新型违法行为增设了处罚规定（新类型入法）。

## 五、常见违反治安管理行为（情境判断用）

| 类别 | 代表行为 |
| --- | --- |
| 扰乱公共秩序 | 扰乱机关、团体、企事业单位秩序；扰乱车站、码头、商场等公共场所秩序；**散布谣言、谎报险情疫情警情**故意扰乱公共秩序 |
| 妨害公共安全 | 非法携带枪支弹药、**管制器具**；盗窃、损毁公共设施；违反危险物质管理规定 |
| 侵犯人身权、财产权 | **殴打他人、故意伤害**；非法限制人身自由、非法侵入住宅；侮辱、诽谤；**盗窃、诈骗、抢夺、敲诈勒索、故意损毁财物**（未构成犯罪的） |
| 妨害社会管理 | 卖淫嫖娼、赌博或为赌博提供条件、吸食注射毒品；旅馆业不按规定登记；隐藏、转移、变卖或损毁行政执法机关依法扣押、查封、冻结的财物 |

> 分界线（情境题核心）：同一行为看**情节与后果**——一般打架 = 治安案件（殴打他人）；致人轻伤以上 = 刑事案件（故意伤害罪）。**先判断案件性质，再选程序**。

## 六、精讲情境例题（2 例）

**例 1.** 民警巡逻中发现甲（17 周岁）盗窃电动车，价值 900 元，系其一年内第二次违反治安管理。下列处置正确的是？
A. 甲未满 18 周岁，裁决行政拘留但不执行
B. 甲一年内二次以上违反治安管理，可执行行政拘留
C. 甲系初次违反，应当从重处罚
D. 直接立为刑事案件侦查

**解析：** 新法对已满 16 不满 18 周岁、一年内**二次以上**违反的，可以执行拘留——A 错（旧规则不适用），B 对。C 错在"初次"表述与题干矛盾且年龄不必然从重；D 错（数额未达刑事立案标准，属治安案件）。**陷阱：** 拿旧法"一律不执行"做干扰项——新法例外必须记住。

**例 2.** 王某因宅基地纠纷将邻居打成轻微伤，公安机关下列做法正确的是？
A. 属民间纠纷引起、情节较轻，应当先行调解
B. 必须调解，调解不成不得处罚
C. 可以调解；调解不成依法处罚，并告知民事争议可向法院起诉
D. 直接裁决行政拘留并送达看守所执行

**解析：** C 对。因**民间纠纷**引起的打架斗殴，情节较轻的**可以**（不是应当、更不是必须）调解；A 的"应当"错，B 错，D 未先行告知陈述申辩权且忽略调解选项，程序过于粗糙。**陷阱：** "可以 / 应当 / 必须"三档措辞是程序题的灵魂。

## 七、易错点清单

1. **不执行拘留 ≠ 不处罚**：裁决照作，只是不送所执行（"不执行"针对的是执行环节）。
2. 询问时限 **8/24 小时**，办案 **30+30 日**，时效 **6 个月**，合并执行 **20 日**，当场处罚 **200 元**，当场收缴 **50 元**，担保金 **每日 200 元**——七个数字别串。
3. 追究时效从**行为终了之日**（连续 / 继续状态）起算，不是"被发现之日"。
4. 询问**不满 16 周岁**未成年人须**通知监护人到场**（年龄线是 16，不是 14 或 18）。
5. **检查妇女身体由女性工作人员进行**；当场检查须"确有必要 + 出示证件"两个条件。
6. 调解只适用**民间纠纷**引起的打架斗殴 / 损毁财物且**情节较轻**——"可以调解"不是必经程序。
7. 暂缓执行拘留的前提是**申请复议或诉讼期间**且**不致发生社会危险**——不是交钱就放。

## 八、速记卡（考前 5 分钟过一遍）

> 警告罚款与拘留，吊销许可四处分；老外附加限出境，驱逐出境独立成。
> 十四十六十八初，七旬孕哺四不拘；新法例外记心间，屡教不改照样拘。
> 询问八二十四，办案三十加三十；时效六月合并二十，当场二百收缴五十。
> 民间纠纷轻伤情，可以调解不必须；协议履行不处罚，不成照罚民事诉。

## 九、自测练习

1. 简述不执行行政拘留的四种情形（旧法主线），并说出新法新增的例外。
2. 传唤后询问查证的时限是多少？哪种情形可延长到 24 小时？
3. 治安案件的办案期限及延长规则是什么？
4. 治安调解的适用范围和法律后果是什么？
5. 被处罚人如何申请暂缓执行行政拘留？

### 答案附录

1. 已满 14 不满 16 周岁；已满 16 不满 18 周岁**初次**违反；70 周岁以上；怀孕或哺乳自己不满 1 周岁婴儿。新法例外：已满 14 不满 16 周岁情节严重、影响恶劣，或已满 16 不满 18 周岁一年内二次以上违反的，可以执行。
2. **8 小时**；案情复杂、依法可能适用行政拘留的，不超过 **24 小时**。
3. 受理之日起 **30 日**内办结；案情重大、复杂的，经**上一级公安机关批准**延长 **30 日**。
4. **因民间纠纷引起的打架斗殴或损毁他人财物等情节较轻**的，**可以**调解；达成协议并履行的**不予处罚**；调解不成或不履行的依法处罚，并告知可就民事争议提起民事诉讼。
5. 在**申请行政复议、提起行政诉讼期间**，向公安机关提出申请；公安机关认为暂缓执行不致发生社会危险的，由被处罚人或其近亲属**提供担保人**，或**按每日 200 元交纳保证金**后暂缓执行。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **数字错**：期限 / 金额 / 年龄线记串（回到时限速查表重记）；
- **措辞错**："可以 / 应当 / 必须"档位判断错；
- **新法错**：拿旧法规则答新法题（重点核对新法变化一节）；
- **情境错**：案件性质判断错（治安 vs 刑事），导致整个程序选择链全错。
