# 治安管理处罚法专题 ⭐（公安专业科目分值第一的法）

> 治安案件是公安日常工作的主战场，本部法是专业科目**分值最高**的一部：处罚种类、不执行拘留的四情形与例外、各类时限、调解、听证，年年必考。
> **本专题已对照中国人大网公布的《治安管理处罚法》全文（2025 年 6 月 27 日修订通过，2026 年 1 月 1 日施行）逐条核对**，以下均按现行新法表述。老教材 / 旧题库的数字（当场处罚 200 元、从重"6 个月内"等）已过时，注意甄别。
> 使用方法：过考点 → 遮住表格自测 → 错点记入 [错题本.md](../错题本.md)。

---

## 一、总则要点

- **处罚原则（第 6 条）：** 以事实为依据、过罚相当；公开、公正，尊重和保障人权、保护公民人格尊严；**教育与处罚相结合**，充分释法说理。
- **管辖（第 7 条）：** 治安案件的管辖**由国务院公安部门规定**（实操沿用"违法行为地为主、行为人居住地为辅"，见公安机关办理行政案件程序规定）。
- **受案（第 90 条）：** 对报案、控告、举报、主动投案及其他机关移送的案件，**应当立即立案并进行调查**；认为不属于违反治安管理行为的，告知报案人并说明理由。
- **刑事优先（第 8 条）：** 构成犯罪的依法追究刑事责任，**不得以治安处罚代替刑事处罚**。

## 二、处罚种类与适用规则（速查表）

### 处罚种类（第 10 条）

| 主处罚 | 附加（对违反治安管理的外国人） |
| --- | --- |
| 警告、罚款、行政拘留、吊销公安机关发放的许可证件 | **限期出境、驱逐出境**（附加适用） |

- 收缴与追缴（第 11 条）：违禁品（毒品、淫秽物品）、赌具赌资、吸毒用具及本人所有的作案工具**收缴**；违法所得**追缴退还被侵害人**。

### 从轻、减轻或不予处罚（第 20 条，六项）

情节轻微；主动消除或者减轻违法后果；**取得被侵害人谅解**；出于他人胁迫或者诱骗；主动投案、如实陈述自己的违法行为；有立功表现。

> **认错认罚从宽（第 21 条，新法）：** 行为人自愿如实陈述、承认违法事实、愿意接受处罚的，可以依法从宽处理。

### 依法不予处罚 / 特殊人群（第 12-15 条）

| 对象 | 规则 |
| --- | --- |
| **不满 14 周岁** | 不予处罚，责令监护人严加管教（14-18 周岁从轻或减轻处罚） |
| 精神病人、**智力残疾人**（新法增列） | 不能辨认或控制自己行为时违法的，不予处罚（责令监护人加强看护管理和治疗）；**间歇性精神病人在精神正常时违法应当处罚**；未完全丧失辨认控制能力的应当处罚，但可以从轻或减轻 |
| 盲人或者又聋又哑的人 | **可以**从轻、减轻或者不予处罚 |
| 醉酒的人 | **应当处罚**；醉酒状态中对本人或他人有危险的，采取**保护性措施约束至酒醒** |

### 正当防卫（第 19 条，新法新增明文）⭐

为免受**正在进行的不法侵害**而采取的制止行为，造成损害的，**不属于违反治安管理行为**；制止行为明显超过必要限度造成较大损害的，依法处罚但**应当减轻**；情节较轻的，不予处罚。（与刑法正当防卫联动的治安版。）

### 从重处罚（第 22 条，四项）

有较严重后果的；教唆、胁迫、诱骗他人违反治安管理的；对**报案人、控告人、举报人、证人打击报复**的；**一年以内**曾受过治安管理处罚的（旧法为 6 个月，**新法延长到一年**）。

### 不执行行政拘留的四情形与例外 ⭐⭐（全卷最高频考点之一）

| 对象 | 关键词 |
| --- | --- |
| 已满 **14 不满 16** 周岁（第一项） | 一律不执行 |
| 已满 **16 不满 18** 周岁，**初次**违反（第二项） | "初次"是题眼 |
| **70 周岁以上**（第三项） | 年龄 |
| **怀孕或者哺乳自己不满 1 周岁**婴儿（第四项） | 哺乳"自己不满1周岁"的婴儿 |

**例外（第 23 条第 2 款，新法）：** 前款**第一、二、三项**行为人违反治安管理**情节严重、影响恶劣**的，或者**第一、三项**行为人**一年以内二次以上**违反治安管理的，**不受前款规定的限制**（可以执行拘留）。

> 例外范围精确记忆：①"情节严重、影响恶劣"→ 第一、二、三项（**不含**怀孕哺乳）；②"一年以内二次以上"→ 仅第一项（14-16 岁）和第三项（70 岁以上）——**16-18 岁只有"情节严重影响恶劣"一条例外，"二次以上"不管用**。
> 对可能执行行政拘留的未成年人，公安机关应当告知其和监护人有权要求**听证**（第 117 条第 2 款，听证不公开）。
> 不执行拘留 / 不予处罚的未成年人，依《预防未成年人犯罪法》采取**矫治教育**等措施（第 24 条）。

### 合并执行与时效

- 两种以上违法行为分别决定、合并执行，行政拘留合并执行**最长不超过 20 日**（第 16 条）；
- 追责时效：**6 个月**内没有被公安机关发现的不再处罚（第 25 条）；从行为**发生之日**起算，连续或继续状态从**行为终了之日**起算。

## 三、办案程序（时限速查表 ⭐）

### 调查取证

| 环节 | 规则 |
| --- | --- |
| **传唤（第 96 条）** | 经**办案部门负责人批准**使用传唤证；**现场发现**的，出示人民警察证可以**口头传唤**（笔录注明）；无正当理由不接受或逃避传唤的，经批准可以**强制传唤** |
| **询问查证（第 97 条）** | 不得超过 **8 小时**；**涉案人数众多、身份不明的**，不得超过 **12 小时**（新法新增档）；情况复杂、依法**可能适用行政拘留**的，不得超过 **24 小时**；执法办案场所询问应**全程同步录音录像**；保证饮食和必要休息时间 |
| 询问未成年人（第 98 条） | 询问**不满 18 周岁**的，应当**通知其父母或其他监护人到场**；不能到场的，通知**合适成年人**（成年亲属、学校、单位、居住地基层组织或未成年人保护组织代表）到场并记录在案 |
| 人身检查、生物样本（第 102 条） | 经办案部门负责人批准；**不得重复提取、采集**；采集被侵害人的信息样本应**征得本人或监护人同意** |
| **检查（第 103 条）** | 人民警察**不得少于 2 人**并出示人民警察证；**对场所检查**经**县级以上公安机关负责人批准**使用检查证（确有必要立即检查的可当场检查 + 全程录音录像）；**检查公民住所须出示检查证**；**检查妇女身体由女性工作人员或医师进行** |
| 回避（第 95 条） | 是当事人近亲属 / 有利害关系 / 可能影响公正的应当回避；民警回避由所属公安机关决定，**负责人回避由上一级公安机关决定** |
| **单人办案（第 108 条，新法）** | 询问、辨认、勘验、行政强制措施等调查取证**不得少于 2 人**；在**规范执法办案场所**进行询问、扣押、辨认、调解的，可以由**一名人民警察**进行，但须**全程同步录音录像**（否则相关证据不能作为处罚根据） |

### 决定

| 环节 | 规则 |
| --- | --- |
| **办案期限（第 118 条）** | 自**立案**之日起不得超过 **30 日**；案情重大、复杂的，经**上一级公安机关批准**延长 **30 日**，**以二次为限**；**鉴定期间、听证期间不计入**办案期限 |
| **当场处罚（第 119 条）** | 事实清楚、证据确凿，处**警告或 500 元以下罚款**的，可以当场作出决定（新法由 200 元提至 500 元）；被处罚人无异议且全程录音录像的，**可由一名民警**作出；**24 小时内**报所属公安机关备案 |
| **听证（第 117 条）** | 作出**吊销许可证件、处 4000 元以上罚款**的处罚决定或采取**责令停业整顿**措施前，**应当告知**听证权；**可能执行行政拘留的未成年人案件**告知听证权（听证**不公开**）；其他案情复杂或有重大社会影响的案件，当事人要求且公安机关认为必要的，应当听证；**不得因当事人要求听证而加重处罚** |
| **法制审核（第 114 条，新法）** | 涉及重大公共利益、经听证程序、疑难复杂或多法律关系的案件，**先经法制审核**，未经审核或审核未通过不得作出决定；初次从事法制审核的人员应通过**国家统一法律职业资格考试** |
| 决定书（第 115-116 条） | 载明事项六项（含救济途径和期限）；宣告后**当场交付**，不能当场宣告的 **2 日内送达**；决定拘留的**及时通知家属**；有被侵害人的送达被侵害人 |
| **记录封存（第 136 条，新法）** | **违反治安管理的记录一律封存**（不限未成年人！），不得向任何单位和个人提供或公开；国家机关办案需要或有关单位依国家规定查询的除外 |

### 执行

| 环节 | 规则 |
| --- | --- |
| 罚款缴纳（第 123 条） | 收到决定书之日起 **15 日内**到指定银行或**电子支付系统**缴纳；被处 **200 元以下罚款且无异议**、边远水上交通不便地区缴纳确有困难、当地无固定住所不当场收缴难以执行的，**可以当场收缴**（新法由 50 元提至 200 元）；当场收缴须出具财政部门**统一制发专用票据**，否则有权拒缴 |
| **暂缓执行拘留（第 126 条）** | **申请复议、提起行政诉讼**期间，**或遇升学考试、子女出生、近亲属病危死亡**等情形（新法增列），可申请暂缓执行；公安机关认为**不致发生社会危险**的，由被处罚人或近亲属提供**担保人**（第 127 条四条件），或**按每日 200 元标准交纳保证金**，暂缓执行 |
| **出所制度（第 126 条第 2 款，新法）** | 正在被执行拘留的人遇上述情形可申请**出所**，**出所时间不计入拘留期限** |
| 担保与没收（第 128-130 条） | 担保人保证被担保人不逃避执行，不履行的处 3000 元以下罚款；被担保人暂缓期间逃避执行的，**没收保证金、拘留仍执行**；拘留被撤销或执行的，**及时退还保证金** |

### 治安调解（第 9 条）⭐

- 适用范围：**因民间纠纷**引起的**打架斗殴或损毁他人财物**等违反治安管理行为，**情节较轻**的，公安机关**可以调解处理**（应当查明事实，遵循合法、公正、自愿、及时原则）。
- 结果：调解达成协议的**不予处罚**；调解不成或不履行的依法处理，并告知可就民事争议**向法院提起民事诉讼**。
- **新法增补：** 处理决定前，当事人**自行和解**或经**人民调解委员会调解**达成协议并履行，**书面申请经公安机关认可**的，不予处罚。

## 四、常见违反治安管理行为（情境判断用）

| 类别 | 代表行为 |
| --- | --- |
| 扰乱公共秩序 | 扰乱机关、公共场所、公共交通工具秩序；非法拦截交通工具；破坏选举秩序；**散布谣言、谎报险情疫情警情**；扰乱大型活动秩序（可并处 **6 个月至 1 年禁止进入体育、演出场馆**——新法新增） |
| 妨害公共安全 | 非法携带枪支弹药、**管制器具**；盗窃损毁公共设施；违反危险物质管理规定；**高空抛掷物品**（新法明确入治安处罚）；**违规飞行无人机、升放气球等情节较重的处 5-10 日拘留，非法穿越国（边）境的 10-15 日**（新法新增） |
| 侵犯人身权、财产权 | 殴打他人、故意伤害；猥亵；非法限制人身自由、非法侵入住宅；侮辱、诽谤；盗窃、诈骗、抢夺、敲诈勒索、故意损毁财物 |
| 妨害社会管理 | 卖淫嫖娼、赌博、吸毒（吸毒者可并处 **6 个月至 1 年禁入娱乐场所**——新法新增）；旅馆业不按规定登记；出租房屋不登记承租人信息、明知犯罪不报告（新法细化） |

> 分界线（情境题核心）：同一行为看**情节与后果**——一般打架 = 治安案件（殴打他人，新法处 5-10 日拘留并处 500-1000 元罚款，幅度普遍提高）；致人**轻伤以上** = 刑事案件（故意伤害罪）。**先判断案件性质，再选程序**。

## 五、精讲情境例题（2 例）

**例 1.** 甲（15 周岁）一年内三次实施盗窃电动车（价值均未达刑事立案标准），本次被查获。下列说法正确的是？
A. 甲不满 16 周岁，裁决行政拘留后一律不执行
B. 甲一年以内二次以上违反治安管理，不受"不执行拘留"的限制，可以执行
C. 必须执行行政拘留
D. 三次盗窃已构成犯罪，直接立刑事案件

**解析：** B 对——新法第 23 条第 2 款：**第一项（14-16 岁）行为人一年以内二次以上**违反治安管理的，不受"不执行"限制；A 是旧法思维；C 错在"必须"（是"不受限制"，裁量上仍可执行可不执行）；D 错（数额未达刑事标准）。**陷阱：** 例外条款分两支——"情节严重影响恶劣"适用于第一至三项，"一年内二次以上"**只适用于第一项（14-16）和第三项（70 岁以上）**，对 16-18 岁只有前者管用。另注意：对可能执行拘留的未成年人，须告知听证权（听证不公开）。

**例 2.** 王某因宅基地纠纷将邻居打成轻微伤，公安机关下列做法正确的是？
A. 属民间纠纷引起、情节较轻，应当先行调解
B. 必须调解，调解不成不得处罚
C. 可以调解；调解不成依法处罚，并告知民事争议可向法院起诉
D. 直接裁决行政拘留并送所执行

**解析：** C 对。因**民间纠纷**引起的打架斗殴，情节较轻的**可以**（不是应当、更不是必须）调解；A 的"应当"错，B 错，D 未告知陈述申辩等权利且忽略调解选项。**陷阱：** "可以 / 应当 / 必须"三档措辞是程序题的灵魂；新法还允许"自行和解 / 人民调解委员会调解 + 书面申请经认可 → 不予处罚"。

## 六、易错点清单

1. **不执行拘留 ≠ 不处罚**：裁决照作，只是不送所执行；且"不执行"有例外（见第 23 条第 2 款，注意例外适用范围）。
2. 七组数字（新法多有调整，旧题库最坑）：询问查证 **8/12/24 小时**、办案期限自**立案**起 **30+30（二次为限）**、时效 **6 个月**、合并执行 **20 日**、当场处罚 **500 元**、当场收缴 **200 元**、担保金**每日 200 元**。
3. 从重处罚的"曾受处罚"期限是**一年以内**（旧法 6 个月）。
4. 询问**不满 18 周岁**的未成年人须通知监护人 / 合适成年人到场（旧法是 16 周岁，新法改为 18）。
5. 听证的三个新法要点：**4000 元以上罚款 / 吊销许可证件 / 责令停业整顿**告知听证；未成年人可能执行拘留的听证**不公开**；**不得因要求听证而加重处罚**。
6. 检查妇女身体由**女性工作人员或医师**进行（新法增加"或医师"）；检查公民住所必须出示检查证。
7. 暂缓执行拘留：复议诉讼期间**或**升学考试、子女出生、近亲属病危死亡等法定情形 + 认为不致发生社会危险 + 担保人 / 每日 200 元保证金。
8. **记录封存是"一律封存"**——所有违反治安管理的记录，不只未成年人。

## 七、速记卡（考前 5 分钟过一遍）

> 警告罚款与拘留，吊销许可四处分；老外附加限出境，驱逐出境附加行。
> 十四十六十八初，七旬孕哺四不拘；恶劣可拘一二三，二次以上一三项。
> 询问八十二二四，立案起算卅加卅；时效六月合并廿，当场五百缴二百。
> 听证四千吊销停，未成年拘不公开；从重一年曾受罚，记录封存人人同。
> 民间纠纷轻情节，可以调解不必须；和解履行经认可，不予处罚息争议。

5. 暂缓执行行政拘留的申请情形和条件是什么？

### 答案附录

1. 四情形：已满 14 不满 16 周岁；已满 16 不满 18 周岁**初次**违反；70 周岁以上；怀孕或哺乳自己不满 1 周岁婴儿。例外：**第一、二、三项**行为人**情节严重、影响恶劣**的，或**第一、三项**行为人**一年以内二次以上**违反的，不受限制。
2. 三档：一般 **8 小时**；**涉案人数众多、身份不明**的 **12 小时**；情况复杂、可能适用行政拘留的 **24 小时**。
3. 自**立案**之日起 **30 日**内办结；重大复杂经**上一级公安机关批准**延长 **30 日**，以二次为限；**鉴定期间、听证期间不计入**。
4. **吊销许可证件、处 4000 元以上罚款**的处罚决定和**责令停业整顿**措施；对**可能执行行政拘留的未成年人**；其他案情复杂或有重大社会影响的案件（当事人要求 + 公安机关认为必要）。
5. 情形：**申请行政复议、提起行政诉讼期间**，或**遇升学考试、子女出生、近亲属病危、死亡**等情形；条件：公安机关认为**暂缓执行不致发生社会危险** + 提供符合法定条件的**担保人**或**按每日 200 元交纳保证金**。

## 错题归因模板

做错时按四类归因，记入 [错题本.md](../错题本.md)：

- **数字错**：期限 / 金额 / 年龄线记串，或被**旧法数字**误导（回到时限速查表重记）；
- **措辞错**："可以 / 应当 / 必须"档位判断错；
- **范围错**：不执行拘留的例外条款适用范围、听证范围、封存范围记漏记错；
- **情境错**：案件性质判断错（治安 vs 刑事），导致整个程序选择链全错。
